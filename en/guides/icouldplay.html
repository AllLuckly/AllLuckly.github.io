You provide the videos and servers. First use a familiar local file to check picture and sound, then add a remote source. This gives you a clear comparison if something fails.

Choose a tutorial for your task

  • Play from an SMB folder: Open one NAS video and check access and playback.
  • Connect to Jellyfin: Check the server address, account and visible libraries.
  • Load SRT subtitles: Check language, video edition and subtitle timing.
  • Troubleshoot playback: Compare engines with the same file and isolate the problem.

Posters and categories describe media; downloads and playback access the content itself. These tutorials check them separately and do not treat a completed scan as proof that every file plays offline.
