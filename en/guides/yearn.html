Yearn does not include game ROMs. With your own files ready, take one game through import, launch, saving and loading again before organising a larger collection.

Choose a tutorial for your task

  • Check game files and platforms: Identify console formats and companion disc files.
  • Connect a Bluetooth controller: Pair in system settings, then check common buttons.
  • Use save-state slots: Distinguish Save from Load and check loading after exit.
  • Troubleshoot launch issues: Check files, platforms and errors when a game does not start.

A successful import does not guarantee every game is compatible. A save entry, a cloud-sync indicator and successfully restored progress are separate checks. Keep original files and existing progress when investigating a difference.
