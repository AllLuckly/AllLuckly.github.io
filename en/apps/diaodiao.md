**调调** is a personal music player for iPhone and iPad. Import audio from your own collection onto the device, or connect a compatible personal music server to keep that collection within reach.

Begin with one familiar track: check its title, artist and album, listen to the opening, then arrange what comes next. Confirm local import, server access and lyric availability separately.

## Ways to listen

- **Carry your own collection:** select audio from Files, iCloud Drive or another file provider, then play the imported copy on the current device. Confirm that importing has finished before relying on offline listening.
- **Transfer music from a computer:** connect the computer and device to the same Wi-Fi, enable Wi-Fi transfer in 调调, and open the address shown in the app using the computer’s browser to upload your audio in batches.
- **Browse a personal server library:** supply a compatible server address and your access account to browse and search your music. Reading remote content also depends on the server and network.
- **Plan a commute or bedtime queue:** arrange upcoming tracks, choose sequential, repeat or shuffle playback, and set a sleep timer. Background playback and lock-screen controls support everyday listening.

## Start with one track

1. Prepare a small audio file that you own or have permission to use, retaining the original. A recognisable MP3 or M4A makes an initial import easier to compare.
2. Select it through the app’s file-import flow. For iCloud Drive or another provider, wait until the file is readable and importing is complete before checking the music library.
3. Open the imported track and check its title, artist, album and available artwork. Listen to the opening and try pausing and resuming. 调调 reads available track metadata and embedded artwork, and skips files with duplicate content.
4. Leave and reopen the same track to confirm that it remains playable. If you need offline listening, temporarily disconnect the network and try that imported track again; a name in a file picker alone does not establish offline readiness.

Imported local music is stored on the current device. It requires neither a 调调 account nor a music-server connection. You supply any personal server address and access account separately.

## Arrange the queue and lyrics

Put two or three familiar tracks into the queue and check the upcoming order before choosing repeat or shuffle. For bedtime listening, verify the sleep-timer setting before continuing playback. Keep the timer’s setting distinct from the length of a track.

The player can display lyrics when the music source supplies them; timed lyrics support synchronised display. If lyrics are missing, first check what the audio or server provides. Availability depends on the source and server capabilities, so one lyric display does not mean every track will automatically receive lyrics.

## Import formats and the scope of your library

The public description lists **MP3, M4A, AAC, WAV, AIFF, CAF and FLAC**, with a maximum of **512 MB per file**. Import also depends on whether the system can read the audio track; DRM-protected files are not supported. Matching extensions do not establish matching encoding, integrity or readability. A short, known-working track provides a useful comparison when diagnosing a problem.

调调 provides playback tools for music supplied by the user, without a public online music catalogue. For a personal server, start with one authorised library and verify its directory and playback before expanding the collection. The public description does not enumerate every compatible server, and a result with one service does not certify all services.
