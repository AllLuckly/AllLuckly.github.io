准备一份包含PNG块名的小报告，在漫阅逐页核对四个字母。目标不是学会在阅读器里改图片，而是遇到外部检测清单时，能分清四个位置的独立意义。只凭名称可读出属性位，不能知道未知块的载荷、实际解码结果或一张漫画有几页。

## 先把报告做成能返回的三页

在外部文档工具新建三页：第一页放原始名称，第二页画四栏判读表，第三页留错误对照与核验记录。使用IHDR、tEXt和假设的私有名称vpAg作为练习，不往真实PNG里插入这些字节。每页加P1到P3角标并导出PDF，另留可编辑稿。导入漫阅后先检查三页角标齐全，再为判读表页添加书签。报告里的四字母只是文本，不是阅读器显示出的内部检测面板，也不因为报告有三个例子就推断源图片有三页。

## 逐字抄写后才给四栏命名

在P1放大到可区分大写I与小写t的程度，先逐字抄完整名称，再在P2按位置一到四对齐。PNG块类型用四个ASCII字母，每个字节的数值32位掩码可检对应属性位；这里说的是按位与32，不是第三十二个字符或三十二页。大写字母该位为零，小写为一。四位的意义各自不同，不能只数有几个小写就给整个块贴一个标签。示例IHDR结果全零，tEXt结果一、零、零、一，vpAg结果一、一、零、一。

还可用字符数值做独立抽查：小写t的ASCII值116，大写T为84，相差32；对116与32按位与得32，对84则得零。结果记零或一时须先说明把非零映成一，不能把原始32误抄成第三十二个属性。四字母本身共四字节，不能因表里列四种性质就说增加了四个独立块。若报告把tEXt统一显示成大写，先找保留原始大小写的输出再作判读。

```text
name  bit5 per byte (mask 32)
IHDR  0 0 0 0
tEXt  1 0 0 1
vpAg  1 1 0 1
```

## 第一位只判断关键与辅助

在第一栏写首字母大写表示关键块，小写表示辅助块。于是IHDR是关键，tEXt和vpAg是辅助；这不等于重要信息一定肉眼可见，或辅助信息都可以随意删除。解码器遇到不认识的关键类型时，不能继续假定自己正确理解整幅图；未知辅助块则可以忽略。把这些规范层面的处理要求写在报告旁，不虚构漫阅弹出的错误消息。若实际遇到打不开的图片，记录真实反馈并保留原件，不能仅因首字母大写就断言是哪一个块损坏。

## 第二位不表示文件是否联网

第二栏由第二字母判断公开或私有：大写为公开，小写为私有。所以tEXt的E表示公开，vpAg的p表示私有。私有是类型定义的范围，不表示加密、会员专属、包含个人信息或必须登录服务器。公开也不是已经上传互联网。vpAg在本课只借其字母模式做演示，未定义任何载荷；不根据名字猜它存封面、页码或作者。若外部工具给出实际私有类型说明，另存该工具的定义与版本，不能把本课的假设值当注册清单使用。

## 第三位保留规则不要改成渲染结论

第三栏的保留位在所引PNG版本中应为零，即第三字母大写。三例的D、X和A都满足这一点；若写成vpag，第三字母a变小写，该数据流不符合这版命名要求。但规范也要求解码器把这类名称作为未知类型处理，不应仅因保留位为一就报错。将文件合规与某个阅读器是否继续显示分成两行，不能由其中一项直接推出另一项。纠正练习报告时只改文字，别在原PNG上改大小写后误以为校验值和语义都会自动更新。

## 第四位放回编辑器的复制情境

第四栏说明未知块在图片被修改后能否安全复制：末字母小写为安全复制，大写为不安全复制。tEXt和vpAg的末字母是小写，IHDR为大写；这不是读图权限，也不是病毒扫描结果。该机制主要供PNG编辑器处理未知辅助块，认识的块还须遵守自身规则。即便安全复制，跨越IDAT前后的位置仍有限制，不能据此任意重排所有块。阅读本报告无需编辑文件；若以后用外部工具转存，另核工具是否保留元数据，不从一次显示正常反推全部资料保留。

## 用单位置错例检查自己的判读

在P3写tEXt改成TEXT的对照，只作为名称字符串，不说二者是同一种合法块。原名称首位与末位为一，改写后全零，因此既改变关键性也改变复制属性；不能把自动大写当作排版美化。再对照vpAg与vpAG，只有末位改变，前两栏应保持辅助、私有。如果四栏全跟着改变，回到按位置读的步骤。报告文字看不清时先放大并检查原PDF是否使用可辨字体，不能把显示模糊后的猜测填进表；保留未确认格而不制造确定答案。

## 重开后交付属性与观察两份账

退出阅读再打开书签页，不看P1先给三例填四栏，然后返回原始名称逐字核对。验收应能解释为什么辅助不等于私有、私有不等于加密、安全复制不等于可以随意重排。保留P3错例和更正理由，若重开或书签操作尚未做，就在记录中写待做。交付PDF、可编辑原稿和实际观察栏；本课得到的是报告语义判读，不是对任意PNG兼容性的证书。换了外部检查器后还应核名称是否原样显示，防止工具把大小写归一化后丢失关键证据。
