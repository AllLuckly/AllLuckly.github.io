用自制 TXT 比较预组与组合重音、全角与半角搜索，逐条核原文与实际结果。

## 建立只用于测试的小文本

在自己已有的文本工具里新建练习稿，准备四行不同标记：A 行的 café 末尾使用预组字符 é，B 行的 cafe 后面跟组合重音，C 行是 note 加全角数字４，D 行是 note 加半角数字4。四行前面的 A、B、C、D 用来定位结果，并非要搜索的正文。先保存自己的原文件及来源，测试只用新建副本，不改写正式书籍。实际输入工具可能自动转换字符，因此外观相似不能证明 A 和 B 的码点顺序仍然不同；必须记录原稿和复制时经过的工具。

## 用已有工具生成可复核字符

如果电脑已装 Python 3，可在一个新建空练习目录运行以下自写脚本。它以 UTF-8 创建 book-search-sample.txt，使用独占创建：已有同名文件时会报错而不会覆盖。脚本输出每行去掉字母标记和空格之后的码点，用于检查素材而不是推断书屿搜索实现。A 的最后码点为 U+00E9；B 是 U+0065 U+0301；C 数字为 U+FF14，D 为 U+0034。没有 Python 时可用已有支持码点检查的工具，无法确认则将该环节记为待核，不下载陌生程序。

```python
from pathlib import Path
lines = ["A caf\u00e9", "B cafe\u0301", "C note\uff14", "D note4"]
with Path("book-search-sample.txt").open("x", encoding="utf-8", newline="\n") as f:
    f.write("\n".join(lines) + "\n")
for line in lines:
    print(line[0], " ".join("U+%04X" % ord(c) for c in line[2:]))
```

## 导入副本并检查四行显示

通过书屿当前可见的本地导入入口选择测试 TXT，打开后逐行确认 A 至 D 和文字均可见。记录应用版本、设备、文件名、导入时间，以及显示是否发生乱码或缺字。样本很短，分章或书架排序不是本次要验证的对象；先确认内容可读，再测搜索。若工具改变了字符、系统选择的是另一个同名文件或文本只显示前两行，先回原稿确认副本身份，必要时另存新样本，不能把这些情况直接归因于搜索。

## 在同一本中逐个提交查询

进入当前书籍实际可用的正文搜索，先输入预组形式的 café，记录输入来源、命中数、结果片段和标记 A 或 B；回到同一书后分别查询分解形式、全角 note４ 和半角 note4。每次清除上一条查询，再观察返回列表，不要同时更换书籍、范围和设备。若键盘或复制操作自动规范化输入，注明无法确认查询的原始码点；系统显示一样并不保证输入字节相同。本课不预设四次搜索必然分别命中哪一行。

## 点进结果而不是只数条目

对每个实际结果点入正文，核左侧 A 至 D 标记和附近整行，再返回搜索列表。把查询、可确认的码点、显示命中数、实际进入的行和是否有重复分别登记。结果摘要可能截取不含标记的片段，必须进正文核对；同一页面出现两行也不能只凭页面相同就说只有一次命中。若界面不显示总数或不提供逐条跳转，照实记录可见范围，不用假定隐藏结果。

## 分开字符相等与检索行为

Unicode 的 NFC 和 NFD 能把预组与分解的规范等价形式统一到各自选定的表示；全角数字与半角数字属于兼容关系，不应直接叫作同一个码点。以样本核外部字符关系：A 的预组词和 B 的分解词不具有相同码点序列，但做 NFC 后相等；C 的全角数字与 D 的半角数字做 NFC 后仍不同，做 NFKC 后可以一致。这个对照解释两类标准关系，不能把兼容规范化当作所有正式文档都必须执行的清理步骤，因为它可能抹掉原先有意义的表示差别。某次搜索若同时找到两种形式，只说明这一文件、查询和环境下的可见结果，可能有多种实现路径；若只找到一种，也不证明全部字符或全部书籍都会这样。搜索是否忽略大小写、重音或采用其他匹配规则，也须另作受控测试。没有读取实现或系统输入处理的证据，就不要把结果写成某个确定的底层算法。

## 无结果时按层排除

先确认搜索范围是当前这本测试书，目标行在正文可见，查询没有多余空格或遗漏重音，再确认文件已经正确导入。可用 ASCII 的 note4 作同文件对照；如果它也无结果，继续检查搜索入口、索引或实际错误，不先认定是重音归一化问题。若目标能在正文看到却无法从查询进入，保留文件副本、输入方式、完整提示和版本，按实际界面重试一次。不要随意批量改写原书、删除索引或重装应用。

## 重开并提交带范围的结果

退出再打开同一测试书，重复至少一个先前查询并核正文行，记录是否出现相同结果；未执行的导入、查询和重开分别写未完成。交付练习源稿、码点清单与四次查询记录，附设备、版本和时间。复制过程若已规范化字符，应保留这一限制，不能用视觉截图冒充码点检验。测试结束按自己的选择保留练习文件，正式阅读资料和笔记照常保存；一次小样结果不替代其他格式、语言或版本的兼容性测试。
