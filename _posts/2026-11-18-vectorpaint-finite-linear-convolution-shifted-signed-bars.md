画一张离散卷积的移位叠加图，先列每个输入样本贡献，再把同一索引的贡献相加。负柱保留在零线下方，四个输出索引不能为了对齐三项输入而删掉最后一项。这是外部数学账本的矢量展示，不是给图像或声音调用滤镜。

## 先声明有限序列索引与零延拓

设x[0..2]=(1,2,1)，h[0..1]=(1,−1)，范围外两序列均为零。定义y[n]=所有整数k上x[k]h[n−k]之和，这里只有有限非零项。h的负一是符号值，不是缺失数据，也不是应取绝对值的长度。建立输入表、移位贡献、输出柱、索引与说明图层，先存原生稿。样本无量纲，索引表示离散位置，不自动代表秒或像素；若另赋采样间隔必须独立声明，不能从画面列间距推断真实时间。

## 先定四项输出范围再画列

最小可能非零索引为零加零，最大为二加一等三，因此完整线性输出占n=0、1、2、3四列，长度三加二减一等四。即使某列相加后恰为零也保留其索引，不能按柱子是否可见决定长度。先在账本画四个等距栏，再放输入和移位行，避免边做边把最后一列裁掉。序列相乘不是把对应位置直接逐项相乘；若只写一、负二、一三项，既没有正确处理h的长度，也没有执行定义里的移位求和。

## 逐个输入样本生成带权移位行

k=0时权重一，贡献(1,−1,0,0)；k=1时权重二，把h右移一列并乘二，得(0,2,−2,0)；k=2时权重一再右移两列，得(0,0,1,−1)。每行注明k与x[k]，用浅色框对齐同列，零也写出以便查索引。移动的是贡献的位置，权重二同时乘h的正负两项，不能只把正柱加倍。h只有两项，不要把空白栏随意补成一；零延拓的零是定义的一部分，画图留白不是自由选择数值。

## 按列求和并用定义抽查中间项

四列相加得到y=(1,1,−1,−1)。单独核n=1，x[0]h[1]+x[1]h[0]为负一加二等一；核n=2，x[1]h[1]+x[2]h[0]为负二加一等负一。超范围项为零，不能把h[负一]或h[二]当成最后一项循环读取。画输出时每列只保留一个合计柱，移位贡献仍留在独立层供检查。不要把正负贡献的绝对高度相加，那会把代数求和变成完全不同的能量或总量指标。因核为(1,−1)，本例也等于y[n]=x[n]−x[n−1]，用零延拓得首项一减零、末项零减一，再核边界两项。核总和为零，尤其不能除以核总和来“归一化平均”，该除法未定义。

## 用总和与多项式作两项外部校验

输出总和一加一减一减一为零，等输入总和四乘核总和零；该总和关系是查漏列的必要线索，但单凭总和零不能证明每列都正确。再把系数写成(1+2z+z²)(1−z)，展开为1+z−z²−z³，四个系数与输出一致。z是形式变量，不是画布纵坐标。把两项校验放在旁栏，保留逐列计算作为主证据；若总和对而中间正负号互换，仍必须判错，不能用一个整体守恒值掩盖局部索引错误。

```text
x[0..2]=(1,2,1); h[0..1]=(1,-1); zero elsewhere
y[n]=sum_k x[k]*h[n-k]
k=0: 1 -1  0  0
k=1: 0  2 -2  0
k=2: 0  0  1 -1
y:   1  1 -1 -1
sum(y)=0=sum(x)*sum(h)
(1+2z+z^2)*(1-z)=1+z-z^2-z^3
length-3 circular control: (0,1,-1)
```

## 保持正负零线与列宽一致

建议2200×1700画布，输出n零到三的横位置依次400、800、1200、1600，零线Y=1300，每值一对应180像素向上。正一柱顶在1120，负一柱底在1480，均留画布内，标签写带符号的值。输入与贡献表置上方，文字不盖住零线。缺少数值栏时用辅助线手工规划，不能为塞进页边把某个负柱向上翻。SVG或PDF中保留文字与矢量柱便于阅读，若导入位图参考则单独记录，不把混合内容自动叫全矢量结果。

## 区分循环折返与按重叠数平均

若另定义长度三循环卷积，线性结果n=3的负一折回n=0，得(0,1,−1)，这是不同边界规则，不能当作原四列图的修正版。若每列再除以参与项数，则是在定义另一个平均操作，本课没有这一步。排障先查线性还是循环、零延拓和索引方向，再查负号与权重；不要先改柱宽来掩盖算式不一致。控制版本需另存并标清规则，允许比较不同结果，但不能把规则变动藏在“软件显示差异”中。

## 重开由移位行恢复四个输出

保存可编辑贡献行和输出组，导出SVG或PDF并另开PNG，缩小核四列索引齐全，放大核下方两根负柱与负号。重开原生稿先隐藏输出，按三行逐列复算再恢复对照；确认n=3未被裁掉或误折返。交付定义、四列账、总和与多项式校验及循环控制，未做的操作记待办。该图说明有限线性卷积，不承诺VectorPaint提供信号处理、自动卷积或实时滤波能力，也不由无量纲样本推断实际音质或图像锐度。
