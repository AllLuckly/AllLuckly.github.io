阅读一份本地 HTML 时，目录文字可见，不等于点击后一定能跳到正确位置。本课用自制单文件样本比较链接的 `href` 片段和目标元素的 `id`，先在本地网页工具核对，再观察书屿导入后的可见结果。这里的链接指向同一份文件内部，与旧课的外部网页、相对图片是否离线可用是两个问题；不假定书屿一定保留或支持任何 HTML 跳转。

## 准备两个可区分的练习副本

在自己已有的纯文本编辑器中新建 UTF-8 文件 `anchor-good.html`，写入下方样本。它不包含脚本、外部图片、远程样式或网络请求，文字为自创的无隐私示例；不需要上传到网站。保留这个原样基线，再另存一份 `anchor-missing.html`。不要改动用户已有网页或电子书，也不要把扩展名 `.html.txt` 当成 HTML 文件。

```html
<!doctype html>
<html lang="zh-CN">
<meta charset="utf-8">
<title>文内跳转练习</title>
<p><a href="#part-b">前往第二节</a></p>
<h2 id="part-a">第一节</h2>
<p>这里是第一节的自制练习文字。</p>
<div style="height: 100vh"></div>
<h2 id="part-b">第二节</h2>
<p>目标句：青山之后是小河。</p>
</html>
```

在第二份副本里只把链接目标从 `#part-b` 改成 `#part-c`，保留第二节的 `id="part-b"` 和其他内容不变。前者有匹配目标，后者没有同名 `id`；内容相同便于定位链接差异。不要直接改基线，也不需要创建或删除用户原有文档。若没有适合编辑 HTML 的环境，可保存纸面结构并将后续操作标记未完成，不到未知网站上传文件。

## 理解片段与标识的关系

`href="#part-b"` 指向当前文档的片段 `part-b`，目标标题的 `id` 为 `part-b`；链接中的井号表示片段引用，本例 `id` 值自身不包含井号。HTML 标准定义文档标识与片段导航；名字必须按源文件实际字符核对，不因标题文字都是“第二节”就认为两个标识相同。此处选用简单 ASCII 标识，避免把编码、大小写和网络地址混成另一项实验。

第二份的 `#part-c` 没有对应目标，浏览器可能不移动或以其实际方式处理；不要预填具体错误提示。页面中的 `style` 只帮助在一般浏览器产生一段空白，让跳转更易观察；书屿可能忽略该样式、重排内容或不呈现链接，因此不能把空白大小当作兼容性保证。

## 先在本地网页工具建立参照

在支持交互 HTML 的本地浏览器或已知安全的预览工具中打开 `anchor-good.html`。先在文档顶部找到“前往第二节”，再向下确认第二节与目标句确实存在。回到顶部，在同一窗口点链接，观察标题或目标句是否进入可见范围；记工具、文件名、实际位置和反馈。若整个页面因屏幕太大而同时可见，先缩小可视窗口或使用工具的可恢复缩放，再观察；不能确认移动时写待核。

再独立打开 `anchor-missing.html`，确认其正文仍有第二节，然后点同名链接，记录实际结果。先核正确副本和错误副本的源代码，不把两次浏览器结果互相代填。此参照只说明该本地工具对样本的行为，不说明书屿已经通过。

## 导入书屿并识别版本

通过系统可信文件传送将两份样本送到 iPhone 或 iPad，记接收位置类型和文件名。打开书屿，在当前可见的本地文件导入入口先选择基线文件，记录预览和导入反馈；再尝试导入缺失目标的副本。若应用按内容或名称去重、只生成一个条目，按可见反馈记录，不删除已有书籍，也不凭文件名相似推断两份都已导入。

从实际可打开的条目中先确认开头、第二节和目标句；如果内容缺失、只显示部分正文或无法识别是哪份文件，暂停跳转判断。书屿公开支持 HTML 阅读，但不保证它呈现所有样式或文内链接。若链接文字被提取为普通文本，记录“文字可见，跳转入口未观察到”，不要求设备出现不存在的控件。

## 对照链接动作与目标

若实际阅读界面提供可操作的链接，在用户愿意时从已确认的基线顶部触发一次，观察目标标题、正文位置与反馈。没有动作或不能点按时如实记录；若页面本来很短、两节同时可见，则视为跳转结果无法判定，而不是凭“第二节在屏幕上”写通过。不要将点击次数、浏览器历史或目标句能手工找到，自动等同于链接跳转成功。

只有在能够确认第二份确实独立打开的情况下，才对缺失目标副本做同一观察。若应用展示了位置变化，记录具体显示；若没有变化，也不要据此认定所有无效片段行为相同。两份不同文件、两种阅读器和文字提取路径均可能影响结果，比较时注明设备、版本与可见界面。

## 排查与安全边界

本地参照失败时先核 `href` 是否以 `#` 开头、目标 `id` 是否完整一致、文件是否保存以及是否误开了错误副本；每次只改练习副本的一项。浏览器正常而书屿没有链接时，记录是否只提取了文本、样式和目标标题是否可见，不假设必须保留网页交互。若导入失败，先查文件类型、编码、接收位置及应用反馈，不通过重装、清库或连接陌生服务器排查。

本例没有外部 URL，也没有脚本或表单。不要为测试把私人 HTML 上传到第三方服务；与支持人员沟通可提供这份自制样本、版本和脱敏反馈。实际书籍如含外部链接或图片，应另按原始来源和用户授权判断，不从本次文内片段测试外推。

## 保存结果并恢复

交付一张表：两个文件的 `href`、目标 `id`、本地参照、书屿导入结果、可见链接动作、目标位置及待核项。保存原基线和错误副本；是否清理练习文件由用户决定。恢复原本阅读位置和设置，不删除已有作品或笔记。本文未声称在书屿、浏览器或设备上完成真实导航测试。
