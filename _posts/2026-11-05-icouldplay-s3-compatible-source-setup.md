S3 兼容存储的网页管理台和对象访问接口通常不是同一个地址，网页登录密码也不等于 API 凭据。云映 1.1.1 的公开说明加入 S3 兼容存储，本篇从已有服务的小范围读取开始，不指导购买服务、创建长期密钥或迁移整个媒体库。请让服务管理员提供已授权的读取配置与一个可用视频样本；没有这些条件时，先整理所需字段，不用随机网上地址和别人的密钥试连接。

## 向管理员取得完整读取配置

先整理服务端点、桶名、区域、访问密钥标识、秘密访问密钥、是否采用临时会话以及允许的对象前缀。管理员还应说明采用路径式还是虚拟主机式访问，以及样本在桶中的完整键名。普通观看只需任务所需读取能力，不应为了排查索取全服务管理员账号。把秘密保留在可信的交付方式里，操作清单只记字段是否齐全和身份代号。若管理员给的是一条临时下载网址，应说明本篇需要 S3 来源配置，不能把那条网址拆成猜测的密钥来填写。

## 核对端点不是管理页面

在云映添加来源选择 S3，端点字段按服务给出的 HTTP 或 HTTPS API 基础位置填写。示意 `https://objects.example.com` 不是实际服务，请替换为自己的可信端点，不把管理台登录页、桶中某个影片网址或 `s3://` 形式的对象标识直接放入该字段。当前 S3 表单端点只接受协议、主机与必要端口，不含服务子路径、桶名或对象键；若部署必须使用子路径，当前入口可能不适用，应由管理员提供兼容端点，不能拿对象前缀代替服务前缀。保存前核对协议、主机和必要端口，HTTPS 出错时先核对正确地址与证书，不以关闭验证作为教程步骤。

## 桶名和区域各按实际服务填写

桶名只填写实际桶的名称，不加协议、斜线或影片名。区域按服务文档或管理员给出的签名区域填写，不能因为界面有默认值就认为它适合所有兼容服务。区域影响请求的签名配置，服务网页显示的地理位置名称也未必就是该字段接受的字符串。先把桶名和区域逐字对照，不边改区域边换账号。某个服务要求固定区域时，保留这个条件作为该来源的记录；它不代表其他 S3 服务都使用同一个值。测试失败只得到通用提示时，也不要凭提示猜测真实桶是否存在。

## 完整填写同一组凭据

把访问密钥标识和秘密访问密钥填到对应字段，二者不是用户名和网页密码。管理员提供的是临时凭据时，还需要同一组会话令牌；不能把昨天的令牌与今天的新密钥拼起来。复制后注意前后空白、截断和输入法替换，不把内容显示在录屏或公开截图中。没有会话令牌的长期凭据不要凭空填入随机文字；确属临时凭据但缺一项时，应先取得完整授权配置，而不是绕过它。本文只核对现有读取配置，不要求生成新密钥或扩大权限来换取成功。

## 访问方式和对象前缀缩小到样本

路径式开关按服务支持的方式设置，不靠随机切换协议和桶名同时试错。两种地址结构可参考 [AWS 桶虚拟主机说明](https://docs.aws.amazon.com/AmazonS3/latest/userguide/VirtualHosting.html)，兼容服务仍应以自己的部署要求为准。对象前缀用于把浏览范围缩小到练习目录，例如桶内已有 `practice/clips/`，不要再把桶名重复写进去。前缀不是访问权限规则本身，限制界面浏览范围不等于凭据已被限制。只选择本来已获准读取的范围，后续再单独核对实际可见对象。

## 连接后验证列表与文件各一次

运行当前界面的连接与目录选择流程，先找管理员确认的样本，不为扩大测试直接扫描整个桶。对照文件名、可见大小和层级，然后播放开头与中间的内容锚点。列出对象所需的请求与读取视频的请求不同，能看到文件不保证能取得它的内容；反过来，一条可用下载链接也不保证该身份可以列桶目录。若列表正常但不能播放，把两项分开记录，请管理员核对样本的读取范围。不要把文件名出现解释为已经在手机留下完整离线副本。

## 失败时一次只改变一类字段

完全无法列目录时，按端点与访问方式、桶与区域、凭据是否完整及有效、允许前缀的顺序核对。不要在一个步骤里把四类都改掉，否则偶然成功也不知道哪项原来错误。只有某个文件失败时，保持连接配置不变，先核对该对象身份与服务端可读状态。兼容实现、加密条件或对象类型可能有差异，不承诺任何标为 S3 的服务都可直接使用。需要协助时只提供字段种类、服务名称和失败阶段，隐藏密钥、令牌、签名网址与真实私人对象名。

## 留下可维护的来源说明

最后记录服务代号、桶与前缀的脱敏说明、区域、访问方式、样本结果和核对日期，凭据仍按原有方式管理。恢复练习播放位置，保留原对象，不在此次入门中执行删除或移动。以后凭据轮换、区域配置改变或服务迁移，先用同一样本重做连接、列表与播放三项，再恢复日常使用。写清哪些只是已保存、哪些已经看到、哪些实际播放过，避免一条来源卡片存在就被当成所有文件和所有设备都验收完成。
