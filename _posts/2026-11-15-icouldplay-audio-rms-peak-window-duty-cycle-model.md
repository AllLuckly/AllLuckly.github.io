两段声音最高点一样高，平均持续程度仍可能不同。本课先用四个抽象样本手算均方根RMS，再在外部分析自己的音频，并用云映听同一个已登记片段。抽象数字不会直接拿去耳机播放，也不把RMS当成响度、听力安全或播放器音量百分比的等义词。

## 一、给数字模型和声音文件分不同名字

纸上准备A、B两行数值，另为自己的实际短音频记录文件名、长度、采样率和声道。四个样本只是展示算式的抽象模型，不是有意义的四秒音频；样本个数与秒数取决于采样率。真实听辨选自己已经能正常播放的温和片段，在舒适音量下开始，不为了比较冲击感提高设备音量。原件保留，任何外部处理都另存，不覆盖云映当前的参照来源。

## 二、先计算两个绝对峰值

A依次为0.5、负0.5、0.5、负0.5，B为0.5、0、0、0。对每个样本取绝对值，再找最大值，两者都是0.5。符号表示波形方向，不能用普通最大值与最小值互相抵消，也不能因为A有负数就说它音量为负。把绝对峰值与带符号的样本序列分别写，避免后面开平方时才发现第一步已经把正负号当成音量控制。

```text
A = [0.5, -0.5, 0.5, -0.5]
B = [0.5, 0.0, 0.0, 0.0]
peak(A) = peak(B) = 0.5
RMS(A) = sqrt((0.25 + 0.25 + 0.25 + 0.25) / 4) = 0.5
RMS(B) = sqrt((0.25 + 0 + 0 + 0) / 4) = 0.25
```

## 三、依次平方、平均和开平方

逐个平方后，A四项都是0.25，总和为1，除四得到0.25，再开平方为0.5。B只有第一项平方为0.25，总和0.25，除四得到0.0625，再开平方为0.25。每一步的中间值都保留，不先对样本求普通平均再平方；A的普通平均为零，但它并不因此没有信号。本课要交付能复算的步骤，而不只是记住峰值相同RMS不同这一句结论。

## 四、用共同窗口检查零值的影响

两个模型都保留四项。B的三个零值仍在平均分母中，所以RMS降低；若只挑非零样本算，就变为0.5，已经改变了测量窗口与问题。对实际音频，同一段开头结尾和静音是否纳入必须记录。不要拿A整段和B最响的一小瞬间比较，再把差异归给文件格式。空轨道区域和真实数字静音也应按外部工具的定义区分，不能假定每个分析器都以同样方式处理空白时间。

## 五、将比例换算与设备音量分开

在相同数字参考下，RMS从0.5到0.25是振幅量值减半，对数差约负6.02dB；这个计算并不规定手机音量要调到某个百分比。绝对峰值若用同一满刻度参考也约为负6.02dBFS，两种数恰好相同仍是不同列。模型没有考虑频率加权、时间积分方式或人的听觉，所以不能把两倍RMS直接译成两倍主观响度，更不由这些数值给出听力安全结论。

## 六、在外部工具分析真实固定区间

如果已有Audacity等工具，可选定自有音轨的一段固定时间，使用实际提供的分析功能登记RMS。记录工具版本、选区起止、声道与数值，另一段采用相同窗口规则；没有工具就完成模型算式，不虚构报告。立体声的左右数据是否都存在也要核实。不要把云映进度条或设备音量滑块当作RMS测量仪；播放器没有公开分析入口时，外部结果必须明确标注来自外部。

## 七、在云映把听感写成独立观察

打开与分析记录同一身份的音频或视频，固定输出设备、音量和所选轨道，听已标记的区间。可以写声音更持续、某处瞬间突出或难以区分，不把听感硬改为计算出来的预期。两个文件若经过不同归一化、声道混合或输出处理，先登记这些条件，别把全部差异归到RMS。重新选轨后也应重核来源身份，避免分析一个文件却听另一个同名副本。

## 八、改变分母观察窗口造成的偏差

再给B尾部加四个零，得到八样本模型C，绝对峰值仍为零点五，平方和仍为零点二五，但平均后变为零点零三一二五，开平方约零点一七六八。信号中的非零值未变，窗口加长却改变了RMS。这里并非应用偷偷调低音量，而是自己改变了统计问题。请把四样本和八样本两种分母圈出来，再用同一工具复核真实区间是否包含了额外静音。若两段录音时长不同，先确定比较的是整段持续程度还是相同长度的片段，再选窗口；不要只为了得到更接近的数字删掉较安静的部分，也不要宣称这些离散模型是对真实歌曲的实测。

## 九、重算并交付不同层次的证据

重开笔记，复算峰值0.5与RMS的0.5、0.25，再核分母四和共同窗口。交付抽象模型、外部工具记录或未执行说明，以及云映的实际听辨；不把四样本模型冒称已制作的影片，也不把分析数值冒称所有播放路径的输出电平。原音频与参照文件保留，后续改音量或转码时另开一行记录，确保比较对象与单位始终能追溯。
