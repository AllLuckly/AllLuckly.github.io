用同一份已核字体比较拉丁字母与一个未映射汉字，先在外部读字符映射，再在实际键盘观察。交付覆盖证据与显示记录；官方图说缺少字符使用系统字体，不等于看见相似字形就能证明具体哪套系统字体参与了本次渲染。

## 一、固定被检查文件而非只记家族名

选择自己有权使用、已能在安装版导入或选择的字体，保留原文件与实际来源。本课外部示例采用下方Noto Sans文件，给出本批保存的完整文件哈希，避免以后同名更新后仍引用旧结果；不要求每种设备都接受这份可变字体。家族名字相同不保证字节与覆盖相同，另一个Noto系列也不能直接套结论。先记当前键来所选字体、主题、字号与宿主，原稿继续保存。没有确认实际选中的字体就只做外部覆盖练习，不把它说成已经在手机观察到回退；所有材料均来自公开作者来源或自己的授权副本。

```text
NotoSans[wdth,wght].ttf
SHA-256: bfb7bb691513f12e734dc346c03a03f784912432d7e3fa8e56efcf906fe86b3d
```

## 二、用字符身份定义映射问题

在外部卡写大写A为U+0041，汉字雨为U+96E8，比较的是这两个码点在选定字体的基本字符映射中是否有非零字形。OpenType的cmap将字符编码映到默认字形索引，缺字通常用零号未定义字形表示，所以仅看到表里有一个键名也不够，仍要核是否有效映射。它不直接回答实际键盘用了哪套回退字体，也不代表复杂排版或变体序列全部支持。不要把字体文件名、Unicode编码和屏幕字形混作一件事，更不能因为雨显示正常便倒推原字体必然含这个汉字。

## 三、已有工具时读表不在键盘执行脚本

已有Python与FontTools环境时，可把下方代码保存到电脑练习文件，确认字体实际路径后运行；这里没有在键来里粘贴执行的入口。代码先取可用Unicode映射，再检查对应字形是否非零，没有Unicode表就明确停止，不把未知当全部缺字。没有该工具可使用已有的字体字符报告，但要记录方法，不能凭家族宣传语猜覆盖。本批另用独立的字体二进制映射检查，所保存示例对A有映射、对雨没有；这是外部文件证据，不是FontTools脚本或手机渲染已经执行的承诺。读者取得不同版本应重新核，不能照抄预期当运行输出。

```text
from fontTools.ttLib import TTFont

font = TTFont("NotoSans[wdth,wght].ttf")
try:
    cmap = font.getBestCmap()
    if cmap is None:
        raise ValueError("No Unicode cmap; coverage not established")
    for ch in ["A", "雨"]:
        name = cmap.get(ord(ch))
        glyph_id = font.getGlyphID(name) if name is not None else 0
        print(f"U+{ord(ch):04X}", glyph_id != 0)
finally:
    font.close()
```

## 四、在同一键盘分别找可观察字符

保持字体与主题，回私人普通笔记确认当前确为键来。先在真实字母键面观察A，再用自己熟悉且当前启用的中文方案产生雨的候选，按安装版实际方式完成，不假定所有方案用同一拼音编码。如果没有雨候选或某区域不可见，写不适用，不用宿主正文截图代替键盘观察。官方图把作用范围列为按键、候选字与编码区，实际能看哪一层就记哪层。到提交正文时另核文字，宿主采用自己的字体并不说明键来导入失败；它与键盘内部的显示是另一条证据。

## 五、将外部缺字与当前显示共同解释

若已确认选定文件未映射雨，而当前候选仍能显示雨，可以把这与公开的系统回退说明并列，写为与回退机制相容的观察。不要仅凭看起来像系统字便宣布具体字体名称，也不能把汉字出现说成文件突然增加了字形。若A也看着和默认接近，可能只是轮廓本就相似，需保留选中状态与外部映射，不急着判完全没应用。另一字体若两字都有映射，就没有本例缺字对照，应换真实未映射字符并另立身份卡，或把回退观察留空；不能为了符合预期改报告内容。

## 六、恢复默认作参考不冒充渲染检测

保存自选字体结果后，可通过真实恢复默认字体入口建立另一轮参考，重新产生同样候选再比较；旧的未提交组合不保证在进入设置后保留。这个动作只改字体条件，不同时调候选字号或语言。默认轮与自选轮汉字相似，最多是可见形状的对照，不能代替系统渲染日志证明回退链。缺字回退保证范围也不等于每个符号、emoji或组合标记都能在任何环境正确显示，本课只处理已明示两个普通码点。若默认不是原先日常值，最后还需按记录恢复，不能把默认一词偷换为精确原配置。

## 七、按映射选择与可见层逐项排障

外部工具无Unicode表时先保留检查范围未知，导入后找不到家族先回文件与选择过程，只有宿主正文不同则回宿主样式。不要把所有现象统称缺字，也不因一个字符没显示就断言整字体损坏。若实际候选变了，先核输入方案与原样样本，不从候选排序变化推断字形映射被改写。每轮只修一项，保留字体原件与报告，不在字体软件里随意改字形让它符合已写结论。本课没有修改字体、生成回退字体或自动扫描键盘覆盖的功能，未运行的工具和未观察的区域继续标待核。

## 八、交付文件映射显示三层台账

保存字体来源与哈希、两个码点的外部映射结果、键盘实际可见层和正文，明确哪一步用工具、哪一步用公开说明、哪一步是自己观察。重开输入区后再核当前选择，实际做过才写返回成功。应能解释未映射汉字仍可显示为何不矛盾，同时承认无法从外观确定全部私有渲染细节。以后换字体版本、中文方案或设备重做必要检查，不能把Noto Sans这一文件的A与雨结果推广到同名系列或全部字符。日常字体与稿件恢复到自己确认的状态，原始材料继续保留。
