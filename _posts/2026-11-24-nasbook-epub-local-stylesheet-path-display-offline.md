用可编辑的短篇 EPUB 比较原始文字、样式资源路径与离线阅读结果。

## 先区分文字与样式

一本 EPUB 的正文可以引用包内 CSS 样式表；文字内容、样式规则和阅读器自己的显示设置是不同层次。章节看起来没有预期的间距或颜色，并不一定代表文字丢失。本练习从合法自制的样本入手，比较路径、资源和实际显示，不推断书屿一定提供 CSS 编辑入口。

## 建立两段可识别正文

在支持 EPUB 的编辑器中建立测试书，写一个独特标题及两段短文，给第二段添加容易识别的间距或字重规则。请使用自己编写或获授权的文字和字体；保存独立副本，避免覆盖日常阅读的书籍。把标题及两段首句记在纸上，后续用于确认内容是否完整。

## 核对样式文件与清单

查看编辑器里的章节文件和 CSS 文件，记录两者在 EPUB 内的相对位置。EPUB 包的资源清单应列出相关资源；核对样式文件存在、媒体类型正确，并确认章节引用的是这份样式，而非同名旧文件。不要凭电脑上原始文件存在就认定它已经被打包进 EPUB。

## 检查相对引用的起点

样式引用中的相对路径应从引用它的章节文件位置解析，而不是从电脑桌面或任意文件夹开始。打开编辑器中的链接检查，逐段核对目录名称、大小写及文件扩展名。若章节位于子目录，而样式位于另一个目录，应按实际结构设置路径；不要在未检查的情况下随意增加返回上级的符号。

## 检查样式表内部资源

如果样式又引用了包内图片或可用字体，分别检查这些引用及其资源清单，不把 CSS 文件存在等同于依赖资源齐全。为避免字体授权与可用性干扰，第一次样本可以只使用段落间距。若外部网络资源参与显示，应另行记录联网条件，不把网络上的文件当成已包含在离线书包内。

## 校验并保存测试副本

运行编辑器的 EPUB 检查或 EPUBCheck，先修复资源缺失、链接及包结构报告，再另存测试副本。把检查时间、工具报告和文件名放在一起，保留最初原件；校验通过只表示检查范围内没有发现相应问题，并不保证每个阅读器都会采用每条样式规则。

## 导入书屿核对书本

通过书屿当前提供的文件导入入口选择样本，先确认标题和两段首句，防止误开旧版。记录设备、应用版本以及是否使用阅读器自己的文字或主题设置。具体按钮依实际界面为准；若无法导入，保留具体错误，不删除书库或替换原书作为第一步。

## 比较正文与间距

在同一阅读环境下查看两段，先逐句核对文字，再观察第二段的样式是否可辨认。即使两段看起来相同，也分别记录正文完整性与视觉结果；阅读器可能应用用户偏好或限制部分样式。不要宣称某条 CSS 在书屿受支持，除非本次真实观察有证据。

## 复核离线结果

如需判断包内资源是否够用，先确认样本导入完成，再按设备实际方法暂时断开网络，在书屿重新打开该样本并比较两段。操作前确保不影响其他正在进行的任务，结束后恢复原网络；如无法断网，记录未执行。离线文字可见不等于所有字体、图片和链接都已核对。

## 每次只改一个条件

当样式异常时，在合法工作副本中先修正一处路径或缺失资源，重新校验后以不同文件名保存，再导入并重复相同观察。不要同时改主题、字号、内容和路径，否则无法分辨变化来源；若客户端保留旧书记录，先确认当前打开的副本。保留修改前后的报告，方便回退。

## 留下可复查的证据

记录样本名称、章节与样式相对路径、校验结果、正文完整性、显示差异、联网状态及未完成步骤。比较其他设备时另起一行，避免把一次观察推广到所有版本。只分享自有短句与不含隐私的报告，完成后保留原件和备份。本教程没有声称已进行真机或私人书库测试。

## 分清缺失文件与覆盖样式

路径存在且校验通过，仍可能出现排版不同：例如阅读器的用户设置覆盖了部分书籍样式，或者所选规则在当前阅读环境未呈现。先保持同一本测试副本和相同字号，记录已启用的主题；如果确有可用设置，再逐项切换并还原。不要把未观察到的设置写成书屿必有功能，也不要据此修改原书。

## 用第二个工具交叉核对

在另一款可信 EPUB 检查工具中查看同一副本的正文和资源报告，有助于区分打包错误与不同显示结果。先核对文件名及内容一致，并记录两边各自的显示条件；一个阅读器能显示某种样式，不能证明另一个阅读器必须采用完全相同的规则。若报告不一致，保存具体提示及检查工具版本，再逐项核实。
