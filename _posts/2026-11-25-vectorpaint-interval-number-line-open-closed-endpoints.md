画出 [-2, 3) 的数轴，核对端点、刻度、区间符号与测试值。

## 先写明要表达的范围

本图表达所有满足 -2 ≤ x < 3 的实数，区间记为 [-2, 3)。左端 -2 包含在内，右端 3 不包含在内，两端之间所有实数都包含；这不是只包含整数的列表。OpenStax 用方括号表示包含端点、圆括号表示不包含端点。开始画之前先把不等式、区间和两个端点写在纸上，避免边画边改变含义。

## 新建画布并分开对象

在 VectorPaint 新建横向作品并保存可编辑原稿，例如选择约 1600×900 的画布。使用当前版本实际可见的对象或图层入口，将数轴、刻度、区间线、端点和文字分组或分开保存；名称可自行选取。保留上下空白供区间符号与说明使用。若界面与教程不同，先核对可见工具，不假定每个按钮名称相同。

## 建立水平轴线

用直线或开放路径画一条水平轴，左右留边；如果使用箭头，请让箭头说明数轴继续延伸，而不是把箭头误认为区间包含所有方向。把线与端点图形分开，之后可以单独调整粗细。缩小画面确认轴线连续、没有歪斜；若拖动后有轻微倾角，可在当前界面支持时比较两个端点高度。

## 放置等距刻度

先在轴上标出 -3、-2、-1、0、1、2、3、4 八个刻度，任意相邻整数之间保持相同距离。可以复制短线并按可见的排列方式移动，也可以逐个放置后检查间距；不要求假设某个自动分布按钮存在。把数字标签放在刻度正下方，负号要清楚。逐个核对每个标签的中心和刻度，并比较相邻间距；即使数字宽度不同，其对应的刻度仍应保持等距。比较 -2 到 0 与 0 到 2 的跨度，应当相等。

## 画区间线段

在 -2 与 3 对应的刻度之间另画一条醒目的线段，使用不同于底轴的颜色或粗细。它表示两端之间的全部实数，而不是五个离散刻度。线段只到达两处端点，避免延伸至 4 或在 -2 左侧开始。可先降低线段的视觉权重检查底轴，再恢复样式；前后顺序要让端点仍然清楚。

## 区分实心与空心端点

在 -2 处叠加实心圆表示包含；在 3 处放置空心圆表示不包含。若空心圆填充透明，后方区间线可能穿过圆心造成误读：可使用与背景相同的填充，并保留明显轮廓，同时确认它仍是单独可编辑对象。分别放大检查圆心是否对准刻度，再缩小检查两种状态仍能一眼区分。

## 放置区间和不等式标签

在图上方写 [-2, 3)，下方写 -2 ≤ x < 3。核对左方括号对应实心点、右圆括号对应空心点；不要把右端写成 ≤。文字离端点和刻度留出间距，负号、逗号、括号不能被线段遮住。若选用的字体缺少 ≤，先验证实际显示结果，必要时使用支持该符号的字体。

## 用四个值检查

逐个代入 -2、0、2.5 和 3：前两个满足，2.5 也满足，3 因为不是小于 3 而不满足。再试 -2.1，它小于左端因此不满足。检查图中结果是否与这五次判断一致；特别注意 2.5 虽没有整数刻度，仍位于线段内部。若图与文字冲突，回到最初的定义修正，不只修改标签以掩盖错误。

## 检查黑白与小尺寸

复制一个工作版本转成黑白或改用同色线条，保留空心与实心端点的形状差异；不要只靠红绿区分包含关系。将画面缩小到预计阅读尺寸，查看刻度数字、括号和两个端点是否仍清楚。若空心圆变成小黑点，增加圆的直径和内部留白，再检查其中心是否仍对齐 3 的刻度。

## 比较相邻区间

另存一份副本，把右端的空心圆改为实心圆，同时将标签改为 [-2, 3] 与 -2 ≤ x ≤ 3。两幅图的刻度、线段长度和左端保持一致，只比较右端 3 的包含关系。将 3 代入两幅图检查：前一幅不包含，后一幅包含。不要只改圆圈而遗漏括号或不等式；对照后保留原图作为本课目标，副本只用于比较。

## 检查对象和可读性

选中右端的空心圆并轻微移动，观察区间线和数轴是否保持原位；随后撤销移动，确认圆心仍在 3。这个检查用来确认图形分开可编辑，不要求合并对象。把标签和端点附近放大，检查符号没有被描边遮挡；缩小后如果文字难认，先增大文字和留白，不要移动刻度或改变区间长度来制造空间。

## 排查并保存输出

端点位置偏移时先检查圆心与刻度，而不是移动数字来迎合圆；线段穿过空心点时检查对象顺序与填充。保存可编辑原稿，再通过当前版本可见的导出入口另存 SVG 或 PNG，重新打开检查端点、标签和裁切。回到原稿确认对象仍可编辑，记录文件名和测试值；未在设备实际执行的操作标为待验证。

## 再核对负号和区间内部

放大左侧标签确认 -2 的负号没有被裁切，再在数轴上指出 -1.5 所在位置：它虽不在整数刻度上，仍位于区间线内。核对该值与不等式的判断一致，避免把线段误读为有限个点。
