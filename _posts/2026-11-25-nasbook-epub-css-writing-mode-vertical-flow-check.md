用授权自制段落观察 writing-mode 声明和书屿显示，不将列方向等同翻页方向。

## 理解书写模式

W3C CSS Writing Modes 说明 writing-mode 控制行的横竖排列以及块流方向；vertical-rl 是竖向文字、块由右向左推进，horizontal-tb 是横向文字、块由上向下推进。它不同于 EPUB 全书章节顺序或应用手势。规范声明并不保证书屿实现每个值，观察应分开记录。

## 准备授权自制段落

使用自己制作或出版者允许检查的 EPUB，准备两段自制短文字，在每段中加入易识别的起始和结束标记；记录文件版本、来源与备份位置。自制内容不含私人信息，避免公开受版权限制的书页。若书籍受保护或许可不允许内部检查，仅观察界面并将结构检查标记未执行。

## 记录首次阅读画面

在书屿打开目标章节，记录文字行或列的排列、各标记的位置、设备方向及可见阅读设置。先确认短句与目标章节身份；显示不完整时记录具体位置，不能仅凭画面断定是哪条 CSS 生效。保留原件、书签和笔记，不重置应用。

## 检查声明和作用范围

仅在许可和工具允许时检查 EPUB 副本的目标 XHTML 及引用 CSS，记录 writing-mode 的实际值、选择器以及该规则是否可能作用于目标段落。多个样式表和继承可能影响结果；搜索到 vertical-rl 不等于确定它控制整个文档。无法检查时写未知，不修改唯一原件。

## 比较列和段落推进

结合出版者提供的预期，观察自制标记在每列或每行中的相对位置，以及第二段出现在什么方向。不要只根据一列文字就推断所有段落均采用相同规则；文字方向、列之间推进和章节在目录中的先后是不同观察。若标记被遮挡或无法辨认，记录未确认而不是推测内容。

## 单独记录翻页动作

在当前界面按实际可见方式翻到相邻页面，再返回原位置，记录手势或按钮、到达的页面标记和设备方向。应用翻页方式可能由设置或书籍结构决定，不能从一次手势推断 writing-mode，也不能以 CSS 声明推断某个按钮必定存在。无法定位相邻页时写未完成并保留书签。

## 改变一个阅读条件

如果书屿允许，保持同一文件与章节，只改变字号或设备方向中的一个条件，再观察标记、列和页面。宽度变化可能引起重新分页，不表示源码被修改；不可用的控件记未提供。不要同时改写样式、替换文件和修改系统语言，以免无法确定变化条件。

## 独立对照与排查

许可允许时在可信阅读器中打开相同副本，记录设备、版本、尺寸和标记的位置；不同字体与视口可能导致布局差异，不单独证明哪一方错误。若文本完全未显示，先核对章节、文件和字体；只有排列不同再检查样式范围及实际设置。没有对照条件就保留未知，不安装未知软件。

## 恢复和记录

恢复原字号与方向，确认原件、书签和笔记保留。结果表分开填写样式声明、列和段落推进、章节位置、翻页动作与未执行项；分享前移除私人路径和未经许可的内容。本文依据公开标准与应用资料，不声称真机测试或保证书屿实现竖排 CSS。

## 一组可复现的自制标记

在符合 EPUB 格式的自制样本中准备两个段落，分别写“甲段开始、甲段结束”和“乙段开始、乙段结束”；只在对应段落规则中声明 writing-mode: vertical-rl。记录 CSS 文件位置和选择器，再在书屿观察两个段落及其标记。按标准含义，声明表达竖向文字和由右向左的块推进；实际阅读界面是否呈现相同效果仍须观察，不能将预期直接填为测试结果。

## 把段落顺序和页面动作分开

用一栏记录文件或出版者提供的甲段、乙段顺序，另一栏记录屏幕上两段的位置，再单独记录翻至下一页使用的实际动作。即使竖排列从右向左推进，具体应用的翻页按钮或手势也可能受书籍与设置影响。若看不到乙段，先通过目录或前后翻页确认位置，不立即称段落丢失；没有足够证据时写未确认。

## 注意文字方向与字体

writing-mode 描述行和块的排列；单个字符的朝向还可能受到其他样式、文字类型与字体影响。看到拉丁字母旋转或保持直立时，单独记录该现象，不由此猜测整篇文档的章节顺序。若文字以方框显示，先检查字符与字体是否可用；缺字与列推进方向是不同问题。无需安装来历不明的字体进行测试。

## 保留对照条件

如果出版者提供横排和竖排两份合法自制样本，先确认文字相同、各自的文件身份及样式声明，再比较画面。两份副本若有其他不同设置，应将这些变量列出，不能只归因于 writing-mode。没有授权对照时只保存单次观察；不要编辑或覆盖真实书籍以制造对比。最终表格应说明哪些内容来自规范、哪些来自样本、哪些只是本次界面观察。
