绘制由一条连接边相连的两个三角形，比较删除桥边与删除环上边的结果。

## 定义练习图

使用无向简单图，左侧三个顶点 A、B、C 组成三角形，右侧三个顶点 D、E、F 组成三角形，另有唯一连接边 C–D。边集合是 AB、BC、CA、DE、EF、FD、CD，共六个顶点七条边。图论中的连接性关注删去顶点或边后顶点之间是否仍能互达；本课检查删一条边，不改变顶点。

## 建立画布与对象

在 VectorPaint 新建横向画布，例如 1800×1000 像素，保存可编辑原稿。通过当前版本可见的对象控制分开顶点圆、字母、三角形边、连接边和说明文字。让两个三角形之间有足够空间放 C–D 标签，并在下方保留删边前后对照区。按钮和分组方式以安装版本实际显示为准。

## 绘制左侧三角形

在左侧放 A、B、C 三个顶点，例如 A 上、B 左下、C 右下，并分别画 AB、BC、CA 三条线。字母放在圆附近但不盖住边的接点；连线应明确接到对应圆，避免交叉位置被误读成新顶点。沿 A→B→C→A 追踪一圈，确认左侧三边组成闭合环。

## 绘制右侧三角形

在右侧放 D、E、F 三个顶点并连接 DE、EF、FD。可以将 D 置于左侧靠近 C，以便连接边有清晰路径；右侧形状无需与左侧尺寸完全相同，因为图论结论依赖连接关系而非几何面积。沿 D→E→F→D 追踪，确认右侧也是三边闭环，且没有无意间添加其他跨组连接。

## 连接 C 与 D

用一条线连接 C 和 D，确认它是两组三角形之间唯一的边。可暂时用不同线型突出它，但仍保留端点字母及文字说明，不能只靠红绿颜色。此时 A 可经 A–C–D–E 到达 E；同理左组任一点可先到 C、经 CD 到 D，再在右组到达目标，因此整张图连通。

## 在副本中删除 C–D

复制原图，在副本中只隐藏或移除 CD 这条边，保留 C、D 顶点及两侧三角形的边。结果分成左侧 {A,B,C} 和右侧 {D,E,F} 两个连通部分；从 A 出发不能沿剩余边到达 E。原图连通而删除 CD 后不连通，所以 CD 是桥边。不要把删边误做成删除 C 或 D 顶点。

## 在另一副本删除 AB

从完整原图再复制一份，这次只移除左侧 AB。A 与 B 仍可通过 A–C–B 连接，左三角形剩余顶点依然互达；右三角形完整且 CD 仍连接左右两组，所以整图仍连通。由此 AB 不是桥边。这个对照说明三角形提供替代路径，不是因为 AB 在画面中比较短或颜色比较浅。

## 比较每个节点的邻接

在草稿列出邻接关系：A 连 B、C；B 连 A、C；C 连 A、B、D；D 连 C、E、F；E 连 D、F；F 连 D、E。对照原图逐行追踪，确认没有漏掉 CD 或多画一条 A–D。检查删 CD 的副本时，只有 C 与 D 的互相邻接被移除；其余邻接关系不变。

## 标注结论与可读性

给三幅图分别加“原图：连通”“去掉 CD：两部分”“去掉 AB：仍连通”，并用文字指出 CD 是桥、AB 不是桥。边的粗细和颜色可辅助比较，但字母、删去的边名和结论必须足以在黑白图中理解。为图提供文字替代，列出六个顶点、七条边以及两次删除后的路径或分组。

## 检查反例与假设

如果误把 AB 当桥，沿 A–C–B 走一遍；如果误判 CD 非桥，检查是否意外画出另一条从左组到右组的线。若额外加入 B–E，删除 CD 后仍能通过 B–E 跨组，因此结论会改变；那是另一张图，不应悄悄加到原题。边没有箭头表示无向图，不要将此结论直接用于不同有向图的可达性。

## 保存和复查输出

保存可编辑原稿，再通过当前可见的导出入口另存 SVG 或 PNG。重新打开检查六个顶点字母、七条原图边、两份副本及说明文字未被裁切；回到原稿确认 CD 和 AB 能独立选取。若线条被合并无法单独隐藏，可在副本中重画并再次核对邻接。未在设备执行的步骤标为待验证。

## 对其他环边逐一找替代路径

在原图中只删除 BC 时，B 可以经过 B–A–C 到达 C；只删除 CA 时，C 可以经过 C–B–A 到达 A。右侧同理：删 DE 后 D 可经 D–F–E 到达 E；删 EF 后 E 可经 E–D–F 到达 F；删 FD 后 F 可经 F–E–D 到达 D。每次都从完整原图重新开始，不能把前一次删掉的边留在下一次副本里。由于这些边的两端各有余下的替代路径，且 CD 保留，删其中任意一条都不会拆开这张图。画出其中一条替代路径时，可在副本中使用虚线强调，但不要在原图新增一条实际上不存在的边。

## 对照两个连通部分

在删除 CD 的副本里任选 A，沿剩余边可以访问 B、C，但没有边跨到 D、E、F；任选 D 则可访问 E、F，也无法跨回左侧。将这两个顶点集合分别写在图旁，检查每个原顶点恰好出现一次，两个集合没有重叠且合起来仍是六个顶点。此处是图论中的连通部分，不是把画布裁成左右两张图片：移动顶点位置不会单独改变连通性，只有改变边或顶点的关系才改变图。给图增加标签时，让集合括号不盖住 C、D 的圆形，以免读者误以为两端被删除。

## 比较新增跨组边的副本

另建一个副本并添加 B–E，明确标记这是改变后的图。此时即使移除 CD，仍有路径 A–B–E–D 从左组到右组；在该改变后的图中，CD 不再是桥。将这份副本与原图的删 CD 结果并排查看，可以发现桥的结论取决于整张图是否存在替代跨组路径，而不是一条线画在两个形状之间就必然是桥。恢复原稿时移除临时新增的 B–E，再按最初七条边重新核对，避免把反例误当成原题内容。
