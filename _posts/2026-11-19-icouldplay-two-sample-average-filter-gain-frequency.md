把相邻两个声音样本先相加再除以二，是一个简单滤波模型；把整条声音每个样本都除以二，则是统一增益。这两种操作可能看起来都带一半，却会得到不同频率关系。本课从原创离散数列做明确对照，之后才在云映查看外部制作的真实片源，不假定播放器自带这个滤波器。

## 固定双点公式与独立增益对照

在工作卡写采样率八千，输入为x，平均输出为y等于当前x加前一项x后除二，另设对照v等于当前x除二。编号从零开始，并明确本课理论幅度在持续正弦的稳态区间计算。若做有限片段，要写出片段前的初始样本取零，而不是隐含循环接尾。保留输入、两种处理与导出记录，分别命名；不要在云映寻找未经公开证实的两点滤波按钮。现有外部工具没有这项操作时，纸面数列仍可完成，实际处理与播放留未执行，不把同一原片换名当已经生成两份不同处理结果。

```text
y[n] = (x[n] + x[n-1]) / 2
v[n] = x[n] / 2
Fs = 8000
```

## 从常数输入先验单位增益

先令输入持续为零点二，双点平均在两项都已进入常数区间后仍为零点二，而统一减半对照为零点一。这个结果能立即排除两种操作永远一样的说法。有限片段的第一项若前值设零，平均输出第一项是零点一，下一项才到零点二；把这一边界单列，不拿首项当整个稳态增益。常数只是数学直流输入，不要求把直流文件长时间放进音响试听；本课不会建议用听见或听不见来测量直流是否保留，理论、样本和实际声音各有适用范围。

## 按频率分别计算幅度响应

对频率f的正弦或余弦，稳态幅度比例为cosπf除采样率的绝对值。八千采样率下，一千赫兹约零点九二三八八零，二千赫兹约零点七零七一零七，四千赫兹为零；统一减半则在这些频率都乘零点五。若输入幅度零点二，前两组平均输出幅度约零点一八四七七六和零点一四一四二一，不能把增益比例直接写成输出样本值。四千组宜用余弦的交替正负样本演算，避免零相位正弦在全部采样点本来就为零而误以为已经证明滤波。

```text
steady_amplitude_gain(f) = abs(cos(pi*f/Fs))
```

## 手算交替数列与脉冲边界

用零点二、负零点二交替的持续数列，两邻项总和为零，因此稳态平均为零；统一减半仍交替为正负零点一。再单独令输入只有n零的一项为一，其余为零，前值也设零；平均输出在n零和n一各为零点五，其后为零，而统一减半只在n零有零点五。把两份小表写清编号，不把输出两项当两个新的音轨。这个脉冲检查既核相邻依赖，也核有限开始条件；幅值一只是演算单位，不要求以满刻度脉冲在设备上实际播放。

```text
input impulse:  [1,   0,   0, 0]
average output: [0.5, 0.5, 0, 0]
half output:    [0.5, 0,   0, 0]
preceding input sample = 0
```

## 相位延迟不能靠把首项删掉掩盖

在零到半采样率之间且增益非零的稳态范围，这个平均模型还带半个样本的相位延迟，八千采样率下为六十二点五微秒。它不是说文件只能存半个样本位置，也不是所有瞬态都只需删掉半个数字即可对齐；真实输出仍在整数采样格点给值。四千赫兹增益为零时，相位本身不能按正常非零信号读取。将频率增益与相位条件分栏，不用只删掉第一个样本的方式把两份文件强行弄得像同一波形，删整样本会新增另一时间变动并改变边界。

## 实际片源比较只核已经导出的处理

若已用可信工具制作自有影片，片头分别写原稿、相邻平均与统一减半，并保存导出音轨参数。先在外部确认处理确实应用于音轨，再通过云映本地视频入口选择片源；保持正常速度、同一音轨位置和同一输出设置，短时以舒适音量观察差异。纸面计算的一千与二千增益不能直接写成设备实测数字。没有完成处理时只比较原稿不会得到滤波证据；媒体库封面相似也不能代替文件身份。恢复观看时换回原片，而不是让日常影片一直使用不明处理副本。

## 数值不符时查前一项、相位和采样率

如果两种处理总一样，检查是否把前一项误写成零，或是否只测到某个巧合输入。四千组没信号时先查原始数列是不是已经全零，别把这种输入当成功相消。外部处理结果不一致，核工具是否用了更长窗口、重新归一化或改变采样率；十六千采样率下同样二千赫兹的比例已不是本课零点七零七。记录每次修正及输出对象，不同时切换播放器引擎来遮盖制作差异。没有样本读取工具时保留证据限制，不从耳听判断六十二点五微秒的精确延迟。

## 交付输入条件和逐层证据

重开原稿和两份副本，核文件、片头、音轨与速度。交付常数、交替样本、脉冲三张小表，两个非零频率幅度计算、相位限制和实际播放记录，未制作或未测部分明确标注。结论限定为这套两项等权平均，不扩展为任何名叫平滑或降噪的工具都相同；真实对白和音乐也不是一条永恒纯音。能解释常数为何保持、交替数列为何抵消、统一增益为何都减半，才算完成。网站文本和数学审核通过，只说明记录可复查，不代表云映已有滤波分析、自动测量或全设备听测报告。
