制作一枚圆形窗口图：斜向色带穿过圆内背景，原始矩形和色带继续存在于窗口外，只是被裁剪区域限制了显示。先用外部 SVG 原文检查结构，再在 VectorPaint 实际可用的导入方式中观察；不能因为扩展名是 SVG 就保证每个裁剪对象都能在任意版本中按原结构编辑。

## 固定画布和圆形窗口

建立 160×140 用户单位的示意画布，以圆心 80、70 和半径 35 作为窗口。圆的理论边界为 x=45 至115、y=35 至105；完整背景矩形从 x=20 到140、y=20 到120，覆盖整个窗口。另画一条斜色带穿过矩形。数值是用于练习的原创设定，不是应用默认网格或设备像素。先将圆、背景、色带分别记录，避免把背景本身误画成圆形后再声称裁剪生效。

## 保存包含定义与引用的 SVG

把下面完整内容保存为 clip-window.svg：defs 中的 clipPath 定义圆，分组引用该 id，组内保留矩形及色带；最后一个无填充圆是单独的描边轮廓。保存纯文本原稿与副本，确认根元素和命名空间没有遗漏。窗口外的矩形和色带在源文件中仍有坐标，显示时被裁剪，不代表源代码中的那些点已经被删除。未实际保存或导入时，把对应检查留待核。

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 160 140">
  <defs><clipPath id="window"><circle cx="80" cy="70" r="35"/></clipPath></defs>
  <g clip-path="url(#window)">
    <rect x="20" y="20" width="120" height="100" fill="#b9d6cf"/>
    <path d="M20 85 L140 35 L140 70 L20 120 Z" fill="#31554c"/>
  </g>
  <circle cx="80" cy="70" r="35" fill="none" stroke="#172d28" stroke-width="2"/>
</svg>
```

## 分开裁剪形状和可见轮廓

上面的定义圆只提供分组的裁剪区域；最后一行圆才画深色轮廓。轮廓宽度 2，若居中描边，理论上可覆盖距圆心 34 到36 的区域，因此外沿比半径 35 的裁剪窗口稍大。不要把这条轮廓误认为它也限制了前面分组，或者认为裁剪圆默认自动带描边。若只想检查裁剪效果，可在外部副本中暂时移除最后一行，保留原稿；两种输出应分别命名。

## 做一个移除引用的反例

复制原文，只删除分组上的 clip-path 属性，其他代码保持一致。此时矩形和斜色带可在圆外显示，最后一行轮廓仍在，圆本身不会自动裁剪它们。用原稿和反例检查：原稿有裁剪引用，反例没有；不要同时修改圆半径或矩形尺寸。若两版看起来相同，先核打开的文件是否真是不同副本、引用是否被删，再核查看器实际是否支持；不能仅凭观察就推断应用删除了窗外形状。

## 检查 id、路径和实际导入

确认引用中的 #window 与 clipPath 的 id 完全一致，大小写或拼写不同都需要修正。按安装版实际可用的 SVG 入口导入副本，先观察圆内是否有浅底与斜带，再看轮廓是否连续。选择对象时记录软件实际呈现的图层或路径，若导入转换了结构，不把转换后的对象自动称作原始 clipPath。公开信息说明 SVG 编辑，但不同 SVG 特性的导入保真仍须实际验证；导入失败则保留提示、版本、原文和反例。

## 修改内容而非只改窗口

在有备份的副本中，将色带填充改成另一种对比色，保持圆心、半径、背景和引用不变；如果应用里不能可靠定位该对象，可在外部文本副本只改 path 的 fill 后重新导入。核对圆内带状区域是否换色，圆外仍被限制；单独轮廓的颜色应维持原样。再把颜色改回或保留两个命名清楚的版本。不要同时挪动圆或改变 viewBox，否则颜色对照不能独立说明引用是否仍生效。

如果需要证明矩形与色带原本延伸到窗口外，可以同时查看移除引用的反例，而不是用选择框或截图猜测隐藏内容。把三份文件依次标为“原稿”“无裁剪引用”“仅改色”，并记下实际打开的应用和时间；对照时先确认圆心、半径及 viewBox 没有变化。若只能看到扁平图而无法核节点，就把源代码检查和应用编辑结果分开记录，不能把无法选择某节点直接解释为源文件丢失该节点。

## 用不同背景排查透明与白底

根画布没有额外的全屏白色矩形，圆外应按查看环境显示透明或其默认背景；在浅色与深色背景上分别预览，检查是不是查看器白底被误认为文件固有白底。裁剪窗口内部被背景矩形填充，但圆外透明与矩形源坐标依然存在并不矛盾。若圆边出现细缝，先放大查裁剪和单独描边是否对齐，再核导出设置；抗锯齿在不同渲染器中可能不同，不据截图宣称逐像素一致。

## 导出并留存可复查的原稿

保留完整原文、移除引用的反例和颜色对照，另存实际可编辑稿。按安装版提供的入口导出 SVG 或 PNG 并另开，比较圆内斜带、边界和透明背景；PNG 是像素图，不保留可编辑裁剪结构。若需交付结构可编辑的 SVG，应打开实际导出文件检查是否仍有 clipPath 或被转换的其他结构，不根据外形相似推断源结构相同。未完成导入、导出或重开时明确待核。
