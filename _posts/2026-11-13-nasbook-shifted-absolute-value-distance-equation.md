看到绝对值等于三，不能只把竖线擦掉。本课在书屿读一张原创小卡，把与数轴点二相距三单位的任务拆成两侧候选，再用零与负右端作反例。计算在纸面或已有笔记中完成，书屿负责阅读与回查，不假定应用提供方程求解器或自动数轴。

## 一、保存完整题面与实数条件

用已有可读格式另存原创练习卡，题面写在实数范围求解，不把解答藏进文件名。导入或打开后，先核竖线成对、减号和等号齐全，记录书名、章节或可回查锚点；应用缺少某种笔记入口时用外部记录，不编造按钮。原书与旧摘录保持，练习卡另存。先独立读题再看结果，避免把视觉上两个竖线误认成数字一或把数轴中心二的位置省略，造成实际读了另一个方程。

## 二、把三种右端逐行抄全

下方三式只有右端不同，先分行抄录，并在每行旁写距离不能为负。不要在输入阶段就自动把负三改正三，也不能因三个式子相似就共用同一份解集。竖线围住的是 x 减二整个表达式，不是只围住 x；这个范围决定数轴中心。纸面结果暂时留空，在书屿用可见位置回读题面而不直接跳到解答；若显示符号损坏，先处理可读副本，不能凭记忆代替原题。

```text
A: |x - 2| = 3
B: |x - 2| = 0
C: |x - 2| = -3
Domain: real numbers
```

## 三、数轴从中心向两侧量相同距离

依据[OpenStax 绝对值函数与方程](https://openstax.org/books/college-algebra-2e/pages/3-6-absolute-value-functions)的距离解释，在纸上标中心二，向右三单位到五，向左三单位到负一。两点到二距离相同，不表示两点本身相等，也不表示题目只许非负 x。标清每格尺度，不能数刻度线数量代替区间长度。数轴由自己手绘，不是声称书屿自动生成；把图与题面锚点放在同一条记录，便于之后核是距零还是距二。这里二是中心坐标，三是距离大小，不能把相邻两个汉字连读成小数二点三；在记录里分别写中心栏和距离栏。距离使用同一数轴单位，不能只给右侧扩大格宽后仍说两侧相同三单位。

## 四、分两支求解再各自代回

A 的两支为 x 减二等于三，以及 x 减二等于负三，分别得到五与负一。代回原式时，五减二为三，负一减二为负三，两者取绝对值都三。若只写第二支的负三为不合格，说明把绝对值之前与之后的值混淆。记录两次代回而不是只检查容易的一支，最终解集按两个不同实数列出；等号连接每一步成立的关系，不把两条互为选择的分支横串成它们同时相等。

## 五、零距离与负距离另判个数

B 距离为零，只能在中心二；两支写出来都得到二，合并为一个不同的解，不能因写了两行就报两个解。C 右端为负三，而左端在实数范围非负，所以无解；不是 x 等于负三，也不是“负解被删除后还剩正解”。先看右端符号再考虑分支，能避免把所有绝对值题一律复制成两个答案。每种情况保留理由，结论不要只写零、一、二而不说明数的是不同实数解。

## 六、用括号范围变化核对读题身份

另写对照为 x 的绝对值再减二等于三，此时先移项得到 x 的绝对值等于五，候选五与负五。它与 A 只差竖线范围，结果却不同；A 的负一不能直接搬过去。把两种范围用文字说明，再各代一个负候选，定位具体错误来自符号范围而不是加减算术。对照另存，原题不改；如果读到的原书排版不清，回查清晰版本后再判断，不能根据已知答案反向猜作者本来把竖线放在哪里。

## 七、排查漏支与误删负候选

若只得五，检查是否漏了左侧距离；若把负一删去，检查是否额外添加了原题没有的 x 非负条件。若 C 也列两根，回到距离非负的前提，而不是反复换移项符号。代回必须用原式，不能只用自己已经写错的某一支。纸面每次改一处，并保留错误原因；书屿中只记录真实可用的定位与笔记动作，没有自动校验提示就不编造已弹出反馈，也不删除旧笔记来让所有历史解法看似一直正确。

## 八、返回原题并遮住答案复核

离开当前阅读位置再按已记录锚点返回，核题面仍是同一卡和同一范围。遮住解答，独立重画中心二与两侧三单位，给 A、B、C 分别写两、一、零个不同实数解及原因。再打开记录对照，确认每个候选都代回原式。成果保存题面、数轴、分支、代回与修正说明，未知排版问题另列；验收是别人能复算，不是书屿已替你证明所有绝对值方程。原书、原日期和原摘录继续保留。
