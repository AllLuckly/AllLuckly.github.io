英文或法文名称里的重音可能由一个预组字符表示，也可能由基本字母加组合重音表示。两种写法经常看起来相同；本课使用非私人词语 café，分开记录键来实际输入、宿主显示与外部 Unicode 检查，不把键盘当作规范化工具。

## 准备两条明确的字符序列

在普通文本宿主准备一个练习副本，目标词是 café。参考卡 A 的最后一个字符是 U+00E9（带重音的预组 é）；参考卡 B 的末尾是 U+0065（e）后跟 U+0301（组合尖音符）。两条开头都是 U+0063、U+0061、U+0066。先在纸上写下 A 为四个码点、B 为五个码点；这不是字节数，也不代表显示宽度、光标次数或用户感知字符数。保留原稿，不用真实姓名或密码。

## 确定实际可用的输入方式

确认键来已加入系统键盘并在普通字段选中。以实际可用的语言和布局输入目标词，尝试键盘可见的字符或候选方式；键来公开资料说明多语言输入，但不保证每一种布局都提供某个法文重音键、长按菜单或组合输入方式。若找不到目标字符，记录当前语言、布局和结果，改用自己信任的参考文本做后续对照，并注明该字符是粘贴而非通过键来录入。不能凭显示需要就声称键来一定能直接生成两种形式。

## 先记录实际正文与可见结果

在练习副本中输入或粘贴一行 café，记录使用的步骤、候选是否出现、确认动作以及光标移动后正文是否保留。重音是否清楚、位置是否覆盖字母是显示观察；不要只因看见 é 就判断它一定是 U+00E9。宿主可能对输入进行转换，也可能保留不同序列；这一步只记录真实表现。若正文不是目标词，保留首次结果，在另一个副本更正后继续。

## 建立两个参考副本

使用可信 Unicode 参考或自己控制的文本工具分别准备参考卡 A 与 B，将它们放在有标签的独立行，不覆盖刚才键来输入的行。若准备 B 时宿主立刻规范化，保存后只能看到一种表示，就标明该宿主无法保留本对照；换一个能保持原始文本的本地工具，或停止并将 B 留待核。复制粘贴、渲染与规范化可能由不同组件完成，不能仅凭一个界面动作断言变化来自键来。

## 用外部工具核码点

在自己控制的电脑上，将三行非私人测试文本分别交给能显示 Unicode 码点的本地工具。逐行核输入结果末尾是单个 U+00E9，还是 U+0065 U+0301；若工具自动规范化输入，不能用它作为原始序列证据。先检查该工具对两张已知参考卡是否确实报出预期四个与五个码点，再检查实际输入。若没有可验证的工具，写“序列未核”，不要从外观猜测。不得把私人草稿上传第三方网站做此检查。

## 比较规范化与原始相等

若电脑提供 Python 3，可在本地终端运行下面的小程序；只粘贴本课的非私人测试词，按回车提交到本机程序。它分别显示字符串的码点，并计算 NFC、NFD；不发送网络请求，也不修改原文。终端输入或复制过程仍可能改变文本，所以先用两张参考卡确认工具结果。看到参考卡结果不符时停止，不以该工具判断键来原始输入。

```python
import unicodedata

text = input("Practice text: ")
for label, value in (("raw", text),
                     ("NFC", unicodedata.normalize("NFC", text)),
                     ("NFD", unicodedata.normalize("NFD", text))):
    print(label, " ".join(f"U+{ord(ch):04X}" for ch in value))
```

Unicode 将这两种表示视为规范等价；对照工具若能分别显示 NFC 与 NFD，可在原始副本不变的情况下观察转换结果。A 与 B 原始码点序列不同，但 NFC 形式可一致；规范等价不意味着所有系统搜索、排序、字节比较或同步都一定相同。记录原始序列、转换方式、转换后序列三项，不要用转换后相等覆盖原始差异。再次核实实际输入行，不能只比较两张人工参考卡。

## 在两个字段或宿主中复查

可将已知参考的副本分别放入另一个自己控制的普通文本字段，再按同样方法检查粘贴后的原始序列。记录源、目标和复制动作；如出现变化，结论是交接前后观察不同，需要进一步隔离，不能自动归责键来、iOS 或某个宿主。两处显示一样但没有码点证据时写“视觉相似，序列待核”。原稿、参考卡与交接副本应保持可区分，避免把转换后的文本当作最初录入内容。

## 排查与收尾

重音显示为方框时，可记录宿主字体与显示环境，再确认字符本身是否存在；字体显示问题不等于序列必然损坏。候选没有目标时先检查实际输入语言和可见选项，不承诺每个布局都支持；复制后结果变化时分开检查工具、宿主和复制过程。每次只改变一个条件并保留前态。交付输入方式、A/B 参考码点、可见状态、外部检查及待核项，恢复常用键盘。本文没有声称完成真机输入、字体或搜索兼容测试。

记录测试日期和工具版本，便于下次复查。
