## Understand font fallback

CSS describes font-family as a prioritized list of font names or generic families that provide alternatives. Whether a character displays also depends on glyph coverage, the reading system’s font selection and environment. A declared font does not prove Book Isle loaded or used it; a box alone does not prove file corruption or that the character is absent.

## Prepare an authorized multilingual phrase

Choose an EPUB you made or the publisher permits you to inspect, with a non-sensitive phrase containing distinguishable Latin letters and an authorized example from another script. Record source text, origin and file edition and back up the original. Do not download unlicensed fonts or share the book. If internal inspection is unavailable, observe only the interface and mark related steps unperformed.

## Establish a display baseline

Open the target section in Book Isle and record the phrase, visible font setting, size, orientation and whether each character is distinguishable. Record positions of boxes, blanks or different glyphs. If the whole book cannot open, first check file completeness and format recognition. Preserve bookmarks and notes without clearing app data, and do not infer whole-book corruption from one glyph difference.

## Inspect declarations and resources

Only when permitted and equipped, inspect target XHTML and referenced CSS in a copy. Record applicable selectors, font-family candidates and any font-resource declaration. Resolve any local font path from the stylesheet and check the resource exists; a declared path does not prove it loaded. Font distribution depends on its license, so a reference in a book does not authorize copying or publishing it.

## Distinguish characters and glyphs

With authorized source or publisher information, record the target character and intended text; do not treat a visible box as the original character. A missing character, absent glyph, unloaded resource and unsupported reader feature are different hypotheses. If the character or font coverage cannot be inspected, mark the cause unknown rather than substituting visually similar text.

## Change one reading condition

If Book Isle offers font or size controls, change only one visible setting and return to the same phrase, recording characters and wrapping. Mark a missing font selector unavailable; do not assume the app accepts an EPUB’s embedded font or every system font. Keep file, orientation and other settings fixed, then restore the original value.

## Bound copying and search conclusions

If the app permits selecting, copying or searching the self-made phrase, record the result in a private plain-text note and compare it with authorized source text. Correct copying alongside a visible box shows different observations but does not establish the chosen font. A search hit does not prove every glyph is visible. Mark unavailable or uncertain steps untested and do not paste private book text publicly.

## Troubleshoot with a trusted control

Where permitted, use a trusted reader for the same file and section and record device, tool and display. Different system fonts, sizes and layout areas can cause differences; a control alone does not prove an app defect. If a font path is missing, contact an authorized publication maintainer. Do not install unknown fonts, change security settings or overwrite the sole original.

## Restore and document

Restore original font and size settings and confirm original file, bookmarks and notes remain. Record source characters, inspectable font list, resource presence, Book Isle display, copying and skipped steps separately. Remove private paths and unauthorized content before sharing. This guide relies on public standards and app information, claims no device test and does not guarantee a particular font-loading method in Book Isle.

## Distinguish two sample characters

A self-made phrase may contain an ordinary Latin letter and a Chinese character whose source you can confirm; record each source character and visible result. A normal Latin letter and a box for another script do not mean the entire font list failed, nor does one visible character establish coverage for every character. Compare the same book and passage without substituting a similar-looking character.

## Record candidates without guessing selection

Record declared font names in priority order, but a name in CSS does not prove a font is installed, the resource is valid or it was selected. If Book Isle does not reveal the actual font source, mark it unknown. Inspect font resources only with publisher permission and appropriate tools; do not copy a replacement font from another website because a path is missing.

## Preserve environment conditions

For an independent reader control, record device system, reader version, font size and target character. Available fonts and reading areas differ, and a different display does not by itself establish a different EPUB source. One correct rendering does not guarantee every device has the glyph. Mark unavailable environment information unknown rather than implying stronger evidence.
