English translation of the [Chinese original](<https://allluckly.cn/guides/nasbook-html-fragment-link-target-id-offline-check/>), translated on 2026-11-22. Original publication dates, attribution, code and version notes are retained.

A visible contents label in a local HTML document does not establish that activating it reaches the right location. Use a self-made single-file sample to compare a link’s `href` fragment and target `id`, first in a local web tool and then as actually imported into Book Isle. This link targets the same file, unlike the earlier lesson on external pages and relative images. Do not assume Book Isle necessarily preserves or supports HTML navigation.

## Prepare two distinguishable practice copies

In an existing plain-text editor create UTF-8 `anchor-good.html` with the complete sample below. It contains no scripts, external images, remote stylesheet or network request, and the text is self-made and nonprivate. Nothing needs to be uploaded. Preserve this baseline and save a second copy as `anchor-missing.html`. Do not change existing user pages or books, and do not treat `.html.txt` as HTML. In the sample, the labels mean “Go to section two,” “Section one,” “Section two,” and “Target sentence: Beyond the green hills is a small river.” Preserve the Chinese text exactly while comparing files.

```
<!doctype html>
<html lang="zh-CN">
<meta charset="utf-8">
<title>文内跳转练习</title>
<p><a href="#part-b">前往第二节</a></p>
<h2 id="part-a">第一节</h2>
<p>这里是第一节的自制练习文字。</p>
<div style="height: 100vh"></div>
<h2 id="part-b">第二节</h2>
<p>目标句：青山之后是小河。</p>
</html>
```

In the second copy change only the link target `#part-b` to `#part-c`, leaving the second heading’s `id="part-b"` and all other content intact. The first has a matching target; the second has no matching `id`. Identical content helps isolate link differences. Do not modify the baseline or create or delete unrelated documents. If no appropriate HTML editing environment exists, retain a paper diagram and mark later steps unperformed rather than uploading files to an unknown site.

## Understand fragments and identifiers

`href="#part-b"` refers to fragment `part-b` in the current document. The target heading’s `id` is `part-b`; the hash belongs to the reference, not the `id` value. HTML defines document identifiers and fragment navigation. Check source characters exactly: two headings both titled 第二节 do not by themselves make their identifiers equal. This uses simple ASCII identifiers so encoding, case and network addresses are not mixed into the experiment.

The second file’s `#part-c` has no matching target. A browser may stay in place or handle it in its actual way; do not invent an error prompt. The sample’s `style` creates blank space in a typical browser to make movement easier to see. Book Isle may ignore styling, reflow content or omit link interactions, so blank-space size is not a compatibility promise.

## Establish a local web-tool reference

Open `anchor-good.html` in a local browser or known-safe preview that supports interactive HTML. Find 前往第二节 near the top, then scroll to confirm 第二节 and the target sentence exist. Return to the top, activate the link in the same window, and observe whether heading or sentence enters view. Record tool, filename, actual location and feedback. If the whole page fits on screen, reduce the viewport or use reversible zoom before observing; mark movement pending if it cannot be determined.

Open `anchor-missing.html` independently, confirm the second section still exists, and activate its same label, recording the actual result. Check the sources of both copies rather than substituting one browser result for the other. This is a reference for that local tool, not evidence that Book Isle passed.

## Import into Book Isle and identify versions

Transfer both samples to iPhone or iPad through a trusted system file method and record destination type and filenames. In Book Isle use the local-file import entry actually shown, first selecting the baseline and recording preview and import feedback, then trying the missing-target copy. If the app deduplicates or creates one item, record feedback rather than deleting existing books or assuming both imported based on similar names.

For each item actually opened, first identify the beginning, second heading and target sentence. If text is missing, partial or the file identity is unclear, pause the navigation judgment. Book Isle publicly lists HTML reading but does not guarantee every style or fragment link. If a link label is extracted as plain text, record “text visible; no link action observed” rather than requiring an unavailable control.

## Compare link action and target

If the actual reader offers an actionable link and the user wants to, activate it once from the confirmed baseline’s beginning. Observe target heading, body position and feedback. Record no action or inability to tap as observed. If both sections already fit on screen, movement cannot be determined; do not mark a pass merely because the second section is visible. Click counts, browser history and manually finding a sentence are not automatically equivalent to link navigation.

Only when the second copy is independently identifiable and opened should you perform the same observation on the missing-target sample. Record any actual movement or lack of it without generalizing to all invalid fragments. Two files, two viewers and text extraction can all affect the result, so include device, version and visible interface.

## Troubleshoot and respect boundaries

For a local reference failure, check `href` starts with `#`, the target `id` matches exactly, the file was saved and the correct copy opened. Change one practice-copy item per round. If the browser works but Book Isle has no link, record whether only text was extracted and whether style and heading are visible, without assuming web interactions must be retained. For import failure inspect type, encoding, destination and feedback before reinstalling, clearing the library or contacting an unfamiliar server.

The sample has no external URL, script or form. Do not upload private HTML to a third-party service for testing. Support can use this self-made sample, versions and redacted feedback. Real books containing external links or images require separate decisions based on their source and user authorization; do not generalize from this internal-fragment test.

## Preserve results and restore

Deliver a table of both files’ `href`, target `id`, local reference, Book Isle import, visible link action, target position and pending items. Keep the baseline and missing-target copy; the user decides whether to remove practice files. Restore the earlier reading position and settings without deleting existing works or notes. No real Book Isle, browser or device navigation test is claimed.
