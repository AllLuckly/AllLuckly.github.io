## Understand visual transforms

W3C CSS Text describes text-transform as a visual styling transformation that does not change underlying content and must not affect plain-text copy and paste. Whether a publication uses it, Book Isle implements it and the system copy path behaves as specified require separate checks. Visible uppercase alone does not establish that the source was uppercase.
