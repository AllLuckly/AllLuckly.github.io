Distinguish page-streaming links from whole-archive acquisition, then check system Files import and local reading using an authorized CBZ.

## Confirm the source and app boundary

Choose an OPDS catalog you manage or may use and an authorized CBZ, recording title, chapter, page count and a recognizable panel. ManYue publicly describes OPDS-PSE page streaming and says ordinary OPDS items offering only whole-archive links do not support direct reading. A title or cover in the catalog does not establish a page-stream link or direct opening of a whole-archive item.

## Inspect links actually supplied by the server

Have someone authorized to inspect the catalog use a trusted tool or server interface to check whether the item supplies OPDS-PSE page resources, a whole-archive acquisition link or both. The OPDS-PSE project describes it as an unofficial page-streaming extension to OPDS; follow actual server and version documentation. If link details are unavailable, record unknown rather than guessing. Do not share credential-bearing catalog URLs.

## Obtain the test file through an authorized path

If the provider permits whole-archive download, use your account and a trusted server interface or browser to save the CBZ in a location accessible from the device’s Files app. Obtain only authorized content and do not bypass authentication or content protection. Record filename, size and actual save location; retain the server original. Stop and record the reason for an HTML login page, incomplete file or prohibited download.

## Import using the actual ManYue interface

Use the local file-import entry actually offered in ManYue to choose the saved CBZ and wait for the actual import and parsing result. If the interface warns about replacement, a duplicate name or import failure, read the prompt and preserve existing records; cancel if the effect is unclear. External download and system-file import are an alternative workflow, not direct page streaming from an ordinary OPDS archive in ManYue.

## Verify the local comic and test offline separately

Find the comic on the local shelf and compare title, page count and recorded first, middle and last images. An import-complete prompt and all pages being readable are different outcomes. If offline use is needed, confirm the file is local first, then disconnect through your own device process and open different pages. Mark offline use untested if not performed; online opening does not establish offline availability.

## Troubleshoot in layers and restore

If authorized download is not offered, stop and contact the provider. If the file will not open, check actual format, size and download state rather than merely changing an extension. If imported page count differs, compare source-archive contents and local copy without deleting the only original. Restore the network and confirm original material and records remain. Share only redacted versions, steps and prompts. No device or server test is claimed.

## Different links establish different things

Suppose a test catalog item offers only cover art and a whole CBZ acquisition link, with no confirmable page-streaming link. It may provide bibliographic data and a complete archive, but these do not themselves constitute OPDS-PSE page resources. ManYue’s public description says this kind of ordinary OPDS item is not directly readable. Only after obtaining an authorized file and importing it successfully is there a local comic to inspect. Do not describe manual download as direct reading of that item in the app.

If a catalog offers both page and archive links, ask the administrator whether they refer to the same comic edition and chapter. One working link does not establish that the other is accessible; account, authorization and network can differ too. If server output cannot be inspected, record only the actual client interface rather than guessing link type from cover style. Remove source addresses, signed parameters and account keys from notes.

## Check file identity before import

Find the saved test CBZ in Files and compare name, size and completion time. If server-side size is available, use it as a preliminary comparison. Equal size alone does not prove byte equality or complete pages. If a browser reports a download but the saved object is a login page or zero-byte file, resolve sign-in and the actual download first; do not rename a webpage as CBZ to import it.

If the shelf already contains a similarly named comic, record its current chapter, cover and reading position first. If an import prompt offers replacement or merging, understand the scope and cancel if unknown. A self-made cover marker helps distinguish entries. After import confirm whether you selected the new copy or an old record; matching titles do not establish shared progress.

## Keep a recoverable state when something fails

If a trusted external tool cannot open the CBZ either, check its source, download completion and actual file type. If it opens externally but ManYue import fails, record app version, file size, reproduction steps and redacted feedback for support. Do not repeatedly overwrite the original through downloads or publish copyrighted comics. Stop importing untrusted content and check with the provider.

Afterwards retain source and needed local copies and restore network settings. Do not clean the existing shelf unless the user understands the cleanup scope. A report should distinguish “link confirmed,” “authorized download completed,” “file imported” and “offline tested,” marking unperformed steps untested. A later check can then resume at the unfinished step.
