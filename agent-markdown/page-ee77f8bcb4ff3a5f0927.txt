用自己的小目录核对站点基础地址、登录身份与起始路径，分开验收目录浏览和视频播放。

OpenList 或 AList 可以把多个存储挂到一个站点里，但站点首页、文件夹路径和真正的视频链接是不同对象。云映 1.1.1 已公开加入这类来源，本篇先把一个允许访问的小目录接入，不替换你已有的 SMB 或 WebDAV 来源。需要的是自己信任的站点和已获授权的观看账号，不是管理员后台口令。完成后你应能解释列表来自哪个目录、选中的是哪份文件，以及视频是否真的开始播放。

## 先在站点核对许可样本

在你平时使用的可信入口打开站点，用计划在云映使用的同一账号进入样本目录。选择一段自己有权播放的普通视频，记录文件名、大小和开头内容；不要只确认管理员账号能看到，因为普通账号的可见范围可能不同。若目录尚未挂载、上游存储已断开或样本本身无法读取，先处理服务端现状，再添加新客户端。练习只需要一两个文件，不为方便把整个私人存储改成公开，也不要求临时上传无权分享的影片到公共测试站。

## 把站点入口还原为基础地址

在云映添加文件来源时选择 OpenList / AList，地址填写站点的基础服务位置。示意如 `https://media.example.com`，它不是可直接使用的真实服务器。若你自己的服务确实部署在子路径下，按管理员给出的完整服务前缀填写，并核对浏览器访问的是相同部署。不要把具体影片页面、含签名的下载网址或浏览器中的长查询串放入地址字段。网页看起来相同不代表接口前缀相同；反向代理只转发了首页却没有转发 API 时，仍可能在连接测试阶段失败。

## 按获准方式填写登录信息

按站点实际要求填写用户名和密码，或在确有授权且表单提供时使用站点 API 令牌。不要把上游网盘令牌、Apple 密码和 OpenList 登录混为一谈，也不要从别人的浏览器会话里复制认证资料。某些站点允许匿名访问，但只有管理员已允许的目录才应这样使用；匿名并不保证任何文件都能下载。若同时存在多种认证字段，先沿用管理员明确给出的单一路径，避免把过期令牌与新的用户名密码混填后无法判断哪一种生效。凭据只写入应用相应字段，普通操作笔记保留身份代号即可。

## 起始目录填写站点文件路径

起始目录使用站点内的文件路径，通常以斜线开头。假设站点把练习目录显示为 `/Practice/Clips`，就核对该路径，而不是填操作系统磁盘位置或整个网页网址。名称大小写、空格和实际挂载层级都要按站点显示确认。进入来源后看到的根目录可能已经是所选起点，不需要再重复附加同一层路径。目录另有密码时，在相应目录密码字段填写，而不是改账号密码。先让测试只覆盖这个小起点，等列表和播放都通过，再决定是否扩大选择范围。

## 连接后选择少量目录保存

执行当前界面提供的连接检查，进入目录选择后只选练习目录，核对名称与预期子文件夹。若界面允许稍后选择，也要清楚本次保存了连接还是已安排扫描，不把来源卡片出现解释为媒体全部索引完成。初次列表为空时，比较起点、账号范围与站点当前内容，避免直接重扫整个大库。不要同时勾选父目录和它里面相同的子目录来凑数量；保存后检查一两个已知文件有没有重复出现，记录实际选择范围，后续维护时才知道扫描覆盖到哪里。

## 从同一项目验证播放与定位

找到事先记录的视频，比较文件名和可见信息后播放十几秒，再定位到一个熟悉锚点。目录接口能列出文件，不代表上游返回的媒体地址在手机网络里可访问；有些地址仍指向局域网或临时签名。播放失败时保留列表成功这个事实，再核对站点自身是否能为同一账号打开同一文件。不要把取得的长链接复制到公开聊天里，也不要为了测试给媒体地址追加账号密码。若样本能播放，结论只覆盖这一次来源、目录和文件，不声称所有上游网盘都已兼容。

## 按入口、权限和媒体三层排查

连目录选择都进不去时，先检查基础地址、代理前缀和认证组合。只有某个受保护目录失败时，检查起始路径与目录密码；列表正常而播放失败时，再看上游媒体链接、当前网络和文件本身。每次只改变一项，保留失败时间与简短提示。若现有 WebDAV 来源能用，这只能作为另一条路径的对照，不能证明 OpenList 原生接口设置一定正确。服务端不同版本和挂载方式可能有差异，不为追求一次成功而关闭全站权限检查或把私人内容搬到公开目录。

## 留下来源关系而不保存临时链接

最后保存站点代号、起始目录、所选范围、样本名称与浏览和播放结果，不把临时下载网址当作永久文件标识。关于站点接口可参考 [OpenList 官方 API 入口](<https://docs.oplist.org/guide/api/>)，具体行为仍以自己的服务版本与账号权限为准。完成后恢复样本观看位置，保留已有来源方便对照。以后上游重新挂载、站点更换域名或权限调整，应从小样本重新核对；一张旧海报仍然存在，只说明应用有这条资料，不证明原来的下载路径仍有效。
