DEVELOPMENT NOTES · 20 articles

After a feature comes dependencies, builds, tests and releases. These articles preserve older tooling and debugging experiences. Use them to trace a problem while distinguishing project configuration from the local environment.

## How to read this collection

1. Connect the CocoaPods installation, publishing and static-library articles. Note the tool versions, outputs and configuration files in each step.
2. For build and test issues, compare Xcode versions and target systems before following Git fixes or compatibility notes. Older plug-in approaches especially need a support check.
3. Review, in-app purchase and release articles explain historical decisions. For an actual submission, use Apple’s current rules and your project’s real configuration.

These notes date from 2015–2017. Their examples have not been rerun for this archive update. Check the dates and version notes before applying the ideas to a current project.
