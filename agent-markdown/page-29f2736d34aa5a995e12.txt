The first two chapters built a mini program structure and displayed an article list. This article covers network requests for that list and connecting the returned data.

First, find index.js, then consult [WeChat mini program network-request documentation](<https://mp.weixin.qq.com/debug/wxadoc/dev/api/network-request.html?t=1476197482156>)The sample code is easy to find:

```
wx.request({
  url: 'test.php',
  data: {
     x: '' ,
     y: ''
  },
  header: {
      'Content-Type': 'application/json'
  },
  success: function(res) {
    console.log(res.data)
  }
})

```

> url is the interface to request.

> data contains our request parameters.

> header sets the request headers; Referer cannot be set there.

> success is the callback invoked after a successful response from the developer's server, with res = {data: ‘content returned by the developer server’}.

> console.log( res.data ) prints the response data.

The default request method is get. We will use that here. The code is:

```
onLoad: function () {
    console.log('onLoad')
    var that = this
    wx.request( {
      url: 'http://sep9.cn/qt5wix',
      data: {},
      header: {
        'Content-Type': 'application/json'
      },
      success: function( res ) {
        console.log( res.data )
      }
    })
  }
```

Run it to check whether the request returns data. The result is shown below:

![1](<https://allluckly.cn/images/blog/weixinxiaochengxu/20161019/1.png>)

The request succeeded. Simple, right? 😄 Now let us populate the corresponding UI.

First, add this code in the successful-response handler:

```
success: function( res ) {
        console.log( res.data )
          that.setData( {
            
          })
      }
```

The `that.setData( { })` method mainly assigns the data.

The returned data is `res.data`. Printing it shows the same structure as our hard-coded data, but with different field names. Assign the fetched values to the existing data source, then change its fields to match the network response. The final code follows:

```
//index.js
//获取应用实例
var app = getApp()
Page({
  data: {
    newList:[  
    ]
  },
  //事件处理函数
  bindViewTap: function() {
    wx.navigateTo({
      url: '../logs/logs'
    })
  },
  onLoad: function () {
    console.log('onLoad')
    var that = this
    wx.request( {
      url: 'http://sep9.cn/qt5wix',
      data: {},
      header: {
        'Content-Type': 'application/json'
      },
      success: function( res ) {
        console.log( res.data )
          that.setData( {
            newList: res.data
          })
      }
    })
  }

})
```

Change the field bindings in index.wxml to match the server response, then run it. The result follows:

![1](<https://allluckly.cn/images/blog/weixinxiaochengxu/20161019/2.gif>)
