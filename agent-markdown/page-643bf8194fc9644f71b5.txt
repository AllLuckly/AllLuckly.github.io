Preserve the original language setting and compare menu labels with text in a self-made comic, then restore the original state.

## Prepare a page whose content will not change

Make an original page reading “今天见 / See you today,” and preserve the original and a CBZ working copy. Import and open it in ManYue, checking both phrases, title and current position. Apple’s store lookup lists languages including Chinese, English and Japanese, but actual language controls and choices depend on the installed version and device. A language list does not guarantee comic sources provide content in those languages.

## Record the original interface and restoration method

Record device, system and app versions, currently visible interface language and identifiable shelf, reader and settings entries. First identify a restoration method the user understands; stop at observation if the original language cannot be restored reliably. Do not change account, region, purchases or source configuration to produce a language change. Those settings differ from app menu language.

## Create separate menu and page baselines

In the current language record two actual menu labels and their functions, then record both phrases in the sample image. Menu labels come from the app or system, while words on the page are image content; keep separate columns. A title or chapter supplied by a comic file or source is a third category. Its remaining unchanged does not by itself mean the menu translation failed.

## Use a language entry actually available

If the current app settings or system offers a clear language choice for this app and the user wishes, record the original and choose an available language the user understands. Stop if the entry is absent, whether it changes the whole system is unclear or restoration is uncertain. Do not change the entire device language for a test. Follow actual prompts back to the app; signing out, deleting comics or purchasing again is unnecessary.

## Compare menu labels and page content

Revisit the same two menu functions and record their current labels and whether each function remains identifiable. Reopen the same comic page and check the two image phrases, title and chapter. Record observed interface translation, unchanged image text and source-provided metadata separately. If one item remains in the original language, retain the exact interface and version rather than concluding the entire app lacks translation.

## Check the return position and individual differences

Return from the reader to the shelf, then reopen the sample using identifiable menus. Check work, chapter and original reading position. List ordering, title language and page content can come from different layers. For a difference, check source and current sort before deleting or rebuilding a library. Record an app reopen only if actual feedback requires it; do not invent a restart prompt.

## Match menu functions rather than isolated words

Choose two clear, non-destructive menu actions, such as entering the shelf and returning to the reader. Label their location and intended actions A and B and copy the text actually shown. After the language change, identify the same function and navigation level before recording its new label instead of matching a possibly abbreviated English word alone. If the interface rearranges or an icon has no text, record its location, icon and actual action; visual similarity alone does not establish identical behavior. Do not attribute the language of an iOS system dialog to the comic image, or treat a source-provided work title as a built-in app label.

## Inspect source-provided display without altering content

The two phrases drawn in the original image are pixels, so an ordinary interface-language choice should not be treated as editing the source image. Still reopen and check the sample rather than marking it passed from expectation. A remote source may provide its own title or translation, and its content depends on the source; changing app menu language does not guarantee another language is available there. If different pages appear before and after, first inspect file identity and chapter position rather than calling different dialogue automatic translation. Do not upload private comics for confirmation, and do not equate the app’s interface language with changing account or device region.

## Return through the recorded entry

After observation, return through the recorded entry and identify the original option rather than guessing unfamiliar labels. If system assistance or a person familiar with the language is needed, first avoid exposing accounts or private content. After restoration check title, chapter and original image again. If no change was made, do not claim a successful restoration; report only that the original state was retained and whether an entry was visible.

If the target appears in the public store list but cannot be found on the device, record it as not found; the listing is not an actual language-change result.

If the original entry cannot be found, seek familiar assistance while preserving current data; do not delete the app to reset language.

## Restore the original state and organize results

Restore the original language using the earlier record, then check the menu and sample page again. Record device and app versions, original and target choices, two menu labels, content changes and position outcomes. Mark an unavailable entry or unperformed change untested. Preserve the original image and reading records and do not provide private comics in feedback. The exercise uses store language information and Apple system guidance and claims no physical-device language change.
