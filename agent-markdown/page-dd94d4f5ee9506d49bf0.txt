## Prepare two nonprivate drafts

Create a practice note in an ordinary editable app using the fictional sentence “明天下午三点见面。” (“Meet tomorrow at three in the afternoon.”). Do not enter real names, locations, medical details, accounts or other sensitive content. Keep an untouched source and a separate working copy for selection and translation. Record OS, 键来 version and host. Clearly separate the drafts to avoid selecting the wrong line later.

Apple says available translation languages and entry points depend on the system, region and host. If unavailable, do not install an unfamiliar third-party app or change regions merely to complete the exercise; mark translation pending. There is no need to send a message, sign into another account or publish the result.

## Confirm input in the original

In the source body, select 键来 with the system keyboard switch and verify it is active. Enter the sample and check that every word and the final Chinese period are committed to the body; text in a candidate area is not yet committed. If the keyboard or host changes a word automatically, record and correct it. Copy the confirmed source to the working draft and compare the two character by character.

Copy and paste use the system and host’s visible controls. If the clipboard contains something you cannot lose, preserve it safely first or enter the sample manually: copying may replace earlier clipboard contents and cannot guarantee their restoration. The working copy must be separate; relying on a later undo is not a substitute for preserving the only original.

## Select the exact sentence in the copy

Select the whole sentence in the working copy, checking that the range starts with 明 and ends with the period without including a neighboring title or text. Adjust selection handles where available; hosts may differ. If adjacent content is selected, cancel and try again. The example contains no private details, so uncertainty about translation processing does not expose an actual message.

Find Translate in the actual selection menu; if it is not visible, inspect additional options offered by the system. If the entry is absent, a language unsupported or management restrictions apply, record the reason or unknown and stop. ## Inspect the translation and direction

Only with a confirmed selection and available feature, open system translation and check Chinese as source and English as target. If detection is wrong, select from the options actually offered. Check whether the output retains both “tomorrow at three in the afternoon” and “meet.” More than one natural wording may be valid; do not treat a single phrase as the only answer. If time, date or meaning is missing or changed, mark it for human correction rather than sending it.

Apple mentions downloadable languages for on-device translation, but options and languages vary. For sensitive content, first consult Apple’s current data-handling settings. This exercise requires no language download, promises no offline translation and does not equate visible translated text with an installed language pack.

## Separate copying from replacing

If the system offers Copy Translation, paste into a new line in the working draft; otherwise record the missing option. Leave the Chinese working line intact and label the English line as machine-translated draft. Check date, time and meaning and that unrelated source text was not included. Correct only the English working line when needed, preserving the original.

A system may also offer Replace with Translation for editable selected text; it changes that selected original. Try it only in a working copy with verified selection and the user’s consent. Record the source and output first; never apply it to the only original. Afterward check copy boundaries and confirm the original remains intact. If the option is absent, mark it untested. Host undo behavior varies and is not the sole backup.

## Check meaning and visible state

Make a short table for meeting, tomorrow, afternoon, three o’clock, punctuation and missing context. The source gives no time zone, location or participants, so a translation should not add them as facts. English word order and punctuation can differ if a person confirms the meaning. Machine output is not automatically a verified fact and no specific wording is guaranteed correct.

If the language direction is wrong, inspect system language choices or reselect the sentence and retry separately. If the original input is wrong, inspect 键来 and host focus, candidate commitment and source. If translation appears correct but paste fails, inspect destination focus and host permissions instead of diagnosing a 键来 translation fault. ## Preserve results and finish

Keep the Chinese original, working line, English draft and check table, identifying machine output, human-confirmed points and incomplete steps. Restore keyboard and system settings as appropriate; the user may retain or remove the sample. Do not mark a pass without actually opening and checking the translation.
