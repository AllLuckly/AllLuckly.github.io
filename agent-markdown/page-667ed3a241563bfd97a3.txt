A remembered sentence may produce no search result because of the query, search scope, file structure or a different edition. Start with a short phrase visible in the current book and narrow the problem step by step. Preserve the book and existing notes. Neither rebuilding the whole library first nor interpreting one empty result as data loss is necessary.

## Establish a visible reference passage

Open the target book, find an actual paragraph and record the chapter and a distinctive short phrase. Start with ordinary prose rather than an image heading, formula or complicated footnote. Visible text provides a stronger reference than memory because translations, revisions and punctuation can change matching behaviour.

Check the title, author and edition so a same-name book is not confused with the target. For PDF, establish whether the page contains text or only a scan by trying the selection capability available in that reading path. Visually recognisable letters do not prove extractable text exists. Text pages and image pages require separate treatment.

## Clear leftover filters and query conditions

Inspect whether the current search covers shelf metadata, book text or notes, using only the scopes exposed by the installed version. Remove old words and unnecessary filters. Search a known title first to establish whether the target lies within the visible scope. A tag or reading-status filter can hide it without the file being absent.

Record title matches separately from text matches. Metadata and full-text indexing concern different material, so a visible author does not establish that the whole book was parsed. Keep scope fixed while changing the query instead of switching libraries and terms together, which makes the cause of a changed result unclear.

## Begin with short distinctive terms

Try a few recognisable words from the passage rather than pasting a long sentence with quotation marks, newlines or unusual spaces. Add constraints after finding a result. Shorter terms help test punctuation or tokenisation effects, but extremely common words produce too many matches to serve as the only indexing check.

Compare simplified and traditional characters, full-width and half-width forms, numbers, variant characters, spelling and hyphens with the actual text. Change one detail at a time and retain the original query. Do not alter the book’s text merely to make a result appear; observe existing content before modifying anything.

## Distinguish reflowable text from scanned images

TXT and ordinary EPUB usually contain extractable text, but images, embedded objects and unusual structures may follow different paths. PDFs can contain scans, text layers or both. CBZ consists mainly of image pages and does not imply automatic recognition of all pictured lettering. Extensions do not replace inspection of the actual contents.

If scanned material must be searchable, use an authorised external tool to obtain a text-layer copy, proofread its recognition and import it. Recognition can misread numbers, units and names, so check matches against the page. This workflow does not require an unverified built-in recognition button or guarantee perfect results after conversion.

## Confirm that the file is locally readable

A title in a remote catalogue does not prove that its text was downloaded and processed. Open or obtain the sample through the supported flow, check beginning, middle and end, and wait for any preparation visibly indicated by the interface. Remote catalogue search and local full-text search may use different data and scopes.

For a system cloud drive, confirm that the original has downloaded. For NAS, inspect download state and the local copy. App entitlements, server account rights and extractable text are separate requirements. Establish file readability first, then investigate text matching so the failing layer remains clear.

## Compare a second known-good book

Choose a small EPUB or TXT with clear body text, note a distinctive phrase and search through the same entry point. If it matches, focus on the target’s edition and structure. If neither matches, revisit scope and preparation state. Keep the same device and search interface to limit additional variables.

You can also search the same phrase in a tool that reads the original file. Failure there points toward wording, text layers or file contents; a failure in only one path is a more specific observation to record. A working comparison book alone does not prove the first book corrupt. Actual chapter and content evidence is still needed.

## Keep a reproducible problem record

Record app version, file format, known chapter, test phrase, scope and result, including whether the file is local or remote. Use a small sample without private content if reproduction is necessary instead of sharing an entire personal library. Consider current maintenance controls after identifying the behaviour; uninstalling or clearing all records is not a prerequisite.

Clear the test conditions afterwards and confirm that shelves and notes remain browsable. An empty query result does not mean books or notes were deleted, and restoring the original scope helps prevent that mistake. Even if unresolved, the checks identify whether the next step concerns the file, wording, download or search interface.
