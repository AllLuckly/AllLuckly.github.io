用一般劈线核五百八十的两边恒等式，不把它预先当中线、高或角平分线。

画一个底边内有分点的三角形，从上顶点连到分点，再用Stewart恒等式核线段长度。重点是哪个边长平方乘哪一段底边，以及求得的是长度还是长度平方。坐标与恒等式外部复算，图形只做手工展示。

## 先定底边分点与一般劈线

设A=(0,0)、B=(10,0)、C=(4,6)，D=(3,0)在AB内部。AB长十，AD长三，DB长七，CD是从顶点到对边的劈线，暂不加中线或直角符号。三角形非退化，所有长度取同一种无量纲单位。将条件、三角形、劈线和计算标签分层，先存原生稿。D不等于底边中点五，也不与C同横坐标，因此不能凭画面顺眼就宣称CD是中线或高；本课的长度关系不需要这些额外资格。这里用D在AB内使三与七都是正长度，且相加为十。若把D拖到边外，不能仍把有向延长段当正的三七两段套原账；需要重新声明外分符号，当前图不承担这项推广。

## 先用坐标独立求三条平方长度

CA的平方为4²加6²等五十二，CB的平方为(4−10)²加6²等七十二，CD的平方为(4−3)²加6²等三十七。记录CA=√52、CB=√72、CD=√37，不能直接把五十二或三十七写在线段长度栏。D到C有水平差一和竖直差六，因此图上CD并非竖直。先把这些坐标结果作为独立对照，后面再由定理反求；两条路径必须使用同一个D，不得偷偷换到C的垂足使计算更容易。

## 把每个平方配到正确的底段

本图明确写CA²乘DB，加CB²乘AD，等AB乘(CD²加AD乘DB)。于是左边52乘7加72乘3，等三百六十四加二百一十六为五百八十。乘CA平方的是靠B的分段DB，不是看到字母A就机械配AD。可用两种细引线在外部账本标配对，但引线不当作新增边。先保留完整符号式再代数值，避免换教材采用不同a、b、m、n命名后仍背一串没有对象的字母。两边量纲均为长度的三次方：边长平方再乘底段，右边长度乘平方长度之和。若把CA而非CA平方代入，量纲就不匹配，数值看起来接近也应先判作公式抄错。

## 由恒等式反求长度再乘回

右边是10乘(d²加21)，与五百八十相等，所以d²加21等五十八，d²等三十七，长度d取正根√37，约6.083。负根不作为几何线段长度，三十七也不是最终长度。乘回10乘(37加21)仍五百八十，和坐标法一致。若错把52配3、72配7，左边变六百六十，会导出d²四十五；这个错误结果可用坐标差立刻反驳。保留错例与正确配对，不能靠把图中CD随意拉长让它像√45来“验证”算式。

```
A=(0,0); B=(10,0); C=(4,6); D=(3,0)
AD=3; DB=7; AB=10
CA^2=52; CB^2=72; CD^2=37
CA^2*DB+CB^2*AD=52*7+72*3=580
AB*(CD^2+AD*DB)=10*(37+21)=580
wrong pairing: 52*3+72*7=660 -> d^2=45 (incorrect)
```

## 等比例落点并把标签让到边外

建议2400×1700画布，X=300+150x、Y=1400−150y。A、B、C、D分别落(300,1400)、(1800,1400)、(900,500)、(750,1400)。先连外边，再以另一颜色连CD，底边三与七的文字放在各自区间下方。两轴同尺度，D的标记不能因标签拥挤偏离底边。若无数值输入入口，用网格与外部坐标表手工近似；标注√37是数学结果，不是量像素得到的精密实测值。不要把文字引线误并入主轮廓形成多一条劈线。

## 用一般坐标展开解释配对来源

另在纸面设底长c，分点横坐标m，另一段n=c−m，顶点为(p,h)。两邻边平方是p²+h²与(p−c)²+h²，劈线平方为(p−m)²+h²。展开n乘前者加m乘后者，公共项整理成c乘\[劈线平方加mn\]，这才说明配对为何如此。当前示例取c十、m三、p四、h六。一般推导须保留D在边内和三角形非退化条件，不把一次数值相等包装为已经独立证明所有空间图形的同类公式。展开后含p的项为负二cmp，两边相同；常数差中的mc²−cm²等于cm(c−m)=cmn。这项代数核查能具体说明多出的mn不是为了让示例凑成五百八十而临时加入。

## 移动分点只改一项并重算

另存D′=(4,0)对照，AD′四、D′B六，此时CD′正好为六，恒等式左边52乘6加72乘4等六百，右边10乘(36加24)也六百。该对照变成高，不代表原来D三的位置也有直角。若结果仍抄√37，先查旧标签；若三与七没更新，查是否只移了点没改账本。一次只改分点，C与底边保持原样，保留两版并分清引号标记。定理用新条件重算，不是应用会随拖动自动更新数学文字。

## 重开由两条算法交付同一长度

保存可编辑原稿，隐藏计算配对的临时引线，导出SVG或PDF并另开PNG。缩小核D落在三七分段处，放大核负号、根号与平方标记没有丢失，再重开原稿确认劈线与文字可分开修改。交付坐标法、定理法、错配四十五和移动分点对照，未执行的导出重开留待办。完成标准是能说明一般劈线的条件及正确配对，不是仅看到一条从顶点连到底边的线，也不声称已有内置Stewart求解工具。
