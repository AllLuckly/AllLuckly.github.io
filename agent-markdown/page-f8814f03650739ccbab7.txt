**ManYue can store locally imported comics in its library for offline reading.** The simplest starting point is a CBZ, CBR, or PDF that opens correctly. Add it to a bookshelf with “Import Local Comics,” then open it to read.

This tutorial is based on the public description and import entry points of ManYue 2.0.2. Some versions show an additional import preview or results page; follow the prompts actually displayed.

## Before you start

- Prepare a comic file you own or have permission to read in the Files app on your iPhone / iPad.
- For the first exercise, use an ordinary, small, unencrypted file so that you can verify the entire process easily.
- Install [ManYue](<https://apps.apple.com/cn/app/id6753895889>). The version checked requires iOS / iPadOS 15.0 or later.

ManYue itself does not provide comic content. This tutorial uses local files and does not require adding a comic source or connecting to a NAS first.

## 1. Find the local comic import entry point

On the home screen, choose “Import Local Comics,” or open the import entry from the local comics page. In “Import Comics,” choose “Select File.”

You can also choose a folder, but a single file makes the imported title, page count, and target bookshelf easier to confirm on your first attempt.

## 2. Choose a comic from the Files app

Find and select the prepared CBZ, CBR, or PDF. If it is stored in a cloud drive, first confirm that it can download to the current device. A cloud placeholder showing only a filename is not completed local content.

The store description also lists CB7, ZIP, RAR, and 7z. Support for an extension does not mean every encryption method, compression algorithm, or damaged file can be read. If import fails, first check that the file is complete.

## 3. Choose a bookshelf and confirm the import

If you already have bookshelf groups, choose the destination under “Add to Bookshelf.” If an “Import Preview” appears, check the title and content, then choose “Confirm Import.”

Wait until the import actually finishes. If the results page lists failures, check their reasons; a finished task does not mean every book was saved successfully. Open imported content through “View Bookshelf” or the local library.

## 4. Open a book and adjust the reading mode

Open the newly imported work from the bookshelf or local comics list. Choose landscape / portrait and single-page / double-page layouts to suit your reading habits, and zoom in to inspect details.

ManYue saves reading progress and supports bookmarks. After your first import, leave the reader and reopen the same book to confirm that you can find where to continue reading.

## 5. Confirm that the content is actually available offline

Finish the import or download first, then open the book without a network connection and check that you can turn pages. Confirm that every page is fully saved before relying on offline access.

A cover or directory in a remote library only shows that the list can be browsed; it does not prove the complete comic is on the device. Before traveling offline, confirm that the intended content has finished importing or downloading.

## Complete the first reading workflow with a small sample

For your first attempt, use a short comic of a dozen or so pages that you made yourself, or a small PDF. Write down its expected title and page count first. Select only that file in the import screen, confirm the destination bookshelf, wait for a clear result, and then open it. If something goes wrong, you can distinguish a wrong file, an unfinished import, or a different group without searching through many similar titles.

After opening the book, read several pages from the start, then jump to the middle and end. For chapter-based content, open at least two chapters and confirm their names and order. A displayed cover is only the first step; the real checks concern the reading pages. Keep this sample for a while so that it serves as known content when changing networks, devices, or settings later.

## Keep these three things after your first import

Keep the original comic file, remember the group it was imported into, and note one easily recognizable page. Exit the reader and reopen it to confirm that you can continue reading, then check several pages offline to confirm that the content is on the device. Once these steps pass, import more files the same way. This is easier to learn than processing the entire library at once.

Keep originals in your own organized file folders and use the app's reading copies for everyday reading. Bookshelf groups help you find books, while reading history returns you to recent positions. Each has its own role. Before freeing storage later, confirm which originals remain and which content must stay available offline, then choose the specific cleanup operation. Organizing a list and deleting files are different actions.

## Frequently asked questions

### What is the difference between “Import Comics” and “Import Comic Sources”?

Importing comics adds your own comic files to the local library. Importing comic sources adds JS / .ManYue source files or links to connect to the corresponding content source. They use different entry points, file types, and content sources.

### Why will an imported file not open?

Check the extension, file size, and integrity first, including whether the file is encrypted or uses an unusual compression method. Try another ordinary small file to verify the workflow, then troubleshoot the original according to the import error.

### Does iCloud or WebDAV sync synchronize all comic files?

No. The public description lists reading history, favorites, and app settings as the sync scope. To read offline on another device, still confirm that the comic content has been imported or downloaded on that device.

### How do I move from local reading to a NAS?

ManYue supports WebDAV / SMB and server libraries such as Komga and Kavita. Identify your server type, address, and access account, then choose the corresponding entry. Some features require Pro or Ultra. See [ManYue use cases and limitations](<https://allluckly.cn/en/apps/manyue/>).
