English translation of the [Chinese original](<https://allluckly.cn/guides/vectorpaint-word-square-grid/>), translated on 2026-11-03. Original publication dates, attribution, code and version notes are retained.

A small word square practises lettering alignment, but its crossings must also agree. Use CAT, ARE and TEN as three example rows, manually verify the same three columns, then create a prompt with blanks. This is a static word-form exercise rather than an automatic crossword generator or a complete vocabulary or language lesson.

## Verify the letter matrix outside the app

Write rows C–A–T, A–R–E and T–E–N and read each column downward to confirm CAT, ARE and TEN again. Valid row words do not automatically establish valid columns. Reserve nine cells and instructions on an 800 by 800 pixel canvas. These words provide a verifiable starting example; any replacements require a complete new row-and-column audit. Keep the source matrix before drawing so an impossible crossing is discovered before extensive layout work.

## Start with nine equally sized cells

Duplicate one unfilled square into a three-by-three grid and check for overlapping duplicates. Decide whether to use one outer frame and dividers or consistently overlapping cell borders; avoid uneven shared-edge weights. Leave room for letters and instructions. Keep grid and text separate so alignment does not move the framework. Inspect the empty grid at delivery size and confirm each cell is easy to identify.

## Enter letters cell by cell and keep them upright

Enter nine independent letter objects from the source list using one font and size initially. Judge optical centring by the glyphs, while preserving coherent rows and columns. Do not distort letters to fit square cells. Read all rows and columns to catch stale duplicated letters. Uppercase is an exercise choice; lowercase or another writing system needs fresh glyph and layout checks rather than inheriting the same approval.

## Keep the complete solution while making blanks

Duplicate the full solution for the prompt and record three chosen blank positions by row/column. Hide letters in the prompt without deleting the only solution. Blank cells should still look writable rather than disabled. State whether clues provide row words, letters or another explicit instruction. Without uniqueness checking, describe completion of this example rather than claiming a standard uniquely solvable crossword. Version blank positions with the solution.

## Distinguish row and column clue identifiers

Use distinct row and column identifier systems, defining left-to-right and top-to-bottom directions. Keep IDs outside cells or in a consistent corner without colliding with letters. Audit clue order against the actual grid. If only row words are supplied, state that columns are a check rather than implying hidden missing clues. Include only the identifier systems needed to explain where to fill and how to verify.

## Refill the prompt from its recorded blanks

Hide the solution, refill the three blanks using the prompt’s stated information and read every row and column. Do not rely on memorising the draft; follow the supplied clues. Add missing information or narrow the task instead of secretly changing the solution. Check that known letters were not displaced during testing. Keep test letters out of the shared blank prompt. This validates this example’s instructions and files, not an automatic app-wide word validator.

## Inspect grid lines and glyph distinction after export

Save solution, prompt and blank records and name their exports distinctly. Inspect glyph clarity and linework at real size; a font working for these letters is not automatically suitable for every letter. Allow handwriting room in print and test small screen clues and background contrast separately. Reopen the prompt for answer leakage and the solution for all nine letters. Update the external matrix and both editable sources before exporting new words.

## Resolve crossing conflicts in the matrix first

Locate row/column conflicts in the source matrix instead of masking them through geometry or colour. For mismatched blanks, verify the blank-list revision and opened files. Investigate duplicated borders for uneven line weights and distinguish text-box centring from optical glyph position. Read all rows and columns and check all blank positions after repair. Both crossing correctness and visual placement must work for the static exercise.
