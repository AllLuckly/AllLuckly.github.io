Yearn is a **retro game emulator for iPhone and iPad**. Import your own game files, organise the library and play with on-screen or physical controls. Before a longer play session, test saving, quitting and loading again to confirm that your game can resume.

## Which platforms are listed?

The checked store description lists NES, SNES, Game Boy / Game Boy Color, GBA, N64, Nintendo DS, Sega Genesis and PlayStation. Platform support does not mean every file is fully compatible. The game edition, file integrity, matching BIOS and device performance can all affect the result.

Yearn does not include game ROMs. With files you are entitled to use, begin with one game and complete import, launch, controls, saving and exit before organising a larger collection.

## Set up controls and saves

- **Touch controls:** adjust virtual-button size and opacity, and check that controls do not obscure the game.
- **Physical controllers:** pair in system settings first, then check directions, confirm, cancel and other common buttons.
- **Save states:** use separate slots for different points and check the selected slot before overwriting. Save states are different from the game’s own saves.
- **Cross-device checks:** confirm iCloud status, the matching game and save time, then test whether the second device restores the expected progress.

Start by [importing your first game](<https://allluckly.cn/en/guides/yearn-getting-started/>), then read about [save slots](<https://allluckly.cn/en/guides/yearn-save-slots/>) and [Bluetooth controllers](<https://allluckly.cn/en/guides/yearn-bluetooth-controller/>).

## Display and offline preparation

Adjust display options after the game runs correctly. Observe the original aspect ratio, then compare landscape, scaling and dual-screen layouts one setting at a time. For system screen mirroring, check audio output and control latency separately. Before leaving home, verify that the game and required files are on the device; a cover in the library is not enough.
