Manually draw a six-string chord grid and verify fingered, open and unplayed strings for open C major.

## Define chart conventions

This exercise manually draws an open C-major chart for a standard-tuned guitar, not an automatic music-recognition tool. Yamaha describes vertical lines as strings, horizontal lines as frets, X as an unplayed string and O as open. Fender places open C at string 5 fret 3, string 4 fret 2 and string 2 fret 1, played from string 5 across five strings. Write these facts on paper before drawing in VectorPaint. Do not apply the example unchanged to a differently tuned instrument.

## Set up canvas and objects

Create an approximately 1200 by 1500 pixel portrait canvas using the current interface and save an editable original. Reserve a title and nut-marker area above, the grid in the middle, and legend and notes below. Organize grid, dots, text and background using available layers or objects; use identifiable entries if labels differ. Canvas dimensions are suggestions and do not establish physical print size.

## Draw six strings and the nut

Draw one vertical line, then use available duplication or manual drawing to make six equally spaced parallel lines. Set the convention left to right as strings 6, 5, 4, 3, 2, 1, from low E to high E; write those numbers in your working sketch to prevent reversal. A thicker horizontal line at the top represents the nut and crosses all six strings. Its thickness is a diagram convention, not a precise depiction of the physical nut.

## Draw three fret spaces

Below the nut draw three parallel horizontal lines crossing all six strings to form three stacked fret spaces. Fret 1 is between nut and first line, fret 2 between first and second, fret 3 between second and third. Place a fretting dot within a space, not on a horizontal fret line. Count five gaps between strings and three fret spaces, then check that horizontal lines reach both outer strings; this prevents a missing string or extra fret.

## Place the three fretting dots

Using the recorded fingering, place a dot in fret 3 on the second vertical line from the left (string 5), in fret 2 on the third line (string 4), and in fret 1 on the fifth line (string 2). Keep dots consistently sized, centered on their string lines and vertically inside the correct fret spaces. Use a high-contrast fill, but do not rely on color alone to distinguish fretted and open strings.

## Mark open and unplayed strings

Above the nut place X over string 6: this voicing is played from string 5, leaving string 6 unplayed. Place an open O above strings 3 and 1. Strings 5, 4 and 2 already have fretting dots and receive no O. Reading left to right gives X, 3, 2, O, 1, O, where numbers identify frets rather than fingers. Explain that distinction in the legend to prevent confusion.

## Cross-check in reverse with a table

Make a six-column check table beside the draft: string 6 X; string 5 fret 3; string 4 fret 2; string 3 open; string 2 fret 1; string 1 open. Find each corresponding line from the table, then read the diagram back into the table. Check that the string 2 dot is not on fret 2 and that fret 3 was not confused with string 3. If sharing the chart alone, retain the string-number direction and nut explanation so readers can orient it independently.

## Check note names on the strings

In standard tuning the played strings from 5 through 1 give C, E, G, C and E. String 6 is marked X and excluded. Note names can support the working check, but differ from fret numbers and finger numbers. Confirm that string 6 is on the left before reading each column, so names are not retained on a mirrored chart. Hide working note labels afterward if desired while retaining the final legend.

## Add a readable title and legend

Above the chart write “C major, open position, standard tuning”; below write “X: unplayed; O: open; filled dot: fretted.” Do not add numbers inside dots as finger recommendations unless separately checked and labeled as finger numbers; this example needs none. At small scale check that string numbers, X and O remain distinct. In print or grayscale, filled dots and open circles should remain distinguishable without relying on blue and red. Increase spacing when necessary rather than only increasing saturation.

## Separate chart reading from playing

The locations represent one open C-major voicing; they do not guarantee a single hand shape suits every player or claim this chart was play-tested. An experienced player can review it against their instrument. If trying it, confirm tuning and start from string 5 without pressing through pain. As a design task, the six strings and fret positions can be checked statically against sources even without a guitar; mark unperformed playing checks pending.

## Save and check the output

Save the editable original and use a share or export entry actually visible in the current version to save a separate image. Reopen it and count six strings, three frets, three filled dots, two open circles, one X, title and legend. Return to the original and check that grid and markers can be identified separately. If a marker is missing, check visibility, crop and file location before overwriting the only original. Include chart-reading and fingering sources and mark unperformed device or export steps pending.

## Use one incorrect fret as a reverse check

Copy the checklist on paper and deliberately change only the second string’s stopped position from fret one to fret two, leaving the other strings unchanged. Compare the diagram and table left to right to find the single mismatched column. In standard tuning the open second string is B, the first fret is C and the second is C sharp; these are not the same note. Use the incorrect table only for self-checking; keep the published diagram’s open C fingering.
