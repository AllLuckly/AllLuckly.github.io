> "Integrate Baidu Mobile SSP launch ads into your APP to increase revenue."

> Bison

My free app is about to be released. I have been wondering how to earn back the 99 dollars for my developer membership.  
 Adding ads to my app seemed the easiest way to earn it back. But I am a perfectionist,   
 I dislike ads everywhere, with an interstitial suddenly appearing while you are using an app. Besides harming the user experience,   
 they also spoil the app's appearance, which I cannot tolerate. Caught in that dilemma, I took a look at Baidu Mobile SSP.  
 Baidu SSP offers many ad formats. For me, a launch ad is the best fit: first, it does not interfere with the user's   
 experience, and second, it does not spoil the app's overall appearance. That settled the decision.  
 Now let us see how to integrate it.

> Baidu SSP official website [Go to the resource](<http://mssp.baidu.com/home/developer.html>)

First register an account with Baidu SSP, add a mobile application under application management, and fill in the relevant information. Then download the SDK and drag its `ios_api` folder into your project.

## warning: iOS9 compatibility notes:

> 1. In the plist, add baidumobads to the LSApplicationQueriesSchemes array. Note: the Xcode7.0 simulator reports error:(null), whereas a physical device does not. This error can be ignored here.

```css
    <key>LSApplicationQueriesSchemes</key> <array>
    <string>baidumobads</string>
    </array>
```

> 2. ENABLE\_BITCODE=YES. The SDK supports BITCODE; if you do not need it, simply set this to NO.

> 3. In the plist, set NSAllowsArbitraryLoads to true under NSAppTransportSecurity. Note: in Xcode7.1, set Allow Arbitrary Loads to true under App Transport Security Settings.

```css
    <key>NSAppTransportSecurity</key> 
    <dict>
    <key>NSAllowsArbitraryLoads</key> 
    <true/>
    </dict>
```

> 4. The .dylib libraries used by the SDK have .tbd extensions in Xcode7. Import the libraries with the corresponding names.

`QuartzCore.framework`

## Then configure the compiler parameters.

> targets-\>BuildSettings-\>Other Linker Flags -\> add -ObjC -lstdc++

That completes the configuration. From here, we will discuss only Baidu SSP launch ads.

Import the headers in `AppDelegate`: `#import "BaiduMobAdSplashDelegate.h"` `#import "BaiduMobAdSplash.h"` Add the `BaiduMobAdSplashDelegate` delegate.

The specific code is as follows.

.h file

```css
@property (strong, nonatomic) BaiduMobAdSplash *splash;

@property (strong, nonatomic) UIView *customSplashView;
```

.m file

```css
- (BOOL)application:(UIApplication *)application didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {

    //百度广告
    [self BaiDuNew];

    return YES;
}

- (void)BaiDuNew{

    [self.window makeKeyAndVisible];
    BaiduMobAdSplash	*splash	=	[[BaiduMobAdSplash	alloc]	init];
    splash.delegate	= self;
    //把在mssp.baidu.com上创建后获得的代码位id写到这里
    splash.AdUnitTag = @"2365464";
    splash.canSplashClick	=	YES;
    [splash	loadAndDisplayUsingKeyWindow:self.window];
    self.splash	= splash;

    //可以在customSplashView上显示包含icon的自定义开屏
    self.customSplashView = [[UIView alloc]initWithFrame:self.window.frame];
    self.customSplashView.backgroundColor = [UIColor whiteColor];
    [self.window addSubview:self.customSplashView];
    [self.window bringSubviewToFront:self.customSplashView];


    //在baiduSplashContainer用做上展现百度广告的容器，注意尺寸必须大于200*200，并且baiduSplashContainer需要全部在window内，同时开机画面不建议旋转
    CGFloat width = self.window.frame.size.width;
    CGFloat height= self.window.frame.size.height;
    UIView * baiduSplashContainer = [[UIView alloc]initWithFrame:CGRectMake(0, 0, width, height-100)];
    [self.customSplashView addSubview:baiduSplashContainer];

    UIImageView *iconView = [[UIImageView alloc]initWithImage:[UIImage imageNamed:@"icon.png"]];
    [iconView setFrame:CGRectMake(width/2-70-40, height-90, 80, 80)];
    [self.customSplashView addSubview:iconView];

    UIImageView *logoView = [[UIImageView alloc]initWithImage:[UIImage imageNamed:@"ITBlog.png"]];
    [logoView setFrame:CGRectMake(CGRectGetMaxX(iconView.frame)+40, height-90, 130, 50)];
    [self.customSplashView addSubview:logoView];

    UILabel *label = [[UILabel alloc]initWithFrame:CGRectMake(CGRectGetMinX(logoView.frame)-2, CGRectGetMaxY(logoView.frame), 130, 25)];
    label.font = [UIFont systemFontOfSize:13];
    label.textAlignment = NSTextAlignmentLeft;
    label.textColor = [UIColor lightGrayColor];
    label.text = @"自学iOS开发进阶首选";
    label.textAlignment = NSTextAlignmentCenter;
    [self.customSplashView addSubview:label];
    //在的baiduSplashContainer里展现百度广告
    [splash loadAndDisplayUsingContainerView:baiduSplashContainer];
}

- (NSString *)publisherId
{

    return @"ab17bd77";
}

/**
*  广告展示成功
*/
- (void)splashSuccessPresentScreen:(BaiduMobAdSplash *)splash
{
    NSLog(@"splashSuccessPresentScreen");
}

/**
*  广告展示失败
*/
- (void)splashlFailPresentScreen:(BaiduMobAdSplash *)splash withError:(BaiduMobFailReason) reason
{
    NSLog(@"splashlFailPresentScreen withError:%d",reason);
    //自定义开屏移除
    [self.customSplashView removeFromSuperview];
}

/**
*  广告展示结束
*/
- (void)splashDidDismissScreen:(BaiduMobAdSplash *)splash
{
    NSLog(@"splashDidDismissScreen");
    //自定义开屏移除
    [self.customSplashView removeFromSuperview];
}

/**
*  广告点击
*/
- (void)splashDidClicked:(BaiduMobAdSplash *)splash
{
    NSLog(@"splashDidClicked");
}
```
