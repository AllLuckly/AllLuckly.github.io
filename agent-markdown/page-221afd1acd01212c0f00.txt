以原创离散数列比较五千与负三千赫兹，先核相位和采样边界，再记录自制影片音轨的真实播放。

文件写着八千采样率，不表示能保留八千赫兹的声音。把高频先采成错误数列，再交播放器播放，也不能恢复被混叠掉的原始信息。本课先算一组明确样本，再把外部制作条件与云映中的实际音轨分别记录，不把听见较低声音直接归因于播放器故障。

## 固定采样条件与自己的参照材料

建立练习记录，把采样率写成每秒八千个样本，样本编号从零开始。计划比较振幅零点二的五千赫兹与三千赫兹正弦，不拿真实歌声做单一频率假设。纸面材料无需先制造可听文件；若有现成可信制作工具，再准备各有片头文字的自有短片，并记录导出音轨实际采样率与编码。源工程、导出片和记录分开放，不能把项目设置当成导出文件已经符合的证明。本课的数列运算不是云映内置发生器，也不要求安装陌生音效插件。

## 先列八个样本而非凭听感猜频率

用下方公式从n等于零算到七，角度用弧度，时间是n除以八千秒。两组都从零相位开始，第一组代五千，第二组代三千；先保留正负号，再按六位小数核对。五千组的前四个归一化值是零、负零点七零七一零七、一、负零点七零七一零七，乘振幅后再记。不要把负值改成绝对值，这会变成另一种波形。计算器或自己已有脚本都可用，实算方法与舍入位数写进记录，表格不是设备采样测量值。

```
Fs = 8000
x[n] = 0.2 * sin(2*pi*5000*n/Fs)
y[n] = 0.2 * sin(2*pi*3000*n/Fs)
x[n] + y[n] = 0  (integer n, ideal arithmetic)
```

## 证明负三千对应并保留反相关系

对整数n，五千除八千等于一减三千除八千，因此五千组的正弦等于负三千组正弦，也就是三千组逐样本取负。它不是同零相位三千正弦的原样复制；改用余弦又会出现不同的相位对应。把两组逐项相加，应只剩舍入误差，而不是逐项相减为零。这里负频率用作离散公式的数学表示，不是播放器新增一条负三千音轨，也不表示人能把频率听成负数。只凭单独听两段纯音，通常也不能确认这种极性关系，判断须回到源数列。另将每组编号延伸到十五，周期重复时仍须核符号，不从前两点猜完整循环。

## 把奈奎斯特边界与防混叠处理分开

八千采样率的半值是四千赫兹，五千已越过这个边界。合格的采样链通常须在采样或降采样前抑制边界外成分，而不是先得到混叠数列再靠播放器修复。若原素材实际四万八千采样率，外部工具正确降到八千时五千成分可能被滤掉，结果并不必然是清楚的三千纯音。将故意直接套公式得到的混叠模型与真实工具带滤波的处理分别命名。边界本身也不能随意写成恰好四千的任意相位波形都可完整重建，严格条件必须留出说明。

## 在云映只观察明确标识的导出片

已有自己的导出片时，通过安装版实际可见的本地视频入口选择它，先核片头标识、文件时长和当前音轨。保持播放速度、输出设备和音量一致，以舒适的小音量短时比较，记录是否可播、声音是否存在以及明显差异；不要用调高音量补偿不同频率的听感。若仅完成纸面数列，就把播放一栏留未执行，不能写已经听到三千。应用若不能打开某份实验容器，先记录文件路径与编码，不据此判定它对混叠理论的处理错误，也不要改后缀冒充转码。

## 只换一个频率建立未越界对照

另算一千赫兹在同一八千采样率下的前八个样本，其周期恰为八个样本，未超过半采样率。把五千模型、一千模型与真实工具导出分别列行，不能把三者的实际样本数混写。若做新影片，仅改变目标频率并保留振幅、片长与导出设置，另取名字。这个对照说明频率与采样格点的关系，不代表所有低于四千的实际录制都没有失真；量化、噪声、编码和模拟路径仍是其他条件。写结论时限定到本例正弦与已经计算的整数格点。

## 按时间单位与实际导出参数排错

若算出的八点全为零，先检查角度制、是否误把n当整秒以及公式中的采样率是否漏写。两组关系反了时核正负号和初相位，不通过左右交换声道迁就。真实导出与纸面不一致，先回外部工具查滤波、采样率转换及峰值处理；云映界面音量不是样本振幅校准器。只在自己的副本改一项再导出，保留失败稿和实际参数。没有频谱或样本读取工具，就如实保留声音印象与证据限制，不从耳听给出精确三千赫兹或几分贝差值。

## 交付数列、制作条件和实际结果

重开所选片源，核是否仍为同一个导出对象，并恢复原先音轨与正常速度。交付八点计算、逐项负值关系、一千对照、外部处理条件与实际观察；未制作或未播放的项目留空并标未执行。以后换成九千采样率时必须重新计算半值与折回关系，不能继续引用本课三千结论。完成标准是能说明混叠在何处进入，以及播放器实际接收到哪份文件；不能从某段可以播放推断所有采样率、编码或设备输出都已验证，也不能用数学等式替代真实文件的身份核验。
