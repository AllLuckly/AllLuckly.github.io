把 Markdown、HTML、RTF 和 DOCX 作为私人阅读资料导入，检查正文、外部图片与版式边界，再整理可查找的文档书架。

除了小说，书屿也可以用于阅读自己的 Markdown、HTML、RTF 和 DOCX 文档。把工作资料放进书架时，最需要先确认的是文字是否完整、结构是否适合连续阅读，而不是期待它替代原来的排版软件。

## 挑选适合放进书架的资料

先准备四份小样本：一篇带标题和列表的 Markdown、一份保存完整的 HTML、一段 RTF 文字，以及包含两个章节的 DOCX。只需使用自己的练习内容，不必拿唯一的正式合同或复杂报告测试。每份保留原文件，并记录原本应该出现的标题、段落和图片数量。

这类文档可能依赖外部样式、网络图片、嵌入字体或特殊对象。书屿的主要任务是阅读与管理，不能假定所有表格、脚注、批注、公式和修订痕迹都会像原始编辑器一样呈现。若文档价值依赖精确版面，先保留 PDF 版本用于对照，再决定是否用文本阅读形式。

## 一次只导入一种格式

从书架的「本地文件导入」选取一个样本，在预览中核对格式，再开始导入。打开后先看标题是否正确，再逐段对照原文件。确认这一种格式正常后，才继续导入下一种。把四十份文件一次送进去，很难判断是哪类结构导致显示差异。

例如 Markdown 样本可以包含一级标题、三条列表和一段引用；阅读时检查文字顺序与段落边界。看到样式与编辑器不同并不一定影响理解，但若列表内容缺失、顺序改变或代码块混成一段，应回到原文件核对，再决定是否转换为其他形式。不要在未检查前删除原始文档。

## HTML 要检查资源是否跟着文件走

HTML 常见的问题是主文件已经保存，图片和样式却仍指向互联网或旁边的资源目录。导入后先看正文，再临时断开网络检查图片是否还在。如果只有文字保留，说明资源可能没有完整打包；这与 NAS 下载速度或书架排序没有直接关系。

网页链接也不等于本地文档。若你的目标是长期阅读一份材料，应使用合法方式保存完整副本，并在合适工具中整理好相对路径，或者生成可独立打开的 EPUB/PDF。不要把登录后的网页地址当成可以永久离线使用的内容，登录状态和网页资源都可能改变。

## DOCX 与 RTF 关注内容结构

打开 DOCX 或 RTF 后，按原文顺序检查段落、标题、表格附近的文字。若有图表，确认图表后面的解释没有被遗漏。阅读副本适合查阅主体内容，但正式修改、审阅和版式交付仍应回原来的编辑工具完成；书架显示的名称属于阅读资料，不能据此判断原文内部的标题字段已经被改写。

对于课程笔记，可以先把过于复杂的布局简化成短标题、普通段落和清楚的编号。每节围绕一个主题，比一页里堆很多文本框更适合手机屏幕。需要查看精确公式或多栏排版时，使用相应 PDF 副本；这是一种按用途分配格式的方法，不是要求所有资料都转换成同一种文件。

## 整理一个小型资料书架

给四份样本使用清楚的书名，例如「摄影笔记—基础概念」「摄影笔记—器材清单」，并按实际内容添加标签。文件格式只说明保存方式，标签更适合表达主题。若同一份资料同时有 DOCX 和 PDF，保留版本日期，有助于发现哪份才是本周修订过的内容。

第一次整理可以只建立“学习”“工作参考”两个标签，读完后再逐渐细分。过早创建几十种分类，容易让同一资料在多个近义标签之间摇摆。确认文档能正常打开和搜索，比把封面做得很漂亮更重要；封面只是识别辅助，不能代替版本和内容核对。

## 搜索与位置检查

在一份文档中选一句独特的文字，完成导入与索引准备后，用书架搜索查找。先搜短词，再看结果是否来自书名还是正文。扫描图片里的文字、嵌入对象或没有被解析成文本的部分，不能保证进入全文索引。搜不到时，应先检查实际阅读页面，而不是直接判断索引损坏。

回到文档读两三段，退出重开，检查位置是否合理。文档经过外部修订重新导入后，段落数量与结构可能改变，旧位置不一定仍准确。重要笔记保留原文短句和文档版本，能够帮助你在新版中重新确认上下文，而不是只依赖一个百分比。

## 常见问题与格式选择

**导入支持 DOCX，为什么版式不像 Word？** 导入和阅读支持不等于完整的文档编辑与排版兼容。文本框、复杂表格、脚注和修订信息都应在原编辑器中复核；若要求页面完全一致，先导出 PDF，再按固定版面阅读。

**HTML 里的图片为什么变空白？** 检查图片是否位于外部网络、是否需要登录、是否与主文件一起保存。只改 HTML 文件名不能修复资源路径。对长期资料优先保存能独立使用的合法副本。

**Markdown 中的符号需要全部删掉吗？** 先观察实际显示，通常没有必要为了阅读手工删去所有标记。只有当结构确实影响理解时，才在副本中整理；保留原文件有利于以后继续编辑与生成其他格式。
