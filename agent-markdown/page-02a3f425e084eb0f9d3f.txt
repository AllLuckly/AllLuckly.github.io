逐项算二阶矩阵对两条方向的作用，核特征值三与一、无限多倍数向量及零向量反例。

矩阵把某个向量变成原向量的数倍，这种关系值得单独记录，但零向量不能用来冒充所有特征值的证据。本课用原创二阶矩阵题卡，在书屿逐格核乘法、比例与非零条件，再用同一输入的分解验证连续作用。不是让应用自动进行线性代数分析。

## 先抄矩阵与列向量约定

题卡V1设A第一行二、一，第二行一、二，输入都是实数列向量。定义要找非零v与数λ，使Av等λv；λ是数而v有两个分量，二者不是同一种对象。把原式与非零条件放在同一可见框，导出清楚PDF或EPUB导入书屿，给框加书签。若以图片存矩阵，先核上下行与左右列，不预设搜索能理解数组。这里处理实向量和指定矩阵，不从一张对称表格的外观就断言每个实矩阵都具备相同特征方向。

## 两组乘法各核两个输出分量

取u为(1,1)，按行乘列得到(3,3)，恰好等3u；取v为(1,−1)，得到(1,−1)，恰好等1v。对应特征值分别三与一，不能把两个分量相加后拿六或零当特征值。每个候选都要用同一个比例同时解释两分量，不是第一项乘三第二项随意改。把两次乘法写在题卡下，逐项保留负号。即使A对称也不能用逐项乘法代替矩阵乘法；这里u与v名字只是本课标签，不代表所有教材都按同样次序命名。

```
A=[[2,1],[1,2]]
u=(1,1); A*u=(3,3)=3*u
v=(1,-1); A*v=(1,-1)=1*v
w=(1,0); A*w=(2,1), not a scalar multiple of w
```

## 用非候选与零向量检查定义

w为(1,0)时，Aw为(2,1)，任何λ乘w第二项都为零，所以不存在同一λ使两项相等，w不是本矩阵特征向量。再看零向量，A乘零等零，且任意λ乘零也零；正因它无法区分λ，定义将它排除。不能把满足等式的一部分条件当完整资格。将非零要求单独高亮，并用w的第二分量写反证，不用模糊的看起来转向作唯一理由。若两个分量都非零，逐项比值可辅助核，但遇到零分量不能直接做除零运算。

## 求特征多项式并保留整条方向

本例det(A−λI)为(2−λ)²−1，展开为λ²−4λ+3，分解成(λ−1)(λ−3)，只给一与三两种特征值。对三，方程得到两个分量相等，所以所有非零c乘(1,1)都合格；对一，得到两分量相反，所有非零c乘(1,−1)都合格。两条特征方向不表示总共只有两个特征向量，也不是每个方向只准单位长度。取c为二分别乘回，核输出(6,6)与(2,−2)，再核它们仍对应原特征值，不因向量变长而把λ翻倍。

还可核迹为二加二等四，等于三加一；行列式为四减一等三，等于三乘一。它们能发现某些特征值算错，却不能单独证明候选向量正确；若把任意向量都贴上三，迹和行列式不会替它完成乘回。两类证据应分别保存：数的关系核特征值，向量乘法核特征对。

## 负特征值和零特征值另作控制

另卡B取对角负一、二，非对角为零，输入(1,0)变成(−1,0)，λ负一仍是合法特征值，方向可以反向。再卡C取对角一、零，输入(0,1)非零却被送到零，故λ零也可合法。必须分清零特征值与零特征向量：前者允许，后者仍排除。两张控制卡不能悄悄替换V1的矩阵，A自身的特征值依旧只有三与一。记录时连同矩阵身份、输入、输出、λ四栏，避免一条等式截出来后失去适用对象。

## 分解一个普通输入核连续作用

取x为(3,1)，它等2u加v，不是A的特征向量。线性作用给Ax等6u加v，为(7,5)，直接按原矩阵算也得到七与五。再作用一次，A²x等18u加v，为(19,17)；直接算A乘(7,5)同样十九与十七。系数各沿本方向乘对应λ，不把普通输入整体都乘三。把分解与直接乘法做成两栏，可发现漏乘系数或把v的特征值也写三。此处解释特定输入的计算，不宣称所有矩阵总能这样分成两条实特征方向。

w还可写成(u+v)除二，所以Aw为(3u+v)除二，仍回到(2,1)。这解释为什么混合两个不同特征值的方向通常不能整体用同一个倍数描述；不是所有特征向量相加都还是特征向量。只有沿同一特征值的线性组合在非零时仍保留相应关系，本课不把零组合也算进去。

```
x=(3,1)=2*u+v
A*x=6*u+v=(7,5)
A^2*x=18*u+v=(19,17)
B=[[-1,0],[0,2]]; B*(1,0)=(-1,0)
C=[[1,0],[0,0]]; C*(0,1)=(0,0)
```

## 在书屿将定义和验证成对保存

为V1定义框与乘法表分别高亮或记页位，笔记先写自己的候选λ，再代回两分量，不只复制答案三和一。若查不到λ符号，可用V1角标返回，不把检索无命中当没有该条件。算出六时查是否把输出分量相加；拿零输入证明任意λ时查非零要求；把变长与λ变化混淆时回c为二的控制。更正一处后重算直接乘法与分解两条路径。软件保存的书摘是阅读记录，不是特征关系已经被自动证明的证书。

若把列向量横排作展示，务必保留它是列输入的说明；排版逗号形式不授权改成行向量右乘。对象方向变更后，原先逐行乘列的两项证据不能照抄。

## 重开逐项排除过强结论

重开题卡，先给u、v、w、零四个输入判断，再说出A有两种特征值却有无限多个非零倍数特征向量。回B与C确认负λ和零λ不被误删，随后复算(3,1)两次作用。验收需要完整矩阵身份和非零条件，不凭平行图标给所有情况贴标签。保存纸面推导、来源与实际阅读操作，未做重开仍待办；若换成没有实特征方向的旋转矩阵，重新解定义，不把当前对称例子的结论推广成每个实矩阵必有两条实方向。
