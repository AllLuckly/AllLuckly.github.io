Switch an owned recording from device speaker to paired Bluetooth headphones and back, separately recording system destination, player state and audible result.

## Prepare your devices and one recording

Use an iPhone or iPad with 调调, your own Bluetooth headphones already paired according to their instructions, and a short recording you are entitled to use. Preserve an external original. Choose a safe quiet setting, start at low volume and note title, duration and an identifiable opening. Record OS, app version if visible and headphone identity. If the accessory is unavailable or unpaired, follow its actual instructions and mark later observations pending.

## Establish the device-speaker baseline

Find the recording in 调调, verify title and duration, select the device itself as the actual output, and play briefly at a suitable volume. Record the track, playhead, audible location and player state, then pause. If the sound is not the expected recording, check identity; if the playhead does not move, check readability. Do not use headphone remote controls or change songs in this round. Record the visible next queue item if useful for detecting an unintended skip.

## Confirm the Bluetooth connection

Follow Apple’s system guidance to establish that your own paired accessory is connected to this device. Connected is not the same as selected as the current playback destination. Preserve the current track and paused state, and note the actual accessory name. Do not confuse a similarly named nearby device with yours. If it is missing, check power, range and its current connection according to its own instructions; leave subsequent steps pending if unresolved.

## Select the headphones as system destination

Resume the same recording. Use the playback-destination control actually shown in Control Center or on the Lock Screen to select the identified Bluetooth headphones. Apple documents these system locations; interface details can vary with OS version. Check the selected destination, the player’s moving playhead and recognizable sound in the headphones separately. One does not prove the other two. Do not assume 调调 provides its own Bluetooth-device chooser. If several similarly named devices appear, verify your accessory’s full name; do not switch at random when identity is unclear or select someone else’s device.

## Record player state before and after

Return to 调调 and check the current track, approximate playhead, play or pause state and previously noted next item. Check the system destination again and record any observed interruption or continuation without presuming seamlessness, a pause or a restart. If the track has naturally ended, record timing and repeat with the same original track; the next track does not prove the first continued. This is an observation sequence, not a millisecond latency measurement.

## Select the device again and check output

From the system’s available destinations, select the device itself, verify the displayed destination and listen at an appropriate level for the speaker. Return to the app to check track and playhead; record whether you manually pressed play or pause. If the option is unavailable, record the actual list and investigate the system connection instead of deleting the pairing. Each switch has its own result; the first success does not guarantee the second or predict disconnect behavior.

## Troubleshoot source, connection and destination separately

If the playhead moves without headphone sound, check system destination, connection and volume. If the system does not list the headphones, investigate the connection before reimporting audio. If neither output produces sound, check player state and the same file without simultaneously changing source. If only one output fails, record that device and selection before concluding that the recording is damaged. Change one condition at a time and preserve the prior state; mark unavailable tests pending.

## Deliver observations and restore

Keep a three-column ledger for system destination, player track/state and where sound was actually heard, with rows for device baseline, headphones and return to device. Add versions, accessory identity and incomplete checks without recording account information. Restore your usual output and volume, and keep the source audio and notes. These observations apply only to the actual devices and conditions; they do not establish universal Bluetooth, background, quality or latency behavior. No real device listening is claimed here.
