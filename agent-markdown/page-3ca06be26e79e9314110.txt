按明确峰值参照换算两个幅度，保留外部测量与云映实际播放各自的证据。

音量滑块一半，不等于文件峰值负六分贝，更不等于耳朵觉得一半响。本课先给数字满幅峰值定参照，手算两张电平卡，再用自有短片记录云映播放条件。计算和可用外部测量不冒充播放器内置分析，主观听感也不代替声压或响度的校准测量。

## 一、先区分文件幅度与输出条件

选一段短的自有带声视频，记录文件身份、音轨、设备、输出路径与可见音量位置，采用平常舒适的固定音量。原片保留，若已有外部音频工具能取得文件峰值，登记工具与读数范围；没有则只完成纸面卡片，不写已经测到该文件电平。耳机、扬声器和系统处理都会影响实际听到的声音，不能只凭同一个滑块位置断定两台设备输出相等。云映没有显示分析表时，字段标未取得，而不是补造调试页面。

## 二、给样本峰值定义同一个满幅参照

本课明确使用归一化样本峰值：满幅峰值为一，P 卡为零点五，Q 卡为零点二五，数值取样本绝对幅度的峰值。不是把平均值、均方根或重建后的真峰值混入同一栏，也不从视频亮度猜音频幅度。下方公式是本课的峰值电平约定，计算需要正的幅度比；零不能直接代入普通对数键。先写明参照，再看分贝数，否则同样写负六，可能根本是在比较另一类指标。

```
Reference peak: 1.0
P sample peak: 0.5
Q sample peak: 0.25
Sample-peak level (dBFS) = 20 * log10(peak / 1.0)
```

## 三、复算两张卡与相对差值

用已有计算器的十为底对数或纸面近似，P 得约负六点零二零六 dBFS，Q 约负十二点零四一二 dBFS。Q 的线性峰值是 P 的一半，电平差为约负六点零二零六分贝，不是负百分之五十个分贝。核[Audacity 关于线性幅度与分贝的说明](<https://manual.audacityteam.org/man/amplify_and_normalize.html>)中的幅度参照，并保留精确公式与约数位。计算结果属于给定卡片，不自动属于你的影片；没有测量就不能把文件名填上去冒称实测。

## 四、同峰值也不直接推出相同响度

另写两条说明：一段只有很短瞬间达到峰值，另一段较长时间维持较高幅度；仅知道两者最高样本相同，不能确定整段主观响度相同。频率、持续时间、动态与输出条件还可能不同，本课不计算响度单位或声压级。也不能从负十二比负六更负就说“声音速度更慢”，这些电平数字没有秒的单位。把峰值、整段听感、是否失真各留一栏，未知的就留未知，别用一个数包办所有声音质量判断。

## 五、回到云映保持条件听同一段

在云映选中自己的真实短片与正确音轨，从同一可辨认锚点顺播，记录听清了什么，而不是立刻报一个精确分贝值。若已有独立制作的较低电平副本，可核文件身份后对照，保持速度、输出与音量位置；没有副本不必临时调整多种增强效果。实际差异只报告本轮条件，不因为听到差别就认定样本峰值恰好减半。暂停后回放同段，避免把不同台词的强弱差当成音量设置变化，原文件与默认条件都保留。

## 六、音量位置与文件改写分开检验

改变播放音量通常改变输出条件，不能单凭滑块位置说原文件峰值已被改写。[Audacity 电平表说明](<https://manual.audacityteam.org/man/meter_toolbar.html>)也区分线性、分贝刻度与输出控制。若在外部工具真正给副本施加增益，那是另一个处理步骤，需重新保存、核身份和测量范围；不要把仅调云映音量的观察填到文件处理栏。测试结束恢复自己原来的音量位置，不把对照条件留给下一次不同素材再当默认基线。

## 七、排查负号、参照与测量类型

若零点五算成正六，检查比值是否倒置；若 Q 与 P 只差三分贝，检查是否误用功率比的公式或混入另一个指标。若工具显示不同数值，先核是样本峰值、均方根、真峰值还是输出电平，不立即宣布工具错误。播放器音量百分数不能直接代入本课幅度比，除非已有明确校准关系。排查只改一项，保留原读数与工具条件；听不到差异仍可记录，不为追求结论持续提高音量，也不清空媒体资料。

## 八、退出重开后交付三层证据

退出播放再回同一短片，核音轨、输出与原音量条件，再听同一锚点。最后保存纸面峰值卡与公式、取得的外部读数与身份、云映播放观察三层，未执行测量明确标注。确认没有把负六 dBFS 写成一半响度，没有把滑块百分数当数字幅度，也没有把听感当校准声压。原片和副本不覆盖，换设备另做记录；验收是读者能区分三个对象并复算给定值，而不是声称应用已提供专业声音计量认证。
