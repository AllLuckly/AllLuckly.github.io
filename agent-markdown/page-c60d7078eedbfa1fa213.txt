Observe text size, pagination and content anchors separately in two authorized samples without automatically treating display differences as file corruption.

## Prepare two samples with different layouts

Choose two authorized EPUBs: one known to be reflowable text and one identified by its publisher as fixed layout. If the layout cannot be confirmed, record unknown rather than guessing from the cover. Retain original files and publisher information. In each book choose a recognizable sentence, image or chapter heading as an anchor and record system and Book Isle versions.

## Understand EPUB layout declarations

W3C EPUB 3.3 describes `rendition:layout` as reflowable or pre-paginated, with reflowable as the default when not declared; individual content items can override it. Fixed layouts often restrict user styling to preserve page layout. This specification describes the format and does not guarantee Book Isle’s implementation for every fixed layout, font or special item. If file structure cannot be inspected, do not unpack or modify the original for this exercise.

## Record the reflowable sample baseline

Open the first book in Book Isle at its anchor and record visible text, line count, position and actual reading appearance options. If the interface offers a font-size control, record its original value, increase it one step and inspect glyph size, line wrapping and page count around the same anchor. Check whether the reading position still refers to the same sentence using content, not page number. If no control exists, record not observed and stop that action.

## Inspect the fixed-layout sample separately

Open the second book and record the same categories of baseline information. If the same actual font-size control is available, change one step and observe layout, text and images. Record no change, partial change or scaling as observed; do not predict that fixed layout must never respond. If page zoom is offered, observe it separately. Scaling an entire page and reflowing text are distinct outcomes.

## Verify positions and investigate differences

Restore original settings for each book and return to the recorded sentence or image. Changed line breaks or pagination after font or viewport changes do not alone prove missing text; a fixed-layout font that does not change does not alone prove corruption. If text or images are missing, inspect the same authorized file in another trusted reader and record differences first. Do not overwrite the original or delete reading records.

## Record outcomes and restore the environment

Record each sample’s known layout, app and system versions, font setting and anchors before and after, restoration result and untested items; do not upload private books. Explicitly mark unknown layouts or unavailable controls unknown or untested. The exercise follows the public format standard and app description and does not claim a particular EPUB was tested in Book Isle on a physical device.

## Use anchors instead of page numbers across layouts

For example, a reflowable sample’s anchor is “the square after rain” on page 12 at the original font size. After enlargement it might occur on page 16 or in a scrolling view. Record whether that sentence and neighboring paragraph remain visible rather than requiring a fixed page number. Different books do not have the same position merely because both display page 12. Chapter names and text fragments help recover position, but do not paste private content into a public report.

For the fixed-layout sample choose a practice page with an image and caption and record their relative position. Before and after adjustment, inspect whether both remain within the visible area, then observe whether the font control changes content text or only the interface. If zoom is needed, record what is visible before and after zoom separately. Do not immediately claim a caption was deleted because it moved offscreen; scroll or return to the original view first.

## Assess mixed content item by item

W3C allows individual EPUB content items to override the publication layout, so chapters of one book can behave differently. If the contents page and body respond differently to font size, record chapter, content and action for each instead of extrapolating from one page. Book construction, embedded fonts and reader implementation may affect appearance; without evidence mark the particular cause unknown.

If the second book will not open, confirm the imported file is the same authorized copy, whether a trusted tool can open it and whether publisher restrictions apply. A cover displayed and readable body are separate results; record any app error as redacted actual text. Do not edit EPUB metadata to force reflow or use another edition or format as direct proof of a reader defect.

## Keep a reproducible comparison

Use two rows for each book’s redacted identifier, source of known layout, original and changed font sizes, anchor, line count and position after return. Mark values unavailable in the interface not observed and unperformed checks untested. Confirm both original appearances are restored and source files and existing notes remain. For support, share a self-made sample, versions and observations rather than an entire copyrighted book.

## Control display conditions

Keep device orientation, window size and system display zoom constant where possible. If any changes, record the time and change separately; line-count differences may otherwise result from available width rather than font settings. If you cannot restore them, pause the comparison and restore each condition from the original record.
