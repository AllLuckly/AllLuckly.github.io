Check chapters, illustrations, footnotes and offline access in an illustrated EPUB, separating missing resources from layout differences.

Illustrated EPUBs often contain pictures, notes and internal links. Reading one paragraph after import does not establish completeness. Use one of your own illustrated books as a reference sample, then check images, navigation and notes. The goal is a reliable mobile reading copy, without expecting identical printed pagination on every screen.

## Choose a sample with a known structure

Prepare an EPUB with a cover, chapters, at least two illustrations and one note. Open it in the original reading tool and record illustration chapters, the note's corresponding words and the last chapter. You need a reference before attributing missing material to import or the reader.

Retain the original and source date, testing a copy. For your own authored book, a clearly labelled test image can help check sequence; do not alter your only formal original. For protected or incomplete files, first establish permitted use and file status through the original source.

## Check completeness through the contents

After import, inspect chapter names and hierarchy. Enter the first, a middle and the last chapter and compare headings. A contents entry that opens blank text may indicate a broken link or missing content; complete text with simplified navigation is a different issue.

Introductions, copyright pages and appendices may appear in the reading sequence without a main contents entry. Record a missing navigation link separately from missing text. For a failed jump, look for that heading in nearby text before deciding the copy needs repair or replacement.

## Check illustrations and their captions

Go to the recorded chapters and verify that pictures appear with the correct captions. Change type size once and check paragraph order around them. Reflow changes pagination, but should not make you mistake one illustration's explanation for another. Context is a better reference than screen page numbers.

For blur, compare source image quality before assuming import compression. For cropping, try the available orientation or display controls and compare the original reader. Rendering choices may change size. Establish whether the source lacks detail or the display has a boundary issue before exporting or rebuilding the book.

## Test note navigation and the return path

Open a note marker and inspect its explanation. EPUB notes may appear at chapter ends, book ends or elsewhere; not every file provides the same popup. Return using the available control and verify you can continue at the original paragraph, bookmarking it first if useful.

Some note numbers are plain text without links, and some files lack a return link. Compare the original reader to establish whether navigation exists. If this reader handles it differently, retain chapter and a short quotation and use bookmarks or text lookup rather than repeatedly tapping into an unclear location.

## Repeat image checks offline

After local import or full download, disconnect, leave the page and reopen the book. Check illustrations you did not just visit and the final chapter to avoid merely validating cached pages. Embedded resources and externally linked images need separate treatment; network content may not work offline.

For a disappearing illustration, record its location and inspect the source resource relationship. Reappearance online suggests a dependency, without proving permanent storage. Prefer legally obtained complete packages for long-term reading rather than treating web links as guaranteed offline book attachments.

## Choose EPUB or PDF for the task

EPUB generally suits novels with occasional illustrations and adjustable text. Retain PDF for exact references to printed pages, complex tables or formula layouts. Both can serve the same work, but verify editions before treating them as equivalent simply because their titles match.

For PDF, record file and printed page numbers separately; for EPUB, record chapter and figure name. Clear references help notes and review. If exact complex layout is central, a fixed-layout counterpart is more direct than repeatedly shrinking body text, but the PDF itself still needs completeness checks.

## Keep a reproducible conclusion

Record edition, contents results, image results, note behaviour and offline results. For failure, identify an illustration, chapter or whole-file issue and add a passage you can find again. This gives a useful sample for later replacement or a developer report rather than only saying the book looks wrong.

Reopen the most important image and note and confirm you can reliably return to text. Keep originals until the new copy is dependable, including important notes tied to the old edition. This sample's suitability does not establish identical EPUB rendering on every device and file.
