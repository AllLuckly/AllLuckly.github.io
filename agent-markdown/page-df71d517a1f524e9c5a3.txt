 How to adjust constraints for the resolution

![1](<https://allluckly.cn/images/blog/tuogao/tougao15/1.png>)

The Chat screen needs a custom cell. I created it with a xib, but the AutoLayout constraints could not change with screen resolution. Here is how I handled that.

```css
/**
*  avaterImgView高度约束
*/
@property (weak, nonatomic) IBOutlet NSLayoutConstraint *avaterImgViewHeight;

/**
*  avaterImgView宽度约束
*/
@property (weak, nonatomic) IBOutlet NSLayoutConstraint *avaterImgViewWidth;
```

Drag the constraint you want to change from the xib into the .h file.  
 Then add the method.

```css
//更改约束
- (void)changeConstraints
{
    _avaterImgViewHeight.constant = WGiveHeight(45);
    _avaterImgViewWidth.constant = WGiveHeight(45);
}
```

This lets us change an AutoLayout constant dynamically. If you know a better approach, I would appreciate your advice!

The SDWebImage method I use most often

Import the header file.

```css
#import "UIImageView+WebCache.h"

[self.avaterImgView setImageWithURL:[NSURL URLWithString:_model.avatar] placeholderImage:[UIImage imageNamed:@"avater.jpg"] completed:^(UIImage *image, NSError *error, SDImageCacheType cacheType) {

}];
```

This method displays placeholderImage until the actual image loads.
