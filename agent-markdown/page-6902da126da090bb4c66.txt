## 一、先把源稿练习与真实任务分开

新建一份私人普通文字副本，把本课目标写成“输入两种标记，不执行对应动作”。第一行的英文意思是阅读草稿，第二行意思是保存副本，但这里两项都只是原创新样本中的文字，勾选状态是约定的测试数据，不是已经读完或保存的证据。不要拿实际工作清单替代练习，避免误改正在使用的完成状态。另建三栏记录源稿、按规则的纸面含义与实际宿主显示，后两栏不能互相代替。选择可以查看原始字符的编辑区，若只提供可点复选框而隐藏原文，先换一个普通文本区，不把便利的界面误当成原样输入已通过。

## 二、逐行输入并保留硬换行

确认正在使用键来后，按实际键面输入第一行半角连字符、空格、方括号标记与英文正文，再在宿主普通正文中插入一次真正的换行，输入第二行。第二行方括号内是小写英文字母叉形字符，不是乘号、对勾图案或中文叉字。文章代码围栏不属于目标，也不在两行之间额外插入空白行。先提交当前输入组合，再使用宿主实际提供的换行能力；若当前字段的回车作用是发送或提交表单，就停止并换到安全普通编辑区。本文不假设每个键盘布局的回车标签相同，也不把键面文字当成所有宿主的行为保证。

```
- [ ] Read draft
- [x] Save copy
```

## 三、给两行空格分别编号

第一行共有四枚半角空格，依次位于连字符后、第一对方括号里面、闭方括号后以及两个英文单词之间。第二行有三枚，分别在连字符后、闭方括号后与单词之间；方括号内部已经是小写字母，因此没有内部空格。只在纸上为这些位置编号，不能将编号写进源稿。这个差异是本课核心：把第一行所有空格一起压缩或删除，会同时破坏标记与正文分词。核对行首没有意外缩进，行尾没有顺手加句号。宿主视觉上把列排齐并不能证明空格种类和位置符合目标，需要回到可复制字符做逐位比较。

## 四、按 GFM 约定读回状态

参考 GFM 的任务列表扩展，列表项开头的方括号标记配合后续空白可表示任务状态：第一行空白标记对应未勾，第二行字母标记对应已勾。本课固定使用小写字母，即便规则也允许大写，输入成大写仍与唯一目标不完全一致。读回时同时核连字符构成列表项、标记跟在列表文本开头，以及标记后仍有空格；不能只看到一对方括号就认为所有上下文都满足。纸面解释写“样本状态”，不写“已完成阅读”“已完成备份”。状态文字可正确表达约定，却并不自动造成任何现实动作，这一点应与实际执行记录分栏保存。

## 五、修复一枚缺失的标记后空格

保留正确原稿，再复制一份，只删第一行闭方括号后的空格，其他三枚空格与第二行全部保持原样。先用位置账定位这个差异，再通过宿主插入点在该处补回一枚半角空格；不要在括号里面再多补一枚来凑总数。核对修复行有四枚空格且各在正确位置，说明总量正确与位置正确必须同时成立。这个修复不需要点选任何复选框，也不需要实际运行渲染器。若宿主自动把列表转换成自己的格式，先查能否还原或查看原文；无法保留源稿时换练习区，不在看不见字符的情况下连续删除猜测。

## 六、检查两行而不是两条视觉带

把编辑区变窄再变宽，观察英文正文是否折到下一视觉行；源稿仍应只有两条任务原行，中间仅一次硬换行，而不是随屏幕宽度改变条目数。若复制到另一普通文字区后第二条与第一条连在一起，优先查真正换行是否存在，以及复制选区是否跨了完整两行。若多出第三个列表项，核对是否把说明或末尾回车也当作正文。这里复用换行基础但验收更具体：每条任务标记必须与自己的英文正文在同一原行，不能让括号留在上一行而正文靠下一次硬回车补上。记录原行边界与可见折行是两份不同证据。

## 七、将宿主渲染与键盘输入分责

有的宿主按 GFM 展示复选框，有的显示纯文字，还有的采用自己的清单语法；只把这些记为宿主显示，不推断键来实现了清单系统。本文不要求执行解析，未做时写明渲染未测试；若读者另行用工具检查，须单独保存真实结果，不能把纸面规则说明直接填成运行通过。若空格丢失或标记变图案，先比较提交后的原始文字与保存重开后的文本，判断变化发生在输入、自动格式还是持久化阶段。主题、字体和键帽外观影响看见什么，但不能替代对源稿字符的检查，也不赋予提醒、截止时间或后台执行能力。

## 八、保存源稿和状态解释对照

交付两行干净源稿、一张空格位置账和两项样本状态说明，另外写明真实阅读与保存动作没有由这两行文字证明。先核两种标记，再核每行英文，最后核一次硬换行；检查顺序保留在旁注，便于下次复现。若关闭重开宿主后原文仍在，才记录实际保存通过，否则不凭截图推定。将来确实要管理事项时，应在对应应用里创建并核实际状态，不能把本课输入过的小写字母当成任务执行日志。这次成果是用键来准确写出一种带状态约定的文本，并能发现缺空格、错行和显示转换各类问题。
