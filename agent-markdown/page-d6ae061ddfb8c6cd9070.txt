DEVELOPMENT NOTES · 24 articles

From local storage to remote messages, these notes record approaches to persistence, request wrappers, push notifications and instant messaging. Identify the data layer first, then examine what each part of the code does.

## How to read this collection

1. For local data, begin with Core Data, archiving and caches. Compare storage formats, update timing and invalidation policies; these tools solve different problems.
2. For networking, start with NSURLSession and request architecture, then follow the CocoaAsyncSocket connection flow through requests, callbacks, failures and retries.
3. Push notifications, contacts, maps and payment integrations depend on permissions and changing services. After reading the historical workflow, consult the provider’s current documentation.

These notes date from 2015–2017. Their examples have not been rerun for this archive update. Check the dates and version notes before applying the ideas to a current project.
