Create a detail window from an owned illustration, checking source markers, leaders and consistent content without altering its meaning.

English translation of the [Chinese original](<https://allluckly.cn/guides/vectorpaint-detail-callout/>), translated on 2026-10-27. Original publication dates, attribution, code and version notes are retained.

A detail callout is useful only when its source location is clear. Use an owned organiser illustration to practise copies, masks and leaders. Enlarging content does not invent missing detail or establish new measurement accuracy.

## Choose a detail worth explaining

Choose a meaningful feature in an owned editable drawing, such as a lid joint, and state what needs explaining. Place the source left and detail/text right on a 1200 by 800 pixel canvas. Preserve the original. For photographs, assess source pixels first; enlargement cannot restore absent detail.

## Mark the source region

Outline the actual source region without covering its feature. Match the marked area to the forthcoming detail window and add an ID if useful. The marker is an exported explanatory object, not a temporary guide. Inspect it without decoration and choose a clear leader exit direction.

## Copy source content into the detail window

Copy the feature and necessary context, then scale proportionally. Mask it into the chosen window after checking stacking. Do not distort or selectively enlarge only part of the structure. Keep source and detail on the same revision and preserve a complete copied source for crop changes.

## Connect the source marker to the window

Draw restrained leaders between the source marker and window boundary, avoiding labels and misleading attachment to the illustrated object. Reduce crossings through placement. Use matching IDs throughout. Manual leaders need checking after moves. Test whether the marker-to-window route is clear before restoring all content.

## Explain what the enlarged view actually shows

Describe the actual feature without implying tested real-world performance. Label conceptual content and use confirmed observations for real objects. Calculate any magnification label rather than guessing; “detail illustration” may be more appropriate. Explicitly distinguish added explanatory elements from content present in the source.

## Test maintenance with a source edit

Change one source edge colour in a test and inspect the detail copy. Ordinary copies do not automatically stay linked. Update in-region changes from the same basis and verify surrounding structure. Record a common artwork revision so the callout does not explain an obsolete feature. Remove diagnostic colours afterward.

## Check export clarity and correspondence

Save and inspect marker, detail and explanation in that order. Diagnose raster-source limitations before increasing output dimensions. Adjust leaders at target width. Keep source and detail together in reports, version the figure clearly and reopen the final file to confirm matching content and clean crop boundaries.

## Diagnose a detail that does not match

Compare region, orientation and revision first. Correct ambiguous leader endpoints rather than adding more lines. Expand the crop if it removes the key join. Obtain reliable source material or label supplementary illustration when the detail is absent; enlargement cannot create evidence. Confirm where the detail comes from and what it explains.
