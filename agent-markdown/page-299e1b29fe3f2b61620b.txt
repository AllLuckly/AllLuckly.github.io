Listing key metadata in a master does not assign encryption state to each media segment. Read original placeholder samples to compare SESSION-KEY preloading with KEY’s subsequent scope. This task retrieves no keys, downloads no encrypted payload and performs no decryption. A tag supplies no promise of universal protection-system support in iCouldPlay.

## Keep two text samples separate from real credentials

Prepare master.m3u8 and media/main.m3u8 externally, preserving roles and bases. example.com is a reserved teaching domain; none of the URIs supplies real keys or media, and this task makes no requests to it. For an owned real source, record identity, tag state and acquisition time without publishing private tokens or key bytes. No encryption server is required: text suffices for the scope ledger. Add only observations from already normally accessible owned media and mark unperformed steps accordingly.

## Read preloading metadata in the master

SESSION-KEY declares AES-128, a placeholder URI, IV and explicit identity format/version string 1; the variant then references the media playlist. The tag allows preloading before reading media playlists, not a mandatory request, and is not associated with a particular media playlist. It is optional and does not establish one protection state for every subsequent segment. CODECS and bandwidth are hypothetical too. Record it as preload metadata rather than copy it into each segment’s current KEY state.

```text
#EXTM3U
#EXT-X-VERSION:5
#EXT-X-SESSION-KEY:METHOD=AES-128,URI="https://example.com/hls/keys/key-a.bin",IV=0x0000000000000000000000000000002a,KEYFORMAT="identity",KEYFORMATVERSIONS="1"
#EXT-X-STREAM-INF:BANDWIDTH=1000000,CODECS="avc1.4d401e,mp4a.40.2"
media/main.m3u8
```

## Read media KEY scope up to the next KEY

The first media KEY is AES-128 and applies to seg42.ts. The next METHOD=NONE declares seg43.ts unencrypted within the same identity-format scope. Only one KEYFORMAT is used here; do not generalize clearing behaviour to multiple formats. Two four-second segments declare eight seconds; sequence 42 is not forty-two seconds. KEY also covers intervening declared initialization sections, but this example has no MAP or invented initialization file. Track method/URI per segment. A remaining master SESSION-KEY does not make segment two AES-128, and text does not certify payload preparation.

```text
#EXTM3U
#EXT-X-VERSION:5
#EXT-X-TARGETDURATION:4
#EXT-X-MEDIA-SEQUENCE:42
#EXT-X-KEY:METHOD=AES-128,URI="https://example.com/hls/keys/key-a.bin",IV=0x0000000000000000000000000000002a,KEYFORMAT="identity",KEYFORMATVERSIONS="1"
#EXTINF:4,
seg42.ts
#EXT-X-KEY:METHOD=NONE
#EXTINF:4,
seg43.ts
#EXT-X-ENDLIST
```

## Compare method and format/version for the same URI

Both samples use the same absolute placeholder key URI, avoiding base-resolution differences. SESSION-KEY and KEY sharing a URI must match METHOD, KEYFORMAT and KEYFORMATVERSIONS: AES-128, identity and quoted 1 here. Their IVs also match by design, but that requirement names the preceding three attributes, not every attribute universally. Preserve original values and roles. A key-a.bin suffix does not certify a valid response; bytes remain unknown, and an address is not key content itself.

## Read IV length and value without treating it as a key

The IV has thirty-two hexadecimal digits after 0x, representing sixteen bytes. Final 2a is decimal 42, an original example matching the first sequence number. An explicit IV is read as given; do not claim every case must derive it automatically from sequence. IV is not key bytes, duration, rate or hash, and writing it decrypts nothing. Perform no AES operation or encrypted-file validation here: check length and scope only. Missing actual keys do not prevent the text task and require no searching or guessing.

## Remove the preload tag without changing media state

Delete only SESSION-KEY in a master copy and leave media unchanged. seg42 and seg43 remain AES-128 and NONE. The change removes an early metadata opportunity, not encryption. Conversely, retaining the master tag while deleting media KEY does not supply its missing segment scope and changes this sample’s media declarations. Use owned text copies only, without altering production access. Existing playback plus this paper control establishes neither actual request counts nor guaranteed startup improvements.

## Audit forbidden NONE and duplicate session tuples

SESSION-KEY forbids METHOD=NONE. Media KEY may use NONE, but that line must contain no other attributes such as URI or IV. Duplicating the master session entry exactly repeats the METHOD, URI, IV, KEYFORMAT and KEYFORMATVERSIONS tuple, forbidden in a master. Detect these in text without expecting a fixed player error. Real failure still needs separate playlist, authorized-resource and decoding evidence; one successful path certifies no other method or protection system. Preserve one-factor faults and never call a field repair key acquisition or authorization.
