把书屿笔记、高亮和阅读统计导出为 Markdown 或 CSV，完成目标保存与内容核对，并区分可读资料留档与完整恢复备份。

读书笔记值得以应用之外也能打开的形式保存。书屿的数据导出可以把统计、笔记和高亮整理成 Markdown 或 CSV。本文从一条测试笔记开始，完成导出、保存、重新打开和内容核对，避免只点了分享却没有真正留下文件。

## 明确你要保存哪一种资料

先决定这次导出的是阅读统计、笔记还是高亮。笔记通常包含自己的评论与选中文字，高亮主要保存标记过的原文，统计记录阅读投入；它们用途不同，不必为了“完整”每次都生成一堆重复文件。先选一类验证成功，再建立定期保存习惯。

准备一条内容明确的测试笔记，例如在练习书第二章写下“导出检查，保留原文和我的说明”。记录书名与章节，确保之后能在输出文件中找到。电子书正文与阅读资料是两类内容：导出笔记不会自动把整本 EPUB、PDF 或音频文件一起打包。

## 从设置选择类型与格式

进入「设置」→「数据导出」，查看当前提供的类型与格式组合。想直接阅读、编辑文字，可以先选笔记的 Markdown；想在表格中排序或汇总，选择 CSV。界面可能把类型和格式合并成一项，例如“笔记 Markdown”，按实际选项操作即可。

选择后等待文件生成，再进入系统分享面板。不要急着退出 App，尤其在笔记数量很多时，生成过程可能需要时间。若出现失败提示，先保留错误信息并确认设备空间，再用较简单的数据类型验证；连续重复点击可能只会生成多份同名结果，不能代替排查。

## 明确选定保存位置

在系统分享面板中选择「存储到文件」或你实际使用的目标，建立清楚的文件夹，例如“阅读资料/2026-10”。文件名可包含日期、类型和范围，像“2026-10-23-笔记.md”。若系统目标已有同名文件，先决定是否保留历史版本，避免无意覆盖上周的资料。

点击最终保存后，打开系统「文件」App 找到输出文件。只有能在目标位置看到并重新打开，才算完成保存。分享面板出现、文件预览打开、甚至选中了文件夹，都可能还差最后的确认动作；第一次一定走完这个闭环，之后就更容易判断每次是否成功。

## 用 Markdown 核对内容与出处

打开 Markdown 文件，搜索测试笔记里的独特短语。检查是否有书名、章节、选中文字和自己的说明，并与书屿内原记录比较。Markdown 是可读文本格式，显示样式取决于打开它的工具，看到井号或列表符号不一定是错误，也不代表内容损坏。

再抽查一条包含标点、换行或较长原文的笔记，看是否保持可理解的顺序。导出是为了让资料能离开原界面继续使用，核对重点应是文字与来源，而不是要求外部工具显示和 App 完全相同的卡片样式。需要漂亮分享图时，可使用书摘卡片的独立流程。

## 用 CSV 做表格前先检查列

选择 CSV 时，用支持该格式的表格工具打开，先看列名与中文是否正常，再检查一条记录是否落在正确列中。笔记里可能包含逗号、引号或换行，不能只按肉眼看到的逗号数判断列数。导入工具的字符编码和分隔设置不正确，会造成看似乱码或整行挤在一格的问题。

统计导出可能包含今日、本周或月度等不同范围。做比较时先确认范围和单位，例如时长是否以秒表示，再计算或作图。不要把某一行累计值与单日值直接比较，也不要在还没有保留原始 CSV 时就大量修改数据，留一份原输出更方便复查。

## 把导出和备份分开安排

Markdown 与 CSV 便于阅读、检索和二次整理，能作为独立文件长期留档，但不能一键恢复整套书屿状态。它们不自动包含所有原书文件、封面缓存、远程账号和设置。需要迁移设备时，应另外准备电子书来源，并按同步功能的范围处理阅读数据。

可建立一个轻量节奏：每读完一本重要的书导出笔记，每月底保存一次统计，原书继续按自己的文件备份方式管理。保留日期版本，能帮助你找回误删或误改之前的文字；实时同步常常会传播最新变化，不能替代所有历史留档需求。

## 常见问题

**为什么导出的笔记文件很小？** 文字记录本来可能很小，文件大小不能代表笔记是否齐全。用测试短语、书名和记录数量抽查，比只看几 KB 更可靠。高亮与笔记是不同导出类型，也要确认没有选错。

**保存后为什么别的设备还看不到？** 可能保存到了本机位置，而不是你预期的云端文件夹；也可能外部文件服务尚未上传。先确认目标路径与文件服务状态，这与书屿的 WebDAV 阅读数据同步是两条不同流程。

**可以把 CSV 再导回书屿恢复所有进度吗？** CSV 是便于查看和整理的导出资料，不是书屿数据库的替代文件，也没有因此获得一键恢复全部记录的能力。需要恢复或迁移时，应使用实际支持的同步和导入方式，不要把可编辑表格误当成应用数据库备份。
