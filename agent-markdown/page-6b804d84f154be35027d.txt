Learning path · 40 tutorials

Start with a canvas, brushes and layers. Practise leaves, flowers, still life and landscapes, then learn PNG, JPEG, PSD and native-project saving.

[Start with the first tutorial](<https://allluckly.cn/en/guides/aquarell-getting-started/>)[About Aquarell](<https://allluckly.cn/en/apps/aquarell/>)

New to Aquarell? Begin with the basics, then choose a small drawing exercise. If you already have a piece, jump to export or troubleshooting.

The sizes, colours and settings in these exercises help you compare results; they are not the only correct choices. Keep a separate practice project and use each tutorial’s checks to review your result.
