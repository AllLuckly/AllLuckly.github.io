## Prepare a reversible baseline

Open an ordinary note on your own iPhone or iPad and copy a non-private sample such as “青山 ABC 12。” into a practice draft. Record the current system text-size slider position, Jianlai theme and font or size if visible, and host body-text display. Mark unknown values pending. Apple says system text size affects apps supporting Dynamic Type; it does not promise every interface or third-party keyboard follows it. Preserve the original settings and keyboard selection.

## Inspect three regions at the original setting

Select Jianlai in the same ordinary field and observe key labels, any actually displayed candidate region and host body text. Type the sample, inspect the committed text and preserve the original line. Record readability, clipping and absent regions separately; a scheme with no candidate region is not evidence of small text. The listing describes customizable font appearance, but does not guarantee the system slider controls keys or candidates. These are personal visual observations, not pixel measurements or accessibility certification.

## Change only the system text size

If you choose to compare, open the actual system text-size setting and move the slider from its original position to another usable position. Do not also change bold text, display zoom, theme or Jianlai font. Apple says supported apps respond to Dynamic Type; menu names vary by OS. Record the slider positions rather than inventing exact point sizes. If the device also shows a per-app text-size control, record whether the host already has an individual setting; do not change it and the global slider simultaneously. Distinct scopes can affect the comparison. If the current scope is unclear, mark it pending rather than asserting a global effect. If a management policy prevents changes or you prefer not to change it, mark the trial unperformed without bypassing restrictions.

## Return to the same host and observe

Return to the practice note and confirm the same app, Jianlai theme and input scheme. If focus was lost, select the practice line and record doing so. Inspect keys, candidates and existing body text separately, then type the same sentence on another line. Record actual changes: only body text, part of the interface, no obvious change or another result are all possible. Do not assume Jianlai follows system text size. Mark obscured regions uncomparable and do not mistake scroll position for text scaling.

## Compare the original and adjusted text

Check Chinese characters, Latin letters, digits, spaces and punctuation in both original lines, recording character equality separately from visual size. A size change does not establish changed content, and identical text does not prove every label is legible. Preserve first results and correct only a copy. Do not infer font points or touch-target size from screenshot zoom, device resolution or finger width; record what you actually observe.

## Restore the baseline before an app-font comparison

If you also want to test Jianlai’s own font or size, first restore the original system text size. Change one real, reversible Jianlai font or size option, return to the same host and observe. If none can be identified, record not found. A public appearance feature does not promise the same control in every version, layout or scheme. Compare this run with the original baseline rather than attributing a result after changing system and app settings together.

## Troubleshoot system, host and keyboard separately

If Settings changes but host text does not, check whether the host supports Dynamic Type and whether its document has its own text size. If body text changes but keys do not, record that result rather than automatically declaring an app defect. For an absent keyboard, inspect focus and active input method; for absent candidates, check whether the current scheme produces them. If larger text makes controls hard to use, restore a usable original setting. Change one condition per trial and keep actual feedback.

## Restore settings and deliver the comparison

Restore system text size, Jianlai font or theme and usual keyboard from your initial notes, then verify the note, two original lines and backup remain. Deliver initial and adjusted system settings, observations for the three regions, character comparison and unperformed parts. List any separate Jianlai font trial independently. Avoid personal text or account data in shared records. These observations cannot be generalized to every device; no physical, medical or assistive-technology compatibility test is claimed.
