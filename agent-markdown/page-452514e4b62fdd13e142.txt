## 先固定字样、字体与同一原片

选择至少十二秒的自有静景短片，保留原视频与既有字幕，练习另存副本。正文固定四个ASCII字母ABCD，不插入空格，因为空格本身会另改文字。样式表用Arial作可读字体示例，若当前路径回退或没有它，先记录实际字体条件，只有外部可确认的同一字体才能作为后续可比基线；不保证设备装有特定字体。脚本画布固定640乘360，字号36，缩放初值100。播放器适应方式、方向与速度先保持，不靠改视频宽高制造字幕变宽，原有观看设置也留好恢复依据。

## 把三段条件与时间范围先排清

第一条一至三秒为fsp零与横向100，第二条四至六秒只把fsp改为4，第三条七至九秒回fsp零并把横向比例改为150。三条都定位在120、140，同一字号、纵向比例、文字、描边与阴影，区间之间各有一秒空档。第三条是对基线另一种因素的独立对照，不应说从第二条起只改了一个值；比较时分别与第一条相对。先把时间与参数表保存，确认片长覆盖九秒之后，再制作文件，不把三条都放同一时刻叠在一起以为可更快比较。

## 保存包含样式与三条事件的完整ASS

将下方全文保存为UTF-8纯文本spacing-scale.ass，包含Script Info、V4+ Styles与Events，不仅复制三行Dialogue。重开文本确认扩展名不是ass.txt，Format列与Style、Dialogue位置对应；ABCD位于覆盖块之外，反斜线、括号和逗号保持ASCII。这里所有编辑在外部完成，不让云映承担字幕编写。源码中的fsp4不是四秒时长，fscx150也不是画面宽150像素。若已有其他字幕工作稿，应另存而非覆盖，随后在关联记录写明文件名、源稿位置与本轮修改，避免实际打开旧副本后误判参数不起作用。

## 区分字间脚本单位与百分比缩放

Aegisub将fsp解释为字母间距，单位为脚本分辨率像素，可以负值或小数；横向fscx以百分比改变文字形状，100为原比例。二者都可能让整行看起来更宽，却不是同一种处理：增加字距不等于把每个字形横向拉伸，比例变化也不能直接说每一对字母间固定增加4。字号保持36也不表示fscx没有作用，因为字号与横向缩放分属不同参数。实际字形、字距与行边界还受字体和排版条件影响，本课不提供整行宽度的通用字体公式，不由脚本数值填设备截图的测量栏。

## 用四参考点模型解释差别而不代替渲染

外部另定义四个参考点横坐标0、20、40、60，原来三个间隔各20。若只给每个间隔增加4，得到0、24、48、72，总跨度从60到72；若将全部横坐标乘1.5，得到0、30、60、90。它们只是本课独立声明的几何示意，不是ABCD真实字形的advance、字偶距或ASS渲染器必用的四点。四点之间只有三个间隔，不能误加四次。可以由此理解间隔加法与整体比例乘法不同，但不能用72或90去给手机字幕宽度打勾。保留参照轴与单位，原始模型没有随字体回退自动变成测量报告。

```
Declared paper points, NOT font metrics:
base x:     0 20 40 60
gaps +4:    0 24 48 72
scale x1.5: 0 30 60 90
gaps -2:    0 18 36 54
```

## 在云映分段核身份与真实外观

按安装版真实支持的字幕路径，将完整文件关联到对应原片，先核第一段ABCD能读、时刻与文件身份正确，再在第二、第三段内部观察。分别记字母之间空隙、单字轮廓与整行范围是否出现可辨变化，不只填写宽了。显示覆盖、字幕大小或字体若无法固定，要写进条件而不假装三轮完全相同。外部编辑器预览可作另外一份记录，不能代云映填通过。若没有关联入口或尚未实际观看，保留源码和纸面核验，渲染栏明确待核，不编造隐藏的字幕样式面板。

## 只改第二条字距作负值反例

另存counter-spacing.ass，仅把第二条fsp4改为fsp-2，其他事件、字体与比例均不改。纸面四点若每间隔由20变18，会得到0、18、36、54；这个反例说明负字距与负播放时间无关，也不要求实际字母一定重叠。重载副本后只在四至六秒比较真实现象，原三条件稿保持。若毫无差别，先核当前文件、反斜线和参数范围，再查路径是否解析，不同时改字号逼出宽度变化。文字出现原始标签时先排格式问题，不能把未解析文本当缩放算法错误。

## 交付参数账、纸面值与实际范围

保存完整ASS、三段条件、四点模型、负值副本与实际观察，重开原片时重新确认所选文件，只将真正看到的区间记通过。能够解释fsp的加法间距与fscx百分比的区别，指出为什么字号不变也可能横向变化，并明确哪些数值不是屏幕测量。对照照片若另存，写上原片时刻、字幕文件名与观看方向；第一段缺失的轮次不能仅凭后两段比较补签基线。有自动换行时，先确认四字仍在同一行，不能把换行后的包围范围与原来的单行跨度直接相减，必要时另立一次显示条件重新做三段。结束后恢复自己的原字幕与日常显示，不改视频编码或原音轨。未执行的反例、重开与播放分别留待核，不声称云映新增排字、字体几何分析或字幕编辑功能，也不从一种字体的单次结果推断所有脚本与输出设备都一致。
