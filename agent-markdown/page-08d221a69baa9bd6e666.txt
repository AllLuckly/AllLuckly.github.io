Plot three hypothetical changes on a shared zero line and check signs, direction and proportional lengths.

## Define the changes

Suppose three items changed by -4, +6 and 0 units from their own prior periods. These fictional values are for the exercise and do not represent actual statistics; a change is not the resulting total. The UK Office for National Statistics says bars using filled areas extending from an axis should start at zero. This chart places zero in the middle, with negative changes to the left and positive changes to the right.

## Choose range and scale

Use a horizontal range from -10 to +10, for example 30 canvas units per item, giving 300 units on each side. This is an exercise scale and can be resized uniformly, but both sides must use the same scale. The -4 bar is therefore 120 units long and the +6 bar is 180, a 2:3 length ratio. Record these calculations before drawing instead of estimating both lengths by eye.

## Create canvas and objects

Create a landscape VectorPaint document, for example 1600 by 1000 pixels, and save an editable original. Use the object controls visible in the installed version to separate axis, ticks, three bar rows, category labels and value labels. Reserve space for a title and unit. If a grouping method is unavailable, use the object controls that actually exist rather than assuming a particular button.

## Draw a shared zero line

Draw a vertical zero baseline and label it 0 underneath. Place -10, -5, +5 and +10 at equal intervals left and right. Check that the distances from 0 to -5 and 0 to +5 match. The zero line should extend through all three rows so each bar’s starting point is comparable; do not give rows different origins even if their ends look aligned. Optional gridlines should be lighter than the bars.

## Place categories in three rows

Reserve a label area beyond the negative scale and place A, B and C in equal-height rows. Leave enough room that a negative bar cannot cover the category text. Bars should have equal thickness and follow the same category order as the source notes. Do not make the largest value thicker, which would add visual emphasis beyond its length.

## Draw the negative and positive bars

Draw A from zero 120 units left for -4 and B from zero 180 units right for +6. Both share the zero line as an endpoint. Their rectangles start at different left edges, but the negative bar’s geometric width is still positive. Check that the free ends align with -4 and +6 and that the lengths 120:180 reduce to 2:3.

## Represent zero without inventing length

C has a change of 0, so do not draw a visible-length bar: any positive length would imply a nonzero change. Put “0 units” next to the zero line in that row. If a small marker helps locate it, explain that it marks zero and must not look like a short bar. Zero differs from missing: this example explicitly has a zero observation; absent data should be labeled “No data” instead.

## Add signed value labels

Place -4 units outside the left end of A and +6 units outside the right end of B, aligned to their rows. Keep the minus sign clear of the bar and edge; retaining the plus sign reinforces direction. Place C’s zero near the baseline without overlapping its axis label. All numbers should be readable as text, not dependent on color. If space is tight, increase margins rather than altering the data scale.

## Check direction and proportion

Compare each row against the source table: A ends left of zero, B right of zero and C remains at zero. B should be 1.5 times A’s length. Temporarily hide ticks and labels to inspect the shared origin, then restore them to check correspondence. If using real changes instead of the example, recalculate every bar and retain the period and unit; do not reuse the fictional-data note.

## Check color and title

Different hues may distinguish negative from positive, but direction, signs and row labels must carry the meaning independently and remain readable in monochrome. A suitable title is “Changes from the previous period for three items (hypothetical data),” with units specified. Do not call it a total comparison: final totals cannot be inferred from this graphic. At publication size check the minus sign, zero value and baseline.

## Check bar-end alignment

On a working copy, add temporary one-unit ticks and verify that A’s left end meets -4, B’s right end meets +6 and their other ends touch zero. Hide fills temporarily and show only outlines to reveal small gaps or overlaps at the baseline. Inspect each rectangle’s geometric width rather than treating label spacing as bar length; whitespace around labels is not data. Restore the normal style and compare lengths again at thumbnail size. If a length is wrong, fix the rectangle first, then reposition its text so the label does not conceal a misleading shape.

## Troubleshoot and export

If the negative value appears too long, verify both scales and rectangle lengths instead of adjusting labels alone. If C appears positive, remove any decoration mistaken for a bar. Save the editable original, then use the available export control to save a separate SVG or PNG. Reopen it and inspect ticks, title, minus sign and bars for cropping. Return to the original and verify editable objects; mark device steps not actually performed as pending.

## Recheck the zero row

Zoom into C’s row and confirm the “0 units” label is unobscured and no bar length implies a positive or negative change. Supply all three example values alongside the chart so readers can check direction and length.
