## 保留一个原稿与两条不同处理支路

选择自己的短录音并确认原FLAC能正常解码，保留原件与来源工程。建立tag-copy与half-copy两个工作副本，前者只用于元数据操作，后者用于真正改变样本幅度，两支不串做，否则无法解释差别。录音应有可辨开头与适中峰值，不需要高音量或测试满幅。原歌名与外部代号分开记，避免后来只凭文件名推断处理。尚未生成副本时先交计划，不把本文的三行名称当实际音频下载；没有可靠外部工具就保持原件，并将对应处理明确留待做。

## 读清ReplayGain写入的是增益元数据

Xiph的metaflac官方文档说明add-replay-gain先计算音轨与专辑增益峰值，再将结果存为FLAC标签；它不是让本课把任意数字冒充扫描结果。若使用已有工具，按其真实说明只对tag-copy运行并保存实际输出，注意原有相关标签可能被替换，原件不参与。对没有此工具的用户，可先读取一份自己合法取得且有报告的工作副本，未确认字段就写未知。扫描结果、标签文本和播放器是否使用是三种状态；官方列出FLAC可导入并不自动承诺调调实现全部ReplayGain解释。

## 外部核标签支路是否保留解码样本

在外部先比较原稿与tag-copy的实际解码音频资料，核采样率、声道、帧数以及有条件时完整PCM内容。进行样本比较时也先固定解码输出格式。文件整包哈希可能因标签改变而不同，这与解码样本是否相同不是同一比较；不要只看文件大小没变就填音频一致。只有可靠比较已经执行，才保存样本相同的结论；没有工具就只确认元数据操作范围并标样本待核。也不要把FLAC内部校验字段当作任何编辑后的全文件安全认证。这个支路的目的在于建立标签变化和音频变化可独立讨论的证据，而非预先给调调填某个音量结果。

## 将另一支样本乘半并保留明确数值模型

对half-copy通过外部音频工具真正降低幅度，本文纸面约定每个归一样本y为原样本x乘0.5，例如0.6变0.3、−0.4变−0.2、零仍零。若实际工具只接受分贝，先按它的说明换算和记录真实数值，不把整数减六当成精确乘半的数学等号。导出时保持原采样率、声道与区间，并避免再写入未核的增益标签影响比较。真实整数格式还会有舍入，纸面示例不是保证每个字节精确一半。保留实际处理与导出报告，不把播放器音量滑块降低叫源样本已改。

```
PAPER SAMPLE MODEL ONLY: y = 0.5*x
x:  0.6   -0.4   0
y:  0.3   -0.2   0
metadata-only branch: inspect actual tags and decoded PCM separately
baked-gain branch: inspect actual changed samples and export conditions
No player ReplayGain application is presumed.
```

## 导入时将去重结果与标签支持分离

将准备好的可读工作副本按真实导入入口处理，每份记新增、去重或失败反馈。只改标签的副本可能遇到内容去重，公开说明没有公布判定算法，不能由这一结果反推到底比较文件哈希还是解码音频。若库中无法独立辨认tag-copy，就不要拿原稿充当它继续听音；该支路标播放器比较未建立。half-copy也要核真实声音与来源，文件名不同不能代替身份。处理记录可留在外部，不为了强迫出现三行而反复转码、改名或更换录音，那会破坏同源控制关系。

## 固定输出和音量只记录可辨的实际听感

只有来源能独立辨认时，在同一输出、正常速度与同一舒适音量设置下分别播放相同声音区间。每轮先核标题与锚点，再记实际是否能辨认响度差别；不要边听边分别调音量追求一样响。tag-copy相似不证明标签未被读取，变小也不单独证明ReplayGain已启用，输出链或其他处理仍可能参与。half-copy外部样本确有降低，也不保证所有场景主观响度恰减半。本课没有精密响度计，不填写LUFS、峰值或扬声器声压测量通过；无法分辨也是范围明确的记录。

## 按处理支路与文件身份排查混淆

三份都一样先查是否实际点到同一库条目、tag-copy是否去重、half-copy是否只改了文件名或只导出未处理区间。差别过大则回外部处理报告核额外归一化、标签或错误源段，不靠不断调系统音量把结果修成想象。每次只查一支一项，保留原稿与首次反馈。标签值不明就记录原文本与工具来源，不自行补齐一套看似专业的字段。即使外部样本比较通过，也只对那次文件资料成立，不能把手机整条输出链记为bit-perfect，更不能根据一种格式推出所有音乐服务自动统一响度。

## 交付三层证据并保留未承诺功能边界

最后分交元数据处理与字段、外部解码样本比较、调调可辨播放观察三层记录，并附half-copy处理模型与真实工具结果的差异。能说明整包字节变化、音频样本变化和实际响度不是同一问题，哪一支未建立就明确留待核。结束时恢复日常播放音量，原录音和工程保持，临时副本不覆盖唯一原件。本文不指示寻找未公布的ReplayGain开关，不宣称内置扫描、音频编辑或响度标准认证。今后换工具、标签或输出路径重新核，不能把一次小样本扩成播放器对全部增益元数据的完整支持结论。
