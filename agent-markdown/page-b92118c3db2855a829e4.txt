## Separate the published condition from an import result

The public 调调 listing states a maximum of 512 MB per file; supported formats also require system-readable audio and no DRM. A single-file limit and a batch total are different questions. A total above 512 MB does not by itself mean each file exceeds the limit, and choosing one oversized file does not make it smaller. The listing does not specify all boundary rounding and error behavior, so do not promise success or failure for a display rounded to exactly 512 MB.

## Establish a paper comparison

Suppose three owned recordings A, B and C are 200 MB each and D is 600 MB. These are exercise values, not measurements. Each of A–C is below 512 and their total is 600; D alone is above 512. The calculation addresses only the published per-file size condition, not format, rights, system decoding, storage or transfer outcome. All example figures use the same unit; clarify actual units before adding them. Under the standard unit definitions, 200 MB is 200,000,000 bytes whereas 200 MiB is 209,715,200 bytes; do not silently add the labels as identical units. The store does not detail its conversion or rounding rule for 512 MB, so this illustration does not prove the app’s internal boundary implementation. Leave near-boundary cases unknown. Use the actual values displayed by your file tool.

## Prepare a real file ledger

Inspect your authorized recordings in the computer or file provider and record name, source, displayed size and unit for each. Preserve originals; do not rename an extension or truncate a file to make it appear smaller. Prefer small, clearly formatted files well below the limit that can already play independently. Three small files are enough; there is no need to manufacture or upload an oversized file. Preserve rounded displays and avoid a precise boundary conclusion when units are unclear.

## Check each item and the selection total

Compare each file individually with the published limit, then calculate a batch total only for compatible units and known values. Total size helps estimate transfer and device storage, but the per-file listing is not a complete batch-capacity specification. Mark files clearly below, clearly above, or near the boundary or unclear in units. Do not pass near-boundary, unreadable or uncertain cases on arithmetic alone. Exclude unauthorized or protected tracks.

## Import a real small batch

Use the system file provider or the same-Wi-Fi browser transfer flow actually available in 调调. Verify selected path and file identity, then submit your prepared small batch. Follow controls actually shown; do not assume identical batch selection or errors for both paths. Record selected files, import feedback and duplicates skipped. Do not present the hypothetical 200 MB files as actual uploads or deliberately send an oversized file merely to prove the limit.

## Verify each library item and actual playback

After import, find each item in the 调调 library and inspect title, duration and a short audible segment. Record selected count, interface feedback and actual playable items. The public description says duplicate content can be skipped, so a lower count is not automatically a size failure. Size is only one precondition; it does not prove format, audio-track readability, rights or successful import. Keep the ledger and actual feedback for any missing item.

## Troubleshoot size, format and device space separately

For a file clearly above the published per-file limit, use another suitable owned file or handle the original within your rights; renaming an extension does not evade the limit. When a clearly smaller file still fails, check format, system readability, DRM, available space, network and the actual error, changing one condition per retry. A batch total over 512 MB does not prove every item must fail, and compliant individual sizes do not prove sufficient device storage. Preserve unknown errors and mark uncertain causes pending.

## Deliver the paper model and real observations

Keep separate records for the four paper values and the real files’ displayed size, unit, selection, feedback and playback. The A–C total of 600 MB is hypothetical; actual counts and sizes come from your own files. Retain originals and desired imported results, and close a transfer session you no longer use without deleting unrelated content. Behavior can change by app version, OS and provider.
