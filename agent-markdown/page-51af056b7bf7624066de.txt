用三条相同文字比较line设置，分别记录规范条件、实际位置与可读性。

字幕的 line:1 不是第一秒，也不是距屏幕顶部一个像素。本课使用同一段短片和三条原创字幕，比较整数行位置与百分比位置，避免把数字相同当成单位相同。文件在电脑准备，云映只使用安装版本已有的字幕选择和播放入口；最终保存的是源码到屏幕的条件记录，不声称应用提供行位置数值编辑器。

## 一、固定短片与显示参照区域

选择至少十四秒、没有烧录相同字幕的自有短片，先顺播确认画面与声音可用。记录文件身份、来源、时长和设备方向，说明观察参照是可见视频区域，不把整块屏幕与含黑边的区域默认混用。电脑用纯文本编辑器保存 UTF-8 字幕，另留无位置参数的备用版。加载入口不存在时先完成文件审核，播放栏明确写未执行；不能从文件保存成功推断已显示。开始前把字幕字号和画面显示方式固定，不同时改变方向、缩放与来源，让后面的位置比较有共同条件。

## 二、保存三个单项条件不同的条目

下方三条文字与时长相同，时间互不重叠。前两条的 line 是整数，第三条带百分号；先完整复制，再逐行核箭头、空格、百分号与空行。不要把第三条的百分号删掉以求整齐，那会改变被检验条件。文件扩展名真正保存为 .vtt，不是富文本或双后缀。建议在笔记先抄三条参数，再写三条预期可读文字都相同，外观栏暂空。示例没有纵排设置，本课不将水平视频中的观察直接推广为所有字幕书写方向的结论。

```
WEBVTT

00:00:01.000 --> 00:00:04.000 line:0
Keep this line separate.

00:00:05.000 --> 00:00:08.000 line:1
Keep this line separate.

00:00:09.000 --> 00:00:12.000 line:90%
Keep this line separate.
```

## 三、先认单位再画位置示意

参考[W3C WebVTT 行位置设置](<https://www.w3.org/TR/webvtt1/>)，整数与百分比属于不同的行定位条件，不能把它们当同一像素坐标。给纸面视频框画三幅相对位置示意，并在旁边保留参数原值；图是帮助理解条件，不是设备截图或精确测量。不要把 line:1 写成视频第一秒，因为出现时间仍由时间行决定，也不要把90%说成这句话只显示九成。实际布局还受文字、显示环境与实现处理影响，规范预期与播放器观察必须分栏。当前样本没有形成精确位置测量，不据草图承诺每台设备逐像素相同。

## 四、顺播三条并逐项核文字

加载配对字幕，从零秒顺播到十二秒后。每条先读全句，再记录大致位置、可见行数与是否有裁切，不只填写正常。第一与第二条之间尽量保持控制栏显示状态一致，避免临时菜单遮住画面时误记位置。看不清可以重看同一段，但先不改源码。若某条根本未出现，记下时间与文件身份，先按加载和时间问题排查，而不是把空白当作成功定位到屏幕外。实际文字完整与位置参数生效是两项不同检查，前者通过不能代替后者。

## 五、把没有差异与单位误读分开

如果三条看起来位置相近，就记录当前条件未观察到明显差异，不倒过来删掉参数后宣称规范没有这些设置。若整数两条有相对移动，仍只描述观察到的方向，不凭眼睛估算它恰好移动了多少像素。第三条与前两条比较时保留百分号及相同句子，不能因为结果不符合纸面图就缩短文字来迎合。可另外用普通备用字幕确认基本可读路径，但这属于回退对照，不是证明所有布局兼容。一个没有显示差异的有效记录，比为了凑预期而不断换设置更方便以后复查。

## 六、改变字号时另开一轮记录

若安装版本确有字幕字号入口，原样记录选项和值，再只改这一项重新顺播。没有该入口时不编造按钮，可以保留第一轮结果等待别的显示环境。新的文字行高可能影响可见排布，因此两轮不能只凭同一个 line 数字就叫同一像素位置；但文件的出现时间与正文仍没有被这一步修改。每轮保留设备方向和画面模式，注明改变的唯一条件。最后恢复自己原来的设置并核备用版仍可读，不让练习永久改变日常观看配置却没有记录。

## 七、排查参数位置与旧字幕轨道

参数文字出现在正文时，先检查它是否误放到下一行；它应与时间区间在同一行，位于结束时间后。若更换文件后结果不变，先核字幕选择的实际身份，不把相同句子外观当作必定加载了新文件。必要时退出播放页再选择副本，从条目前顺播。只有部分文字不见时检查编码、字体和原文，不用随意加减 line 值掩盖缺字。每次修一个发现的问题，保留前后文件，不清空媒体库来代替定位；仍不清楚的兼容行为写待核，不声称真机全部通过。

## 八、完成源码到画面的对应记录

最终保存短片与字幕身份、三条原参数、实际句子、位置与行数、显示条件和未确认事项。退出再返回，同样从零秒重看，核对没有将百分比改成整数或将行号写成时间。用普通字幕版再播放一次确认回退可用，原影片和原字幕仍保留。验收是别人能够在同样条件下重做比较，并看出哪些是定义、哪些是观察，而不是一张截图证明全部 WebVTT 布局都兼容。以后换来源或方向，新增一轮记录，不覆盖这次结果。
