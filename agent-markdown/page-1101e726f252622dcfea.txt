After entering a meeting outline with Jianlai, supported versions of Apple Notes can style section headings and collapse the content beneath them. The keyboard enters text; heading styles and collapsing are Notes features. Controls may differ by system version and account type. Collapsing is one observation of visible state, not an automatic backup or a substitute for keeping the original. If heading controls are absent or a style affects an entire section unexpectedly, stop and check the selection and host instructions. This exercise keeps a three-section baseline before checking whether collapsed content can be recovered.

## Prepare a test note

Create a blank note in Notes on iPhone. Confirm Jianlai is enabled in system settings and select an actually visible Chinese or English input mode. Do not use real meeting minutes, personal data or unbacked-up content. Record device, system, Notes account and keyboard layout. If the note is not editable, choose a new editable note instead of altering restricted content. Apple says the first line becomes the note's title, so keep the practice title separate from the sections below.

## Enter three sections with Jianlai

Enter “Practice outline” on the first line, then enter “Prepare”, “Check equipment”, “Execute”, “Record time”, “Finish” and “Save result”, each on its own line. This is fictional practice, not an instruction for real work. Check actual line breaks, words and order after entry; automatic visual wrapping is not a new paragraph. If a candidate or autocorrection changes the text, correct the committed text first. An unconfirmed candidate is not saved content.

## Copy a baseline

Before formatting, use the system's actual selection and copy controls to copy all seven lines to a second test note, then verify the copy contains all the content. If you do not want to use the clipboard, keep a screenshot or handwritten record without private data, but a screenshot is not an editable copy. Neither note should contain sensitive information; do not overwrite an existing note. Inspect all visible lines in the copy instead of assuming the title proves a complete copy. If fewer than seven lines were copied, repair the baseline before changing heading styles. The baseline helps verify content after collapsing; it does not prove account synchronization or backup reliability.

## Style the first section heading

Return to the first note and select only “Prepare”, not “Check equipment”. Use the formatting control offered by Notes to choose Heading or a comparable heading style. If the option is missing, the account does not support it or the system differs, record incomplete and stop the formatting comparison. This is host styling, not Jianlai keycap typography. Confirm the heading still contains the same word and the following line was not accidentally replaced.

## Style the other two peer headings

Similarly give “Execute” and “Finish” the same heading level. Before each change check the selection; alter only the target line and then inspect adjacent text. If the host offers multiple heading and subheading levels, record the actual choice rather than assuming every system groups sections identically. Afterwards verify all three descriptions remain under their intended headings and were neither accidentally styled as headings nor deleted.

## Observe collapse and expansion

If the current Notes interface provides a collapse control by the heading, use the visible control to collapse “Execute”. Observe whether “Record time” is temporarily hidden and check the “Prepare” and “Finish” sections. Expand “Execute” again and check that the original text reappears. Hidden text is not necessarily deleted. If the control is absent or unavailable, mark not tested instead of repeatedly toggling settings or assuming every version supports it. Record the actual screen and outcome, not an expected result.

## Edit the body while expanded

With “Execute” expanded, use Jianlai to add “ and place” at the end of “Record time”, then check the resulting line reads “Record time and place”. Verify the preceding heading remains “Execute” and the next heading remains “Finish”, so the change did not land in another section. If cursor location is unclear, cancel and place it again; do not type blindly into a collapsed section and guess where the text went. Keep the unmodified baseline for a concrete comparison.

## Collapse again and check the content

Where the control is available, collapse and expand “Execute” once more and verify the revised body can be found. Compare with the baseline: the only intended text change is “ and place”. Heading styling may alter appearance, but should not be described as a character change. If text differs from expectation, inspect selection and cursor position first and use the host's actual undo or recovery options. Do not assume one undo reverses one character or overwrite the only baseline.

## Record limitations and finish

Record keyboard input, availability of heading styles, collapse and expansion, and whether the body edit remained. State why any step was not tested. Notes formatting depends on system and account; this exercise establishes no causal relationship between Jianlai's theme or input language and collapse availability. Keep or delete the test notes as you prefer and restore the prior keyboard. This guide uses Apple's public instructions and does not claim a step-by-step test on a particular personal device.
