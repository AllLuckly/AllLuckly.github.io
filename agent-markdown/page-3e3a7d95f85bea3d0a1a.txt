用两条自制字幕核对类名是否成为文字，以及同一文字在不同显示条件下的表现。

字幕源码里出现 red，不表示屏幕上一定写着 red，也不表示每个播放器都自动把这一段染红。本课把一个单词相同、类名不同的小样本带入云映，先核文字有没有完整保留，再记录自己实际看到的样式。任务成果是一张包含源码、播放时间、文字和样式观察的对照记录，不需要购买字体，也不需要把现有影片的字幕覆盖掉。

## 一、准备独立副本与文字基线

选一段自己有权使用、至少八秒且画面不依赖字幕才能识别的短片，另存为本课副本。先在云映顺播，确认视频本身能打开、到六秒后仍能播放，再给记录写上片名、来源位置和总时长。使用纯文本编辑器新建 UTF-8 的字幕文件，保留另一个没有任何标记的副本作为回退。这里准备的是外挂字幕文件，不是在云映中编写程序。字幕的加载或选择应使用安装版本已有入口；若没有对应入口，停在文件核对阶段，不能把“创建文件成功”记成“应用显示成功”。先写清这条边界，后面的样式差异才有可比较的起点。

## 二、只改变类名，保留同一句话

在文件中输入下面两条原创内容。第一条把同一个词放在 red 类中，第二条放在 review 类中，外面的句子不变。第二个类名是为练习任意取的分组名称，不是某个云映命令。保存时检查扩展名真正为 .vtt，而不是被编辑器追加 .txt；时间行使用半角箭头，条目之间保留空行。先在纸上写出预期可读文字都是“Check the blue cup.”。不要在预期列填红色、蓝色或粗体，因为本轮尚未给这些样式建立可靠依据。这样同句与不同类名才能形成明确的对照，而不会把内容修改误当成样式变化。

```
WEBVTT

00:00:01.000 --> 00:00:03.000
Check the <c.red>blue cup</c>.

00:00:04.000 --> 00:00:06.000
Check the <c.review>blue cup</c>.
```

## 三、从条目前开始顺播，分别记文字与外观

把字幕与短片配对后，从零秒顺播到第一条结束，先抄实际可见句子，再写有没有看到角括号、类名或者缺失词。继续顺播到第二条，并沿用同一记录顺序。正常速度看不清时可以再次播放这一段，先不要同时改字号、换音轨和更换视频来源。建议把记录分成四列：条目时间、实际文字、文字外观、无法确认之处；外观写“蓝杯这两个词与其余文字同色”比写“类失效”更具体。屏幕可见证据和对原因的解释分开后，另一位读者才能用相同文件重查，而不是只能接受你的结论。

## 四、按规范理解类名，不替播放器保证样式

查阅[W3C WebVTT 规范](<https://www.w3.org/TR/webvtt1/>)的类标记说明：类名承担分组作用，本身不是要给观众阅读的词。规范也列出 red 默认前景色类，而 review 是本例自定义分组；规范预期与播放器实际显示仍须分栏。把这些写进源码说明即可；不要据此替云映承诺网页 CSS、全部默认颜色类或自定义样式规则都能一致执行。若两个条目文字相同而外观也相同，记录结果就是当前条件下没有观察到样式区别。若出现不同颜色，仍只记录当前样本与当前设置，不推广成任意类名都可自动选色。保持 red 与正文中的 blue 同时存在，恰好能防止把正文语义与样式名称混在一起，检查时不能悄悄把 blue 改为 red 来迎合颜色预期。

## 五、制作无标记对照，定位文字损失

另外保存一个只含普通句子的字幕副本，时间区间与原文件完全一致。切换到该副本前记录当前字幕文件名，切换后重新从零秒顺播，确认实际加载的是对照而不是旧字幕仍留在屏幕上。如果普通版完整、类标记版却显示标签或少字，就把差异限定为该标记样本的处理问题，并保留两个原文件供复查。若两版都没有文字，应先检查是否启用了正确字幕、时间是否落在一至六秒内、视频是否选对。不要直接删掉全部标记后覆盖唯一原稿，否则会失去定位差异的依据，也难以知道修复到底改变了什么。

## 六、用另一处短片时间验证，排除画面背景干扰

若文字都存在，但两次观看对颜色的判断不同，先检查条目下方是否有亮暗不同的画面。保留原文件，把同一句安排到短片另一段较平稳的背景上，另存新文件并写清时间变化；不要一边挪时间一边改类名。检查文字边缘是否被背景吞没，比较的是可辨认程度，而不是单凭肉眼估算准确色值。也可以先暂停在条目中间读取完整句子，再恢复顺播确认起止。此步骤只能帮助你发现背景造成的阅读差异，不等于应用提供了颜色取样器，也不构成对显示器色彩准确性的测试。记录时仍须保留“未测色值”这类实际限制。

## 七、问题排查：标签、重复文字与加载混淆

如果屏幕把 c.red 连同括号显示出来，先检查文件中是否为了演示而写成了转义后的文字，或被富文本编辑器插入其他符号。若一句话出现两次，检查视频是否已经烧录同一句字幕、另一条内嵌字幕是否也开启，不能一概归因于类标记。若只有某个词不见，逐字比对开始与结束标记，确认正文确实放在它们之间。更换文件后结果不变时，重新核对选中的字幕身份，必要时退出该播放页后再选择副本；这里是核对文件与显示状态，不是建议反复清空媒体库。每次只修改一个已发现的问题，再保留修改前后的证据。

## 八、完成检查与可复用记录

完成时应保存短片身份、两份有标记及普通文字字幕、每条实际显示的句子、当前可观察样式，以及不能确认的部分。核对两句的词序、标点与时间范围，不把“看起来同色”写成“规范不支持颜色”，也不把“这次显示红色”写成“所有设备必然一致”。下一次换文件来源或换显示设置后，可以沿用相同记录格式复查，但要注明新的观察条件。这样成果是能够复现的一次字幕核对，而不是凭一张截图宣告完整兼容。最后确认原影片与原字幕都未被覆盖，并从普通文字版重新播放一次，确保仍有一份可直接阅读的备用文件。
