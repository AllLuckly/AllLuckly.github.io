用八位SDR灰阶核视频范围、全范围与误读控制，分开码值位置、信号解释和显示亮度。

同一个十六码值，在不同范围约定下含义不同。本课先做两种范围的纸面映射，再用有记录的自有灰阶短片核身份与观看条件；云映只负责播放，不假定存在范围重标记或色彩测量菜单。

## 先把任务限定为八位标准动态范围

准备自己已有的八位SDR灰阶素材、导出记录与外部报告，保留原件，再记编码、位深、范围标记和观察设备。本课只讨论灰阶亮度分量，色度保持中性；不把十位HDR、广色域或所有解码器混进同一数表。没有已知范围的短片时先完成纸面映射，把实际播放对照记待核，不能凭一段看起来灰的影片猜它的原始码值。文件能打开与报告已读是两件事，报告没列范围就写未知，不以扩展名代替标记，也不要求云映读取全部底层像素。

## 两种名义范围按端点分别归一

八位视频范围的名义黑白端点为十六与二百三十五，差为二百一十九；全范围端点为零与二百五十五，差为二百五十五。这里归一只是按端点求信号位置，视频范围用码值减十六再除二百一十九，全范围直接除二百五十五。两式分母不能交换，十六在视频范围恰是名义黑，不是缺少黑色。下面保留五个输入，全部是纸面预期，未声称从真实影片逐像素读出；中性色度取一百二十八也不能拿来当亮度中间点的证明。

```
eight-bit SDR grey; neutral Cb=Cr=128
video position=(code-16)/219; full position=code/255
code: 16, 71, 126, 180, 235
video: 0, 55/219, 110/219, 164/219, 1
full: 16/255, 71/255, 126/255, 180/255, 235/255
code 0 interpreted as video: -16/219
code 255 interpreted as video: 239/219
video nominal endpoints: 219 intervals, 220 inclusive codes
full endpoints: 255 intervals, 256 inclusive codes
```

## 同一码值先核解释再谈灰阶位置

十六按全范围解释约为零点零六二七，二百三十五约为零点九二一六，因此把视频范围误按全范围解释会压缩所用端点区间，可能呈现黑位抬起、白位降低。这个结果说明输入解释不匹配，不证明每段偏灰影片都犯了同一错误。中间的一百二十六码值在两式中也不完全相同，先按账复算。归一数不是线性物理亮度，也不是人眼觉得一半亮的保证；传递函数、显示映射和环境另有作用，不把约零点五写成准确一半尼特。

## 反向误读与超出名义范围分开记

全范围零若按视频范围式算为负十六除二百一十九，二百五十五则为二百三十九除二百一十九，大于一。某条显示链若把这些值限制到零一，暗部或亮部可能合并；是否限制要看实际路径，不能写所有播放器一定同样裁切。超出名义黑白的码值也不自动等于文件损坏，不能为清掉它们覆盖原稿。另核端点差二百一十九与含两端的二百二十个整数码不同，全范围则是二百五十五个间隔、二百五十六个码值，避免计数与归一分母混用。

## 外部做两份对应内容和一个误读控制

在自己已有、可明确导出范围的外部工具中，制作内容相同且正确编码的两份短片，一份视频范围、一份全范围，另留误读示意的副本或纸面图。灰阶布局、时长、字幕身份与输出条件固定，外部报告记录实际结果。两份正确处理的影片可以看起来相近，不能把全范围天然更黑更亮当验收目标。压缩导出可能改变具体像素，报告中的范围标记也不单独证明像素全部合规；没有测量就不填逐像素通过，工具不能控制范围时保留未知，避免仅改文件名冒充完成。

## 云映同一输出先核身份再看两端细节

逐份通过当前可用文件来源打开云映，先核片名、时长和灰阶布局，再固定正常速度、画面适应、亮度与同一输出设备观看。分别描述暗端、亮端相邻块是否可分以及中间变化，不只写好看或难看。若屏幕或投屏路径切换，另开记录，不能把新路径的处理算原片范围改变。片内烧入的数表是制作时说明，不是播放器实时测量；截图也经过显示与保存过程，不能拿截图读数直接认证源视频的十六和二百三十五，实际看到与外部报告并列保存。

## 按标记、像素和显示三层排查

若报告与文件身份不符，先找错副本；若范围标记与实际生成条件不符，回外部工作稿；若同一文件换显示路径才变样，先记路径条件。三者不统一叫云映把灰阶弄坏。一次只修一项，旧控制保留，不先用播放器亮度补偿再宣称范围解释已正确。也不把本课八位端点套到十位或HDR素材，后者另需对应标准与完整色彩流程。缺逐像素证据时缩小结论为当前可见差异，未执行的外部导出、设备测试和色彩校准均不补写成功。

## 重开交付两种映射与实际观察

保存原稿、两份正确副本、误读控制、导出记录和五档算表，重开核仍是相同身份与显示条件。验收能解释十六为何在一种约定下是黑、另一种下高于零，二百一十九为何是差而非含端点码数，并说明正确全范围与视频范围不必有观看优劣。纸面结果、外部像素证据、播放器可见表现分别写清，待核项保留。以后换位深、编码或显示路径重新建账，不把这组数当全站所有影片标准；成果是可复查的素材范围比较，不是新增范围编辑或全设备认证的承诺。
