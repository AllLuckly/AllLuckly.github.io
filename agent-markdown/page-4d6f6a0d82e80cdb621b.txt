## Read every file path in a directory

Use fileManager’s enumeratorAtPath and nextObject() to enumerate.

```
let appMainBundlePath = NSBundle.mainBundle().bundlePath

func filePathesInDir(dirPath:String) -> [String]{
    var filePathes = [String]()
    var fileURL:String


    let fileManager = NSFileManager.defaultManager()
    let enumerator = fileManager.enumeratorAtPath(appMainBundlePath + dirPath)


    while let element = enumerator?.nextObject() as? String{
        if let ext = ext {
                fileURL = appMainBundlePath + dirPath + "/" + element
                filePathes.append(fileURL)

    }

    return filePathes
}
```

## Capsule-shaped Button

The result is shown below:

![1](<https://allluckly.cn/images/blog/tuogao/tougao37/8.png>)

Principle: use the layer’s radius, as shown:

![1](<https://allluckly.cn/images/blog/tuogao/tougao37/9.png>)

Then simply set radius = button height / 2.

![1](<https://allluckly.cn/images/blog/tuogao/tougao37/10.jpg>)

The code is as follows:

```
func makeRadiusBtn(btn:UIButton,borderColor:CGColor){
    let btnH:CGFloat = CGRectGetHeight(btn.bounds)

    btn.layer.borderColor = borderColor
    btn.layer.borderWidth = 1.0
    btn.layer.cornerRadius = btnH / 2
}
```

## Get UIColor from hexadecimal

Since RGB colours online are commonly hexadecimal, supporting that notation in UIColor is useful.

One macro definition meets the requirement.

```
#define UIColorFromRGB(rgbValue) ［UIColor colorWithRed:((float)((rgbValue & 0xFF0000) >> 16))/255.0 green:((float)((rgbValue & 0xFF00) >> 8))/255.0 blue:((float)(rgbValue & 0xFF))/255.0 alpha:1.0] <br>
```

Usage is as follows.

```
self.view.backgroundColor = UIColorFromRGB(0xCECECE);
```

How it works

```
#define UIColorFromRGB(rgbValue) \\\\\\\\\\\\\\\\
[UIColor colorWithRed:((float)((rgbValue & 0xFF0000) >> 16))/255.0 \\\\\\\\\\\\\\\\
                green:((float)((rgbValue & 0x00FF00) >>  8))/255.0 \\\\\\\\\\\\\\\\
                 blue:((float)((rgbValue & 0x0000FF) >>  0))/255.0 \\\\\\\\\\\\\\\\
                alpha:1.0]
```

Apply masks to extract the corresponding RGB digits, then right-shift using ».

For red, for example, 0xCECECE & 0xFF00000 = 0xCE0000. One hexadecimal zero represents four binary zeros, so 0xCE0000 » 16 = 0xCE. Divide by 0xFF (255) to obtain the proportion.

## Set the URL Scheme

For example, I have an app called 25min.

In 25min’s info.plist, add a URL type, set the URL identifier and add URL Schemes. Item 0 under URL Schemes defines the beginning of the URL scheme. ![1](<https://allluckly.cn/images/blog/tuogao/tougao37/11.png>)

Then add the URL Schemes handling method in appDelegate.

```
//return true 则启动app，false则不启动。
    func application(app: UIApplication, openURL url: NSURL, options: [String : AnyObject]) -> Bool {
        return true
    }
```

Now 25min:// opens the 25min app. Test the URL in Safari to check whether it switches apps.
