## Confirm prerequisites

Plex documents that from server version 1.41.0, with the Plex Series or Plex Movie agent, external subtitles can be placed in a subs or subtitles folder alongside video files. For episodes this folder belongs inside the season containing the videos. iCouldPlay publicly supports Plex and subtitles, but that does not guarantee every server result or track-selection control will be visible; check the server first.

## Prepare isolated material

Ask the administrator for an isolated shows library, a self-made or authorized short and a self-made SRT aligned with its opening; keep original video and subtitle backups elsewhere. The subtitle can contain one cue: line one is 1, line two is 00:00:01,000 --\> 00:00:03,000, line three is TEST, followed by a blank line. Use no personal information. Record Plex server version, the agent actually used by the library, video duration and first cue time. If version or agent prerequisites are not met, stop the folder comparison and record why. Record server and client versions separately: an updated iCouldPlay app does not establish that the remote Plex server meets the prerequisite.

## Create the show hierarchy

Under fictional Practice Series (2030) in the test library create Season 01 and name the short copy Practice Series (2030) - s01e01.mp4, using the extension matching its actual format. Follow Plex naming guidance for season and episode identifiers. Record the full relative path and opening picture, check for existing names before copying, and do not move or rename episodes in the real collection. If an older show has the same title, use the test-library name and opening picture to confirm identity before touching any subtitle files.

## Start with a sidecar next to the video

Place the test SRT copy beside the video in Season 01, matching its base name and adding a Plex-supported language suffix, for example Practice Series (2030) - s01e01.en.srt. The language code labels the track; it does not prove the words are correct or guarantee automatic selection. After the administrator scans or refreshes the test item, inspect the episode and server-recognized subtitle information in Plex Web. Record whether the track is selectable and the actual cue. If it already fails there, resolve the test sample or server recognition before moving it.

## Establish an iCouldPlay playback baseline

Connect iCouldPlay to the same Plex server with an account authorized for the test library and open the episode. If the current interface offers subtitle selection, choose the recognizable test track, play to the first cue and record actual words and time; otherwise record that the control or track was not shown. A server-side subtitle file alone does not prove iCouldPlay loaded it, and a language suffix is not an observed caption.

## Move the test copy into Subs

Have the administrator record the sidecar’s name, size and path, create a Subs folder inside Season 01, and move only the test subtitle copy into it, keeping filename, content and video unchanged. Verify that no other identically named test sidecar remains next to the video, otherwise the source read is ambiguous. Do not touch real subtitles; stop if a same-named destination exists rather than overwriting it.

## Refresh and inspect the server

Have the administrator scan or refresh the test item normally and wait, then recheck the subtitle track in Plex Web. Change only the subtitle folder compared with baseline, not its language label, video content or account, so the difference is interpretable. Record the actual language label, visibility and first cue in the short. The folder rule depends on server version and agent; another server or older agent is not a substitute. If unrecognized, check the parent of Subs, extension, file read permission and refresh completion first.

## Verify again in iCouldPlay

Return and reopen the same test episode in iCouldPlay. Using controls visible in the current interface, inspect subtitle tracks and play to the same time, comparing whether the test sentence actually appears. Record selection, picture and Plex Web outcome; server recognition is not client success when the client offers no corresponding track. If several tracks carry the same language label, select each and use the test sentence to identify the target rather than assuming the first label points to it. If two text layers appear, turn selectable subtitles off first and distinguish burned-in text from a selectable track.

## Separate naming from synchronization

A correct subtitle path helps recognition but does not prove it matches a different cut or timeline. If text appears consistently early or late, record known events at the beginning, middle and end. First confirm subtitle and video come from the same test edition, then assess constant offset versus gradual drift. Do not modify real subtitles or repeatedly rename files to hide timing mismatch.

## Restore and keep results

Have the administrator return the test subtitle to its original sidecar location or clean it up by agreement, confirming originals and real episodes remain unchanged. Record server version, agent, relative paths before and after the move, refresh time, web track and actual iCouldPlay playback. Mark unperformed steps. Hide private server addresses, accounts and real media paths when sharing; an isolated experiment is not a guarantee for all Plex configurations.
