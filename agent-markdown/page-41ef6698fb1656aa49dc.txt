Compare server language preferences with actual player choices using a test account and verifiable audio.

## Distinguish automatic and manual

Plex account language settings can attempt automatic selection of matching audio or subtitles when their prerequisites are met. Its documentation also says a manual choice is not automatically replaced afterward. This is a Plex account and server rule, not a guarantee that iCouldPlay shows identical controls or results. Observe the difference without changing another person’s preferences or generalizing one playback to every client.

## Prepare a two-track short

Prepare a self-made or authorized short copy with two audio tracks saying “Chinese track” and “English track” at the same moment. Set appropriate language tags in the authoring tool, retaining the project and unmodified original. Record track count, labels, spoken content, duration and actual container; labels alone do not prove the sound. Have an administrator place the copy in an isolated Plex movie library.

## Establish an independent account baseline

Use a separate Plex test account authorized for the test library and record its original language preferences and automatic selection setting without passwords or tokens. Leave real accounts and other users’ progress unchanged. After the administrator scans the test movie, confirm the entry and both tracks are visible on the web. If only one is recognized, inspect the short and server state before comparing automatic selection. Place distinct spoken cues at the same video time so the comparison does not rely on remembering an entire scene; audition both in the authoring tool if needed.

## Set a test language preference

In the Plex test account, enable automatic selection in the current interface and choose one language present in the file as preferred; record values before and after. Plex says related automatic language settings require the automatic-selection option and will attempt a language match, not guarantee one. If the current server or account lacks the setting, do not change another account; mark this branch unperformed. Record the chosen language code and display name, verifying the sample has a matching track so an absent language is not mistaken for automatic-selection failure.

## Establish a Plex Web reference

Using the test account, open a test item for which no manual track choice has been made. In Plex Web note the selected label and play to the spoken cue to verify actual sound. Record preferred language, displayed track name, actual audio and starting position. If label and speech disagree, inspect the media copy in the authoring tool, including track order, language codes and cues; if correction is needed, regenerate only the isolated copy and rescan before calling it a player translation or automatic-selection defect.

## Manually choose the other track

Use the audio-track control visible in Plex Web to select the other language manually and play the same spoken cue. Record the action, label and sound. Leave and reopen the test item to observe whether the manual selection remains; record the actual result, not the documentation’s expectation as a test. For a clean baseline, an administrator may prepare another isolated test item rather than deleting real user data. Before repeating the test, confirm the second item did not inherit the prior manual choice. If this cannot be confirmed, record the limitation rather than calling it a fresh automatic baseline.

## Observe track selection in iCouldPlay

Connect iCouldPlay to the same Plex server and test account, open the short and record the initial track label and actual sound. If the current interface has an audio selector, choose the other track and return to the same spoken cue; record an absent selector or single track honestly. iCouldPlay may use different presentation or state handling, so Plex Web behavior does not establish the client’s implementation.

## Do not rely on language labels alone

Compare playback against the spoken-cue checklist. If a Chinese label produces the English cue, inspect media tags and file identity first; if both sounds are identical, the copy may contain duplicated audio. Confirm the server-selected file and iCouldPlay item, then compare the device output and volume. Do not confuse Bluetooth routing, mute or in-file tags with the language-preference rule.

## Record evidence of manual choice

For each observation record time, account, client, automatic setting, preferred language, whether a manual choice occurred, displayed label and actual cue; use “unknown” where necessary. Change one factor at a time, not account, language and track together. Before sharing screenshots, remove server addresses, account names and other users’ library entries to avoid exposing personal data. Record only the self-made cue words; do not upload someone else’s dialogue or unauthorized video.

## Restore settings and hand over

Have the test-account owner restore language preferences and the automatic setting to recorded values. The administrator retains or removes the test copy by agreement, confirming original media and real accounts are unchanged. Record Plex and iCouldPlay versions, actual web and client results, and unperformed steps. Separate documented expectations, observations and unresolved questions; this guide claims no private-service login or device test.
