Japanese vowel length can change a word’s meaning. In 键来, おばさん and おばあさん differ by one あ, but they should not be treated as the same form of address. Build a two-line comparison in a private note and check romanized input, candidates, and final kana separately instead of guessing the text from sound.

## Understand the two targets

The first line is おばさん; the second is おばあさん. The Japan Foundation’s discussion of Japanese pronunciation uses the pair to illustrate vowel length, and its family-terms material lists them separately. The first can refer to an aunt or a woman addressed similarly; the second can refer to a grandmother or an older woman. Actual address also depends on relationship, context, and politeness, so this practice card is not automatic advice for addressing anyone.

Count the kana first: the first line has お, ば, さ, ん, four characters; the second has お, ば, あ, さ, ん, five. The extra あ follows ば rather than appearing at the end. Both keep the voicing marks on ば. Put the targets on paper or somewhere else temporarily and compare after entering them; real relatives’ names are unnecessary.

## Enable Japanese and enter the words

Confirm 键来 has been added to the iPhone and select it in an ordinary note. The current fifth App Store screenshot shows a 日本語 switch under language and input, says to select an input language in the keyboard function menu, and describes romanized Japanese input; the globe switches system keyboards. Enable and select Japanese using the interface actually visible. If the installed version differs and you cannot find it, stop and record that rather than confusing the system globe with 键来’s internal language switch.

On the first line, try typing obasan, observe the composition and candidates, choose the actually offered hiragana おばさん, and commit it. Do not assume it will be first or treat uncommitted letters as text already written. After committing, move focus or end composition and confirm the note contains the four kana. If the actual input scheme behaves differently, record the keys and candidates you see instead of guessing repeatedly.

On a new line, try obaasan. The two a letters represent the ばあ in this example; inspect the actual candidates, select おばあさん, and commit it. It should contain one more あ than the first line. If a kanji or another candidate was selected automatically, correct it to hiragana in a copy of the note before comparing and separately record the first actual result; do not claim the app always supplies a particular candidate automatically.

## Recheck with grouping

Split the first line on paper as お｜ば｜さん and the second as お｜ばあ｜さん. The bars are only grouping marks and do not belong in the words. Both start and end alike, but the middle differs between ば and ばあ; inspect that position carefully. Counting is not a substitute for reading each character, because an omission and a wrong extra character can cancel out in the total.

Place the cursor in the second line and observe the actual edit position. If the note app supports moving the cursor, check character by character that a complete あ follows ば, but do not assume one backspace always removes one visible character. If you delete something by mistake, undo or rewrite the word in a copy, then check from the start. Keep the first line unchanged while repairing the second so the comparison baseline remains available.

## Verify characters, not just sound

You may label the lines “short” and “long,” but the labels are not part of the Japanese words. Compare positions: both begin お, ば; the first then has さ, while the second has あ, さ; both end in ん. Check the extra kana first and then the voicing marks. If the device font makes characters hard to distinguish, enlarge the note; zoom does not change text and appearance alone cannot establish a candidate’s origin.

Record the keyboard and language, the two romanized attempts, the candidates chosen, final text, and any manual corrections. If the keyboard does not offer the target, mark it incomplete and use a known kana-entry method or consult the installed version’s help. Do not assert a particular order or invent a button. Listening to pronunciation can be additional study, but this exercise verifies text positions and does not measure vowel duration. To check meaning, consult a reliable dictionary or teaching material in context; the same kana can refer to different people in different situations, and an automatic candidate does not establish that a form of address is appropriate. Keep observations of what you typed separate from your understanding of meaning, and do not treat candidate order as proof of meaning.

## Common errors and restoration

If the two lines are identical, check whether the second attempt omitted an a or the same candidate was committed twice. Do not rely on a glance at the composition area; compare only after confirming the target is in the note. If ば becomes は, inspect the committed character and voicing marks, then enter the desired word again instead of blaming the theme or font. If kanji makes character comparison difficult, choose a hiragana candidate or keep the original result and write the target hiragana separately.

When finished, return to your usual input language. If you use the system globe to switch keyboards, check the current keyboard’s identity again. Keep the practice card without private information; there is no need to send it to anyone. For a later repeat, record device, version, and input scheme rather than generalizing one observation to all keyboards and devices.
