## 理解视觉变换

W3C CSS Text 说明 text-transform 可用于视觉上的大小写等变换，不改变底层内容，规范要求纯文本复制粘贴不受该属性影响。出版文件是否采用该属性、书屿是否实现及系统复制路径的实际结果都需要单独检查；不要把屏幕上看到的大写直接当成源文字本来就是大写。

## 准备自制授权样本

使用自己制作或出版者允许检查的 EPUB，选择一段无私人信息的自制英文短句并记录准确大小写；另存原文件备份。若出版者说明样本有 text-transform 声明，保存该说明。不要公开受版权限制的大段正文，文件受保护或许可不允许拆包时只观察界面，不尝试绕过保护。

## 建立阅读基线

在书屿打开目标章节，借目录、搜索或翻页找到短句，记录可见大小写、字号、设备方向和上下文标记。若目标没有显示，先确认书籍打开、章节和文件版本正确；不要立刻推断 CSS 出错。保留书签与原有笔记，不清除应用数据或替换原文件。

## 检查源码与样式

仅在获得许可且有合适工具时，在副本中找到目标 XHTML 源文字及其引用样式，记录是否存在 text-transform 和适用的 uppercase、lowercase、capitalize 或其他值。章节可能有多个样式和继承规则，一个搜索命中不证明该规则一定作用于目标。若不能检查源码，将源文字和声明标记为未知或未执行。

## 比较显示和源文字

将授权样本中已确认的原始短句与书屿实际显示逐字比较，把源值和屏幕值分开记录。如果两者大小写不同，这只是观察到的显示差异；在缺少样式作用范围和实现证据时，不应断言具体规则导致变化。大小写可能影响专有名称含义，不要凭视觉形式改写出版者原文。

## 检查纯文本复制

若书屿当前界面允许选择和复制自制短句，将它粘贴到自己的纯文本笔记中，记录实际字符和大小写，再与源文字对照。规范对纯文本复制有要求，但操作系统、应用与目标编辑器可能影响一次观察；不将单次结果推广到所有设备。无法选择或复制时标记未提供，不用未知工具绕过。

## 单独比较搜索结果

如果应用提供搜索，可以分别尝试自制短句的源大小写和可见大小写，并记录关键词、位置及实际命中。搜索可能不区分大小写，结果还受索引和语言处理影响；两种查询都命中不能证明源文字已被修改。没有搜索入口或合法样本时将该步骤记为未执行。

## 排查并保留原件

若显示、复制和源码不一致，逐项核对文件版本、目标段落、样式作用范围、当前应用和粘贴目标，一次只改变一个条件。可信阅读器可作独立对照，但其表现不同不单独证明书屿错误；无需安装未知软件或改动唯一原件。保留未知原因，必要时联系有权维护样本的出版者。

## 恢复与记录

恢复原阅读设置并确认原件、书签和笔记保留。结果表分别填写出版者提供的原文、可查样式、书屿可见字符、纯文本粘贴结果、搜索与未执行原因；分享前去除私人路径和未经许可的内容。本文依据公开标准及应用资料，不声称真机实测，也不保证书屿支持特定 CSS 属性。

## 先确认对照短句的身份

自制样本可以选取一个含大小写混合字母、数字和标点的短标题，并在私人记录中保存原始拼写。比较前先确认目标章节和附近标记，避免将目录中的同名标题与正文中的另一处文字混为一谈。如果样本来自出版者，记录版本与允许检查的范围；不需要为本练习收集用户的姓名、邮箱或其他私人数据。

## 样式声明和实际作用分栏

将源码中发现的属性值、选择器、目标文字是否匹配该选择器以及是否存在其他覆盖规则分别记录。即使文件某处包含 uppercase，也可能作用于其他标题而非正在看的段落；若无法确定规则范围，则写未确认。屏幕显示的大写可能来自源文字本身、样式、应用处理或其他原因，不能不经检查就指定其中一个。

## 粘贴目标也要记录

纯文本与富文本目标可能保留不同的格式信息。若设备提供选择，记录本次使用的目标编辑器和是否为纯文本，再观察字母本身；不在公开网页输入私人内容。若粘贴目标自动改写文字或无法确认模式，此次结果不能单独证明阅读器改变了复制文本。必要时用另一可信纯文本目标做独立对照，但不要为此安装未知软件。

## 保留语义与不确定性

部分语言和专有名称对大小写敏感，视觉转换可能改变读者对词语的理解。检查时以有权查看的出版者原文为依据，不自行把全大写显示改成所谓正确拼写。若既不能检查原文也不能复制，仍可如实记录画面和未测条件；没有证据的内部实现和来源应保留未知，而不是为表格填入猜测。

## 一组可复现的自制样本

可复现自制样本：源文字写为 Read Me 42，对目标段落声明 text-transform: uppercase。按 CSS 规范，屏幕视觉样式可呈现 READ ME 42，但底层源文字仍为 Read Me 42，纯文本复制不应因该属性改变。先核对选择器确实作用于样本，再分别记录书屿画面与粘贴结果；预期来自规范，不保证应用支持或表示已经实测。
