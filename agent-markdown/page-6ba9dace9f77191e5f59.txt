## Distinguish documented pass count from Gaussian strength

Aegisub defines extended integer be strength as the number of ordinary-edge passes: 2 means two passes, not a two-pixel radius. The documentation discourages be in new subtitles because of frame-scaling limitations; it remains here as a legacy-format comparison, not a production recommendation. Zero disables each effect.
