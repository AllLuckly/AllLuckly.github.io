## Multiply each value by its own probability

Compute 0×1/2=0, 2×1/4=1/2 and 5×1/4=5/4, not the deliberately proposed 4/5. Their sum is 0+2/4+5/4=7/4=1.75. Probability weights a score; do not divide by it. Also retain reciprocal error 4/7 as a control, since expectation does not invert the result. Products have score units while probabilities are dimensionless.

```text
sum     1         E[X]=7/4=1.75
```

## Recalculate a doubled-plus-one scoring rule

For Y=2X+1, scores become 1, 5, 11 with corresponding probabilities unchanged. Weighted expectation 1×1/2+5×1/4+11×1/4=18/4=4.5, independently 2×1.75+1. Add the constant to every possible score, not only the maximum. Doubling scores does not double probabilities. This is a transformation of the same variable and needs no second independent experiment. Keep X/Y tables separate to avoid a stale score row.

```text

possible Y: 1,5,11
E[Y]=1/2+5/4+11/4=9/2=4.5
2*E[X]+1=2*(7/4)+1=9/2
```
