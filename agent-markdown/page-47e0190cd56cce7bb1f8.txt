用两千克三十度斜面分镜复算十牛下滑分量、十倍根三支持力与五米每平方秒加速度。

斜面图中的箭头多，不等于作用力真的有那么多。本课把真实外力、重力分解和运动结果分成三个画框，在漫阅逐框核方向与数量。原始数据和算式由外部制作，阅读器负责显示与返回位置；不声称应用自动绘自由体图或模拟物体运动。

## 题设先排除隐藏的绳和摩擦

外部画一块质量2kg的小方块放在与水平成30°的固定直斜面上，取g为10m/s²。明确忽略摩擦与空气阻力，没有绳拉或手推，保持接触且没有垂直离面加速度。开始可以在释放瞬间速度为零，但并不是静力平衡；失去约束后会沿坡加速。题设栏与画面放同一页P1，另做P2分量与P3结果。若想画手扶方块的准备状态，必须另框标有外力，不把释放前后的箭头混在同一自由体图里。

## 只画作用在方块上的两个外力

先画重力w等mg为20N，方向竖直向下；再画支持力N，垂直斜面指向离开表面的一侧。不要因为方块沿坡运动就把支持力画成竖直或沿坡，也不把方块对斜面的压力画进方块受力图。后者作用对象是斜面，与支持力构成相互作用对，却不是同一物体上的两根平衡箭头。给两根实线箭头标来源，重力来自地球，支持力来自接触面。此时未分解重力，先留支持力大小待算，不能从箭头画得多长反推精确数值。

## 把坐标轴转到沿坡和垂坡

在P2复制同一重力箭头，设沿坡向下为正，垂直斜面向外为正。重力与指向斜面内部的负垂直轴夹角为30°，因此沿坡分量mg sin30°为10N，压向斜面的分量大小mg cos30°为10√3N，约17.321N。用虚线表示分量，并写它们合成原来的w，不是另外两种作用。若同时画实线重力与两个分量，图例必须注明分解辅助，否则求和时可能错误地算成三份重力。计算器中的30需按度处理。

```
m=2 kg; g=10 m/s^2; theta=30 deg
w=20 N
w_parallel=mg*sin(theta)=10 N (downslope)
w_perp=-mg*cos(theta)=-10*sqrt(3) N (outward axis)
N=10*sqrt(3) N
F_net_parallel=10 N; a_parallel=5 m/s^2
```

## 垂直平衡只抵消一个分量

接触约束使垂坡加速度为零，所以N加负的10√3等零，支持力大小为10√3N。它小于20N，不是斜面偷走了部分重量，而是只有重力垂坡分量在这个方向需要抵消。沿坡仍有10N，不能从垂坡合力零就推整体合力零。给P2另画一个小式，写N不等于mg在本题成立；水平面才在其他条件相同时恢复N等mg。若有绳索斜拉或其他外力，垂坡方程要重列，不能继续无条件套N等mg cosθ。

可将每根箭头的作用对象写在尾端小框中：支持力作用方块，方块施给斜面的力作用斜面。两者大小相等方向相反也不能在同一物体的方程里抵消。这种对象核对先于数值，若对象栏混错，得到漂亮的零合力也不能证明受力图正确。

## 沿坡用牛顿第二定律求运动

沿坡没有摩擦和其他外力，合力10N除质量2kg，得到加速度5m/s²，方向沿坡下。速度与加速度分开记：释放瞬间速度可为零，加速度已非零；若先给方块沿坡向上的速度，当前加速度仍可向下，不能只看速度箭头决定受力。报告不必添加时间位移公式，但若画下一格位置变了，要说明时间间隔，不能把任意格距直接叫测得速度。这个理想模型说明运动趋势，不承诺真实物体在粗糙桌板上也恰好以5加速。

若希望方块在该无摩擦斜面保持静止，须另加沿坡向上的10N外力，并在新图注明来源；加入后已是另一题。不能把静止愿望凭空变成支持力的沿坡分量。新图仍可有相同垂坡支持力，但沿坡方程多一项，必须把改动清单交给复查者。

## 用角度边界与矢量和双重抽查

先把角度纸面改为零：沿坡分量零，支持力20N；再改60°：沿坡分量10√3N，支持力10N，核正弦余弦没有互换。回到30°时，两重力分量平方和为100加300等400，开方回20N，而不是10加17.321等于重力大小。分量是矢量的正交投影，不能把大小简单相加。若为示意箭头选每牛顿8像素，20N重力长160像素，10N分量80像素，支持力约138.564像素；这是外部作图比例，屏幕缩放后需按标签读，不是力的测量。

## 在漫阅按作用对象定位错箭头

导入三页PDF，先核P1的无摩擦与无绳条件，再到P2看虚实线，最后读P3的5m/s²。可在分量页加书签，回查时指明箭头属于方块还是斜面。若支持力画竖直，先修方向；若合力写零，查是否把沿坡分量也抵消；若写出四个真实力，查重复计入分量。只改一项后重读题设，保留错误版作对照。未做的导入、书签或横屏观察都留空，不用一张静态图替代实际物体运动实验。

错稿若只把箭头移动而没改图例，重开后仍会留下两套解释。应在同一次更正中核箭头、名称、作用对象三项，再恢复整页确认没有把接触面也当作受力物体一起框进来。

## 重开交付两力两分量一个结果

重开书签页，先数真实作用力两种，再指出重力的两个辅助分量，最后说出支持力10√3N与沿坡加速度5m/s²。验收还要说明支持力与重力不是本题的作用反作用对，释放瞬间静止不等于受力平衡。保存题设、角度对照、单位与实际操作记录，尚未重开只记纸面通过。若后来读到有摩擦、弹簧、拉绳或离开斜面的画面，要重新画作用对象和外力，不把本课的两力图强套所有斜坡故事。
