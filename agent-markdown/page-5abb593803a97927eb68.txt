A recent project needed an animation, so I looked through a lot of related material.  
 I found nothing suitable, so I made a custom implementation.  
 The main principle uses the sine rule for triangles   
 and the cosine rule to animate a view moving around an image's center.

See the code below.

Core code

```css
self.center = CGPointMake(_radius * cosf(_angle) + imgView.center.x, _radius * sinf(_angle) + imgView.center.y);

_timer = [NSTimer scheduledTimerWithTimeInterval:_time target:self selector:@selector(moveView) userInfo:nil repeats:YES];
```
