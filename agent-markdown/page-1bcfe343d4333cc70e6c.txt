把浓度、总量与温度下的中性条件分开，不把pH当线性酸量或危险程度。

刻度三到五只隔两格，不表示水合氢离子浓度仅差两倍。本课用两份给定浓度卡和体积对照，在漫阅逐页核对数、单位与中性判据。数据都是原创理想读图输入，不测液体、不调配溶液，也不作健康或危险程度判断。

## 先限定稀水溶液和浓度近似

外部设25°C的两份理想稀水溶液，甲\[H3O+\]=1×10⁻³mol/L，乙1×10⁻⁵mol/L。P1浓度卡、P2体积卡、P3温度与错例，导出PDF留源稿。导入后核指数负号，为P1加书签。本课用pH约等于负十进对数的浓度比，即−log10(\[H3O+\]/1mol/L)；严格定义涉及活度，实际高离子强度等情况不能只用浓度当精确活度。本题近似范围写在图首，不因材料出现pH就假设所有真实溶液均理想。

## 负对数让较低pH对应较高浓度

甲由−log10(10⁻³)得pH3，乙得pH5。甲浓度除乙为10⁻³/10⁻⁵=100，pH较低而水合氢离子浓度较高。差二单位对应十的二次方，不是浓度差二mol/L，更不是pH五“酸五份”。把浓度表和pH表用对应箭头相接，但箭头只表示数学转换；图中液体颜色或深浅若无标定说明，不用来反推精确浓度，读者也不从漫画画面判断化学试纸读数。

## 先反算一遍避免对数符号抄反

用\[H3O+\]=10^(−pH)mol/L恢复三对应10⁻³、五对应10⁻⁵。另给丙pH4，浓度10⁻⁴，位于甲乙几何中间而非浓度算术平均；甲乙浓度平均为0.000505mol/L，其pH约3.2967，不等四。这个平均只是给定浓度的数学平均，不声称实际混合任意酸都会得到该值；体积、平衡和反应条件另有要求。原卡、反算和错例分别保留，不用改指数让图上等距看着更像线性。

```
ideal dilute concentration approximation; 25 degC
A: hydronium=1e-3 mol/L -> pH=3
B: hydronium=1e-5 mol/L -> pH=5
A/B concentration=100; pH difference=2
A volume=0.001 L: hydronium amount=1e-6 mol
B volume=1 L: hydronium amount=1e-5 mol
neutral criterion: [H3O+]=[OH-], not universal pH=7
```

## 体积不同先算物质的量再比总量

P2给甲体积1mL即0.001L，乙体积1L。当前水合氢离子物质的量按浓度乘体积，甲1×10⁻⁶mol，乙1×10⁻⁵mol，乙虽浓度低百倍，却因体积大千倍而总量高十倍。这里数的是给定状态的H3O+，不等于溶液内所有可供出的酸性质子，也不是滴定总酸度。pH不含体积信息，不能只看三和五就断言甲样本的水合氢离子总数一定更多。

体积错例可单独留表：把甲1mL漏换算而当1L，会误得10⁻³mol，比正确10⁻⁶大千倍，并错误颠倒与乙总量的排序。修正时只把体积还原0.001L，甲的pH仍三，不因总量更正而改成六。浓度定义按每升计，物质的量改变和浓度标签改变不是同一操作；表格必须同时保留浓度单位与体积单位，不能只把一个小数点挪动后不解释哪项输入发生变化。

## 中性先比两种离子再读温度

25°C取Kw=1×10⁻¹⁴，若中性则\[H3O+\]=\[OH−\]=1×10⁻⁷mol/L，pH7。甲pH3与乙pH5在此温度均为酸性。判断依据是水合氢离子浓度大于氢氧根，不是数字低于七在所有温度下都通用。可由Kw反算甲\[OH−\]=10⁻¹¹、乙10⁻⁹mol/L，两者与各自H3O+相乘均10⁻¹⁴；单位和温度栏要随表保留，别让孤立的七成为无条件中性定义。

25°C的pOH栏也可由负对数独立恢复：甲OH−为10⁻¹¹，pOH十一；乙为10⁻⁹，pOH九，分别与pH三、五相加等十四。不能把pH与pOH相乘要求十四，也不要求两个浓度相加等Kw，Kw在此是乘积关系。水合氢浓度比甲大百倍时，氢氧根浓度恰反向小百倍，这个反向比较仍依共同温度与Kw，不推广到不同温度的两杯材料。

## 温度控制保留六点三一仍中性

P3引用教材的80°C纯水条件，\[H3O+\]与\[OH−\]都约4.9×10⁻⁷mol/L，pH和pOH都约6.31，仍因两浓度相等而中性。二者和约12.62，不再是25°C常用十四。此控制只说明Kw随温度变化，不从本课推断任何加热液体的安全或真实测量值。比较材料时先核温度和所用近似；不能见6.31小于七就把这份纯水改标酸，也不能把七强行贴到所有状态上。

## 按对数底数体积与中性范围排障

差两格只比两倍时先查十进底数；乙总量误判更少时补体积；80°C卡被标酸时回两离子相等判据。放大负指数、H3O+和OH−的符号，不把分子式的数字三当浓度三。逐次只修一栏，再做反对数或Kw乘回。若资料只给颜色照片或未注明条件的“酸度”，不补一组精确pH和危害标签；无法确认的近似、温度与体积写未知，避免一个算对数值继续扩大成无证结论。

pH还不能单独给某种酸的本征强弱。酸强度涉及解离平衡，材料的分析浓度也会影响溶液pH；看到一杯pH较低，不能跳过组成和浓度就宣布其中酸分子一定属于更强酸。此课只比较给定水合氢状态，不辨认未知溶质，不给Ka或配方，更不把“酸性”“浓度高”“危险”三词互换。读者可把这些未能推出的主张另列反例栏，以免一项正确对数计算替后续无证判断背书。

## 重开用浓度总量中性三个问题验收

重开PDF回P1，不看答案写甲乙pH3、5和百倍浓度差，再到P2写乙总量高十倍，到P3解释6.31中性。交付正反对数、体积账、Kw与温度控制，未做的导入书签重开标待办。验收是知道同一个pH表能回答哪些问题、还缺哪些条件，不声称漫阅测溶液、自动读取试纸、验证毒性或已经完成真实化学实验；所有精确数值都回到题给模型和可靠定义。
