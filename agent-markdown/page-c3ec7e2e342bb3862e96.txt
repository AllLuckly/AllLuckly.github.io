Connected in Bluetooth settings is only the first step in connecting a controller to an iPhone. You still need to confirm that Yearn recognizes it and that the game receives directional and button input. This guide checks pairing, recognition, input and recovery after disconnection separately, rather than stopping at a connection icon.

## Prepare the controller and a test scene

Charge the controller first and consult its own pairing instructions. Brands and models use different button combinations for pairing mode, so do not apply one sequence to every controller. If it was previously connected to a console or computer, check that it has not automatically reconnected there. Disconnect it from the old device if necessary.

In Yearn, prepare a legally obtained game that works with touch controls, and stop at its title menu or a safe position. Touch input then provides a comparison if the controller does not respond. Choose a sample that can test direction, confirm, back and pause separately, rather than a long opening animation that is not yet accepting input.

## Complete system Bluetooth pairing first

Put the controller into pairing mode. Open Bluetooth in iPhone or iPad system settings and select it from the discoverable devices. Wait until the connection stabilizes rather than returning to the game as soon as you tap its name. If a pairing code is requested or an unsupported-device message appears, follow that model's official instructions.

If the system cannot find the controller, move it closer, check its charge and confirm that its pairing light is still flashing. If it is connected elsewhere, disconnect that connection before trying again. Refresh in the app only becomes useful after system pairing succeeds; repeatedly opening Yearn Settings cannot replace that step.

## Check recognition in Yearn

Open the controller page in Settings and see whether the device name appears under Connected Controllers. If the list has not updated, use Refresh before returning to the game. The name may come from information supplied by the controller and differ from the full product name on its box. Identify it by observing what appears when you connect and disconnect it.

Back in the game, observe whether the on-screen controls change. The input path specifically handles extended gamepads; this does not mean every device capable of a Bluetooth connection is a game controller. A keyboard, remote or device implementing only part of a protocol may appear in the system list without replacing a full gamepad.

## Test four input categories in order

In the first round, use only the directional pad to move the menu cursor up and down. Next, test the lower and right-hand face buttons, noting each action. Test the shoulder buttons in the third round, then check what Start, Menu or Options does in this game. Change one input at a time so that simultaneous presses do not obscure which one worked.

Older consoles have their own button layouts, while modern controllers have their own letter labels. The same letter does not necessarily occupy the same position. Describe results as the lower button or right-hand button, then compare them with the game's confirm and cancel actions. If the positions merely differ from your habits, read the input troubleshooting guide before assuming the controller is faulty.

## Evaluate the stick and directional pad separately

If left-stick-as-directional-pad is enabled, use both the directional pad and left stick to follow the same route. If the pad works but the stick drifts, check the deadzone and whether the stick returns to center. If neither moves anything, first check for a disconnected controller or a scene that does not currently accept input.

The stick deadzone in Yearn Settings ignores small inputs near the center. Make small adjustments around the default value. Release the stick to see whether movement continues, then slowly push it toward the edge. An overly large deadzone can also ignore gentle movements, so do not maximize it to eliminate one instance of drift.

## Test disconnecting and reconnecting too

Save a verifiable checkpoint in the game, then pause and disconnect the controller. Check whether touch controls return. Once you can use the menus again, reconnect. This confirms that you have an exit path after a temporary disconnection; there is no need to test during a critical battle or a one-chance scene.

If only some buttons work after reconnecting, return to the game library and reopen the current game. Record the device orientation, controller model and system version when the issue occurs. Do not start by uninstalling the app: that complicates files and progress without directly addressing Bluetooth pairing.

## Frequently asked questions

**The system says Connected, but Yearn does not respond?** Check the app's controller list, whether the game permits input in the current scene, and whether touch works, in that order. If the app does not recognize that device type, use a supported controller type first. A system connection does not establish app compatibility.

**Can a wired connection replace Bluetooth?** Some compatible controllers can connect through a data-capable cable and adapter, depending on the device and controller. A charge-only cable may not carry input. Follow the hardware instructions.

Record the connection name, working inputs and reconnection behavior. Once you have a stable combination, consider a permanent stand, TV display and holding position. This controls variables more easily than buying many accessories before troubleshooting.
