Make equal-duration copies and distinguish a fade, playback pause and file duration in 调调.

English translation of the [Chinese original](<https://allluckly.cn/guides/diaodiao-owned-audio-fade-versus-unchanged-ending/>), translated on 2026-11-24. Original publication dates, attribution, code and version notes are retained.

The end of an owned recording can stop abruptly or fade gradually. Make two copies of the same duration in an external audio editor, then import them into 调调 and compare their final ten seconds. A fade changes amplitude; it is not a shorter file or an automatic player transition.

## Prepare the original and measurement points

Choose an owned or authorized recording of at least thirty seconds and retain the original and backup. Select a stable passage without a safety warning sound. After confirming it plays on the computer, make working copies A and B. Keep A's original ending; apply a fade only to B's last ten seconds while both copies retain the source’s full duration. If the source is not exactly thirty seconds long, record its duration and count backward ten seconds from its end; thirty seconds is only the calculation example.

Make a table for file, processing, total duration, the positions ten seconds and five seconds before the end, and the ending. Leave audible results blank until observed. The comparison uses two endings of the same recording, not different songs, devices or compression formats. Choose a trusted installed editor with waveform selection; do not upload private recordings to an unfamiliar site.

## Mark the range on the copy

Open working copy B and locate the end on the editor's time ruler, then locate the point ten seconds before it. For exactly thirty seconds, select from twenty to thirty seconds; twenty-five seconds is the midpoint of that selection, not the midpoint of the entire track. Zoom the ruler to check both boundaries and avoid selecting the first ten seconds or only the final second. Preview the selection; if it is already silent, choose a suitable source passage.

Before saving, record the editor and original path. In a non-destructive editor, the project and exported audio are different things. Confirm that the actual audio export will go to the separate exercise folder. Do not overwrite the sole original or extract protected material from a subscription service.

## Apply the fade to B

Apply the fade offered by the editor to the selected ending, checking the tool documentation for selection scope. Audacity documents fade effects on selected audio; commands and curves may differ in other editors, so do not assume identical amplitudes. Inspect the waveform trend and listen: the portion before the final ten seconds should remain the same recording, while the ending gradually becomes quieter.

If the fade begins at the start, undo and recheck the selection. If duration changes, check whether trim or delete was used instead. Save B under a different name without overwriting A. Leave A unprocessed as the original-ending reference. Ideally export both using the same format and parameters; if the tool provides different formats, record the difference and do not attribute every audible difference to the fade.

## Check files and duration

Close and reopen A and B, verify playback duration in the editor or file information and record their locations. In the thirty-second example, the starts, twenty-second positions and endings correspond to the same moments of the recording; only B's last ten seconds fade. If B ends ten seconds early, delete may have been used instead of fade. Return to the retained original and make a fresh copy.

Displayed seconds may be rounded. Where precision matters, use the editor's finer time display instead of relying on an integer in a list. Confirm both local files play independently before using 调调's available local-file import. If file size, format or protection does not meet the installed version's conditions, investigate the actual message; renaming an extension is not conversion.

## Import into 调调 and identify both copies

Select working copies A and B individually in 调调, observe each import response, and record the titles and durations visible in the library. If the titles match, use recorded filenames, processing order and audible endings to identify them, returning to the copies when needed. Do not assume the app always distinguishes files by filename or tag. Play each and confirm the first part is the same recording, then listen to the ending at a personally comfortable level.

As far as practical use the same output device and volume for each run from ten seconds before the end. A's ending follows the original; B should become gradually quieter. Record any change of device or environment rather than mistaking it for the edit. Avoid headphones in traffic or where environmental warnings matter, and do not greatly increase volume to hear a faint tail.

## Compare fade with pause

Pause B about five seconds before the end and record the playhead. Pause is a playback state; it does not permanently edit the file. Resume at the same point and observe the final seconds. The fade midpoint is halfway through its time range, but need not sound half as loud: curve shape, source sound, equipment and hearing all affect the subjective result. Compare A at the same position and record what was heard without presenting it as a device measurement.

If no change is heard in B, check whether an older copy was imported, whether the selection covered the end, whether the processed audio was exported and whether playback started at the correct position. Change one condition and export a newly named copy for another trial. Keep the old record and do not clear the whole library. Mark uncertain provenance pending rather than attributing the result to an automatic fade in 调调.

## Save observations and restore

Reopen 调调 and check that both copies remain identifiable; verify the original and backup still exist. Record duration, both time points, audible results and incomplete steps separately. A file waveform, player position and subjective sound are different kinds of evidence. Keep the practice copies or delete them yourself if appropriate; mark unperformed device or format checks pending. No physical-device or private-library test is claimed.
