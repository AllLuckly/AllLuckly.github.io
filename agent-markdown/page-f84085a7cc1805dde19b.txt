手工保存一份最小 VTT，为自制短片添加三条时间提示，分别核对文件格式、播放选择和开中末时间。

给自己的演示短片写字幕，最好从三条能核对的提示开始。云映公开说明列出 VTT 外挂字幕，本篇制作一份简单文件，在原视频开头、中间和结尾各放一句，再检查实际显示。这里不依赖自动识别对白，也不把播放器当成字幕编辑器；文本制作在自己的编辑工具中完成。

## 先为短片确定三处事件

选择已经能正常播放的一段自制视频，记录三个明显动作出现的时间，例如举起开场卡片、移动物体和展示结束卡片。每条提示持续两三秒即可，避开相互重叠。提示写自己确认的内容，不需要复制商业影片对白，也不必先做几十条文字，让第一轮检查保持简单。

在应用之外先看完短片，确认这些事件与时长。视频以后若剪掉开头或中间一段，旧时间轴就需要重新检查，所以先固定本轮原件。把视频文件名和三个事件写在同一份笔记里，后续加载错字幕或选错剪辑版时，有明确参照，不靠字幕文件名称看起来相似来判断。

## 了解最小文件的结构

使用可以保存纯文本的工具，新建以 WEBVTT 标识开头的文件，其后留空行。每个提示包含开始时间、箭头、结束时间和文字，提示之间用空行隔开。时间采用同一格式并让结束晚于开始，先不用颜色、位置或复杂标签，避免把基础语法与样式问题同时加入。

可参考 [W3C WebVTT 说明](<https://www.w3.org/TR/webvtt1/>)理解标识、时间与提示分组。下面的时间仅用于示例，应换成自己的短片事件，不表示视频在这些秒数必然有对白。文字本身也只是自制提示，保存前再核对每条是否对应实际动作，文件能被文本工具打开还不足以证明时间匹配。

```
WEBVTT

00:00:02.000 --> 00:00:04.000
Opening card

00:00:20.000 --> 00:00:23.000
Move the object

00:00:45.000 --> 00:00:48.000
Ending card
```

## 保存为真实的纯文本字幕

保存时选择 UTF-8 纯文本，并确认最后文件名以 VTT 扩展名结尾，没有被工具额外加上 TXT。检查文件大小合理，再重新用文本工具打开看首行和时间箭头。富文本、文档格式和纯文本不是同一内容，只改后缀不会把一份排版文档转换成可解析的字幕文件。

把这份字幕和对应视频副本放在容易找到的位置，名字说明主题和版本即可，不把同名理解为自动保证匹配。文件在云端时先完成下载；选取列表可见而内容未到本机，会引入另一种失败原因。保留可编辑原稿，每次修改另记版本，避免反复覆盖后忘记刚才加载的是哪份。

## 在播放中选择这份字幕

打开同一视频，进入当前提供的字幕管理或外部导入入口，选择刚保存的文件。返回播放后，核对实际选中的是这份字幕而不是关闭状态或另一份旧文件。菜单名称随版本可能不同，以可见入口为准；没有入口时记录当前播放路径，不必通过改变扩展名反复尝试。

先跳到第一条提示开始前几秒，正常播放到它结束，观察出现与消失。字幕只在对应区间显示，停在开场静音但尚未到提示时间时没有字，并不说明失败。若整段都没有提示，先回文件查语法、保存格式和选择状态，再考虑播放路径差异，不要立刻重做视频编码。

## 中段和结尾分别再核对

按事件笔记检查中间与末尾提示，先观察实际内容是否对应，再估算提前或延迟。三处都差不多一个固定时长，和删改点后突然错位是不同情况；本次自制短片应优先修正自己的时间记录，不借全局偏移掩盖三条本来就写错的时间，让原稿保持能独立理解。

修改字幕后以明确新文件名重新加载，确认播放器正在使用新版本，再回同一事件比较。不要同时改变字体、视频副本和时间设置，避免结果改善后不知道原因。若视频总长短于最后一条提示，最后永远不会出现，应先检查是不是选错短版或把分钟与秒写混了。

## 给提示文字增加中文后复查

基础英文提示可显示后，可以在新副本里改成自己的中文短句，仍保留三个相同时间区间。出现乱码先回文本工具核对 UTF-8，少量字符方框则检查字符与字体覆盖，不把两者混为一个问题。先用常见字验证，不需要为一次文字显示差异重置所有字幕样式。

需要双行时让每条提示保持简短，按自然词组换行，再在实际观看尺寸下检查。不要把一大段讲解全塞进两秒，能显示不代表来得及读。这里的行数和时长是自己的编辑选择，不承诺所有内核还原复杂 WebVTT 定位与网页样式；基础文字正确后再逐项测试其他效果。

## 保存视频与字幕的对应结果

完成后记录视频名、字幕名、三个事件与实际显示结果，退出播放再重开复查。断网时分别确认视频和字幕都能被重新选择或读取，不只看先前画面残留。字幕原稿也独立保存，应用中的选择状态不能代替外部文件备份，更不表示一份字幕适用于所有同名剪辑版本。

完成标准是三条提示均能在预期动作附近出现并结束，原稿可重新打开修改，而且你能解释每条时间来自哪一处画面。以后增加对白先扩展少量条目，再重复开中末检查，出现问题也有这份最小文件作对照。不要用复制整份别人字幕来代替理解自己的时间轴与保存流程。
