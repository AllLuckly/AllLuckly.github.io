Unwanted collection while zooming calls for clearer gesture assignments. Compare the options available on a supported image path and verify the actual favourite. Book favourites, page bookmarks and collected images are different objects, and a collection notification does not establish an exported photo.

## Check that the page supports image collection

Use an authorised recognisable image and verify normal collection support first. Global shortcut settings do not guarantee every local or remote path supports it. Check for an existing identical favourite before testing, ideally with a self-made sample. No sharing or extra downloads are required.

## Establish a no-shortcut baseline

Disable the shortcut and observe ordinary double-tap and swipe behaviour with other settings fixed. A normal collection button can remain the fallback. Keep direction, menu trigger and image counts unchanged so the subsequent gesture comparison has a meaningful baseline.

## Test double-tap collection alone

Enable double-tap collection if available and verify the correct image in the list. Observe which action occurs when double-tap zoom is also configured; do not assume a preferred priority. Keep one dependable action and remove only verified accidental test entries rather than clearing the collection.

## Interpret swipe collection within the mode

Read the mode-specific swipe description and test a deliberate direction once. Record start, axis and result, then inspect the favourite. Page turns, vertical scrolling and zoomed panning differ. Disable an unsuitable shortcut rather than relying on perpetual precision, and recheck after changing modes.

## Separate collection from bookmarks

Use image favourites, bookmarks and book favourites for their respective purposes. Add explanations in supported notes or your own record without assuming arbitrary folders or annotation fields. Verify identity and reopen the result rather than treating a stored thumbnail as proof of permanent access.

## Verify export separately if needed

For a real image file, use the available save/share flow and reopen it at the destination. Collection does not establish export or permanent offline availability. Respect source permissions. A share panel can be used for local saving without messaging anyone; inspect the actual output and avoid confusing an older image with the new one.

## Keep a simple assignment and reopen

Choose one clear collection action and distinct zoom, menu and advance controls. Use supported scope, check another book and reopen the sample. Retain a no-shortcut baseline for later comparison. A shortcut is useful when the result is clear, not when the maximum number of triggers are enabled.

## Acceptance and reporting

Finish with predictable gestures, the correct stored image and stable reading controls. Investigate conflicts or path capability when double tap only zooms; verify file availability separately for offline access. Report mode, settings, direction and list result using a shareable sample, keeping the normal button fallback.
