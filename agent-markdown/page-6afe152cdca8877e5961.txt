ManYue can import compatible comic sources and access content through their browsing, search, and reading entries. A comic source consists of rules and configuration you add, not a comic catalog bundled with the app. This guide explains JS files, ManYue files, single-source addresses, and source lists, then verifies a small import.

## First confirm the source and file purpose

Obtain the source file or address from a maintainer you trust and are authorized to use, and confirm that it targets a source system supported by ManYue. An ordinary web link, comic detail link, download page, and source-script URL are different things. A correct file extension alone does not establish trust. Check the publisher and instructions rather than finding an arbitrary address and adding sources in bulk.

Start with one source instead of importing the entire list. A source may require an account, depend on the server's page structure, or offer different features. Successful import only means the app can load the configuration, not that all content is accessible. ManYue does not host content or grant authorization for third-party services; reading access remains subject to the source's actual rules.

## Use a local JS or ManYue file

Open “Comic Sources,” open the add entry, and choose “Import Source File.” In the system file picker, locate the `.js` or `.ManYue` file, confirm, and wait for processing. If instructions or an agreement appear, read their specific scope before continuing. Confirmation is not a formality that lets you ignore the source's content.

After importing, return to the comic source list and check that the name, version, and source identifier match the file you obtained. A ManYue file may package one or more sources, so compare the result count with the provider's description. The same displayed name does not prove sources are identical; internal identifiers and versions also affect updates and favorite associations.

## Distinguish a single source from a source list when adding by address

The add panel also accepts URLs. If the maintainer provides a single source-file address, paste the complete link and submit it. If it is a source list, configure it through the address entry under “Comic Source Lists.” A list address usually points to an index file; do not treat a project home page as an index unless the maintainer explicitly says to do so.

When the list appears, select one source you need and check the result. Do not use Add All simply for convenience and install a batch of unneeded, unclear, or poorly maintained sources. More sources complicate search scope, update notices, and fault diagnosis. Starting with one reliable source makes each entry's origin easier to understand.

## Verify three basic actions after importing

First confirm that the source appears in the list, then open its discovery or browsing page, and finally search for a title you know exists there. Enter work details and check whether chapters load. Only open a chapter to verify pages when you are authorized to read it. Successful browsing, search, and reading are different results and can be recorded separately.

Some sources have no discovery page or search capability, so missing buttons do not necessarily mean import failed. Follow each source's declared capabilities rather than expecting identical features from all sources. If it provides a login entry, use that service's account; do not confuse ManYue membership with third-party login.

## Keep a maintainable source record

Once verified, note the maintainer's public release page, current source name, and version. If access later fails, check the original release channel for updates before replacing it with a same-named file from an unknown repost. Retain provenance for source-list addresses too; a URL alone often cannot establish whether the same maintainer still controls it.

A locally added file may not have a remote address for automatic updates. When updating, obtain a new version according to its maintainer's instructions and check the version. Do not assume the app automatically discovers updates for every local script. Retain important favorites and reading records through existing backup methods, especially before removing or replacing a source.

## Check the input first when import fails

For a parsing error, confirm that the file is not an HTML login page, a saved web page, or a renamed archive. If an address fails, check whether the link requires login, has expired, or returns an actual source file. Repeatedly creating a same-named source will not repair the network or maintainer's service when its website is temporarily unavailable.

Do not disable system security checks, paste login tokens of unknown origin, or publicly share account information to make a source “work.” Where explicit access controls exist, use methods allowed by the service. Comic sources are optional for readers who only want their own local comics; local import works independently.

## Frequently asked questions

**Why are there still no comics after importing a source?** A source provides access capabilities. You usually still need to enter discovery, search, or open the relevant library. It does not download everything to the phone at once or automatically fill the local bookshelf.

**Which is better, JS or ManYue?** They are different delivery formats. Choose the one officially provided by the maintainer, clearly documented, and compatible with your current version. The extension alone cannot establish quality, content legality, or long-term availability.

**If a source imports but chapters will not open, is app membership the problem?** Check the specific error and the source's requirements first. Third-party accounts, service changes, source parsing, and networking can all affect reading. App entitlements are only one possible layer; not every failure is a membership issue.
