固定24帧每秒，分开180度与45度曝光、帧间隔和实际运动模糊观察。

同为二十四帧每秒的两段影片，运动边缘仍可能不同。本课先核自有素材的拍摄记录，再把单帧曝光与连续帧间隔分别算清，在云映观察同类动作，不把播放器亮度或倍速当快门设置。

## 先备有真实拍摄记录的两个片段

选择自己拍摄、已获准使用的短片，最好是同机位同动作、相同二十四帧每秒而快门不同的两份。没有这类素材时可先完成纸面账，把观看比较保留待核，不给现成文件猜填快门角。记录文件身份、拍摄帧率、快门或曝光值、导出帧率与动作时点，原件保留。拍摄设置在原拍摄工具核，云映当前任务只是播放，不能从它的画面亮度滑块推断传感器曝光；自动曝光没有留下记录时如实写未知，不拿文件扩展名当记录。

## 一帧周期与曝光窗口分别换算

在理想恒定帧率模型中，一帧周期为一除二十四秒；快门角占整周比例再乘该周期。半周一百八十度对应一除四十八秒，四十五度只占八分之一周，对应一除一百九十二秒，两者曝光相差四倍，帧间隔却一样。下面的账按秒和毫秒并列，不把角度直接当毫秒或显示器刷新率。这里是纸面时间关系，不保证当前相机拥有所有角度；记录若给秒数就先按实际秒数核，不要求读者去找一个未公开的同名播放器菜单。

```
capture_rate=24 frames/s
frame_cycle=1/24 s=41.6666667 ms
exposure=angle/360*frame_cycle
angle=180 -> 1/48 s=20.8333333 ms
angle=45  -> 1/192 s=5.2083333 ms
ideal_projected_speed=960 pixels/s
between_frames=40 pixels; exposure_trails=20,5 pixels
```

## 用理想匀速标记分开两种位移

另在纸面设投影标记每秒横移九百六十像素，则相邻帧参考位置相差四十像素；两种曝光窗口内移动距离分别二十与五像素。后两数是匀速、固定视点和投影速度已知的理想拖迹长度，不是任意实拍边缘的测量值，也不包含镜头失焦与读出偏斜。将每帧位置和帧内移动画两行，不能把二十像素当下一帧只走二十。真实素材若没有速度记录，只观察边缘形态，不以肉眼宽度倒推出准确曝光或宣称摄像机记录有错。

## 导入后先核版本与正常播放速度

通过自己已可用的本地文件或既有来源路径打开第一份，核标题、时长和动作锚点，再打开第二份。当前播放速度保持正常，画面适应方式与输出设备固定，不一边切快门样本一边改倍速或裁切。若导出时一份被转成另一帧率，先在外部记录该变化，不能继续称只有快门一个条件不同。文件能找到、实际能播和记录匹配是三项检查，失败先保留原反馈；不用更换所有引擎或清空整个媒体库来证明素材身份。

## 同动作区域比较连续与静止边缘

顺播两份相同动作片段，先认运动物体，再找同画面静止边缘作参照，记录运动拖迹与背景清楚程度。当前版本若可暂停，就在可重复时点暂停观察；没有逐帧入口不编造逐帧按钮，截图也不自动等于传感器原始帧。较短曝光可能令单张更锐，但正常播放的运动观感未必更连贯，不以更清楚直接判所有片源更好。光线、景深或动作不一致时注明额外变量，不替未记录的条件填相同；这里只描述实际看见什么。

## 显示节奏不能反推快门设置

二十四帧素材在不同刷新率屏幕可能采用不同显示节奏，卡顿、重复显示与曝光拖迹不能只凭一个感觉合并判断。先留在同设备同输出路径比较，实际掉帧或网络等待另记，不从播放暂停的等待时间算拍摄曝光。若只拿两台不同设备各放一份，缺少共同显示条件，结论要缩小范围。已有运动模糊写在素材里，播放器调暗不把它重拍成短曝光；倍速改变播放时间，也不会恢复传感器已经合成到单帧里的所有过程，纸面与呈现分栏保存。

## 按记录、导出和显示三层排查

若算式不符，查角度和秒数单位；若帧率不同，查导出与文件身份；若只有顺播不稳，查同一来源和显示条件。不要把三者都写快门错误，也不为获得二十像素拖迹随意锐化或重编码原件。一次只替换一份有据素材，原对照保存。缺拍摄记录就停止精确反推，可以继续写观察但明确未知项；不要求云映自动读取所有快门元数据或测运动速度。求助用自有短片身份与脱敏设置表，不把他人影片或未授权拍摄作为必需样本。

## 重开交付两张时间账和观察表

保留两份原片、拍摄记录、纸面周期曝光账与实际观看结果，再重开确认仍是同一素材和正常播放状态。验收能解释为何两份一帧周期相同而曝光不同，理想标记四十像素帧间位移与二十或五像素拖迹各指什么。无法执行的暂停、采样和精确测宽不补写通过。以后换帧率或动作重新计算，不能把今天的数值套所有影片；成果是一份有来源、有条件的素材对照，不是云映提供拍摄快门控制、无损去模糊或所有设备真机认证的证明。
