## Prepare an existing accessory and ordinary note

Use an iPad with Jianlai enabled, your own working external keyboard and an ordinary note editor. Preserve a practice copy with the target “蓝天 ABC 12。” and work on a new line rather than in a secure field or important document. Record device, OS, host, accessory model and installed app version if visible. Apple documents external keyboard use and keyboard switching on iPad; controls vary. Without the accessory, record preparation only, not a hardware-test pass.

## Establish an onscreen input baseline

Using controls actually available on your device, show and select the Jianlai onscreen keyboard in the ordinary field. Record theme, Chinese scheme, any candidate area and cursor position. Enter the target, verify the committed text and preserve the original line. If the keyboard is absent, check focus, active keyboard and host support for third-party keyboards before declaring an installation fault or deleting it. Record the initial connection state and any action taken to show the keyboard.

## Connect the external keyboard and observe

Connect your accessory by its own supported method; for Bluetooth, inspect actual system connection feedback. Do not unpair unrelated devices or enter another person’s account. Return to the same field and observe whether the onscreen keyboard remains, whether any input indication appears and whether focus is retained. Results vary by model and OS; do not presume the keyboard necessarily hides, stays visible or selects a specific scheme. External typing does not establish that Jianlai’s onscreen keys appeared.

## Try the system’s actual onscreen-keyboard control

Apple describes ways for some Apple external keyboards to show the onscreen keyboard. Follow the control actually available for your accessory and OS. If a visible switch or show control exists, confirm its meaning, use it and then verify whether the screen keyboard appears and whether it is Jianlai. Do not claim one dedicated key or shortcut works on all accessories. If no clear control exists, record it as not found and leave the step pending rather than trying unknown combinations.

## Compare actual input sources

On a separate line, use the external keyboard if available for the Latin and numeric portion of the target. On another line use Jianlai’s onscreen keyboard only when it is actually visible and selected. Label the source of each line and inspect case, spaces, digits and committed text. Do not require external typing to use Jianlai themes, candidates or haptics. If the external input uses a system or other scheme, identify it honestly. Preserve first results and correct only copies. If a visible input scheme is selected for external typing, separately record its system-displayed name and the actual input process; otherwise leave the path unknown. Hardware, system input scheme and onscreen keyboard are distinct layers, and neither hardware brand nor final characters establish the internal processing path.

## Check retained context during transitions

Compare cursor and existing text before connection, while connected and after showing the onscreen keyboard. Focus, candidates or scheme can change, but record only observed behavior. If the host loses focus, tap the practice line again and record the action. Separate host reflow from input-method display. Verify the target and neighboring text before proceeding; similar theme colors do not establish the active input source.

## Troubleshoot connection, host and input method separately

For an unresponsive external keyboard, check the system connection and accessory. When external typing works but the onscreen keyboard is absent, inspect the actual system show control. If a keyboard appears but is not Jianlai, check the active selection. If only one host behaves differently, compare another ordinary field before concluding universal incompatibility. Change one condition per trial. Secure-field restrictions are separate; unavailable controls, unknown sources and unfinished connections remain pending.

## Deliver the record and restore normal use

Keep connection states, onscreen visibility, actual keyboard name, both original lines, focus-restoration actions and pending checks using only non-sensitive information. Restore your preferred input method and accessory connection, and verify the original note remains. There is no need to remove Jianlai, reset the device or unpair accessories. Apple system documentation and the Jianlai store listing establish only the general scope; no common interface across accessories or completed physical hardware test is claimed.
