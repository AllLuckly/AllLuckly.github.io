## 先固定六个词与普通中文草稿

在新的私人笔记中确认键来真实可用的中文输入状态，记录当前方案、宿主与安装版本，原主题、字体和方向保持。目标依次为行李、银行、重新、重量、音乐、快乐，每词两字；它们是这张卡的完整词，不让一个孤立字代替语境。先在外部保留目标，输入后再独立比较，不能随错误稿一起改掉原卡。官方多语言能力可支持中文录入，但不保证每个方案采用同一编码或每个候选位次一致。若当前不是键来，就先恢复可辨普通输入，不把系统键盘的结果算成本课已完成。

## 用词义和可靠读音资料认三组差别

本卡行李是出门携带的物件，行读xíng；银行是机构名称，行读háng。重新中的重读chóng，重量中的重读zhòng；音乐中的乐读yuè，快乐中的乐读lè。本课所引台湾教育部词典使用繁体字形，读音仅按所引条目记录，不作为各地语音的统一规则；实际目标卡仍采用上面明确列出的简体文字，不能在输入过程中无意换体后还说逐字相同。拼音只作外部读音说明，不要求你把带声调字母键入中文编码区，更不把词典的发音资料说成键来正在朗读或自动纠音。

## 逐词录入第一组并核真正提交

先按自己的真实方案录入行李，若出现候选就选择目标词，确认两字已经留在正文再继续。随后输入ASCII斜线，再录入银行；斜线只是这张卡的分组标记，不是拼音的一部分。使用拼音方案时可以按词读音准备输入，但不要把xíng的声调符号当每套方案必需；使用其他方案则保留自己的真实按键路径。候选里看见银行而正文仍是编码不能算提交完成，最终要逐字检查银与行。找不到目标时保留停止点与实际反馈，不用粘贴整组后称已经验证逐词输入。

## 按同一格式完成重与乐两组

在真实换行后录入重新/重量，再换行录入音乐/快乐，最后一行末尾不另加句号或空格。每组都先提交左词，再认斜线与右词，不能因为重或乐字相同就只输入一次。屏幕宽度导致的自动折行不代替两处源换行，若宿主自动改写分隔，先保存实际结果再修订。目标不是测输入速度，因此可以在每词后暂停核身份，不要求一次连续打完整段。原卡没有读音字母，读音提示留在外部表，不混进最终三行正文；换到另一键盘完成的部分也要单独注明。

```
行李/银行
重新/重量
音乐/快乐
```

## 把字形重复与读音差别分两张表

整张卡共有十二枚汉字、三枚ASCII斜线与两处换行。行、重、乐各出现两次，但每组的左右词、字在词中的位置和读音不同：行李首字与银行末字，重新首字与重量首字，音乐末字与快乐末字。先按位置核文字，再回词义表读音，不能用出现次数对就替代全词正确。本文的计数只适用于这份已列明字符，不定义所有汉字组合或宿主内部换行编码的字节长度。语音不同不要求字符码位也不同，尤其两个行仍是同一个汉字，不能误造两种特殊行字来区分发音。

```
External readings, not keyboard commands:
行李 xíng lǐ / 银行 yín háng
重新 chóng xīn / 重量 zhòng liàng
音乐 yīn yuè / 快乐 kuài lè
```

## 用一处错词控制区分字符与意义验收

另在外部纸面副本把第二行右词重量改成重亮，字数仍是二，整卡总数也可能不变，却不等于目标词；不要把这个故障副本发给任何人。它说明长度和首字正确仍不足，不能据同一个重字就说意义通过。再对已提交真稿逐词比较，必要时在单独修订稿改一处，保留初稿差异。若宿主纠错恰好替换为正确词，记录实际处理路径，这不证明你最初按键已完整正确，也不证明所有多音词都会自动改对。错误控制是外部分析，不是键来生成的测试结果。

## 沿方案、候选与提交正文排查

出错先核当前真实输入方案、整词目标与是否已提交，再看宿主有没有换词；不要先改字体来修读音，因为字形外观不能决定词的普通话读法。若词典显示繁体而目标简体，按原目标核字，不把引用资料字形直接覆盖你的卡。每次只修一个词，保留来源与前后结果，不同时换方案、重置词库和改语言后猜唯一原因。无法完成一词时交可确认部分和停止点，不能为了六项全勾选混入另一输入法结果。没有内置读音评测能力的证据，就不写正在检测声调或给发音准确率。

## 保存六词三行与真实输入路径

交付目标、原始输入、修订稿及六词的实际路径，另列读音资料与未执行项。重开普通草稿后若真核过三行保留，才记重开结果；文字保留不代表输入方案或其他设置全都同步。恢复自己原来语言与方案，练习卡保持私人草稿，不需要联网发送。通过标准是六个完整词与分组格式正确，并能解释同字不同词为何不能只背一个读音。它不是普通话考试、全部多音字词库或所有宿主的候选认证，也不替没有执行的手输、语音与真机操作填通过。
