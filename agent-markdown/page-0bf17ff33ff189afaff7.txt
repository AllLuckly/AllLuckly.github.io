The value of the square root of nine and the numbers whose squares equal nine are related but different questions. Read original radical cards in Book Isle, separating expression values, equation solutions and variable conditions. Use negative substitution to check absolute value. ## 2. Preserve three distinct targets

The cards ask for an expression value, an equation’s solutions, and an expression valid for all declared inputs. Classify the task before answering. Shared squares or numbers do not make them identical. Here sqrt and ^ are explicitly declared plain-text notation for principal square root and exponentiation, not Book Isle commands. ```
Domain: real numbers
Card A: sqrt(9) = 3
Card B: x^2 = 9 has solutions x = 3 and x = -3
Card C: sqrt(x^2) = abs(x)

## 3. A principal square root has one nonnegative value

The principal-root definition in [OpenStax radicals and rational exponents](<https://openstax.org/books/algebra-and-trigonometry-2e/pages/1-3-radicals-and-rational-exponents>) gives a nonnegative value. Thus the radical of nine is three, not plus-or-minus three. Both three and minus three square to nine, but that does not make the radical expression two-valued. Keep the two-number statement for the equation question. Check zero as well: its principal root is zero, so “nonnegative” must not become “always positive.” Explain that an expression value is being evaluated rather than merely memorizing a forbidden symbol.

## 4. Find all values satisfying the square equation

For card B, substitute three and minus three separately; both squares equal nine, so both belong to the solution set. Zero and two fail. If the problem additionally restricts the unknown to nonnegative values, retain only three while preserving that restriction beside the equation. Do not silently remove the negative solution. A compact plus-or-minus notation represents two candidates, not one sign-changing number or an instruction to add them into zero. Two substitution records help distinguish omitted solutions from confusing an expression value with a solution set.

## 5. Check the absolute value using minus three

For card C substitute minus three: square to nine, then take the principal root to obtain three. Replacing the result directly with the original input, minus three, contradicts that calculation. Across real inputs the result is absolute value: the input itself when nonnegative and its opposite when negative. Check positive three and zero too. These cases follow input conditions, not a preferred sign. Preserve the substitution chain rather than writing an unconditional claim that squaring and square-rooting cancel.

In a reverse-order control, taking a principal root and then squaring returns a nonnegative radicand, but a negative input is outside that real-valued chain.
