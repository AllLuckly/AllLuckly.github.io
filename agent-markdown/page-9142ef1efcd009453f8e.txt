Learning path · 70 tutorials

Start with a local video, connect NAS folders and media servers, organise films and series, then check subtitles, audio tracks and playback compatibility.

[Start with the first tutorial](<https://allluckly.cn/en/guides/icouldplay-getting-started/>)[About iCouldPlay](<https://allluckly.cn/en/apps/icouldplay/>)

You provide the videos and servers. First use a familiar local file to check picture and sound, then add a remote source. This gives you a clear comparison if something fails.

**Choose a tutorial for your task**

- [Play from an SMB folder](<https://allluckly.cn/en/guides/icouldplay-smb-nas/>): Open one NAS video and check access and playback.
- [Connect to Jellyfin](<https://allluckly.cn/en/guides/icouldplay-jellyfin-library/>): Check the server address, account and visible libraries.
- [Load SRT subtitles](<https://allluckly.cn/en/guides/icouldplay-external-subtitles/>): Check language, video edition and subtitle timing.
- [Troubleshoot playback](<https://allluckly.cn/en/guides/icouldplay-player-engine/>): Compare engines with the same file and isolate the problem.

Posters and categories describe media; downloads and playback access the content itself. These tutorials check them separately and do not treat a completed scan as proof that every file plays offline.
