用原样相位和幅度模型核2Hz拍频、441Hz载波及绝对包络，把公式峰点与瞬时样本分开。

两个接近频率叠加，可能听到周期性强弱变化，但不能把这种变化直接当成第三条低频音轨。本课外部准备两个正弦和它们的等增益叠加，分别记录公式、素材制作与云映实际听音；没有制音和测量记录就不声称已从任意音乐检出精确拍频。

## 先固定频率、相位和振幅条件

纸面定义x1=0.2sin(2π440t)、x2=0.2sin(2π442t)，t以秒计，两者起始相位均零，拟制作为两秒单声道源。0.2是同一归一幅度约定，不是播放器音量百分比；两段由外部工具生成，云映不被假定具备双音发生器。原音、叠加前后数据和生成记录保留，不拿两首不同音乐的听感冒充这组受控正弦。若工具不能给出目标频率或相位，先完成纸面任务，实际素材条件写未知，不为填满结果表而猜参数。

## 用和差恒等式分开载波和包络

将两式相加得到0.4cos(2πt)sin(2π441t)，其中快速正弦的频率是平均值441Hz；带符号的慢余弦频率为1Hz，但强弱包络看绝对值，周期变成0.5秒，拍频因此为两频率差的绝对值2Hz。先把三个数字的角色分别命名，不把平均值441称拍频，也不把1Hz慢因子直接当每秒只有一次强弱。这个表达是原两音叠加的另一种写法，不表示频谱里自动增添一条独立2Hz音轨，更不是把播放速度调到二倍。

## 核五个包络点而不冒充波形峰值

在t为零、0.25、0.5、0.75、一秒时，绝对包络依次是0.4、零、0.4、零、0.4。这些是包络的值，不是原叠加样本在这些瞬间都达到同样数值：例如t为零时两个正弦都为零，瞬时样本为零而包络最大。把波形值和包络值分成两行，是本课重点检查。cos负号翻转快速因子的极性，不把负包络当负音量；实际响度变化与设备条件另记，不能只看五点表便宣称所有听者都已听到同样两次脉动。

```
t in seconds; both sources start at phase zero
x1=0.2*sin(2*pi*440*t); x2=0.2*sin(2*pi*442*t)
x1+x2=0.4*cos(2*pi*t)*sin(2*pi*441*t)
absolute envelope=0.4*abs(cos(2*pi*t))
t:                  0     0.25     0.5     0.75     1
absolute envelope:  0.4   0        0.4     0        0.4
actual sample at t=0 is ZERO, not 0.4
beat rate=abs(442-440)=2 Hz; carrier=(440+442)/2=441 Hz
control440+440: no slow beat envelope
control440+443: beats3 Hz; carrier441.5 Hz
```

## 做同频与频差改变的两个对照

第一份对照将两个频率都设440、相位仍相同，叠加为0.4sin(2π440t)，没有本例慢强弱包络；不能把音量更大误称拍频更快。第二份只将442改成443，频差变三，模型拍频为3Hz，平均载波为441.5Hz，需重写包络点，不能继续套0.25秒的零点。两个副本分别保存而不覆盖原440/442材料；若同时改振幅或相位，就要新增条件栏，尤其不再用完全抵消的理想零点当未知录音的必然结果。

## 外部制音时保留加法而不隐含归一化

若具备外部工具，按原两式制作相同采样率、相同时长的源，叠加时记录是否存在自动归一化或限幅。本例理想绝对峰上界不超过0.4，足以用适中制作电平展示，不必将设备音量拉高。可把原两音、叠加和两个对照的标签烧入自己的说明视频，保留外部工程及导出转换资料；若实际只做了纸面计算，就不把几行公式当成音频文件。制成的声音与屏幕包络图还应核同一时间起点，不能任意移动图再说已验证相位。

## 在云映分开单音与双音听音记录

通过已有真实来源打开成片，先核当前标签，再在正常速度、固定输出和舒适音量下依次听原音、叠加与对照。只记录是否能听到强弱变化，不要求凭耳朵确认441Hz或逐毫秒零点；系统处理、压缩和实际制音误差均可能影响效果。若只一只耳机或输出变了，另建条件，不把新听感与旧记录混成同一次实验。云映播放成功只说明当前素材路径可用，不证明它自动分析出了拍频或为双音新增了第三条媒体音轨。

## 按频差、相位和数据身份排障

若包络每秒被记一次，查是否漏取慢因子绝对值；若五点中把零秒样本写成0.4，查是否把包络当波形。若真实叠加没有预想强弱，先回外部确认两份频率、相位、增益与是否被自动处理，不同时改所有设置逼出结果。每次只修一个故障副本并保留原始两式。拍频与节拍器每分钟拍数属于不同概念，虽然都可计次数，也不能把2Hz直接当音乐速度或一段对白中两个说话者的数量，标签与数值各有来源。

## 重开交付频率、包络与实际观察

保存440/442原式、441载波、2Hz拍频、五点包络表和两个对照，重开先核时间单位与起始相位没有改变。实际重开云映时只重复具备的素材和条件，未执行的制音、导出或听音明确待做。验收能解释1Hz慢因子为何对应2Hz强弱包络，以及零秒包络最大为什么样本仍为零。原录音工程与未知处理环节都保留，不声称内置频谱检测、自动分轨、听力测验或所有播放设备都保留精确拍频细节。
