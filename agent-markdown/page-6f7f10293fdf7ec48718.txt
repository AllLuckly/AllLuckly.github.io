Use a self-written passage to compare system text size and visible reader settings in EPUB and PDF separately.

## Prepare two owned samples with the same text

Prepare an EPUB and a PDF you may use, each containing the same short passage, for example “Wind passes the doorway; the light is still on.” Include the same title and a recognizable chapter marker in both files, place a marker at the top of the PDF page as an upper-edge reference, and keep originals and backups. PDF pages may have fixed layout while EPUB may reflow in a reader. Compare observed display only; do not assume content or text size automatically synchronizes between formats.

## Record original system and app states

Record device, system and installed Book Isle versions, current system text size, display settings and any actually visible reader font-size or zoom state. Make sure the user knows how to restore original values before changing anything. Apple documents adjustable system text size, but apps and content may respond differently; do not convert a system value directly into a book font size.

## Establish EPUB and PDF baselines

Open the two samples separately in Book Isle and confirm title, content and file format. Record chapter, line count for the passage and surrounding text visible on one screen. Line count and perceived legibility are observations under current window conditions, not precise font measurements. If one file cannot open, diagnose format and import rather than substituting the other result. Preserve existing reading positions and notes.

## Change only the system text setting

With the user’s agreement and a known restoration method, change the system text size by one distinguishable step using the current system interface. Do not simultaneously change reader settings, device orientation or window size. Return to the EPUB and observe shelf labels, reader menus and body text separately. The same system setting can affect some interface regions and not others; a changed menu does not prove the body changed.

## Compare the PDF page display

Open the PDF containing the same passage and observe menu text, text on the page and zoom state, checking title and chapter to avoid the wrong file. If a whole page image grows because the window or zoom changed, do not conclude that system text size modified text inside the PDF. Record visible lines, cropping and any need to scroll horizontally, marking unavailable evidence unknown.

## Restore the system baseline before testing reader settings

Restore the original system text size first and confirm the system interface state. Only if Book Isle actually presents a comprehensible font-size or zoom setting, record its original value and change one step while observing EPUB body and menu. For PDF use only page zoom controls actually visible. Mark an absent entry unavailable rather than assuming one font-size control applies to every format or modifying the original files to produce a change.

## Check content and reading position

Compare whether the short passage remains complete, the chapter position is identifiable and reflow changed line count or page number. A different page number does not automatically mean text changed, and window cropping does not prove loss. If the reader jumps, first record the actual first result and file identity; do not edit bookmarks and then claim position never changed. Restore the user’s original reading settings as needed.

## Use four result rows rather than one overall judgment

Make rows for system text setting, Book Isle menu, EPUB body and PDF page, with baseline, observation after the system change and observation after restoring it and changing an in-app setting. If a system change enlarges menu labels but leaves the PDF page unchanged, record those outcomes separately; do not claim the whole book lacks accessibility support. If an EPUB passage changes from three lines to four, also check actual window and font-size state. If orientation or width changed simultaneously, that trial cannot be attributed to one setting. Mark unobserved areas unknown instead of filling them with expected values.

## Avoid mistaking reflow for missing text

When an EPUB reflows, one sentence can cross different lines or pages. Locate the chapter and complete short phrase first, then check whether surrounding text is readable. Enlarging a PDF page can put an edge outside the window; inspect it using actually available scrolling or zoom rather than concluding that file content was deleted. If the passage really cannot be found, check the same original in a trusted external reader, then record the Book Isle file label, current settings and first observation. Do not overwrite the original to fix display.

## Recheck the baseline after restoration

After restoring the system text setting, return to the same device orientation and window width and reobserve the original menu and EPUB passage. If they still differ from the first baseline, check whether the actual reader setting or zoom was restored before concluding that book content changed. Use PDF page edges and top markers as references and a bookmark or chapter anchor to return to the same location. For feedback provide only self-written sample content, versions and reproducible steps; other private books, notes and device notifications need not be public.

## Organize the comparison and restore states

Make rows for system setting, Book Isle menu, EPUB body and PDF page with baselines and observed changes, marking actual and untested steps. Restore original system and app values and confirm both original files and important notes remain. If the version lacks an adjustment, preserve that observation rather than filling in expected behavior. This exercise uses public reading capabilities and Apple guidance and claims no physical-device layout or accessibility test.
