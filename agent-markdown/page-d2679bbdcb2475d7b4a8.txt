## 理解空白与换行

W3C CSS Text 说明 white-space 控制空白如何折叠以及是否允许软换行：normal 通常折叠连续空白并允许换行，pre 保留空白和强制换行，pre-wrap 保留空白且允许换行。规范描述样式行为，不保证书屿一定采用书籍中的每项声明；源码空格、样式和屏幕显示应分开记录。

## 准备授权短样本

选择自己制作或出版者允许检查的 EPUB，优先包含一段自制文字、可辨认的连续空格和一处明确换行。记录文件版本、来源、预期显示及原件位置，另存备份。不要公开受版权限制的原书文字；许可不允许检查内部结构时，只观察可见画面并将源码检查记为未执行。

## 记录初始阅读界面

在书屿打开目标章节，用自制短句定位样本，记录当前字号、设备方向、行首和行尾及空白大致位置。屏幕看不到连续空格时，不立即断定源码缺少它们；也可能受样式、宽度或阅读器行为影响。无法找到章节时先检查文件是否完整与目录是否正确，不修改原书或删除原有笔记。

## 检查源码和作用样式

仅在许可允许且具备工具时检查 EPUB 副本，定位目标 XHTML 和实际引用的 CSS。记录目标文字的空格与换行、相关选择器和 white-space 值；同一章节可能引用多个样式或有继承覆盖。normal、pre 与 pre-wrap 是不同声明，不能凭一个文件名或单个搜索命中断定最终生效值。没有源码权限时写未执行。

## 只改变一个阅读条件

在书屿实际提供选项时只改变字号或设备方向之一，保持同一文件与段落不变。重新定位短句，记录屏幕换行位置与空白是否变化。可用区域改变会影响软换行，但不应自动被描述为文件中的字符发生变化；无法改变设置时记未提供，不安装未知工具或修改系统安全设置。

## 比较明确换行和自动换行

结合有权查看的源码或出版者说明，分开记录样本中有意设置的换行与因屏幕宽度产生的换行。若没有结构证据，不要仅凭两次画面就断言某个换行一定来自换行标签或 CSS。阅读时确认段落前后内容仍连续；一行位置变化不单独证明文字丢失或重复。

## 检查复制与搜索的边界

如果书屿实际允许选择、复制或搜索短句，在私人笔记中记录得到的文字，再与授权样本对照；不得公开粘贴受限制内容。复制结果可能受应用、操作系统和目标编辑器共同影响，显示出的空格数量不自动证明源文件被修改。功能不可用或不能确定时直接标为未测，不使用绕过工具。

## 独立对照并排查

可在许可允许时用可信阅读器打开相同副本，记录工具版本、可用宽度、字号与画面。不同字体和阅读区域可能影响换行，差异本身不证明某个应用出错。若样本完全不显示，先核对文件、章节路径和读取权限；若只是空白不同，再检查样式范围和阅读条件，一次只改变一项。

## 恢复和记录

恢复原字号及设备方向，确认原件、书签与笔记保留。结果表分别写源码是否可检查、样式声明、两次显示、复制或搜索结果及未执行原因；分享前删除私人路径与受限文字。本文依据公开标准及应用资料，不声称设备实测，也不保证书屿实现某个 CSS 值。

## 建立两种自制格式的对照

若出版者提供可授权检查的两段自制样本，一段使用普通段落，另一段保留明确空白，可分别记录其结构、样式与屏幕结果。两段文字本身的长度和位置可能不同，应先确认每段标记及预期；不要把两段不同内容直接比较成相同条件。没有可用对照时保留单一样本的观察，不能自行改写唯一原书制造实验。

## 分清源码行尾和强制换行

XHTML 文件在编辑器中看到的源码换行，可能作为普通空白参与排版；强制换行也可能来自元素或适用的 CSS。只有在获得源码与样式证据时才能记录具体结构，不能仅凭编辑器中一行结束就认定屏幕必定换行。对照时先记下原文标记、实际元素及阅读画面，不要删除空行来“修复”无法确认的问题。

## 留意空格和制表符

连续空格与制表符都属于空白，但它们的可见宽度和处理受样式与排版环境影响。若授权样本含制表符，可在副本中记录字符类型，不要用屏幕上大致宽度推断必定有几个空格。复制后的文本也可能在目标编辑器中显示不同；记录源文件、书屿画面和粘贴结果三个阶段，而不是将任一阶段当成另外两个阶段的证明。

## 保存可复查的结果

将出版者预期、源码声明、两次阅读条件和实际换行分别填入表格；其中任何部分无法确认时写未知或未执行。不同的屏幕尺寸、字体和应用设置可能共同改变布局，所以比较时应保留这些条件。若观察与预期不符，可以向有权维护文件的人提供自制示例和精简记录，不分享私人 EPUB、认证信息或未经许可的大段内容。

## 一组可复现的自制样本

自制章节可用同一字符串 A、连续三个 U+0020 空格、B，分别放入受 normal 和 pre 样式影响的段落。CSS 规范预期 normal 折叠连续空白，而 pre 保留空白；在书屿分别记录 A 与 B 的可见间距，并确认样式规则实际针对对应段落。若不能检查源文字或切换宽度，写未执行；该示例不保证应用支持任一值。
