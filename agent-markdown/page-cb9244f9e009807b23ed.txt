用键来输入一条离线 Markdown 链接源稿，逐项核对方括号标签、圆括号目标与原样地址。样本使用保留的无效域名，不发送请求、不点击试访问；最终成果是源稿与纸面解释，不声称宿主已渲染成功或链接可用。

## 一、建立只保存源稿的练习区

先选择自己的普通文字草稿，确认可以查看原始字符，而不是只有富文本链接标题的输入框。新建本地练习副本，将任务写成“准确保存一条链接语法，不访问目标”。本次地址是专门为离线说明准备的保留无效域名，不代表真实网站、作者服务或待登录入口；即使宿主把它显示成可点项目也不点击。把目标文字、人工解释与宿主实际显示三栏分开。若宿主只能自动生成富文本且无法查看源稿，就另选能保留原字符的私人编辑区，不能以一枚好看的链接卡片替代这一任务要求，也不必为练习注册新服务。

## 二、输入标签，再接目标括号

确认键来后，按实际英文与符号键面输入下方唯一目标，先完成一对方括号及其中的标题，再紧接左圆括号、地址与右圆括号。方括号后与圆括号前没有空格，标签内部在英文单词和零七之间恰有一个半角空格；零七是标题的一部分，不当作需要去零的数值。正文行不含代码围栏、引号或句末标点。若尚有组合未提交，先完成提交再逐字核对，不因为预览区出现类似标题就跳过实际源稿。键面的符号位置按安装版为准，本文不编造专用 Markdown 模式、自动补括号按钮或快捷模板。

```
[Draft 07](https://example.invalid/notes)
```

## 三、画出两种括号各管哪一段

在纸上为方括号与圆括号分别画框：方括号里的内容是链接文字，圆括号里的内容是目标地址。按 CommonMark 的内联链接说明，这个简单样本没有额外标题参数，也不涉及嵌套标签、转义括号或相对地址解析。先点数各一对括号，再确认次序是闭方括号紧跟开圆括号，不能把两者混成同一种形状。括号配对正确也要核内容边界，末尾右圆括号应在路径之后，不能把它复制进地址本身。纸面解释写在单独一栏，不追加到源稿尾部；否则看似注释的字也会变成另一段输入文本。

## 四、逐段核对地址而不访问

把目标地址依次指读为协议部分、两枚斜杠、主机名、路径前的斜杠和路径单词，核对英文拼写与半角句点。保留域名中的无效后缀原样，不换成真实商业站点或自己的私有地址；RFC 2606 对该保留后缀的说明是选择这个样本的依据，不是需要实际查询域名的理由。源稿里不加空格，不把路径大小写随手改掉。核对工作只对照文字，不打开浏览器、不让读者通过点击判断“是否成功”。若想将来用于真实文章，应在另一个正式任务里核对授权目标与发布效果，本课的离线结果不承担那项验证。

## 五、修复断开的括号连接

在新副本中只把闭方括号与开圆括号之间加进一个空格，原正确行保持不变。观察字符账就能指出与任务目标的差异，不必调用渲染器证明它是否会被某种方言容忍。按本次无空格约定，用宿主插入点或选区只删这一个空格，再核标签内部应保留的那一个空格没有被一并删掉。这个对照专门训练同是空格却处在不同位置的区别；全局删除所有空格会损坏标签，不能算修复成功。若选择范围不确定，取消选择后重来，并在修复记录写明删的是连接处而非标题内部。

## 六、把纸面含义与宿主显示分开

在人工解释栏写明预期可见文字是英文标题与零七，预期目标是圆括号内的完整地址，这是按所引语法阅读的结果，不是已经运行的解析报告。宿主可能保留全部源字符，也可能自动把部分内容识别为链接，甚至根本不支持 Markdown；只记录自己真正看见的显示状态，不把其中一种当作键来承诺的行为。本课不进行预览解析或网络测试，验收中将渲染与访问写为未执行。键盘皮肤中的字体也不负责把源稿转成网页，宿主显示有变化时首先找它的文本模式与自动格式设置，而不是假定输入法自带发布功能。

## 七、排查括号、替换与复制范围

若原文对不上，先核两对括号与连接处空格，再核标签里的零与字母，最后比较地址各段。全角括号或弯引号的出现属于字符替换问题，不由“长得差不多”豁免；若复制后多了说明文字，检查选区是否包含下一段，不要贸然重打整条地址。宿主只显示标题时，应回到可查看原文的位置；若找不到便说明该宿主不适合本课源稿验收，保留现有副本换普通编辑区。每次改变一个因素再对照，不通过试点链接探测网络。原始文本、显示状态和实际访问是三类证据，最后一类在这次练习中始终没有执行。

## 八、交付离线源稿与边界卡

最终保存一行干净原文、一份括号边界图和一张检查卡，列出标签内部一空格、连接处无空格、完整目标地址与未执行的渲染及访问。重新打开草稿后可再复制核对字符，确实完成才记保存通过；不要只保留富文本截图而丢掉源行。把本次实际宿主与输入状态写在旁注，下次出现不同显示仍能回查。这个成果解决的是结构化文字的准确输入与解释，不证明无效域名能用，也不证明任何 Markdown 宿主都兼容；以后换成真实目标时，应建立新的校对与发布检查，不能沿用本次未访问的状态冒称链接已上线。
