Learning path · 40 tutorials

Learn shapes, fills and strokes, then edit paths and nodes, organise layers, add gradients and text, and choose SVG, PNG or PDF for delivery.

[Start with the first tutorial](<https://allluckly.cn/en/guides/vectorpaint-getting-started/>)[About VectorPaint](<https://allluckly.cn/en/apps/vectorpaint/>)

If vector drawing is new to you, make a small geometric icon before working with paths and nodes. Once object controls feel familiar, combine colour, text and layers in a design exercise.

Before delivery, find out whether the recipient needs editable paths or an image to display. SVG and PDF may also contain raster images; an export format does not automatically change the original objects.
