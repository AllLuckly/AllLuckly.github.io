DEVELOPMENT NOTES · 15 articles

From Swift 2 and Swift 3 notes to the Objective-C runtime and design patterns, these articles preserve the process of understanding language behaviour. Syntax changes; asking why a piece of code executes this way is still useful.

## How to read this collection

1. Start with delegation, blocks and common Swift pitfalls. Distinguish values, references, closure captures and object lifetimes.
2. For runtime articles, work through properties and ivars, messaging, then dictionary-to-model conversion. Separate what the runtime can do from what your project actually needs.
3. Compare templates, singletons, flyweights and responsibilities against a concrete duplication or shared-state problem before choosing a pattern.

These notes date from 2015–2017. Their examples have not been rerun for this archive update. Check the dates and version notes before applying the ideas to a current project.
