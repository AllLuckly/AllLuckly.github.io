A vertical comic may feel too wide on a tablet, yet narrower display can leave awkward swipe areas. Compare margins, width limits and side gestures separately in continuous vertical reading. Display space changes neither crop the source nor regenerate its images.

## Choose a tall page with text and a wide scene

Use a loaded tall page containing dialogue and a wide scene. Keep orientation and viewing distance fixed, recording top, middle and end anchors. Observe text size, movement and side access before changing anything. The goal is readable complete artwork with usable gestures, not filling every screen pixel.

## Confirm the applicable vertical mode

Verify a supported continuous vertical mode and inspect its margin and width controls. Gallery image count is a different setting. Skip absent controls and record mode/version. Use the intended book scope if needed, then compare one parameter at a time at the same dialogue.

## Change margins gradually

Record the margin value and increase it modestly. Recheck the same lettering and the full wide scene, including access to top and bottom. Large margins can make text too small. Percentages describe display behaviour rather than exported dimensions and should be re-evaluated after a screen or orientation change.

## Check width limiting separately

With margins fixed, compare width limiting on and off across small and large images. Observe actual scaling without assuming a universal pixel cap. If margins already solve the problem, another restriction may be unnecessary. Check ordinary dialogue too so a solution for one oversized image does not shrink the whole chapter excessively.

## Test scrolling from the side space

If limiting creates side space, inspect the margin-swipe option and compare controlled swipes from the margin and image. This does not change story direction. Investigate shortcut or system-edge conflicts separately. If unavailable, ordinary image-area scrolling is sufficient; source cropping is unnecessary.

## Verify the return from detail zoom

Zoom into small text, restore the whole image and continue downward. Check scale, position and side gestures after returning. Practise zoom focus, restore and scrolling separately before combining them. Reduce shortcut overlap if necessary and compare the same content throughout.

## Recheck after rotating the device

Rotate to the other orientation you actually use and inspect the same passage. Different proportions can require a different choice. Use supported device or book scopes as appropriate and check another page-based comic for unintended global changes. Reopen once and retain only meaningful values with their reasons.

## Acceptance and common misunderstandings

Finish with readable dialogue, intact scenes, reachable image sections and dependable gestures. Source whitespace and display margins are different; width limiting can legitimately make letters smaller. Restore recorded values for isolated retesting rather than repeatedly repackaging files. Preserve the original artwork unchanged.
