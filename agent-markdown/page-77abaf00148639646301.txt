Body-start landmarks and chapter contents have different roles. Check publication structure, then observe the actual opening position in Book Isle.

## Understand three navigation roles

In EPUB 3.3, toc is the primary chapter hierarchy, page-list identifies static page boundaries, and landmarks mark important structural locations such as content start or contents. Landmarks are optional; the specification recommends bodymatter and toc when available. Reading-system behavior varies. A marker in a file does not prove Book Isle offers a dedicated control or automatically skips front matter.

## Prepare an authorized sample

Choose an EPUB you created or are authorized to inspect internally, ideally with a cover, front matter, contents and body. Preserve the original. Record title, edition, front-matter heading, first-chapter heading and a short self-made marker for the opening sentence. Without inspection rights or a suitable sample, observe contents and reading order in Book Isle only and mark the landmarks check unperformed. Do not download unknown-source files.

## Map the structure first

Write cover, front matter, contents and chapter one in four rows with titles and approximate order. The first contents entry may be front matter or chapter one; the actual body-start marker must be assessed from the file, not assumed to equal the first entry. Record identities of similarly named shelf editions so the comparison does not accidentally open a different copy.

## Optionally inspect the navigation document

An authorized file owner copies the EPUB to an isolated location and uses a familiar archive tool to inspect its navigation document. From package information identify the resource with the nav property, then inspect whether a nav with epub:type landmarks exists and whether links carry toc or bodymatter types. Read the copy only; do not edit or repackage the original. Mark unknown or missing when the document, link or target cannot be confirmed; do not assume the app consumed it.

## Verify links and targets

If landmarks toc and bodymatter links are confirmed, record sanitized relative filenames and fragment identifiers and verify targets exist in the copy. If they point to different places, record the contents and body titles separately. Mark file structure pending if a target is missing, cannot be opened or its path is unclear. Link text is not identical to target content; do not write a guessed target back to the publication.

## Observe the first opening in Book Isle

Import the authorized copy into Book Isle and open normally, recording whether the first visible position is cover, front matter, contents, chapter one or elsewhere. Existing reading progress may reopen a prior location, so record whether the book was read before. Do not clear production progress to force a first open. If a genuinely new test copy cannot be safely established, mark first opening unverified.

## Return to the body using contents

Use the contents control actually offered by Book Isle to open chapter one, verify title and self-made opening marker, then return to front matter or contents. Record control name, target and readability. If no contents control is visible, locate by sequential reading; the specification does not prove an app has a body-start button. A working chapter link does not alone prove landmarks were used, because contents and landmarks are distinct structures.

## Compare starts without inferring implementation

If Book Isle opens at the body and the file has a bodymatter marker, record that the positions coincide; this alone does not prove the app used the marker, since restored progress or another opening policy may apply. Starting at the cover does not by itself invalidate the EPUB marker either. Keep file inspection, app display and conditions in separate columns. Without file evidence, leave the mechanism unknown.

## Investigate navigation anomalies

If a contents link opens the wrong chapter, confirm the expected file and edition, then compare the same authorized copy in a reliable reader. Record link, expected title, actual title and time. Do not modify XHTML or delete bookmarks in the sole original. If sequential reading works but no separate landmarks control exists, use the actual chapter navigation or a personal bookmark where suitable.

## Document evidence for optional structures

EPUB permits a navigation document without landmarks; this is distinct from the required primary contents navigation. Separate checked and absent, not inspected, and present but not displayed by the app instead of calling all three unsupported. A found marker still needs target and edition verification in its own row. Stop internal inspection if the archive cannot be safely read, is protected or the publisher restricts handling.

Associate the inspected copy with the item imported into Book Isle using title, edition, contents order and the owner’s copy record; similarly named files can differ. Do not call a restored position a first opening or delete existing books, notes or progress to force a reset. A true new-import comparison requires an authorized test copy with no existing record.

Finally compare at least contents and chapter-one targets. Record position before, action, actual title and return method separately. One successful jump establishes that observation only, not correctness of every chapter link. Mark unchecked chapters unperformed.

## Restore and hand off

Preserve the original EPUB and prior reading records. The owner handles an isolated copy under their normal policy. Record sample identity, whether navigation structure was inspected, confirmed toc and bodymatter targets, actual Book Isle starting position and unperformed steps. Exclude long copyrighted passages and private paths. This guide uses W3C specifications and claims no physical-device test.
