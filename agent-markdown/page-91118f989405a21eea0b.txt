## 2. Confirm computer and device connectivity

The public description requires the phone or tablet and computer to use the same Wi-Fi. Check their actual connected networks rather than merely looking for wireless icons. Guest networks, company networks or isolated hotspots may prohibit communication even under the same network name. Follow the network’s management rules; do not disable protection or change remote configuration for one song. Keep device, network name and connection details in a private local note. Connectivity confirmation is a prerequisite, not transfer success: the webpage and file still need their own checks.

## 3. Enable transfer and read the current address

Open the installed version’s Wi-Fi-transfer page, enable it and read the complete address it currently displays. Include any port. ## 5. Upload once and wait for real feedback

Use the page’s actual file-selection or upload control, select this one track, check its name and count, then submit once. For an inaccessible page, check the current address, same-network condition and whether transfer remains enabled. For an upload that fails, inspect size, readability and the browser’s actual error.
