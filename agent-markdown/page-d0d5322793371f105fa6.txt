以半径四的反演圆换算五组坐标，检查同射线、距离乘积与被排除的原点。

本课把直线x=2上的五点手工反演，再画到同一坐标系。图的目标是说明距离倒数怎样改变位置，以及为什么结果圆上的原点只能画成空点。计算与证明先在纸面完成，VectorPaint负责图形、辅助线、节点和文字，五个示范点不会让应用自动求出整条曲线。

## 确定反演中心、半径和允许输入

新建横向练习页，写O=(0,0)、反演半径R=4，并把“输入点不得为O”放在题目下面。反演要求原点、输入点和输出点同在一条射线上，且OP乘OP′等于16；不是把横纵坐标分别取倒数。先用P=(2,0)计算输出(8,0)，观察离O较近的输入被送到较远处。给原始点、像点、参考圆分三种线型，颜色只作辅助，不让同色线的交叉被误认作额外条件。把工作文件保存为原生格式，另留一份空白坐标页。

## 用统一比例搭出可核对的坐标页

建议画布2400×1800，屏幕原点取(800,900)，数学每单位在两轴都用140像素；屏幕纵坐标向下，所以采用下方换算式。先画细坐标轴和每单位刻度，再画以O为心、屏幕半径560像素的参考圆。直线x=2放在屏幕X=1080处，延伸线用虚线，不把画布边缘当作数学端点。若当前界面没有对应数值栏，用网格和参考线手工定位并标出近似；不凭未见过的控制项声称可输入公式自动成图。

```
R = 4; O = (0,0); input P != O
T(x,y) = (16*x/(x*x+y*y), 16*y/(x*x+y*y))
screen(X,Y) = (800+140*x, 900-140*y)
```

## 逐行算五组点而不跳过负号

为每个输入先算平方和d=x²+y²，再把两个坐标同乘16/d。下方五行保留正负配对；(2,4)的d为20，所以得到(1.6,3.2)，不是把4直接改成四分之一。原始点上下对称，像点也应上下对称；负y输入仍产生负y输出，不穿到相反射线。先在纸上核分数8/5与16/5，再用小圆点逐一落图，旁边写同一字母加撇号。不要先连一条好看的弧再把计算值改成弧上位置。

```
input     image          image screen
A (2,0)   (8,0)          (1920,900)
B (2,2)   (4,4)          (1360,340)
C (2,-2)  (4,-4)         (1360,1460)
D (2,4)   (1.6,3.2)      (1024,452)
E (2,-4)  (1.6,-3.2)     (1024,1348)
```

## 把同射线与距离乘积分开核验

选B=(2,2)与B′=(4,4)，连接O到两点，看它们都位于第一象限同一方向；两段长度分别是平方根8和平方根32，相乘为16。再看D=(2,4)与D′=(1.6,3.2)，比例为0.8，同样为正，因此输出在输入与O之间。给这两例各留一条算式，不以画面大致共线代替距离条件。参考圆上的点应保持原位，但这句话不表示每个输入都在参考圆上，也不要求五条连接线长度相等。 还可比较原始A、B的间距为2，而像A′、B′的间距为4√2，两者不同。这个数值对照说明反演不保持一般两点距离，不能用旋转或镜像工具把整个输入图层一次搬过去。若用连接线展示对应关系，端点只能指向各自算出的像，不能拿相同长度作匹配规则。

## 由代数求像圆再添加轮廓

把像点记为(u,v)。由u=32/(4+y²)、v=16y/(4+y²)得到u²+v²=8u，整理为(u−4)²+v²=16。于是添加数学中心(4,0)、半径4的圆，屏幕中心(1360,900)、半径560。用轮廓而非实心填充，让原始直线和五组点仍可见。五点落在此圆上只是抽查；整条直线的结论依赖这个对任意有限y成立的推导。原点以外的圆上点也可反演回x=2，因而不是只得到五点之间那段短弧。 反向检查也可写成16u/(u²+v²)=2，使用的是圆方程与u不为零；该圆除O外都有u大于零。这样同时说明其余圆上点都有有限原像，也指出为何反向论证不能把O代进去。

## 在原点明确画出不能补上的空点

像圆经过O，但反演公式在O没有定义，而且任何有限输入的像都不会等于O。把圆在该处的点位盖出一个小空心标记，并直接写“排除O”；这个标记是集合说明，不是把附近一段圆弧也删除。随着直线上y的绝对值增大，像点逐渐靠近O，有限值仍不等于O。检查说明文字没有把极限说成实际输入的输出。也别把参考圆和像圆混为一圆：它们半径相同，圆心分别是O与(4,0)，在图上位置不同。

## 用反向代入定位作图错误

若B′出现在右下，先查屏幕Y的减号，不重算成负数学y。若D′没有落在同一射线上，查是否给两个坐标用了不同倍数；若五点都偏离像圆，查是否误把16写成4。挑D′重新反演，平方和为12.8，乘数为1.25，必须回到(2,4)。如果数值对而轮廓不合，只调整图形定位或比例，保留原始算表。把出错层另存副本，恢复正确稿后再检查一次，避免为了遮错移动原点或改变一侧刻度。

## 重开核点、空点和导出边界

关闭再重开原生文件，逐数确认五个输入和五个像的标签仍可读，两个圆心未合并，O仍为空点且有文字说明。导出SVG或PDF作为阅读版后，再检查细虚线、撇号和负号没有消失；栅格预览中的小孔变小不等于数学集合改变。交付图时附坐标表、屏幕比例、像圆推导和反向抽查，说明绘图是手工近似，公式才规定精确对象。没有实际重开或导出的操作须留作待做，不把本文示例写成已在某台设备上验证。 阅读版另核D与E的标签分别在上、下方，不被原始直线遮住。辅助圆线宽宜低于像点标记，关掉辅助层后仍须能从文字识别反演半径和被排除点，避免图层隐藏也把必要条件一起藏掉。
