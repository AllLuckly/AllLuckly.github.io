Use five fictional observations to practise equal x-spacing, a zero-based y-axis and verified point-to-point connections.

English translation of the [Chinese original](<https://allluckly.cn/guides/vectorpaint-coordinate-line-chart/>), translated on 2026-11-03. Original publication dates, attribution, code and version notes are retained.

Every turn in a line chart should have a defined numerical source. Plot fictional values 3, 6, 4, 8 and 5 manually in VectorPaint, checking axes and correspondence. The app is not performing statistical validation; an attractive connected line does not establish that its data is correct.

## Record five observations and their scope

List observations one through five as 3, 6, 4, 8 and 5 outside the app, defining one unit and measurement basis. This exercise uses equal observation spacing; do not silently treat unequal durations as equal. Reserve axis-label room on a 1200 by 800 pixel canvas and mark the dataset fictional. Check order/range and choose a 0–10 y-axis before drawing rather than truncating it to amplify variation. Maintain the same definitions in titles and notes.

## Build verifiable axis spacing

Draw axes and equally spaced y ticks at 0, 2, 4, 6, 8 and 10, plus five equally spaced x positions. Align reference lines with ticks, not merely tidy-looking labels. Values 3 and 5 lie halfway between adjacent even ticks. Use grid and duplication references as needed. Manually drawn reference lines are artwork objects and export with the work. Check the actual export behaviour of the grid and native guides before deciding what remains. Verify the coordinate system with data hidden before placing observations.

## Plot each value independently

Place identical marker circles at heights 3, 6, 4, 8 and 5 in sequence, aligning their centres rather than edges. Audit each against the list before connecting them. Read x labels and y heights individually and confirm observation four is highest. Use supported position controls where useful, or consistent grid references, without claiming unverified numerical precision from manual dragging.

## Connect observations without invented turns

Connect observations in order with an open, unfilled straight-segment path through marker centres. Do not close it into an area or smooth the turns for decoration, since smoothing can imply unprovided behaviour between observations. Other interpolation would need its own rationale. Keep the line behind markers and labels and verify its sequence, including endpoints and stroke-cap effects.

## Label values without overstating conclusions

Place values near points without covering the line and leave room above the maximum. A single series may not need a complex legend, but units, scope and fictional status remain essential. Describe the observed sequence without claiming long-term trends or causation. Real month labels require verified spacing and sources. Use consistent label sizes instead of typographically exaggerating the maximum.

## Test a single-value revision

Change the third value from 4 to 7 in a test: update the list, marker, line node and label. Check both adjacent segments while keeping other observations unchanged. Labels alone or marker movement alone would leave incorrect artwork. Ordinary paths are not bound automatically to a data table. Restore the original example or retain a clearly named revised dataset, using this one-point test to assess maintainability.

## Audit axes, points and text in the export

Save and reopen the export, reading the y-axis, then each observation and value, then tracing the line. Check type, markers and subordinate grid weight at delivery size. Keep axes, units and scope when embedding in reports rather than cropping the line alone and retaining the same interpretation. Name data revision and size clearly and preserve editable structure for future point changes.

## Diagnose apparent errors point by point

If the maximum appears at observation three, inspect x order, path sequence and labels before flipping the line. For a systematic vertical offset, check zero and unit spacing. Confirm centres, not marker edges, define coordinates. Diagnose missing output lines through stroke and contrast rather than adding an inappropriate fill. Repeat independent point reading and the revision test until every position has an explicit source value.
