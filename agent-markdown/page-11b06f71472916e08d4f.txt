固定220Hz参照，核四个频率的比例与log2音程，分开频率、音量、节拍和实际听辨。

频率相差同样的赫兹数，不代表音程也相同。本课用四个原创频率做外部比例卡与自制说明片，在云映按标签跟听；频率单位、参照频率与实际音量分开，不把换播放速度当成制作四段独立频率素材的方法。

## 先固定四个频率与参照身份

设四段素材的目标频率为220、440、660、880Hz，以220Hz作共同参照，每段拟为三秒、同一波形类型与相同制作增益。频率来自外部生成记录或已知原件，不从歌曲标题或人声听感猜填。没有制音工具可先做纸面卡，把听音留待做；也不把同一文件改四个名字当成四份频率证据。这里采用教学数值而非一套完整调律表，尤其660不是凭整数外观就可称某个平均律音高的精确标准值。

## 将赫兹差、比例和音程分三栏

相邻频率每次都增加220Hz，但相邻比值依次为二、一点五、三分之四。八度的定义采用频率二比一，因此只有第一对恰好是一八度，不能把后两段也按同样赫兹差记成一八度。先用整数分数核比值，再换成小数，保留分子分母属于哪两段。这里的Hz是每秒周期数，不是每分钟节拍；三秒时长也不是频率。不要因为四段标签递增就推断音量递增，增益和频率是不同的制作条件。

## 用共同参照计算累计八度数

将音程写成n=log2(f/220)，四段相对参照的值依次为零、一、约1.584963和二。660相对220的比为三，不能因为三倍便称三八度；三八度需要八倍频率。另从440到880只跨一八度，虽然880相对220是二八度，说明参照改变后计数也变。把累计值与相邻差各放一行：相邻约为一、0.584963、0.415037，三者之和回二。六位小数是显示近似，计算时保持分数和对数定义，不用小数误差制造不一致。

```
common reference f0=220 Hz
f (Hz):              220        440        660          880
f/f0:                  1          2          3            4
log2(f/f0):            0          1          1.584963     2
adjacent ratios:             2         3/2          4/3
adjacent octave gaps:        1         0.584963     0.415037
doubling control: 220 -> 440 -> 880; one octave per step
440 -> 880 is ONE octave; 220 -> 880 is TWO octaves
```

## 制作翻倍与等差两张对照卡

另列220、440、880作为每次翻倍的序列，连续两步各是一八度；再与原来的220、440、660、880等差序列并排。二者共享部分点却不是同一分组，不能删除660后仍说四段原任务未变。若想增加反例，取440与660，比为一点五而非二，只说明不是一八度，不推断它在所有调律体系中的名称。保留哪张卡回答相邻问题、哪张回答共同参照问题，标签不要只写低中高而隐藏具体值，否则以后重开无法复算。

## 外部制作同条件三秒素材

若具备外部工具，按真实可用的制音入口生成四份素材，保持波形、时长、采样率和制作增益，开头结尾可加同样的短淡变以免突变，但须记录这样做影响哪些区间。将频率和素材身份烧入自己的说明视频，保留原始声音与导出记录；四份源文件能对应是先决条件，不以修改云映倍速代替。若视频导出发生采样率或编码转换，另记处理，不能仅凭设定栏就认定最终音轨精确保留目标频率或全程幅度不变。

## 云映跟听先读当前频率再比较

通过既有来源打开说明片，保持正常速度、同一输出设备和舒适日常音量。先读当前标签，再按原顺序听四段，另记是否能辨认升高，不要求凭耳朵报精确赫兹。等制作增益也不保证每个频率主观一样响，不为了追求一样响同时改各段音量，否则增加了另一变量。若有一段听不到，先回源件、音轨与输出条件核，不直接认定频率值不存在或应用有固定频率屏蔽；没有执行听音就只交比例表，不勾选听辨通过。

## 按单位、参照和处理记录排障

若660被记三八度，先查是否把倍数直接当对数；若440到880被记二八度，查是否误沿220参照；若四段实际只一段变调，回外部文件与倍速状态核身份。每次只修一张故障卡的一项，原四个目标值保持可回查，不改数值去配合听觉预期。画面上的音名、音高插件读数和数学频率各有来源，未使用插件就不写已检测；也不把播放器系统音量、文件峰值和节拍数混进频率比公式解释。

## 重开交付四段身份与两类间隔

保存频率、相邻比、共同参照八度数、相邻差和导出记录，重开先从220与880回算二八度，再核中间660的三倍关系。实际重开云映只核同一素材顺序和正常速度，未知输出环节照实保留。验收能解释为什么等加220不等音程、为何参照不能中途变，以及为什么同制作增益不等主观响度。未完成的制音、导出与听辨分别待做，不声称内置音高生成或分析、精确调律检测、专业听力测试或所有设备同样听感。
