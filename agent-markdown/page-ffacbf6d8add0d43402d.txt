用三次外层与平方内层复算二十四，另保留内层导数零和不可直接套规则的边界。

复合函数在一点的值等于八，不代表导数也是八。本课自制一页内外层卡，在书屿逐行追求导对象、代入点和乘法，再用展开式独立复算。应用保存的是阅读位置与人工解释，计算不由内置求导器完成。

## 固定两层规则与求导点

外部设g(x)=x²+1，f(u)=u³，复合F(x)=f(g(x))=(x²+1)³，三者在相应实数范围均可微，目标点x=1。P1放输入输出与导数两栏，P2展开复核，P3反例，导出清晰PDF并留可编辑稿。导入后核平方只作用x、三次方作用整个括号，给P1加书签。有文本高亮入口可分别标内外层，不能选择公式就外部记整式与页角编号，不虚构应用认识函数对象。

## 先算函数值但不把它当斜率

在x=1，内层输出g(1)=2，外层再给f(2)=8，所以F(1)=8。另栏才写内层导数g′(x)=2x与外层对u的导数f′(u)=3u²。两种导数各对自己的输入变量，不能把u与x的名字擦掉后只留一个三平方。阅读时先口述一进入g得二、二进入f得八，再说明“值”栏到这里结束，后面的变化率并不是再重复同样的代入操作。

## 外层导数的代入点必须是二

链式法则给F′(x)=f′(g(x))g′(x)。本例先算f′(2)=12，再算g′(1)=2，两者相乘得24。若把外层导数也在原x=1求，会用f′(1)=3而误得6；若只求外层便停在12，又漏了内层变化率。把正确24、错点6、漏乘12分别写原因，不是看到不同答案就任选一个。规则在这里是乘法，不是将十二与二相加成十四，两个因子表达连续输入交接的变化率。

```
g(x)=x^2+1; f(u)=u^3; F(x)=f(g(x))
x=1: g=2; F=8; f_prime(g)=12; g_prime=2
F_prime(x)=3*(x^2+1)^2*(2*x)=6*x*(x^2+1)^2
F_prime(1)=24; F_prime(0)=0; F_prime(-1)=-24
wrong evaluation f_prime(1)*g_prime(1)=6
wrong missing inner derivative=12
```

## 一般式与展开式独立对齐

一般结果为3(x²+1)²乘2x，即6x(x²+1)²。另在P2把原函数展开成x⁶+3x⁴+3x²+1，逐项求导得6x⁵+12x³+6x，提因子后与链式结果一致。代x=1得6+12+6=24，是第二条算法而非照抄前栏。展开中的三x四次来自二项式系数，不能把(x²+1)³只写x⁶+1。复核用同一原函数，改成(x+1)²再相符并不能验证当前题卡。

用另一点x=2检验展开式与复合式没有只在一点碰巧相等：g(2)=5，外层斜率七十五，内层斜率四，乘得三百；展开导数给一百九十二加九十六加十二，同为三百。这里七十五不是F(2)的一百二十五。若某张卡给二十四，不先套首个点的答案，先查目标点是否仍是一。

## 零内层斜率与负点各作一项控制

P3取x=0，g值一、外层斜率三，内层斜率零，因此F′(0)=0，F(0)却是一。零来自乘上的变化率，并非整个函数恒零。再取x=−1，内层输出仍二，外层斜率仍十二，内层斜率−2，结果−24；两个点的函数值同八，导数却相反。记录每个点的整条链，不能只因内层值相同就省略内层导数，也不把负斜率解释成函数值变负。

因F是偶函数，正负一的值相同，而本例导数在对应两点符号相反；这是本多项式的对称复核，不能推广成所有取值相等的两点斜率必相反。另在x=0，内层值并不为零，合成斜率为零来自内层斜率，不是来自函数值消失。将这两句因果分别标出，可排查把任意零都当成同一对象的笔记。

## 条件不足不等于复合必不可微

链式法则的常用充分条件是g在目标点可微且f在该内层输出处可微。另卡设g(x)=|x|、f(u)=u²，在零点g不可微，不能机械写外层零乘一个未定义导数便说规则已用。可是复合恰为x²，直接求导在零仍得零。这说明缺某项规则前提时应另查复合，不可无条件宣布复合不可微。绝对值卡与主多项式卡分开，避免把规则的适用条件偷换成必要条件。

## 按对象代入点与运算类型排障

答案八先查是否把函数值当导数；六查外层代入点；十二查漏内层因子；十四查是否相加。放大撇号与括号，能选文字时把f′(g(1))整体保留，不只标一个数字二。修订自己的笔记时一次改一行，再用展开式核对应项；扫描公式搜不到并不表示规则缺失，可用P1角标返回原页。任何有限像素斜率测量都不能替代这份精确符号计算，书屿放大也不提供额外数学假设。

最后核公式抄写：三倍括号平方中的平方覆盖整个x²+1，而不是只把一平方。可把x=1代入两版，正确外层因子十二，错误3(x²+1²)为六，尚未乘内层就已偏离。恢复括号后再做乘法，不能用最终答案反推中间式必然正确。

## 重开从两层变化率恢复二十四

重开PDF由书签回P1，遮住答案先给g(1)、f′(2)、g′(1)写二、十二、二，再乘得二十四。随后用展开行和零点反例解释为何函数值八不是斜率，缺前提也不必一律判不可微。交付题设、两算法、四种错因与控制卡，未实际执行的导入、高亮或重开记待办。成品是人工跟读与复算，不声称书屿自动求导、证明全部复合函数结论或完成设备数学识别测试。
