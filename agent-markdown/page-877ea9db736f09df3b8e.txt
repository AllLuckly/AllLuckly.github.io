DEVELOPMENT NOTES · 5 articles

These notes move from FFmpeg build outputs to decoding, camera and microphone capture, streaming and playback. Trace the flow of media data before studying each API.

## How to read this collection

1. Begin with the FFmpeg-iOS build notes: identify headers, static libraries, target architectures and scripts. The original environment and dependencies are historical.
2. Compare H.264 decoding and capture articles. Note the input format, timing information, decoded data and resource-release points.
3. Finally, read streaming wrappers and ijkplayer integration as separate capture, encoding, transport and playback stages. Recheck old URLs, protocol settings and dependencies before use.

These notes date from 2015–2017. Their examples have not been rerun for this archive update. Check the dates and version notes before applying the ideas to a current project.
