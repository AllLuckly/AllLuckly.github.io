In the diagram, Origin marks the baseline and acts as the origin. descent extends downward and is generally negative, while ascent is positive. lineHeight, capHeight, and x-height are also labeled. How do we obtain these values in code?

```
let font = UIFont.systemFontOfSize(14)
print(font.descender)       //-3.376953125
print(font.ascender)        //13.330078125
print(font.lineHeight)      //16.70703125
print(font.capHeight)       //9.8642578125
print(font.xHeight)         //7.369140625
print(font.leading)         //0.0
```

Here, define text at size 14 and obtain its corresponding metrics. These values are read-only.

Plain-text layout has some subtle issues. First, draw text containing Chinese, English, numbers, and emoji to see the result.

Drawing before adjustment

![1](<https://allluckly.cn/images/blog/tuogao/tougao17/2.png>)

Lines containing emoji take up more height and leave larger gaps. Consequently, calculating text height from font size and width using boundingRectWithSize does not work here, and the layout is not particularly attractive. We therefore cannot draw it directly with CTFrameDraw. Instead, we may need to specify a line height and use CTLineDraw to draw one line at a time.

First, calculate the Size occupied by the text.

```
let SCREEN_WIDTH:CGFloat = UIScreen.mainScreen().bounds.size.width  //屏幕宽度
/**
计算Size

- parameter txt: 文本

- returns: size
*/
func sizeForText(mutableAttrStr:NSMutableAttributedString)->CGSize{
    //创建CTFramesetterRef实例
    let frameSetter = CTFramesetterCreateWithAttributedString(mutableAttrStr)

    // 获得要绘制区域的高度
    let restrictSize = CGSizeMake(SCREEN_WIDTH-20, CGFloat.max)
    let coreTextSize = CTFramesetterSuggestFrameSizeWithConstraints(frameSetter, CFRangeMake(0, 0) , nil, restrictSize, nil)
    return coreTextSize
} <br>
```

It is straightforward: obtain a framesetter from the attributed text, then calculate the occupied size from that framesetter.

The first 5 steps are the same as in the previous section. This time, after obtaining CTFrame, we do not call CTFrameDraw directly. Instead, obtain all the CTLines and calculate their total height. Derive each line's height from that total, iterate through the CTLines, calculate each line's Y coordinate, set its position, and draw it individually.

```
CGContextSetTextPosition(context,lineOrigin.x, lineOrigin.y) 
CTLineDraw(lineRef, context!)
```

Next, let's automatically recognize links and similar text.

> The idea is to attach and observe a tap gesture on the control, obtain the touch position, and, after recognition ends, use CoreText to examine each CTLine. Determine whether the touch falls within a recognized special string and identify that string. Use CTLineGetStringIndexForPosition to find the tapped character's position within the complete string.

First, write two regular expressions to detect @ mentions and links in the text. Add other expressions for anything else you need to detect.

```
//url的正则
let regex_url = "(http|ftp|https):\\/\\/[\\w\\-_]+(\\.[\\w\\-_]+)+([\\w\\-\\.,@?^=%&:/~\\+#]*[\\w\\-\\@?^=%&/~\\+#])?"

let regex_someone = "@[^\\s@]+?\\s{1}"
```

Regular expressions are outside this article's scope; look them up on Google.

Next, match the string with the regular expression, return the corresponding range, and change the attributed text's color.

```
//识别特定字符串并改其颜色，返回识别到的字符串所在的range
func recognizeSpecialStringWithAttributed(attrStr:NSMutableAttributedString)->[NSRange]{
    // 1
    var rangeArray = [NSRange]()
    //识别人名字
    // 2
    let atRegular = try? NSRegularExpression(pattern: regex_someone, options: NSRegularExpressionOptions.CaseInsensitive) //不区分大小写的
    // 3
    let atResults = atRegular?.matchesInString(attrStr.string, options: NSMatchingOptions.WithTransparentBounds , range: NSMakeRange(0, attrStr.length))
    // 4
    for checkResult in atResults!{
        attrStr.addAttribute(NSForegroundColorAttributeName, value: UIColor.redColor(), range: NSMakeRange(checkResult.range.location, checkResult.range.length))
        rangeArray.append(checkResult.range)
    }


    //识别链接
    let atRegular1 = try? NSRegularExpression(pattern: regex_url, options: NSRegularExpressionOptions.CaseInsensitive) //不区分大小写的
    let atResults1 = atRegular1?.matchesInString(attrStr.string, options: NSMatchingOptions.WithTransparentBounds , range: NSMakeRange(0, attrStr.length))

    for checkResult in atResults1!{
        attrStr.addAttribute(NSForegroundColorAttributeName, value: UIColor.blueColor(), range: NSMakeRange(checkResult.range.location, checkResult.range.length))
        rangeArray.append(checkResult.range)
    }


    return rangeArray
}
```

Here I recognize only @ mentions and links; add other patterns as needed. For convenience, this code is not encapsulated. You could use a structure containing an NSRange array and a type, or a dictionary—choose your own design. This example handles recognition only. Here is a brief explanation.

1. Define an array to store the matched Range collection.

2. Create a regular-expression object from the pattern defined earlier. This can throw an exception; for convenience, I have not handled it here. The option is CaseInsensitive, which ignores letter case. There are many other options; Command-click to inspect them.

3. Obtain the match results, which contain the range property we need.

4. Iterate over the results, add them to the array, and change the color attribute of the characters in each range.

Not bad—we recognized the text with little code. Next, let's handle taps.

First, register a tap gesture and set its delegate.

```
override init(frame: CGRect) {
    super.init(frame: frame)
    //添加手势
    let tap = UITapGestureRecognizer(target: self, action: "tap:")
    tap.delegate = self
    self.addGestureRecognizer(tap)
}
```

Then implement the gesture handler and delegate.

```
extension CTURLView:UIGestureRecognizerDelegate{

    func tap(gesture:UITapGestureRecognizer){

        if gesture.state == .Ended{
            let nStr = self.str as NSString
            let pressStr = nStr.substringWithRange(self.pressRange!)
            print(pressStr)
        }
    }

    override func gestureRecognizerShouldBegin(gestureRecognizer: UIGestureRecognizer) -> Bool {
        //点击处在特定字符串内才进行识别
        var gestureShouldBegin = false
        // 1
        let location = gestureRecognizer.locationInView(self)

        // 2
        let lineIndex = Int(location.y/lineHeight)

        print("你点击了第\(lineIndex)行")

        // 3 把点击的坐标转换为CoreText坐标系下
        let clickPoint = CGPointMake(location.x, lineHeight-location.y)

        let lines = CTFrameGetLines(self.ctFrame!);
        let lineCount = CFArrayGetCount(lines)
        if lineIndex < lineCount{

        let clickLine =  unsafeBitCast(CFArrayGetValueAtIndex(lines,lineIndex), CTLineRef.self)
        // 4 点击的index
        let startIndex = CTLineGetStringIndexForPosition(clickLine, clickPoint)

        print("strIndex = \(startIndex)")
        // 5
        for range in self.spcialRanges{

            if startIndex >= range.location && startIndex <= range.location + range.length{

                gestureShouldBegin = true
                self.pressRange = range
                print(range)

            }   
          }
       }
        return gestureShouldBegin
    }
}
```

gestureRecognizerShouldBegin is a delegate method. We use it to detect special strings.

1. Obtain the touch point's position in the current view.

2. Obtain the line number from the ratio of the y coordinate to the line height. lineHeight is a global variable. Download the example code to follow along.

3. Convert to CoreText coordinates.

4. Obtain the character's index.

5. Iterate over the special-character ranges and check whether index falls within one. If it does, assign that range as the currently pressed range and print it.

In the tap method, retrieve and print the string corresponding to this range. Any associated action can also be handled there.
