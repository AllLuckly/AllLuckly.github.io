On a supported installed version, distinguish the selected book, displayed position, page turn and the result after opening the reader.

## Establish the version and reading sample

Prepare a short authorized EPUB that opens in Book Isle, and choose a chapter whose neighboring pages are easy to distinguish. Record the title, chapter, current sentence and adjacent next passage. First turn a page within the reader and reopen it. A cover or filename alone does not establish that its content is ready. Apple lookup samples returned 1.1.5 while another cached response returned 1.1.4; distribution may lag, so check the version actually available and installed.

## Find the Reading widget in the system list

Return to the iPhone or iPad Home Screen and use the current system editing interface to open the widget list. Search for Book Isle and inspect whether the Reading widget is actually offered. Apple documents the general process, but layouts vary by system and device. If the widget is absent or unsupported, record version and observation and stop; an ordinary app icon is not a widget, and resetting the Home Screen is unnecessary.

## Identify the target and initial display

Add an available widget size and inspect its title, text or other identifying content against the sample. Record placeholders, loading, a different book or a setup request separately. Choose the target only if an actual configuration entry is offered; otherwise leave it pending. Limited widget space may truncate content, so a short excerpt alone does not prove that text is missing.

## Perform one action and record before and after

Only if an actual page-turn control is offered, record a recognizable current sentence, use it once, wait for the display and record the new sentence and direction. If nothing changes, do not repeatedly tap or assume multiple background page turns; note the wait and visible feedback. Control names and appearance depend on the interface, and this exercise does not promise identical interaction for every size.

## Open the reader and compare the position

Open Book Isle through the widget or the ordinary app entry. Confirm the same book and compare chapter and body text. A changed widget, a changed reader position and exact agreement are three separate observations. If pagination reflows, use the recorded sentence rather than a page number as the anchor. If an entry opens the app without selecting the book, record that behavior instead of assuming a direct jump.

## Troubleshoot refresh and book identity

If the widget does not update, first check that the same book still opens in the app and that the widget remains present. Network or remote-file checks apply only when the sample actually comes from a remote source; a local book does not require server changes. Return the app to the foreground and observe again, recording any change. Do not delete books, notes or the app to force a refresh, or infer a fixed system refresh interval.

## Compare reflow and pagination

Record the first few characters, one punctuation mark and the next paragraph’s opening sentence in a private check card. Locate them at the reader’s current text size, then look for the visible excerpt in the widget. A widget, phone and iPad can wrap and display different amounts of text; that alone does not mean the chapter changed. If the excerpt cannot uniquely identify the location, mark agreement indeterminable rather than deciding from one common word. Do not change the original book to manufacture a difference or assume a widget screen equals a book page.

## Record the outcomes of the two actions separately

Use columns for time, text before the control, feedback from one tap, text afterward and the reopened reader location. If the display changes later, record the observed time window without claiming an exact refresh delay. During a repeat with the same book, avoid simultaneously changing type size, orientation or edition. If the original position cannot be recovered reliably, preserve the record and stop; start a later check from a new unambiguous anchor.

## Identify a displayed excerpt

If the widget shows only part of a sentence, compare it with distinguishing surrounding passages in your self-made sample. Common words can recur; use chapter, contiguous text and the source location together. If the visible excerpt is insufficient, write “cannot uniquely locate” rather than inferring the target page from background or cover. Any comparison screenshot should use only self-made material and exclude notifications and private information.

## Keep the baseline file

After checking, confirm the original EPUB backup still opens. A temporarily blank widget does not mean the book was deleted.

## Keep a reproducible check record

Record system and app version, widget size, sample identity, text anchors before and after, and the reader observation. Mark unavailable widgets, missing page controls and unfinished checks untested. Remove the test widget if desired, and confirm the original book and reading records remain. These steps are designed from public release notes; no physical-device widget test is claimed.
