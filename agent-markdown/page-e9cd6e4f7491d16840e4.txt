从零一双初值列出F0到F8，核项号、递推次数与同步状态更新的差别。

只写“后项等前两项之和”，还不能确定唯一数列；初值、起始项号和更新顺序都可能改变结果。本课读一份原创递推卡，在书屿逐段对应定义与状态表，用外部手算检验F8等21。伪代码只是纸面算法说明，不是要求应用执行程序，也不把搜索到一串熟悉数字当作已核对所有条件。

## 先固定零起点与两个初值

题卡R1声明F0等0、F1等1，n大于等于2时Fn等前一项加前二项。零下标是本课项号，不表示书中物理第零页；如果教材从F1和F2开始命名，应先建立对应再比较。把递推式和两初值放同一段可读文字，导入支持的PDF或EPUB后核角标R1。不要只摘录递推式就删掉初值，也不要看见两个1便把它们合成一项；数值相同不等于项号相同。

边界查询也要单列：要求F0时直接返回已给初值0，F1时返回1，不应先执行一轮再输出。若程序式说明只接受非负整数项号，负项号不在本课输入范围；不能为了让它有值随意继续倒推。把输入条件写在题卡，而不是藏在最终答案后，读者就能核停止条件究竟在更新前还是更新后。

## 逐项展开到八而非只认熟悉数列

先写F2等1加0得1，F3等1加1得2，随后F4等3、F5等5、F6等8、F7等13、F8等21。从F0到F8共有九项，不是八项；两初值之外新填F2至F8共七项。表格每行保留项号、所用两项和值，不能只排0、1、1、2、3、5、8、13、21就省掉对应关系。若计算错从哪一项开始，回到该行的两个来源，而不是把后面全凭记忆改成标准串。

## 把状态对解释成连续两项

若用a、b两变量记录，先规定当前状态为Fn与F(n+1)，起始a等0、b等1对应n等0。下一状态必须用旧b和旧a加旧b，即从0、1变1、1，再变1、2、2、3。n每增加一表示窗口右移一次，不是同时跳过两项。做外部状态表时每轮都写n与a、b，避免看b的数却说它是Fn。书屿页码与滚动位置也不参与这套索引，阅读时不要将“第八行”自动当F8，先核表头是否含初始行。

中断练习可停在n等4，状态3、5，另记下一轮从这对旧值出发。恢复后再移四轮，应到n等8的21、34；若把计数重置为零却不重置状态，就会把相同数对写成错误项号。阅读书签只帮助返回这一行，不会替你保存或执行算法变量，状态表必须由笔记完整保留。

## 保存旧值再执行两次赋值

外部伪代码可先算两个临时量，再更新a与b，确保右侧都来自同一个旧状态：

```
next_a = b
next_b = a + b
a = next_a
b = next_b
```

从状态0、1执行一次，得到1、1。这里只解释赋值语义，不声称书屿能运行这四行。若在笔记里只写a变b而没交代b怎样变，记录还不完整；可用高亮将临时计算两行与赋值两行分组，但别把颜色本身当同步更新的证明。

## 对照覆盖旧a的错误顺序

错例顺序如下：

```
a = b
b = a + b
```

从0、1出发，第一行已把a改1，第二行便算新1加旧1得2，状态成1、2；再做一轮成2、4，而正确两轮应1、2。两个过程有时碰巧出现相同单个数，不能只看见一个2就认为算法一致。把错例与正确版本分栏，不同时换初值来掩盖覆盖问题；修复应恢复旧状态来源，而不是每轮手动把结果改成想要的值。

## 换初值说明递推式并不唯一

另页R2用G0等1、G1等1，递推形式相同，所得1、1、2、3、5、8、13、21、34，所以G8为34，不是R1的21。初值改变就是另一数列，不能说只是书屿显示少了开头零。对照还可核正确状态法从R1移八轮后a等21、b等34，与只新增七项到F8的列表口径不同：一项数新生成项，一项数状态窗口移动，起点不同须说明。不要把这两个次数直接当互相矛盾。

还可核G的前两项等F1、F2，之后两者服从相同前两项求和，所以按已声明项号G\_n对应F\_(n+1)。例如G4为5而F4为3、F5为5，差别是索引平移，不是某个结果随机变化。这个对应依赖两组明确初值，不能把任何相同递推形式都说成只差一项；其他初值可能产生不同关系。

## 在书中返回定义而非只找答案串

用书屿可见书签保存R1定义与状态表入口，或在外部笔记写章节和角标。若全文搜索可用，先搜R1这样的独特文字，而不是假定数学下标能完整检索；命中后核前后两初值。笔记记录n含义、当前a与b是谁、旧值是否保留、最后查询的是F8还是F9。若转存造成下标丢失，回原题卡核版式，不用文件名中的数字代替数列项号。自己的伪代码与作者定义分开标来源，不能把改写程序冒作原文。

## 重开独立重建九项与八轮状态

重开后遮住结果，先从0与1重算九项到21，再用旧状态法移八轮得21、34，最后解释错序为何首轮已错。验收包含R2的34及两种次数口径，不能只背熟悉数列。换初值、项号约定或递推式都重建表，不把今天的两变量更新套到任意递推。恢复到原定义页，检查笔记仍能对应版本；这些是外部手算与阅读核验，没有声称应用执行循环、自动检测程序错误或验证真实系统性能。
