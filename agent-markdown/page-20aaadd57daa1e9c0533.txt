Handcraft three monochrome media-action icons and check shared bounds, labels and legibility at small sizes.

English translation of the [Chinese original](<https://allluckly.cn/guides/vectorpaint-play-pause-stop-icon-action-set/>), translated on 2026-11-20. Original publication dates, attribution, code and version notes are retained.

Design an original monochrome play, pause and stop set in equally sized frames, with each shape expressing a different action. This is a static exercise, not a player integration. A real product also needs clear names, state and operable interaction. Construct editable shapes and a few paths without assuming an automatic icon generator.

## Establish three consistent icon frames

Place three 120 × 120 unit guide frames on a landscape canvas, leaving some space around each shape and naming the groups Play, Pause and Stop. Separate guides, the three shapes and labels, then save the original. These are exercise coordinates, not a universal platform requirement. Use one dark fill and a transparent or white background instead of color-coding actions. At small size, move oversized labels outside frames rather than remove wording that helps interpretation.

## Build a play triangle from three points

In the first frame make a closed right-pointing triangle at local coordinates (44,30), (44,90) and (92,60). The left vertical base is 60, the tip is level with its midpoint and horizontal height is 48; this is not an equilateral triangle. Confirm a closed path and interior fill without making a guide-frame edge part of the triangle. If the tip looks low, check the three points and coordinate direction before recording an optical adjustment. Do not point it left and retain the right-pointing exercise label.

## Build pause from two vertical blocks

In the second frame place two disconnected rectangles at local upper-left points (38,30) and (68,30), each 14 wide and 60 high. Check aligned tops and bottoms, a 16-unit gap and total outer width 44. The gap stays background; an accidental filled union must not turn the symbol into one rectangle. Use shapes, alignment or manual nodes actually available. If dimensions can only be approximate, record that rather than asserting identical pixels across devices.

## Use a square for stop

In the third frame place a 48 × 48 square at local upper-left (36,36), leaving background around all four sides. It is solid, not a hollow square ring, which changes the cue. This setup centers it geometrically, but geometric and optical centering can differ. If it feels too heavy, first inspect size and surrounding space, then record any small adjustment in a copy rather than blindly enlarging all shapes to equal bounding areas.

## Compare area and visual weight

The original triangle area is 48 × 60 ÷ 2 = 1440 square units; two pause blocks total 2 × 14 × 60 = 1680; the stop square is 48 × 48 = 2304. Equal frames do not give equal filled areas. Area is one comparison, not a complete measure of visual weight. Reduce the side-by-side icons and judge shape, negative space and background. If adjusting the square, retain both original coordinates and revised dimensions rather than mislabeling an optical adjustment as the original calculation.

```
play: triangle base 60, height 48, area 1440
pause: two 14 x 60 rectangles, gap 16, total area 1680
stop: 48 x 48 square, area 2304
shared frame: 120 x 120 per icon
```

## Use labels to describe the next action

Label the icons “播放”, “暂停” and “停止”, retaining the English group names as layout references. In real interaction, whether a control displays play or pause depends on its current state and design convention; the drawing alone does not establish that playback has started or paused. This sheet is not an operating control, and icons, labels and state notes do not replace real accessibility naming and interaction tests. Use original short labels, not another app's branded icon.

Make a comparison card with observable current state in the first column, desired action when pressed in the second and the corresponding shape in the third. Fill it only with exercise states, not claims about an existing player. Check that “playing now, press to pause” and “paused now, press to play” are not reversed. Stopping may also affect playback position depending on the product; this drawing names the action without prescribing the outcome. If delivering graphics alone, keep the card as a separate attachment so it is not accidentally exported inside an icon frame.

## Check small sizes on different backgrounds

Preview the original at target sizes of 32 and 64 pixels. Check that the pause gap survives, play has a visible point and stop stays solid. Compare light and dark backgrounds, adjusting contrast rather than relying only on color to distinguish actions. Antialiasing, scaling and pixel alignment can change small-size appearance; screenshot edges are not original path coordinates. If pause blocks merge, first widen the gap or simplify sizing in a copy, record changes and recalculate coordinates before output.

## Save the source and inspect each output

Keep the three editable groups, coordinate notes and any optical-adjustment copy. Hide guides and inspection labels, then export SVG or PNG separately through controls actually offered by the installed version and open each in a separate viewer. Inspect crop, transparency, triangle direction and pause gap. PNG is raster; an SVG containing bitmaps is not automatically all vector. Reopen the source and move one rectangle to check actual editability. Mark unperformed export, reopening or real interaction tests pending; a static sheet is not an online media control.
