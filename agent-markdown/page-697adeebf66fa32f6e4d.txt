“This is confusing” gives an original-comic creator little to inspect. Read an authorised draft in ManYue and prepare one concise, recoverable issue report describing the encounter, return path and remaining uncertainty. This does not rewrite the story, disclose unpublished work or certify device compatibility from one reading opinion.

## Confirm review permission and draft identity

Record supplied version, date, page count and discussion scope, including personal-only versus named-collaborator sharing. Use authorised files without assuming publication permission. Preserve the draft and store notes separately; label updates as new versions. Choose one review focus—reading order, dialogue understanding or display behaviour—before starting. Exclude unauthorised server content and do not request credentials merely for convenient verification.

## Read once and record the first difficulty

Read in supplied order and record the first place requiring a return, with the comprehension task. Describe which speaker, panel order or action you initially inferred before proposing changes. Retain that first observation after learning the answer instead of rewriting it as always clear. Select one consequential issue rather than dozens of preferences. Resolve incomplete loading first so a blank image is not confused with a comprehension problem.

## Write a minimal return-and-recheck path

Describe entry through a chapter or known page, the panel inspected and the reading progression that produces confusion. Add two stable landmarks, such as the figure beside the window and the lower-row speech balloon, rather than recording only something like about sixty percent. Test supported page bookmarks after leaving and supplement them externally with panel location. State paired-page or orientation conditions and whether a single-page comparison was actually done. Mark unobserved conditions untested rather than inventing other-device behaviour. A short precise path helps the creator reproduce the observation.

## Separate display behaviour from narrative understanding

Compare suspected clipping, missing images or order against the same supplied source in a trusted tool before calling a plot error. Record viewing differences where the source is intact, and source limits where it also lacks content. Intact art with unclear speaker attribution is a comprehension issue. Both types can coexist with different evidence and responsible parties. Do not demand a complete redesign for an unknown viewing path or certify every device because another tool works.

## Separate observation, interpretation and suggestion

An observation might be reading the lower-left balloon first; an interpretation might cite its tail; a suggestion might ask about spacing. Make suggestions optional because intentional ambiguity or suspense may be the goal. Personal style dislikes are not objective errors, and one reader cannot speak for everyone. Tie each proposal to an observation and defer unrelated decoration opinions. Do not mark up the original; any authorised sketch belongs in a separate labelled discussion copy.

## Perform one targeted recheck

Revisit once to check preceding-page cues, small print or connectors. If you missed something, label it an initial missed cue and retain what was present rather than silently deleting the issue. Keep unresolved confusion without demanding your fix. Recheck a new version using the same task and landmarks after verifying changed page identities. Avoid unlimited setting changes followed by cherry-picking one smooth result as a complete repair; retain actual tested conditions.

## Share only necessary evidence

Include version, reader task, location, first observation, recheck and optional suggestion. Share within permission, not an external group containing the whole draft, server address or private conversation. Confirm screenshot permission and attach full-page location because a crop lacks context. Use text or a clearly labelled personal diagram without image permission. This prepares material; an authorised person chooses recipients and timing. No automatic sending or public-feedback feature is assumed.

## Finish a one-page actionable review

Completion means the creator can locate the issue, distinguish observation from suggestion and see untested conditions. One specific issue offers a clearer task and evidence than many vague judgements. Revised versions need fresh checking because positions and cues can change. A report establishing only a display difference should say so instead of claiming completed story review. Retain necessary records and permissions, handling deletion only as actually agreed without removing originals or sole recoverable copies.
