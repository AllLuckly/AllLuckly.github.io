In an ordinary host that supports rotation, use the same sentence to record system orientation, visible Jianlai layout and committed text separately in portrait and landscape.

## Prepare an ordinary host that rotates

Use an iPhone with Jianlai installed and an ordinary text editor that actually supports both orientations. Create a practice note and record the original rotation-lock and keyboard choices. Do not use a password field or overwrite an important document. Hold theme, input scheme and the test sentence “今天看海 ABC 12。” fixed. Record host, OS, device and installed app version if visible; a store listing does not establish the installed version.

## Establish a portrait baseline

Hold the phone upright, confirm the host is actually in portrait and Jianlai is selected. Type the target on a new line. Record whether candidates appear, how labels and body text are arranged, and the exact committed text before correcting anything. Note whether a one-handed or other layout is active and keep it consistent. Record absent controls as absent rather than filling them from another phone’s screenshot. Screen width does not establish individual touch-target size.

## Check rotation lock and host scope

Apple documents checking portrait orientation lock in Control Center. If this exercise requires unlocking, record the initial state and restore it afterward using the system’s real interface. Rotation depends on the host and device, so unlocking does not guarantee every app rotates. Use an ordinary host known to support landscape; if necessary, follow Apple’s guidance to check system rotation in another supported app, then return. System rotation and Jianlai input are separate observations.

## Confirm the actual context after rotation

Turn the device sideways and establish whether the host really entered landscape; physical orientation alone is not proof. If it did not, inspect orientation lock and host support and mark landscape pending when unresolved. Do not delete the note, reinstall the keyboard or alter unrelated settings. If landscape appears, confirm Jianlai, theme and input scheme again, and inspect the visible keyboard and document area. If the system switched keyboards, record it before selecting Jianlai using actual controls. If rotating removes focus from the field, select the original practice line again and confirm cursor and context before typing; record that action rather than claiming focus was automatically retained.

## Type the same sentence in landscape

On a new line enter “今天看海 ABC 12。” with controls actually displayed. Record candidate visibility, available digit and punctuation entry, and whether committed text remains visible. Different schemes can display different controls. Compare characters, spaces, case and punctuation with the portrait result. Preserve the first outputs and correct only a separate copy. Agreement in these two trials does not establish behavior for every key, language or host.

## Separate layout changes from accuracy

First compare whether rotation occurred, then visible keyboard placement and controls, and finally the two committed lines. A wider-looking key does not establish a proportionately larger touch target. A smaller body area is not by itself proof that Jianlai caused it: host controls and system layout can also change. Preserve any error and inspect candidate selection and cursor placement before attributing a cause. Do not change theme, font and other variables just to produce a difference.

## Troubleshoot lock, host and keyboard separately

If the screen does not rotate, check system lock and host support first. If the screen rotates but Jianlai is absent, check the active keyboard and whether the host accepts third-party keyboards. If the keyboard appears but text does not, inspect focus and candidate confirmation. For lost text, preserve host, time and context and inspect host save behavior. Change one condition per retry, marking unperformed steps pending. One trial cannot establish universal model, orientation, host or performance compatibility.

## Deliver observations and restore settings

Keep two rows for portrait and landscape: actual host orientation, active keyboard and layout, visible controls, original committed text, issues and pending work. Record the initial rotation-lock state and any temporary change. Restore lock, theme and usual keyboard, then verify the note and original remain. Do not delete the keyboard or practice note. Apple says some apps do not support rotation; the store describes Jianlai support for iPhone/iPad and appearance customization. No real-device orientation test is claimed.
