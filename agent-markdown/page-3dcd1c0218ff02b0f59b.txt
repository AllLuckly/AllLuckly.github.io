## Prepare a twelve-second reference and separate copy

Retain an owned video at least twelve seconds long without the exercise rectangle, preferably with a mid-grey or dark background so the white fill is distinguishable, plus its existing subtitles. Draw a 640×360 script frame with x rightwards and y downwards. Record copy name, encoding and source in a separate note and hold video fitting fixed. Without an external-subtitle control, audit text and leave presentation unperformed. Script coordinates are not device pixels; preserve everyday subtitle files.

## Save a complete drawing-and-text control

Save the complete content as UTF-8 polygon.ass and reopen it as plain text. The first event draws during 1–4 seconds; the second supplies ordinary text at 5–8. Preserve all style/event columns. Use lowercase m/l and space-separated coordinates with ASCII overrides. Record the filename, both intervals and source location so a same-name older copy is not selected later.

## Trace four edges and the closing point

Trace (0,0),(120,0),(120,60),(0,60),(0,0): four edges, width120, height60 and area7200 square script units. The repeated start is not a fifth distinct vertex. m starts a contour and l continues straight lines. Closing explicitly fixes this exercise’s boundary. The calculated area does not establish a count of covered device pixels; placement and scaling are separate. On paper, shifting every point twenty units right preserves all side lengths and area, whereas moving one point can change shape. Keep whole-path translation and one-point editing on separate cards to identify whether the coordinate placement or actual contour changed.

## Separate drawing mode from character scope

p1 enables drawing interpretation and p0 ends that scope. Commands between them describe geometry, not visible words. The separate Shape control. event uses ordinary font-dependent text. A shared file does not turn all text into outlines, and p0 is not an event time. Keep this reference’s drawing and text in separate events; any mixed-event experiment needs its own scoped copy.

## Change one vertex for a shape control

In a copy, change only the upper-right point from(120,0) to(100,0). The top shortens and right edge slopes while the bottom stays120, so the paper outline is no longer rectangular. Use this change to identify the selected copy, retaining font and script size. If nothing changes after reloading, inspect identity and interpretation before video cropping; preserve the original rectangle.

## Diagnose text, path and placement separately

For wrong proportions, compare vertices/script dimensions rather than audio language. Missing text glyphs and absent drawings are different failures. Retain failing copies and source outlines; one rectangle cannot establish every complex Bézier drawing’s support.
