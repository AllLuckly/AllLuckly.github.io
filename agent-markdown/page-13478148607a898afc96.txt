在不发送的普通文本中比较直引号与弯引号，按实际结果记录系统和宿主行为。

同一段英文台词的直引号和弯引号看起来接近，却是不同字符。用一条不发送的练习句比较键来输入、系统选项和宿主最终正文；不假定系统的智能标点会作用于每个第三方键盘或每款编辑器。

## 写下两份明确目标

准备原文 `He said, "Go."`：逗号后有一个半角空格，Go 首字母大写，句点在引号内，两侧均为 ASCII 直双引号 U+0022。第二份展示稿为 `He said, “Go.”`，其中左双引号是 U+201C、右双引号是 U+201D；句子其他部分保持相同。不要把两份目标混写成同一种标点，也不要使用真实聊天记录。先存一份参考卡，实际练习放在独立副本中。

## 核对宿主与键盘前态

选择自己控制的普通文本编辑宿主，确认不会自动发布或发送。确认键来已添加并在当前字段实际选中，记录设备系统、宿主、键盘语言和布局。查看苹果系统键盘设置中实际可见的智能标点选项及其原状态；如果该系统版本没有这个选项，记为不可确认。不要假设该设置必然控制键来或宿主，之后要分别观察；练习不需要改变隐私权限或使用密码框。

## 在原始设置下输入第一稿

用实际可见的按键或候选录入第一份练习句，尤其记下左右引号各是如何输入的。确认大小写、逗号、空格、句点和完整正文；若候选或宿主在输入过程中改变了引号，保留首次结果并记变化出现的时刻。不能从键帽上显示直引号推断正文一定保留 U+0022，也不能将智能替换的结果说成用户主动选择了弯引号。

## 先核正文再判字符

分别看两侧引号的形状与方向，注意某些字体可能让它们难以区分。用宿主可用的选择、复制或本地字符检查工具读取非私人练习文本；有条件时逐项检查开头和结尾引号的码点。若没有能够验证原文的工具，记录“外观观察、码点待核”，不要凭视觉断言。检查工具或粘贴也可能转换文本，先用保存的两张已知参考卡确认其行为；不需要把私人内容上传外部网站。

## 单独改变一个系统条件

有 Python 3 的电脑可以只输入本课的非私人句子，在本机检查两侧引号相关的码点。下面的程序输出全部字符而不联网，也不编辑原稿；复制或终端处理仍可能改变文本，因此先拿两份参考卡验证。如果输入和屏幕显示相同，不能因此省略对码点的核对。

```
text = input("Practice sentence: ")
for position, ch in enumerate(text, 1):
    print(position, repr(ch), f"U+{ord(ch):04X}")
```

例如原文两枚引号都应显示 U+0022；展示稿左右分别是 U+201C 和 U+201D。数字位置随文字本身变化，逐一检查实际行，不直接套用其他句子的序号。若参考卡进入工具后已变化，停止并把原始字符留待核。

如果设备显示智能标点开关，记录原状态并仅改变这一项，在新的一行重复同样的英文练习；保持宿主、键盘、输入语言与手动动作不变。写下改变前后真实显示的开关、输入动作和最终正文。若系统选项改变后键来结果没有变化，这是有用观察，不应宣称设置无效或应用故障。若设备没有该开关或无法安全更改，就跳过对照并保留待核；完成后按原记录恢复。

## 可选系统键盘参照

若希望区分作用范围，可在同一宿主的新副本中切换到已启用的系统键盘，使用同一目标句和同一系统选项各试一次。记录这轮确实选中了哪个键盘；不要在两个键盘间同时修改宿主设置。系统键盘和键来在相同条件下的结果不同，只能说明本次观察不同，不能直接推出所有第三方键盘或所有应用都会如此。原先没有启用的键盘不必为了练习移除或修改。

## 排查并保护原稿

若引号在输入后才变化，区分键盘输入、候选确认、宿主自动格式与粘贴来源；如果重开草稿后才变化，单独记录保存与同步过程。检查是否仍在目标字段、是否误选类似标点，再一次只改变一个条件。直引号与弯引号不是正确和错误的绝对分类：本练习的原文与展示稿有不同契约，应按目标逐字符验收。保留第一次结果，不通过覆盖原稿掩盖差异。

## 恢复并交付

恢复智能标点原设置和常用键盘，确认原有草稿与其他系统键盘仍在。交付参考文本、系统设置前后、使用的键盘与宿主、真实输入动作、两侧字符或待核状态。若无法区分字符，只报告观察范围；本文基于公开多语言说明和苹果系统键盘设置设计练习，没有声称真机自动替换或兼容测试。

记录这次检查日期与设备系统版本，版本或宿主改变后重新观察，避免把旧结果直接当成新结果。
