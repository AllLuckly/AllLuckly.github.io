Use self-made clips to distinguish Plex specials directories, season-zero numbering and actual playback in iCouldPlay.

## Understand specials naming

Plex’s TV organization documentation gives a Specials directory with s00e plus episode number for specials. Season-zero numbering supports server identification; it does not itself prove a file is an official special of a real show. Metadata providers and episode ordering can affect matching. Observe whether iCouldPlay exposes a specials entry and order in the actual connection.

## Prepare an isolated self-made show

In an isolated show library you administer, prepare two authorized self-made clips with visible markers A for an episode and B for a special, recording duration and retaining backups. Use a fictional show name rather than another person’s real show. The normal test account needs library access. Observe read-only if restoration is uncertain.

## Create a reproducible layout

In the test library create a fictional River Demo (2020) show directory. Put River Demo (2020) - s01e01.mp4 with marker A in Season 01, and River Demo (2020) - s00e01.mp4 with marker B in Specials. Both must be genuinely playable video copies, not renamed extensions. This fictional title and year do not identify a real metadata-provider item.

## Record the pre-scan state

In Plex’s web interface as the normal test user, record any existing River Demo item, seasons, directories and playback state. If a same-name item exists, verify its identity with administrator authorization before overwriting anything. Connect iCouldPlay to the same server and account and record existing show entries. Confirm the isolated library so production specials are not mistaken for test results.

## Scan and inspect server grouping

Run or wait for an isolated-library scan using current server controls and record completion and version. Check whether the server recognizes A as season 1 episode 1 and groups B under specials or the relevant season-zero entry, recording actual labels. A fictional show may have no external metadata, so do not require a real-provider match; record file, numbering and server grouping.

## Separate provider ordering from filenames

Plex documents different episode-order sources; a real show’s special number should be checked against its chosen metadata provider. The test s00e01 is self-made and does not establish identical numbering across platforms. If the server differs from expectation, record the selected ordering source and refresh state without renaming production files to force a match.

## Inspect the actual iCouldPlay entry

Return to the same server and normal account in iCouldPlay, find the test show and inspect actual season or specials entry points. If visible, open both authorized clips and verify A and B markers and return behavior. Mark a missing specials entry or item unobserved. Server support for season-zero organization does not guarantee the same menu or order in iCouldPlay.

## Troubleshoot and preserve originals

If the server shows only one episode, check file completeness, directory hierarchy, s01e01 and s00e01 numbers and the scan. If web shows B but iCouldPlay does not, check account, show identity and page state. Change one reversible condition at a time. Do not overwrite production movies, delete others’ favorites or alter the sole original to fix an assumed issue.

## Restore and document

Restore isolated files and settings from backup, confirming original clips and other users’ data remain; defer uncertain effects to the administrator. Record directory hierarchy, scan state, server grouping, iCouldPlay entry, A and B playback and skipped steps separately. Remove private paths and credentials before sharing. This guide relies on public documentation and claims no device or private-server testing.

## Distinguish directory from content

Specials is a directory name for server identification; it does not change a file’s images or make it an official special. Clip B must be self-made and identifiable by marker and duration. A normal clip placed there is only a directory-rule sample, not a real program special. If extension and actual format differ, prepare a proper copy rather than disguising it by renaming.

## Separate episode numbering from viewing order

The test s00e01 denotes season-zero episode 1 and s01e01 denotes season 1 episode 1; this does not require watching B before or after A. Real viewing order needs reliable evidence and may differ from provider aired or disc order. This exercise checks grouping of two self-made samples, not a fabricated story order for a real show.

## Record identity at two layers

For the server record relative file path, server entry name, season and episode number and whether playback shows A or B. In a separate iCouldPlay record note account, entry and image. When the name matches but playback was not checked, mark file identity unconfirmed. If two same-name server series appear, inspect both paths and library scopes before deleting anything.

## Separate missing metadata from playback failure

Fictional River Demo may not exist at a remote provider; that does not necessarily prevent playback. If artwork and description are missing while both self-made files are grouped by episode number, record both observations. If nothing appears, inspect scan and path. Do not import another real show’s metadata to decorate the sample or disclose private server addresses and tokens.
