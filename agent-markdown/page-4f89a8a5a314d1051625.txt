用授权样本观察 EPUB 深浅配色声明、设备偏好和实际阅读结果。

## 理解偏好声明

W3C 媒体查询规范的 prefers-color-scheme 用于表达用户希望页面使用浅色或深色主题，偏好来源可以是系统或用户代理设置。样式表包含该声明并不保证书屿一定读取它，也不保证书内所有文字与图片都自动适配。用户选择、阅读器自有主题、书籍样式和实际画面需要分别记录。

## 准备授权测试样本

选择自己制作或出版者允许检查的 EPUB，最好有一小段黑白文字和一张自制图片，并明确说明是否包含对应媒体查询。保存原件和备份，记录书名、文件版本与来源；不要把其他人的受保护书籍拆包。如果许可不允许查看内部文件，只进行可见画面的比较，结构检查写为未执行。

## 建立第一组观察

在书屿打开同一测试章节，记下当前设备外观和应用阅读主题的实际设置、文字颜色、背景颜色以及图片边缘。记录标题或自制短句以便回到同一位置；若设置不可查看，标记未知。不要因为屏幕整体偏暗就认定书籍执行了某段 CSS，也不要将设备亮度和页面背景颜色当成同一设置。

## 检查样式表及其范围

仅在许可和工具允许时，检查副本中目标章节引用的 CSS，记录是否有 prefers-color-scheme、对应的 light 或 dark 条件以及具体作用的选择器。章节可能引用多个样式表或包含其他规则，不能只找到一个词就断言它控制整本书。保留实际相对路径，并将文件内容与出版者说明分开记录；不改写原书来强行得到某种结果。

## 只改变一个可见条件

按设备和书屿当前界面实际提供的选项，只改变设备外观或应用阅读主题中的一项，保持文件和目标章节不变。重新打开同一位置并记录文字、背景、图片和设置状态；无对应开关时写未提供。不要同时更改字号、亮度和多处主题，否则无法判断观察差异与哪一项有关。

## 区分图片和文字表现

对比文字和页面背景是否仍清晰，再看自制图片是否自带固定的浅色底、透明区域或深色边框。图片本身可能不随文字颜色变化，透明区域也可能显示底下的页面颜色；看见亮色矩形不一定证明主题切换失败。保持图像内容与 CSS 声明分栏记录，不根据图片外观推断软件内部使用了哪条规则。

## 按实际情况检查辅助需求

如果用户需要更大的文字或系统对比度功能，单独记录其原设置，再按实际可用入口进行一次独立观察。辅助功能和书籍自身 CSS 不应混为一项；没有使用或不能确认时标记未测。发现文字难以阅读时可恢复原设置并暂停该样本，不要求读者为了测试长期使用不适合的配色。

## 分层排查而不猜原因

若设备设置变化而书屿画面没有变化，先确认是否返回同一章节、控制是否保存和应用自己的主题是否覆盖预期；若样式声明不存在，则不能拿它解释结果。另一可信阅读器可作为独立对照，但它的显示不证明书屿具备同样支持。一次只改一个条件，记录未知原因，不安装未知软件或修改安全设置。

## 恢复设置并保存结论

完成后恢复设备和书屿原来的外观及辅助设置，确认原文件、书签和笔记仍在。记录样本版本、样式是否存在、两次设置和可见颜色、图片背景以及未执行原因；分享前移除私人路径与未经许可的内容。本文参考公开标准与应用资料，没有声称在特定设备上测试，也不保证应用实现该 CSS 媒体查询。

## 建立两列不混淆的记录

用一列记录样式文件中声明的条件、选择器及颜色值，另一列记录在书屿看到的文字和背景。两列出现相同颜色并不自动证明该声明生效，因为其他样式或应用主题也可能产生相近结果；颜色不同也可能涉及选择器范围、继承或覆盖。若无法确认具体来源，结论写为“观察到颜色变化，来源未确认”，不要把推测记录为已经验证的应用能力。

## 保留一次独立对照

如果出版者提供另一份明确不含该媒体查询的合法测试副本，可在保持设备与应用设置不变的情况下，比较同一个自制段落。先核对文件身份，确保没有把原书和副本误认为相同版本；两份文件之间除目标规则外还可能存在其他差异，因此单次比较依然不能证明因果。没有具备许可的对照文件就跳过，不自行修改唯一原件。

## 记录可读性而非偏好高低

浅色和深色只是不同外观偏好，阅读舒适度受环境光、文字大小、个人视觉条件和显示器影响。对本次样本记录自己是否能辨认文字及边界，不推断某个主题必然适合所有人；若需要更精确的颜色对比评估，应在有授权的副本和合适工具中另行测量。保持任何个人辅助设置私密，完成后及时恢复。

## 一组可复现的自制样本

自制样本可给段落设置浅色规则：选择器 p 使用黑字 #000000 和白底 #ffffff；另在 prefers-color-scheme: dark 条件中为同一 p 设置白字 #ffffff 和黑底 #000000。记录两种声明和应用实际显示，再只改变一个外观条件进行比较。两组是格式示例，不证明书屿采用该条件；如果应用强制自身主题或没有可用切换，按实际记下。
