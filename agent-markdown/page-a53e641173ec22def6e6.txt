用四组自拟系数核M=(L+R)/2、S=(L−R)/2及逆变换，将编码表示、声道标签和实播观察分开。

Mid与Side是一种双声道表示方式，不是自动找到人声与伴奏的两条独立录音。本课声明自己的归一约定，外部复算和差与逆变换，再用自制说明片核标签；云映不被假定内置M/S编码器、分轨器或自动混音分析。

## 先固定同一原始波形与声道身份

选自己的短录音作为u(t)，先在外部确认归一幅度不超过一，再把L、R定义为这同一波形乘不同系数。表中的0.6与0.2是增益系数，不说整段每个样本都恒定为这些值，也不把常数直流当可听演示。保留原录音、系数表和左右标记，声音由外部准备，云映只用于可读成片的观看。若材料本来是单声道，先记缺少真正的左右输入，不从只有一个音量滑块的界面猜出两份独立声道。

## 明确半和半差这个归一约定

本课定义M=(L+R)/2、S=(L−R)/2，逆向则L=M+S、R=M−S。其他设备或格式可能采用不同缩放，不能只看到M/S字样就直接套数值。把前后两张矩阵卡配对保存，先由代数展开证明逆向恢复L与R，再讨论声音；若漏掉除二，逆回会多一倍，不能靠降低播放器音量掩盖错误。这里仍只有两个数值通道，Side不是从原录音凭空分离出的第三名说话者，Mid也不保证只含人声或画面中央的物体声。

## 逐行复算四组原创系数

第一组L为0.6u、R为0.2u，得到M为0.4u、S为0.2u，逆回仍为0.6u和0.2u。第二组交换左右，M不变、S变成负0.2u，说明Side符号与本课定义的左右次序有关。第三组两边同为0.5u，S为零；第四组L为0.5u、R为−0.5u，M为零而S为0.5u。负号表示极性，不是负时间或播放器回放倒着走。四行都采用同一u，才可直接比较系数；若换了另一段录音，必须重新说明输入关系。

```
declared convention: M=(L+R)/2; S=(L-R)/2
inverse: L=M+S; R=M-S
all coefficients below multiply the SAME bounded waveform u(t)
case       L       R        M        S
1          0.6     0.2      0.4      0.2
2          0.2     0.6      0.4     -0.2
3          0.5     0.5      0.5      0
4          0.5    -0.5      0        0.5
case1 with S discarded: reconstructed L=R=0.4*u
raw M/S labelled as L/R is NOT the inverse transform
```

## 做一次只保留M的故障对照

在第一组副本中故意丢掉S，令S为零再逆回，两边都会变成0.4u，已不等于原来的0.6u、0.2u。这说明丢失一部分表示会改变可恢复信息，不证明任何单声道播放一定采用同样计算。另一故障是把M、S未经逆变换直接标成左、右输出，那是0.4u与0.2u的另一对通道，不是正确还原。保留两个故障副本的确切处理步骤，不把可逆编码、舍弃分量和通道误标都概括成一种音质变化；先核数值身份，再记录实际听感。

## 外部制作带矩阵说明的成片

将四组系数、正确逆回和丢S对照放进自己的说明画面，若具备外部音频工具，可把同一u按系数制作相应双声道段，并在保存前复核没有额外自动归一化。云映所用成片应已正确导出为普通左右声道，不要求播放器把M/S当作左右再自动解码。若只能做文字说明，保持成片静音并明确没有进行声音比较。保留项目与导出处理记录，若压缩或系统重采样介入，纸面可逆等式不等于最终设备字节也原样可逆。

## 实播时分开通道标签与空间感觉

通过已可用来源打开说明片，先读当前哪一组与是否为正确逆回，再固定音量、输出设备和声音设置。实际左右能否辨认按观察填写，系统单声道选项、扬声器串音或不同耳机都可能改变听感，不能只听中间声像就判M公式已被播放器调用。若确有声道记录，仍需外部原件支持标签；画面写Left并不保证媒体里真装在左边。没有精确通道量测就不填写隔离度、相关系数或无损解码认证，也不将本课说成自动去人声操作。

## 按约定、符号和逆向步骤排障

逆回大一倍先查漏除二，左右互换先查S的符号及逆矩阵，只有中间成分先查是否丢S，而不是同时修改整套音量和输出。若外部正确而实播不同，再查封装、通道配置和系统处理，不从单次听感把代数恒等式判错。每次只修一个故障副本，使用原四行系数复算，保留未经修改的u。不要把不同软件的M/S归一命名强行视为同一数值协议；需要对接真实工具时先读它自己的说明，未核之处写未知。

## 重开交付正逆两张卡与丢失项

保存正向、逆向、四组结果与两个故障副本，重开逐行验证M加S回L、M减S回R，并确认所有系数仍乘同一u。实际重开云映只重复具备的观看与听音条件，尚未制作或未播的例子明确待做。验收能够解释为何交换左右会让S变号、为何丢S后两边同为0.4u，以及为什么M/S不是三个独立声音来源。原录音与可编辑项目都保留，不许诺云映新增M/S编辑、自动人声分离、完美空间定位或全设备逐样本还原。
