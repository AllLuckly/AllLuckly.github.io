Learning path · 20 tutorials

Begin with local ebooks, reading layout and notes, then connect WebDAV, SMB, OPDS or Calibre and check reading-data sync.

[Start with the first tutorial](<https://allluckly.cn/en/guides/nasbook-getting-started/>)[About Book Isle](<https://allluckly.cn/en/apps/nasbook/>)

Use one of your own ebooks to learn importing and reading before connecting a remote library. Each tutorial includes a result check, so a title in a list is not mistaken for a fully available book.

Book Isle does not supply books. Reading-data sync and moving book files need separate handling. Some manageable formats do not yet support full reading; check the limits stated in the tutorial and app.
