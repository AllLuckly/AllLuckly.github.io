Fix an original Chinese/English version note and verify input states and final characters segment by segment.

## 1. Fix the complete delivery target

Use target `周五 review v2.1，确认后再发布。` as nonsensitive practice, not a real publishing schedule. Specify lowercase review, no space inside the version, and one ordinary space at each of the two language/version boundaries. Preserve the reference separately from typed results; pasting it does not establish keyboard entry. Meaning, case and separators all matter, not approximate similarity. A different date/version needs its own target rather than a silent mid-task substitution.

## 2. Identify the keyboard and language path

Confirm Jianlai and an established Chinese/English switching path. The containing app’s interface language need not change. Retain layout, theme and host instead of also comparing nine/26 keys. Use an actual direct mixed-entry path if available, recording it without promising automatic language detection everywhere. Revisit enabled input choices if needed rather than type through another keyboard and attribute the result to Jianlai.

## 3. Commit the opening Chinese before its separator

Enter and commit the opening Chinese before handling its separator. During composition, a space-bar action may confirm a candidate; do not assume one press both commits and inserts a gap. Inspect actual output. Establish the insertion point after committed text before changing language. Use a controlled ordinary note instead of a real work-group notice. Verify the opening characters/position now rather than skip them because English follows.

## 4. Check English case and boundaries

Select the actual English state and verify the word’s case in the document, not only a candidate suggestion. Record any capitalisation/substitution and correct through available keys and host positioning without inventing an autocapitalisation switch. Inspect ordinary spaces on both sides; proportional spacing can obscure count, so use cursor checks where available. Keyboard-theme fonts do not promise identical document styling. Separate appearance from character identity.

## 5. Check the version’s letters, digits and dot

Enter the version and inspect its Latin letter, two digits and ASCII dot with no internal spaces. A Chinese full stop is not interchangeable with that dot, and case differences remain differences. Follow actual digits/symbol controls without fixed coordinates or invented holds. An unavailable character leaves the task incomplete instead of being substituted and passed. This is a textual version identifier, not decimal arithmetic or a promise of automatic mathematical formatting.

## 6. Return to Chinese and inspect the complete sentence

Return to Chinese for the target punctuation and ending, commit it and read the complete sentence. Check both spaces, version boundaries and final full stop for losses or duplication. Whole-sentence candidates still need segment-level document inspection. An external four-part checklist is sufficient; no built-in proofreader is assumed. Do not pre-label an automatic substitution as a fault when it did not occur. Retain this round’s actual text.

## 7. Diagnose language state and character differences

For wrong Chinese, inspect scheme/candidates; for English case, inspect committed text; for spaces/dots, inspect characters and composition state. These are not all language-switching failure. Correct one location without resetting themes, system language or all keyboards. Preserve before/after evidence. Missing saved text belongs to host-storage diagnosis, not invented cross-app synchronisation or deletion by Jianlai. Use the original practice sentence for help rather than a real notice, leaving undocumented detection/correction unknown.

## 8. Reopen and deliver exact text rather than gist

Save, leave and reopen, then compare Chinese, lowercase English, version, two spaces and punctuation with the target. Retain entry path and actual corrections rather than infer document identity from keyboard appearance. A new note needs a new target and input round; old screenshots are not current evidence. The deliverable is one character-checkable mixed draft, not automatic translation, publishing-workflow understanding, permanent proper-name learning or device certification across all layouts/hosts.
