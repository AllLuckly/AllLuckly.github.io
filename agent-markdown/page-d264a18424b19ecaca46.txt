## Prepare two verifiable target sentences

In an ordinary practice note, write two original targets: “今天的天气很好。” and “今天的计划很好。” They share “今天的” but end differently. Keep targets separate from blank input lines and avoid real schedules, accounts or private messages. Confirm Jianlai and an available Chinese input scheme are active; record device, host and installed version if visible. Its public listing describes multilingual input and prediction, but does not guarantee a specific suggestion, ranking, language or host.

## Type the shared prefix manually

On a new line use the actual Jianlai scheme to enter “今天的” and confirm it remains in the document. Then observe whether any selectable suggestion is visible around the keyboard. Do not place “天气” on the test line first and call it a suggestion. If an unconfirmed composition remains, complete and verify the prefix using real controls; candidates used to form “今天” are distinct from suggestions appearing after the committed prefix. Record only what is actually shown. If the same area contains candidates for current composition and possible continuation suggestions, describe the actual state, whether input was confirmed, and document changes before and after selection. ## Check whether a suggestion matches the target

If a continuation suggestion appears, inspect its characters before deciding whether it matches “天气” and whether to select it. A different word is not the intended choice. If there is no suggestion, target or clear selection action, record absent or pending and finish manually; do not repeatedly type merely to force an expected screenshot. Do not assume space or Return accepts a suggestion just because another keyboard behaves that way, or claim fixed ranking or known learning behavior.

## Record selection and document text separately

If the target suggestion really appears and you select it, record the text and actual action, then finish “很好。” and inspect the document. Otherwise type the continuation manually and label it as such. Suggestion appearance, user action and retained text are separate states. Check the full sentence, Chinese period and neighbors; preserve the first result and correct only a copy. Manually typed text is not a successful suggestion, and a visible suggestion is not necessarily already committed.

## Complete the second sentence manually

On another line enter and confirm “今天的” again, observe the current display and manually complete “计划很好。”. Record any actual selection; there is no need to choose a suggestion. The two targets share a prefix but have different intended continuations, so a plausible suggestion need not match this task. If a host or keyboard changes the text, preserve the original result before diagnosing; do not automatically attribute host replacement to Jianlai.

## Separate target match, suggestion and selection

Compare each original line with its own target. Correct text, appearance of the target suggestion and its actual committed effect are three distinct questions. Correct manual text is possible without a suggestion, and a different suggestion is not necessarily a fault. If a target appears but the result differs, preserve action order and cursor location before reviewing a copy. Two short trials do not measure prediction accuracy or establish what every user will see.

## Troubleshoot scheme, focus and host

If no suggestions appear, first verify the active keyboard, available Chinese scheme and ordinary field focus, then inspect settings or guidance actually provided by the installed version. Do not assume Apple’s system-keyboard predictive toggle controls Jianlai internally, or change privacy restrictions or grant extra access merely to force a suggestion. If visible choices do not respond, record the action and host and compare another ordinary field if practical. Leave unresolved behavior pending.

## Deliver the two records and restore settings

Keep the targets, actual prefix, visible suggestions, selection actions, original committed lines and unfinished checks. Do not collect private typing history or clear a dictionary to force a result. Restore your usual input scheme and confirm note and backup remain. Apple’s predictive-text documentation describes the system keyboard and does not automatically establish Jianlai key behavior.
