Distinguish four corners, two interior points and a boundary midpoint from hull vertices, then add an exterior point to obtain a five-vertex hull.

English translation of the [Chinese original](<https://allluckly.cn/guides/vectorpaint-convex-hull-interior-boundary-extreme-points/>), translated on 2026-11-19. Original publication dates, attribution, code and version notes are retained.

Enclose a point set in its smallest convex set without requiring a boundary tour through every input. Interior points belong to the hull but are not extreme vertices; an input midway along a straight edge need not create a corner. Specify an extreme-vertex output convention, then check segments and half-planes instead of accepting any rubber-band-looking outline.

## Plot seven distinct points by coordinates

Take A=(0,0), B=(6,0), C=(6,4), D=(0,4), E=(2,1), F=(4,3), G=(3,0). On about 1600 × 1200 pixels use u=300+140x, v=900−140y, reserving room rightwards for a control point. Use equal markers without connections first. Group points, boundary, notes and control, then save. Do not delete E and F as noise because they appear inside. G’s collinearity with AB is a positional condition, not a duplicate input or identical point.

## Separate the smallest convex set from a visiting tour

A set is convex when the whole segment between any two of its points remains inside. Its convex hull is the smallest convex set containing all inputs. “Smallest” concerns set inclusion, not a shortest path visiting seven points. Close ABCD with a pale interior: E and F lie inside and G on the bottom edge. Explain that filled region and boundary together represent the hull; four lines alone may imply that only the outline is the set. Path filling performs no convexity analysis.

## Retain the four corners without adding interior vertices

Every convex set containing the inputs contains their four corners and all convex combinations of those corners, hence the whole rectangle. The rectangle contains the other three points, so it is exactly the hull. Output extreme vertices A, B, C, D counterclockwise, closing to A without counting A again. Keep E and F as interior markers instead of dragging them onto the boundary. G lies between A and B without a turn, so this extreme-vertex list omits G, not its membership in the hull. G=(A+B)/2 directly represents it as a nontrivial convex combination of distinct inputs, so it is not extreme. E also equals one half A plus one quarter B plus one twelfth C plus one sixth D. These nonnegative weights sum to one and yield (2,1). Check weights separately instead of treating them as screen coordinates. This demonstrates containment without making E a fifth boundary vertex. One such representation establishes inclusion; uniqueness is unnecessary.

## Check every point on the left of each directed hull edge

For counterclockwise edges AB, BC, CD, DA, require respectively y≥0, x≤6, y≤4, x≥0 for every point; all seven satisfy them, including equality at boundaries. Equivalently use cross(U,V,P)=(Vx−Ux)(Py−Uy)−(Vy−Uy)(Px−Ux): nonnegative means left or collinear. AB gives zero for G and six for E; BC gives eight for F. Calculate before labelling. Screen-down coordinates reverse orientation signs, so do not apply mathematical counterclockwise tests directly to screen rows.

```text
A=(0,0); B=(6,0); C=(6,4); D=(0,4)
E=(2,1); F=(4,3); G=(3,0)
extreme hull vertices CCW: A,B,C,D
G on boundary, not an extreme vertex; E,F inside
cross(A,B,G)=0; cross(A,B,E)=6; cross(B,C,F)=8
add H=(8,2): hull A,B,H,C,D; area 24+4=28
wrong tour turn cross(C,F,D)=-6
```

## Reconstruct the boundary after adding an exterior point

Save a version adding H=(8,2). It lies right of old BC, violating x≤6, so the old rectangle no longer contains all inputs. Close new extreme vertices A, B, H, C, D and weaken old BC as an internal reference, not a hull edge. Independently check area: old rectangle 24 plus triangle with base BC and height two, area four, gives 28. Area is not the definition. Add only H, without moving E, F or G; relocating labels without changing the boundary is not an update.

## Use an all-point concave tour as a failed hull

A control tour A, G, B, C, F, D, E, A visits every input but indents inward. At C, F, D, vectors CF=(−2,−1), FD=(−4,1) have cross product −6, contradicting a counterclockwise convex boundary’s nonnegative turn. Visiting all inputs and closing is insufficient; this is not another valid hull. Also note that wholly collinear inputs have a segment hull. This example’s noncollinear corners justify polygon-vertex terminology.

## Diagnose missing points, collinear points and concave turns

If all seven are called mandatory vertices, distinguish inputs, boundary points and extreme points. Restore G’s boundary marker if omission from the vertex list was mistaken for exclusion from the set. After adding H, test the old right half-plane for a missed exterior point. Fix a concave tour at its negative turn rather than hiding the indentation with transparency. Keep baseline and control, checking every point against every hull edge. Approximate placement is not exact collinearity; retain coordinates and do not assume paths recompute a hull when nodes move.

## Reopen and check containment and minimal convexity

Save native work and seven-/eight-point lists, export SVG or PDF and open a PNG separately. At fit-to-window size compare four- and five-corner versions; enlarge for G on AB without a false turn and visible E/F. Reopen editable work, hide the answer, recover the old hull through four half-planes and test BH and HC.
