## Start with what you want to do

| Your task | App | Before you start |
| --- | --- | --- |
| Watercolour-style illustrations and sketches | [Aquarell](<https://allluckly.cn/en/apps/aquarell/>) | PSD export preserves raster layers; editable text and groups are not guaranteed. Keep the native project for further editing. |
| Import local CBZ, CBR and PDF comics | [ManYue](<https://allluckly.cn/en/apps/manyue/>) | The app does not supply comics. Some server and sync features require a membership. Ordinary OPDS downloads and OPDS-PSE page streaming are different capabilities. |
| Create geometric icons and logos | [VectorPaint](<https://allluckly.cn/en/apps/vectorpaint/>) | SVG and PDF can contain raster images. Exporting does not automatically turn a photo into vectors; tracing results depend on the source and colour settings. |
| Read local TXT, EPUB, PDF and supported documents | [Book Isle](<https://allluckly.cn/en/apps/nasbook/>) | No books or online bookstore are included. In the checked version, MOBI, AZW, AZW3, CBR and DJVU mainly support management and sync rather than full reading. Reading-data sync does not transfer every book file. |
| Play local videos and videos from Photos | [iCouldPlay](<https://allluckly.cn/en/apps/icouldplay/>) | You provide the videos, accounts and servers. Compatibility depends on the file, device and playback engine. Poster matching, remote access and offline downloads are separate tasks. |
| Import and organise your own game files | [Yearn](<https://allluckly.cn/en/apps/yearn/>) | No game ROMs are included. Some platforms need a matching BIOS supplied by you. Importing does not guarantee compatibility. Save states, in-game saves and cloud sync are different; verify progress before changing devices. |

These introductions describe the versions and sources checked on each page. Check the App Store and current in-app screens for compatibility, pricing and membership details.
