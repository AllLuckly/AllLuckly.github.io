A half-visible character at a page edge may lie outside the current view or may already be cropped from the source. Establish boundary evidence for one page in ManYue before choosing another readable copy. This is not simply a lettering-sharpness check, and assumes neither automatic edge reconstruction nor that every intentional bleed is an error.

## Choose a page with identifiable edge information

Choose an already-read page with a balloon, page number or frame and record edition, chapter and suspected edge. Do not change sources, reinstall or add margins to the sole original first. Determine whether lettering is cut or dialogue is intentionally interrupted, a balloon crosses a frame, or artwork bleeds. Read adjacent panels before asserting missing content; awkward phrasing alone is insufficient. Use another clearly closed edge on the same page as a control and retain uncertainty where necessary.

## Return to a view that establishes the whole image

Use visible gestures or settings to reach a view where all image edges can be checked, without assuming an unverified universal reset button. Inspect top, bottom, left and right rather than shrinking slightly around the centre and calling it full-page. Paired-page or split-wide-image modes affect the viewport; record prior settings and compare a complete single image if needed. Rotate separately from layout changes. If the edge reappears, identify a viewport issue rather than declaring source corruption.

## Compare boundaries with fixed landmarks

Record at least two landmarks, such as a top-left frame junction, right balloon closure and bottom page number. Black margin width alone is unreliable when the display background hides the file boundary. Compare image proportions cautiously: a different screen ratio does not prove cropping. If a landmark remains absent, note its direction and nearby wording for source comparison. Do not introduce a cropped screenshot as the page itself, since its new edges would confuse the test.

## Inspect the actual same source file

Open the identical file and page in a trusted image or PDF tool, not a cover thumbnail or another scan edition. Missing source content cannot be reconstructed by the reader; check an authorised source for a complete revision. If the external path shows more, record conditions and investigate layout, server previews or conversion. This narrows the layer without proving a specific cropping routine. Preserve the original for a reproducible comparison.

## Separate binding loss from image boundaries

A scan near the binding can hide, warp or darken text without the file boundary cutting it. Distinguish a hard image edge from a visible gutter containing distorted characters. Added margins enlarge the canvas but cannot restore unscanned material. Generated reconstruction is not evidence of the original sentence; obtain a reliable complete copy for quotation. Intentional decorative bleed without lost information may need no change, and does not justify recropping an entire book.

## Verify that a replacement is actually complete

Match an authorised complete replacement by landmarks and surrounding action, checking for revision rather than assuming it restores the same line. Inspect the problem page, beginning, middle, end and spreads to catch new omissions. Label source and edition and retain the old file until accepted. Changed numbering, image count and boundaries can shift positions; relocate bookmarks and notes by chapter and image rather than assuming same-title import inherits every record. Then decide which copy is primary.

## Keep a recoverable boundary evidence pair

Keep original and comparison paths, page identity, two landmarks, observations and supported references or an external locator. Prefer a self-made four-corner-labelled sample for reporting, stating whether it reproduces the same display difference. Describe direction and dimensions when the private page cannot be shared, instead of uploading a volume. Label screenshots as rendered results and separately retain source identity; disclose screenshot resizing so its boundary is not mistaken for the original’s.

## Acceptance and when to stop

Finish by distinguishing viewport, delivery path, file boundary and binding loss, excluding at least one while retaining unknowns. Added white canvas does not restore letters. A fuller different edition requires identity and authorisation checks before any patching. Stop repeated cropping once a usable copy is confirmed; uniform white margins are not the objective. For unresolved cases, retain the original and minimal evidence pair rather than disrupting page order or reading records over one edge issue.
