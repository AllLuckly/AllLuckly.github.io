DEVELOPMENT NOTES · 7 articles

These notes ask where a task runs and why an interface stalls. They cover threading fundamentals, RunLoop and diagnostic techniques. Sketch the possible execution order before returning to the code.

## How to read this collection

1. Read the three threading articles in order. Distinguish tasks, queues, threads and synchronous waits; write out possible execution orders for nested calls.
2. Next, examine RunLoop and thread lifetime. Ask when a thread waits and what wakes it, rather than treating a persistent thread as a universal fix.
3. Relate stall detection and UIKit tuning to a real workload. Define what you measure, then compare timing, call stacks and screen behaviour. Historical measurements are not conclusions about current devices.

These notes date from 2015–2017. Their examples have not been rerun for this archive update. Check the dates and version notes before applying the ideas to a current project.
