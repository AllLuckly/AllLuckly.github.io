Text copied from a picture needs proofreading against the image. On supported devices, languages and regions, Apple’s Live Text can select and copy text from Photos. Recognition is a system function, not a built-in Jianlai scanner. Jianlai is used for subsequent input and corrections in an ordinary note. This exercise records recognition, paste and proofreading separately using a non-sensitive card you make yourself.

## Prepare a practice card and safe copy

Write two clear lines on paper, for example “天气晴朗” and “下午三点”, and photograph them yourself. Avoid phone numbers, addresses, real appointments and other people’s information. Check both lines are clear and complete. Uploading or sharing is unnecessary. Create an ordinary practice note titled “Image text proofreading”; do not paste recognition results into a payment, contact or instant-message field.

Confirm the device supports Apple Live Text, Photos opens the image and Jianlai can be used in the note. Live Text is not available in every language or region. If recognition is unavailable, consult Apple’s system guide or mark it pending without changing accessibility or privacy preferences against the user’s wishes. Record system and Jianlai versions, photo source and practice sentences, not device identifiers.

## Select text in Photos first

Open your photograph in Photos. Use the currently visible Live Text control to recognize it, then select only the first line, adjusting the selection boundaries. Apple says recognized text can be copied to Notes and other apps; wording depends on the system. Check both ends of the selection before choosing Copy or its equivalent. Do not invoke phone, URL or other quick actions.

If selection controls are absent or the result clearly omits a line, record that observation. You may improve lighting and clarity and take a new photo, but do not rewrite the card to fit the recognition or attribute system recognition to Jianlai. If the device is unsupported or the user does not want to enable the feature, mark the exercise unfinished and stop.

## Paste into the note and preserve the initial result

Return to the note, confirm the insertion point is on a new line and use the host’s visible paste action. Record any system paste permission prompt and let the user decide; do not bypass it. Save the initial recognized result immediately, optionally copying it to another line before corrections so the comparison remains available.

Compare the image and pasted line character by character: order, each character, spaces and omitted text. Make columns for card, initial recognition, differences and corrected result. If “天气晴朗” is copied exactly, honestly record “matches”; do not invent an error. Compare with the photograph rather than memory. Jianlai is not needed for this initial stage.

## Correct the practice copy with Jianlai

When correction is needed, confirm Jianlai is active and use the host’s available insertion-point or selection controls to locate the difference. Change one character first: inspect neighbors, enter and select the target candidate, and verify it is committed. If a wrong candidate or too large a range was replaced, record the result and use the host’s available undo or the initial copy to recover. Do not blindly delete repeatedly when undo is unavailable.

If recognition was entirely correct, a separate practice copy may deliberately change “晴” to “清”; label this a human-created demonstration difference and use Jianlai to change it back. Do not report the artificial error as Live Text failure. If precise positioning or selection is unsafe or unclear, retain the initial result and mark proofreading incomplete rather than resetting the keyboard or changing permissions.

## Check the second line and final result

Return to the photo and copy only the second line to a new position in the note. Record the initial paste before checking each character of “下午三点”. Check for an omitted second line, merged lines or extra spaces as possibilities, not predetermined outcomes. If the system did not recognize the second line, mark it unrecognized; manual typing is not automatic copying.

Correct any differences one character at a time. Save and reopen the note, comparing both lines and their order with the card. Record which characters came from system recognition, which were changed manually and which remain unverified. Matching appearance establishes this visual check only, not character encoding or accuracy on every other image.

## Troubleshoot and restore

For an empty paste, check whether the selection was copied, the insertion point and the system prompt. If Jianlai is absent, check the ordinary field and active input method. For recognition differences inspect image clarity and selection; for editing errors inspect selection and candidates. Do not attribute all three to Jianlai. Change one condition at a time and keep a recoverable copy; do not uninstall or clear an entire clipboard history to troubleshoot.

The user chooses whether to retain or delete the practice photo and note, identifying each precisely first. Do not transmit private material. This exercise uses public documentation, does not claim a device test and does not guarantee the same flow across devices, languages or hosts.

For a different photo, font or camera angle, preserve a new initial result and correction record. This attempt’s accuracy cannot predict another image. The user chooses the practice-card text.
