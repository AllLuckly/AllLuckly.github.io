Draw an exploded fictional organiser with a shared axis, consistent gaps, leaders and part names, keeping illustration separate from assembly precision.

English translation of the [Chinese original](<https://allluckly.cn/guides/vectorpaint-exploded-diagram/>), translated on 2026-10-26. Original publication dates, attribution, code and version notes are retained.

An exploded diagram separates overlapping parts to explain their order. Practise with a lid, insert and base box. This hand-drawn illustration does not provide a 3D model, material calculations or assembly-interference checks.

## List the parts and their order

List the lid, insert and base from top to bottom and note each purpose. Confirm actual structure and disassembly order for a real object. On a 900 by 1100 pixel canvas, establish a temporary centre axis and right-hand label area. Use three simple blocks to test order and height, and label the work as a structural illustration.

## Establish the common closed outline

Build the base from a simple top and sides. Use shared width and edge directions for the lid and insert, then view them together as a closed object. Correct inconsistent vertices rather than rotating an entire part to hide a mismatch. Group each part’s surfaces and details under a useful name for later separation.

## Separate parts along a shared direction

Move the lid upward and base downward around the central insert, keeping their centres near one axis. Open enough space to reveal overlaps without losing their relationship. This is manual separation, not an automatic 3D explosion. Begin with equal gaps and refine them visually. If surfaces separate incorrectly, check for an incomplete part group.

## Show correspondence with light reference lines

Add light lines between a few corresponding corners, keeping them weaker than part outlines so they do not resemble supports. Segment and stack them behind parts where appropriate, and avoid labels. Two informative correspondence lines are usually better than a dense grid. Hide them temporarily to confirm that the parts themselves remain recognisable.

## Create a separate annotation column

List lid, insert and base in a right-hand column with a short purpose each. Start leaders on identifiable surfaces and order labels to avoid crossings. Move lengthy explanations below the diagram. If using numbers, place the same numbers on the drawing and list. Read each leader’s actual target rather than assuming its proximity is clear.

## Check the assembly relationship and output purpose

Inspect shared directions and centres when zoomed out, then seams and leader endpoints closely. Save the original and reopen an export without temporary axes. Real assembly instructions also need confirmed order, orientation, fasteners and wording. A matching closed view can help, provided it uses the same part names and colours.

## Test a change to one part

Increase only the base side height in a test, retaining shared face directions and other part widths. Check lower edges and reference lines, then separately reduce the lid-to-insert gap. Compare shape and spacing effects independently. Record the clearer result. Real structural changes also require renewed part-name and assembly-order checks, not merely a taller illustration.

## Restore coherence when parts seem unrelated

If parts resemble unrelated boxes, reduce the gaps, restore common proportions and remove unnecessary heavy bottom faces. For confusing leaders, fix the target before moving the label. Inspect seam geometry and stacking before judging export hairlines at normal size. Obtain precise measurements from verified drawings rather than measuring this hand-drawn illustration.
