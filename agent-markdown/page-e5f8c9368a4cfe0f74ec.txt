用两行原创文字，在两个自己的普通编辑宿主之间做一次复制交接，再用键来只修改目标副本的状态词。最终保留原稿、交接结果和改后目标三份对照；复制粘贴由宿主或系统提供，键来负责文字输入，不假定云同步、剪贴板历史或跨应用格式保真。

## 一、明确两个宿主与两份文档身份

选两处自己能编辑并辨认的普通正文区域，尽量使用不同宿主，分别在外部笔记标为原稿甲与目标乙，避免因标题相似误改同一份。用全新的无隐私练习文档，不操作真实消息、共享文件或业务清单。先确认乙确实可接收普通文字，回车不会发送内容，再把当前宿主名称与文档标识记在观察表。甲与乙只是本地练习身份，不意味着同步关系；若只有一处可编辑宿主，就先准备甲并把跨宿主部分记为未执行，不能把在同一文档里选中两段文字冒称完成了应用间交接。任务目标是保留原稿并让副本独立变更。

## 二、在原稿甲输入两行基线

在甲确认键来后输入下方原样两行：第一行中文标签后有一枚半角空格，编号按大写字母与零七保留；第二行中文状态标签后是一枚半角冒号、一枚半角空格与英文草稿词。两行间只有一次硬换行，不加代码围栏、句号或说明。提交组合后逐段核对正文，特别检查编号零不是大写字母欧，状态词没有自动首字母大写。甲是否真正保存由宿主决定，先做它实际可用的保存流程并记录结果，不据键盘收起便推定已保存。保留一份外部基线抄录或截图用于后续比对，但可复制原文仍是主要交接对象。

```
清单 B07
状态: draft
```

## 三、用宿主选择与复制，不剪切

通过甲实际提供的选择能力选中完整两行正文，核选区不包含文档标题、旁注或其他段落，再使用宿主或系统明确标为复制的动作。不要选择剪切，因为本课要求甲保留原文。复制后先回看甲仍有相同两行，若误剪切，应依据基线在练习副本恢复并重新核对，记录这次偏差，不继续把残缺源稿当成功交接。Apple 文本编辑资料说明系统选择与复制粘贴的作用，这不等于键来有同名工具栏。当前若仍有未提交组合，先处理组合再选正文；候选文字与文档选区不是同一对象，不能混作两行都已经复制的证据。

## 四、在目标乙粘贴并先做不改稿验收

切换到乙的空白普通正文，把插入点放在预定位置，用乙或系统实际可用的粘贴动作放入内容。先不通过键来改任何字，逐行比较甲与乙的文本，核标签、编号、半角冒号、空格与一次硬换行均一致。若宿主出现粘贴许可或替代选项，只按自己能辨认的流程继续，结果不确定就停下记录，不能为了凑完成状态假定已经粘贴成功。字体大小、颜色或视觉折行可能不同，本课验收的是字符与原行边界，不保证富文本格式相同。保留乙刚接收的状态快照，再开始后面的局部修改，防止混淆交接差异和编辑差异。

## 五、只在乙把状态词改为就绪词

确认自己仍在目标乙，用宿主选择或插入点定位第二行的英文草稿词，再通过键来替换为下方目标里的英文就绪词。只替换这个词，中文标签、冒号、空格、第一行编号与换行全部保留；新旧词长度相同也不能据列宽相同跳过逐字核对。若选区误含冒号或换行，先取消重选，不用连续输入覆盖更大范围。提交完成后，将乙与改后目标对照，确认并未把真实工作状态同步到任何服务，这只是练习副本的一段文字。键来提供输入，定位与选择由宿主实现，本课不编造专用替换按钮或自动状态管理。

```
清单 B07
状态: ready
```

## 六、回到甲证明原稿确实未变

离开乙前按其实际方式保存或保留练习结果，再回到甲，检查第二行仍是原来的草稿词而非就绪词，第一行编号与原始两行边界也一致。此处不能只凭“我做的是复制”就填通过，必须真的回看；若甲也改变，先查是否两处其实打开了同一文档、同一共享源或自己切错窗口。不要立即归因为键盘自动同步，更不要为验证而删除任何原文件。把甲现在的文本与基线、乙改后的文本做三方对照，明确哪份应相同、哪一词应不同。若发现文档身份混淆，保留现状与基线，重新建立清楚的私人练习副本再做一次。

## 七、排查复制范围、原文与显示差异

乙多出标题或说明时，回查甲的复制选区；少一行时，核硬换行与选区终点；粘贴后符号变宽或词被大写时，比较接收前后文本并调查乙的自动处理。若只是字体不同或屏幕折行，不在没有字符差异证据时认定复制损坏。若乙无法输入键来，另记宿主输入限制，不把它和剪贴板内容混为一谈。每轮只修一个环节，保留基线甲与乙初收快照，避免反复复制改后内容反向覆盖原稿。本文不提供剪贴板历史恢复承诺，误复制后应依据保存的练习原文重新开始，而不是寻找未经公开的键来云备份入口。

## 八、交付三份对照与操作归属

保存甲基线、乙初收与乙改后三份对照，并附甲最终回看仍未变的记录，明确实际宿主、文档身份、复制和粘贴动作是否执行。输入验收看字符，交接验收看乙初收，独立副本验收看甲回看和乙改后，不能用一次截图代替全部环节。尚未真正保存重开的文档，持久化栏留未测试。以后换宿主或接收字段时，应重新验证源字符和换行，不能把这次通过扩大成所有应用兼容。成果是有证据的文字副本交接与局部修订流程，不是云同步设置，也不证明键盘拥有复制记录、跨设备状态或真实任务发布能力。
