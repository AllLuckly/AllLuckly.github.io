## 如何选择？

| 你想完成的事 | 对应应用 | 先了解 |
| --- | --- | --- |
| 把灵感画成一幅水彩插画 | [Aquarell](<https://allluckly.cn/apps/aquarell/>) | Aquarell 以像素绘画为主；PSD 导出的是像素图层，不能据此认为文字与图层分组仍可编辑。继续创作应保留原生作品，导出图片适合分享。 |
| 把自己的漫画书库带在身边 | [漫阅+](<https://allluckly.cn/apps/manyue/>) | 漫画文件与漫画源由用户自行添加，应用不提供漫画内容。部分 NAS、同步与服务器功能需要会员；普通 OPDS 只有整包下载链接时不能直接逐页阅读，需区分 OPDS-PSE。 |
| 从第一条路径到可编辑的设计 | [VectorPaint](<https://allluckly.cn/apps/vectorpaint/>) | SVG 或 PDF 可以包含作品中的位图元素，导出不会把所有图片自动变成矢量。图片矢量化更适合线稿、标志和平涂图，照片效果取决于原图及颜色数量。 |
| 把个人电子书库整理成随时能读的书架 | [书屿](<https://allluckly.cn/apps/nasbook/>) | 书屿不提供在线书城或书籍资源。当前核对版本中，MOBI、AZW、AZW3、CBR、DJVU 主要用于导入管理与同步，不能据此认为可以直接阅读；阅读数据同步与书籍文件传输是两件事。 |
| 把本地视频和个人服务器放进同一个播放入口 | [云映](<https://allluckly.cn/apps/icouldplay/>) | 视频、账号与服务器由用户自行准备，应用不提供影视资源。格式支持仍受编码、设备与播放引擎影响；海报匹配、远程播放和已下载内容的离线观看需要分别检查。 |
| 整理自己的复古游戏，接着上次的进度玩 | [Yearn](<https://allluckly.cn/apps/yearn/>) | Yearn 不附带游戏 ROM，部分平台需要自行准备匹配的 BIOS。导入成功不代表每款游戏都能正常运行；即时存档、游戏内存档和云端同步需要分别核对，换设备前应确认同一游戏能识别并读取保留的存档。 |

这里是开发者的应用介绍与使用指南。功能、价格与可用地区以官方 App Store 页面为准。
