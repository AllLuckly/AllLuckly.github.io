Record source and visual anchors for two authorized comic copies, then compare imported entries and their reading positions.

## Prepare two distinguishable samples

Choose two authorized comics with the same title but distinguishable covers or chapter content. You can use your own short practice comics: write “Version A” on A’s first page and “Version B” on B’s, and pack each ordered set of numbered images as CBZ. Keep the original folders and archives; do not use another person’s private work. Record size, filename, cover and a distinct marker on each second page. Title alone does not identify an edition.

## Import the first copy and establish a baseline

Use the installed ManYue interface’s local import method for A. After import and parsing finish, find the resulting shelf entry and check its cover, second-page marker and page count. Leave it on the identifiable second page, exit and reopen, then record the actual position. If import fails or its page count differs from the source archive, investigate the file before treating A as a reliable baseline; do not overwrite the original archive.

## Import the second copy and read actual prompts

Import B next. If the interface reports a name conflict, replacement or duplicate, read the prompt and available outcomes first; cancel if the effect is unclear and preserve the existing entry. Do not assume the app must create a separate book or automatically merge same-title items. If import completes, record the actual number of shelf entries, visible names and covers, then open each and identify it by its page marker.

## Observe reading positions separately

Only if two independent entries are confirmed, leave A on page two and B on page three, then exit normally through the current interface. Reopen each and record the actual page and edition marker. If only one entry exists or the page cannot be identified, state that independent-position comparison was not possible; one cover is not proof that both files remain safely stored. Page numbering may change with reading settings, so use image markers as additional anchors.

## Separate source files, imports and reading data

Check that original archives A and B remain in the computer or Files app, recording source files, shelf entries and reading positions separately; these are not the same data. If both entries show the same image, check filenames, markers and import order and whether the same source was selected twice. Do not immediately delete an entry or rename an original archive. Stop and preserve the state if prompts are unclear, reading data cannot be recovered or shelf results differ from expectations.

## Prepare reproducible results

Record app version, redacted identity and size of each archive, import prompts, actual entry count and position on each reopen; do not publish entire comics or private reading history. List untested items if both imports were not completed. When requesting help, provide observations and redacted screenshots of your own sample rather than account details. Confirm the originals still open before deciding whether to remove practice entries through your own management process. No device execution is claimed.

## Prepare a source comparison ledger

Before importing, give A and B one row each for storage location, filename, byte size, first-page marker and second-page marker. For example, draw a star on A’s second page and a circle on B’s. Reserve columns for shelf entry, import prompt and reopened position, filling them only after observation rather than writing “success” in advance. Equal file sizes do not prove identical files. Visual markers and source records identify the samples; they do not replace an integrity check.

Keep source files and imported results separate: an archive can reside in a computer folder while the shelf shows an item processed by the app. Whether renaming a shelf item changes a source filename depends on the installed version and actual operation. Until deletion scope is clear, retain both source archives and practice images so the original inputs remain available even after an incorrect selection.

## When two entries look the same

If titles and covers match, open the entries in turn and compare second-page markers. Record the entry path and image seen. If both show the star, investigate whether A was selected twice or B’s original archive itself contains the star; these are possibilities, not established causes. Reopen both source archives on the computer to inspect their pages. Do not delete a shelf entry as a trial.

If one entry shows the star and the other the circle but their reopened positions match, check whether each was exited normally, which entry was recorded, and whether the displayed image belongs to that edition. One observation does not establish that reading state is shared. Record the precise sequence and results before deciding whether to retest. Confirm existing progress can be preserved first; do not run replacement experiments on a real long work.

## Check the scope before cleanup

At the end, match each shelf entry to A and B in the ledger again. Before removing a practice entry, check whether the current interface explains effects on local files, cloud files and reading records; if not, stop and consult official help. Do not delete a remote original to test shelf behavior. Afterwards, verify both original archives and self-made images at their saved locations. If observation remained read-only, record that cleanup was not performed.
