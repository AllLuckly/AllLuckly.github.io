Use two original recordings to distinguish file sorting, actual playback sequence and reopened position without assuming multi-file grouping.

## Make two distinguishable recordings

Use a recording tool you are authorized to use to make two short audio files. In the first, say “First segment begins” at the start and “First segment ends” at the end; in the second, say “Second segment begins” and “Second segment ends.” Also record “First segment middle” within the first track; you may add a different middle sentence in the second. Leave a few seconds of silence in each and use a suitable volume. Name them 01 and 02, record format, actual duration and location, and keep separate originals. Do not use restricted audiobooks as a feedback sample.

## Check each recording in the system first

Open each original in a trusted player on the device or computer and confirm start, end and audible content. Filename numbers 01 and 02, system-displayed duration and actual speech are three distinct forms of evidence. A filename alone does not prove a valid recording. If the second file repeats the first, fix your working sample and recheck it before attributing the issue to Book Isle.

## Record the intended import scope

Book Isle’s public listing supports common audiobook formats but does not thereby promise automatic recognition of every file, chapter metadata or multi-file grouping. Record installed version and file types. Decide whether to check two individually readable files or a grouping method actually offered by the interface. Without a confirmable grouping or folder entry, import individually and mark automatic grouping untested rather than inventing a control.

## Import and identify each item

Import working copies using an entry actually available in the installed version and record each displayed title, format and identifiable source. If the app shows two books rather than a set, record that actual result rather than deleting or renaming existing user content to match an expectation. If the entries cannot be distinguished, inspect available file information or listen to their openings; stop if identity remains unclear.

## Compare list order with actual sound

Record the visible order of both entries. If a sort setting exists, record the actual option and do not equate filename order with playback sequence. Open 01 and hear its start and end markers, recording position; open 02 and confirm its start marker. Record automatic continuation only if the interface really offers continuous playback or a next item and you actually use it. Otherwise mark that behavior untested.

## Check interruption and reopening position

Choose a clear spoken anchor in the middle of the first file and record item and time. If the user wishes, leave the player and return to that same item through the actual entry, comparing phrase and time. The last-opened shelf title is not an audio check. If reopening lands elsewhere, preserve the first result and distinguish manual seeking, another entry and an unknown state rather than correcting it before claiming recovery.

## Check names and content in a file table

Give each recording a row for actual filename, format, duration, opening sentence, ending sentence and Book Isle item label. If a file named 01 begins “Second segment begins,” first mark the filename and audio as inconsistent; app list order cannot repair it. If the system displays a different name, retain both and identify content by actual speech. There is an automatic-transition result only if the user actually performs continuous playback; manually opening 02 proves only that it can be opened manually.

## Compare one interruption before and after

Find a short phrase in 01 that is not at the beginning or end, noting time and a few surrounding words, then leave the player. On reopening, do not seek first; record the first audible content and note if a few seconds were needed to identify it. If displayed time matches but speech differs, check whether 02 or another copy was opened. If speech matches while displayed times differ slightly, retain both observations rather than calculating a sync accuracy. Confirm both originals still open in a trusted player afterward.

## Distinguish two files from chapters within one file

If the player displays a chapter list, first identify whether that list belongs to file 01 or 02. Embedded chapters within one file, two independent audio files and a grouping shown in Book Isle can have different boundaries. Count a chapter as observed only if its list entry is actually shown and its content can be opened; do not turn file numbers into assumed embedded chapter numbers. If 01 does not automatically advance to 02, record the visible playback options and sound, then document a manual opening of 02 separately. Use only your own two recordings for feedback, not a complete restricted audiobook.

If the two samples come from different folders, record each source before comparing and do not assume the interface combines folders.

## Troubleshoot differences and keep originals

If list order differs, first inspect current sorting and file identity. If selecting 02 produces the first segment, check original file contents in the system player and identify the imported copy. Change one condition at a time rather than renaming, re-encoding and reimporting simultaneously. Record device, system, app version, file labels, list order, individual audio and reopening results; mark unperformed automatic playback untested. Preserve originals and backup. No device, grouping or playback test is claimed.
