Use two original chart states with fixed values and a changing vertical axis to separate visual height from data change.

English translation of the [Chinese original](<https://allluckly.cn/guides/icouldplay-animated-chart-changing-axis-record/>), translated on 2026-11-09. Original publication dates, attribution, code and version notes are retained.

An animated bar can grow taller because its axis range shrinks, even if its value stays fixed. Record two self-made chart cards as a clip, then replay by content landmarks in iCouldPlay. Retain axes, units and labels for every state. This is manual reading, not automatic data extraction, animation-script control or conversion of a recording into an interactive chart.

## Prepare two cards that differ only in axis range

Create two original bar-chart cards in an external drawing tool. Category A has 20 practice points and B has 40. Use a zero-to-100 vertical axis on the first card and zero-to-50 on the second, with the same plot height, category positions and labels. Record each for several seconds, identifying states one and two. Use no real business data. Creation is external preparation, not an iCouldPlay chart feature. Preserve source cards but fill viewing notes independently from what the recording shows.

## Locate state boundaries on the first playback

Play the whole clip normally and note approximately where state one ends and state two stabilizes. Do not transcribe bar tops halfway through a transition, when old axes and new bars may coexist. Playback time locates content; it is not the chart’s statistical date. Record any displayed month or year separately. Second ten in the file has no automatic relationship to October in the data.

## Transcribe axes and units for state one

Replay from before state one and pause on a stable image. Record zero-to-100, major tick spacing and practice-point units before A equals 20 and B equals 40. If colors identify categories, copy the legend rather than assuming its mapping stays fixed. The [ONS axes guidance](<https://service-manual.ons.gov.uk/data-visualisation/guidance/axes-and-gridlines>) treats scale as important to comparison. Record legible labels first instead of replacing values with screen heights.

## Read state two afresh instead of copying conditions

At stable state two, read again: zero-to-50, A still 20 and B still 40. Both bars grow within the same frame without absolute values increasing. Record fresh evidence rather than copying the first row and changing only its time. If a real clip’s labels are unreadable, mark them unreadable. An apparently doubled height cannot establish doubled values. Flag any change in axis range, units or legend for that state.

## Explain the apparent height change numerically

In the first card, A occupies 20 divided by 100, one fifth of the effective plot height. In the second it occupies 20 divided by 50, two fifths. B moves from two fifths to four fifths. These are linear, zero-based cards. Do not apply the formula unconditionally to truncated, logarithmic or broken axes. Check arithmetic against the source cards. If a card was drawn incorrectly, record the production error and make a separate corrected recording instead of disguising it in viewing notes.

## Check value changes and category order independently

Real animations can change scale and data while also ranking categories. Identify A and B by name each time rather than following left and right bars. A moved label with unchanged value is an ordering change; people replaced by percentages changes the measure. Neither can simply be called growth. Record simultaneous changes separately without inferring a cause from one frame. The original example changes scale alone to provide a controlled comparison.

## Return to stable intervals when transitions are unclear

If pausing lands in transitions, seek earlier and play normally rather than requiring exact frame positioning. Sketch the two stable states externally without treating a transitional composite as a complete coordinate system. If animation is too fast, use an actually available speed control and note the setting. Unreadable details remain unconfirmed; slowing cannot recover absent source information. Restore normal speed so later viewing is not mistaken for the original pacing.

## Check the scope of the conclusion

For this example, say that A and B retain their labeled values and the changed range explains their taller bars. Do not claim all animations mislead or that matching labels establish trustworthy underlying data. Real material needs separate source, definition and date checks. Record narration separately from labels and preserve contradictions instead of choosing the preferred account. Conclude only from observed states without filling unseen intermediate points into a trend.

## Save a state-and-axis comparison record

Keep file identity, two content landmarks, ranges and units, category labels, values, proportional calculations and unreadable fields. A later replay should locate the same stable views and distinguish authored example values from observed readings. Restore playback settings and preserve the cards and recording, dating later revisions separately. No automated chart extraction, frame-level device test or audit of a real statistical project is claimed. Completion means complete, traceable correspondence.
