## 先固定三行ASCII目标与使用范围

新建私人英文或符号草稿确认键来，保留当前方案、主题和字体。三行目标分别为Co、CO、Ca(OH)2，全部按ASCII字母、括号与数字原样写，不额外加句号或空格。它们是明确的文字训练材料，不是容器标签、配方或待执行反应；不从家中找对应物品进行验证。外部另存目标与元素符号资料，实际稿保留为独立证据，不能看到错误就连原参照一起改。宿主若会自动大写，先记录当前行为，输入后再逐字核，不能因系统替换恰好碰到某个正确式子就宣称原按键路径完整正确。

## 两字母元素符号的小写第二字母有意义

化学元素符号以大写字母开始，含第二字母时该字母小写。Co是一项钴元素符号，C与小写o要连着读；CO则由C和O两个大写符号组成，是一氧化碳的分子式，不能只因发音或字宽接近便混为同一对象。先在外部把Co框成一项、CO分成两项，再回真实正文核第二字符究竟是小写o还是大写O。字体外观改变不会替换实际字符，也不用零数字0冒充任一种字母。字母外观、元素符号切分与整个式子的含义分别登记，不将一个候选提示当化学识别结果。第三行逐格为C、a、左括号、O、H、右括号、2，恰七个ASCII字符；Co与CO各两个，按每处源换行一项计，三行逻辑总数十三。编号不写进原稿，七格也不表示七种元素，大小写状态不另占字符。

## 逐行录入并把切换状态与正文分开

先输入大写C、小写o，确认提交为Co，再真实换行输入两个大写字母CO。大小写操作按当前键盘实际可辨的状态，不预设一次Shift一定只影响一个字或自动锁定；需要时暂停看正文再继续。第三行先录Ca，再半角左括号、OH、右括号与数字2，最后不另加终止标点。Ca里a必须小写，括号内两字母都大写。候选、键帽大写和已提交字母是不同状态，最终以正文为准；如果切换到另一输入法才完成一行，单独注明，不将整卡都算键来手输。

```
Co
CO
Ca(OH)2
```

## 括号后的二作用于OH整组

对Ca(OH)2外部切分为Ca和两份OH，每份OH有一个O和一个H，所以一个式量单位的计数为Ca一、O二、H二，共五个原子。这里氢氧化钙的式子用于离子化合物的组成比，不把它描述成照片里真实独立的五球分子。数字二不是只乘H，也不是把Ca也乘二；括号范围先确定再计数。保留字面数字2的目标，不在原样检查中自动换成Unicode下标₂；若另外制作美化展示版，应另存并说明字符形式已变，语义相近不能代替原文逐字一致。

## 只去括号的副本不再具有同一计数

另做外部控制只删左右括号，得到CaOH2。按本课符号和后置数规则，计数变成Ca一、O一、H二，共四；它不再与原目标Ca(OH)2相同。这份错例用来检查文本范围，不保证它对应某种可取得、稳定存在的真实物质。不要把错误式写到任何实际物品上，也不靠把字母画大弥补漏掉的括号。两个式子的数字都为二，但二所作用的范围不同，说明长度、数字相同与组成相同不能合为一关；未实际输入反例时就只交外部分析，不说键来已经自动报错。

```
Ca(OH)2 -> Ca:1 O:2 H:2; total 5
CaOH2   -> Ca:1 O:1 H:2; total 4
```

## 前置系数与组内数字再分一次范围

再另列2Ca(OH)2作外部数学控制，前置二表示两份原来的式量单位，故计数Ca二、O四、H四，总十。它不把元素符号改成Ca2，也不是一份原式里钙突然多一个。先展开两份括号式再相加，可与原五乘二核回；不能把前置二与右侧二合并成末尾四后仍保持钙一。此处只有组成计数，没有质量、反应速度或样品纯度输入，不补任何真实测量结论。原来的三行目标并不包含这个前置系数控制，不把它顺手追加到真实输入稿末尾后还叫完全一致。

```
2Ca(OH)2 -> Ca:2 O:4 H:4; total 10
Leading coefficient applies to the complete formula unit.
```

## 按大小写括号和字符种类排错

Co与CO混淆先看实际第二字符和宿主自动大写，Ca写成CA则核是否把两字母都锁成大写；计数O一先查括号是否保留，全部变两倍先查是否无意加了前置系数。全角括号与ASCII括号可能外观接近，本课原样目标仍不相同，不能在比较前静默规范化后说初稿通过。每次只修一处并保留前后稿，再重新切分和计数。没有可靠文本副本时注明判断限制，不凭一张小截图报告准确码位，也不将外部化学知识说成键来实时识别、自动配平或纠正危险标签。

## 重开交付原样字母与组成两套检查

重开普通草稿，逐行核Co、CO、Ca(OH)2，确认只有两处源换行、没有额外编号。分别交大小写文字一致、符号切分、括号组计数与两个外部控制，未做步骤留待核；恢复日常输入状态，原稿不发送也不贴到物品上。验收是能从明确字符解释为何Co不等CO、为什么组后数字影响两个元素，不是要求输入法懂化学。以后增加电荷、结晶水、同位素或更深括号，应重新核完整表示规则，不能从这张小卡推所有化学式解析、实物鉴定或全部宿主字体兼容已经通过。
