## 准备同一文字前缀与独立绘图

选择至少十四秒的自有静景短片，先保留原字幕与原片，不覆盖日常观看文件。示例在每条事件前写BASE和一个空格，随后进入p1绘图，画宽80、高30的矩形，结束用p0回文字模式。文字仅作同一事件内的相对参照，不保证当前字体的基线能由设备像素直接测出。画布固定640乘360、字体示例Arial、字号36、横纵缩放100，描边和阴影均零。若字体回退先记条件，后续不改字体、字号与视频适应方式来配合期望位置，避免看起来下移其实来自整行布局变化。

## 给零与正负偏移安排互不重叠的区间

第一条一至四秒设pbo0，第二条五至八秒设pbo20，第三条九至十二秒设pbo-20；文字、路径、定位120、140与其余参数逐字相同。时间中留空档方便辨认，观察时选二秒、六秒与十秒等段内时刻，不只在切换帧截一次图。三段为静态条件先后呈现，没有补间移动，不能把两条事件之间的空档当连续平移动画。先列出待核问题：绘图相对基线朝哪边、矩形自身宽高是否变、整行定位条件是否固定。正负号属于绘图偏移，不是字幕显示时间的加减，第三条仍在九秒开始，不能因出现减号就把它向前挪二十秒。

## 保存完整基线对照而非只粘绘图命令

将全文保存为UTF-8纯文本drawing-baseline.ass，重开核对头部、样式、事件和扩展名，不保存成富文本或ass.txt。BASE在覆盖块外，m、l坐标位于p1与p0之间而不在花括号内部；pbo放在启用绘图的覆盖块里。三条路径都显式走回起点，正文尾部p0不可因没有后续文字就随手删掉，以免以后接字时忘记模式边界。编辑由外部文本工具完成；云映仅按安装版实际可用路径关联观看，不假设它有图形路径编辑器、基线标尺或自动生成此文件的按钮。

## 按官方方向解释正值向下与负值向上

Aegisub把pbo定义为绘图基线的Y偏移，正值使绘图出现在基线下方，负值在上方；这与把pbo20说成上移相反。它不等于重新设置pos，也不改变视频帧坐标。这里画布纵轴按字幕坐标向下理解，比较的是同一脚本、相同绘图比例下的偏移方向。文字字形、行框与定位锚点可能共同影响最后屏幕布局，因此不能直接把pos的140加20写成“矩形顶边必为设备第160像素”。保留相对基线的定义，实际绝对边界须另有渲染与测量证据才可填写。

## 在固定p1模型里核范围不核设备像素

外部纸面模型只研究本样本p1、纵向100时的局部路径，把原来的y映为y加偏移。矩形原范围x为0至80、y为0至30；偏移20后y为20至50，偏移负20后为负20至10。三者宽80、高30、面积2400均不变，负坐标也不表示高度变成负数。进一步逐角核正二十稿：左上从0、0变0、20，右下从80、30变80、50；两角位移相同而不是只有底边移动。负二十稿左上变0、负20，右下变80、10，仍是两边共同平移，不能只看到下端10就认成新高度10。这个平移模型解释为什么不能把pbo当高度参数；它没有计算实际字体行框、播放器覆盖缩放或设备像素。更改p2或纵向比例时不照搬这张固定条件表，须另开模型，不能将本课范围冒充所有绘图模式的通用测量结果。

```
Declared LOCAL p1 model; fscy=100; NOT device pixels
pbo 0:   x [0,80], y [0,30],    width 80, height 30, area 2400
pbo 20:  x [0,80], y [20,50],   width 80, height 30, area 2400
pbo -20: x [0,80], y [-20,10],  width 80, height 30, area 2400
pbo 10:  x [0,80], y [10,40],   width 80, height 30, area 2400
```

## 实际关联后先核文件与模式边界

在云映实际支持的字幕流程关联此文件与原片，先确认BASE能读、矩形出现和第一段身份正确，再依次观察三段。分别记录相对文字的高低、形状宽高是否可辨，以及字幕整体是否有显示覆盖或换行；同一事件前缀只是参照，不把它声称为独立钉死的屏幕基线。若只有文字没有图形，查p1、坐标与p0的位置、当前副本及所用路径，不能马上说正值无效。若未实际播放或安装路径无法关联，保留文件与纸面结果，观看栏待核；外部编辑器预览另署来源，不代替云映通过。

## 只把正偏移二十改为十作反例

另存drawing-baseline-ten.ass，只将第二条pbo20改为pbo10，时刻与路径逐字保留。纸面预期该条y从20至50变成10至40，宽、高、面积仍不变；它不是回到零，也不是把矩形缩成一半高度。重新关联副本后只比原第二段与新第二段，第三段负值不要同时调整，保留可恢复的三条件原稿。若改成移动pos，BASE前缀与行定位也会参与变化，那已是另一个任务；若改矩形坐标30为15才是在改路径高度，不拿这种混合改动证明pbo能缩放。

## 交付方向、尺寸与真实观看三份记录

保存完整样本、三段表、局部平移算例、正十副本与实际路径记录，结束恢复原字幕及观看条件。验收应能指出正下负上的官方方向，解释负坐标为何仍有正高度，并区分绘图基线、整行定位与视频画面。无法固定字体或显示条件时，清楚写本轮未能作绝对比较，不删去不一致结果。源码核验、外部预览与云映观看分开记，重开未做不填成功，不声称已完成真机像素测量、内置绘图编辑或全引擎兼容；留存原参数才能在换路径后重做相同三段而非靠记忆复原。
