## 明确两项属性

MDN 与 W3C 的 SVG 资料区分填充透明度 fill-opacity 和描边透明度 stroke-opacity：前者影响填充操作，后者影响描边操作。它们不同于将整个元素作为整体处理的 opacity。本实验在同一背景上比较两枚方形，先保持其他参数一致；SVG 规范不保证 VectorPaint 的某个版本保留每项属性，应用中的结果需要实际观察。

## 建立背景与两枚方形

在纯文本编辑器新建 UTF-8 SVG，根元素设置 SVG 命名空间与 viewBox 0 0 240 120。先画覆盖画布的浅灰色背景矩形，再画两个互不重叠的方形：左方 x=20、右方 x=140，均 y=20、width=80、height=80。两个方形填充红色、描边深蓝、stroke-width=8。背景不是测试对象；保存为 paint-opacity.svg 并复制备份。

## 设置相反的透明度

左方设 fill-opacity=0.25、stroke-opacity=1；右方设 fill-opacity=1、stroke-opacity=0.25。两个元素都不要额外设置 opacity，填充与描边颜色也不要带透明通道，避免混入第三项因素。两组只交换填充和描边各自的不透明度。写下属性表并确认两个方形没有共享 CSS 覆盖这些值，再打开文件。

## 预测中心与外侧描边

左方内部的红色会与灰色背景混合，远离交界的深蓝描边应保持不透明；右方内部为不透明红色，深蓝描边则部分透明。描边沿轮廓居中，部分落在填充内部、部分落在外侧；右方内侧描边下方是红色，外侧描边下方是灰色，因此两侧混合结果可能不同。不要把整圈半透明描边误认为永远混合同一种背景。

## 在浏览器建立参考

用支持 SVG 的浏览器打开文件，观察两方形内部、靠内侧描边和靠外侧描边。将视图整体放大到便于辨认，但不要依据一个边缘像素推断精确颜色；抗锯齿会影响边界。若左方描边也明显透明，检查 stroke-opacity、整体 opacity、颜色透明通道和样式覆盖。若两个方形的颜色完全相同，先确认是否打开最新副本。

## 单独改变背景

另存一份副本，把背景从浅灰改成白色，两个测试方形的属性不变。左方半透明填充和右方半透明描边的外观可能随背景改变；左方不透明描边和右方不透明填充的颜色在远离重叠和抗锯齿边缘处应保持其绘制颜色。这个比较说明透明区域显示受其下方内容影响，不改变原始 fill 或 stroke 颜色值。

## 比较整体 opacity

从原稿再另存一份，为一个新方形设 fill-opacity=1、stroke-opacity=1，并将整体 opacity 设为 0.25。将它与已有方形分别对照，但不要声称三个方形处处相等：整体透明度作用于整个对象，填充和描边各自的透明度则作用于各自的绘制操作，交界处的合成关系不同。保留原稿与每个副本，明确记录第三方形仅是额外对照。

## 在应用中导入副本

在 VectorPaint 的作品集，点右上角方框向下箭头导入图标（无障碍标签为“导入作品”）；若作品集为空，可点“从文件导入”，在系统文件选择器中选择本练习的 SVG 工作副本。若界面不同、入口不可见或文件无法读取，记录未完成。导入后先不编辑，比较两种内部和描边的可见结果，再尝试单独选择各方形。应用可能将外观转换为不同表示；看起来相同不证明两个 SVG 属性仍作为独立可编辑设置存在。

## 排查颜色和层级

若右方描边内外颜色不同，先检查它是否分别覆盖红色填充和灰色背景；这可能是预期的合成结果。若背景盖住方形，检查绘制顺序与图层，不要只更改透明度。CSS 的 fill-opacity 或 stroke-opacity 可覆盖同名展示属性；核样式、父组继承和颜色本身的 alpha 后再修改。每次只改一个条件，记录原值和新值。

## 保存与重开

保存应用可编辑原稿，再用当前版本实际可见的分享或导出入口另存文件，不覆盖 SVG 备份。重新打开输出，检查背景、两方形内部和描边；若为 SVG，用文本编辑器查看 fill-opacity、stroke-opacity 和可能的整体 opacity 是否保留或转换。位图只能比较外观，不能证明属性可编辑。记录预期、浏览器、应用和重开结果，未实际执行的设备或导出步骤标记待核。

## 用三处取样说明边界

每个方形分别标出内部中心、描边靠内侧和描边靠外侧三处观察位置。中心远离描边，主要用于看填充与背景；内侧描边同时覆盖填充，外侧描边则覆盖背景。这个位置表帮助解释右方半透明描边两侧外观不同，不能把交界处的像素直接当作单独的描边原色。取样位置避开四角和边缘抗锯齿区，以减少缩放引起的视觉差异。

## 保留对照表和副本

在表中为原稿、白背景副本和整体 opacity 副本各记一行，列出填充透明度、描边透明度、整体透明度、背景和实际观察。若副本未使用某个属性，写默认或未设置，而不是默认为零。确认每个文件的修改日期和名称，重开正确的文件再核查；没有实际在应用操作的单元留空或标为待核，并附上实际使用的版本。
