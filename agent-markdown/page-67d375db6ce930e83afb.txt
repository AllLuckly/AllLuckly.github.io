A filename visible in Files may still represent cloud data not downloaded to the phone. Delayed import can involve the file provider, app import or playback. Use one of your own clips to check source availability, system download, local import and offline reopening separately rather than labelling every failure cloud incompatibility.

## Identify the actual access path

Record whether the video is local, in a system cloud drive or managed by another provider. Open it there and observe download or login requirements. Cached names and thumbnails do not establish file availability, and this test does not initially require changing NAS or server connections.

If another copy is in Photos, use only one source for this test. Record duration and size and retain originals. File providers, Photos and remote app libraries are separate routes; matching names do not imply shared download states or permissions.

## Complete the provider's download first

Use its current download or offline controls and wait. Open the beginning and a later position beyond thumbnail preview. Providers use different status symbols, so judge the actual service rather than treating one cloud icon as universal evidence.

Keep connectivity stable and check space and login. If the original cannot be retrieved there, resolve that stage before repeatedly selecting it in iCouldPlay. For large files, test a small clip in the same folder to establish basic access.

## Make an independent local comparison copy

Where permitted, copy the sample to a known on-device directory without moving the source. Compare size and duration and open its middle. Confirm actual data, rather than a shortcut or pending reference masquerading as a completed local copy.

This isolates the provider stage without requiring permanent duplication of every video. Use a small sample and choose long-term storage later. Retain both source and test copy until the imported version is checked, preserving references if paths change or playback fails.

## Import the definite local copy

Select the sample through local import, verify name and format, wait and inspect opening, middle and ending. If no new entry appears, investigate an existing same-name item and its actual content rather than assuming automatic overwriting or renaming.

If local import works but provider access does not, record their differing conditions. If both fail, inspect format, completeness and space. Keep content fixed and change one access condition rather than simultaneously converting codecs and switching providers, which obscures the useful comparison.

## Reopen offline after leaving playback

After successful import, leave the player, disconnect and reopen the same entry. Seek to a later position not just loaded and verify picture and sound. Continuing an already loaded segment alone provides weaker evidence of complete offline availability.

External subtitles need separate local checks. Cards, video and subtitle files are distinct data. Establish picture and sound first, then add captions. Preserve confirmed conditions when one stage fails instead of resetting the entire process and losing your baseline.

## Separate copying, syncing and cleanup

A provider's downloaded original and an app-managed imported copy may occupy different locations. Inspect them independently. Before space cleanup, identify whether the action removes a cloud download, app copy or original; similarly named remove buttons can have different effects.

Do not delete the only cloud original immediately after import or assume cover-cache cleanup removes videos. Use disposable copies for small tests and retain backups for real recordings. Do not promise that deleting an external file can never affect playback; establish actual copying or referencing behaviour with your sample.

## Keep a repeatable sequence

Record four checks: source opens, provider download completes, app import completes and offline reopening works. Add actual observations to identify the failing stage. Reuse this clip after changing provider or account instead of mixing a whole collection's network, account and format failures together.

Completion means knowing the playback source, original location and offline content. Device, source, format and failing stage support further investigation without sharing private clips or logins. Expand gradually once stable rather than repeatedly reinstalling and losing clear data relationships.
