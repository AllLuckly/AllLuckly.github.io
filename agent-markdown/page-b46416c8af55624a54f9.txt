## Understand writing modes

W3C CSS Writing Modes says writing-mode controls horizontal or vertical lines and block-flow direction: vertical-rl uses vertical text with right-to-left block progression; horizontal-tb uses horizontal text with top-to-bottom blocks. This differs from EPUB chapter order and app gestures. A specification does not guarantee Book Isle implements every value; record observations separately.

Use an EPUB you made or the publisher permits you to inspect. Prepare two self-written short passages with identifiable start and end markers, recording file edition, source and backup location. Avoid private data and unauthorized publication of pages. If protection or license terms prohibit internal inspection, observe only the interface and mark structural inspection unperformed.

## Inspect declaration and scope

Only with permission and suitable tools, inspect target XHTML and referenced CSS in an EPUB copy. Record actual writing-mode values, selectors and whether a rule may apply to the target passage. Multiple stylesheets and inheritance can matter; finding vertical-rl does not prove it controls the whole document. Mark unknown if inspection is unavailable and do not edit the sole original.

## Compare column and paragraph progression

Using publisher-provided expectations, observe self-made markers within each row or column and where the second passage appears. One column does not prove identical rules for every paragraph. Text direction, progression between columns and chapter order in contents are separate observations. Mark obscured or unreadable markers unconfirmed rather than guessing content.

## Record page turns separately

Use controls actually visible to move to an adjacent page and return, recording gesture or button, destination marker and orientation. Page-turn behavior can depend on settings or book structure; one gesture cannot establish writing-mode and CSS cannot guarantee a particular button. Mark the step incomplete if the adjacent page cannot be identified, preserving the bookmark.

## Change one reading condition

If Book Isle permits it, keep the same file and chapter and change only font size or device orientation, then inspect markers, columns and pages again. Width changes can repaginate without changing source. Mark unavailable controls as such; do not simultaneously edit styles, replace files and change system language.

## Compare and troubleshoot independently

Where permitted, open the same copy in a trusted reader and record device, version, size and marker positions. Different fonts and viewports can produce differences without proving either implementation wrong. If text is entirely absent, first check section, file and fonts; inspect style scope and settings when only arrangement differs. Preserve uncertainty without a control and do not install unknown software.

## Restore and document

Restore original font size and orientation and confirm originals, bookmarks and notes remain. Record CSS declaration, column and paragraph flow, chapter position, page-turn action and skipped steps separately. Remove private paths and unauthorized content before sharing. This guide relies on public standards and app information, claims no device test and does not guarantee vertical CSS support in Book Isle.

In a self-made conforming EPUB, prepare two passages marked “A starts, A ends” and “B starts, B ends”; declare writing-mode: vertical-rl only in the corresponding paragraph rule. Record CSS location and selector, then observe both passages and markers in Book Isle. ## Separate passage order from page actions

Record publisher or file order of passages A and B in one column, screen positions in another and the actual next-page action separately. Even with right-to-left vertical columns, an app’s buttons or gestures can depend on book and settings. If B is not visible, first use contents or adjacent pages to locate it rather than declaring it missing; mark the result unconfirmed without enough evidence.

## Note character orientation and fonts

Writing-mode describes line and block arrangement; individual character orientation can also depend on other styles, script and font. Record rotated or upright Latin letters without guessing whole-book chapter order. If boxes appear, inspect character and font availability first; missing glyphs and column progression are different issues. Do not install unknown fonts for the test.

## Preserve comparison conditions

If the publisher provides authorized self-made horizontal and vertical samples, verify matching text, file identities and style declarations before comparing. List any other differences; do not attribute every change solely to writing-mode. Without an authorized control, retain one observation and never edit or overwrite a real book to create a comparison. Identify which findings come from the standard, sample and actual interface.
