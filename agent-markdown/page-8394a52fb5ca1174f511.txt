DEVELOPMENT NOTES · 48 篇

一个界面效果，往往牵涉布局、事件和绘制三件事。这组文章从具体控件出发，记录当时如何实现列表、富文本、转场和动画，适合按手头的问题挑着读。

## 怎么读这一组

1. 先找对应的控件或交互：列表高度、事件传递、输入框和弹出视图，比从动画代码直接开始更容易定位问题。
2. 读动画时把初始状态、最终状态、时间和坐标变换分开记录，再比较 UIView 动画、关键帧和 Core Animation 的写法。
3. Core Text、Core Graphics 和波浪效果可以接着读；留意示例的坐标系、绘制范围及 Swift 版本，不要只照搬视觉参数。

这是 2015–2017 年的历史记录，示例未在本次整理中重新运行验证。先核对文章日期和版本说明，再决定哪些思路适合当前项目。
