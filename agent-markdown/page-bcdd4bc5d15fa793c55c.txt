用二为底的八与四逐步核乘积公式，不把外面的加法搬进真数相加。

对数外面的加号，不能直接变成真数里面的加号。本课在书屿读一组原创算式，先确定底数与实数定义域，再把乘积关系反查到乘方。记录依靠现有阅读位置、可用笔记或外部纸笔，应用不替你做符号化简，也不以一次计算器输出自动证明所有输入成立。

## 一、把底数、括号与变量条件抄完整

准备自制短练习文件，记录版本、章页与目标算式旁短句。先写本课用实数对数，底数为二，真数为正；推广规则时底数须大于零且不等于一，两项真数分别大于零。原书没给条件就回定义核，不因为两数乘积为正就先替每项通过。根式、指数和对数符号不能混记；扫描小下标模糊时标底数待核，不凭后面熟悉答案补成二。不能选字的文件可手录必要算式并回原图确认，书屿的页面缩放并不等于应用已经识别数学结构。

## 二、从乘方定义求两个已知值

先不套运算公式，用二的三次方等于八、二的二次方等于四，分别得到两个对数值三与二。笔记一栏写真数，一栏写满足乘方关系的指数，避免把对数答案抄成底数二。保留底数在每个式子中，不把一个十为底的值混进来相加。原创算例不是现实声压、酸碱或投资数据，单位与实际模型都不在本课范围。若使用外部计算器，注明只是复核这两个输入，原始乘方关系仍须自己说明，不能把软件显示精度当成代数依据。

## 三、乘积公式逐项对应到三十二

依据[OpenStax 对数性质](<https://openstax.org/books/algebra-and-trigonometry-2e/pages/6-5-logarithmic-properties>)，满足条件时乘积的对数等于同底两个对数之和。本例八乘四为三十二，二的五次方为三十二，所以左边五与右边三加二对应。逐项画箭头，真数乘法对应指数加法，不是把对数值三与二也相乘。下方记号明确 log\_2 表示以二为底、星号表示乘法，不是书屿的命令或程序入口。保留原始表达式与化简结果两行，使别人能够回查每个数从哪里来。

```
2^3 = 8; 2^2 = 4; 2^5 = 32
log_2(8*4) = log_2(8) + log_2(4) = 3 + 2 = 5
```

## 四、真数相加的错例用反代发现

另写明确错例，把真数改为八加四，却仍把答案写五。八加四为十二，二的五次方为三十二而不是十二，因此这个改写不成立。十二位于八与十六之间，对应二为底的对数在三与四之间，也不会等于五；此处只给范围，不用近似小数遮盖错误。把错例标为自己构造的对照，不覆盖原乘积例子。若实际教材出现真数相加，先按其完整式子处理，不能因为看见对数与加号就把本课乘积公式硬套进去，也不把某次偶然相等当成一般规则。

## 五、乘积为正不替两个真数通过定义域

再看负二乘负八为十六，乘积作为一个正真数的对数可以讨论；但将它拆成两个负真数的实数对数就不符合本课定义。分别检查原表达式有定义、拆开各项有定义与所用公式条件，不把前一项通过迁移给全部。这里没有引入复数分支，不用复数解释来掩盖实数范围已经改变。底数一、底数零或负底数也不能照搬这套实数定义。缺少条件时在笔记留待核，不为保持结果五或四而擅自取绝对值，改变真数后仍声称原式没变。

## 六、同底与改底分别保存条件

若另做十为底对照，先重新求各项，不把二为底的三与二直接贴给新底数。乘积规则的形式可以仍按条件使用，具体数值却不同；同一个真数不代表同一个对数值。若参考书提供换底公式，另列使用的底、分子与分母，不在这篇乘积练习中跳过来源直接混算。无需在应用里寻找底数设置按钮，公式文本中的条件由读者核对。对照版本与原版本保留各自标签，解释的是规则与输入如何对应，不是通过排版颜色让不同底数看起来整齐。

## 七、排查下标、括号与运算顺序

答案不符时，先核底数是否一致、加号在括号内外哪一边、真数是否全为正，再查乘方反代。复制笔记可能把小下标排成普通数字，保留清楚的纯文本约定，不宣称应用已修复公式渲染。扫描不能搜索时用章节与短句返回，不先删除书重导。导出后打开文件，核星号、括号、负数错例的定义域与“不能拆”的否定没有丢失。自己纠错保留原因与原式，不只把最后答案改成五让过程看起来通过，未知底数仍明确待核。

## 八、返回原定义重新验算三种情形

退出阅读器再返回同一段，遮住结果，重做八乘四的五、八加四不等于五，以及负因子不可在本实数域直接拆开的理由。最终保存版本位置、底与定义域、原式、逐项对应、反代检验与未知六项。验收是另一个读者能说明每一步采用什么条件，而不是只背“对数能变加法”。以后原书改变真数范围或底数，重新读定义；书屿保留的是阅读与回查线索，不能替代对公式适用范围的判断，也不能把三次自制验算当所有输入的证明。
