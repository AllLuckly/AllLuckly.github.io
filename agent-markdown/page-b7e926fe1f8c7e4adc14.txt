用维护者确认的安全地址核对域名、IP 与证书身份，再在漫阅中检查目标书库和漫画。

## 准备已知书库与安全入口

准备自己有权使用的 HTTPS 漫画服务、一部可辨认封面的漫画以及维护者公布的完整域名地址。记录服务类型、端口、原有路径和失败提示，保留原设置及本地原件；可用时截取不含密码的提示。本文针对同一服务的域名与数字 IP 身份核验，不要求架设证书或购买新服务。若没有维护者确认的安全地址，就停在收集信息，不猜测未知设备地址。

## 拆开地址中会变化的部分

把维护者给出的地址拆为协议、主机、端口和路径，例如 https://comics.example.test:8443/library/ 只是示意，不能直接用于连接。另记正在失败的数字 IP 形式，保留端口和路径。不要公布家庭公网地址、账号或令牌；示例域名不代表你的真实服务。域名和 IP 即使指向同一台机器，也可能因虚拟主机、反向代理或证书设置到达不同配置，不能只凭相同页面颜色判为同一书库。

## 在可信域名入口确认服务

在同一设备的浏览器输入维护者提供的域名地址，确认没有证书警告，并按正常授权查看是否能到达预期服务。如果看到警告，停下并记录实际提示，不选择忽略证书继续，也不提交账号。正常页面应再通过服务身份、路径和有权访问的漫画确认；若出现登录界面但无法登录，就只记录界面可达，不能写成书库已验证。浏览器成功只是对该浏览器与该次连接的观察，不保证应用一定相同。

## 只读比较证书身份资料

若维护者能安全提供证书或浏览器显示证书详情，检查主体备用名称（subjectAltName）中的 DNS 名称和 IP 地址类型，并记证书有效期与颁发方。不要把证书序列号、内部主机名及完整截图公开。按照 RFC 9525，IP 形式的参考身份要与证书中的 IP 地址条目精确匹配；证书只列域名时不能假设同一服务器的数字地址也满足身份检查。名称匹配还不是完整信任结论，证书链、有效期与客户端策略也会影响结果。举例说，若证书详情仅明确列出 comics.example.test，不能因此认定另一别名或直接输入的数字地址必然匹配；实际还需按照列出的身份类型和适用规则检查。若详情未显示备用名称，不凭证书标题推断具体条目，请维护者提供可核对资料。证书内容是否完整展示取决于工具，记录“未看到”不等于断言服务器没有该条目。若只看到安全提示而无法查看证书，把实际文字和时间记下，交给维护者核实，不安装来历不明的根证书。只有维护者确认安全地址和信任链后才继续，无法确认时保留未测结果。

## 在漫阅使用已确认的完整地址

在漫阅+中选择实际可用的服务器连接类型，按服务维护者资料填写已确认的 HTTPS 域名、端口和原路径；若当前版本缺少该服务入口或要求更高权益，记录当前状态，不虚构设置项。保持账号与目录不变，使用正常认证，观察保存、登录和目录反馈。已有连接有价值时先保留原记录或截图，不清除数据来测试。若失败，记显示的原文和出现阶段，不把所有错误直接归因证书。

## 验证书库和指定漫画

连接后先确认书库名称、目标目录及漫画封面，再打开首、中、末几个有辨识标记的页面。目录出现不等于获取图片成功；若只能看到列表，分别记录目录成功与页面失败。关闭阅读后再从同一入口找到作品，确认没有误入另一个同名库。本次只检查目标作品与观察到的页面，不将一次成功推论为全部章节都已下载或离线可读。

## 失败时按差异缩小范围

若域名和 IP 结果不同，先确认协议、端口、路径、网络、账号及实际服务身份；域名解析、代理规则和证书都可能造成差异，不能从一次对比断言原因。检查证书时发现名称或有效期问题，应请服务器维护者修复并提供正确安全地址，而不是关闭校验、改用明文或盲目信任证书。若浏览器可用而应用失败，记录两者时间、版本及具体提示，继续检查服务类型与应用入口，必要时向维护者反馈脱敏信息。

## 留下可复核的结果

保存脱敏后的服务类型、地址组成、证书身份是否可查、浏览器结果、漫阅连接阶段以及目标页检查结果；未执行的项目写未测，证书详情不可见则写未知。检查原有连接和本地漫画仍可找到，并恢复临时修改的设置。安全域名能连接说明该次条件下可用，不证明数字 IP 应该可用，也不证明所有证书问题均已解决。需要进一步核查时交由服务维护者，勿分享密码、访问令牌或私人漫画。
