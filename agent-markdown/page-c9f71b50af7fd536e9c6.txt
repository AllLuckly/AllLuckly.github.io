A zero dot product does not give every pair a defined right angle. Read an original three-dimensional exercise in Book Isle, calculate the scalar and check nonzero conditions. ## 1. Fix component order and coordinates

Use real 3D vectors a=(1,2,2), b=(2,-1,0) in x/y/z order. Preserve punctuation and signs, identify both as nonzero and label any drawing a projection rather than proof of a 3D angle. Name the control separately so later replacing b with zero does not overwrite the original data.

```
a=(1,2,2)
b=(2,-1,0)
Component order: x,y,z
```

## 2. Multiply corresponding components and sum

Compute 1×2+2×(-1)+2×0=2-2+0=0. The result is a scalar, not the temporary tuple of component products. [OpenStax’s dot-product chapter](<https://openstax.org/books/calculus-volume-3/pages/2-3-the-dot-product>) supports the component formula and scalar result. Individual products need not all vanish; cancellation can produce zero. Also compute a·a=1+4+4=9=|a|²: a·b=0 does not make a itself zero. For the separate control 2b, a·(2b)=0; a nonzero multiple retains this perpendicular relationship. A zero multiplier returns to the undefined-angle case below. Keep controls separate from the original coordinates. Hiding the third component creates a separate 2D object rather than proving the displayed projection represents every 3D condition; label the coordinate space before comparing.

```
a dot b = 1*2 + 2*(-1) + 2*0
        = 2 - 2 + 0
        = 0 (scalar)
```

## 3. Calculate both magnitudes independently

Magnitudes are |a|=√9=3 and |b|=√5, both positive. Square negative components correctly and retain exact values. This establishes a nonzero denominator |a||b| in the angle formula. A zero magnitude here signals an arithmetic error, not a step to skip because the intended answer is a right angle.

## 4. Infer the angle only under nonzero conditions

For these nonzero vectors, cosθ=0/(3√5)=0, giving 90° in the usual 0–180° range. Include the nonzero premise. Coordinate calculations are independent of whether a projected drawing looks perpendicular; a 2D protractor cannot replace the 3D formula and conditions.

## 5. A zero-vector control has no defined angle

For z=(0,0,0), a·z=0 but |z|=0 makes the angle formula undefined. Algebraic orthogonality defined by zero dot product can include the zero vector; a geometric 90° angle requires nonzero directions. Record both meanings separately. Giving z a length to draw a right angle changes the vector.

```
z=(0,0,0)
a dot z=0, |z|=0
Angle formula denominator: |a|*|z|=0
Geometric angle with z: undefined
```
