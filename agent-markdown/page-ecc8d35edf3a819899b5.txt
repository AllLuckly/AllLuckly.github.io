固定半径二的无滑动模型，用五个时刻核轮心、轮缘点与一拱跨度。

滚动圆轮的圆心沿直线走，轮缘上同一个标记点却不会沿圆心那条直线走。本课绘制一拱摆线和三个静态轮位，纸面参数先核，曲线用现有路径工具手工近似，不把静态插画写成运动仿真。

## 先约定无滑动与同一个标记

设圆轮半径二，沿水平基线向右无滑动滚动，起点标记正好接地，参数是滚过的弧度角而非未经说明的秒数。每一幅轮位跟踪同一个轮缘标记，不在每个时刻重新选当前接地点，否则得到的是基线点列而不是摆线。圆轮、轮心与标记分别设图例，基线保持水平。当前只是理想几何模型，不考虑轮胎变形、打滑与真实路面；外部算出的结果用于组织插画，不宣称从现场视频反算出设备运动。

## 用圆心加旋转偏移写坐标

圆心横坐标是二倍参数、高度恒二；标记相对圆心的偏移为负二倍正弦、负二倍余弦，合起来得到下列式。参数零时标记在原点，圆心却在零、二，不能把两者写成同一坐标。所有三角函数按弧度处理，四分之一圈应代入圆周率的一半，而不是数字九十。先保留精确表达再取显示小数，后续移动圆轮的距离由无滑动关系决定，不按每幅轮外缘刚好相接来猜间距。纸面账和手绘节点误差分别记录。

```
r=2; 0<=t<=2*pi
C(t)=(2*t,2)
P(t)=(2*(t-sin(t)),2*(1-cos(t)))
t=0       -> P=(0,0)
t=pi/2    -> P=(pi-2,2)
t=pi      -> P=(2*pi,4)
t=3*pi/2  -> P=(3*pi+2,2)
t=2*pi    -> P=(4*pi,0)
span=4*pi; height=4
```

## 五个时刻先落点再画曲线

依次取零、四分之一圈、半圈、四分之三圈、整圈，标记高度为零、二、四、二、零。横坐标依次零、圆周率减二、二倍圆周率、三倍圆周率加二、四倍圆周率；它们不是等间距点列。约一千六百乘一千二百画布可取每单位六十像素、基线屏幕纵坐标七百五十、起点横坐标三百，完整跨度约七百五十四像素。纵向向上量二百四十像素到最高点，横纵同一比例，点名按参数顺序保留而非按视觉均分。

## 三幅轮位检查半径与接地

为避免拥挤，主图只画起点、半圈、整圈三只淡轮，圆心分别在横坐标零、二倍圆周率、四倍圆周率，高度都为二。每只圆半径二，下缘接同一基线；起点与整圈标记在下缘，半圈标记在上缘。轮心轨迹另用细虚线表示，不让它与摆线颜色混淆。整圈后轮心前进四倍圆周率，正好一个周长，不是四单位直径。若半圈标记仍在下方，先核是否忘记旋转标记；不要只平移一只带固定下点的圆当成完整滚动过程。

## 按顺序连成一拱并保留端部

用钢笔或现有节点工具按五点顺序建立平滑主路径，在两端附近可补更多外部计算点帮助控制弯曲。五点都对不等于中间曲线精确符合方程，成品注明手工近似，不将贝塞尔拟合写成解析摆线。两端回到基线形成相邻拱会出现的尖接处，不能用大圆角把端部改成圆底半椭圆；一拱也不是半个圆，跨度与高度比例不同。最高点在中间，左右以中线互为镜像；修曲线时不移动已确认点去迁就过长手柄。

## 用对称和两种长度核图注

第一、第三个非端时刻的横坐标和为四倍圆周率，高度相同，可用来检查左右对称；中点横坐标二倍圆周率，高度四。轮心行程是一拱横跨度四倍圆周率，不能从曲线较长就把轮心平移距离改大。本课不测弧长，也不以轮外圆周长度替摆线长度；若另写弧长，应有额外推导与单独数值，不在图下注含糊的总长。保留参数、轮心坐标与标记坐标三列，任何一列改变后都重新核对应时刻，不能只改曲线外观而留下旧轮位标注。

## 按角度单位与身份排查错误

若最高点不在半圈，先核弧度与角度输入；若标记一直沿水平线，核是否画成圆心轨迹；若每个点都在地面，核是否每次换了接触点。三种问题不能靠同一条平滑命令解决。一次只修外部坐标或图中一类对象，再比较五点与三轮位。缩小看引线是否错接到另一个圆，必要时减少轮廓密度，不删参数身份。没有内置运动播放就保留静态步骤图，不把导出SVG称为已经生成动画，未知速度与实际帧率也不填入验收结果。

## 重开交付主线与静态轮位

保存可编辑原稿，并按现有导出方式重开检查轮廓、标签与图例。验收应清楚指认基线、轮心直路、轮缘曲路，以及起点接地、半圈在顶、整圈再接地三种状态；一拱跨度四倍圆周率、高度四。导出后节点不可再编辑的表示与原稿分开存，不拿一张截图当全部结构已保留。若文字挡住尖接处，移动说明而不是改几何。成果是可重复的原创静态示意，读者实际手绘结果另行观察，不宣称已在全部设备执行无滑动运动仿真或真机验证。
