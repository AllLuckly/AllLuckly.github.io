Use a readable control book to distinguish file availability, source permissions, container information and current-version support.

## Preserve the authorized original first

Choose a legally obtained EPUB that encounters an opening problem in Book Isle, plus a short unprotected EPUB you created or are explicitly authorized to use as a control. Record title, edition, source, acquisition time and device. The two books need not have matching content. Preserve the files and existing notes in their original locations; do not overwrite them, change their extensions or download an unknown unlocking utility. Without a problem sample, prepare only the control and mark diagnosis unperformed rather than damaging an existing book to produce an error.

## Confirm the file is not an undownloaded placeholder

Inspect the problem book in Files or its actual file provider, wait for any required download and check name, size and location. A cover or title alone does not prove all bytes are local. Save an accessible copy in an identifiable practice location and select it through Book Isle’s actual import entry. Preserve any system permission or network message and its stage; do not infer protection from that message. Completed import, a shelf entry and readable body text are three separate checks, each recorded from observation.

## Check the same path with the control book

On the same device and through the same import entry, select the unprotected original or authorized control EPUB. Inspect its shelf entry, cover, contents, beginning and end. Record version and observed behavior; changing file, device and network together cannot isolate a cause. If both fail, first investigate the entry path, storage, provider and actual message. If the control succeeds while the problem book fails, the two samples behaved differently; this alone establishes neither protection in the problem file nor support for every unprotected EPUB.

## Consult the source for the authorized reading path

Read the seller’s, library’s or publisher’s instructions for this particular book: check whether it requires a designated app, account, loan period or licensing flow. Do not generalize one service’s rules to every EPUB or enter credentials into a third-party diagnostic tool. If an authorized alternative reading path is offered, follow its current instructions and record the source; successful opening there does not prove two downloaded files are byte-identical. If requirements are unclear, mark them unknown and ask the provider rather than guessing.

## Inspect container information read-only with clear limits

If authorized to inspect the file and an existing trusted archive viewer is available, inspect entry names in a copy to see whether EPUB container structure and META-INF/encryption.xml are visible. Skip and record uninspected if the tool, rights or confidence in the file are missing. EPUB 3.3 also records font obfuscation in that file: its presence alone does not prove the entire book is DRM-restricted. Conversely, not seeing the name does not prove every licensing condition or the file’s integrity. For information observed in a copy, record the tool and inspection date; mark the listing incomplete if the tool shows only part of it. Keep unclear or unverified information unknown rather than substituting a filename for the provider’s license description. Do not remove, alter or bypass any protection.

## Separate messages, font appearance and body text

Record Book Isle’s actual message and stage: selecting, importing, opening the contents or turning body pages. If only a font looks different, first inspect whether wording is complete; if the body is blank, record whether contents and first and last pages open; for an unreadable-file message, first confirm that the file is complete and accessible. These observations have multiple possible causes. Neither a message nor font appearance alone proves encryption, an application defect or publisher responsibility. Preserve the sequence without inventing success or repeatedly altering the file.

## Prepare a feedback summary without private content

If the issue remains unclear, record device and system, confirmable app version, file type, source category, control result, exact message and whether download state was checked. Share a file only when authorized and necessary; prefer a self-made shareable sample or a minimal screenshot without book content. The provider can explain the title’s license and authorized reading path; app support can investigate concrete reproduction information. No Apple credentials, server address or entire private library is needed for an initial report. Leave contact pending if it did not occur.

## Preserve originals and recheck the readable option

Reopen the known-readable control and check contents and end pages. Record whether the unresolved book still lacks evidence about file availability, source authorization or app compatibility. If the provider offers an authorized alternate format or designated reader, keep it separate from Book Isle’s local records; do not claim automatic note migration, conversion or a fix. Retain original file, practice copy and time record. Any import, container inspection or licensing check not actually performed remains incomplete.
