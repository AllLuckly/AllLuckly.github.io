## Prepare text you are authorized to use

Choose an owned or authorized EPUB with a short, complete and recognizable passage. Record title, edition, chapter and opening and closing words, retain an independent original and confirm the file opens normally. The Book Isle listing describes text reading, highlights and notes. This exercise checks whether the system’s Speak Selection can be used on selectable text in the current version; it does not call it a built-in audiobook or promise every EPUB works. If text cannot be selected or the system menu has no Speak option, record it as unavailable rather than inventing an entry.

## Review system settings and how to restore them

Consult Apple’s system guidance and find the current iPhone or iPad accessibility setting for spoken content or its equivalent, then enable Speak Selection. Names and paths may change with OS version, so use the actual screen. Record the previous setting and volume for restoration. Skip if the device is managed by someone else or changes are inconvenient; do not disable existing accessibility tools. System spoken content and VoiceOver are different features. With VoiceOver enabled gestures differ, so consult Apple’s corresponding instructions first.

## Verify speech in a system app first

Open a short self-written passage in an available system text app and select one sentence. If the menu offers Speak, activate it, listen, and observe any pause or other controls. Set a comfortable, non-disruptive volume and do not suddenly raise headphone volume. This control checks system settings and current output in that app; it does not establish that Book Isle exposes the same selection menu. If silent here, check system settings, output and selection before testing Book Isle. With multiple audio destinations, record the current speaker or headphones and keep the same output for comparison. System speaking rate and language affect what you hear but are separate from whether body text was selected. If a name is unclear, check its spelling in the passage instead of treating synthesized pronunciation as proof the book text is wrong.

## Select a short explicit passage in Book Isle

Open the prepared EPUB in Book Isle and locate the recorded chapter and sentence. Use whatever text selection the current reader actually provides and verify the start and end of the selection; do not select a whole chapter first. If only highlight, copy or other actions appear without a system Speak option, record the actual menu. Notes support does not establish speech support. Do not overwrite existing highlights to test; use your own sample if testing annotations, and distinguish selection, saved annotation and playback.

## Listen only if the speech action is offered

If the selection menu actually offers system Speak or an equivalent, activate it and listen to the chosen sentence, comparing its beginning, end and reading order. If pause or resume is available, try it once and record the feedback. If only buttons or other page text are spoken, do not claim the target passage was read. Observe waiting and output separately. The audiobook player plays existing audio, whereas system speech synthesizes accessible text; their capabilities and progress should not be conflated.

## Separate body text, images and selection scope

In an EPUB with images of text or scanned pages, visible letters do not prove text is selectable or that the system can recognize and read it in the intended order. Compare with clearly selectable body text in the same book and record the image result; do not promise an OCR button in Book Isle. If speech skips text, check whether the selection crosses lines or includes notes and compare the same sentence in a system text app. Several causes are possible; one observation cannot prove a file or app defect.

## Keep an accessible alternative when unavailable

If Book Isle text is not selectable or the system menu lacks Speak, stop that path and record device, OS, app version, format, chapter and actual menu. If you lawfully have an accessible text version, use system speech in another supported reading environment and return manually to Book Isle using chapter and boundary words; this is not automatic progress sync. When seeking support provide a self-written short sample and redacted steps, not a private complete book, password or protected content, and do not bypass restrictions to obtain text.

## Recheck selection and restore personal settings

Return to the shelf and reopen the same book and chapter, confirming the original and prior notes remain locatable. Record whether this test actually created a highlight; text selection is not automatically a saved note. Restore system speech, rate or volume changed for the exercise while preserving accessibility settings the user needs. Separately record the system-app control, Book Isle text selection, menu availability, words actually spoken and pause result. Mark unperformed steps untested; success covers only this device, version and selected passage.
