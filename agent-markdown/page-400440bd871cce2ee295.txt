在白底上设计两组等字号灰字样张，外部计算相对亮度与对比度，分开色值判断和实际阅读观察。

设计一张原创文字对照卡：同一白底、相同文字和字号，分别使用 #767676 与 #777777 两种不透明灰色。两者每个八位通道只差一级，按标准 sRGB 相对亮度公式与白色计算的对比度却分别约为 4.542 和 4.478。先做设计样张，再在外部核算；本例不声称应用内有自动无障碍评分，也不凭单项计算认定整个产品合规。

## 固定背景、内容和比较条件

新建约1600×1000像素横画布，铺一块不透明 #FFFFFF 白色背景，分上下两行安排同一段原创短句，例如“Open the saved draft”，每行使用相同字体、字重、字号和间距。上下行分别标记 A 和 B，标签放在文字区域外。背景、两行文字和标注独立分组并保存可编辑稿。画布大小与短句只为练习，不表示网站或任何产品的实际字号；要让比较有效，除文字颜色外不要随意改变其他条件。

## 输入两种颜色并核不透明度

第一行设为 #767676，第二行设为 #777777；若当前版本提供明确的色值输入入口就使用它，否则记录实际可设置方式，无法精确输入时不把近似色称为精确样本。两行文本和白底均保持不透明，不额外加阴影、渐变或叠层。选中对象逐一核颜色归属：白色属于背景，灰色属于文字；不能只看色板上已有色块就假设文字已使用它。若一行外观变深，先排查透明度和上层覆盖，而不是马上判断公式有误。

## 将八位通道转换为标准 sRGB 值

十六进制 76 与 77 分别是十进制 118 和119；将其除以255，得到约0.462745和0.466667。灰色的红、绿、蓝三个通道各相等，但转换到线性光值时不能直接把这些小数当相对亮度。对于大于0.04045的标准化通道值 c，使用 ((c+0.055)/1.055)^2.4；本例两个灰均在此范围。白色三个线性通道均为1。保留计算过程，不以截图中某个抗锯齿边缘像素代替文字指定色值。

## 计算亮度和对比度，不先四舍五入

按 WCAG 的相对亮度权重，L=0.2126R+0.7152G+0.0722B；灰色三个线性通道相等，因此 L 等于任一线性通道。白底较亮，对比度为 (1+0.05)/(L+0.05)。外部计算得到 #767676 约 4.54222496:1，#777777 约 4.47808945:1。保留未截断结果判断，再为阅读显示适量小数：后者四舍五入到一位会显示4.5，但实际小于4.5，不应因此当作达到该门槛。

```
background = #FFFFFF; text A = #767676; text B = #777777
channel A = 118/255; channel B = 119/255
linear(c) = ((c + 0.055)/1.055)^2.4 for these values
contrast = (1.0 + 0.05)/(linear(c) + 0.05)
A = 4.54222496...; B = 4.47808945...
```

## 正确说明 4.5 的适用范围

WCAG 2.2 的文字最低对比度准则通常要求至少4.5:1，也列出大号文字、非活动组件等例外；应按具体内容与条件判断，不把这个门槛推广到所有图形或所有字号。本例仅比较两组指定的不透明 sRGB 色值和白底：A 的理论结果高于4.5，B 低于4.5。它不是针对某个应用界面的完整审计，也不保证每个人都能轻松阅读。不要把一行文字的数值通过写成整个页面、所有状态或所有用户都已通过。

## 在实际视图中核字号与颜色

回到样张，检查两行是否使用相同字号、字重、内容和白底，再观察灰色差异。将画面按实际目标尺寸查看，并在不改变原稿的前提下做一份稍大字号副本，比较阅读感受；字号变化不是本课两种颜色计算的原因。视图缩放、显示器、色彩管理及抗锯齿都会影响感受，不要从肉眼看不出差别推断两色相同，也不要用肉眼轻松阅读替代外部公式。记录观察的设备和查看方式，没观察到的结果保持待核。

为避免行号误导，可以把原始两行复制到第二张对照卡，并交换它们的上下位置；新卡仍保留颜色标签、相同的字重和字号。这样可检查位置或背景局部变化是否影响自己的观察，但它不能改变任一色值的理论比值，也不是视力或阅读能力测试。比较后关闭临时副本即可，原稿中 A 和 B 的色值与标识仍需一一对应。

## 排查错色、透明和取样位置

若外部工具结果与上述不同，先确认颜色依次为 #767676、#777777 和 #FFFFFF，且没有把字母 O 写成数字零；再检查公式的线性化与 0.05 项。半透明文字与背景混合后，实际显示色会改变，本样张不使用透明。截图取样时字形边缘会混入背景和抗锯齿颜色，不能将边缘像素当作标注的原始文字色。保存原稿并一次只改一个条件；如果无法确认对象使用的精确色值，标明近似而非填写理论通过。

## 导出并保留判断边界

保存可编辑原稿，按安装版实际提供的入口输出图片或 SVG，在独立查看器中检查两行文字、标签和白底是否完整。另存外部计算记录，包括原始色值、公式和未截断结果；如色彩空间或导出结果发生改变，应对实际交付内容重新检查。SVG 中含位图不自动成为全矢量，PNG 不保留可编辑文字。未执行的导出、重开或设备阅读测试记待核，标注“样张比较”而不是发布无依据的无障碍认证。
