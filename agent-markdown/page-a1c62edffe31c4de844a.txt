English translation of the [Chinese original](<https://allluckly.cn/guides/manyue-auto-reading-pause-check/>), translated on 2026-10-26. Original publication dates, attribution, code and version notes are retained.

Automatic reading is useful only when interruptions do not make you lose your place. ManYue 2.0.3 publicly describes improvements to pausing on app changes and saving reading position. Test your actual layout with a short book, distinguishing automatic page turns, continuous scrolling and ordinary manual reading.

## Choose a sample with obvious positions

Use a short comic with recognisable pages or a self-made numbered sample. Confirm complete local access so network delays do not resemble pausing. Record mode, orientation, chapter and starting scene. Previously read content makes comparison easier and avoids confusing unfamiliar story developments with skipped pages.

## Identify the available automatic control

Inspect the automatic page-turning or scrolling controls exposed by your installed version and current mode. A page interval and a scroll speed describe different actions. Record unavailable or conditional controls and skip them. Observe actual movement before testing pause behaviour; changing a value alone does not prove automatic reading is running.

## Practise pausing in the foreground

Start slowly, let the content advance briefly, then use the visible pause or stop control. Wait beyond the next expected advance and confirm the image stays put. Turn one page manually and check whether automatic movement remains paused. Learn the actual stop action on the sample before testing interruptions during normal reading.

## Switch to another app while running

Restart automatic reading, note a clear scene, and switch to the home screen or a note app. Return after a few seconds and inspect both position and running state before tapping anything. Immediately pressing start would hide whether an automatic pause occurred. Repeat a small boundary discrepancy consistently and record what happened on your device.

## Check locking and reopening separately

Test system locking separately from app switching and record its outcome. Then pause deliberately, return to the shelf and reopen the same entry to check saved position. Do not rename or reimport the file during this comparison. If the chapter restarts, verify that you opened the existing resume entry rather than selecting the chapter’s beginning in the contents list.

## Use scene anchors for continuous pages

For vertical continuous reading, record a visible scene within the image as well as its index. Returning to the same tall image does not necessarily mean returning to the same section. Compare the anchor and nearby content. Test ordinary pages and tall images separately. If needed, retain a chapter reference or bookmark while isolating the affected layout.

## Turn an irregular result into repeatable steps

For unexpected continued movement or an offset position, record app and system versions, layout, automatic control, interruption action and approximate delay. Repeat once with the same sample and unchanged settings. A numbered sample can express expected and observed positions clearly. Do not infer data loss from one observation or clear history as part of the test.

## Questions and completion criteria

Is needing to start again after returning an error? Pausing may be the intended protection against missed content; first verify the position. Does a stationary page always mean pause? Loading or a chapter ending can also stop movement, so use a complete local sample. Finish knowing how to stop, inspect state after interruption and verify the actual saved position.
