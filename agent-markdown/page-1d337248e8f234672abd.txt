以两条直线的系数叉乘求交点，设置平行与重合对照，不把第三分量零除成有限坐标。

画一张平面直线交点图，旁边保留三分量账本。有限交点可以落到普通坐标图中；平行线的齐次结果是方向对应的无穷远点，不能挤在画布边缘；重合线得到零向量，更不是一个合法交点。三种情况用不同结果卡说明。

## 先区分点坐标与直线系数

本课平面点用非零三元组p=(x,y,w)的齐次表示，w非零时对应普通坐标(x/w,y/w)。直线用非零系数l=(a,b,c)，关联条件是ax+by+cw=零，两类三元组不能因都有三个数就混用。取l1=(1,1,−4)、l2=(2,−1,−2)，在w=1的有限平面分别是x+y=4与2x−y=2。建立直线、交点、坐标标签与分类账层，先存原稿；原点齐次坐标是(0,0,1)，不是非法零向量(0,0,0)。

## 按顺序叉乘保留全部三分量

计算l1叉l2，第一分量1乘负二减负四乘负一，得负六；第二分量负四乘二减1乘负二，得负六；第三分量1乘负一减1乘二，得负三。于是p=(−6,−6,−3)，第三分量不零，除以负三归一化为(2,2,1)，有限点是(2,2)。不要只抄前两项当成(−6,−6)，也不能把第三项丢掉后按绝对值凑位置。叉乘顺序颠倒只整体变号，所代表的非零齐次点仍相同。

## 代回两条方程作独立验算

有限点(2,2)代入第一线得2+2−4=零，第二线得4−2−2=零，须同时满足。也可直接把未归一化的p代入齐次关联式：负六加负六加十二为零，负十二加六加六也零。两种写法一致，说明非零整体倍数不改变点。若只满足一条线，先查叉乘的第二项符号与第三项，再查是否把线系数当点坐标；别把图中的交点拖到两线视觉交叉处就删除失败记录。代回检查比用粗线遮住误差更可靠。例如p也可写(4,4,2)，归一化仍是(2,2)，并非另一个更远点。这里允许乘的倍数必须非零；乘零会把合法齐次对象变成非法零向量，不能继续声称表示不变。

## 把有限图与齐次账本分区

建议2400×1600画布，原点(400,1200)，两轴每单位120像素。交点落(640,960)，两线可按x在负一到五、y在负三到八的窗口截取可见部分，截断处注明“显示窗口”。先用方程算各边界上的有效端点再连线，不能把窗口边框当作新增数学直线。右侧留账本，显示原叉乘与归一化，标签引线不参与运算。没有数值入口时用辅助线近似，图示比例与精确代回分别记录，不声称画布对象具有射影求交计算能力。

## 平行线得到方向而非有限边缘点

改用l3=(1,1,−6)，即x+y=6，它与l1平行且不重合。叉乘l1叉l3得(−2,2,0)，第三分量零而整体非零，是射影表示中的无穷远点，对应方向(−1,1)。普通有限平面里两线没有交点，不能执行除零，也不能把它画在X最大处标成一个很远的数。另开结果卡写“无有限交点；齐次方向(−2,2,0)”，图中只显示平行关系。两线间距有限不意味着沿延长线走得足够远会在有限位置相遇。

## 重合线的零向量必须单独分类

再设l4=(2,2,−8)=2l1，两条系数只差非零倍数，表示同一条直线。叉乘得到(0,0,0)，这个向量不代表任何射影点，因此不能与上一节第三项零的非零向量混为一谈。两线有整条公共线，交点不唯一；“无合法单点结果”不等于它们没有公共点。把有限相交、平行不重合、重合三栏并列，分别写非零w、零w非零向量、全零向量，结果条件按完整三分量判断，不能只看最后一个数字。

```
l1=(1,1,-4); l2=(2,-1,-2)
l1 cross l2=(-6,-6,-3) -> (2,2,1) -> affine (2,2)
l3=(1,1,-6)
l1 cross l3=(-2,2,0): nonzero ideal point, no affine intersection
l4=(2,2,-8)=2*l1
l1 cross l4=(0,0,0): invalid point, coincident lines
```

## 用倍数对照与零输入定位错误

将l1整体乘三，或把有限p整体乘负二，正确归一化后应仍是同一条线或同一点；若位置改变，检查是否只改了部分分量。把l=(0,0,0)当输入则连直线本身都未定义，应在计算前拒绝，不等到画面异常再补救。排障依次查输入非零、系数对应、叉乘符号、w分类与归一化。图上近平行线可能在窗口外有很远的有限交点，不能仅凭显示范围宣布w零；本课整数例以精确算式分类，不用视觉阈值冒充数学相等。

## 重开逐张结果卡复述条件

保存可编辑直线和结果卡，输出SVG或PDF并另开PNG，缩小核三类说明没有串到错误图旁，放大核负号和第三项零。重开原稿，隐藏有限交点，凭两线系数复算后再恢复它；对平行和重合版本不添加虚构单点。交付叉乘、两条残差、倍数不变与无效零输入账本，未做的输出检查标待办。该课是手工射影坐标阅读图，不由一幅图推断真实相机参数、实体透视深度或应用内置三维重建。
