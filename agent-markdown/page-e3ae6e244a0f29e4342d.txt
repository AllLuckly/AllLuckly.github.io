对照三条只改常数的方程，核系数符号、重根与实数范围，再代回候选。

判别式为零不表示 x 等于零，判别式小于零也不表示所有数域都没有根。本课在书屿读三条原创二次方程，把归零、抄系数、数不同实根和求候选分成四步。演算用纸面或已有笔记完成，不把书屿阅读界面写成自动代数求解与证明工具。

## 一、先固定实数解与原题位置

把原创练习卡存成自己已有可读格式，明确本课只数不同的实数解。打开后核上标二、减号和等号，记录文件身份与可返回的位置，不把平方漏读为二乘 x。原书、原日期和旧笔记保留，解答另页放置，先自己读题。应用没有某种批注功能时用纸面，不能为了做练习假设会出现自动求根按钮。遇到模糊扫描先找清晰题面，不能从后面的答案反推一个自己想要的常数再当原题。

## 二、三条归零式分别抄系数

下方三式都已把右边写零，先逐条抄 a、b、c。它们的 a 均为一，b 均为负四，c 依次三、四、五，不能把 b 的减号抄成外面的另一个运算。暂时只登记系数不求根，使后面错误能定位到读题还是公式。平方项系数为零时便不是本课的二次方程，这个条件要和实数范围一起写出。三个常数相近不表示可以只算第一条后把所有结果复制过去，题面身份应各自保留。

```
A: x^2 - 4x + 3 = 0
B: x^2 - 4x + 4 = 0
C: x^2 - 4x + 5 = 0
D = b^2 - 4*a*c; a != 0
Count distinct real solutions.
```

## 三、判别式中先把负系数整体平方

依据[OpenStax 二次方程与判别式](<https://openstax.org/books/college-algebra-2e/pages/2-5-quadratic-equations>)，本课计算 b 的平方减四乘 a 乘 c。负四整体平方为十六，不是负十六；按三条分别得到十六减十二等于四、十六减十六等于零、十六减二十等于负四。保留每个乘积与符号，不能只填最后正零负三个标签。这里的 D 是由系数算出的辅助量，不是 x 的解，也不是影片日期或文件编号，阅读笔记中要给符号写明角色。

## 四、由正零负数不同实根

在实系数且 a 不为零条件下，A 的正 D 对应两个不同实根，B 为零对应一个不同实根，C 为负对应没有实根。B 常说重根，按重数可以记两次，但本课明确问不同的解，所以只数一个，不能在同一份答题卡里来回换计数口径。C 的结论带实数范围，若原书扩展到复数，题目范围已变化，应另开记录；不能把“无实根”删去实字后当作所有数学语境通用的无解。

## 五、求出候选并代回原式

A 因式分解为 x 减一乘 x 减三等于零，候选一与三，各代回原式都得到零；B 为 x 减二的平方等于零，候选二，代回也为零。写清因式分组，不能把两个括号相乘误读成相加。B 的解二说明 D 为零绝不等于 x 为零，代零进 B 会得到四，正好构成反例。求候选与数个数互相核验，但只代已找到的一根不能证明没有漏根，因此仍保留判别式依据。把代回展开为一减四加三等于零，以及九减十二加三等于零，可检查平方与乘法有没有先算。两根要用各自整条算式，不把一根的平方配给另一根的一次项；解的身份必须贯穿同一行。

## 六、用配方与未归零对照查范围

C 可写成 x 减二的平方再加一等于零。实数平方非负，加一后至少一，因此没有实根，与 D 的判断对应。另写 A 的右边改成一的独立对照，先移到左边后常数变二，才计算新的 D 为八；不能沿用原 c 为三。对照不是原题更正，而是示范右端变化如何改变系数。若 a 另改为零，先按一次方程处理，不把原二次公式的分母零当作计算器故障，也不能说所有这样的式子都无解。

## 七、排查漏负号与重根重复计数

若三条 D 都为负，先查是否把负四平方写负十六；若 B 列出二、二并说两个不同实根，回到计数口径。若 C 硬填正负二，检查是否跳过了负判别式与实数前提。每次只改发生错误的一步，保留原输入、修正理由和代回过程，不只擦掉最终标签。书屿没有自动判错反馈时如实写手工核查；来源若只剩残缺题面，待取得完整条件后再定论，不用网上另一个相似例子冒充本书这道题。

## 八、离开重返后独立复算三行

离开当前阅读页，再按原锚点返回，确认三条常数仍为三、四、五且右端为零。遮住答案，独立抄系数并复算 D 为四、零、负四，再数两个、一个、零个不同实根。最终保存题面、系数、判别式、候选与代回、范围条件及修正记录。原书和旧日期不改，未执行的笔记导出或跨设备行为不写通过。验收是另一位读者能沿记录检查每步，而不是凭标题宣称应用已为所有二次方程提供自动证明。
