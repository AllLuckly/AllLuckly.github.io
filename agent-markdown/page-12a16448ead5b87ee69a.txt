Use an owned test book to check local files, notes and membership-dependent remote features, recording actual and pending results.

## Start with the published entitlement and actual device state

The public Book Isle listing places NAS, WebDAV, SMB, OPDS and Calibre private-library access and WebDAV private sync among membership features. After membership expires, those remote capabilities are locked. Books already downloaded to the device, local reading, local notes and local shelf management remain usable. Record the state and time actually visible on this device; an old receipt, another device screenshot or this article’s date does not prove a current entitlement. This exercise requires no purchase, cancellation or subscription change; store region and installed-version interfaces can differ.

## Identify one owned sample

Choose an owned or authorized test book. Record title, author, edition, file format, a recognizable chapter and a short passage. Keep an independent copy of the original file on the device or in your own library; matching covers, titles or authors do not prove two files are the same edition. Avoid the only important book and sensitive pages. Screenshots need only the information required for comparison. If no local book can be confirmed, use the app’s actual available import path for a small owned EPUB or PDF and identify it after opening. Leave subsequent local-reading checks pending if import was not completed.

## Distinguish a remote listing from a readable local copy

While entitlement and the connection are available, record whether the book is being viewed through a remote library or already has a downloaded device copy. If downloading, select the intended file through the actual interface, wait for completion and record the visible result. A listing, cover or button press alone does not prove that the complete book reached the device. Open it from the device’s readable entry and inspect beginning, target chapter and end against the original’s identity. If download fails or access has already expired, mark the local copy as not obtained; a remote listing is not an offline book.

## Test reading and one local note

Create an identifiable practice note at the target chapter with a date and non-sensitive marker. If that format and interface permit, also save one highlight or bookmark. Leave the reader, reopen the book and verify the passage, location and actual saved record. Text and reading records are distinct: opening a file does not establish that a note synchronized; seeing a note does not mean another device has the book. If an annotation entry is unavailable, do not invent menu labels or promise that every format supports every annotation type; record what is actually available.

## Check transferred content, not configuration alone

If membership is still active and WebDAV is already configured, complete the test note, run the existing sync using the current interface, then check the same edition and marker on the destination device. A configured address or success message alone does not prove the particular note arrived. Check remote directory, account and destination book copy independently. If sync is unavailable, unclear or membership has expired, preserve the present local record; do not clear the sync directory or conclude a missing remote record is lost. Do not edit the same important note on two devices simultaneously to manufacture a conflict.

## Test offline reading when practical

Once the sample is confirmed on-device and no download or sync is running, temporarily disconnect at a convenient time. Open that confirmed local book, navigate to the same chapter and inspect the saved note. Restore the network afterwards and record when it was disconnected and restored, respecting the original settings. If the text is unreadable offline, check whether the opened entry was remote, whether the download finished and whether the local original is readable. Do not delete server content, uninstall the app or erase data to run this check. Mark offline behavior untested if the test was not performed.

## Diagnose the scope of an entitlement prompt

If a remote connection or sync shows a membership prompt, record whether it happened during browsing, downloading or sync and what entitlement state is actually visible. A locked feature does not itself establish that local books were deleted. Open the previously confirmed local sample and check the book, note and shelf entry separately. If that sample also fails, examine file identity, device storage and format while retaining the actual error; the membership prompt alone does not diagnose it. If the App Store subscription state and in-app entitlement differ, record time and region and use official support; do not guess the outcome of a refund, renewal or purchase restoration.

## Deliver and recheck a recoverable list

Keep the original-file location, edition identity, device name, local reading and note results, and whether sync actually completed. Reopen the sample and practice note to compare with the first check; handle the disposable practice note according to your own preference. If membership remains active, list future checks without waiting for expiry or changing the subscription for demonstration. Other remote books not downloaded, notes not synchronized to this device and all server availability lie outside a single-sample pass. Assess each from future actual observations.
