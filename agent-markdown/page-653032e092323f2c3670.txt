Standard pinyin spelling and the key sequence accepted by a phone keyboard need not be identical. Use 女, 路 and 居 to build a practice card: check the standard spellings, observe the candidates in Jianlai’s Chinese input layout, and verify the characters committed to a note. The installed version determines actual behavior; this exercise does not assume a dedicated ü key or any particular substitute.

## Prepare a safe note

Create a practice copy in your own ordinary notes app, titled “Pinyin observations”. Avoid accounts, real names and sensitive content. Confirm the field accepts Chinese and switch to the Chinese pinyin layout actually installed in Jianlai. If Jianlai or a suitable layout is unavailable, or the host temporarily switches to the system keyboard, mark the test pending rather than attributing another keyboard’s results to Jianlai.

Record the Jianlai and system versions, device, layout, date and whether the previous uncommitted composition was cleared before each example. Keep notes locally and inspect screenshots before sharing. This exercise does not require changing dictionaries, reinstalling, or enabling Full Access.

## Check standard spelling first

The *Hanyu Pinyin Scheme* writes 女 as nǚ, 路 as lù and 居 as jū. The final of 女 is ü, while that of 路 is u. 居 uses a final from the ü series after j, where standard spelling omits the two dots, yielding ju. Prepare columns for target character, standard spelling, candidate and committed result. Write the rule before using the keyboard rather than inferring it from the keys shown.

The tone marks in nǚ, lù and jū are teaching notation; a phone keyboard need not require them as input. Homophones exist, and candidate ordering can vary with layout and personal use. These examples test selected characters, not a promise that the first candidate will always be correct.

## Try 女 in Jianlai

On a new line, use the currently visible Jianlai pinyin layout to enter 女. Observe the available letters or symbols and use the app’s visible instructions and a method you know. Do not assume every layout has a separate ü key or treat another input method’s substitutions as a guaranteed Jianlai feature. If the input method is unclear, record the visible keys and mark the question pending instead of repeatedly changing settings.

When candidates appear, do not immediately choose the first. Identify 女, select it and verify it appears in the note; text still in the composition area has not necessarily been committed. Record the actual key sequence, whether the target appeared, your choice and the final note. If it did not appear, record “not found”; manually copying the character is not evidence that the candidate appeared.

## Compare 路 and 居

Before each example, commit or cancel the previous composition and start a new line for 路. Its standard pronunciation lù uses u, not ü. Observe candidates, select the target, check the body and record your actual sequence. If you choose a different homophone, correct it using the host’s available editing controls on the practice copy and distinguish correction from the first entry.

Then enter 居. Standard jū is written with u even though its final belongs to the ü series. This is an orthographic omission rule, not a claim that all instances of u sound like ü or an inference about the keyboard’s internal algorithm. Observe and commit the target and record the sequence and result. If absent, inspect the layout and composition state; if still unavailable, mark the step unfinished without clearing personal learning data or resetting the device.

## Check three layers

Separate standard spelling, actual keys and committed characters in the table. The reference establishes the spelling; this session supplies the observed keys and candidate order; the body must be inspected character by character. Correctly entering three examples does not establish behavior for other syllables, a nine-key layout or another device. Report only the layout tested.

If the table was copied, reopen the note and verify that 女, 路 and 居 remain on their intended lines. If copied pinyin with tone marks displays incorrectly, check the font and text before blaming Jianlai. Separate crowded lines for clarity without changing system settings.

## Troubleshoot and save

For an incorrect character, distinguish key entry, candidate selection and subsequent host editing. A target that appeared but was not selected is different from a target that never appeared. If the system keyboard takes over, inspect the active field and input indicator. When the layout is unavailable, record the limitation; do not experiment in password or other sensitive fields. A request for help can include non-sensitive reproduction steps and device versions rather than personal dictionaries or documents.

Deliver three rows listing standard spelling, actual keys, whether the target appeared, the committed result and unfinished steps. Save and reopen the practice copy. Keep the original keyboard, language and permissions as they were. This exercise uses public sources and does not claim a physical-device test.

## Add a repeat-check condition to the card

After an interval, reopen the same note and check the three target lines character by character before looking at candidate order. If a candidate appears in a different position, record the current layout and actual text, then check whether the device or input context changed. A position change alone does not prove a setting took effect. Use only public practice content, not private messages, when repeating the exercise. Leave unperformed steps blank with a reason rather than inferring a second result from the first.
