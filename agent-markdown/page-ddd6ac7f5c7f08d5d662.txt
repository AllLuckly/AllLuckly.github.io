## Define source and scope

Plex allows local movie extras in named subfolders such as Interviews and Deleted Scenes, or as inline files with type suffixes. This guide tests the subfolder method only and does not assume iCouldPlay displays extra categories. Server recognition, an iCouldPlay page control and actual playback are three separate results; record any absence.

## Prepare isolated videos

Have the administrator prepare an isolated Plex movie library, a self-made or authorized main short and two distinct extra copies: an interview beginning with INTERVIEW and a deleted scene beginning with DELETED. Keep originals outside the test library and avoid private recordings or unauthorized material. Record actual format, duration and opening markers for all three and check for destination-name collisions. Put all three opening markers in a checklist before comparing playback.

## Check local-asset settings

Ask the administrator which Plex movie agent the test library uses. Plex says the current Plex Movie agent needs local assets enabled in the library’s advanced settings; older agents also involve enabling and ordering Local Media Assets. Inspect or adjust only the isolated library and authorized configuration. Do not claim all versions have identical screens or change others’ real libraries for the test; record the initial state for restoration. If the setting is shared by the server rather than limited to the isolated library, ask the administrator about impact; if it cannot be isolated safely, do not change it and mark dependent steps unperformed.

## Create the main movie folder

Create fictional Practice Film (2030) in the isolated library and place the main copy there following Plex movie naming guidance, for example Practice Film (2030).mp4 with the extension matching the actual container. Initially omit extras and have the administrator scan normally. When the web item appears, record title and opening picture as a baseline; record an absence of remote metadata as well.

## Place the interview subfolder

Inside the movie folder create Interviews and copy the interview clip as the descriptive Interview sample.mp4. Verify no same-named destination exists and that the extension matches the real format. Do not place the interview as an unmarked main movie in the folder root or alter the main feature. Record relative path and size so the later client picture can be associated with the sample. Open the test clip on the server to verify its first frame says INTERVIEW rather than accidentally containing the deleted scene.

## Place the deleted-scene folder

Also create Deleted Scenes inside the movie folder and copy the other short as Deleted sample.mp4. Verify it differs from the interview and that its opening marker and duration match the preparation record. Each extra belongs in its own documented folder; check both name and placement. Do not combine the two folders or use both suffix and subfolder methods for the same test copy.

## Refresh server metadata

Plex notes that extras added after a movie is already in the library may require refreshing that movie’s metadata. Have the administrator refresh the test movie normally and wait, then record whether interview and deleted scene appear in Plex Web, their names and openings. If only one appears, check paths, local-asset settings and permissions first; also confirm the refresh targeted this test movie rather than another with the same title and record when it finished; do not clear the entire library or replace real metadata to troubleshoot.

## Observe actual iCouldPlay controls

In iCouldPlay use the same server and authorized account to open test-movie details. Record whether the current version shows extras, each item name and location. If playable, verify INTERVIEW and DELETED openings and sound separately. Record an absent control, a single item or playback failure independently; do not infer client category support from Plex Web. Identify the main feature separately from its opening.

## Separate local from online extras

This exercise checks only files placed locally by the administrator; the mere presence of an extra does not prove it came from a particular folder. If the server also displays automatically obtained online content, compare the self-made marker, path and name, asking the administrator to identify sources if needed. Plex online automatic extras have separate subscription and network prerequisites; do not treat them as local recognition or download unauthorized media.

## Troubleshoot and restore

If the server lacks an item, check library agent, file format, subfolder and refresh. If the server is correct but iCouldPlay differs, verify account, movie identity and interface location, then save observations without private addresses. Do not assume playback failure must be a naming issue or call an undisplayed third-party category a missing server file. If needed, ask the administrator to open the files on the server and verify both opening markers against the web and iCouldPlay records, avoiding confusion between similarly named items. The administrator removes test copies by agreement and restores any changed isolated-library settings.

## Keep a minimal handover

Record relative names and folders for the main feature and two extras, opening markers, server version, agent setting, refresh time, web categories and actual iCouldPlay actions; mark untested cells unperformed. Confirm the three original videos and real library remain unaffected before ending, and remove accounts, server addresses and private titles before sharing. This guide relies on public documentation and claims no private-service or device test.
