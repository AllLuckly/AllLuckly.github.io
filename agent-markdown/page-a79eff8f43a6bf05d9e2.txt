Aggregate search finds one title across multiple comic sources you have added. ManYue groups results by source; it is not an unrestricted internet search and does not prove same-named results are the same edition. Use two working sources for an evidence-based comparison.

## Verify independent search in both sources first

Prepare two trusted, authorized comic sources with search support, and search a known title in each separately. A source lacking search or already failing independently is not an unexplained aggregate omission. Aggregation organizes existing interfaces; it does not add a missing search API.

Choose a work whose author and content you know, recording its usual name and possible aliases. Avoid a very broad single-character query and its irrelevant results. Do not add many unfamiliar sources just for quantity; the goal is result quality, not a crowded search page.

## Choose the aggregate scope on the search page

Open Search and inspect the current target. Select Aggregate Search and enter a keyword. If settings include Search Sources, retain only the two verified sources initially. Local-library, online-source, and aggregate searches cover different scopes; confirm the area before comparing local imports with online chapters.

After submitting, inspect each source section. A slow or failed source does not mean all failed; check their individual loading states and results. Use results already returned instead of clearing the keyword and restarting all requests. Frequent identical queries add waiting and make results harder to associate with requests.

## Compare information beyond the name

For a same-named result, inspect author, synopsis, cover, chapter count, and updates. Covers may be reused across editions, and titles may be abbreviations or translations, so compare at least two additional details. Spin-offs, remakes, collected editions, and serialized versions are not necessarily identical because they share a main title.

A simple checklist can record source A's chapter count and latest title, and whether source B has extras or different volume names. This describes current visible results, not an absolute long-term quality ranking. Content changes; today's completeness does not guarantee the same later.

## Continue narrowing within one source's results

The aggregate page offers a quick initial view per source; full filtering and additional pages usually require that source's search-results page. A small preview does not prove there are no other matches. Follow available More controls and use filters the source actually supports.

When changing keywords, try the core title, then aliases commonly used by the maintainer or work. Chinese, original-language, and translated titles may use different indexes. One empty result does not prove absence, and one source's success does not mean another supports identical search syntax.

## Retain the source identity after choosing a reading entry

Choose an edition suitable for continued reading before favoriting, adding to Read Later, or following updates. Recording source and edition helps return to the right entry. Same-named works across sources may differ in chapter order, extra pages, and image count. Relocate by chapter title and content when switching rather than copying the old page number.

Before comparing another source, retain the original progress and notes, then open the target edition separately. Aggregate search does not automatically merge all results or guarantee seamless migration of reading records. After many chapters, an identifiable plot point is a more reliable switching reference than just page thirty.

## Handle abnormal results source by source

If only one section fails, search the same keyword within that source and check login and updates. If all fail, check network and search scope. If an expected source is absent, inspect source-selection settings and confirm that it declares search support. Native server libraries may use a different entry point from script sources.

Remove temporarily unneeded sources from the search scope while retaining favorites and history. Run another query and confirm that only intended sources appear. This reduces noise without deleting accumulated source records. When restoring the scope, check one known query again.

## Frequently asked questions

**Can aggregate search cover every NAS and local file?** No. This entry aggregates supported comic sources selected for searching. Local libraries and native servers may have separate search scopes. Check the page's current target instead of interpreting “aggregate” as every storage location.

**Can same-named results be exchanged freely?** Still compare author, edition, chapters, and pages. Serialized and collected editions may split chapters differently, and inserted extras can shift numbering. Recheck your reading position.

**Why does one source show few results?** The aggregate preview may show only initial results, or the keyword and source interface may limit matches. Open full single-source results before changing keywords. Do not judge the entire catalog by preview count alone.
