用原创整数周期与半整数周期余弦核DFT采样格、泄漏和补零条件，播放时只观察真正准备的自有影片。

频谱图上的点更多，不代表原始声音已经录得更久或更精确。短片分析中，窗口长度、信号频率与补零经常被混作一种设置。本课用十六点原创数列做完整可复算记录，再把图卡放进自己的讲解片，在云映逐项跟读；频谱计算发生在外部，不是应用隐藏的分析仪。

## 先固定真实样本数与分析区间

建立两组各十六个样本的余弦，采样率一万六千，振幅零点二，频率分别二千与二千五百赫兹。编号零至十五，分析块按N除采样率为一毫秒，首点到末点跨度则十五除一万六千秒，即零点九三七五毫秒，两种长度说明不同对象。将真实样本单独保存，不先补成六十四点再称有六十四个录制值。材料可以是纸面数列；若做讲解视频，标明它展示的是计算卡而非设备频谱测量，保留原始数列、外部运算和影片三层身份。

## 写明DFT与归一化约定

下方定义X为逐项乘复指数后的总和，显示幅度取X绝对值除十六，不再额外乘二。十六点时相邻频率格为一千赫兹，k等于二和三分别为二千、三千；k是整数索引，不是任意频率标签。实数余弦有正负频率两侧成分，所以在本约定下振幅零点二的整格余弦会在正侧对应格给零点一，而非零点二。若外部工具采用单边乘二或其他缩放，先记真实约定，再与本表换算，不能把显示值不同直接归咎于键入、影片或播放器。

```
Fs = 16000
N = 16
x[n] = 0.2 * cos(2*pi*f*n/Fs),  n = 0..15
X_M[k] = sum(x[n] * exp(-2*pi*i*k*n/M), n=0..15)
shown_magnitude = abs(X_M[k]) / 16
M = 16 or 64 (zero-padding only)
```

## 整周期参照只在对应格集中

二千赫兹在这一毫秒块里恰为两个周期。按十六点DFT，正侧k二的归一化幅度为零点一，对称负侧k十四也为零点一，其余理论为零，数值程序可能留舍入误差。用自己已有的计算工具逐项复算，记录所用公式、点数和精度；不把接近十的负十五次方残差当片源多出一种可听噪声。这里集中是针对本例准确整格、矩形截取、纯余弦成立，不能扩展成任何短音乐窗口都应只有一根谱线，真实片头文字或声标也不是这份十六点余弦的一部分。

## 半周期边界会把能量分到多个格

二千五百赫兹在同一块里是二点五周期，十六点频率格没有恰好二点五千这一项。使用同样归一化，k二幅度约零点零五九六五二，k三约零点零六七九五八，其他格也出现非零值。它不是原始信号突然同时变成二千与三千两条纯音，而是有限窗口DFT表示的分散。把这组与整周期结果并列，保留全部原始十六点；如果外部程序先把波形延长重复，已经改变了分析对象，不能再用这组结果验收，窗口边界和真实追加样本必须分开说明。

## 补零只改变频率取样格而非原始观察时间

复制同一十六点，在末尾追加四十八个零，做六十四点DFT，幅度仍除原始十六。频率格此时一万六千除六十四等于二百五十赫兹，k十可计算二千五百处的值，但原始观测仍只有十六点，不变成四毫秒真实录音。谱曲线被更密地取样，有限窗口造成的主瓣宽度和相邻信号可分辨条件并未因零点自动改善。若改为再录四十八个真实样本，那是另一项实验；两者的文件长度可能相同，数据来源和能说明的问题却不同，不能只看数组长度作结论。

## 加窗是改变权重的另一项处理

若外部工具另选Hann等窗，输入各点先乘窗权重，已经不是原先十六点矩形截取，幅度标定也须说明。它可能降低远处旁瓣，同时改变主瓣形状，不能简单写成删除了所有泄漏或永远更清晰。第一轮先固定矩形窗口完成上面数值，再另存加窗副本记录工具具体定义；对称窗与周期窗名称相近也不擅自当同一组权重。本课不要求安装科学计算库，已有工具不可复算时可停在公式与原表，未执行的窗函数比较不写通过，更不要拿另一张软件截图充当自己的结果。

## 在云映跟读图卡时先认清单位与版本

将自己的整格、非整格和补零结果各做一张清楚图卡，若已有制作条件放进带章节标题的自有讲解片。通过实际本地视频入口播放，在每张卡停留时核真实点数、分析点数、采样率、格距及归一化分母，字体太小时先回源卡检查清晰度。云映播放的是可见图卡，不会因为画面上写DFT就获得真实音轨的谱线。没有制作影片则记录纯文本核对已完成、视频部分未执行；不要靠切换播放速度改变图卡数字，倍速与源分析窗口是两套条件。

## 按公式差异排错并交付可复算文件

若整格显示零点二先查是否单边乘二，补零后幅度缩成四分之一则查是否错误改除六十四；频率差千倍时核赫兹与千赫兹。出现本课以外数值，回查起始相位、实际点数和窗权重，一轮只改一个条件。保留原数列、公式与输出、加窗或补零说明及真实图卡播放记录，重开片源核身份后恢复普通观看。最终须能解释更多频谱格与更长真实观察不是同义词；数学核对和网站页面通过只证明教材可追溯，不代表云映已经执行频谱测量或在任何录音中分辨出任意接近的两个频率。
