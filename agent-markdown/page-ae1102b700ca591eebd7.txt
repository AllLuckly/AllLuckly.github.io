## Prepare an understood shortcut that can run manually

调调 1.0.3 publicly lists Shortcuts support. First inspect actions actually offered by the installed version and select one you understand, can safely test and do not expect to make unwanted changes. Create and manually run a private test shortcut as in the previous guide. Record the real action name, inputs and manual result. Release notes do not enumerate actions, so do not assume a fictitious “play a chosen song” action. If none is identifiable and safe, leave this exercise pending.

## Give the test shortcut one clear identity

Give the test shortcut a distinguishable name and inspect its actual actions and inputs, confirming it is the same one that ran manually. If it asks for a track or other information, record the choices and results actually available; a suggested name is not a verified parameter. Do not put credentials or private service paths in a public widget label. Preserve other shortcuts. This exercise creates no automation and promises neither background nor offline execution.

## Distinguish two widget sources

Apple provides a system Shortcuts widget that runs a selected shortcut; 调调 separately describes its own Home Screen widget. They are different controls. This exercise uses the system Shortcuts widget and does not claim 调调’s own widget runs arbitrary shortcuts. Record your current Home Screen and existing widgets without moving or deleting them. If policy or OS version makes the system widget unavailable, mark the trial unavailable.

## Add a system Shortcuts widget

Following Apple’s guidance, touch and hold the Home Screen background to edit, use the actual Add control to locate Shortcuts, choose a size suitable for one shortcut, add it and finish editing. Icons and wording vary by OS, so fixed screenshot coordinates are not universal instructions. Place the new widget where you can identify it without removing existing widgets. If there is no space or you prefer not to change the layout, stop and record the step as unperformed.

## Select the previously verified shortcut

Use the system widget’s actual edit options to select the verified test shortcut, finish editing and inspect its label. If it is absent, check saved location and name rather than running a different shortcut. Larger widgets can display a collection; prefer a small widget when the actual system supports choosing one item. Record any version-specific difference. A label points to a shortcut; it does not prove an action has executed.

## Tap once and check feedback and result separately

When ready, tap the selected shortcut once in the newly added system widget. Observe any progress, request for input, opening of Shortcuts or error. Apple notes some actions open the app or need additional input. Then check the action’s actual promised result and relevant 调调 state and sound. A query or open action should not be described as playback. Widget presence, trigger feedback, action result and audible output are separate checks; mark unobserved portions pending. If an action waits for confirmation or further input, record the prompt and actual choice rather than describing a pending action as complete. When its effect is unclear, stop the run, retain the manual baseline and consult the action’s device-specific description instead of accepting an unknown prompt.

## Compare manual and widget entry

Use separate rows for the earlier manual run and this widget trigger: shortcut identity, input, system feedback and observable result. Manual success followed by the widget opening an app is not automatically failure. If nothing happens, check the selected shortcut, actual inputs and system feedback before retrying one condition at a time. Do not assume every 调调 action completes without an interface, or grant extra permissions and repeatedly trigger unclear operations to force a result. Without a manual baseline, do not claim equivalent outcomes.

## Remove only the test widget and restore

The user may decide whether to keep the private shortcut. Restore normal playback and verify other layout items remain.
