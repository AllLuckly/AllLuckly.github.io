书屿把本地电子书和个人 NAS 书库接到手机、平板的书架中，适合已经有一批书籍文件，希望自己整理、阅读和保存笔记的人。

## 从本地书籍还是服务器开始

第一次使用，先准备一本不带 DRM 的 TXT、EPUB 或 PDF，核对书名、目录和正文。确认阅读流程正常后，再添加远程来源。WebDAV、SMB、OPDS 与 Calibre 对应不同的服务方式，应该按服务器实际开启的接口选择，不必把所有入口都配置一遍。

| 你的书籍在哪里 | 选择对应教程 |
| --- | --- |
| iPhone / iPad 的本地文件 | [导入第一本 EPUB 并继续阅读](<https://allluckly.cn/guides/nasbook-getting-started/>) |
| NAS 或私人网盘文件夹 | 按服务选择 [WebDAV](<https://allluckly.cn/guides/nasbook-webdav-library/>) 或 [SMB](<https://allluckly.cn/guides/nasbook-smb-library/>) |
| 电子书目录服务 | [浏览 OPDS 书库并下载电子书](<https://allluckly.cn/guides/nasbook-opds-library/>) |
| 电脑上的 Calibre 书库 | [连接 Calibre 内容服务器](<https://allluckly.cn/guides/nasbook-calibre-server/>) |

远程列表能显示书名，和一本书已经完整下载，是两个不同状态。准备离线阅读时，应断开网络实际打开需要的章节；换设备时，也要分别处理阅读数据和书籍文件。

## 先分清文件格式的能力

除了 TXT、EPUB 和 PDF，书屿还提供 Markdown、HTML、FB2、RTF、DOCX、CBZ 等文件的处理入口。文档转换后的阅读表现可能与原始排版不同，导入后需要检查段落、图片和目录。

当前核对版本中，**MOBI、AZW、AZW3、CBR、DJVU 主要支持管理与同步**，不要把能够出现在书架里理解为已经支持完整阅读。若要现在阅读，先使用自己准备的受支持格式；只改扩展名不会转换文件。

## 阅读之后，把记录留在书架中

书签适合标记准备回看的位置，笔记用来记录想法，标签和阅读状态则用于整理书库。先围绕一本测试书完成这些操作，再批量整理其他书籍，会更容易理解各类数据之间的关系。

[WebDAV 同步](<https://allluckly.cn/guides/nasbook-webdav-sync/>)负责阅读数据。同步之后，还应检查第二台设备是否有同一本书、目录是否对应、进度能否定位；看到同步成功提示，并不代表所有书籍本体都已搬过去。

## 学习路线

这里准备了[60 篇书屿教程](<https://allluckly.cn/guides/nasbook/>)，从导入第一本书、书架整理、不同格式的阅读，到 NAS 连接、Calibre 与数据同步。每篇围绕一个操作目标展开，也列出完成后的检查方法。

书屿主要处理电子书与阅读记录；以漫画为主，可以同时了解[漫阅+](<https://allluckly.cn/apps/manyue/>)，根据自己的文件类型和书库来源选择。
