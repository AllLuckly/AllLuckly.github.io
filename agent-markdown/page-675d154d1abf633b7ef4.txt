Observe one nonconflicting practice shortcut with the system keyboard and Jianlai separately, without assuming third-party use of system text replacement.

## Prepare nonconflicting practice text

Create a practice note on your own iPhone without changing existing content. Use a non-private example: shortcut “zzmnote” and phrase “明天见”. Inspect your existing system text replacements first; if the shortcut exists, choose another unused one and record that choice instead of overwriting a rule. Confirm Jianlai and at least one system keyboard are available in an ordinary field. Record OS, host and installed Jianlai version if visible.

## Separate the system rule from Jianlai features

Apple documents system Text Replacement for expanding shortcuts into longer phrases. Jianlai’s listing describes multilingual input and prediction, but does not establish that Jianlai reads the system replacement list or uses the same trigger. Creating a rule is a system action; record Jianlai’s actual behavior independently. No expansion is not automatically a broken installation. System rules, app predictions and host replacements can come from different layers.

## Create one practice rule using actual system controls

If you choose and may change settings, follow Apple’s Settings \> General \> Keyboard \> Text Replacement path and actual Add control. Enter your nonconflicting phrase and shortcut in their respective fields, save and verify the new practice item. Do not alter other rules, reset the dictionary or change iCloud. If settings are unavailable, differ or you prefer not to add an item, mark the rule-dependent steps unperformed. If it synchronizes to other devices, verify actual state when restoring.

## Establish a system-keyboard comparison

In a new line of the same ordinary note, select an available system keyboard and type the created shortcut. Follow actual system suggestions or controls if a replacement appears. Record typed shortcut, visible suggestion, your action and final document separately. If no expansion occurs, inspect spelling, saved rule and active keyboard; retain the result without guessing a universal trigger key. Keep the target phrase and original shortcut separately for comparison. If expansion occurs, record whether it followed typing, a suggestion selection or another observable event. If multiple candidates appear, identify the one actually chosen rather than treating an unselected suggestion as committed text.

## Return to Jianlai for an independent trial

On another line, select Jianlai using the system switch control and confirm it is active. Type the same shortcut and observe any suggestion or replacement and your actual selection or confirmation. Do not assume the system keyboard’s trigger applies. Record final text and cursor. If the phrase does not appear or the suggestion is unclear, type the phrase manually on another labeled line rather than calling it automatic expansion.

## Compare the two lines without inferring implementation

For each round distinguish correct shortcut entry, appearance of the phrase, user acceptance and final document. System expansion with no Jianlai expansion, both, or neither are possible observations. A visible suggestion is not necessarily committed text. Do not infer system-dictionary access, synchronization, network behavior or universal language support from one trial. Correct manual completion proves only that text was entered, not that automatic replacement passed. The sample shortcut is just a practice label, not an account or verification code. On another device, first verify actual synchronization and input method; one device cannot establish another’s behavior.

## Troubleshoot rule, input method and host separately

If the system reference fails, check that the practice rule was saved and the shortcut entered exactly. For Jianlai, check the active keyboard, ordinary field focus and actual suggestions. Record host and state if another host differs; do not immediately remove Jianlai or reset the system dictionary. Change one condition per trial and keep the original lines. Secure fields and hosts declining third-party keyboards cannot establish general compatibility. Mark unknown causes pending. Record each trial’s time and OS version for later review.

## Remove only your practice rule and preserve existing entries

Return to the system list, identify the exact practice shortcut and phrase, and remove only that item using actual controls. Do not reset the keyboard dictionary, which affects other personal entries. Verify prior rules remain, restore your usual keyboard and retain the original note and backup. Keep a non-sensitive record for the system rule, system-keyboard trial, Jianlai trial, any manual completion and unfinished work. No Jianlai compatibility with system replacement or physical test is claimed.
