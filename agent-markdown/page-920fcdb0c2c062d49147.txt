In a form with multiple fields, correctly spelled words can still land in the wrong field. Use a local practice draft that will not be sent to check focus, candidates, committed text and field identity separately. No real event or invitation is required.

## Prepare two nonprivate test values

In an editor you control or a local form that clearly will not publish automatically, prepare two independently editable fields, Title and Place. Use the invented values “窗边读书会” and “青石活动室,” not a real address or contact. Record existing contents and keep a copy. If the host has only one text area, choose a local tool with distinct fields; two lines in one field do not establish two inputs. No account, invitation or extra permission is needed.

## Check keyboard and host boundaries

Confirm Jianlai was added using system settings and actually selected in an ordinary field. Enter a disposable nonprivate character and use the visible keyboard to identify the input method. Do not use password, secure or third-party-keyboard-restricted fields or weaken security settings. If the host synchronizes drafts, establish its scope; stop and use an offline practice environment if you cannot rule out external publication.

## Establish observable title focus

Tap the Title field and observe any caret, border or other focus indicator the host actually provides. Its appearance varies; do not make a particular color or caret shape universal. If both fields contain existing text, copy the original first and clear only the practice copy if needed. Confirm Title is selected before typing instead of inferring focus from the eventual result.

## Enter and confirm the title

Using the available Chinese scheme, enter “窗边读书会” and confirm the target through the actual candidate interface. If no distinguishable candidate appears or text is committed directly, record that behavior; do not assume a fixed encoding, Space or Return action. Inspect ordinary text in Title: the four characters “窗边读书” must be followed by “会.” Check Place did not change. Still-composing text can change when focus moves, so a preview alone is not committed content.

## Move to Place and verify committed text

Tap Place, observe its new focus and the existing title, then enter “青石活动室.” If the title changes during the switch, preserve the result and record actual system or host feedback without assuming a cause. Check the five Place characters and the title for extra spaces, duplicate candidates or content in the wrong field. If the tap did not take effect, mark focus pending and do not continue typing into a potentially selected Title field.

## Accept by field identity, not visual location

Return to Title and Place one at a time and inspect each field’s actual contents. Their vertical or horizontal positions may change with layout and do not establish identity. Use visible labels or, when labels are absent, the local tool’s accessible names or explicit documentation. Confirm Title is “窗边读书会” and Place is “青石活动室,” each appearing once. Keyboard suggestions and a form preview alone do not prove the correct field contains the committed text.

## Make a reversible focus control

Preserve the verified copy. In a separate practice copy intentionally select Title and enter one meaningless test symbol. Observe where it actually appears, then restore with the host’s undo or direct editing. If undo changes more than the symbol, stop and restart from the preserved copy; do not assume the host groups undo one character at a time. This control establishes only the observed focus and host behavior, not a real event or an error report.

## Troubleshoot and preserve boundaries

If a candidate list is visible but its associated field is unclear, record the screen, finish or cancel the input using an available control, inspect committed text and select the intended field again. If the field is covered, reposition the page or dismiss the keyboard instead of repeatedly tapping and guessing focus. Record the order of manual switches separately from host-initiated moves. If no independent copy or safe form is available, leave the exercise incomplete; do not substitute actual meeting data.

When text lands in the wrong field, examine the last focus change and visible caret, whether composition was committed and whether the host advanced automatically. Change one condition per retry and preserve nonprivate before/after evidence. Mark uncertainty instead of assigning blame to Jianlai. If correct input later changes after reopening, examine host save and synchronization separately. Do not publish, share or invite. Restore the usual keyboard and retain sanitized observations. The exercise is based on public multilingual input and Apple keyboard documentation; no physical form test is claimed.
