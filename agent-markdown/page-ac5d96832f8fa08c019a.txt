## 准备一段能跨六秒辨认的原始声音

用自己的十二秒录音作为完整参照，选择六秒前后都有可辨声音而不是长静音的材料，例如自己持续轻哼并带稳定节拍。音量保持适中，原稿与制作工程保留；不要用未知商业片段或人为把设备音量拉高来找细小差异。先在外部核原始声音跨六秒是否本来连续，若这里已有停顿，另换适合材料或如实注明。十二秒与六秒只是准备目标，实际录音没有生成前不填已听过。原段里的自然呼吸、节拍间隔与软件插入的空隙是不同对象，应先能用原件回查。

## 在外部按同一边界导出两段WAV

从保留的无损工程导出前零至六秒和后六至十二秒两段WAV，选择同一采样率、声道与样本格式，不额外加首尾静音、淡变或自动归一化。确认导出的是各自选区而非完整时间轴，尤其后段应从新文件零点开始。若采用四万八千赫兹且边界精确，每段模型为288000个采样帧，两段共576000帧；声道数不改变帧数，但会影响每帧包含的样本数量。这些是给定条件的预期，实际报告不符要回原工程核，不把纸面数字当已导出证据。

```
DECLARED split model: 48000 sample frames/s, exact boundaries
full: [0,12) s -> 576000 frames
A: [0,6) s -> 288000 frames
B: [6,12) s -> 288000 frames, exported at its own zero
288000 + 288000 = 576000; no intended overlap, omission or added silence
Actual export/decoder/player results need separate evidence.
```

## 先核两份拼回是否仍等于完整参照

在外部工具的工作副本里将后段紧接前段放置，核交界没有重叠或漏掉一段，再与完整参照检查时长和六秒附近声音。不要只把两个文件显示时长相加就断言拼接正确，整数读数可能掩盖边界错误。若具有可靠样本比较工具，可另存实际比较报告；没有就只写自己完成的范围，不伪造逐样本一致。保留分段WAV各自头部与音频资料，完整参照仍是另一份文件。这样播放器中出现差异时，至少先有源材料边界是否正确的独立依据，而非所有原因都归给队列切换。

## 另导MP3对而不忽略编码延迟资料

如要扩展比较，再从同一工程分别导出两段MP3，保存真实编码器、设置和可取得的延迟补齐信息，不从WAV改后缀制造它们。Audacity官方说明MP3编码可能引入起始延迟，并通过LAME信息标签记录供支持的应用处理；这不是调调必然识别该标签的保证。先在外部核两份实际解码资料，不能因为显示仍各六秒就宣布没有补齐，也不把所有文件末尾静音都归同一原因。没有外部导出条件时只做WAV一组，MP3清楚留待准备，不借他人未知录音替代受控副本。

## 在调调自然走过WAV接缝而不手动跳转

先单播完整参照，辨认六秒前后的同一声音，再用实际队列入口按前后段顺序安排WAV对，核正常顺序与当前身份。自然播放跨过两份交界，在观察期间不按下一曲、不暂停、不改变速度，否则操作本身会混入听感。记录两段标题何时变与声音是否有可辨空隙或突变，无法分辨就如实记。播放器显示切曲只证明状态变化，不能单独证明声音有空白；听见咔声也不自动等于缺了一段时间，原边界波形可能另有突变。没有精密量测时不报毫秒级间隙数字。

## 对MP3另立同条件一轮并限制结论

只有两份真实MP3已核身份并可读时，另建同样的前后安排，保持输出、音量、正常速度和观察区间。保存WAV轮后再试，不把两种编码混到一次队列里称同条件。若MP3可辨停顿而WAV没有，只能说明这份材料与路径的差别，仍要回编码延迟、源尾部、播放器切换等证据，不由听感单独锁定内部原因。若两轮都未听出，也不代表逐样本连续或所有专辑无缝。重复时用相同原段与边界，不能为了期望好听而另外裁掉一截后仍沿用原报告。

## 按源边界、队列与编码报告逐项排错

顺序错先核是否有第三项插在两段中间或随机状态；接缝长停先核源后段有没有外部时间轴留白，再查MP3处理记录；点击跳过产生的空隙单列而不混进自然切换轮。每次只改一个工作副本条件，原参照和WAV对保留。若甲末尾本来安静，先用外部波形与原声音说明范围，不把所有安静都当故障。没有实际无缝设置就不指示寻找隐藏开关，也不反复删库重新导入猜修复。实际来源不齐时交明确缺项，模型能算不表示已做全部听音。

## 交付一参照两组接缝与未测范围

保存完整参照、分段边界与帧数条件、两组实际文件资料、队列顺序和自然切换观察，MP3未做的项目明确待核。能够解释源静音、编码延迟与切曲状态为什么要分开，也能指出没有测出的具体原因。结束时恢复日常队列与模式，原件和外部工程不覆盖；不需要把听不到停顿记成音质评分。今后换编码器、采样率、服务器或输出设备，应重建对应条件，不能沿用这一份十二秒材料当全格式无缝证明。本课没有制作音频文件、真机听音或设备波形测量的替代声明，只有可重做步骤与明确的模型预期。
