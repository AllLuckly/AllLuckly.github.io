Compare the system accessibility caption style with the actual iCouldPlay subtitle setting on one selectable subtitle, then restore device preferences.

## Identify the media and subtitles

Choose authorized video already playable in iCouldPlay and selectable text subtitles that are already synchronized. Pick a clear line against a relatively stable background and record title, source, cue time, subtitle name and format. If text already appears on the picture, use the related guide to distinguish burned-in text from selectable subtitles. Apple system caption styles apply to supported apps and content; this does not establish that iCouldPlay uses the system style. Record your own observed result.

## Record original system and player settings

On iPhone or iPad open Settings, Accessibility, Subtitles & Captioning and record the current style and any visible Closed Captions + SDH preference. Labels may differ by device. In iCouldPlay record subtitle source, any confirmed playback engine and visible subtitle-style values. Mark inaccessible details unknown and avoid recording private libraries or accounts. Change one thing at a time and preserve enough information to restore the initial state.

## Establish a baseline on one line

Play the original video with the original subtitle and pause at or repeatedly pass the same line. Record text size, color, background, edge, location and content. Keep orientation, engine, source and subtitle track fixed during comparisons. If burned-in and selectable text appear together, describe each layer separately. Confirm the words are correct before comparing style; if no subtitles appear, resolve loading first.

## Change only the system caption style

Following Apple’s instructions, open the system subtitle and caption style and choose an existing option visually distinct from the original. There is no need to create or delete a style. Leave the SDH preference, iCouldPlay settings and video unchanged, then return to the same clip. Apple describes supported apps, not a guarantee for every subtitle or playback engine. If the option is unavailable, mark this trial unperformed and retain the baseline.

## Record whether it follows the style

At the same cue inspect selectable text size, color and background. Record changed, no visible change or indeterminate rather than assuming the answer. No change could mean a subtitle has its own styling, the current player path does not use the system style, or the difference is too subtle; these are possibilities to investigate. Do not conclude the app is faulty, inaccessible or identical for all media. Text burned into the picture generally cannot be reflowed through caption-style selection.

## Restore the system, then observe the player setting

Restore the recorded system caption style and confirm it is selected while leaving other switches as found. Only then change one actual available player subtitle setting, such as a small size adjustment, and return to the same cue. Record the setting, visible result and whether restoration is possible. If the installed version or subtitle offers no visible style control, mark the step unperformed; do not switch engines, download fonts or modify the subtitle file merely to complete it.

## Troubleshoot an invisible style change

Check that cue time and subtitle track match and playback controls are not covering the subtitle. If a player preview changes but video does not, record subtitle format, whether the words are burned in, and the actual engine if known; consult the layout guide without changing several settings at once. Styled ASS and plain text can behave differently, so one observation does not represent every format. If the system style is hard to distinguish, a supported video app covered by Apple’s guidance can show whether the system control is available; its result is not a test of iCouldPlay.

## Restore and keep a reproducible record

Restore the original player setting. If no exact original value was readable, return to a comfortable everyday setting and note the limitation. Confirm system style and SDH preference, player subtitle source and picture; keep baseline, system-style observation, player-style observation and unperformed steps. System style is a device-wide preference, so restore it for other viewers. No private video needs editing or uploading, and this guide claims no physical-device test or accessibility certification.

To avoid confusing a change in subtitle content with a style change, record the first few words, cue time and picture, then return to the same line for each comparison. Use media you are already authorized to view; do not share accounts or download unknown subtitles for the exercise. On a shared device, note and restore system preferences. If system settings cannot be changed, leave them alone, mark the system-style trial unperformed and record only the current viewing result.
