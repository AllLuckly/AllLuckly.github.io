Use Jianlai to make a local text card with fixed year, month, day, hour, minute, hyphens and a space, then check its characters, fields and purpose separately. The deliverable is an ordinary note, not a configured calendar event, alarm or timezone-qualified network timestamp. Each step separates typing from host date recognition.

## 1. Define what this card records

Create a practice copy in a private ordinary text note and define the task as entering one local date and time while keeping two-digit hour and minute fields. The example means 17 November 2026 at five past nine. First make five paper boxes for year, month, day, hour and minute; use no real appointment or account details. This is a wall-clock reading in an intended local context. No timezone is supplied, so it cannot identify the same instant in another region. Keep separate columns for entered text and observed host behavior. Even a clickable date recognized by the system does not mean a reminder has been created. Leave the original note untouched so the experiment cannot alter a working schedule.

## 2. Split the target into fields and separators

Treat the literal sample below as the sole target. Read it as a four-digit year followed by two-digit month, day, hour and minute fields, rather than one large number. There is one ASCII hyphen between year and month and another between month and day, exactly one ASCII space between date and time, and one ASCII colon between hour and minute. Add no final period or explanation. The string has sixteen characters: twelve digits and four separators. Point through the expected positions by group; a zero occupies a position too. This makes the original text, rather than visually aligned columns in a theme, the checkable reference. A similar-looking long dash, fullwidth space or Chinese colon does not meet this character contract.

```
2026-11-17 09:05
```

## 3. Enter and commit each group with Jianlai

Open the practice host’s ordinary editable body and confirm that the enabled Jianlai keyboard is showing. Use the controls actually present in the installed version to reach digits and the required symbols. Enter the year and first hyphen, pause to check, then add month, day, space and time. Do not prioritize a single uninterrupted entry over checking whether composition is still pending. The hour is zero-nine and the minute zero-five; saying “nine oh five” informally does not justify dropping either leading zero. If the system or host substitutes punctuation, commit the composition first and inspect the resulting body text. Record the keyboard state actually used; do not assume every layout has identical symbol-page numbers or hidden shortcuts.

## 4. Check positions rather than glancing

Check the first four year digits from the start of the line, then the hyphen, eleven, hyphen and seventeen. Verify that character eleven is a space, not another hyphen. The final five characters must be zero-nine, colon, zero-five. You may tick checked boxes on an external paper card, but do not put those ticks into the target line. If the host wraps the display, change the visible editing width to inspect the wrap before concluding that a newline was inserted. Check the order again without rearranging the digits: zero-nine and nine-zero contain the same digits but are different hour fields. Retain copyable original text. A screenshot helps document the display state but cannot by itself prove every character’s identity.

## 5. Repair one deliberately omitted zero

Create a separate faulty line below the practice copy, writing the minute as a lone five while leaving everything else unchanged. Diagnose a minute-field width that is one character short, not a need to add five minutes to the time. Use the host’s insertion point or selection tools to locate the position after the colon, then insert zero through Jianlai. Compare the correct line and repaired line group by group; both should meet the same sixteen-character target. If the selection includes the colon or last digit unintentionally, cancel it and locate the position again before overwriting more text. This exercise tests your ability to restore the format. It does not promise automatic padding, date understanding or invalid-month correction by Jianlai. Record host automation separately.

## 6. Separate field shape from calendar meaning

Correct padding alone does not make every value meaningful. A month of thirteen can still occupy two digits, and an hour of ninety can have the right width while violating ordinary date-time ranges. In the five paper boxes, check month one through twelve, the actual number of days in that month, hour zero through twenty-three and minute zero through fifty-nine. November seventeen at nine oh five meets those ranges. Check the year against the target rather than substituting today’s system date. Formal use would also require the recorder to establish the local timezone and event meaning. This lesson supplies no timezone-conversion example and does not call a local note lacking seconds or an offset a complete network timestamp. Give format and meaning separate pass columns.

## 7. Diagnose display, substitution and recognition separately

If a zero resembles a letter, copy the source characters into another ordinary text area before guessing from a different skin. If the colon looks wider or a space seems wrong, inspect the resulting text and investigate possible host substitution settings. If the line becomes a link, preserve the source and check whether plain-text comparison remains possible; there is no need to tap it, and recognition is not a completed scheduling action. If the text disappears after returning to the note, first check another draft, uncommitted composition or an unsaved host document. Those possibilities do not share a causal explanation with keycap font shape. Restore one variable at a time in the practice copy and record which action changed which column. Do not change language, layout and theme together.

## 8. Save the card and its limits

The final deliverable contains the target line, an identically repaired line and a brief checklist covering field widths, separator characters, calendar ranges and the unspecified timezone. Record the host name and Jianlai input state in a separate annotation area, outside the sixteen-character target. Close and reopen the practice note, then copy and compare the source again. Mark saving as passed only if the host actually retained it; otherwise leave the observation blank. A future appointment or reminder requires a separate action and verification in the actual calendar or reminder app. This card establishes neither. The outcome is an accurately entered and explained time string, plus a recoverable diagnostic path for missing zeros or substituted characters.
