绘制四乘四自设棋盘与两步移动说明，检查坐标方向、棋子数量和起终点，不声称实现棋类规则引擎。

局面图不仅需要格子，也要让每颗棋子身份和位置说得清。本篇自设四乘四棋盘、四颗棋子和两步简单移动，练习前后状态维护。它不是现有棋类教学，不声称移动符合某种正式规则，也不会在图片里自动判胜负或执行走子。

## 先约定坐标与本次自设规则

新建一千二百乘八百像素画布，列坐标从左到右 A 至 D，行号从上到下为一至四，明确这只是本图约定。四颗棋子命名甲乙丙丁，规则仅为每步向水平或竖直相邻空格移动，不越界、不重叠。先在清单写甲在 A 一、乙在 C 二、丙在 B 四、丁在 D 三，逐项核对。不要借用真实棋子名称让人误以为有未说明规则。画布留初始与后续状态空间，先把坐标方向写清，再制作底格与标记，避免后来图看似一致但行号反向。

## 建立十六格与外侧坐标

画一只正方格后复制成四列四行，格边清楚，交线不因重复边框忽粗忽细。外侧列字母与行号分别对齐格中心，角落不要出现容易当第五行的额外标签。棋子区域留足内边距，格子背景可浅深交替，但颜色不承担未经说明的可走不可走状态。先隐藏棋子数十六格，再按坐标逐个指认四个角。底格和坐标合适分组，棋子另层，后续复制局面只动棋子，不误把棋盘拉长或行号带偏。

## 四颗棋子分别保留身份标识

用相同大小圆形或少量几何图形表示棋子，每颗加甲乙丙丁短标识，不只依靠颜色区分。把圆心放在清单指定格中心，先逐颗读坐标，再数总数四。颜色可以辅助阵营，但本例没有胜负或阵营规则，不给读者额外猜测。文字与棋子形状一起分组，移动时不让名字留在旧格。先保存初始局面原稿，后续状态从它独立复制，不在唯一原稿上连续覆盖，方便比较哪颗实际发生变化、哪颗应该保持不动。

## 第一步只移动甲到相邻空格

第一步写甲从 A 一到 B 一，先确认 B 一为空且与起点水平相邻，再在第一状态副本移动完整甲组。旧位置应为空，其他三颗不变，总数仍四。若用箭头说明，起点与终点对应格中心，箭头放说明层，不当成第五颗棋子。不要只把名字甲挪走而圆形还留原位。动作说明先保留坐标，再看图形是否一致；静态路径不自动验证空格和边界，所有条件由清单与画面交叉核对。完成这一张后再进入第二步。

## 第二步基于第一状态继续

第二步写乙从 C 二到 C 三，先从第一步结果复制，而非误回初始状态。目标 C 三在本例为空，与 C 二竖直相邻；丁在 D 三，不应被误当成同格。移动乙后再检查甲仍在 B 一，丙丁保持原位。给状态标题写初始、第一步后、第二步后，阅读顺序明确。若图幅不够可以分文件，不把三张非等比压缩。每份状态都带同一坐标约定，读者不用在脑中猜哪张被旋转或镜像，位置差异才有可解释来源。

## 用位置表核对每张局面

为三张状态各写四行坐标，先看变化行，再看不变行，最后数棋子。只检查移动那颗容易漏掉误选带走的邻棋。可以暂时隐藏颜色只读甲乙丙丁，确认身份仍可分。再把箭头隐藏，看每张单独是否也能说明当前摆放；箭头帮助解释变化，不替代状态本身。若复制时多出重叠棋子，逐个选择才能发现，数量清单不只数文字。测试完成清理多余副本，保留原三状态与对应说明，不宣称图形已经成为可操作游戏或规则检查器。

## 导出时保持同一格距与方向

保存棋盘来源、棋子和三状态原稿，导出后按同样显示格距并排比较。小尺寸要能读坐标与棋子标识，无法辨认就减少装饰或放大，不把重要标签删光。透明输出确认浅格填充与背景关系，白色对象不是自动空洞。文件名含状态序号和版本，分享前分别打开，核对没有把第二步文字配初始图。以后换规则或增加棋子，先重新写清单与合法条件，再改画面，旧两步检查不能证明新玩法正确。

## 坐标或数量不符时定位具体对象

乙移动到 C 四，先检查是不是把行边界当成中心或读反行号，不整体翻转棋盘掩盖。总数变五，找重叠复制片；总数变三，查是否隐藏了整层或误删标记。箭头看似穿过占用格，回规则确认它只表示一步还是多步，不用模糊线解释。图中坐标清楚但文字记录错，应修记录并重新核对全部状态。最终每颗身份、每步起终点与每张数量都能说明，局面图才可用于理解变化，不只是有几颗彩色圆点的方格。
