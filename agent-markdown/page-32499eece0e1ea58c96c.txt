Check season-folder naming, episode identity and actual short-video playback in an isolated shows library.

## Separate folder name from episode number

Jellyfin recommends a series folder containing season folders named Season plus a number; S01E02 in a filename denotes season one, episode two. These serve different purposes. Do not treat the abbreviation S01 as the recommended season-folder name or infer file content from the folder name alone. iCouldPlay supports Jellyfin, but its season and episode presentation must be observed in the installed client.

## Prepare isolated episode samples

Ask an administrator to prepare an isolated shows library and copy two self-made or authorized short videos with visibly different openings. Keep originals outside the test library and avoid overwriting other files. Use a fictional title such as Practice Series and a sample year; record duration and opening image for each short. Without administrator access or suitable material, study the rule but do not fill in simulated results.

## Create the full hierarchy

Under the test root create Practice Series (2030) and within it Season 01. Name the copies Practice Series S01E01.mp4 and Practice Series S01E02.mp4. The extension must match the actual file; changing an extension does not convert video. Operate only on test copies, record paths and file sizes, and check that the first and second contents were not accidentally swapped.

## Scan and establish the web baseline

Have the administrator scan the test library normally in the installed Jellyfin version and wait for completion. In the web interface locate the series, first season and two episodes; record displayed names, episode numbers and associated files. Metadata can vary with providers or caches. If episodes merge or appear incorrectly, compare hierarchy, filenames and scan scope before repeatedly refreshing iCouldPlay. Compare the two relative paths to verify both files are in the same season folder, then check visible episode numbers without publishing the server’s absolute path.

## Play each episode in iCouldPlay

With the same server and an authorized account, open the test series in iCouldPlay and use the season and episode list actually shown to open episode one. Match the opening to your record, return, and open episode two. Note visible season name, both labels, duration and picture. If there is no separate season list or an episode is absent, record that rather than assuming a third-party client exposes the same control as the Jellyfin web interface.

## Check recommended naming without predicting results

Write down the Season 01 folder name and separately copy S01E01 and S01E02 from the filenames, checking the same season number and distinct episode numbers. The documentation discourages abbreviated season folder names such as S01; that does not prove every installation must fail to recognize one. To compare an old naming pattern, change only the isolated copy’s folder name with administrator permission, scan, and record the actual result.

## Restore the name and check files

If an abbreviation comparison was performed, have the administrator restore Season 01, scan again and wait. Verify that both files remain in the same folder with unchanged size and opening content. Do not delete the real library database to remove a possible stale item. If the web view recovers but iCouldPlay still appears old, leave and reopen the list using controls available in the current version and record time and observation.

## Distinguish episode number from video identity

Episode numbers identify filenames and server entries but do not automatically verify that pictures belong to the episode. If the episode-one label opens the second short, compare file openings with the pre-rename record; if copies were misplaced, the administrator should correct them in the test area. Do not declare playback correct from title or duration alone, since different contents can have equal lengths.

## Avoid mixing root-level episodes

Jellyfin advises against mixing episodes directly in the series folder with episodes inside season folders. This exercise keeps both videos in Season 01 and does not add a third same-named copy at the upper level, avoiding a duplicate that might be mistaken for an extra episode in iCouldPlay. Also look for same-named copies created by synchronization tools; record and verify them before deletion, and do not assume Jellyfin created them. For a different historic structure, back up and inventory original paths; let the administrator decide how to organize it rather than bulk-moving real media.

## Investigate differences in display

If the web view lacks episodes, check scan completion, shows-library type and filenames. If the web view is correct but iCouldPlay differs, record account, source, actual list and playback and confirm the same server and test library were opened. If only one episode is missing, compare the two paths, extensions and read permissions before asking an administrator to scan again, recording each changed condition. Do not declare network, permissions or cache to be the confirmed cause without evidence. If needed, prepare a minimal reproduction without server addresses for an authorized administrator.

## Complete the record

After the exercise, the administrator may retain or remove test copies as agreed and confirm that real episodes and original shorts were not moved. Record the original hierarchy, scan outcome, both episode pictures, any controlled name comparison and restoration result; leave unperformed steps blank or mark them unperformed. Remove private paths and account details before sharing. This guide relies on public sources and claims no private-server connection or device test.
