When small corner text zooms around the middle instead, inspect focus rather than increasing magnification. Compare the available pressed-point and screen-centre choices, then verify the return to normal reading. This changes navigation, not source resolution.

## Choose recognisable centre and corner details

Use an authorised image with clear central and corner details. Record upper, lower and middle anchors and keep orientation stable. If enlargement only reveals blur, investigate source quality separately. Repeat presses at the same point so changing finger position does not masquerade as inconsistent settings.

## Verify the long-press action

Inspect and enable the available long-press zoom control, then observe what actually happens before comparing focus. Menu or collection gestures may overlap. Do not assume a universal priority for simultaneously enabled actions. If absent, use another supported zoom method rather than changing system accessibility settings to imitate it.

## Test focus at the pressed point

Select pressed-point focus where available and test upper, lower and centre anchors, restoring the full image between trials. Note finger occlusion and release behaviour. Edge handling can vary with image geometry; judge access to the intended detail rather than requiring identical screen coordinates.

## Compare screen-centre focus

Change only the focus choice and repeat the same points. Screen-centre focus may suit some postures but require repositioning a corner target. Confirm source completeness before calling that missing content. Choose based on actual use, such as central detail on a stand versus corner notes handheld, rather than treating either as universally superior.

## Practise release, restore and next page

After reading the detail, release or restore using the actual control and turn a page. Observe lingering zoom, panning or unintended collection. Practise the sequence slowly before normal reading. Use the touchscreen controls exposed on the current iPhone or iPad rather than assuming mouse or volume-key actions from another platform.

## Reduce overlap with double taps and collection

Assign distinct purposes to double tap, long press and collection where possible. Temporarily disable quick collection and use a toolbar action if it helps isolate the gesture. Verify and remove only an accidental test item. Keep a known way back to settings, and compare focus separately from gesture assignment.

## Check tall images and paired pages

Repeat on a tall image or paired view, recording the specific image and section rather than only page number. Use supported scope differences or another zoom method for an unsuitable mode. Preserve source proportions. Reopen to check persistence, then read ordinary dialogue to verify everyday usability.

## Acceptance and a useful failure record

Finish with accessible centre and corner targets, a dependable restore and no unwanted action. Focus cannot restore absent detail. For a missing control, inspect enablement and mode before recording a version limitation. Report target point, mode, focus and sequence with a self-made sample where possible.
