A static EPUB page marker and a reader’s screen page can represent different location systems. Confirm the source, then compare the same passage.

## Separate static page markers and screen pagination

An EPUB page-list can point to static page boundaries in its content, which may correspond to print or belong to the digital publication itself. Screen pages shown by Book Isle for reflowable content can change with font size or window and must not automatically be treated as the same numbers. The standard defines a file structure; not every book provides a page-list and the current Book Isle version may not expose a control for it.

## Choose an authorized sample

Choose a legally obtained EPUB that opens in Book Isle, preferably one whose publisher states that it includes corresponding print page numbers or a static page list. Record title, author, edition, source statement and short markers near two adjacent boundaries; preserve the original. Without a reliable page-number source, test chapter location only and mark static-page comparison not performed instead of treating screen pagination as print.

## Record both location systems

In a table separate “publication static page marker” and “current Book Isle screen position,” alongside chapter name and a short self-made marker. If the book clearly marks the start of static page 12, locate it using nearby phrases; if the interface shows screen page 18, record that separately. Note font, size, device orientation and time for comparison. Do not share long copyrighted passages.

## Check source and edition

Read publisher information or the EPUB edition statement to determine which print edition a static marker corresponds to, or whether it belongs only to the digital publication. Different editions, abridgments or reflow can make matching numbers misleading. If the source is unclear, retain unknown and verify by chapter and context. A missing static page marker does not by itself prove the file is damaged.

## Establish a Book Isle baseline

Open the sample in Book Isle and use directory, search or bookmark controls actually offered by the installed interface to locate the target phrase. Record screen position and chapter. Look for visible static-page navigation; if absent or its meaning is uncertain, mark unavailable or not observed rather than assuming page-list support. Use actual bookmark or note options if text selection is possible; do not claim automatic print-page recognition.

## Change only the font size

Record the original size and orientation, then change only font size in the reading settings actually provided and return to the same passage. Record whether screen pagination changed, whether the static marker remains visible, and whether the target phrase matches. If the format or reader does not permit a font change, mark inapplicable and leave the original EPUB untouched. An unchanged screen count is a valid observation; do not vary many settings to force an expected outcome.

## Confirm position using context

Restore the original size and use the chapter title and nearby short markers to return to the same passage, checking that the target sentence is not another section with the same heading. If a static marker comes from print, verify its edition and boundary before citing it. Label a digital-only marker as such. Do not describe a reader screen page as a print page without verification.

## Check table of contents and page navigation

If the sample contains a chapter table of contents and static page list, inspect each through controls actually available in the current interface. Chapter navigation targets sections while a page list targets static boundaries; their links may differ. A missing control does not mean the whole book is unreadable. Locate manually via chapter and short phrase, noting that page-list navigation was not verified. Do not modify publication internals or overwrite the source.

## Investigate page-number differences

If the screen position changes with font size while the sentence stays the same, retain both positions and their conditions. If the sentence also changes, check edition, directory target and bookmark identity. If a static marker differs from print, check the stated source edition and boundary before claiming an app defect. Clearly mark any unverifiable number unknown.

## Build a reproducible citation record

Record three lines: ebook edition and source, chapter and short self-made marker for the target, and any static marker whose source can be confirmed. Add columns for screen pages and device orientation before and after the font change. If only one number is known, leave the other unknown. Do not infer a fixed print offset by subtracting reflowed screen-page numbers.

When coordinating with someone who has the printed book, ask them to check chapter and context in the same edition rather than relying on a page number alone; forewords, illustrations or revisions can change boundaries. Use a lawfully shareable short marker and note the print edition and page only after confirmation. If the matching edition is unavailable, retain the ebook location rather than inventing a page number.

During the font comparison confirm Book Isle still has the same file open. If two similarly named EPUBs are on the shelf, distinguish them through edition statement, contents and source records. Do not delete an original to remove ambiguity; record both identities first.

## Restore and hand off

Restore font size and orientation and confirm the original file and prior notes are unchanged. Record edition, short target marker, static-page source, both screen positions, visible app controls and unperformed steps. Based on W3C and public app information, this guide claims no device test and does not guarantee that Book Isle exposes a page-list interface.
