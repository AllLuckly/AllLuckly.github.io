English translation of the [Chinese original](<https://allluckly.cn/guides/jianlai-system-remove-readd-keyboard-one-entry/>), translated on 2026-11-23. Original publication dates, attribution, code and version notes are retained.

The iPhone system keyboard list controls which keyboard entries can be selected. Removing one entry is a different action from uninstalling its app. For someone who needs to re-add Jianlai, this exercise records the current state and verifies a backup keyboard before optionally removing and re-adding one entry. Apple documents adding and removing entries; whether Jianlai reappears and personal settings survive must be checked on the device and is not guaranteed.

## Decide whether the operation is needed

If Jianlai works normally and you have no reason to re-add it, you may read this guide without removing it. Also stop if you depend on an accessibility input method, cannot use a backup keyboard or do not know how to restore access. Avoid the procedure while completing an important form, managing an account or awaiting urgent messages. Save your work and leave sensitive fields first.

The exercise does not require deleting Jianlai, clearing data, resetting dictionaries or restoring the system. Removing an entry may change list order or permissions. Preservation of themes, dictionaries and other data cannot be assumed. If any loss would be unacceptable, first check the app’s actual backup options or skip the exercise. Prepare an ordinary note with no sensitive content for verification.

## Inventory the list and a backup

In Settings, use the current visible route through General, Keyboard and Keyboards to inspect added entries. Record each name and order and the exact name of the Jianlai entry. A private written note is enough; avoid unnecessary information in screenshots. Apple’s paths and controls can vary with system version. Language, emoji and third-party entries may be adjacent, so identify the target carefully.

In an ordinary note’s text field, select a system keyboard you know works, enter a short sentence and verify it is saved. Record how to switch back. If there is no working alternative or the target’s identity is uncertain, do not remove anything. Note the Jianlai version, system version, current theme and visible layout for later comparison; a record is not a backup of those settings.

## Save an input baseline

Back in the note, select Jianlai and enter a non-sensitive short sentence, for example “今天晴朗”. Confirm the candidate is committed to the body, save and reopen the note. Record keyboard identity, visible layout and actual input result. Ensure the exercise is not your only important copy; save a separate copy if needed so a keyboard-list action is not confused with document persistence.

If Jianlai cannot be found or used at this point, do not claim a successful baseline. Record the observation and inspect the system list’s add option and whether the app exists. Stop and consult app support if there is no clear way to add it. The removal steps below apply only when the target is identified and an alternative keyboard works.

## Optionally remove only the intended entry

Return to the system keyboard list and use the edit or remove control actually provided to select only the confirmed Jianlai entry. Check its name before removing it. If names are similar or an additional system confirmation is unclear, cancel instead of moving or deleting another entry. Apple documents different edit interfaces across versions; follow the actual device.

After removal inspect the list for the target and check that the other recorded entries remain. An entry disappearing does not mean the app was deleted; inspect whether the app is still on the device. If something unexpected changes, stop removing entries and check against the original record. If restoration is uncertain, preserve the facts and seek support rather than clearing the keyboard configuration.

## Re-add and inspect permissions

In the same keyboard list, look for Add New Keyboard or its current equivalent and see whether Jianlai is offered. If clearly present, select it and verify its name and count in the list. If missing, record system and app versions, actual list options and steps taken; do not install an unknown substitute or report success. If the app is absent, check its official App Store page and installation status.

Inspect the re-added entry’s current permissions against the earlier record. Full Access is the user’s choice based on the feature and privacy preference. This exercise does not require enabling it and does not claim re-adding restores permissions automatically. If the name, order or available permissions differ, record each difference rather than changing other keyboards from memory.

## Verify actual input in the note

Open the practice note, select the re-added Jianlai entry and check its identity against the earlier record. Enter another non-sensitive sentence, commit the candidate, save and reopen. Record visible layout and theme and compare with the baseline. Matching appearance does not prove the personal dictionary or every setting survived; mark unverified aspects unknown.

If Jianlai is listed but cannot be selected, check that the field is ordinary text, the keyboard is visible and the correct entry is selected. Some fields use the system keyboard; do not repeatedly test passwords. If the task remains incomplete, preserve the working backup keyboard and observations and seek official support. Do not start by uninstalling the app or clearing data.

## Finish the record and restore

Deliver a short table of original entries and backup keyboard, whether removal was voluntary, re-add result, actual permission state, note input and unfinished steps. Restore your preferred order using visible system controls if necessary; do not guess other entries when the initial order was not recorded. Confirm the backup input still works, your note remains and privacy settings match your choice.

This exercise is designed from public sources and does not claim a real-device test. System removal and addition do not guarantee that a third-party app keeps data, restores permissions or works in every field. If the outcome is uncertain, preserve the current state and stop.
