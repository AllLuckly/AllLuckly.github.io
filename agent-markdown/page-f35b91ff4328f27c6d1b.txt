手算四个等权点的拟合线，画竖直残差并用平方和验证，区别于垂直投影和穿点数。

本课为四个虚构数据点画一条带截距的等权最小二乘直线。先算斜率与截距，再逐点连出竖直残差，最后用一个看起来穿点更多的对照线检验目标。数据没有真实测量含义，线条也不提供因果或预测保证；VectorPaint用来展示已算出的关系，不承担自动回归计算。

## 先冻结四点与最小化的量

在图旁完整写出(0,1)、(1,2)、(2,2)、(3,4)，横纵轴都用无量纲练习单位，四点权重相同。模型规定为ŷ=a+bx，残差e=y−ŷ，目标是四个e的平方和最小；这里的残差沿纵轴量，不是点到斜线的最短距离。允许截距a变化，不额外要求直线穿过原点。创建数据、拟合线、残差、计算文字四层，先只放原始点并保存，后续不移动数据来让结果更整齐，也不把示例说成应用读取了实验文件后算出的报告。

## 用均值与中心化乘积算出斜率

先合计横坐标为6、纵坐标为9，除以四得到均值1.5与2.25。逐点求x减均值和y减均值，横向离差平方合计Sxx=5，交叉乘积合计Sxy=4.5，所以b=4.5/5=0.9。再用a=2.25−0.9×1.5得到0.9。把这几个中间量留在文字层，不只抄最后方程；若Sxx为零，这个斜率式不能使用，但本例四个x不同，分母确为正。不要把Sxy当成相关系数，也不因斜率为正就给数据添加真实增长背景。 可把Sxx的四项2.25、0.25、0.25、2.25单列一行，Sxy的四项则是1.875、0.125、−0.125、2.625。先相加再相除，保留负项，是比只看最后斜率更容易复查的计算记录。

## 画点与拟合线时注明两个轴的比例

建议画布1600×1500，数学原点位于屏幕(300,1200)，横轴每单位250像素，纵轴每单位200像素。因此X=300+250x、Y=1200−200y，四个数据点的屏幕位置见下方。两轴比例不同是允许的，但屏幕上的倾角不能直接当作数学斜率0.9。把拟合线端点放在数学(0,0.9)和(3,3.6)，用直线连接并标方程；仅作图区内展示，不把端点叫做拟合定义域。数值栏不可用时用网格手工定位，并承认图形近似。

```
model: yhat = 0.9 + 0.9*x
screen: X = 300+250*x; Y = 1200-200*y
x  y  yhat  e      observed screen  fitted screen
0  1  0.9   0.1    (300,1000)       (300,1020)
1  2  1.8   0.2    (550,800)        (550,840)
2  2  2.7  -0.7    (800,800)        (800,660)
3  4  3.6   0.4    (1050,400)       (1050,480)
```

## 逐点连出带符号的竖直残差

四个预测值依次为0.9、1.8、2.7、3.6，残差依次为0.1、0.2、−0.7、0.4。在同一个x处，从拟合点向数据点画短竖线，不用垂直于拟合斜线的方向。第三点位于拟合线下方，所以数学残差为负；屏幕向下的140像素却是正方向位移，两者不能混写。给每段旁边加e值，零线和数据点仍可见；线宽统一，不用更粗的第三段再额外暗示它有更大统计权重，大小已经由残差数值说明。

## 把平方和与正规条件逐个对上

依次平方得到0.01、0.04、0.49、0.16，合计0.70。另核残差和0.1+0.2−0.7+0.4=0，以及x乘残差之和0+0.2−1.4+1.2=0；这两项可抓出抄错单个预测值的情况。不能只把有正有负的残差相加后说误差全无，平方和仍然为正。文字层分别写“残差和”与“残差平方和”，保留小数点和正负号。若为视觉比较加小方块，必须说明面积比例，否则宁可保留简洁的数字账本，不用装饰面积代替算式。

## 用穿过三点的对照线检验目标

另画虚线y=x+1，它恰好经过第一、第二和第四点，却在第三点留下残差−1，平方和为1，大于0.70。因此“穿过更多点”不是本题的优化目标。要进一步核全局最小，可令u=a−0.9、v=b−0.9，把任意直线的平方和整理成下方非负项之和。只有u=v=0时附加项都为零，所以这里不是只试两条线后凭外观宣布最优。推导使用四点等权且包含截距的前提，换权重、强制过原点或改最短距离目标，都必须重新计算。 另用水平线y=2.25作可选基准，其平方和为4.75；它穿过纵坐标均值，但没有利用横坐标变化。拟合线则经过均值点(1.5,2.25)。这两个核对量来自当前四点，不能在更换数据后继续当固定常数使用。

```
u = a-0.9; v = b-0.9
SSE(a,b) = 0.70 + 4*(u+1.5*v)^2 + 5*v^2 >= 0.70
SSE(1,1) = 1.00
minimum attained only at (a,b)=(0.9,0.9)
```

## 按算表、坐标和残差方向排障

若第三段看起来向上，先看箭头是从拟合点到数据点还是反向，再核屏幕Y；不要把−0.7改成正数消除视觉疑惑。若线过原点，检查是否漏了截距；若斜率看起来太陡，先比较两轴单位，不仅凭倾角修改b。若平方和不是0.70，逐项核四个平方，尤其负数平方仍为正。保留故障版，修一处后再核两个残差和条件。原始四点始终锁定为输入，禁止删掉第三点后继续沿用原本的最小二乘结论。
