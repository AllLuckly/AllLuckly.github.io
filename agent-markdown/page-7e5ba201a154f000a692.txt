Distinguish disk folders, server series and client display with three test comics.

English translation of the [Chinese original](<https://allluckly.cn/guides/manyue-komga-nested-folders-direct-parent-series/>), translated on 2026-11-23. Original publication dates, attribution, code and version notes are retained.

A folder hierarchy need not appear as the same tree in a reading app. Check each comic’s immediate parent, then compare server and client.

## Understand server grouping

Komga documents that library subfolders at any nesting depth can become series, and each file belongs to the series corresponding to its immediate parent folder. The server library representation is not an exact disk tree. Manyue+ presentation is a separate client observation. Compare parent relationships only in an isolated test library; leave production comics in place.

## Prepare three test comics

Ask the administrator to create a separate library they manage or are authorized to use and prepare three authorized CBZ copies A, B and C, each with a distinct self-made first-page marker. Keep originals and a database backup and verify that the test account can read the library. Without permission, reliable backup or administrator help, add, move and rename nothing; mark the exercise not performed.

## Draw the test structure

On paper draw a test library containing Series Alpha. Place A and B directly inside Series Alpha, with an Extras subfolder inside it and C directly inside Extras. Do not assume C is a special chapter of A based solely on folder name. Record relative paths, sizes, page counts and first-page markers without sharing private root paths or account details.

## Write the candidate grouping

Under the documented parent-folder rule, A and B have Series Alpha as their immediate parent, while C has Extras. The candidate result is one series containing A and B and another containing C. Actual titles can also be affected by metadata; this rule does not guarantee display order, covers or Manyue+ layout. Write the prediction before scanning rather than rationalizing an outcome afterward.

## Scan and inspect the web

The administrator scans the test library using the normal current-version procedure and waits for completion. On the web identify A, B and C by their first-page markers, then inspect each series assignment. If metadata changes names, prioritize item identity and actual grouping over the label alone. If a book is absent, inspect placement, format, account and analysis status before treating it as moved or deleted.

## Compare in Manyue+

Connect Manyue+ to the same server, account and test library. Inspect the actual series listing, find A, B and C, and open their first pages. Record displayed series names, counts and locations. If the client does not display some server hierarchy or fields, describe the interface actually observed; do not assume it reproduces the disk tree. If web and app differ, check source and observation time before deleting any shelf.

## Compare paths and reading position

For each book write the immediate disk parent and web series in two columns, with the actual Manyue+ location in a third. Extras is C’s parent, but the server need not display the same tree path. Open C to page two and return to the list to verify readability. Page location, series assignment and reading progress are distinct observations; one does not establish the others.

## Handle metadata title overrides

If the folder is Series Alpha but the web series title differs, ask the administrator to inspect library options and ComicInfo.xml Series and Volume values in the books. Metadata can affect the title. A title change does not automatically change the physical parent folder or prove all three books are grouped together. If metadata is unavailable, retain cause unknown; do not bulk-edit test files or production libraries.

## Optional single-move comparison

Only after the administrator confirms backup and recovery conditions, C’s test copy can be moved from Extras into Series Alpha, followed by a scan and a recorded grouping observation. First record file hash and trash settings. Without a hash Komga may not restore the previous record; do not empty trash. This changes a test-file location and is unsuitable for production. If not approved, mark it not performed; the baseline observation remains valid.

## Check the scan scope book by book

Give A, B and C one row each with immediate disk parent, predicted series, actual web series, visible Manyue+ location and first-page marker. Verify the administrator-configured test-library root includes Series Alpha. If Extras is outside the permitted scan scope, the nested-folder rule cannot be tested from that result. Equal totals alone do not prove correct grouping: all three may appear under unexpected series.

If Extras appears on the web but C does not, first confirm that the test copy is there and its archive opens; then ask the administrator to inspect analysis status. Finding a file and successfully analyzing pages are separate stages. Do not arbitrarily change extensions to make a listing appear. If C opens on the web but not in Manyue+, record both versions, account, book marker and failure stage separately.

For the optional move, the administrator also checks that trash is not automatically emptied after scanning and that the test copy has a file hash and recoverable backup. Move only C without simultaneously changing its name, archive contents or permissions. Mark an ongoing scan as waiting. After restoring, compare the first page and server record of the same book; a matching title alone does not establish identity.

## Restore and hand off

The administrator restores C’s original position or handles isolated copies according to the record, then confirms production libraries and originals remain unchanged. Include relative paths, predicted immediate parents, web grouping, Manyue+ display, readable pages and unperformed steps. Remove private addresses, tokens and comic images before sharing. This public-documentation guide claims no private-server connection or physical-device test.
