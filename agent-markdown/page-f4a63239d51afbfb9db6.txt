用原创四档电平核静态压缩、补偿增益与固定音量对照，分开纸面曲线和真实瞬态。

动态压缩与把整段音量统一降低是两种处理。本课在外部准备合法短片的处理副本，再在云映同一输出下跟听；阈值、比例与补偿先算清，不把播放器音量滑块当动态处理器。

## 先保留原声与处理副本的身份

选择自己的对白或原创测试声，保留未经覆盖的原件，再在自己已有的音频编辑工具中准备处理副本。记录阈值、比例、拐点范围、补偿、起音与释放等实际参数，工具没有相应控制时只完成算例，不编造菜单。音频需要先在外部配入自有可播放视频，两份画面、切点和字幕条件一致，再通过当前可用文件来源打开云映。不能把文件名带压缩就当参数证据，也不要求云映内置Audacity或同名效果；外部处理、影片封装与实际播放分别核。

## 四个输入档按硬拐点模型计算

本课纸面阈值负十八分贝、比例四比一、补偿先设零；低于阈值保持输入，超过阈值只把超出量除四再加回阈值。输入负二十四、负十八、负十四、负六，对应负二十四、负十八、负十七、负十五。下面保留算式，负六不是直接除四得负一点五，比例也不是样本幅值缩为四分之一。此处各数在同一电平参考下，是理想稳态曲线，不宣称短促对白每个瞬间都严格等于静态输出；实际拐点、时间响应和检测方式另列。

```
ideal hard knee; common level reference; threshold T=-18 dB
output(x)=x                       when x<=T
output(x)=T+(x-T)/4               when x>T
input:             -24, -18, -14, -6
compressed:        -24, -18, -17, -15
compressed+3 dB:   -21, -15, -14, -12
fixed gain -9 dB:  -33, -27, -23, -15
above-threshold span: 8 -> 2 dB; whole-set span:18 -> 9 dB
```

## 比较阈值上方差值与整段跨度

负十四到负六相差八分贝，模型输出负十七到负十五相差二，正好四比一；但整组输入最高最低差十八，输出差九，不是十八除四。原因是低于阈值的那档没有按同一比例压缩。把这两个差值分别写在记录中，不能只看总跨度不等于四分之一就判比例失效。输入刚好负十八时与阈值连接，分段规则应连续；另取负二十的对照仍输出负二十。数值均为纸面预期，不把播放器音量百分比与分贝直接相减，也不据听感倒填精确电平。

## 补偿增益只整体平移曲线

模型处理后再加三分贝，四档输出成为负二十一、负十五、负十四、负十二，档间差保持不变。补偿可以抬回响度，却不会把被改变的档间关系自动还原；也不能保证不削波，具体峰值与时间响应要另核。保留零补偿与加三两列，不把阈值也跟着改到负十五，否则已经换条件。真实编辑器可能有自动补偿或软拐点，先记录其实际状态，不把默认值套进本课理想账。原片不覆盖，修改后用新的副本身份导出，避免音轨不同却继续沿用旧结果说明。

## 同峰值固定增益不是同一处理

另把原四档统一减九分贝，得到负三十三、负二十七、负二十三、负十五，最高档同为负十五，却与零补偿压缩的安静档不同。这个对照说明固定增益保留原档间差，动态曲线改变关系，不能只对上一个峰值就说两份相同。可在外部先生成带段号的稳态小样，再与对白片分开命名，实际稳态是否达到要按工具时间响应核，不拿最短一拍代替整档。比较时不追求某个预设更好听，也不把码率压缩与本课动态压缩混为一词。

## 在云映固定输出跟听段间关系

打开原片和处理片，核同一句与同一段号，保持日常合适音量、同一音轨与同一输出，不在每段都追着安静部分调音量。分别记录轻声、重音与段间关系，有无可闻起伏按实际写，不把听到变化直接当精确四比一测量。若一份音轨还加了背景音乐、降噪或混音，先记额外变量，不能说唯一变化来自压缩。没有真实处理素材就把此步留待核；纸面账通过不代表云映做了处理，也不代表已测所有扬声器、耳机或长时间播放状态。

## 按曲线参数与瞬态条件排查

输出不符先核阈值与补偿，再核硬软拐点、检测和起音释放；短音没有达到纸面值不必直接判工具坏。声道、重放增益或额外处理若不同，也先列出来，一次只回一个条件，不把全部声音开关重置。若实际有失真，保存发生时点与源副本，停止把补偿继续加大来求响；本课没有给任何真实环境的响度验收标准。截图上的电平、文件的样本值与人的主观响度分开记，不把一张波形图片的高度当所有播放路径已量准。

## 重开交付三列与条件限制

保存原声、压缩副本、固定增益对照及四档账，重开确认来源与段次。验收能复算超过阈值的八分贝为何变二，以及全组跨度十八为何变九，再说明补偿只平移输出。真实跟听写见到或听到的结果，未执行的峰值测量、瞬态分析和真机兼容不补造。以后改变阈值、比例或素材，都重新计算受影响部分，旧截图不替代新结果。成果是一份外部处理与云映观看互相对应的记录，不是播放器新增动态压缩器、自动修复对白或保证任意录音都好听的证明。
