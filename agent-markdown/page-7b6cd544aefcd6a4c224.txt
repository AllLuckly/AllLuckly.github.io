把零一三六映到零、二分之一、四分之三与七分之六，逐项核点序和分母。

制作上下两条有刻度的数轴，展示四点在分式映射前后的关系。两幅图采用各自声明的显示比例，比较的是坐标算出的交比，不是把屏幕像素直接相除。保留有向差、点的名字和映射的禁用输入，让“不变量”成为可核账本。

## 先选交比约定并固定点序

本课定义CR(A,B;C,D)=\[(c−a)(d−b)\]/\[(d−a)(c−b)\]，小写字母是同一数轴上的有向坐标。取A零、B一、C三、D六，四点互异，分母不为零。不同资料可能排列四点或采用倒数约定，先把公式写在图上再比较，不能只凭“交比”二字搬用结果。新建原轴、像轴、刻度点与账本图层，先存原生稿；点序以名字而非左到右的临时视觉顺序识别，每个输入都保留对应输出。

## 先算四分之五再辨换序倒数

依既定顺序，分子为(3−0)(6−1)=十五，分母为(6−0)(3−1)=十二，交比为四分之五，即1.25。注意中文“四分之五”不是五分之四；若交换A、B，结果变成五分之四，即0.8。保留这项换序对照，并在图上仍用原来的A、B标签，避免把一次换序后的倒数误报为映射破坏不变量。先记约分前十五比十二，能检查是减错点、颠倒分数，还是单纯小数抄写错误。

## 逐点代入分式而不按比例压缩

规定T(x)=x/(x+1)，输入x不能等于负一；分子分母系数的行列式一非零，所以不是把所有点压成常数的退化映射。四点的像依次为0、1/2、3/4、6/7，均可用代入式独立复核。相邻间距会改变，故不能把原轴整组水平缩放当成这个分式映射。把输入与输出写成四行对应表，先用分数，显示小数只作为落点近似，不把6/7截成0.86后当精确值参与恒等式检验。

## 在像轴保留完整分数重新算交比

像轴分子为(3/4)(6/7−1/2)=(3/4)(5/14)=15/56，分母为(6/7)(3/4−1/2)=(6/7)(1/4)=3/14。两者相除是四分之五，与原轴相同。另算普通比AC/BC：原来3/2，映后(3/4)/(1/4)=三；AD/BD则从6/5变成(6/7)/(5/14)=12/5。两个普通比各自改变，但它们按定义组成的比值仍不变。把这两组数放在相邻栏，不能把交比保持扩大成长度、距离比或角度全部保持。可进一步外部推导T(v)−T(u)=(v−u)/\[(v+1)(u+1)\]。四个像差代回定义，每个输入的“加一”因子在分子分母各出现一次并抵消，这才解释不变而非只报告一次数值巧合。推导要求所有输入不在极点且交比分母非零，缺失任一条件都不能照抄抵消步骤。

```
CR(a,b;c,d)=((c-a)*(d-b))/((d-a)*(c-b))
(a,b,c,d)=(0,1,3,6)
CR=15/12=5/4
T(x)=x/(x+1), x != -1
(T(a),T(b),T(c),T(d))=(0,1/2,3/4,6/7)
image numerator=15/56; image denominator=3/14
image CR=(15/56)/(3/14)=5/4
swap A and B: CR=4/5
```

## 给两轴分别声明显示尺度

建议2200×1500画布，原轴在Y=450，以X=300+240x放点，D落X=1740。像轴在Y=1050，以X=300+1500t放点，B′、C′、D′依次落X=1050、1425、约1585.714。两个面板显示倍率不同，因此不能横跨两轴直接比像素长度。轴旁写一单位对应多少像素，点上写精确分数，标签挤时移动文字而不移点。用直线与小刻度手工画数轴，若数值栏不可用就按网格近似，交比证据仍来自外部有理数运算。

## 用极点和重合输入检查适用范围

另设输入负一，分母零，不能在本课有限数轴上填写一个普通坐标。若希望谈射影直线上的无穷远点，需要扩充表示法，不能擅自把它放在画布最左端冒充有限数值。再设C=B，既定交比分母零，四点互异前提也破坏；此时不继续报四分之五。排障先查输入合法性和顺序，再查分母、约分及显示尺度。反例卡保留原条件与失败原因，不靠删除出错标签让图面“恢复正确”。

## 把顺序与近似误差分开排查

先遮住结果，按A、B、C、D读出四个有向差，再按图上约定恢复公式。若得0.8，检查是否换了A、B或用了另一交比定义；若接近1.25但末位不同，查是否提前使用截断小数；若差异很大，查是否误用上下两轴不同的像素比例。每次只改一个因素，保留原图和修正副本。连接对应点的细引线只是阅读帮助，不是表示二维透视相机、光线或实体长度；本课不从这幅一维示意推断相机标定结果。本例正好保持四点左到右次序，也仍应按名字抄公式；换其他合法区间时，不靠“左边那个总叫A”的临时重命名维持结果。

## 重开交付定义而非一组孤立小数

保存可编辑轴、点与文字，导出SVG或PDF并另开PNG。缩小核原像对应不串行，放大核分母、撇号与负一禁用条件；重开原生稿确认两轴可分别修改，标签仍跟正确点对应。交付原轴15/12、像轴(15/56)/(3/14)、换序4/5及极点反例，未实际执行的输出检查标待办。读者应能凭定义复算不变量，也能指出普通比为何改变；不能把数学验证归功于未公开的自动射影变换或交比求解入口。
