Practise content, fonts, size, alignment and empty space through title, explanation and date levels, so the card communicates more than decoration.

## Write the complete copy before choosing a font

Prepare a portrait card of 720×960 px with practice copy: “Weekend Drawing,” “Create a Geometric Illustration Together,” and “Saturday 14:00.” These are examples, not a real event. Copy the wording into a draft and check for typos and omissions before laying it out. Text length determines space requirements; making decorations first and squeezing in a long paragraph later often leads to tiny text or lost margins.

## Create hierarchy with separate text objects

Choose the text tool and create separate title, description, and date objects, keeping each short initially. Try 56 pt for the title, around 24 pt for the description, and around 20 pt for the date, then adjust to the layout. Different text serves different reading priorities; every line does not need another font. One clear font and two size levels can create more consistency than an arbitrary mixture of typefaces.

## Choose a shared alignment edge first

Align the title, description, and date near a shared left reference line with a margin of about 64 canvas units. Object alignment and paragraph alignment are separate: one positions the entire text object, while the other arranges text inside its area. If two lines look misaligned, check object bounds and spaces in the text before moving objects. Do not simulate margins with many spaces.

## Separate information with whitespace, not just bold text

Leave a clear gap between title and description and a larger separation between description and date. The title can be dark and the description slightly lighter, but both must remain readable on the actual background. Pale-gray text with very low opacity can seem to disappear over colored shapes. Establish reading order with light-dark contrast first, then add accent colors. Color cannot replace type size, position, and organization.

## Recheck line breaks after changing the type size

Increasing type size changes not only height but line length and wrapping. After each change to size or text-area width, check for awkwardly split titles, dates beyond the boundary, and punctuation isolated on a line. Do not keep shrinking text merely to preserve the old line count; try shorter copy or more space first. Fonts differ in character width, so check again after changing the font too.

## Distinguish editable text from outlined delivery

Keep editable text to change event names and dates. Once converted to outlines, glyphs become paths and content editing changes accordingly. If the recipient needs stable appearance, evaluate outlines in a copy, retaining the original text first. SVG export does not necessarily package the font file. Since fonts vary between devices, check substitutions, line breaks, and missing glyphs in the target environment.

## Use a content review to catch what a visual review misses

Read the title, description, and date aloud separately, checking repeated words, vague times, and incomplete punctuation. Common event-card problems are not unattractive fonts but “Saturday” without a date, an unexplained time, or an overlong sentence. Practice copy can be brief; in real use, include the information readers need to act before deciding how the layout will accommodate it.

When content becomes longer, edit the wording before compressing the layout. Splitting a sentence with several purposes into a main explanation and a supporting line is often easier to read than reducing twenty-four-point text to twelve. If you must reduce the size, check it at the actual display size rather than only on an enlarged canvas.

Also check whether alignment suits the text length. A short centered title is usually manageable, but centered long explanations create uneven edges that make readers repeatedly search for the next line's starting point. Left alignment may work better for several lines. The point is not to left-align everything, but to choose alignment for the reading task rather than prioritizing decoration over clear information.

## Final check: follow the reading order

Reduce the canvas to roughly its phone display size. Check whether the title is easy to find within a few seconds and the description and date are readable. Read every word instead of inspecting appearance alone. Hide decorative shapes and assess the text structure; if it stays clear, the hierarchy is usually stable. Save the original and preview, and verify the actual time and location before publishing a real event.

## Further exercise: create two hierarchies for the same wording

1. Use a large title and left alignment in one version and a centered layout in the other. Keep the wording identical and compare how easily you can find the date.
2. Double the length of the practice description and observe changes to wrapping and whitespace. Then decide whether to shorten the wording or adjust the text area.
3. Export a preview to a familiar viewing environment and read it at the actual display width. Record hard-to-read areas rather than checking only the enlarged canvas.

## Frequently asked questions

### Why does changing the font make the whole text wider?

Fonts differ in glyph widths and proportions. The same point size does not guarantee the same layout width. Recheck the text area, wrapping, and margins rather than stopping once the font name has changed.

### Can I edit text normally after converting it to outlines?

You cannot continue typing into outlines as ordinary text. Undo or return to the retained text original to restore that workflow. Create the outlined delivery copy only after the wording is settled.

### Can I freely use any downloaded font?

Check the font license and delivery requirements. This tutorial covers layout and editing only; it neither assumes arbitrary fonts are licensed for commercial use nor requires you to download a particular extra font.
