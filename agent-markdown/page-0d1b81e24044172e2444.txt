画零到二十九的对齐余数带，解出八模十五，并用非互质反例检查适用条件。

把两个余数条件放在共用整数刻度的两条带上，找同时满足的位置，再写出超出图框的全部整数解。练习同时检查互质前提与非互质对照，防止把图上两个交点误认为只有两个解。VectorPaint用于手工排齐刻度和符号，求解过程由外部算式完成，不假定存在自动同余求解器。

## 写清两个条件与图框范围

题设为整数x满足x≡2模3且x≡3模5。图中只展示0到29，含两端共30个整数，但数学问题的未知数允许是任意整数。页首写“且”，不是“或”；第一个条件表示x−2可被3整除，第二个表示x−3可被5整除。创建刻度、模3标记、模5标记、交点与推导文字五层，先保留未标记的原生稿。图框限制只是阅读窗口，不是把负整数或大于29的合法解排除，也不把余数值2与3当成两条带的像素高度。

## 共用三十列刻度防止假交点

建议画布2000×1300，用X=200+45n放置标为n的整数刻度，n从0到29，因此最后一列在1505。模3带放屏幕Y=450，模5带放Y=650，交集带放Y=850，各列横坐标必须相同。先画0、5、10、15、20、25等主标签，再补其余小字，避免三条带各自均匀分布造成列位漂移。使用网格或参考线逐列对齐；如果分布功能按选中图形边缘计算而非中心，先核实际中心距离，不能只因按过分布按钮就宣布刻度准确。

## 分别列满两条余数带

从2开始每次加3，模3带共有2、5、8、11、14、17、20、23、26、29十个标记。从3开始每次加5，模5带共有3、8、13、18、23、28六个标记。把两份列表完整抄在下方后再落图，不能因看到8就提前停列。第一带用空心圆，第二带用三角，附文字说明；标记居中放到对应整数列，避免填充色遮住数字。最后分别抽查29−2=27能被3整除、28−3=25能被5整除，确认右端也满足各自条件。

```
range: integers 0..29 inclusive
x = 2 (mod 3): 2,5,8,11,14,17,20,23,26,29
x = 3 (mod 5): 3,8,13,18,23,28
both: 8,23
```

## 用共同列找交集而非把两带相加

逐列比较两条带，只有8与23同时有两种标记；在交集带相同列加实心点，再以细竖线连接上方两个条件。不要把十个加六个误写为十六个共同解，也不要把同列两个符号算成两个不同整数。分别验8除3余2、除5余3，23除3余2、除5余3，并在文字层写23−8=15。图上出现相隔15的两点提示周期，但仅凭两点还不足以证明所有解；下一步用代数得到完整的同余类。

## 代入一个条件求完整整数解

由第一条件写x=2+3t，t为整数。代入第二条件得3t≡1模5，因为3乘2余1，乘逆元2可得t≡2模5。令t=2+5k，于是x=8+15k，k为任意整数；这也写成x≡8模15。把三个等价步骤逐行保留，读者可反向代回两条件。8与23属于同一个模15同余类，不是两类解；取k=−1得到−7也合法，因为−7−2=−9、−7−3=−10分别整除3与5，不能只因图框从零开始就删掉它。 反向代入可核任意k时，x−2=6+15k总是3的倍数，x−3=5+15k总是5的倍数。若两个解同时满足原题，它们的差就被3和5同时整除；由于互质，差必为15的倍数，因此没有遗漏另一种同余类。

```
x = 2+3*t
3*t = 1 (mod 5)
t = 2 (mod 5)
x = 8+15*k, k any integer
k=-1: x=-7; (-7-2)/3=-3; (-7-3)/5=-2
```

## 用互质前提控制结论的范围

本题3与5互质，中国剩余定理保证任意这两个模数的余数组合都有一个模15的唯一同余类；“唯一”说的是类，不是唯一整数。另放一个故障对照：x≡1模4与x≡2模6不可能同时成立，因为前者要求奇数，后者要求偶数，两个余数之差也不被最大公因数2整除。不要仅把模数相乘为24就写出一个解。主图与反例分框，题设模数改变时先核公因数和兼容条件，再决定是否可以套用互质版本的结论。 在本图也可分成0到14、15到29两个连续十五整数窗口，每窗恰有一个交点，分别为8与23。改变窗口起点仍不会改变完整解式，但可见数字和交点数量要按新窗口重新枚举，不能只复制旧标签。

## 再用可相容的非互质例子排障

非互质并不等于永远无解。改为x≡2模4与x≡2模6，两式要求x−2同时是4和6的倍数，所以解为x=2+12k；0到29内可见2、14、26。若写成2+24k，会漏掉14，这说明一般周期应看最小公倍数12。把这个对照只作为条件核查，不混进主图的8与23交集。作图错位先查共用列，解集错误先查同余和公因数，不移动点去迎合错误公式；每次保留故障副本并只修一项后重新列举。 两个非互质对照共同提醒：不能从公因数大于一直接推断无解，也不能无条件把周期写成模数乘积。先验余数差能否被公因数整除，再对具体可相容例子列解，图上的实心点才有明确数学依据。

## 重开检查窗口内计数与窗口外公式

重开原生文件，核三十个整数列、第一带十点、第二带六点、交集两点，8和23的竖线仍对齐。再核完整解式包含k为任意整数，负例−7和两个非互质对照未被导出裁掉。导出SVG或PDF后查看同余符号、模数、负号与空心标记，不以肉眼看到周期替代代数证明。交付两带图、完整列表、代入推导与前提对照；没有实际重开或导出的项目照实留待做。本课展示手工计算结果，不声称应用自动证明定理或执行密码计算。
