- **Choose a familiar layout:** official store screenshots show Chinese 26-key and nine-key layouts among the options. Compare typing and candidate selection with the same short passage rather than choosing from the preview alone.

1. Install and open Jianlai, choosing a built-in theme with clearly readable keys and text while you explore the settings offered by the installed version.
2. In the device’s Settings, open General → Keyboard → Keyboards and select Jianlai through Add New Keyboard. Exact system wording depends on the installed version.
3. In a normal text field such as Notes, use the keyboard-switch control to select Jianlai. Type a short passage and check candidate selection, spaces, punctuation, deletion and line breaks separately.
4. Once basic input works, change one appearance or layout setting at a time and return to the same field. This helps distinguish font readability, key arrangement and input-language adjustments.

## System boundaries and useful comparisons

Jianlai is a third-party keyboard. iOS uses the system keyboard in secure fields such as password inputs, and individual apps can decline third-party keyboards.
