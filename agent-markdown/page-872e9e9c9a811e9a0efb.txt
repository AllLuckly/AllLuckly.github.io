## Declare equally weighted complete strict rankings

Options are A,B,C. Each fictional voter has weight 1 and a complete strict ranking without ties or abstention. Groups are 2 voters A\>B\>C,3 voters B\>C\>A,4 voters C\>A\>B, totaling 9. Individual rankings are acyclic; the object tested later is the aggregated majority relation, not an individual preference.

## Compare A versus B using every group size

For A versus B, group 1 contributes 2 to A, group 2 contributes 3 to B, and group 3 contributes 4 to A. Thus A wins 6:3, so the strict-majority arrow is A→B. C’s position gives no extra ballot in this pair, and C-first voters still rank A relative to B. Every pair must total 9. Keep group contributions and verify the total before drawing. First-choice counts 2,3,4 describe another rule, not this pairwise comparison.

## Check B versus C and C versus A separately

For B versus C, groups 1+2 give B 2+3=5 and group 3 gives C 4: B wins 5:4. For C versus A, group 1 gives A 2 and groups 2+3 give C 3+4=7: C wins 7:2. ## Use the cycle to test for a Condorcet winner

A beats B, B beats C, C beats A: a directed three-cycle. Under this lesson’s strict definition, a Condorcet winner must beat every other option by a strict pairwise majority. A loses to C, B to A, C to B, so none qualifies. This does not mean no rule can select an outcome or that individual rankings contradict themselves. First-choice counts are A 2, B 3, C 4, so plurality would choose C, which still loses pairwise to B. Keep rule-specific outputs in separate columns. Do not multiply majority margins or treat arrows as transition probabilities: each edge summarizes a different pairwise question on the same rankings, with no random state-update rule.
