Separate Jianlai manual typing from Apple system Dictation in a practice note, then return to Jianlai to inspect and revise a copy.

## Prepare a non-private practice sentence

Create a practice line in your own ordinary iPhone note, keeping the original and a backup. Use “明天去公园。” Confirm Jianlai is added and can actually type in this host; record OS, host and installed version if visible. The exercise distinguishes Jianlai typing from Apple system Dictation. The public Jianlai listing does not promise built-in speech recognition. A missing microphone on one keyboard view does not prove system Dictation is unavailable. Avoid secure fields and content you do not want spoken.

## Establish a Jianlai typing baseline

Select Jianlai in the ordinary field and type the sentence manually. Preserve the first result; check characters, punctuation and cursor position, and record the active keyboard and theme. If typing fails, inspect focus, keyboard selection and candidate confirmation. Dictation is not a substitute for repairing keyboard setup. Keep this manual result on its own line rather than presenting a corrected copy as the first attempt. You may label lines “manual” and “dictation”, but exclude those labels when comparing the target. Keep both lines in the same host and document so location and retention can be checked.

## Determine whether system Dictation is available

Apple says Dictation is enabled in system keyboard settings and availability varies by language, region and device. Inspect and record the original setting; enable it only if you choose, following actual system prompts and reading the Dictation and Privacy information. If unavailable or unwanted, mark this part unperformed. Do not require full access for a third-party keyboard or assume the system control appears within Jianlai itself.

## Switch to an actual system Dictation entry

Return to the same ordinary field and use the device’s real keyboard-switching controls to choose an available system keyboard or another entry explicitly offered by the system for Dictation. Confirm the selected input and locate the actual Dictation control. If absent, follow Apple’s guidance to inspect settings and supported conditions; stop when unclear. Do not present the system keyboard, microphone button or speech recognition as a Jianlai feature, or assume the same button position on every OS version.

## Dictate once on a new line

Place the cursor on a new practice line, start the visible system Dictation control, speak the sentence and stop using an available system method. Record the system indication, recognized words and punctuation, then the final document text separately. Recognition can vary by language, environment and OS; correct recognition and automatic punctuation are not guaranteed. Do not dictate accounts, addresses or other content you do not wish to send through the Dictation process. Record any different punctuation without silently replacing it. For a retry, use a third line and label it as a second attempt; retain each result rather than selecting one as representative of all attempts.

## Return to Jianlai for a manual revision

Confirm system Dictation has ended, then return to Jianlai using actual keyboard-switching controls. Record the active keyboard and cursor. If the dictated result differs from the target, correct one real discrepancy in a copy and check whether the edited text now matches the original target. If the result already matches perfectly, you may add an ordinary word only in the copy and record where it was added; then compare the edited line with the target plus that intentional addition, without inventing a recognition error. In both cases confirm the original dictated line and text outside the edit remain unchanged. The revision uses Jianlai; the earlier recognition remains system Dictation.

## Troubleshoot Dictation and typing separately

For a missing system control, check system settings, language and device support. If recognition differs, keep the spoken phrase, recognized result and host text distinct, then revise manually if needed. If Jianlai is unavailable after switching back, check active keyboard, host focus and third-party keyboard boundaries independently. Change one condition at a time and retain original results. On-device processing for some languages does not imply all languages and fields are offline; Apple notes that search text may be sent to a search provider, so use an ordinary note.

## Restore settings and keep a three-column record

Keep rows for Jianlai manual typing, system Dictation and Jianlai revision, with actual entry, language, result and pending work. Restore the original Dictation setting if temporarily changed and confirm the usual keyboard selection. Keep the note and backup; there is no need to remove Jianlai or reset the system. Apple documents Dictation and its language and region limits; Jianlai’s listing describes multilingual typing. No built-in Jianlai Dictation or completed device speech test is claimed.
