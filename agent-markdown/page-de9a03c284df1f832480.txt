用四个有符号样本复算反相与平均和，分开声道互换、时间倒放与实际播放观察。

本课的核心是一个可复算的小模型：右声道逐样本取左声道的相反数。先在外部笔记算清楚，再用自己有权使用的小音频对照云映中实际可见的播放结果。公式不是所有设备的通用下混实现，声音突然变小也不能直接归因于应用故障。

## 一、建立原音与反相副本的身份

选自己录制的一小段人声或短音，保留原始文件；只在外部音频编辑器处理工作副本，分别命名原音、反相和双声道对照，不覆盖日常片源。开始先写下本课讨论的是波形样本符号，而非播放方向、字幕延迟或左右耳位置。没有编辑器也可以完成纸面样本核算，把实际试听记为待执行，不能用算式代替真机试听记录。素材长度、音量和播放出口另记，保证回看时知道每个文件到底是哪一个。

## 二、逐项写出四组有符号样本

用归一化示意数值 L=\[0.2,-0.4,0.6,-0.2\]，定义 R=-L，得到右侧为 \[-0.2,0.4,-0.6,0.2\]。负值不是负的音量，也不是文件损坏，而是这一模型中瞬时幅度相对零线的另一侧。每一行必须同一采样时点相配，不把右列错开一格再说完全反相。这里四项只用于算数，不构成可听的完整录音，真正音频还需要采样率、时长与编码等信息；教学数组不能冒充已经导入播放器的测试文件。

```
L:  0.2  -0.4   0.6  -0.2
R: -0.2   0.4  -0.6   0.2
M=(L+R)/2: 0  0  0  0
```

## 三、算平均和并注明模型边界

本课明确采用 M=(L+R)/2 的等权平均模型，四行各相加后除二都为零。另算同相对照 R=L，得到 M=L；因此抵消来自对应样本的相反关系，并非“双声道总比单声道安静”。[Audacity反相说明](<https://manual.audacityteam.org/man/invert.html>)解释反相对原声混合的抵消情形，支持这里的基本原理。实际系统可能采用其他系数、路由和处理，未经确认不把这条教学算式写成云映、蓝牙设备或所有电视的内部算法。

## 四、分别识别互换、倒放与反相

把左右列互换，平均和仍为零，因为本模型相加次序不影响结果；这不是说互换在所有听感场景都无区别。把样本时间次序反过来属于倒放，不能仅凭正负号翻转判为倒放。给三种操作各写一句发生了什么：位置交换、时间重排、符号翻转。检查笔记中“反相”是否被含糊写成“倒转声音”，若有就替换为具体操作，避免后来排障时调整错误的设置或错误修改原始音轨。

## 五、外部准备时只改变一个条件

若使用外部编辑器，先导出原音副本，再仅对一个复制声道反相并与未改声道成对，导出设置保持一致。不要同时改速度、压缩、均衡和响度，否则无法把结果对应回四行模型。导出后重新打开核文件名、两声道结构与长度，原音始终另留。没有完成外部准备就只提交理论记录；本课不假定云映具有波形编辑或反相开关，播放器里的字幕和来源设置也不能代替音频编辑步骤。

## 六、在云映按真实出口记录观察

通过现有入口打开已准备的短素材，先核原音身份和开头，再以相同系统音量试听对照；避免为了“找声音”持续增大音量，切回普通素材前先恢复原设置。实际是否下混以及采用什么算法，未知就写未知。只记耳机、扬声器或外接设备中本次可核实的出口和现象，不把立体声耳机分别听到两路声音直接描述为已经求和。没有执行试听的读者应保留这一栏为空，不能照抄预期当观察。

## 七、对未完全抵消的结果排查

若没有完全抵消，先回核两份是否真是同一源、是否对齐、是否等幅以及导出后是否仍为对应两路。只要一侧延时或幅度改变，就不再满足 R=-L 的逐样本假设，不能把模型零输出强加给实际结果。也不要仅凭音色发空就断定所有频段完全消失。保留修改前后文件和可重复时点，一次纠正一项；若无法取得声道或路由信息，将结论收窄为“在该出口观察到变化”，不推断不可见的应用实现。

## 八、退出重开并交付两类证据

退出后重开原音，核音量和出口已恢复，再重开对照样本确认身份没有混淆。交付时分别保存四行算式、同相对照、三操作辨析，以及实际文件与试听记录。通过标准是能解释为何此模型抵消、哪些真实条件尚未验证，而不是必须制造一次静音。以后换音轨或设备重新核对应关系，不把本课理论抵消写成所有立体声音频都能用反相修复，也不将未执行的设备测试标成通过。
