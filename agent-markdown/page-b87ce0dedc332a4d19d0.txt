复算左右声道峰值、共同增益与分别归一化，保留比例并限定试听结论。

左右声道峰值不同，不能直接叫音量坏了。本课用一组明确的峰值和共同时间点样本，比较整体放大与分别归一化的结果，再回到云映记录自己的文件。所有音频处理在外部副本中完成，不把计算器练习写成应用新增的音频制作能力。

## 一、准备原件与三份外部记录

选自有短录音，原件只保留不改，笔记分原始、共同增益、分别归一化三栏。先记录两声道身份与相同采样时点，再设本课的线性峰值标尺：满幅为一，左峰值零点五，右峰值零点二五。这里的峰值是各路最大绝对样本，不是平均响度，更不是耳朵对整段声音的评分。如果没有实际音频就完成模型题，真实峰值和试听记待测，避免把题设数值贴到自己的文件上当检测结果。

## 二、以共同增益保留声道比例

为了让较高的左峰值达到一，两个声道一起乘二；结果是左一、右零点五，原来二比一的峰值比仍是二比一。对应的同一时点若为左零点四、右零点一，输出就是零点八、零点二，比值仍为四比一。峰值时点不一定相同，不能只拿两个峰值比替代整段每一时点的关系；共同线性增益保留对应样本之间已有的比例，而不是保证整段左右永远固定为二比一。

```
Original peaks: L=0.50, R=0.25
Common gain 2: L=1.00, R=0.50
Paired sample: (0.40,0.10) -> (0.80,0.20)
```

## 三、再算分别归一化的不同增益

若每路各自把峰值拉到一，左路乘二，右路乘四，峰值变成一比一；同一对零点四和零点一变成零点八和零点四，其比例从四比一变二比一。这个操作确实改变了声道相对关系，不能称为仅把整体旋钮转大。[Audacity归一化说明](<https://manual.audacityteam.org/man/normalize.html>)列出独立处理声道的选项；本课只借其说明区分处理方式，不推断云映或系统音量也会执行这种处理，更不以峰值相等保证听感居中。

```
Independent gains: L x2, R x4
Output peaks: L=1.00, R=1.00
Paired sample: (0.40,0.10) -> (0.80,0.40)
```

## 四、检查标尺、符号与削波条件

把同一时点的负样本也乘相同系数，例如负零点二乘二为负零点四，不能把负号丢掉当绝对音量。计算后逐路核最大绝对值是否超过一，本模型设定的目标正好到一，实际导出还应另查峰值与处理方式，不能凭纸面数值保证没有任何编码问题。线性幅度乘二不是给分贝数乘二；若自己的工具显示分贝，先确认单位，不把两个不同标尺的数字混进同一行算术。

## 五、导出时保持其他变量一致

在有独立声道控制的外部工具里，以原件复制两份，分别执行共同增益和独立归一化；不同时改均衡、动态压缩或速度。保留导出格式、长度和声道布局，并给文件名加共同或独立标记。重新打开导出件检查其确是同一内容与两路声道。当前应用没有该编辑入口时，不寻找一个不存在的制作按钮；可直接完成纸面核算或使用已经合法准备的对照素材，所有处理步骤均标明外部完成。

## 六、在相同播放条件下试听

在云映按实际入口打开三份，先核名称与开头锚点，再在相同系统音量和相同输出设备下比较。只记可核实的左右关系与听感，不用“感觉大声”推断某路精确峰值或综合响度。若系统有辅助听觉设置，仅记录已知状态；不确定就写未核，不擅自归因。切换文件时先保持安全舒适音量，回到原件重新建立对照。没有执行本步的记录应清楚标成预期与待试听，不能复制模型答案冒充观察。

## 七、左右差异不是一律需要修复

若原片左右峰值不同，先问内容是否本来就有空间安排，不能直接分别拉满以求数字好看。若处理后声像改变，回到共同增益对照并核是否误用了每路不同系数；若两份看似相同，再核实际选择的文件和外部导出记录。一次只纠正一项，不覆盖原件。耳机佩戴、素材安排与下游路由都可能影响观察，但未取得证据时只列待查条件，不把可能性写成已经查明的故障原因。

## 八、重开原件并交付计算与限制

退出再开原件，检查输出与系统音量恢复，防止把试验文件留作日常唯一版本。交付应有三组峰值、同一时点的三组样本、每路增益和真实试听状态。通过标准是能说明共同系数保留对应关系，而独立系数可改变左右平衡；不是声称所有文件都必须两路等峰。以后换片源重新量取，不复用本题零点五和零点二五。将设备、日期和未验证项一起留档，保证别人能看懂哪些是算式，哪些是亲自观察。
