Compare the same comic panel and application text under two system color-inversion settings, then restore the original settings.

## Prepare a fixed image and original settings

Open an authorized color comic page with blue sky, a red object and black text, or create your own color practice image. Record title, chapter, panel and reading position. Record the original system appearance, brightness and both inversion switches in Accessibility. Use the same device and brightness for comparisons; do not confuse camera white-balance changes with screen-color changes.

## Record the baseline

Without changing existing settings, observe comic colors and the text, icons and background visible on the shelf or reader separately. If an inversion was already enabled, record it before changing it and compare only if comfortable. The app’s theme, screen brightness and system color inversion are different settings; do not adjust them together during this exercise.

## Check Smart Invert

Apple describes Smart Invert as reversing screen colors with exceptions for images, media and some dark-styled apps. In system Settings, open Accessibility and Display & Text Size, enable Smart Invert using the current interface, and return to the same panel in ManYue. Observe the comic image and application text and background separately; do not promise how the system classifies a particular app area. Follow the interface actually shown on the device.

## Check Classic Invert separately

Turn off Smart Invert if enabled for this exercise, then enable Classic Invert on the same system page and return to the original comic page. Apple describes Classic Invert as reversing screen colors. Record actual changes to red and blue areas, dialogue and app background separately. Do not change the app theme or color filters simultaneously. Stop and restore the original settings if the display is uncomfortable, and choose a comfortable appearance.

## Distinguish display from file contents

Disable inversion changes made for the test, return to the same page and compare with the baseline. A change in system display alone does not prove that the comic source file changed; a screenshot alone also cannot establish appearance on another device. If differences remain after restoration, check the original inversion, color filters, app theme and brightness one at a time. Record the outcome; do not reimport or delete the comic.

## Restore and record observations

Return both switches and any other changed settings to their original states and confirm the comic chapter and position. Record system and app versions, original settings, observed image and interface changes under each setting and untested items; uploading private comics is unnecessary. This exercise follows Apple’s system guidance. Both inversion options are system features, not claimed ManYue controls, and no device test is claimed.

## Observe one practice image under three conditions

Create a practice page with a red square at top left, a blue square at top right, black text in a white speech box and the word “test” below. After import, record its chapter and avoid changing pages. Under baseline, Smart Invert and Classic Invert, record each square, speech box and reading toolbar’s color and legibility. System and app versions can produce different appearances; record observation rather than copying an expected result.

If the toolbar changes under Smart Invert while the comic blocks do not visibly change, record different outcomes for the two regions. This relates to Apple’s documented image exception, but one observation cannot establish the app’s internal rendering mechanism. If a speech box is still hard to read under Classic Invert, identify which part is difficult rather than claiming the setting suits everyone. Comfort depends on the person and environment; restore the original state whenever needed.

## Separate app theme from the system switch

Reading appearance in the app may change background, margins or the reader interface, but available options and their scope depend on the installed version. Keep and record the original app theme while comparing system inversion. If you also want to compare a theme, first restore the original system switches, then change only an option actually present. Return to the same panel after each step so a combined change is not attributed to just one setting.

If returning to the app opens a different comic or chapter, go back to the recorded sample. If colors still differ, inspect whether system color filters or other display adjustments remain active. Record unfamiliar settings instead of erasing personalized configuration. If you cannot restore the earlier state, stop comparing and use the recorded original values to restore each setting, consulting Apple’s guide if needed.

## Create a shareable record without private pages

A table may contain only “baseline: red block visible; Smart Invert: toolbar changed; Classic Invert: fill in observation,” without a comic image. These are example record fields, not expected results; the reader must enter the actual observations. Include system and app versions, date, each switch’s before-and-after state and whether restoration was completed. Mark untried settings untested; a general public description is not a device test.
