Time, battery and position information can be useful without dominating the artwork. Inspect the reader overlay, system status bar and page-number display independently. Hiding one overlay does not itself alter comic files or establish that reading statistics stopped.

## Choose pages with meaningful edge content

Use an ordinary page with corner text and a landscape image with meaningful edges. Keep orientation and scale fixed and note what remains after the menu closes. Observe the device directly because screenshots can represent system display differently. Decide which information you need before disabling everything.

## Check reader time and battery

Inspect the reader time/battery control if available and change it alone. Close the menu and check persistent information, text visibility and layout. This overlay is distinct from the system status bar. Skip absent controls rather than assuming another platform’s interface, and judge whether corner content stays readable.

## Compare the system status bar

With the reader overlay fixed, compare the status-bar control and top safe area. Inspect both orientations without stretching artwork to fill space. Record which combination produces each information layer so future adjustments target the correct control.

## Interpret page numbers in context

Inspect page numbering while advancing once. Covers, pairs and tall images can make displayed units differ from source counts, so retain chapter and scene anchors. Before hiding numbers, verify another reliable navigation route. Numbering assists orientation but does not prove file completeness.

## Check zoomed and landscape views

Zoom into edge text, restore the whole image and inspect all four landscape edges. Separate temporary menu coverage from persistent overlays. Reduce unnecessary information or use available alternatives before considering file edits. Recheck the intact page before reporting missing source content.

## Test during ordinary reading

Read normally and check whether useful status and position remain accessible without repeated menu visits. Choose a minimal practical combination. Displaying battery is not a power-saving feature, and hiding time does not establish stopped statistics. Keep those separate from this visibility check.

## Check scope and persistence

Use supported device scope if the preference is local, checking another entry or device where relevant. Reopen and inspect persistence. Record the original combination and reason for the final choice. Not every control necessarily supports identical scopes; understand each layer rather than merely matching switch states.

## Acceptance and a useful report

Finish with unobscured important content, accessible useful status and reliable navigation. A remaining clock may belong to the reader rather than the system bar. For faults, report mode, orientation, control combination and affected corner using a self-made sample where possible. Preserve source and rollback values.
