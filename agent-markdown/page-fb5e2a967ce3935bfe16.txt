**For your first Aquarell exercise, follow this sequence: create a canvas → draw on separate layers → export PNG → retain the native document.** Start with a leaf or cup to learn the canvas, brushes, and layers, then gradually attempt more complex illustrations.

This guide is for iPhone and iPad users and is based on Aquarell 1.0.5's public description and project controls. Layout and labels may change between versions.

## Before you start

- Install [Aquarell](<https://apps.apple.com/cn/app/id1591340577>). The version checked requires iOS / iPadOS 15.0 or later.
- Choose a simple subject, such as a leaf, and use basic shapes to learn the tools.
- Decide how the image will be used. A small square canvas is a good starting point for a blog or chat. For printing, plan pixels and resolution around the final physical size.

## 1. Create a practice canvas

From the artwork screen, open New Canvas and choose a preset or enter a width and height. For example, start with a **1024 × 1024 pixels**square canvas for a small exercise. This is an example size, not the app's limit.

Enable Transparent Background for a transparent result, or disable it for a white background. Confirm the dimensions and choose Create.

Pixel dimensions determine how much image detail is available. DPI describes print size; increasing DPI alone does not create detail that the image lacks.

## 2. Separate the sketch, color, and details into layers

Sketch the rough outline on the current layer. Open Layers and choose Add Layer to separate color and details from the sketch.

You can divide the work as follows:

| Layer purpose | Suggested content |
| --- | --- |
| Sketch | Outer contour, structure, and position |
| Color | Large areas of base color, light, and shadow |
| Details | Veins, edge lines, and local highlights |

Check the selected layer before continuing. To soften the sketch, change that layer's opacity so the finished color is not affected. Explore blending modes after becoming comfortable with the basics.

## 3. Adjust one brush parameter at a time

Choose a brush and color, then draw a few short strokes to observe the result. Try brush size, opacity, and spacing in turn: size controls stroke width, opacity controls coverage, and spacing controls the distribution of adjacent stamps within a stroke.

Change one parameter at a time to make differences easier to compare. For finer brush adjustments, open Brush Studio. Undo mistakes; there is no need to redraw the entire artwork just to test a color.

## 4. Export an image to share

When finished, open Export and choose Export PNG. Use the share sheet to save it to a suitable location or send it to another app.

PNG suits images requiring transparency or crisp edges. JPEG suits sharing without transparency. After export, check dimensions, edges, and background against the intended publishing use.

## 5. Save an editable native copy

Export an Aquarell native document as well as the finished image. PNG and JPEG sharing images do not preserve the full editing structure.

For pixel-layer exchange, you can also choose Export Photoshop (PSD).**PSD export contains pixel layers**. Keep editable text and layer groups in the native document; do not assume that saving a PSD backs up all editing information.

## Verify the whole workflow with a small exercise

Keep the first exercise small: one leaf, three layers for sketch, color, and detail, and no complex background. Fill the center with a larger brush, then use a smaller brush on the edges. Put the shadow on only one side and add one main vein at the end. This practices layer selection, brush size, and color changes without too many distractions.

After each stage, temporarily hide its layer to confirm that it contains only the intended material. When the color layer is hidden, the sketch and details should remain visible. If they disappear too, correct the layer separation before continuing. This catches accidental drawing on the same layer early.

## What to check before exporting

First, zoom out to the size you plan to display on the blog. Check that the subject is complete and fine lines have not all disappeared. Zoom in to inspect the leaf tip and outline for accidental gaps. Finally, check layer visibility and hide temporary brush tests or color swatches. Not everything in the working document belongs in the finished image.

Open the exported file and check its pixel dimensions and background. Inspect a transparent PNG against both light and dark backgrounds; for a complete illustration, check for unintended transparent gaps. Place it in a blog draft and inspect mobile cropping and article width rather than judging it only inside the app.

## Keep a way to revise it later

Give the native document a clear name, such as “Leaf study, version one,” and name its sharing image as a preview of the same subject. Resume from the original when changing colors or veins later. Do not rely solely on a compressed image downloaded from a chat app.

If a brush works particularly well, note its name, size, opacity, and what you used it for. Comparing it on the same task next time is more reproducible than merely noting that it was a good brush. After this exercise, choose one aspect to explore further, starting from a dependable workflow.

## Frequently asked questions

### Why does the exported PNG still have a white background?

Check the canvas and layers for a white background first. PNG supports transparency, but that does not make every exported PNG transparent. White pixels actually present in the artwork are exported too.

### Why did changing the sketch also change the color?

Check whether the sketch and color are on the same layer and which layer is currently selected. They must be separated before you can change their opacity or contents independently.

### Should I also use Aquarell for an SVG logo?

Aquarell is better suited to brushwork and pixel-layer painting. If you need editable vector paths and SVG, start with [VectorPaint's geometric icon tutorial](<https://allluckly.cn/en/guides/vectorpaint-getting-started/>)to begin.
