## VectorPaint：海岬灯塔

- iPhone Duo 模拟器 / iOS 27.1，VectorPaint 本地构建 1.0.7（6），非商店二进制一致性声明。
- 在旧草稿的副本中删除原有三个对象后开始新作品，保留原草稿。最终文档“海岬灯塔_方形创作”为 1080×1080、1 个图层、17 个钢笔闭合路径对象。
- 顺序：太阳、远山、海面、海岬、岩岸、塔身、灯室、亮面、屋顶、两条带、门、窗、三道波光、光束。
- 只有塔身最终启用 4 pt 黑描边，其余 16 个对象取消描边。没有演示布尔运算、蒙版或外部矢量导入。
- PNG 53,665 字节，1080×1080、白底，直接复制应用分享导出物。SHA256：`478fdb4243c4d38efb28070e097f7f2cdf842475086812b38cf9fe49ce806334`。
- 收藏色板名称为琥珀、紫色、蓝、苔绿、陶红、白、黑。正文 HEX 由最终 PNG 色块取样，陶红为 E04C2E；没有把 8 bit 输出与浮点预设混为一谈。

## 展开与折叠素材

- 两款应用均通过 Device Hub 的 Open → Partially Open → Closed → Open 按钮实际切换，并采集整个设备窗口。
- 每片末 20 秒为真实截图采样剪成的分步镜头，保留四态和少量过渡帧。停顿按阅读节奏剪短，未插值生成连续铰链动画；片中常驻标注“设备窗口采样 · 分步演示”。
- 画面仅包含设备窗口；无麦克风音频，使用 Computer Use 截图采样，未更改 macOS 录屏权限。
- Aquarell Closed 视图月轮上缘裁切，重置画布未消除本轮裁切；成片保留裁切并展示重新展开后的完整构图，不使用 fit-* 尝试帧，不宣称自动完美适配。
- VectorPaint 本次视图缩放从展开 56% 到半折叠约 29%、合拢约 27%，再展开 56%。原稿/PNG 像素维持 1080×1080。
- 两段主创作视频来自 simctl display 3 真实录制。媒体剪辑、字幕与截图附录不修改应用内创作数据或原生作品 PNG。
