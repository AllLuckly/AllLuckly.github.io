# iPhone Duo 电影运镜教程：制作与验证记录

本轮使用用户指定的 video-shotcraft **Ink Press 模板**。成片继承模板十个镜头的局部时长与缓动，在原有字卡间插入真实教学片段；应用字体与配色来自各应用自身。外置中英文 WebVTT 与章节由最终共享时间轴导出，网页主版不烧录底部解说，避免与切换后的字幕重叠。

## 来源与真实性

- 设备为 iPhone Duo 模拟器、iOS 27.1。素材来自本地应用构建，不构成与 App Store 二进制一致的声明。
- 创作过程使用实际应用画布。Aquarell 的后半程由应用正式 MCP 的选区、填色、画笔、图层及导出工具辅助完成；所有像素均由原生绘画引擎生成，没有导入外部合成图。
- 原始 MOV 为稀疏可变帧率录制。剪辑依据实际 PTS、画面观察和阶段记录，先规范到 30fps 再截取；不能用平均帧率或存储帧序号推算操作时间。
- Duo 展开、半展开、合拢与恢复均为 Device Hub 实际切换后的窗口截图。影片将其作为姿态分步对照，明确说明是窗口采样，不插值或伪造连续铰链运动。
- 原生作品 PNG 单独保存，发布副本必须逐字节一致。后期镜头推近、侧移、节奏剪辑与声音设计不改变原稿像素。
- 源录制、阶段截图、导出物、详细工具日志与视频工程均保存在 git 忽略的 `output/duo-cinematic-20261024/`。连接凭据不加入仓库。

## Aquarell：雨夜窗景

- 作品保存在 Painting 3，1400×1000 px、300 dpi、sRGB、13 个原生图层；最终已保存且无活动选区。
- 从底到顶依次为夜色、城市、雾与月色、城市灯火、玻璃雨、窗框、木窗台、吊灯、书、咖啡、陶盆植物、独立蒸汽及最后收光。名称表示教学角色，没有宣称界面中完成逐层重命名。
- 雨层不透明度 58%，雾层 19%，独立蒸汽层 36%。植物包含 13 片多边形叶片；书页用短线表现行列，没有伪造可阅读的正文。
- 最后清理了书页边缘的越界笔迹、重画过亮的蒸汽，并擦去跨过前景静物的一段窗台高光。
- 原生 PNG 324,032 bytes，SHA-256 `4d0085433aca15f2f2ae47953c98e507f45d9b4d9ac629432e49e94e31a5751c`。
- 可编辑 `.aquarells` 原稿 7,887,872 bytes，SHA-256 `db576dfb4b2f832d672a5879b2b0cc742170b69ae6b57856e2e89daf9e00265f`。
- 历史笔触统计包含已清除试样和局部重画，不作为成品可见笔画数量宣传。
- 合拢视口显示的横向范围变窄；重新展开和原生 PNG 用于核对完整边缘，不宣称折叠后所有内容仍完整可见。
- 实际安装版 Info.plist 核对为 1.0.5（1）。

### Aquarell 成片

- 最终网页主版：1920×1080、30fps、5145 帧，视频轨 171.500 秒，含 AAC 尾部的 MP4 容器为 171.562667 秒；网页声明 `PT2M51.563S`。
- 27,792,709 bytes，SHA-256 `ce669c0debdc469093eda5198b06aa1890075160ed73b9461da647144e2cda0b`。
- 19 条中英字幕来自相同的最终时间轴；主要章节起点 0 / 7.333 / 72.967 / 119.033 / 139.367 / 166.667 秒。
- 实际教学片段标注 1.5–4 倍速，剪去长时间等待。声音仅为已记录授权的音效，无背景音乐和旁白。
- 独立审片发现初版的扁长素材槽过小，随后改为各自独立的真实局部与标签。特写镜头的 100 帧按精确帧边界替换后重新封装全片，完整解码通过；原 AAC 整轨保留，解码 PCM 与前版哈希一致。
- 最终影片的入口、运动峰值、落定及两个补丁接缝已独立复核通过；立体声峰值 −5.5dBFS，未削波。原始模板与实际最终抽帧证据保存在 ignored 工程的 `out/qa/independent-review/`。
- 网页字幕实际显示与工作台拆轨一致性单独验证，不以影片审查代替。

## VectorPaint：温室咖啡馆

- 在本地构建 1.0.7（6）中以正常编辑界面完成，1080×1080 px、1 个图层、29 个闭合路径、109 个锚点。
- 使用钢笔逐点落下和闭合、内置填色面板、对象树及几何表单；由 AI 经触控、键盘与辅助功能操作，没有导入外部成图或向应用注入文档数据。
- 六色分别为紫色 `#875CBA`、琥珀 `#F7B53D`、苔绿 `#4A7A59`、蓝色 `#4578D6`、白色 `#FFFFFF`、陶红 `#E04C2E`。实际对象包括台地、墙与屋顶、八片门窗玻璃、遮阳棚与门板、两盆六片大三角叶和四块铺石。
- 两只花盆分别在正常几何表单上移 86.4 px 与 48.6 px；小叶试样操作不稳定后改用较大的闭合三角形。最终没有把未完成的招牌、咖啡豆标识、桌椅或玻璃反光写入教程。
- PNG 经“分享 → PNG → 完整画布 → 1× → 白色背景 → 导出 PNG → 存储到文件”实际导出。79,911 bytes，SHA-256 `6f083586e3f310d342b592966afcdb79e1f5e0f73f1f12eb0303eec81d07b88f`。
- 可编辑 `.VectorPaint` 原稿 25,879 bytes，SHA-256 `6815b7e3a21ce7bf42a7b95ab89feaeb51530fafea54785b63ec21e102844f87`。PNG 导出后又移除一条无面积、无描边的双节点试画线，画面没有可见变化；最终原稿只保留 29 条闭合路径。
- 实际四姿态采样包含合拢后的紧凑横向布局，已剔除切换中的黑屏与等待。录制正常停止后，设备已释放给原应用开发任务。

### VectorPaint 成片

- 最终网页主版为 r2：1920×1080、30fps、5869 帧，视频轨 195.633333 秒，MP4 容器 195.690667 秒；网页声明 `PT3M15.691S`。
- 22,247,867 bytes，SHA-256 `66c86ecd683e1ec1b89b44c40192775e9820bb8e06ff9e3a66f685dc9a050f53`。
- 中英各 19 条字幕，章节起点为 0 / 7.333 / 59.633 / 102.967 / 122.3 / 190.8 秒。实际创作片段包含原速，以及 1.5、2、3、4 倍速；明确标记剪去的等待。
- 片中屋顶检查段根据真实 29% 与 56% 视口重新取景，并把字幕限定为实际可见的“重建后填蓝与四角检查”；没有将这 9 秒描述为完整的重建操作。
- 修正素材槽标记遮挡和屋顶取景两段后按精确帧边界替换，全片完整解码通过；原 AAC 整轨保留，解码 PCM 与首版哈希一致。

## 网页与 GEO 连接

- 每篇作品一个主播放器；横版影片在桌面占满播放器宽度，章节与说明排在下方，避免画布被侧栏挤小。
- 文字教程提供可折叠的章节目录，沿用现有标题导航逻辑；不把目录项重复加入给 AI 阅读的正文 Markdown。
- 中英文正文独立地址、互返语言入口、canonical、hreflang 和原文哈希保持一致。每个播放器同时提供中英两条字幕轨，唯一默认轨随页面语言选择；也可在同一页面的原生媒体菜单中切换。
- `BlogPosting`、`VideoObject`、`Clip` 和对应应用的 `SoftwareApplication` 使用同一组实际媒体事实；章节起点来自成片，不使用源录制时钟。
- 保留直接 MP4、字幕下载、无 JavaScript 的章节时间和完整文字教程。中英文 Markdown 阅读入口由实际构建的语义正文生成。
- 发布后需要更新 Cloudflare Worker 内嵌路由清单，并逐条核对新增页面的内容协商、媒体 Range 请求、字幕、搜索和 sitemap。

## 本地验收

- 实际 Safari 528 px 视口（播放器约 484 px）分别播放 Aquarell 中文与英文步骤字幕，均为单条原生字幕，未与烧录解说重叠。另在中文页通过原生语言菜单选择英文，页面地址不变而实际字幕已切为英文。
- VectorPaint 中英正文已检查桌面阅读布局、语言互返与文字目录锚点。400 px 英文表格曾将 Paths 挤成竖排，现仅对作品表头恢复正常单词换行，已由真实浏览器截图和独立审查确认修复。
- 两篇中英文正文均独立核对原生作品事实；PNG 与原生导出逐字节一致。详细帧审查、七帧工作台像素对比和轨道端点审计保留在 ignored 工程中。
- 128 篇历史技术文章的署名、来源与原始日期校验通过。Markdown Worker 接口回归、WebMCP 搜索接口模拟及站点 JavaScript 语法检查通过；模拟测试不构成 Safari 原生 WebMCP 支持的声明。

- 两支最终影片均通过独立终检：实际关键帧、整片抽帧、运动序列、补丁接缝、完整解码与音效对齐分别核对；声音峰值 −5.5dBFS，未削波。
- VectorPaint 中英 528 px 视口均实际播放单条清楚字幕；在英文页的原生“更多 → 字幕 → 语言”菜单选中文后，页面地址未变，实际字幕已切为中文。
- Aquarell 工作台七帧逐像素相同；VectorPaint 工作台八帧对比无通道差超过 1，只有收尾帧的两个像素存在 1 级差异。两工程全部轨道的最大端点分别等于 5145 / 5869 帧，没有音效尾巴超出成片。
- 最终全站构建通过：339 组互返语言页面，314/314 篇完整英文文章，678 个 Markdown 页面；保留 1,890 个代码块和 3,494 个行内代码节点。36 个阅读索引、642 个直接 Markdown 目标均检查为最新。
- 站点校验通过 749 个 JSON-LD 图、745 个 sitemap URL、180 篇详细教程、6 条完整学习路线和 6 个作品视频。公开 API 目录、字幕本地化与技能发现摘要均通过校验。

发布时使用 `scripts/package_agent_worker.py` 打包当前 678 条路由，再更新既有 Cloudflare Worker。发布后的实际 HTTP 响应、视频 Range、图片/字幕字节、语言互返与 Markdown 内容协商由发布验收脚本核对，证据保存在 ignored `output/duo-cinematic-20261024/production-verification.json`；本地构建结果不替代线上检查。
