# iPhone Duo 创作视频：顺序操作重剪

用户确认参照上一轮《月照松湖》《海岬灯塔》的剪辑方式，替换雨夜窗景与温室咖啡馆的首版影片。实际应用界面占据主要画面，按创作顺序硬切并删除等待；移除 Ink Press 宣传字卡、素材拼贴、装饰运镜和音效。首版制作与作品来源记录保留在 [原制作记录](duo-cinematic-creation.md)。

## 画面与内容

- Aquarell 的横向源录屏保留完整应用界面；VectorPaint 的竖向源录屏沿用旧灯塔影片的竖向构图，不为统一方向而裁掉工具或缩小整窗。
- 原速与适度加速按实际片段标注。中英文外挂字幕和章节均以最终成片时间为准；每个语言页面只有一条默认字幕轨。
- Aquarell 从已保存的蓝色底景和楼群继续，依次展示雾月、窗灯、雨、木框、窗台、灯、书、杯、植物和精修，不宣称视频包含从空白新建到结束的每次操作。
- VectorPaint 展示实际编辑过程。屋顶片段的说明限定为重建后的填色与四角检查，不宣称完整重建过程均在片中。
- 完成作品的原生 PNG 静态展示 3 秒，随后用四张真实设备窗口截图各停留 5 秒，对照展开、半展开、合拢和重新展开。画面与字幕明确标记采样，不伪装连续铰链运动。
- 两部影片均无音轨。AI 辅助方式、模拟器和本地应用构建信息保留在页面与字幕中。原生 PNG 和可编辑画作没有因重剪发生变化。

## 网站替换

两篇中英文作品页保留原地址，用 `*-steps-v2.mp4` 及对应中英 WebVTT 替换主播放器资源，避免继续命中旧影片缓存。同步更新时长、画面尺寸、章节、VideoObject / Clip、视频 sitemap 和供 AI 阅读的 Markdown。

本次没有新增或移除页面，Cloudflare Worker 的路由清单若保持一致，无需为更换媒体重复部署 Worker；实际内容协商仍须在发布后验证。

源录屏、确定性剪辑脚本、分段时间线、来源校验、可编辑工作台工程和独立审片证据保存在 git 忽略的 `output/duo-recut-20261024/`。
