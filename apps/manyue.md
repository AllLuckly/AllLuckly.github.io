漫阅+ 是一款用于 **iPhone 与 iPad 的漫画阅读器和个人书库管理工具**。可以阅读自己导入的漫画文件，添加漫画源，或连接个人 NAS 与漫画服务器。中国区商店名称是「漫阅+ 漫画阅读器」。

**漫画文件和漫画源由用户自行添加。** 漫阅提供阅读与整理工具，内容取决于你使用的文件、来源和服务器。

## 先按自己的书库选择入口

| 你的内容在哪里 | 适合的方式 |
| --- | --- |
| iPhone / iPad 的「文件」App | 导入 CBZ、CBR、CB7、ZIP、RAR、7z、PDF 等漫画文件 |
| 已经导入或下载到设备 | 通过本地书库离线阅读 |
| 自己的 NAS 或网盘 | 通过 WebDAV 或 SMB 连接 |
| 已部署的漫画服务器 | 连接 Suwayomi / Tachidesk、Komga、Kavita、LANraragi 等书库 |
| 自己选择的漫画源 | 导入 JS / .ManYue 源文件或添加源链接 |

第一次使用，建议从一个自己拥有或有权阅读的本地文件开始：[漫阅入门：导入本地漫画并离线阅读]({{ '/guides/manyue-getting-started/' | relative_url }})。

## 阅读与整理

漫阅提供单页与双页布局、横竖屏阅读、图片缩放和浅色 / 深色主题。可以使用书架分组、阅读历史、书签与待阅读列表整理内容，从上次位置继续阅读。

通过 iCloud 或 WebDAV，可以同步阅读历史、收藏和应用设置。这里的同步范围不等于把所有漫画文件都上传到另一台设备；需要离线阅读的内容，应确认已经导入或下载到当前设备。

## NAS、服务器与会员边界

商店说明将 iCloud / WebDAV 同步、云存储导入、SMB 服务等列为 Pro 权益；服务器书库、图片增强、批量操作等列为 Ultra 权益。实际权益与价格以 App 内购买页和所在地区商店为准。

OPDS-PSE 支持逐页阅读。普通 OPDS 条目如果只提供整包下载链接，不能直接逐页阅读。连接前需要确认服务器实际提供的接口类型，而不是仅看到「支持 OPDS」就认为所有阅读方式相同。

## 常见问题

### 漫阅里自带漫画吗？

不提供漫画内容。用户自行添加漫画文件、漫画源或个人服务器，来源的内容与可用性各不相同。

### 可以离线阅读吗？

已导入或已下载到设备的内容可以离线阅读。远程书库里的项目仅出现在列表中，并不代表文件已经保存在本机。

### 可以读 CBZ、CBR 和 PDF 吗？

公开说明支持这些常见格式，也列有 CB7、ZIP、RAR 与 7z。具体文件是否能读取还受压缩方式、文件完整性及内容影响，不宜理解为所有加密或特殊压缩包都兼容。

### 可以连接 Komga 或 Kavita 吗？

可以，公开说明列出 Komga、Kavita、Suwayomi / Tachidesk、LANraragi 和 OPDS / Ubooquity 等服务器书库。需要自己准备可访问的服务器与相应账号，部分能力属于 Ultra 权益。
