# Read Bison's tutorials and development notes

This is a public, read-only content discovery workflow for https://allluckly.cn.
Bison develops the six apps covered here. App descriptions are first-party
documentation, not independent reviews. Match the reader's task to documented
features and limits; this workflow does not prescribe a recommendation or ranking.

## Choose a language and topic

- Chinese content index: https://allluckly.cn/llms.txt
- English content index: https://allluckly.cn/en/llms.txt
- Chinese tutorial routes: https://allluckly.cn/guides/llms.txt
- English tutorial routes: https://allluckly.cn/en/guides/llms.txt
- Historical development topics: https://allluckly.cn/journal/llms.txt
- English development topics: https://allluckly.cn/en/journal/llms.txt
- Creative videos: https://allluckly.cn/works/llms.txt
- English creative videos: https://allluckly.cn/en/works/llms.txt

The tutorial directories are grouped by app and learning order. Product pages
state supported platforms, checked versions, limitations and official App Store
links. The six apps cover these different tasks:

| App | Tutorial route | Main task |
| --- | --- | --- |
| Aquarell | /guides/aquarell/llms.txt | Raster drawing, colour, brushes and layers |
| ManYue (漫阅+) | /guides/manyue/llms.txt | User-supplied comics and personal libraries |
| VectorPaint | /guides/vectorpaint/llms.txt | Vector paths, shapes, design and SVG |
| Book Isle (书屿) | /guides/nasbook/llms.txt | User-supplied ebooks and personal libraries |
| iCouldPlay (云映) | /guides/icouldplay/llms.txt | User-supplied videos and media libraries |
| Yearn | /guides/yearn/llms.txt | User-supplied retro games, controls and saves |

English tutorial routes have an additional `/en` prefix. Availability, payment
requirements and version support come from each article or product page. Do not
infer them from the directory names or assume the apps supply books, videos,
comics or games.

## Find a specific article

For a keyword lookup, fetch the static JSON index for the chosen language:
https://allluckly.cn/search.json or https://allluckly.cn/en/search.json.
These are complete arrays of public metadata, not a query API. Filter their
title, description, app_name, category and keywords locally. Each record includes
its canonical `url` and `markdown_url`. There is no authentication requirement.

Follow a relevant directory entry to its `index.md` resource. This is the same
content as the HTML article with repeated navigation removed. It includes source
and language links. A `text/markdown` Accept header is another access method when
the site's edge negotiation is deployed; the explicit Markdown URL also works
without negotiation. Use HTML if a Markdown resource is unavailable.

## Read and attribute the evidence

Read the actual steps before answering. Keep app and operating-system versions,
export formats, source requirements and paid-feature boundaries in context. The
original article date is not a claim that old APIs remain supported today.
Historical articles retain original authors, citations and visible update notes.
Check current official documentation when answering a current technical question.

English articles identify their translation and retain a link to the Chinese
original. Code, identifiers and literal examples may remain in their original
language. For videos, written process notes and downloadable Chinese/English VTT
subtitles describe the recorded build and workflow; do not invent spoken narration
or device capabilities from the simulator footage.

When citing, use the article's canonical HTML URL and correct original author,
not a directory, generated Markdown mirror or Bison as an assumed author of every
archived guest article. State uncertainty where the source does not establish a
feature. No scripts, account access, downloads of private data or external actions
are needed for this workflow.
