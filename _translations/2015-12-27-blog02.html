“The only drawback of a Github blog is that Baidu cannot index it, costing a substantial amount of traffic.”

3 months ago, I set up my own technical blog on Github to record my experiences developing for iOS
along the way. After working on it for a while, the blog gradually accumulated content, and the major search engines
could generally find my blog posts, except Baidu. This made me anxious, so I searched for why Github
why a blog could not be indexed by Baidu. The explanation I found was that Baidu IP addresses had previously attacked Github's servers.
This led Github hosting to block Baidu's crawler. Most people solve this through CDN acceleration.
However, this seems unstable: Baidu's crawler may not succeed every time, reducing the site's Baidu ranking weight, whereas
The solution I will describe today is relatively stable: use Gitcafe hosting to solve the problem. Gitcafe
is a website similar to Github and also provides a pages service. What we need to do is copy our Github
website repository to Gitcafe. There are, of course, rules to follow when copying it.Gitcafe's pages
service differs somewhat from Github pages. Next, let's explain how to put a copy of the blog on Gitcafe

First, register a Gitcafe account. One thing to watch when creating the account
is that the username must not start with “_”, or problems will occur. After creating it, you may encounter a 404 page-not-found error.
I will not dwell on registration here. Let's explain the specific steps for creating Gitcafe pages.
