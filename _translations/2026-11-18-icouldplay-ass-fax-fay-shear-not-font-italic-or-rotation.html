Separate tag factors from the geometric illustration

Aegisub defines zero as no shearing and fax/fay as the two directions. Separately stipulate paper maps H(x,y)=(x+0.25y,y) and V(x,y)=(x,y+0.25x): point(40,20) becomes(45,20) or(40,30). Those explicitly defined mathematical coordinates are not actual font pixels in iCouldPlay; glyph coordinates, anchors and rendering scale add conditions. Draw reference axes and retain the origin, then record actual direction instead of treating paper values as measurements.

Use italics and rotation as separate counterexamples

On separate copies change only i0 to i1 with both shears zero, or only frz to ten degrees. These test italics and rotation without merging them into the original three conditions. Italics can select different glyphs and need not match shear 0.25; rotation changes overall orientation rather than shearing one axis. The documentation places shearing after rotation and says its coordinate system is unaffected by org. This exercise fixes rotation 0 rather than assuming complex combinations commute. Observe only counterexample versions actually produced.

Troubleshoot parsing, overrides and clipping in order
