A river or window metaphor does not transfer every property to its target. Select an actual passage in Book Isle and record target, source, context-supported shared feature and uncertain interpretations. This is manual close reading without automatic rhetoric detection, symbolic explanation or a standard literary score.

Fix one edition and one actual sentence

Choose one edition you may read and record title, author, translator, chapter and short wording for one locatable metaphor. Do not reconstruct an attractive sentence from memory and attribute it. Read the surrounding paragraph and identify narration, dialogue, quotation or imagination; speaker matters. Use supported selection for a necessary short excerpt, or manual image-page/nearby-word locators for scans without claiming exact text anchoring. Preserve the book and put interpretation in notes/external logs, not rewritten source text.

Describe target and source separately

The target is the object being explained; the source is the borrowed image. Keep them distinct. In the invented teaching sentence “A page is like a window into an unfamiliar place,” target=page and source=window; it is not a book quotation. Use the actual author’s sentence rather than imposing this example. Metaphor need not contain like, and one keyword cannot decide it automatically. Label provisional readings and retain alternatives if needed instead of inventing a unique answer for a tidy table.

Extract shared features supported by context

Find words showing the relevant comparison—for example access to unfamiliar things, not binding merely because pages and windows can both open and close. Keep short source locators and your paraphrase separate. A source may suggest many properties, but retain only two or three relevant, context-supported features rather than every dictionary meaning. Preserve an explicit limited resemblance instead of total identity. Personal associations may be recorded separately, not promoted unmarked into established authorial intention.

Record properties that cannot be transferred directly

A window’s glass does not make the page glass, nor its physical width a measure of content capacity. This check separates figurative comparison from literal physics without rejecting the metaphor. Identify one unsupported property you nearly transferred and explain the missing evidence. If later context develops it, add support rather than excluding it forever. These are interpretation limits, not prohibitions on literature. Distinguish textual evidence from remaining inference.

Keep a separate context for a recurring image

For a later window/river image, record speaker, target and function separately rather than automatically merging identical words into one symbol. Search only supported scope and read context; missing hits need word-form/text-layer checks before absence claims. Select one relevant later passage, not an automatic whole-book imagery census. Different features may coexist without refuting the earlier reading. Label cross-passage connections provisional, not measured meaning-strength from hit counts.

Check qualifications through your own paraphrase

Without notes, paraphrase what the metaphor explains, then compare with the passage. Restore may, as if or limited-aspect qualifications lost for fluency. A plain version without the source image can reveal lost tone, feeling or narrative function; it is a diagnostic, not a replacement for literature. One exercise does not establish chapter mastery, and outside interpretations do not override text automatically. Keep the first draft/revision reason to distinguish new evidence from wording choices.

Retrieve the sentence and scope after leaving

Leave and retrieve the sentence by chapter, short wording and needed page locator, rereading context for correct target/source. Screen pages can change, so percentage alone is insufficient. Export important notes through an available method and inspect quotation/paraphrase/limits externally; retain the book separately because notes are not its backup. Share necessary lawful short excerpts/locators, not copied passages as personal explanation. Separate supported features from unresolved readings instead of treating a filled table as verification.

Return to specific comparison words when interpretation grows too broad

If everything seems transferable, return to actual comparison words instead of adding familiar stories. Reversed target/source requires identifying which object is being explained. Retain evidence/scopes for multiple readings rather than compressing them into one meaning. Failed searches need extractable-text checks, not invented recurrences. After correcting the interpretation, explain target, source, supported features and transfer limits so rereading has evidence beyond attractive words and unverifiable intentions.
