Begin with a private drive or NAS where WebDAV is already enabled. Save a ManYue connection, choose the comic folder, open a sample and download needed books. Afterwards browse through saved servers and prepare this week’s local copies before going out.

Confirm four details with the administrator

Prepare the real address, username, password and comic directory. Use the provider’s explicit WebDAV address, not a drive-management webpage. Preserve deployment subpaths. This article’s https://dav.example.com/comics/ is only a placeholder, not a public library or an address that can be copied for successful access.

Verify that the account lists folders and reads target files. A read-only comic library usually does not need extra write permission; scope depends on server configuration. First connect within a network you control, then separately check current Pro or Ultra cloud-storage benefits. Purchase rights and server permissions are different.

Add WebDAV under remote libraries

Choose WebDAV in Add Remote Library and enter address and credentials in their dedicated fields, not public URLs, shelf names or screenshots. Check scheme, host, port and path, especially spaces or temporary login parameters copied from a webpage.

Enter a small comic folder and compare filenames with the server. For an empty list, inspect the parent path and permitted scope. For immediate login failure, check credentials and address first. These are different folder-selection and connection-setting stages.

Check in this order, with each item corresponding to a later step:

Item What to enter or select What to read next
Service address The administrator’s complete WebDAV address, including required subpaths Whether directory listing works
Username and password Credentials specifically for this service Whether authentication succeeds
Comic directory Choose the actual comic folder after connecting Whether the sample filename is correct
Saved server Find the saved connection in the server list Whether the same folder reopens after exit

Save this small-scope connection before adding more folders. For similarly named services, note a purpose such as “home short comics” to identify the correct saved entry.

Choose an appropriate library scope

Choose the actual comic-storage level in library-folder controls. A parent folder may contain backups, photos and other documents. Do not include everything merely to save a step. Clear scope makes scanning, browsing and troubleshooting correspond to server files.

If files are absent, confirm their location server-side and refresh that scope. Do not clear unavailable records during a temporary outage: unreachable is not deleted. Moved remote files may require rescanning or relocation, not repeated title changes.

Verify online reading and downloads separately

Use a small ordinary file, open it through the available reader and inspect beginning, middle and end. Online success proves current access, not a full local copy. For offline use, explicitly download, confirm completion and open from local content.

No promise is made that every compression format, huge file or special server setup reads instantly. If remote reading fails, check whether the file can be downloaded lawfully and imported locally, separating access from parsing. A cover does not complete verification while file integrity remains unknown.

Example: connect your own short-comic folder

Suppose the administrator supplies an address with /dav/ subpath, with the comics in the ShortStories. Connect with the dedicated account and choose your own CBZ there, not a browser administration URL containing a login page. Open the sample, download it and inspect the local copy.

If directories list but images fail, report that stage difference. Check account read access, file integrity and server support for the request. This is more useful than “WebDAV cannot connect” and avoids changing passwords after successful authentication.

Final checks and safety boundaries

Verify reopening, correct folder, sample reading and needed downloads before expanding scope. Never put real addresses or accounts in public comments; redact credentials and private paths in screenshots. Record original server settings before changing them, avoiding several simultaneous changes with no clear cause.

Why does a working WebDAV library not sync progress to another device?

File access answers where comics are. History, favourites and settings require separate data-sync setup. The provider may be shared, but keep folder purposes explicit rather than mixing comic and sync-backup directories.

What if it connects only at home?

First check whether the address is local-network-only. Do not expose NAS ports casually for reading. Use your own configured remote-access solution or prepare verified offline downloads. The app cannot replace server reachability configuration.
