Check the catalog, format and text through two entries to an owned Calibre library without treating its database as the book itself.

Preserve the library and choose a sample

In a Calibre library you manage, select an EPUB you may read and record title, author, library identity, format and a recognizable short sentence. Preserve the original library and existing backup; do not move, rewrite or manually edit metadata.db for this test. Avoid private books or credentials and use only self-made or shareable text in any public result.

Understand what the two entries represent

Book Isle’s public listing describes Calibre Content Server and Calibre metadata.db as two private-library entries. The content server depends on an already running service you are authorized to access. metadata.db stores library metadata but is not itself the complete EPUB content. A title in a server list or access to a database alone does not establish that the book file can be read. Installed-version interface and conditions govern.

Identify the same library at the Calibre source

In your existing Calibre environment confirm the book, format and library directory, and which library the content server and database actually use. For similarly named libraries, distinguish them with real evidence such as directory and sample chapter rather than guessing from titles or service names. Do not expose new public ports or change account permissions for this exercise. Stop if the service or database source cannot be identified.

Read a baseline through Content Server

Using the actual available, authorized Content Server connection in Book Isle, find the sample and record service label, title, author and visible format. Open or download the EPUB through the current interface and check the same chapter and sentence. Record catalog visibility, file acquisition and readable text separately; an unfinished step does not make the full path successful. Preserve actual network or entitlement messages.

Check metadata and files through the database entry

Use Book Isle’s actual metadata.db entry to select or connect the correct database and record its library source and whether the sample appears. Then observe whether the current interface can find the corresponding EPUB and open the text. If metadata is readable but text is not, first check whether library files are in the correct location accessible to the app; do not guess at database path edits. Mark the step incomplete if the entry or required location is unavailable.

Compare fields without merging records

Use separate table rows for A Content Server and B database, with library label, title, author, format, visible file and body sentence. Pass only what was actually completed. Matching metadata but different text may indicate different editions or library identity. Matching lists with unreadable text on B indicates a file-access question, not automatic proof of database corruption. Change only one confirmed condition per trial.

Record metadata and body text in comparison rows

Make rows for A Content Server and B database, with library label, sample title, author, format, catalog visibility, body-text phrase and unfinished reason. If both list a same-named EPUB but only A reaches the original phrase, write “catalog visible, text unconfirmed” for B rather than “same book readable.” If B shows another phrase, check chapter and edition first; mark uncomparable fields unknown. Two entries on one network may have different account permissions, so redacted account labels and actual visible paths are more useful than merely writing “connected to Calibre.”

Distinguish source changes from client refresh

If two entries differ after a source-library update, record each entry’s last confirmable observation time and check what the user can currently see at the Calibre source. Observe through refresh or reentry controls actually visible in the app; do not delete catalog records or assume clients update instantly. If a title changes after refresh but the original phrase agrees, record metadata and body text separately. If the source already shows a different edition, resolve identity first. Exclude service addresses, database files and private books from reports.

Check database association by file location

If the database entry shows a catalog but cannot find the EPUB, first check in the authorized source library whether that book actually has an EPUB format, then inspect the library location the app can currently access. A correct database name does not prove related book files are readable through the same path. A successful Content Server download establishes only that the server provided that file to the current account. When using a copy, record its creation time and scope; an old metadata.db copy cannot be assumed to contain later additions. The library maintainer should decide any path or permission changes using the service’s documentation. This exercise requires no library deletion, direct SQLite editing or new public server exposure. Confirm the original library and independent backup remain.

If the sample cannot be identified even through read-only actions, record the failure, retain the original state and consult the library maintainer later.

Retain results and existing connections

Record device, installed version, redacted identities of both entries, sample checks and reasons for unfinished items without accounts, hosts or private book text. Return to the original usual connection and confirm the original book and reading records remain available; do not delete or merge other entries. The exercise follows public capabilities and Calibre documentation and claims no real server, database or device test.
