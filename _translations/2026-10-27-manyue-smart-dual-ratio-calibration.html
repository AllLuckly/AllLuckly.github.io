Image proportions can help identify spreads, but they do not determine narrative type. Compare a portrait page, a genuine spread and a whitespace-heavy wide scan within the available smart-two-page controls. Seek a sensible majority result and a clear approach to exceptions.

Identify three different sample types

Select the three types from one authorised file where they exist. Record chapters and scenes and inspect each intact. Do not manufacture a missing category by editing the source. Content determines its role; similar dimensions can conceal different reading structures. Keep these samples fixed throughout calibration.

Confirm ordinary pairing first

Establish correct gallery pairing, direction and first-image treatment before enabling smart handling. Pairing offset and width detection are separate. Leave vertical splitting unchanged. If smart handling or a threshold is absent, keep ordinary pairing with temporary full-image viewing rather than assuming every release exposes the control.

Record the threshold and change one step

Record the current value and permitted range, then change one step without altering other layout controls. Compare which samples switch between paired and single display. Learn the direction from observed results, not a supposed universal ideal value. Inspect an ordinary page and the real spread after every adjustment.

Check the real spread intact

Inspect all edges, central dialogue and figures on the genuine spread. A single-image view can still require zoom on a small screen; the purpose is to avoid shrinking it further beside a portrait page. Preserve complete compositions and recognise that the threshold organises display rather than source identity or ordering.

Inspect the whitespace-heavy page

Check whether whitespace also triggers single-image display and whether that actually harms reading. A few intact exceptions may be acceptable. If many ordinary pages split unexpectedly, adjust modestly and recheck the true spread. Do not crop source edges merely to satisfy an automatic geometric rule that cannot understand narrative importance.

Recheck pairing after the spread

Read from portrait pairs into the spread and several pairs beyond it, then repeat elsewhere. Inspect source order in single-page mode before adjusting more values if an offset appears. Screen counts can differ, so compare scenes. Manual intact-image viewing remains a valid fallback without global reconfiguration.

Verify the intended scope

Use supported book scope for a scan-specific threshold and check another comic. Verify device scope where useful. Reopen and record the final value, samples and acceptable exceptions. Treat it as an explained choice for this material, not a permanent universal setting for files with different geometry.

Acceptance and rollback

Finish with sensible ordinary pairs, intact single spreads, stable following pairs and understood exceptions. Different files can need different values. If no satisfactory threshold exists, restore the recorded value or disable smart handling and use manual viewing. A clear rollback and unchanged original preserve a reliable reference.
