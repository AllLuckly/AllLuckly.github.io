Make three illustrations sharing one traffic-signal housing, with red, yellow and green respectively shown as lit, reinforced by text and position. A U.S. Manual on Uniform Traffic Control Devices example places red, yellow and green top to bottom in a vertical three-light signal. This exercise adopts that specific arrangement, not every local signal or driving rule. The illustration is not for roadway control or driving decisions.

Define canvas and state list

Create a landscape canvas with space between three equal cards. Each contains a vertical housing, three equal circles and a text label: “Red illustration,” “Yellow illustration” and “Green illustration.” Separate background, housing, lamps, state markers and text into layers and save an editable draft. Choose canvas size for viewing and export, not as an engineering specification. Each state describes which lamp is depicted as lit, not traffic rules or a promised real-world signal sequence.

Build a neutral housing

Draw a vertical dark-gray rounded rectangle with three equal circles along one centerline. Keep even gaps between circles and sufficient space to the housing edge. Fill all three circles with the same dark gray, without highlights for now. At thumbnail size check they remain three separate circles rather than a single capsule. If the installed app offers alignment or distribution controls, use those actually visible; otherwise inspect with guides or manually without assuming menu names.

Duplicate and verify geometry

Duplicate the completed housing and circles into three horizontally arranged groups. Select or inspect layers to confirm each group contains one housing and three circles, with matching housing size, center positions and spacing. If changing one changes every state, check whether you are editing one shared object, then create independent copies if possible; otherwise record the limitation. Save an unlit baseline before creating state copies.

Set each lit lamp

Make only the upper circle bright red in the first group, the middle yellow in the second and the lower green in the third; keep other circles darker versions of their colors or gray. Keep positions fixed and make the brightness distinction visible at normal viewing size. Do not illuminate all three for one of these states or depend on a tiny white highlight as the only indicator. If yellow disappears on a light background, darken the housing or adjust its edge rather than moving its row.

Add text and shape cues

Put the corresponding label below each group. If needed add the same visible marker, such as a small white triangle, next to the lit lamp and move it to the corresponding row in each group. Marker, text and lit position must agree. W3C's use-of-color guidance says color should not be the only visual means of distinguishing information; text, position and marker offer additional cues here. A bitmap containing text is not automatically readable by assistive technology. Use original shapes and text.

Check grayscale and thumbnail views

Export a temporary copy or use an available grayscale preview while retaining the color original. In each group temporarily cover text and color, checking brightness and triangle position; restore text and confirm row, marker and label agree. If all circles look equally bright in grayscale, increase the value difference or strengthen the marker. If text is too small, adjust size and card spacing. This can expose dependence on hue but is not a complete accessibility audit or a replacement for separate text, contrast and reading-order checks.

Check export and editable draft

Save the draft, export a separate image through a control actually visible in your version and open it elsewhere to inspect all housings, lamp positions, labels and edges. If SVG output is available, save another copy and reopen it, trying to select individual circles and text. If merged or rasterized, record actual structure rather than claiming editability from appearance. For missing text check font, file identity and text-layer visibility one condition at a time. Mark unperformed reopening or device steps pending.

Check three-card alignment and export crop

On a separate note record whether the three housings share top and bottom alignment, and inspect the gap between each label and its housing. If the third group is close to the export boundary, move the whole group and its label while preserving the circles inside; do not move only the green circle to fill empty space. Compare the left and right export edges with the draft to ensure labels and markers are not cut off. If grayscale inspection uses an external viewer, record the tool and conditions rather than claiming the application provides a specific simulation.

Complete a comparison table

For each card record lit position, label, marker row and color and grayscale observations. Deliver the image, editable draft and table, keeping unresolved or unobservable checks visible. Do not use the design as roadway engineering, actual signal control or driving guidance, or generalize a regional example to every jurisdiction. No completed physical-device test in VectorPaint is claimed.
