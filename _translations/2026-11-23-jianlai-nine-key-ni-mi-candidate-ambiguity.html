A nine-key layout may label one key with several letters, so the same key groups can correspond to different pinyin. Use “你” and “米” to observe ni and mi: check Jianlai’s actual letter groups first, select the target candidates and verify the body. Candidate contents and order depend on the installed version; neither character is guaranteed to appear simultaneously or in a fixed position.

Prepare an editable practice copy

On your own device, create an ordinary note titled “Nine-key candidates”, add lines A: and B:, and save. Do not test in passwords, real messages or important documents. Confirm Jianlai is installed and its actually available Chinese nine-key layout can be selected in an ordinary field. If the system keyboard is active, nine-key is unavailable or identity is unclear, mark the task pending and stop without changing permissions or uninstalling.

Prepare columns for keyboard identity, key groups, actions, visible pinyin and candidates, selection and body result. Record device, system and app versions and host; do not upload personal input history or dictionaries. Reopen the note to ensure the practice lines persist and copy it if needed so accidental edits remain recoverable.

Inspect the actual letter groups

Inspect Jianlai’s nine-key letters and find n, m and i. Record the actual labels. In the common telephone-key grouping, n and m share MNO and i belongs to GHI, so abstractly ni and mi use the same pair of letter groups. The ITU telephone keypad recommendation describes those groups, but governs telephone layouts; it does not specify Jianlai’s actual layout or candidate algorithm.

If the displayed layout differs, labels are unclear or identity cannot be confirmed, follow the device and pause this mapping comparison. Do not assume the numeric keys must be 6 and 4. “Same pair of letter groups” is not an instruction to dial; do not open the phone dialer or contact anyone. Use the current interface’s actual pinyin selection, candidate, paging and commit controls, not another input method’s rules.

Line A: enter “你”

Place the insertion point after A: and use the nine-key method actually available in Jianlai to try ni. After the relevant groups, inspect visible pinyin, candidates and composition. If ni is identifiable, select it as the interface permits and look for “你”. Do not assume the first candidate is the target or that a screenshot’s order applies to every user.

Select the target and verify that it entered the body. Record the complete A line, actual actions and whether a pinyin selection was involved. If the target is absent, input auto-commits or the state is unclear, record what happened and mark the round incomplete. Do not paste “你” from elsewhere and call it nine-key candidate input or clear dictionaries repeatedly to alter ordering.

Line B: enter “米”

Commit or cancel any remaining A composition before placing the cursor after B:. Inspect the actual groups containing m and i and use the available method to try mi. If m and n do share a group, compare A’s groups with the pinyin choices now visible. Select “米” if found and verify it enters the body; record the B line and selection steps, or mark it incomplete if absent.

No tone key or specific tap count is required, and no candidate-generation mechanism is assumed. If a visible pinyin choice is needed, record the actual action. If another homophone appears, inspect candidates before committing. Personal frequency, version and context may change the display; two trials cannot establish the internal algorithm.

Compare ambiguity and body text

Place A and B letter groups, visible pinyin, chosen candidates and final body side by side. If the groups match but characters differ, this session required additional pinyin or candidate selection; one group pair does not necessarily mean one character. If actions or interfaces differ, do not force the abstract mapping onto them; record the difference.

Reopen the note and verify A:你 and B:米 are on their intended lines; formatting and spaces follow the actual host text. If a different character was chosen, retain the first observation, correct the safe copy with the host’s visible selection or insertion-point controls and check neighboring labels. A correction is not a first-attempt success; record both states separately.

Troubleshoot and restore

If nine-key is missing, check Jianlai identity, language and version. If a candidate is missing, inspect composition, any visible pinyin selection and actual candidates. Change one condition per round, retain a not-found result and do not reset the phone, clear dictionaries or remove other keyboards. Preserve accessibility settings; skip if safe operation is not possible.

Restore your usual keyboard; the user chooses whether to keep or remove the practice copy. Deliver actual key groups, actions, candidates, body text, corrections and unfinished steps. This exercise uses public sources and does not claim a device test. A telephone keypad recommendation does not establish Jianlai’s mapping, and one observation is not universal across layouts or devices.

After changing devices or layouts, record letter groups again before practicing; do not prefill a new device’s candidates or tap counts from an old table.
