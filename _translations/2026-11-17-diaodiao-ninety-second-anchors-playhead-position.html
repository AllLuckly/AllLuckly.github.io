Build a ten-, thirty- and seventy-second map for your own short recording, separating elapsed time, remaining time and the position actually heard.

1. Prepare the ninety-second reference externally

Prepare your own ninety-second recording and verify its duration externally. Place the spoken markers “第一段”, “第二段” and “第三段” near ten, thirty and seventy seconds. Record actual onset positions from the editor/source; a spoken phrase has duration rather than occupying one instant. Preserve source and export with filename and supported format. 调调 supplies playback, not an assumed recorder or marker editor. If an existing file has another duration, build a matching card rather than rename it ninety seconds.

2. Bind the imported item to its reference

Import that sample through the visible file flow, then match title, duration and opening sound after feedback. If identical content already exists, verify that item rather than delete it to defeat duplicate handling. Play normally through the first marker and confirm voice/content before pausing. Ninety seconds belongs to this sample, not every track. Similar artwork or title cannot replace audible identity. If the first marker is already absent in normal playback, inspect the source before using the seek control.

3. Identify timer direction before seeking

The official player screenshot shows a progress region, but infer the installed timer meanings from change. Play a few seconds and observe which value increases, stays at duration or decreases, without automatically calling the right value remaining time. For ninety seconds, ten elapsed leaves eighty, written 0:10 and 1:20. Compare values from the same instant. If only one appears, calculate the other externally and label that provenance. Pause for a second record rather than combine moving readings from different moments. Also distinguish a minute:second colon from decimal minutes: 1:10 is seventy seconds, not the sixty-six seconds represented by 1.1 minutes. 1:30 is ninety seconds. At seventy, twenty remain; reaching the third passage does not complete the track. Keep these conversions beside the card.

4. Seek to a position before the second marker

Use the seek control actually available to approach twenty-five seconds, then listen for the second marker roughly five seconds later. Identify real tap/drag behavior. Without exact time entry, adjust approximately from visible readings and record the actual landing rather than inventing millisecond precision. Pausing can help inspect position, but observe whether seeking resumes automatically and press play if needed. Retain the same file, output and mode. An accidental track change requires returning to the sample, not using another song’s thirty seconds. If the target is twenty-five but the landing is twenty-eight, only roughly two seconds remain before the thirty-second marker. Use the observed landing rather than insist on waiting five. Whole-second readability also requires approximate intervals; manual placement error is not a lyric-source or server timing error.

5. Check one later and one earlier landing

Approach sixty-five seconds and check that the third marker follows, then return near five seconds to check the first. Record target, observed timer and first audible marker for each direction. One successful late marker does not verify every seek position. If landing misses an onset, move earlier and play forward: hearing a phrase ending differs from observing its start. This tests passage location rather than rapid scrubbing across the whole file, and waiting for a later cue is not a measured network buffer.

6. Use fractions as estimates rather than pixel calibration

Ten, thirty and seventy seconds are approximately 11.1%, 33.3% and 77.8% of duration. This exposes mistaking thirty seconds for halfway; the midpoint is forty-five. Fractions are checks, not proof that an entire drawn bar is draggable: margins, hit areas and styles can differ. A centimetre of finger movement is not a fixed number of seconds. Retain time/fraction columns. With a 120-second replacement, thirty seconds becomes one quarter, requiring a new map rather than reuse of today’s screen position. Pause near ten seconds for a while. Wall-clock time continues; record the track position under the actual paused state separately. External elapsed time is not automatically played time. If position still changes, record it and verify whether pausing took effect rather than assume the two clocks coincide.

7. Diagnose a wrong passage separately from silence

For a wrong passage, inspect total duration, timer direction and file edition first. If time advances silently, check whether the source is silent there and inspect the output route. If rapid movement is confusing, stop and return to one known anchor rather than diagnose corruption from one mistouch. Preserve observed readings and short markers instead of copying targets into result fields. Frame-accurate addressing, reverse playback, speed changes and passage bookmarks are not promised; record only available controls.

8. Reopen and deliver the three-row position card

Return from the local item after leaving the player, verify identity and repeat one anchor. Record position restoration separately rather than make exact resume behavior mandatory. Deliver three target/result rows, timer interpretation, time conversion and unchecked positions while preserving the source. Explain the passage reached, the sound/reading supporting that judgment and why ninety minus ten leaves eighty. A changed edition or duration needs a new card; three successful anchors do not certify every second or every device’s seeking precision.
