When rearranging a sentence, seeing a phrase at its destination is not enough. Also check the original location for duplication or omission. Apple describes selecting text and dragging it in some iPhone hosts; actual behavior depends on host and system and is not a proprietary Jianlai gesture. Enter non-sensitive practice text with Jianlai, then move a whole phrase in a copy.

Create two identical practice lines

In an ordinary note on your iPhone, create “Phrase movement practice” and use Jianlai to enter A: 苹果 香蕉 梨 and B: 苹果 香蕉 梨. Leave one ordinary space between words, inspect labels and text, save and reopen. For real writing, create a separate practice copy rather than testing selection on the only original. Do not enter addresses, accounts or private messages.

Operate only on A; B is the original comparison. The goal is to move “香蕉” after “梨”, producing A: 苹果 梨 香蕉, while B remains unchanged. Moving may alter spaces, which must be checked separately; the presence of three words alone is insufficient. Record device, system, Jianlai version and host and confirm you know its visible undo or copy-saving method.

Inspect keyboard and text state

In the ordinary field, confirm Jianlai is active and both lines are committed to the body, not candidates or unfinished pinyin. Inspect the insertion point and ensure the entire line is not accidentally selected. If Jianlai is unavailable, composition remains unfinished or the host cannot edit, record the limitation and stop. Do not call another keyboard or prefilled text a successful Jianlai input.

Prepare a table for the entire line before, selected range, actual move or copy action, A after, B after and correction. Handles, menus and fonts vary by system and host. Apple’s text-editing guide is a system and host reference; it does not guarantee every third-party keyboard offers identical controls or drag support.

Select the complete phrase

Use the host’s actual selection method to select “香蕉” in A and inspect both boundaries. Do not include A:, “苹果” or “梨”; record separately whether a space is included. Inspect the complete selection before acting. Finger position alone does not establish accuracy. If selection is imprecise, cancel and retry on the copy, not a formal document.

If handles are offered, adjust using the actual interface. If accessibility input or the host does not support the selection, use a familiar available method or mark it incomplete. Do not type while the selection remains active, which would replace it. Verify B and A are separate body lines and do not accidentally use B as the destination.

Move using a method the host supports

If the host clearly supports dragging selected text, follow Apple’s system text-editing instructions: touch and hold the selection, observe whether it lifts, move it after “梨” on A and release. This is a system and host operation. Without recognizable dragging feedback, do not force it or claim Jianlai supports the feature. If your finger lifts accidentally or the position is unclear, stop and inspect.

If drag is unavailable, the host’s visible cut and paste can be an alternative: confirm the selection, cut, confirm the target insertion point on A and paste. The clipboard may contain important material; use this only if the user agrees to replace it. Otherwise skip or use confirmed dragging. Record the chosen method, not cut and paste as a single drag. If neither is available, preserve the original and mark incomplete.

Check both original and destination positions

Read the entire A line: is “香蕉” present once at the destination, absent as a duplicate after “苹果”, and are all three fruits present once? Check that B remains B: 苹果 香蕉 梨. Moving may leave or remove spaces; adjust to the target sentence only after recording the actual result. Seeing “香蕉” alone is not proof that the whole task succeeded.

If the result is A: 苹果 香蕉 梨 香蕉, there is a duplicate; inspect whether the action copied instead of moved. If “香蕉” is absent from both places, stop and restore using the saved copy or known undo. Do not repeatedly drag or delete blindly. If host recovery is unclear, B remains a reference, but manually retyping is manual recovery, not system undo.

Save and check restoration

Save the intended practice result and reopen the note, checking order and spaces on both lines. Record whether the selection included a space, the action, actual result and manual cleanup. Preserve an incomplete status if unfinished. Restore the usual keyboard; do not clear the clipboard, reset the phone or uninstall Jianlai for this exercise. The user may retain or delete the practice copy after checking it is not a formal document.

Text movement can vary by host, system, input method and accessibility configuration. Success in one host does not establish the same drag elsewhere. This exercise is based on public documentation and does not claim a device test. Before editing important material, keep a recoverable copy and check both source and destination after each change.
