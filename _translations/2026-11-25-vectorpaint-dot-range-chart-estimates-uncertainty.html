Use one scale for three hypothetical estimates and ranges without treating their endpoints as observations.

Prepare and explain the example

Use three hypothetical estimates: A is 40 with range 35–45; B is 55 with range 50–60; C is 50 with range 42–58, all in points. These numbers are an exercise, not a real survey, and no confidence level or statistical method is claimed. The UK Office for National Statistics describes uncertainty ranges using two bounding values; real publication must explain their provenance and meaning.

Create canvas and data objects

Create a landscape VectorPaint canvas, for example 1600 by 1000 pixels, and save an editable original. Use available object controls to keep the scale, three interval lines, endpoint caps, estimate dots, category labels and explanation separate. Reserve space for title and source. Use the grouping and editing controls actually visible; labels may vary by device.

Set one shared scale

Choose a horizontal scale from 0 to 70 points, for example 100 canvas units for each 10 points. Label 0, 10, 20, 30, 40, 50, 60 and 70, checking equal adjacent spacing. All three ranges use this common scale; do not enlarge C separately or lengths cease to be comparable. Derive dot positions and line endpoints from the same zero point.

Set three category rows

Place A, B and C in equally spaced separate rows aligned with the left-hand labels. Each row has a single horizontal position, with endpoint caps of equal height; their vertical extent does not encode a value. Vertical placement identifies categories, not a second numerical scale. State that explicitly if it could be misunderstood.

Draw A’s range and estimate

On A’s row draw a horizontal line from 35 to 45 on the shared scale, with equal short vertical caps at each end. Place a filled dot at 40. At the example scale the 10-point range spans 100 canvas units. The dot represents the estimate 40, not a third observation inferred from the endpoint style.

Draw B and C

Draw B from 50 to 60 with its dot at 55; draw C from 42 to 58 with its dot at 50. At the example scale B spans 100 units and C spans 160, both positioned using the same horizontal axis. Do not force all three lines to equal length, and do not infer from these symmetric examples that every real range must be symmetric.

Add readable values

Label the rows “40 (35–45),” “55 (50–60)” and “50 (42–58),” explaining that parentheses contain the example range, not three observations. Leave space between labels and endpoints without covering the fine line or dot. Use consistent font size and number formatting; if the axis title gives the unit, explain it consistently rather than attaching units to only one row.

Check positions and proportions

Verify each dot lies inside its range: 40 between 35 and 45, 55 between 50 and 60, and 50 between 42 and 58. C spans 16 points, while A and B span 10 each, so C’s line should be 1.6 times as long. Temporary one-point guide ticks can help check endpoints; hide them afterward and confirm the scale remains legible.

Avoid overinterpreting overlap

A and C overlap from 42 to 45, and B and C overlap from 50 to 58. Overlap alone does not establish whether a difference is statistically significant or give a probability that the values are equal. These examples have no associated statistical method. Real results require the study design, interval definition and appropriate analysis; color or dot placement cannot replace that explanation.

Add title and text alternative

A title can read “Three hypothetical estimates and example ranges (points),” with a note that ranges are exercise inputs rather than survey results. Supply a text description listing every estimate and range so information does not depend on color or vision. If replacing these with confidence intervals, accurately provide their method, level, sample and source, with a plain-language explanation rather than retaining this exercise note.

Troubleshoot and export

If a dot falls outside its range, check the scale and inputs before simply lengthening the line. If endpoint caps resemble a second series, shorten them and clarify the legend. Save the editable original, then use a visible export control to save a separate SVG or PNG. Reopen it to inspect rows, numbers, source and unit for clipping; return to the original and confirm dots and lines remain independently editable. Mark unperformed device steps as pending.

Compare endpoints with estimates

Read each row from its lower endpoint through the dot to its upper endpoint and check that labels have not been swapped. A and B both span 10 despite different positions; C spans 16. Temporarily copy the lines to a common row to compare widths, then return them to separate rows so the three groups are not mistaken for one estimate.

Cross-check against a table

Make a draft table with group, estimate, lower bound and upper bound. Enter A as 40, 35, 45; B as 55, 50, 60; and C as 50, 42, 58. Read the graph back into the table row by row and ensure C’s estimate 50 is not placed at B’s endpoint. Compare the lower endpoints 35 and 50: A and B have equal widths of 10 but do not start at the same position. C’s dot and B’s left endpoint both equal 50 but occur on different rows and have different roles. Retain the table as a text description so readers can check without relying on color.
