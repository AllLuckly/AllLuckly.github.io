Type one short sentence in an ordinary field and separately inspect actual candidates, any identifiable unconfirmed composition, the confirmation and retained document text.

Prepare a private practice sentence

Keep a separate copy of an ordinary note, then reserve a line for “今天见。” Confirm Jianlai is added in system keyboards and is actually selected with an available Chinese input scheme in that field. Record the device, host, app version if visible, layout and controls actually shown. Use an ordinary field rather than a password, secure field or host that declines third-party keyboards; do not change security settings to perform the exercise.

Establish the original document state

Leave the input line empty or place recognizable surrounding context, such as “提示：” before it and “结束” on a separate following line. Keep a backup, return between them and confirm the cursor position. Distinguish existing document text, cursor and any keyboard-area input display. Hosts can show composition differently; record what is actually visible without assuming a separate encoding bar or a universal color or underline convention.

Enter the first portion and observe before confirmation

Using the selected Chinese scheme, enter the code or keys needed for “今天”. Before choosing a candidate, observe whether the interface visibly offers an editable composition, marked text or candidates. Record only what you see. If the scheme commits directly or the host does not distinguish the state, record that no identifiable unconfirmed state was observed. Do not assume space, Return or a particular key has the same role in every scheme. Some hosts display still-editable text in the document position with temporary markings rather than in a separate region, so location alone does not establish commitment. Keep the cursor in place before choosing a candidate in this trial and record the current display. Moving it may commit or change an unconfirmed composition; reserve that observation for a separate trial on a new line.

Choose a candidate and verify committed text

Choose “今天” if actually offered; otherwise continue or revise input using the real scheme, without claiming an unavailable choice. Check whether the characters appear in ordinary document text and remain after moving the cursor. Record candidate appearance, selection and retained text as distinct events. If a longer phrase commits at once, record the actual outcome. Preserve the first result before making corrections.

Complete the sentence and inspect punctuation

Continue with “见”, confirm it using the actual interface and enter the Chinese full stop. Compare committed text with “今天见。” and check surrounding text for omissions or changes. Do not treat a key label or preview as the final document. If a half-width period appears, record it first and correct only a separate copy. Use only controls visible in the selected language mode; different schemes need not offer the same candidates.

Make a recoverable unconfirmed-state control

On a new line, begin another short entry. If an identifiable unconfirmed composition exists, you may move the cursor once in this separate trial and record whether it commits or changes, or cancel or revise it using an actually visible control and observe the document. Record success only when both method and result are observed. If the state or cancellation is unclear, mark this control pending rather than repeatedly deleting document text to simulate it. Check that the already committed target still exists. This does not establish undo behavior in every scheme.

Troubleshoot candidates and document text separately

When the expected candidate is absent, check the selected scheme, encoding and visible candidate range. If a selection yields unexpected document text, record the selection and host feedback, then check cursor placement and host replacement. If correct text later changes, examine subsequent editing or host behavior separately rather than automatically blaming Jianlai. Change one condition per trial and preserve the original. An indistinguishable state is insufficient evidence, not a pass.

Deliver the record and restore the draft

Keep the target, initial document state, description or image of actual input, visible candidate, confirmation action, resulting document and unfinished checks. Remove personal information before sharing. Restore your usual input setup and confirm the backup remains. The public listing describes multilingual input and prediction; actual behavior depends on installed version, scheme and host. No physical-device input or compatibility test is claimed.
