PDF front matter and body can use different numbering. Separate physical order, page labels and printed numbers before checking Book Isle.

Separate three numbering systems

A PDF physical page index is its sequence in the file. Page labels can describe navigation numbers using Roman numerals, decimal numbers or prefixes. Printed footer text is page content. Adobe notes that changing labels does not change visible numbers on the page. Readers can present indices or labels differently; observe Book Isle rather than assuming it accepts every label.

Prepare a safe sample

Choose a five-page PDF you created or are authorized to handle and preserve the original. Ideally it has a cover, two front-matter pages printed i and ii, and body pages printed 1 and 2. If a reliable tool is already available, the owner can set matching page labels on a copy; without it, compare physical indices and printed numbers and mark labels unverified. Do not modify protected documents or overwrite originals.

Draw the sample mapping

Write five rows: physical page 1 cover, 2 front matter i, 3 front matter ii, 4 body 1 and 5 body 2. If the sample differs, record its actual structure rather than imposing this example. Add a column for labels actually shown by a reliable PDF tool, such as cover, i, ii, 1 and 2, and another for printed page content. They can differ; mark missing values unknown.

Check contents and footers

Open the original or working copy in a reliable PDF viewer. Record total physical pages and verify each title and footer. If the cover has no printed number, record none rather than guessing page zero. If a label differs from printed text, preserve both and first confirm the same copy and page; do not edit immediately. Preserve chapter prefixes such as A-1 instead of simplifying them to 1.

Locate pages in Book Isle

Import the authorized copy into Book Isle and use the controls actually offered to turn from cover through front matter to body. At each page record visible Book Isle position, page title and printed footer; mark no indicator as not shown. If the interface displays 4, verify the title to determine whether it refers to the fourth physical page. A number alone does not prove that Book Isle ignores page labels.

Test available navigation

If Book Isle currently offers a page-jump field, record its actual input method and try locating front matter ii and body 1 separately. If Roman input is unsupported, stop and mark unavailable rather than guessing or editing the file. After each jump verify title and footer; accepted input does not establish correct location. Without a jump control, use contents, page turns or a personal ledger for the same check.

Verify the section boundary

At the example transition from front matter ii to body 1, printed numbering switches from Roman to decimal. One simple offset cannot describe the entire document. Check titles on both sides and consecutive physical pages, then record each numbering rule separately. Missing front matter or unnumbered blank pages should remain in the actual file sequence; printed numbering alone does not prove corruption.

Compare existing contents links

If the PDF has clickable contents, use Book Isle’s actual contents entry to open the body and verify title, physical sequence and printed number. Contents links, page labels and printed footers can exist independently; one correct element does not establish the other two. Without linked contents, locate manually by chapter title. Do not claim automatic recognition of scanned page-number images.

Handle differences and citations

If Book Isle and another viewer display different position indicators, first confirm the same file and same physical page, then record each display. A label difference alone does not establish changed text. For a citation retain title, edition, chapter, printed number and any needed physical index. Mark unverified label sources unknown. Do not write reader page 4 as printed page 4 without checking.

Check whether the sample actually has page labels

A printed Roman numeral does not prove that a PDF defines a corresponding page label. A viewer displaying physical page 2 as 2 does not by itself prove labels are absent either. Ask the file owner to inspect label styles and ranges with a reliable tool already available; mark unknown if the tool cannot show them. Work on a copy and do not overwrite the sole original.

If a working copy receives new labels, verify that physical page count and page text are unchanged. Labels describe navigation; they cannot repair missing scans, incorrect order or printed footers. A cover may have no printed footer while the viewer assigns a numeric label: both observations can be true.

A citation can retain the same edition, chapter and visible printed number, with physical index for finding the electronic copy again. Where chapter prefixes repeat a number, retain the full prefix and context. Use a personal short marker for private material rather than sending a full scanned page to unauthorized people.

Restore and hand off

Keep the original PDF and existing Book Isle notes intact. Close the test copy or retain it in personal test materials. The five-row table should contain physical sequence, confirmed labels, visible printed numbers, Book Isle indicator and unperformed items. Based on public documentation, this guide claims no device test and does not guarantee any particular PDF-label navigation in Book Isle.
