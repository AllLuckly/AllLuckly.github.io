Compare a movie edition and an encoding version in an isolated Plex library, then verify actual playback in iCouldPlay.

Separate two terms

Plex calls different resolutions or encodings of the same cut versions, while distinct cuts such as theatrical and director’s cuts are editions. Plex says movie editions require Plex Pass for the server administrator; identifying an edition by filename also requires Plex Media Server 1.28.1 or newer and the non-Legacy Plex Movie agent. This guide tests movies only. Plex separately supports editions of a whole TV show, not individual seasons or episodes through that whole-show feature. iCouldPlay supports Plex, but grouping and choice controls must be observed in the actual client.

Prepare three safe samples

Have an administrator prepare an isolated movie library with self-made or authorized material. Make two copies of the same cut with different encodings or resolutions, plus another cut with a clearly added or removed segment. Keep originals and edit projects outside the library. Record each opening, the time of the difference and actual encoding information; do not infer these properties from filename or extension.

Check account and server prerequisites

In Plex Web the administrator checks server-account Plex Pass status, movie-library type, the non-Legacy Plex Movie agent, and a server version of at least 1.28.1. Without prerequisites or administrator rights, do not change settings to force the test; record that branch as unperformed. Ordinary media playback can be checked separately but does not prove an edition can be created. Use a fictional test title to avoid matching a real movie or changing someone else’s watch status.

Arrange versions of the same cut

First place the two copies of one cut into the isolated folder following Plex movie naming guidance, for example Practice Film (2030) - 1080p.mp4 and Practice Film (2030) - 720p.mp4 in a Practice Film (2030) folder, retaining separate encoding and dimensions records. Extensions must match actual containers; the labels are not proof of dimensions. Labels help people distinguish files but do not change their content; check the openings and difference segment to confirm they are indeed the same cut. After a scan, record whether Plex Web groups them under one movie and what versions are visible. If not, inspect matching and file content first.

Label the different cut as an edition

Follow Plex’s official example to add an edition marker to the other cut’s test file or folder, for example Practice Film (2030) {edition-Extended}.mp4, then scan the isolated test library and wait for completion. The label does not create or validate extra footage; use the recorded difference time to establish that the cut is different. Recognition depends on account prerequisites, server and scan, so do not claim two cards must appear before observing them.

Record states separately on the web

In Plex Web record the version information for same-cut copies, the edition label for the other cut and each item’s watch state. Plex says editions can track watch state separately; identical presentation in iCouldPlay remains an observation to make. If differently labeled items resolve to the same wrong match, inspect actual footage and paths rather than asserting different content from artwork or icons alone.

Avoid losing real-library history through renames

Plex warns that renaming an existing library item’s file to add edition information may make the next scan treat it as a new item without carrying watched status or customized metadata. To preserve a real item’s history, the administrator should read Plex’s recommended web-edit method and back up first. This exercise changes isolated copies only, never bulk-renaming real movies or altering others’ progress.

Identify the actual media in iCouldPlay

Connect iCouldPlay to the same Plex server with an authorized account and open the test movie using whatever entries and version controls the current interface actually shows. Record visible title, labels, duration and opening picture. If another copy can be selected, play to the recorded difference segment to identify the cut. If no selector or edition label appears, record “not shown”; Plex Web availability does not guarantee iCouldPlay support. If the footage is the same, first check whether a different file was actually selected and whether the differing segment was reached; record uncertainty.

Separate labels from watch position

Same-cut versions may be associated with one movie item, while distinct editions can have separate Plex watch states; client behavior requires its own check. Write down the initial test position and use only the test account for brief playback. After switching, record displayed and actual playback position. If synchronization is not observed, leave it unknown instead of rapid repeated switching that overwrites the baseline.

Handle matching and playback differences

If the web view lacks an edition, first check Plex Pass, marker syntax, movie-library scan and actual files. If the web view is correct but iCouldPlay lacks a label, confirm the same account, server and item before recording a UI difference. If playback content is wrong, use opening and difference time to re-identify it instead of changing the conclusion to match the label. Server transcoding, network and client decoding require separate investigation.

Clean up and hand over

The administrator may retain or remove test copies as agreed and confirm real-library files, originals and other users’ states remain unchanged. Record the three sample identities, edit difference, actual encodings, Plex account prerequisites, web observations and actual iCouldPlay behavior; mark unperformed steps. Remove server addresses and private titles before sharing. This guide uses public documentation and claims no private Plex login or device test.
