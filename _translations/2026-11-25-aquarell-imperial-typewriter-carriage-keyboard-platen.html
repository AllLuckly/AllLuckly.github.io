Draw a typewriter from an angled reference, checking key rows, paper direction and the carriage connection.

Identify the reference and permission

Choose a permitted angled photograph of a typewriter and record the creator, source and viewpoint. The Science Museum Group describes the Imperial Model 50 in terms of the roller, carriage and keyboard. Different models do not have identical shapes or mechanisms. This exercise follows visible forms; do not impose museum-object details on a different machine or infer working condition from a photograph.

Set up canvas and layers

Create a landscape Aquarell canvas, for example 1800 by 1400 pixels, and save an editable original. Use available layer controls to separate background, body, roller and carriage, keys, paper and sketch. Leave space at both ends of the carriage rather than touching the canvas edge. Dimensions are suggestions; use the controls actually shown by the installed version.

Block the body and viewpoint

Use light lines for the large front, side and upper surfaces, determining which side is visible. Place the keyboard on the inclined front area and the carriage and roller behind it. Compare width, depth and height before drawing letters. Check that corresponding parallel body edges converge consistently instead of making the front face point one way and the keyboard another.

Place carriage and roller

Compare carriage width with the body and check whether its ends extend beyond it. Draw a left-to-right roller axis first, then its visible contour. The end ellipses of the cylinder should be consistent with the same axis. Seat the carriage on the rear upper part of the machine rather than floating it in the background. Leave obscured levers uncertain instead of inventing them for symmetry.

Plan rows of keys

Mark several guide bands across the inclined keyboard surface. Compare the apparent size, row spacing and side boundaries of near and far keys. Treat each key as a small shape with thickness, following the reference without claiming all vintage machines have the same key count. At thumbnail size check that the keyboard shares one orientation; if a row drifts, fix its guide band before adding highlights individually.

Give keycaps depth

On a separate key layer, block keycaps with a consistent base color, allowing nearby keys to be clearer and distant keys simpler. Use one light source to place a small shadow on one side so caps separate from the keyboard bed; do not give every key a different light direction. Add readable characters only to a few nearby keys if visible. Leave unreadable markings blank rather than inventing inscriptions.

Arrange paper and overlaps

If the reference contains paper, draw the visible sheet behind or above the roller according to the observed entry position. If there is no paper, keep the roller empty. The paper edges should relate to the roller and follow the visible perspective. Stop lines where the sheet is occluded rather than drawing a complete edge through the roller.

Separate metal, housing and background

Use broad value areas to distinguish front, side and upper housing, then add a few narrow highlights to metal levers or knobs. Avoid outlining the entire body with an equally thick black line; adjust local contrast where it meets the background. A soft contact shadow can seat the machine on a table, consistent with the light direction used for keys and body.

Compare silhouette before details

Duplicate the work and hide key letters, metal highlights and paper details to inspect the main body, carriage and keyboard shapes. If the carriage floats, check support and overlaps; if the keyboard resembles a flat board, inspect the perspective of the guide rows. Restore details and compare at thumbnail size, removing marks that obscure the main form. Do not hide structural errors under more characters.

Check key overlaps and carriage width

Choose a front key row in the reference and compare how it overlaps the row behind; complete rear outlines should not show through front keys. Temporarily lighten the key layer to check that the guides still follow the keyboard plane, then restore the color. Compare the carriage ends with the body edges. Their apparent extensions need not match in an angled view, but should agree with the reference and overall orientation. Do not move the roller away from the carriage merely to make the image symmetrical. If the photograph crops an edge, retain the crop or mark the missing part unknown. Record one revision and its result rather than changing body proportions, all keys and lighting together.

Troubleshoot and save

If roller ends do not seem to share an axis, fix the axis and end orientations first. If keys look scattered, revisit the keyboard surface and row guides. Save the editable original, then use a visible export or share control to create a separate PNG or JPEG. Reopen it and inspect carriage ends, paper, keyboard and shadow for clipping. Return to the original to check editable layers and record source permission and unperformed device steps.

Check near and far keys

Compare a near key row with a far row and confirm that both remain on the same inclined plane. If the far row becomes markedly larger, return to the reference and reset the guides rather than rotating individual keycaps randomly to suggest perspective.
