1. What is PhotoKit?

PhotoKit is Apple's library for working with photo-library resources. Previously, we used The AssetsLibrary framework , the Camera and Photos apps changed significantly, adding features such as organizing photos by moments. Meanwhile, AssetsLibrary fell behind, and Apple introduced PhotoKit starting in iOS 8.

2. This article's example

This article introduces basic PhotoKit usage. Here is the result:


I previously wrote a Jianshu article about the photo library using AssetsLibrary, which had some problems too: Selecting multiple photos in Swift that is the article. I recommend using PhotoKit for photo-library management where possible.

Tapping Done in the image above returns the photos through a closure, passing a [PHAsset] array for use. You must also supply the maximum number of selectable photos; I use 4 here.

Using it in a vc takes just one line.

self.zz_presentPhotoVC(4){ (assets) in
              print(assets.count)
}
