Change one location in a saved original draft while retaining target, positioning and neighbouring-text evidence.

1. Preserve the original and one intended change

Preserve original 周三 review v2.1，地点不变。 and specify changing only 三 to 四, leaving everything else intact. This is practice, not a real event. Record the intended change separately from the revision; replacing the whole sentence by pasting is not one-character editing. Version, spaces and punctuation are controls, not opportunities for unsolicited polishing. Begin with committed saved text, not unconfirmed composition, and identify the host document before editing.

2. Attribute positioning to the host

Use the host’s actual cursor/selection tools to locate the target. Apple’s text-editing guidance explains insertion/selection, but hosts differ; no Jianlai arrow keys, trackpad gesture or undo tool is promised. Confirm Jianlai and distinguish an insertion point from a selected passage. If precise positioning is unavailable, practise in a controlled note copy while preserving the original instead of deleting blindly in an important document.

3. Read both neighbours before deletion

Read the preceding 周 and following space/English segment, establishing that the range concerns only 三. With an insertion point, deletion needs the correct side and actual host behaviour; approximate visual proximity is insufficient. Available magnification can assist without changing text. Stop if the range is unclear rather than remove a sentence. A small edit still needs positional evidence; quickly retyping everything would bypass this task’s purpose.

4. Perform one observable deletion

Delete within the verified range and immediately inspect whether only the intended character disappeared while following space/English/version remain. That is an expectation, not a prefilled result. Preserve overdeletion or no change and recover through actual host tools or the original copy. Do not invent an undo shortcut. Repeated presses until the draft looks plausible lose the evidence of each action’s range.

5. Insert the replacement and commit it

Enter 四 at that position, verify/commit its candidate if needed and inspect inserted text. Candidate visibility is not a filled document gap; do not leave while composition is pending. Read from 周 through the English segment for retained order/separation. This is one-character replacement, not translation or automatic date adjustment. Editing practice text does not send a schedule notice or update an account.

6. Recheck four neighbouring regions

Inspect date phrase, English word, version and ending punctuation separately. Seeing 周四 alone does not establish preserved case, spaces or punctuation. Compare with the original without an assumed document-diff exporter; an external record can identify the sole intended change. Record any additional alteration separately instead of silently fixing it and claiming only one character was touched. Edit scope is evidence, not an inference from a similar-looking final sentence.

7. Diagnose positioning, deletion and commitment

For deletion at the wrong location, inspect cursor/range; for a wrong replacement, inspect candidates; for an old result after leaving, inspect saving or copy identity. These are not all unsupported revision. Restore one condition while retaining original, target, before/after and version rather than reset theme/system language. Incomplete positioning remains incomplete and can continue in a safe copy. Unperformed undo, cloud synchronisation or cross-device recovery receives no credit.

8. Reopen and deliver evidence of the single change

Save, leave and reopen the identified revision, checking target and all four regions while retaining the original. Deliver actual positioning, deletion, insertion, unexpected changes and final state, not merely the two target characters. Recheck scope after material/host/layout changes. This is a repeatable single-location document revision, not automatic proofreading, system-date modification or certification of editing on every device. Unknown steps remain pending.
