When reading a PDF in Book Isle, a mark already on a page, an external PDF copy and a new reader note may be different objects. Saving a reader note does not by itself establish that the original PDF changed. Likewise, a mark visible in a system tool is not guaranteed to appear identically in Book Isle. Use one self-made single-page sample to check the three separately while preserving the original. No purchase or sharing of private notes is needed.

Prepare an original and independent copy

Make or choose a one-page PDF you own and may edit and copy, containing an identifiable sentence such as “Spring observation.” Record its name, page count, a page location and the original’s location. Do not use contracts, identity documents, other people’s annotations or private work. Save two copies: an untouched baseline and a working copy for system markup. Make their names and locations distinct so the sole original cannot be overwritten accidentally.

Book Isle publicly lists PDF reading, bookmarks, notes, highlights and private sync, but availability can depend on format, version and page. Use controls actually visible on the device. This exercise does not assume Book Isle edits the source PDF or writes reader data to a particular path by default.

Prepare an identifiable mark in a system tool

Open the working copy in a PDF viewer and markup tool actually supported by your device. Apple’s Preview or Notes can annotate PDFs in supported environments. On the identifiable page draw a small circle or brief mark in blank space without obscuring text, then save the copy using the tool’s actual interface. If no entry appears, the file is read-only or the user does not want to modify it, keep the step incomplete. Do not change original permissions or download unknown tools.

Exit and reopen the system copy; check page count, text and circle position, recording tool and feedback. If absent, check whether it was saved to another copy. A mark momentarily drawn on screen is not proof of persistent saving. The circle is a user-added visible page mark, not a claim about a specific PDF annotation subtype or universal editability.

Import into Book Isle and inspect the page

Open Book Isle and use the actual local import entry to select the verified working copy. If a duplicate is reported, record feedback and identify the existing shelf item without deleting books. On the same page use both sentence and location to confirm the file, then observe whether the system circle is visible in the same place. If blank or loading fails, separately record system readability, import feedback and reader display; do not immediately blame the mark.

Import success does not guarantee identical display of all PDF marks, transparency or external annotations. If the circle is missing, first check whether the marked copy or untouched baseline was selected, then record location and version. Do not begin by reinstalling, clearing the library or changing the sole original. Leave page observation pending if not performed.

Create a reader record in Book Isle

Using a note, bookmark or highlight entry actually offered and applicable to this PDF, select an identifiable short phrase or page position and create a nonprivate practice record such as “review this sentence.” If text cannot be selected or an entry is absent, use an available bookmark or mark the task incomplete. Do not assume every scanned PDF has selectable text or invent a required control.

Record visible before and after feedback, source location and the reader record’s content. A mark in Book Isle does not establish that the original PDF was rewritten. If the user can safely inspect an explicitly exported PDF or reading data, compare them separately; do not guess the internal file structure. The system circle and reader note may look similar but have different origins and should be named separately.

Reopen and compare each state

Return to the shelf and reopen the same PDF item in Book Isle. Use page number and sample sentence to establish position. Record whether the system circle appears, whether the reader practice record is still findable and whether text changed. If screen size or reading settings changed the view, use the page and sentence rather than screen pixels as the sole anchor. A reopening observation does not prove that every annotation synced to another device.

Then open the previously saved working copy in the original system tool and compare the original circle and text. Do not assume the new Book Isle note will appear there, or that identical-looking titles identify the same file. If an explicit export exists, save it separately with its source labeled and inspect page count, visible marks and actual records; otherwise mark export untested.

Troubleshoot display, saving and data boundaries

If the system copy lacks the circle, check its save destination first. If it has the circle but Book Isle does not display it, confirm the same copy was imported and record view, page and format. If a reader note is missing, check book identity, current filters and whether it was committed. If remote sync is involved, separately inspect membership, network and the user’s configured WebDAV state. Change one condition per round. Do not delete the only original, reset sync or clear other notes.

Apple documents PDF markup in Preview and Book Isle publicly describes reader records, but those facts do not establish that any mark can be edited bidirectionally between them. Seeing the circle proves only its visibility in this observation, not its object type, editability or cross-device persistence. Support can use redacted file structure, versions and steps; private pages and account information need not be sent.

Preserve the result and restore

Deliver four rows for the original PDF, system-marked copy, Book Isle page display and reader practice record, including reopening results and pending items. The user decides whether to keep the sample and note. Before removal confirm originals and backups are safe; keep them when uncertain. Restore the user’s display and reading settings. This public-source exercise claims no PDF, system-tool or Book Isle device test.
