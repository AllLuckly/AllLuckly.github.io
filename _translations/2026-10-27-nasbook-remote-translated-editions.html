Same-title remote entries can contain different translations, revisions or mismatched files. Verify their actual text before reusing citations or positions. This workflow identifies translations and a chosen reading copy, distinct from format grouping or automatic translation-quality judgement.

Keep candidates independently identified

Label candidates A/B with source, displayed metadata and format, keeping them separate. Mark missing edition fields unknown rather than guessing from cover style. Retain necessary provenance without credentials or temporary private links so later mismatches remain attributable.

Check translator against publication information

Inspect copyright/publication pages and translator notes in the actual file. The cover’s original author alone is insufficient. Use visual checking for scans without assuming full indexing. Record discrepancies before citing remote metadata and verify formal bibliographic details against the actual edition.

Compare the same passage

Compare a recognisable passage from the same chapter, not a preface against story text. Inspect contents and extras too. Different wording establishes different text, not automatically inferior translation. Keep brief edition-specific anchors for future location and citation without copying long sections.

Choose a primary edition and label alternatives

Choose a primary edition for a stated personal purpose and label the other as comparison. Use actual shelf/metadata controls or an external list without inventing a translator-comparison view. Preserve provenance and verify later downloads. Establish identity before recording notes and quotations.

Relocate by text or scene

Use chapter, scene and edition-aware wording to find the equivalent position. Different translations may require names or topics instead of exact phrase search. Do not copy page numbers or percentages. Verify context, create a new anchor and retain the old edition reference; reread earlier if uncertain.

Attach edition to citations and notes

Confirm notes attach to the current file and identify edition-specific observations. Separate both quotations from analysis rather than merging unattributed wording. Reopen exports to check source context, adding bibliographic details externally where the format omits them. Vocabulary differences do not alone establish changed author intent.

Correct mismatches at the source layer

Report item and expected/actual publication information, correcting only through an authorised source process. A local rename is not a server repair. Recheck the same sample before acquiring another copy, keeping a working original. Updated metadata does not prove that an existing local file was replaced.

Acceptance and uncertainty

Finish with distinct identities, verified translator/text evidence, chosen roles and traceable positions/citations. A cover is insufficient and no automatic best-translation selection is assumed. Retain unknowns and avoid whole-book quality claims from one passage; reliable identification is already a useful result.
