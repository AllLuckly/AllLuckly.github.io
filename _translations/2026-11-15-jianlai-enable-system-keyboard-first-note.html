3. Add the keyboard in system settings

Following Apple’s system instructions, open Settings, General, Keyboard, Keyboards, then Add New Keyboard, and identify the installed Jianlai entry. 4. Handle additional permissions separately

Read any permission explanation actually shown and distinguish adding the keyboard from an additional access switch. Check a particular appearance or feedback capability against the installed instructions and your own choice. Toggling every permission repeatedly is not a meaningful setup check. 5. Select Jianlai in the note

Return to the note, focus its ordinary editor and select Jianlai using the system’s visible globe or keyboard-switching control. Identify the current layout or label, then type a short practice passage. Distinguish candidates from text actually inserted into the note. 6. Complete an input-and-edit loop

7. Diagnose installation, enabling and input separately

Secure fields returning to the system keyboard are a separate boundary covered later; real passwords, accounts and payment information are not test material.

8. Save the first-enablement record

Confirm that you can return to the original system keyboard and locate the practice note. Save version, enabled-list entry, actual selection and input result.
