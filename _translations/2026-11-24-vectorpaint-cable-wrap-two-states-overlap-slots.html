Create an illustrative two-state cable-wrap card and inspect the card, loops and slot overlaps.

Define the illustration

Draw a fictional cable-wrap card as a flat diagram: the first panel shows the empty card and the second shows one cable looped around its middle with two retaining slots. The exercise concerns overlaps and explanation, not bend-radius, load or safety guidance. Follow the cable maker’s instructions for actual handling. Use a made-up title rather than a real brand or model when sharing.

Create canvas and layers

Create a landscape canvas in VectorPaint and save an editable original. Divide the composition into left and right panels, leaving room for a title and brief labels. Use available layers for sketch, card, cable and text so the stacking can be inspected. Panels drawn on one canvas are not separate pages; if two files are needed, crop copies later and recheck them.

Draw a reusable empty card

Use public shape and pen tools to make a card with a slightly narrower middle, indicating one inward slot at each side in the outline. Start with a light fill and dark stroke, then shrink the view to see whether both slots remain visible. Duplicate the card into the second panel and keep the empty version. Do not combine both panels into one path that cannot be edited independently.

Label both slots

Use short callout lines on the left to identify the left and right slots; check that each line ends at its intended notch. A drawn slot is not a cutting specification. Making a physical object requires separate material and cable checks, not dimensions inferred from a screen image. Hide labels temporarily and see whether the silhouette still distinguishes both sides; adjust spacing if the notches overlap.

Draw loops in the second panel

Keep the second card beneath the cable and use several parallel curved paths to suggest loops. Extend their ends according to one consistent wrapping route instead of drawing unrelated floating rings. Start with one color and equal stroke width, leaving gaps between adjacent strokes. Here the stroke thickness is a visual choice, not the real cable diameter or safe bend radius.

Check front and back paths

Choose a transition where the cable passes from behind the card to the front: show the front segment above the card and hide the rear segment behind it. Split the illustration into front and rear object groups if useful, controlling visibility by layer order rather than expecting automatic three-dimensional inference. Trace the route with a finger or stylus; when a line stops, decide whether the card hides it or the segment was omitted.

Connect start and end

Lead two short end segments to their respective slots so the beginning and final retention are distinguishable; do not draw a branded connector. If the ends cross confusingly, adjust their paths without moving the notches. Add different numbers or shapes for start and end, then preview in one color. Avoid red and green as the only distinction. Use arrows only for sequence, without implying instructions for powered connections.

Add short labels

Use the text tool to label the panels “empty card” and “wrapped illustration,” with one or two sentences describing the observation sequence below. Preserve spacing between type and card before adding decoration. If long text wraps into the notches or loops, shorten it or adjust the layout. For a web page, follow W3C guidance by describing the state change and important overlap in alternative text; “image” alone does not explain the diagram.

Check small and in monochrome

Shrink to the intended display size and check the empty notches, spaces between loops, end markers and panel labels. Temporarily use light and dark grays or save a monochrome copy to check the front-back route. Treat that copy as a proof and keep the color original. If loops form a dark mass, reduce their number or increase spacing before adding even thinner strokes.

Troubleshoot, save and export

If the cable seems to pass through the card without a front-back change, inspect object order and separate front and rear segments. If the panel silhouettes differ, check for accidental scaling after duplication. Confirm visibility and absence of real personal details, save the original and export a separate SVG, PDF or PNG using an available control. Reopen the output to inspect labels, arrows, loops and cropping; bitmap output does not retain editable paths. Record print or fabrication steps not actually performed.

Match explanation to the image

As a suggested reading check, ask someone unfamiliar with the sketch to describe the two panels and identify the empty card, loops and both slots; do not claim this was performed. If their reading differs from the intended explanation, check whether arrows, markers and cable ends connect before shortening the text. Keep a graphics-only copy to inspect reliance on labels, then restore the labels and alternative description and save the final copy. When inspecting both notches, check whether the callout lines cover them: move each line outside the card while retaining a clear endpoint and check again at small size. If card and cable colors are close, adjust value or stroke width before changing the depicted route. Keep the initial sketch for comparison.
