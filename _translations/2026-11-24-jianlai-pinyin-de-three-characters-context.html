One Pinyin sequence can offer several characters. A candidate is not yet committed text. Type three original phrases in 键来, check 的, 地 and 得 in context, and verify the complete committed lines without assuming a fixed candidate order.

Set up a private-data-free practice note

Open an ordinary note and create a page; avoid password fields, chats and real contact information. Write the targets on paper or a second screen: 明亮的灯, 认真地画, 画得很细. They describe a thing, a manner of action and the result of an action respectively. These teaching examples do not cover every complex use. Keep the practice area blank instead of copying the answers into it.

Confirm 键来 is enabled using the actual system keyboard list, return to the note and switch to it. Check that the cursor is on the first blank line, not in the title or system search. If a host does not show third-party keyboards, use an ordinary note and record the host difference; extra permissions are not needed merely for this exercise.

Separate the three relationships

Identify the parts before typing: 明亮 describes 灯; 认真 describes how to 画; 画得很细 expresses the degree of the action. Do not guess solely from a following verb or preceding adjective: real syntax has exceptions. The exercise checks only three clear phrases, and a short mnemonic is not a complete grammar.

Make a table for target phrase, target character found among candidates, committed text and result. Leave the candidate column blank until observed. Dictionaries, context and versions may change ordering; do not fill in a candidate number in advance or call a different ordering a defect.

Enter the first line

Choose an available Chinese Pinyin layout in 键来. Type 明亮, then the Pinyin for the target character and inspect the candidates. Explicitly select 的 and then enter 灯. If the entire phrase appears, check every character before accepting it. If the interface differs or the desired candidate is missing, record the Pinyin and actual feedback rather than inventing a required button.

Confirm that 明亮的灯 is committed in the note, not still waiting in the candidate area. Move to the end and check for extra punctuation or spaces. If 地 was selected by mistake, repair that practice line and check again; there is no need to erase the page or change dictionary settings.

Enter the second line

Start a new line, type 认真, select 地 using its Pinyin, and then enter 画. Read the phrase and verify the four characters individually. Here 地 connects the manner with the action. The interface may offer a phrase or require individual selections; record what actually happened rather than treating one observation as proof of a prediction feature.

If a selection is wrong, do not assume the body changed while a candidate remains uncommitted. Inspect the cursor and pending composition, then use an actual deletion or selection control to fix it. Identify the target before deleting to avoid damaging the completed first line; reread the second line afterward.

Enter the third line

On the third line enter 画, select 得 at the intended position, and enter 很细. Verify 画得很细 rather than the similarly pronounced 画的很细. Circle 的, 地 and 得 in the handwritten ledger and match each to the committed line on screen.

If the Pinyin does not produce the expected candidate, check the Chinese layout, insertion point, spelling and whether a composition is still pending. Clear only the current uncommitted input and retry character by character. Do not attribute failure to network access or permissions without actual evidence.

Review whole phrases, not isolated characters

Hide the candidate ledger temporarily and read the three committed lines: the lamp is bright, the drawing action is careful, and the result is very fine. Compare each character and its order with the paper target, including line endings. If glyphs are hard to see, enlarge the note or use a readable display; a single font shape alone is not proof of character identity.

For an incorrect line, record the candidate action and correction actually observed rather than inventing an autocorrection history. Reopen the note to check its saved result. If extra whitespace or punctuation appears, investigate whether the line break or host input introduced it, correct that separately, and reread all three phrases.

Check the scope of one replacement

Select one committed target character and verify that only that character is highlighted before entering the same one again in 键来. If the selection extends to an adjacent word, cancel and select again rather than replacing the sentence. Check that neighboring words and the three-line order remain intact. This tests selection scope; it cannot establish stable candidate ordering.

Keep the result and its limits

Keep the note as a personal practice record if useful, noting the 键来 version, layout and whether the target candidates actually appeared. Candidate order can vary with context and settings, so the exercise does not guarantee identical ordering on all devices. Mark unperformed switches, network conditions and accessibility checks pending; no physical-device test is claimed. The exercise does not authorize handling private text.
