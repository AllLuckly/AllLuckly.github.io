A reference index lists discussions of a term without necessarily identifying the most useful explanation. Practise moving between an owned indexed reference, its text and notes in Book Isle. Confirm edition and numbering before interpreting layout differences as an index failure.

Choose a matching edition with an actual index

Use an authorised reference with a genuine index and verify edition, format and coverage. Contents and indexes serve different purposes; an index may simply be pages near the end rather than navigation-panel entries. Retain the original and a distinctive test term. Do not apply another edition’s printed index without qualification.

Record every reference for one entry

Record the full term, subentries, all page references and any see/see-also links. Follow cross-references before deciding their meaning. Use a simple personal list rather than assuming automatic semantic index interpretation. Verify one complete entry first before scaling to many terms.

Distinguish file pages from printed pages

Compare printed and file numbering on a known PDF page, allowing for covers, front matter and later numbering changes. Verify actual content after jumping. Reflowable EPUB screen pages vary with settings; use chapters, quotations or genuine file links rather than demanding identical screen and printed page numbers.

Evaluate the indexed discussion in context

Read headings and surrounding text to distinguish definitions, examples, exceptions and unrelated homonyms. Compare multiple indexed references for the current task and inspect relevant figures/notes. For an unrelated page, verify edition, numbering and transcription before suspecting the index or reimporting the book.

Save verified locations through bookmarks or notes

Save and reopen a verified bookmark. Where text selection is supported, note term, chapter, printed page and discussion purpose; use an external list for image-only pages. This preserves a reference rather than rebuilding the index. Include useful context and a short quotation instead of an uninformative “important” label.

Use full-text search as a separate cross-check

Search a visible term within the available scope and compare results. Editorial indexes and full-text matches need not have equal counts. Image-only scans may lack searchable text. Keep file and scope fixed and do not alter source text to force a match. Treat index, contents and search as complementary paths.

Return to the original entry to finish the check

Reopen the note, verify text and return to the index to mark each reference as identified or unresolved. Keep a readable record with edition, term and quotation. Check book-file availability separately from reading-data sync across devices. Complete one full round trip before expanding the list.

Diagnose wrong jumps through edition and numbering

Check front matter, inserted pages or numbering resets for PDF offsets. For EPUB reflow, use chapters and text. Verify edition and converted-copy identity before deleting notes. Document genuine source-index errors as personal corrections, not original book content. Retain clear evidence for every confirmed or unresolved reference.
