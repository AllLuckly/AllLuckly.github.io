When entering “Tidy the desk on Friday” in Reminders with Jianlai, time words in the text and the date actually set on the reminder are separate facts. Apple permits dates and times on supported reminder accounts; a host may also show a suggestion while typing. Use a fictional task to check title, note and date settings separately. This exercise does not create a real work reminder or assume Jianlai schedules notifications for you.

Prepare a separate test item

Open Reminders on iPhone, choose a test list you are authorized to edit, confirm Jianlai is enabled in system keyboards and select an actually visible input mode. If no suitable list exists, create a dedicated test list using the host's available controls; if the account does not support the feature, mark not tested. Do not use a shared work list or real personal information. Record device, system, account type and keyboard layout, and later clean up only items clearly belonging to this exercise. A shared list could expose even a test item to others, so use an independent private test list. If you cannot create or choose one, stop; there is no need to send anyone test content.

Enter a fictional title

Create an item and use Jianlai to enter “Tidy the desk on Friday”. Confirm the complete text is in the item title, not an unconfirmed candidate or another field. This is practice, not a real plan. Do not select an automatically appearing date suggestion yet. Record whether the host shows one: yes, no or uncertain. A missing suggestion is not a Jianlai fault, and a suggestion does not establish that a notification was scheduled.

Inspect title and date separately

Open the test item's details and inspect the title and date/time state as actually displayed. If the host automatically recognized and set a date, record that and clear the test date through the current interface, confirming no unintended reminder remains. If none is set, record that. Do not infer a scheduled date merely because “Friday” appears in the title, or infer detail state from keyboard appearance.

Add a fictional note

If the account provides a note field, enter “Practice only; no notification needed” using Jianlai. Return to details and check that the note belongs to this item, the title is unchanged and date state remains as confirmed. If the note entry is missing or not editable, mark not tested; do not write somewhere else and claim success. Title, note and system date use different controls. Identify focus before typing so the note is not appended to the title.

Set a date under controlled conditions

If you choose to inspect the date control, use the actual Reminders interface to choose a future date that will not arrive immediately. If time is a separate setting, record whether it was set rather than assuming a date has a specific time. Inspect details to confirm the actual date. If date and time are separate switches or fields, record both; a date does not prove a time was set. If the full date cannot be identified or confirmed future, cancel the choice and mark unconfirmed rather than guessing from relative wording. Apple says account support varies. If the control is unavailable, skip this step without changing account security or forcing synchronization. The exercise does not require waiting for a notification or receiving a real reminder.

Compare three separate facts

Keep a column each for title, note and date: whether the fictional title is displayed, whether the fictional note appears and which date the interface actually shows. If “Friday” in the text and selected calendar date differ, record that difference. The word in a title does not establish the calendar value. If date format or time zone is uncertain, inspect information provided by the device and host rather than guessing from language, and do not use a demonstration date for a real schedule.

Clear the test date and check again

If you set a date or the host recognized one automatically, return to this test item's details, clear date and time using the actual interface, then inspect whether a scheduled value remains. Do not assume removing “Friday” from the title also clears the date. If clearing cannot be confirmed, stop, retain the item identity and consult host instructions; do not alter other items. Clearing a date does not mean deleting the item or changing notification permission.

Check focus and host suggestions

If a note landed in the title, preserve the test record, reposition in the note field and correct locally; do not overwrite existing reminders. If a date suggestion appeared, record whether you explicitly selected it, the actual detail result and clearing result. Do not attribute the suggestion to Jianlai or assert it was adopted. Untriggered notifications, unexecuted steps and uncertain fields must be recorded as unknown rather than invented for a complete table.

Restore and finish

After confirming the test date is clear, keep or delete this test item and dedicated test list as you choose. Verify name and list before acting to avoid removing another person's or an existing item. Restore the previous keyboard selection; no notification or account-security setting needs changing. The record contains only the fictional title, device version and actual observations, not private plans. This guide uses Apple's public documentation and does not claim a step-by-step test on a personal device.
