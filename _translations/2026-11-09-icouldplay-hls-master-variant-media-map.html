An M3U8 entry point can list alternative variants or directly list media segments. Calling both layers a video file makes it difficult to determine what was saved and what the player read. First map a playlist hierarchy in external text, then watch your own legitimate source in iCouldPlay. This task does not require a bitrate menu or claim that visual sharpness reveals the selected variant.

Identify the playlist layer before playback

Open a playlist copy you are authorized to inspect as read-only plain text and note its source and retrieval time. STREAM-INF followed by another M3U8 expresses a different relationship from EXTINF followed by a media segment. Do not merge these layers because they share an extension, or treat a webpage’s play entry point as an independent media file. For real playlists with temporary parameters, retain only necessary identity information in controlled notes and do not publish full authorized links.

Build an original two-variant example

This example teaches structure only. No real media accompanies its paths, so it is not a playable package. Pair each STREAM-INF line with its following URI. The first points into the low directory and the second into high; do not attach both tags to the final line.

#EXTM3U
#EXT-X-STREAM-INF:BANDWIDTH=900000,RESOLUTION=640x360
low/index.m3u8
#EXT-X-STREAM-INF:BANDWIDTH=2400000,RESOLUTION=1280x720
high/index.m3u8

Keep bandwidth and resolution separate

Under RFC 8216 variant stream definitions, BANDWIDTH is in bits per second. The example’s 900000 is not a file size of 900000 bytes. RESOLUTION provides display resolution information for the video variant. Copy original values before interpreting them; “high” and “low” are not substitutes for data. Greater bandwidth or resolution alone cannot prove better image quality because encoding, content and delivery can differ. The table records only what the playlist declares.

Follow one variant to its media segments

From your own source, choose one readable child playlist and map its EXTINF entries to segment URIs, recording durations separately. Initialization sections, separate audio, keys or other requirements are additional dependencies; do not delete them and call the result complete. This exercise requires no encrypted-content downloads or permission changes. Stop at the relationship inventory if dependencies are unclear. Two variants do not mean “play low, then high” as consecutive scenes. Read temporal order from the selected media playlist.

Record only controls actually visible in iCouldPlay

Open a real entry point through a currently supported source and play to a section of your own clip containing text or detail. Record playback and any visible quality controls. If no bitrate selector is present, mark it unavailable instead of searching for a hidden button required by the teaching example. If options exist, copy their displayed values and observation times without inferring the corresponding network requests. One working selection does not prove every candidate works; leave unchecked paths untested.

Separate perceived changes from variant identity

If a section looks sharper or softer, note its content position, whether a seek just occurred and the network conditions; do not immediately assert an automatic bitrate switch. Scaling, motion, blur already in the source and post-buffering display can affect perception. Associate a specific variant only with trustworthy service records or explicit UI evidence; otherwise leave it undecided. Keep orientation and display mode fixed during comparison, and avoid changing source, captions and device simultaneously.

Preserve hierarchy evidence when one variant fails

If the master loads but a child path fails, record master access, child status, segment availability and playback separately. A working alternative does not erase the failed result, and a directory permission issue does not establish that HLS as a whole is unsupported. Resolve addresses against their real base using the earlier URI guide, then let the source maintainer check expiry, redirects and dependencies. Do not submit credential-bearing child URLs to public tools or edit a production playlist to force a selection.

Add audio-group relationships when present

If the real master also has MEDIA tags, check whether TYPE is AUDIO, then match GROUP-ID to the variant’s AUDIO attribute. External audio entries are not additional video quality levels. An audio declaration without an external URI is not automatically missing: check whether the playlist indicates carriage within the video variant. Names can be display labels, so confirm language and purpose by listening. Mark unavailable audio unconfirmed rather than labeling a commentary track as the main dialogue.

Keep a traceable variant map

Draw the master entry branching to two candidate variants, then to their media playlists and dependencies. Mark only inspected nodes confirmed. Saving a playlist is not saving all media segments and does not prove offline playback. Attach the iCouldPlay observations separately, distinguishing text evidence from UI evidence. If the source updates or addresses expire, inspect a newly dated copy. Preserve old screenshots and playlists with their original dates instead of relabeling them as current evidence.
