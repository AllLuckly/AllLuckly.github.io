Start by checking whether your thumb reliably reaches the intended button, then whether controls cover the game. Yearn's controller settings include size and transparency. This guide compares them in the same game menu instead of proposing one set of values for every phone.

Use a consistent grip before adjusting

Choose a game that starts successfully and stop at a menu that does not require continuous reactions. Hold the phone normally: two-handed landscape and one-handed portrait place your fingers differently, and testing on a table does not fully represent handheld use. Keep the default size first, test all four directions and two common action buttons, and note where accidental presses happen most easily.

If a physical controller is connected, disconnect it first and see whether virtual buttons return. External-controller connection can affect on-screen controls. Do not mistake hidden controls for a transparency setting that made them invisible. Preparation only requires a stable set of touch controls; there is no need to change skins and aspect ratio simultaneously.

Start with a small size change

Return to Settings, open the controller page and find the size slider in the virtual-controller section. It offers scaling within a range, plus Compact, Default and Large presets. Starting from the default, move one step in one direction, return to the same game scene and repeat the button actions.

Larger buttons make targets easier to find but may reduce space around the picture. Smaller buttons look cleaner without necessarily making moving inputs easier. Judge accidental presses and grip comfort rather than assuming a larger control looks more professional. To reposition the entire layout, check the controls actually offered by the current skin and interface. A size slider does not mean every button can be freely dragged.

Use transparency to keep buttons recognizable

When adjusting transparency, use a game scene containing both light and dark areas. Buttons clear against a black menu can disappear over a light scene. Start with fairly high opacity to keep them visible, then reduce it slightly after learning their positions.

After every change, check that directional outlines, action-button letters and Menu remain recognizable. Fainter controls do not enlarge the actual game picture; they only change the visibility of the overlay. To see more of the image, examine orientation and game scaling next rather than continually changing button transparency.

Test directions and action buttons separately

Test up, down, left and right first, then diagonal movement. A game may accept only four directions or may not accept diagonals in its current menu, so test in a scene with a movable character. Hold a direction and move your finger slightly to see whether it easily touches Menu or another function button by accident.

Check an action button with a brief action such as confirm, jump or back. If the game needs simultaneous presses, verify each button separately before combining them. When a combination fails, note the two buttons, phone orientation and scene rather than immediately resetting every size to another extreme.

Check haptic feedback separately

General settings include haptic feedback, and related switches may also appear on the controller page. Compare enabled and disabled feedback on a device that supports it before deciding whether you want the cue. iPads and different iPhones have different hardware capabilities. No vibration does not mean a button failed to send input to the game.

Haptics help confirm that a touch occurred, but the game's actual action remains the input result. If feedback is distracting or tiring during longer use, turn it off and test whether you can still operate accurately. When the sensation differs, compare device hardware and system settings before deciding whether the input actually worked.

Allow a test round for each orientation

After testing portrait mode, rotate the device and compare the controls with the game picture in landscape. The wider orientation changes where your thumbs land; a size comfortable in portrait can feel cramped in landscape. Stop at a safe menu before rotating rather than changing grip during an important action.

Record preferences such as default size in landscape with clearly visible buttons, or one step smaller in portrait. Every slider value need not become a standard answer. If the current interface saves only one configuration, use your more common orientation as the baseline and accommodate the other by changing grip or making temporary adjustments.

Questions and check results

Why do I still press the wrong button when the buttons are large? Your thumb's natural landing position may not match the button, or the skin's shape and game artwork may make the target difficult to distinguish. Return to the default appearance for comparison, then change only one size parameter.

What if controls still cover the picture after adjusting transparency? Transparent buttons still occupy touch areas. Try landscape, a slightly smaller game picture or a paired physical controller, checking the control and visual results separately.

Aim for settings that reliably support directions, confirm, back and pause in your usual orientation. Small, comparable changes make a suitable combination easier to find than repeatedly switching every preset.
