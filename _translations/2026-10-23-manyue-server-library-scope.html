After connecting a home Komga server, another NAS, and a Suwayomi library, similar covers and same-named works may appear on the library home page. ManYue can manage display scope by connection. This guide aims to make the source of each comic and the copy you intend to read clear in the list.

Give connections recognizable names

First open “Library” → “Manage Libraries” and review existing connection names, types, and status. Replace vague labels such as “Server One” or “My Comics” with names describing location or use, such as “Home Komga” or “Tablet Test NAS.” Renaming is for recognition; there is no need to change the address or account with the name.

One service type can have multiple connections, and identical types do not mean shared content. Two servers may even use the same internal numeric ID for different works. Do not judge duplicates from covers and titles alone, or remove a connection first to “deduplicate.” Record each connection's actual purpose before choosing its display scope.

Filter the combined library by source

Return to the library, open filters, and select just one source connection. Check that the results belong to that server, then switch to another for comparison. Distinguish same-named works using source, chapters, and local-download status. If the interface combines source, group, and reading-status filters, change one condition at a time so an empty result remains explainable.

A connection's own browsing page should be scoped to that connection. Clearing filters does not automatically search every server. Check the page title and context before deciding whether “All” means the whole site, the current connection, or the current group. This habit reduces mistaken impressions that a work suddenly disappeared.

Choose All Books or Only My Comics

In Manage Libraries, if a connection offers inclusion scopes such as “All Books” and “Only My Comics,” choose according to your use. All Books suits browsing a private server as a complete catalog. Only My Comics suits showing items you have favorited, followed, read, or downloaded on the daily home screen. Test one connection first rather than changing every source at once.

After changing the scope, return to the library to observe the count, then enter the service catalog to confirm that the full library remains browsable. This setting changes aggregate display scope rather than deleting server content; fewer home-screen covers do not automatically free file storage. To read a work not yet included, open it from the relevant service catalog, then favorite or read it as needed.

Use one same-named sample to confirm identity

Find a work present in two connections and open each detail page, comparing source, volume, and chapters. One may be a collected volume and the other a serialized scan edition. Even with the same title, covers, extras, and page order may differ. Retaining separate identities avoids applying one copy's reading position to the other.

Read one copy to a specific page, then return to the library and confirm which connection its Continue Reading entry belongs to. Do not resume from another copy simply because its cover looks similar. Before manually associating editions, verify the content and current feature scope carefully. If both editions serve a purpose, retain them separately and label their sources; fewer cards alone is not a reason to merge them.

Check favorites and offline content after changing scope

After switching to Only My Comics, confirm that the practice works you favorited, read, or downloaded remain findable. Then check whether a work that exists only in the remote catalog and has not entered your personal reading activity is absent from the aggregate list. This verifies what the scope actually means rather than treating a reduced count alone as success.

Check offline content separately too: the current source filter may temporarily hide a downloaded work without removing its files. Clear filters or enter the offline scope to find it. Do not redownload an entire work because a filtered list is empty; first determine whether it is outside the display scope or actually lacks a local copy.

The difference between editing, removing, and switching servers

Renaming, updating a password, and changing the server address have different effects. A new server or different account should usually be a separate connection, preserving the source relationships of original history and downloads. Use migration options only after confirming that the same library has moved. Do not arbitrarily point a failed connection at another machine with similar content merely to turn its status green.

Removing a connection is not the same as deleting the server library, but check the current operation's explanation for how local caches and downloads are retained. Back up necessary information and verify that local copies are readable beforehand. A connection name is only a display label, not a file backup or enough information by itself to guarantee that all identity relationships can be recreated later.

Frequently asked questions

Why does Only My Comics contain more items than Favorites? Personal scope may include content you have read, followed, or downloaded, not only favorites. Understand the inclusion conditions from the current description, then inspect source and status filters. Do not immediately treat extra works as duplicate imports.

Does changing scope delete remote books? This changes aggregate presentation; the original service still manages server files. Deleting files requires a separate explicit action. Fewer library cards do not prove that remote data was removed.

Do identical connection names affect operations? Internal identity is not determined only by the display name, but people can easily select the wrong item. Clear names and checks of type, address, and work source help prevent downloading or hiding the wrong copy or using the wrong progress record.
