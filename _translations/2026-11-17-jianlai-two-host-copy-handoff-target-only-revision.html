Use two original lines to copy a draft between two private ordinary editing hosts, then use Jianlai to change only the target copy’s status word. Retain the source, initial handoff and revised target for comparison. Copy and paste belong to the host or system; Jianlai supplies text input. No cloud sync, clipboard history or cross-app format fidelity is assumed.

1. Identify both hosts and documents

Choose two identifiable ordinary editable bodies, preferably in different hosts. Label them externally as source A and target B so similar titles do not lead to editing the same document. Use new nonprivate practice documents, not real outgoing messages, shared files or working lists. Confirm that B accepts ordinary text and Return will not send it, then record host names and document identities. A and B are exercise identities, not a synchronization relationship. With only one suitable host, prepare A and mark the cross-host part not performed. Selecting two passages in one document is not an application-to-application handoff. The aim is to retain the original while changing a separate copy.

2. Enter the two-line source baseline

Confirm Jianlai in A and enter the two literal lines below. On line one, the Chinese label is followed by one ASCII space and an identifier preserving uppercase B and zero-seven. On line two, the Chinese status label is followed by one ASCII colon, one space and the English draft word. Use one hard newline, no fences, period or explanation. Commit composition and compare the body in segments, especially digit zero versus uppercase O in the identifier and unintended capitalization of the status word. Saving belongs to the host. Use its actual available flow and record the result; hiding the keyboard does not establish persistence. Keep an external baseline transcription or screenshot, while copyable source remains the main handoff material.

3. Select and copy with host controls, not Cut

Use A’s actual selection tools to select both complete body lines, excluding document title, annotations and other paragraphs. Choose an explicitly identified Copy action in the host or system, not Cut, because A must retain its source. Look back at A immediately and confirm the same two lines remain. If Cut was chosen accidentally, restore and verify the exercise copy from the baseline and record the deviation rather than treating a damaged source as a successful handoff. Apple’s editing guide describes system selection and copy-paste; that does not establish a Jianlai toolbar with those names. Resolve pending composition before selecting body text. Candidate content and a document selection are different objects, so neither alone proves that both lines were copied.

4. Paste into B and verify before editing

Switch to B’s empty ordinary body, position the insertion point and use its or the system’s actual Paste action. Before changing any character with Jianlai, compare A and B line by line: labels, identifier, ASCII colon, spaces and the single hard newline must match. If paste permission or alternative options appear, proceed only through an identifiable flow and stop to record uncertainty rather than assuming success. Font size, color and visual wrapping may differ. The check concerns characters and original line boundaries, not guaranteed rich-text formatting. Retain a snapshot of B’s initial received state before the local edit so handoff discrepancies and editing discrepancies remain distinguishable.

5. Change only B’s status word

Confirm you are still in target B. Use host selection or the insertion point to locate the English draft word on the second line and replace it through Jianlai with the ready word in the target below. Replace only that word, preserving the Chinese label, colon, space, first-line identifier and newline. Equal old and new word lengths do not justify skipping a character check merely because columns align. If the selection includes a colon or newline, cancel and select again instead of overwriting a larger range. Commit and compare B with the revised target. This changes exercise text, not an actual work status synchronized to a service. Jianlai provides input while the host provides positioning and selection; no dedicated replacement button or automatic status management is invented.

6. Return to A and check it stayed unchanged

Before leaving B, save or retain the exercise result using its actual method, then return to A. Verify that its second line still contains the original draft word rather than ready, and that the identifier and two-line boundaries match the baseline. Do not pass this check merely because the intended action was Copy: actually look. If A also changed, investigate whether both views opened one document, a shared source or the wrong window. Do not immediately attribute it to keyboard synchronization or delete source files to test a theory. Compare current A, the baseline and revised B, specifying what should match and which word should differ. If identities were confused, preserve evidence and rebuild clearly identified private practice copies.

7. Diagnose selection, source and appearance differences

If B includes a title or explanation, inspect A’s copied selection. If a line is missing, check the hard newline and selection endpoint. If punctuation widens or a word is capitalized after paste, compare before and after and investigate B’s automation. A different font or screen wrap alone is not evidence of damaged characters. If B cannot use Jianlai, record a host input restriction separately from clipboard content. Repair one stage at a time while preserving baseline A and B’s initial snapshot. Do not repeatedly copy the revised target back over the original. No clipboard-history recovery is promised here. After copying the wrong content, restart from retained exercise source rather than searching for an unpublished Jianlai cloud-backup control.

8. Deliver the comparison and action ownership

Save baseline A, initially received B and revised B, plus the final recheck showing A unchanged. Identify actual hosts, documents and whether Copy and Paste really ran. Entry fidelity concerns characters; handoff fidelity concerns initial B; independent-copy behavior concerns final A and revised B. One screenshot cannot replace every stage. Mark persistence untested for any document not actually saved and reopened. A new host or receiving field requires another character and newline check rather than extrapolating universal compatibility. The result is an evidenced text-copy handoff and local revision workflow, not cloud-sync configuration or proof that the keyboard owns clipboard records, cross-device state or real task publication.
