In scientific notes “µ” and “μ” often look similar, but they are U+00B5 MICRO SIGN and U+03BC GREEK SMALL LETTER MU. Unicode defines a compatibility decomposition between them; that does not make their original code points identical. Enter two short labels using Jianlai, then inspect the symbols independently. This exercise does not assume every Jianlai layout has a particular Greek-letter key.

Prepare two target lines

Create an ordinary text note, confirm Jianlai is enabled in system settings, and select the English input mode actually available. The reference lines are “sample A: 5 µm” and “sample B: 5 μm”. These numbers and units are practice text, not measurement results. If a recipient specifies a character standard, record its source and version separately; the exercise compares two original code points and provides no measurement or safety conclusion. Record device, host, layout and date. Do not experiment in a formal report, real equipment label or message ready to send. Glyphs vary by font, so visual inspection alone cannot reliably identify the characters.

Check the reference character identities

Confirm the U+00B5 and U+03BC names in Unicode's public information, then keep each as a separate local reference without copying the explanatory names into the sample. A private reference note can label them “micro sign” and “Greek letter” and place each symbol after its own label, but the reference must itself be checked: a label cannot establish its character's code point. If the source characters are uncertain, use a trusted character-inspection tool to read their code points. Without one, record unverified rather than guessing from shape. Before copying, select only one symbol and avoid surrounding spaces, newlines and explanations. Inspect the note after each paste before proceeding so an oversized selection or missing paste is caught promptly.

Enter the first line's letters and number

In the note, open Jianlai and type “sample A: 5 ”. Check case, the colon and spaces around the number. Candidates or automatic correction can depend on host settings; inspect committed text and correct A if necessary using the actual interface. Select U+00B5 from the identified local reference, copy and paste it after the number, and use Jianlai to type m. Verify the text has one number, one symbol and one m; a toolbar preview is not a substitute for the note itself.

Enter the second line and check order

On a new line type “sample B: 5 ” with Jianlai. Copy only U+03BC from the other checked reference and paste it, then type m with Jianlai. Keep number and unit order identical so the symbol is the variable. If the current keyboard offers a character through a visible control, you can use it, but still check its code point independently. Switching to another system keyboard, copying and pasting, and typing with Jianlai are distinct steps; do not describe them as Jianlai automatically generating a particular code point.

Inspect characters, not just glyphs

Copy each symbol alone into a trusted local character-inspection tool. The first should report U+00B5 and the second U+03BC. Make sure the tool has not applied compatibility normalization first. If that is unknown, record the condition as unknown and do not treat its result as evidence of the original code point. Check that A, B and both digits remain in place, so an enlarged selection has not replaced other text.

Understand the normalization boundary

Unicode says U+00B5 has a compatibility decomposition to U+03BC; NFKC and NFKD apply compatibility mappings. Distinguish original input, a processed copy and a tool display in your notes. Two lines becoming equal after a transformation does not show their original code points were equal. Whether a host normalizes text depends on the actual software; this guide does not infer automatic changes by a particular note app or keyboard. Follow an explicit recipient specification when a particular code point is required, keeping the original before processing a copy.

Correct one error

If the first line contains the wrong symbol, select that one character rather than the entire line. Once the selection is clear, copy from the correct reference again and replace it. Check the replacement with the inspection tool and verify that the number, spaces and trailing m remain. If cursor or selection is unclear, cancel and enlarge the view before acting; do not assume one undo necessarily reverses one character. Keep the second line for comparison but do not copy it back to the first without verification.

Record results and troubleshoot

Record the input path, reference code point, independent inspection result and any reason a step was not executed. If Jianlai is absent, return to an ordinary text field and inspect the system keyboard list and current selection. If paste is available but direct input is not, record the actual method rather than calling a missing specific key a fault. Before checking, ensure only the symbol was copied: if the tool reports two or more characters, a space may have been selected and you should select again. If selection fails, mark the step incomplete rather than experimenting repeatedly in a formal document. A tool that displays only a glyph cannot prove the original code point. Avoid uploading private text to an online service; this sample should contain no personal data.

Finish and restore

After checking both lines and the record, keep or delete the practice note as you choose and restore your previous keyboard selection. For real material, check the recipient's character requirements, preserve the original and inspect a copy. Do not perform bulk replacement merely because characters look alike. This guide uses public Unicode documentation and does not claim a step-by-step test on a personal device.
