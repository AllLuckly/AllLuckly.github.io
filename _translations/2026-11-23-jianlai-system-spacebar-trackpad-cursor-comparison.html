When inserting text in the middle of a sentence, accurate insertion-point placement matters more than key-label appearance. Apple documents holding the space bar to turn the system onscreen keyboard into a trackpad; this does not guarantee a third-party keyboard offers the same gesture. Establish a system reference first, then use a positioning method actually available with Jianlai to insert the same marker in two practice lines.

Prepare identical practice text

In an ordinary note on your own iPhone, create two non-sensitive lines: A: red blue and B: red blue. Check that each has one space between red and blue, save and reopen. Do not test gestures in account, password or important documents. If long presses are inconvenient or accessibility input is in use, skip the system reference and retain existing settings.

The goal is to place the insertion point after red, before the existing space, and insert -, producing A: red- blue and B: red- blue. This marker identifies a position; it does not require deleting the original space. Record device, system, host and Jianlai versions and actual layout. Verify that system English and Jianlai can be selected and that you can return to your usual keyboard. Mark unavailable prerequisites pending.

Distinguish insertion point, selection and keyboard

An insertion point determines where the next character goes; a selection affects existing text. Do not conflate the two. Tap the end of line A and observe the host’s actual cursor or selection. If no insertion point is visible, editing is unavailable or text is selected, exit selection and establish an editable field. Stop if the state remains unclear rather than typing blindly.

Select the system English keyboard, confirm its identity and locate its space bar. Gestures and displays can vary by system. Apple’s instructions are a system reference, not a list of Jianlai controls. Prepare a table for keyboard, starting position, positioning action, visible movement, complete line after insertion and correction.

Line A: establish a system reference

At the end of A, follow Apple’s instructions to hold the system keyboard’s space bar with one finger and observe whether trackpad state appears. Once confirmed, slide to try placing the insertion point between red and the space. Small movements suffice; inspect the cursor after lifting your finger. If no feedback appears, the gesture is uncomfortable or behavior differs, record the round incomplete rather than claiming a verified gesture from an accidental movement.

Only when the target position and absence of selection are confirmed, enter one - and inspect whether the whole line is A: red- blue. If it becomes A: red -blue, acquires an extra space or overwrites text, record the actual result and restore the practice copy using a known host editing method before an optional retry. Do not repeatedly type over an unknown selection.

Line B: use a method available with Jianlai

Place the insertion point at the end of B, switch to Jianlai and verify its identity. Inspect the current space bar and any visible positioning controls; do not assume trackpad, arrow keys or the same hold feedback as the system keyboard. You can use host-supported tapping or insertion-point dragging to reach the position after red. If you actually confirm another Jianlai method is available, record and use it.

Once the position and absence of selection are confirmed, enter one - and check for B: red- blue. Record whether you used body positioning or a visible keyboard control, whether movement was seen, the full line and corrections. If precise positioning is unclear, mark it incomplete rather than asserting Jianlai incompatibility; system, host, accessibility mode and layout can all affect the operation.

Optionally observe a hold without assuming support

Only on a safe copy, if desired and the cursor is visible, briefly hold Jianlai’s space bar and observe any known positioning indicator or other actual feedback. Apple’s system trackpad behavior does not automatically apply to Jianlai. Without a clear indicator, do not continue guessing the result of sliding or experiment on important text. If a space or other text is inserted, record it and restore the practice line.

Do not assign one failed movement to a single cause: gesture, layout, host state or unavailable functionality are possible. Record observable facts such as “no indicator seen”, “cursor movement unconfirmed” or “not attempted”, and consult actual app documentation if needed. If body tapping completed the task, do not alter theme, permissions or touch settings just to complete a comparison.

Review and deliver the observation table

Save and reopen the note, checking for A: red- blue and B: red- blue. Label A as the system reference, B with the actual method, and note deviations and unfinished steps. One successful insertion establishes that position for that attempt, not the gesture for every host, language or layout. Before removing practice text, ensure no other note is affected.

If the cursor appears correct but the character lands elsewhere, inspect text direction, selection and the whole line. Restore the copy rather than clearing the keyboard or resetting the system. Restore your usual keyboard and ensure the note remains editable. This exercise is based on public documentation and does not claim a device test or that Jianlai supports Apple’s system gesture.

For another host, create a separate copy and observe its cursor display afresh; an old table is not a new app’s result. If an action is unsuitable for the user, skip it and record the actual alternative.
