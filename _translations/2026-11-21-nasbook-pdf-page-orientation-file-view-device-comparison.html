Use a self-made two-page PDF to record device orientation, displayed pages and the result of an externally saved copy separately.

Prepare a recognizable two-page sample

Prepare a two-page PDF you may modify. Put “TOP” at the top of each page, labels 01 and 02 at bottom left and a distinctive triangle on page two. Copy the original to a working folder and keep an untouched backup. Open both pages in a reliable PDF viewer to confirm labels. A matching filename does not prove two copies have identical bytes; record their locations.

Record file and displayed orientation separately

PDF page orientation, a viewer’s temporary rotation and the physical orientation of a phone or tablet are different states. In an external viewer record text direction and visible edges for both pages, then note whether the device is portrait and whether the viewer indicates a temporary rotation. Adobe documents a difference between temporary view rotation and saving a page rotation in its own software; this example does not imply that Book Isle has identical controls or behavior.

Import the working copy and establish a portrait baseline

Import the working copy using an entry actually offered in the installed Book Isle version. Open page one and verify 01 and “TOP”, then page two and verify 02 and the triangle. Record device orientation, displayed page orientation and completeness. If import fails or pages do not load, leave the original untouched and resolve file reading and copy identity before comparing orientation.

Rotate the device without editing the file

If the device and current reading environment permit rotation, first record the original system orientation-lock state, change it temporarily only with the user’s consent, and turn the device to landscape. Observe the app window, page text orientation and position, recording the triangle and top marker on page two. If the app or system remains portrait, record the actual state; turning the device is not proof that the PDF file itself was rotated.

Inspect the view and reopening result

Only if Book Isle actually shows a comprehensible view-rotation or zoom entry, record the prior state, operate once and inspect the page. Otherwise mark the entry unavailable rather than assuming it exists. Return to the shelf and reopen the same copy, checking orientation, reading position and title separately. A view reverting, a retained position and a modified file are three different conclusions.

Make a clear external control

If the goal is to study orientation saved in a file, use a separate computer tool to rotate a page of the working copy and save it as a new file. Preserve the original and record the tool and save option. Adobe distinguishes temporary Rotate view from saved page rotation; follow the actual tool’s prompts, with no software purchase required. If no suitable tool is available, skip this control rather than claiming a temporary screen rotation was saved.

Distinguish the two files and compare each page

Give the original working copy and new copy different names. Check 01, 02 and top markers in an external viewer, then inspect both through Book Isle’s actual import behavior. If the app identifies both imports as one book, shows no path or cannot distinguish them, mark identity pending rather than deleting other books to force recreation. Record external file, Book Isle display and device orientation in separate columns.

Record each orientation as an independent observation

Make rows for original in an external viewer, Book Isle on a portrait device, Book Isle on a landscape device, and an externally saved working copy. Use columns for file label, device orientation, top-marker direction, whether the 02 triangle is visible and whether a file was actually saved. If text remains in the original orientation on a landscape device, record that display only; it does not establish a PDF modification. If the external viewer already had a temporary rotation active, restore or explicitly record it first to avoid mixing conditions. Leave the saved-copy row untested when no save occurred; renaming a file does not save page orientation.

Confirm a modification only in a copy

If a rotated copy was actually saved, close the external viewer and reopen the new file. Check both the edited page and the untouched page, then open the backup original and verify its marker order. Record actual tool feedback; the current screen orientation alone does not establish that the disk file was saved.

Confirm file identities before restoring

Before restoring settings or cleaning working files, distinguish the original backup, new file and entry currently open in Book Isle. If names match and paths are unavailable, retain both and mark identity pending rather than bulk deleting. Restore orientation lock to the user’s actual prior state, not always off. Record physical rotation and saved PDF page orientation separately.

Restore settings and retain evidence

Restore orientation lock and window state from the earlier record and confirm the backup original still opens. Keep device and app versions, sample page identifiers, each observed orientation, whether a new file was actually saved and uncertain steps; mark unperformed file modifications untested. Clean up only your own test copies. No Book Isle PDF rotation control or physical-device compatibility test is claimed.
