Hold device, layout and text fixed while observing two available themes under two indoor lighting conditions, then separate readability from input accuracy.

Choose two real environments

Choose two safe indoor locations on the same device, such as daylight near a window and soft evening room lighting. Create an ordinary practice note; do not test while walking or driving. Record an identifiable current theme and whether screen brightness can be held constant. Keep device, text, layout and font fixed first. If automatic brightness changes the screen, record that extra change instead of treating ambient light as the only variable.

Prepare the same input and observations

Write “青山 ABC 123，明天见。” in an ordinary field as the reference and reserve another line for Jianlai input. This short sentence combines Chinese, Latin letters, digits and punctuation; it does not represent every language or vision condition. Confirm Jianlai is the active keyboard each time. Observe key labels, any candidate area and committed body text separately. Never use passwords or private accounts as practice content.

Establish the first lighting baseline

With the initial theme and a comfortable viewing angle, inspect key edges, labels and any candidates actually displayed. Type the reference once and check the committed line. Record specific hard-to-read locations, absent controls and any mistaken selections rather than merely calling the theme bad. If a candidate area is not displayed in this input scheme, record it as absent rather than assuming a font fault.

Change one available theme

Select a second theme using an entry actually offered by Jianlai. If the interface only previews it, record preview separately and verify application before judging the keyboard. Return to the same ordinary field, confirm the appearance changed and type a second line with the same layout, location and brightness conditions. If the theme cannot be applied or the entry differs, record the state and stop the comparison; do not reinstall or delete settings to force it.

Repeat in the second lighting condition

Move the same device to the second indoor location and observe the same labels, candidates and body text in the same order. Record screen brightness or glare changes separately; repeat the first location if device angle may have changed. In the second location, first type the same sentence with theme two for the third trial, then return to the original theme and type it again for the fourth trial. This supplies one observation per theme at each location. Leave any unperformed cell blank; do not copy a result from another condition. Compare the two themes under the same light before comparing each theme across locations. There is no medical score or universal visual recommendation here. A single observation cannot establish that a theme suits everyone or provides therapeutic benefit.

Separate correct text from visual appearance

Compare each committed line actually completed across the four trials with the target, noting omitted characters, case and punctuation. Leave unperformed trials blank instead of substituting another line. Correct text does not prove every key label was readable or that the theme improved accuracy. Conversely an error may involve candidate selection, host replacement or key operation. Preserve the original line before checking each possibility; make corrections only in a separate copy.

Troubleshoot and record limits

If labels are hard to see, verify the active keyboard is Jianlai, the theme was applied, and screen reflections and brightness. If only candidates are hard to read, first establish whether the input scheme actually shows candidates; use only settings actually visible, without assuming identical controls across schemes. If a host declines third-party keyboards, return to a normal field. Avoid secure password fields. Record uncontrolled automatic brightness as a limitation.

Deliver the ledger and restore

Keep both environmental descriptions, device and brightness conditions, both actual themes, original input lines and separate observations for labels, candidates and body text. Mark absent controls, uncontrolled variables and attempts not performed. Restore the former theme and usual brightness, then verify the note is retained. There is no need to delete a theme or claim synchronization across devices. The procedure uses publicly described theme features and claims no completed device, lighting or vision test.
