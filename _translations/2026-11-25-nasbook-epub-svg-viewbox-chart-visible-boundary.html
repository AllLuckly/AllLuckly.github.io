Use an authorized EPUB sample to inspect an SVG chart’s viewBox, visible boundaries and reading result.

Understand the viewBox

The SVG specification explains that four viewBox numbers define a rectangle in user coordinates that maps into an SVG viewport; attributes such as preserveAspectRatio also affect the mapping. Coordinate range, actual geometry and Book Isle’s display region are distinct. The specification does not guarantee every SVG feature in every Book Isle version, and one screenshot cannot establish the sole cause of cropping.

Prepare an authorized chart

Choose an EPUB you created or the publisher permits you to inspect, preferably with a simple SVG coordinate chart. Identify four boundaries and a clear text label. Record title, version and source and preserve an original backup. Do not download an unknown file or publish the book. If internal inspection is not permitted, observe only the reader and mark file inspection skipped.

Establish the Book Isle baseline

Open the sample in Book Isle and navigate to the chart using available contents or page controls. Record whether the chart appears, whether all edges and labels are visible, screen orientation and current reading settings. If the whole book cannot open, first check download completeness and format recognition; do not attribute it directly to SVG. Preserve bookmarks, notes and the original file.

Locate the referenced resource

Only with permission and suitable tools, inspect the EPUB copy: locate the package document and target chapter, then determine whether the SVG is inline or referenced as another file. Record the relative relationship between chapter and graphic; same-name files are not necessarily identical. A missing resource, incorrect reference path and visible image with missing edges are separate problems to record for the publisher.

Read viewBox and dimensions

Inspect whether the target SVG has a viewBox and, if so, record minimum x, minimum y, width and height in order; also record any width, height and preserveAspectRatio. Do not treat the third and fourth values as absolute bottom-right coordinates: the right edge is minimum x plus width and the bottom edge is minimum y plus height. Record missing attributes without inventing defaults.

Compare geometry and markers

If you understand the SVG structure, locate coordinates of the self-made border or markers in the copy and compare them with the viewBox rectangle. Element transforms, stroke width and clipping paths can also affect visibility, so a simple numeric comparison is a lead, not proof of final rendering. If transforms are unfamiliar, stop after recording rather than editing the publication or asserting a specific error.

Change one reading condition

Where the current interface permits, keep the same file and page while changing only device orientation or available reading area. Record edges, label and chart proportions again. Mark unavailable controls as such; do not assume Book Isle has a dedicated vector-zoom button. A changed display area can cause reflow or scaling without changing the SVG file.

Compare with an independent viewer

If an established SVG viewer is available and permitted, open the saved graphic copy and record the software, version, edges and labels it displays. This control helps identify sample content, but viewer and reader may use different fonts and viewports; a difference alone does not prove either is wrong. Skip without a suitable tool rather than installing unknown software or weakening security.

Troubleshoot by layer and finish

If the chart is entirely missing, distinguish missing resource, unsupported format and wrong page first. If only edges or labels differ, inspect the viewBox, transforms, fonts and display area. Change one test condition at a time and leave unknown causes unresolved. Record sample version, attributes, Book Isle and control observations and skipped steps; remove private paths and unauthorized content before sharing. Restore device settings and preserve the original; no device test is claimed.

Check the coordinate arithmetic

For a self-made viewBox of 10, 20, 200, 100, the horizontal range is 10 to 210 and the vertical range is 20 to 120. This is coordinate arithmetic; it does not imply content fills the rectangle. Stroke, transforms and clipping still affect visibility. Use the example only for your own practice and read actual values from an authorized copy.

Separate labels from geometry

Record the border and legibility of labels separately: a border without text is not the same as an entirely missing image. Fonts, transforms, overlap and display area can affect labels, and text may have been converted to paths. Appearance alone does not prove selection or searchability. Use available system and app controls if checking selection or assistive reading, and mark unavailable features untested.

Compare the source and preserve uncertainty

Compare markers, legends and boundaries with a publisher-provided preview or description when available; otherwise mark the expectation unknown. Do not use another edition to guess what the current one lacks. If device fonts or the book copy also changed between observations, record those changes and re-establish the baseline rather than attributing their combined effect to one SVG attribute. Confirm that the original and test copy remain identifiable.
