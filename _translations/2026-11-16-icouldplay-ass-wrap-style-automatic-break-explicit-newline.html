A sentence occupying two screen lines does not prove two source text lines. ASS q controls automatic wrapping, while an explicit break is another instruction. Prepare three copies of the same wording and record the reason for each break and readable extent. A reloadable control does not promise identical word breaks across fonts.

Fix a fourteen-second source and text conditions

Retain an owned clip of at least fourteen seconds and prior captions, recording orientation/fitting. Use a 640×360 script, font request Arial, size 36 and80-unit left/right margins. Record unknown actual font rather than infer installation. Copy the sentence word for word for all three events. Hold viewing zoom, system size and playback speed stable.

Save complete controls for three strategies

Save complete UTF-8 wrap-policy.ass with both style margins80. Event 1–4 uses q1;5–8 uses q2;9–12 also uses q2 but inserts an uppercase-N override break after phrase. Preserve the backslash and plain-text syntax. Separate events/gaps distinguish source instructions, automatic layout and disappearance. Reopen to verify unchanged wording.

Separate wording from the break instruction on paper

All three retain the same word order; the third adds an explicit break location. The instruction is not two spoken characters. Do not merge separate events into continuous wording. Record source text lines, ASS explicit breaks and visual automatic wrapping separately. A two-line presentation alone cannot identify its cause; inspect the selected event.

Audit the different automatic-wrap requests

q1 uses end-of-line wrapping, with actual word positions depending on width, font and size. q2 disables automatic wrapping but still honours an explicit uppercase-N break. It does not forbid every break. Record clipping/completeness before changing video size. A narrow font leaving the first cue on one line is a valid observation, not a reason to secretly rewrite the sentence.

Separate the480-unit budget from measured text width

The paper horizontal budget is 640−80−80=480 script units. An invented seven-word width model totalling 600 exceeds it by 120; 600 is not a measured Arial width. Character count times font size does not establish actual width. Spaces, glyphs and fallback matter. Compare consistent presentation conditions without converting this budget into universal phone pixels or break positions.

Check complete wording and breaks in iCouldPlay

Play the selected file from the start and record appearance, complete words, breaks and disappearance for each cue. For the third, check the break after phrase and whether either part still exceeds the frame. An explicit break does not fit arbitrarily long parts. Without selection controls, leave playback unperformed. Record actual pause/screenshot times rather than substitute an editor preview or partial wording.

Change margins alone for a layout control

In a separate copy, reduce both margins to 40: the budget becomes 560, eighty wider. Keep placement comparable and retain font/wording. Audit identity/width for changed automatic breaks. q2 remaining unwrapped does not by itself mean the margin change failed;its policy disables automatic wrapping. Preserve the explicit break rather than delete it to force matching screenshots.

Reopen and deliver wording-to-policy evidence

Reopen/reselect the original, check all intervals and restore everyday captions. Deliver original/control, margin budgets and observed breaks, separating explicit source requirements from layout effects. Choose one next adjustment from the readability issue. One success does not certify every long sentence, language or device. No video-canvas editing or complete font-coverage test was performed.
