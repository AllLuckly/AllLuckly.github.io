A dashed thread can represent the rear, not a broken strand. Illustrate four holes in an original strip, specifying entering/exiting sides before visibility. This manual static guide establishes no stitch strength, material safety or machine path and assumes no automatic threading.

Fix four holes and the front viewing side

On a 1000 by 600 pixel canvas, place a horizontal strip with A–D left to right at x=200,400,600,800 and y=300. Use the viewer’s front rather than switching to a hand-held rear view. Name strip/holes independently; equal spacing is this layout, not a universal stitch requirement. Identify four centres before thread. Define solid as front and dashed as rear; layering/styles are not measured material thickness.

Test hole rendering against another background

Use verified masks/paths for actual openings or explicitly identify pale-circle concept markers. A pale cover only simulates the current background and is not a transparent hole. Hide strip and markers separately to inspect relationships, then restore. Leave adequate spacing around hole rims. Diameters serve readability, not fabrication dimensions. Keep visible rims near thread passages rather than covering joins with large dots. Retain the complete strip source so one hole cannot irreversibly alter the only original.

Write one enter/exit sequence

Start on the left front, enter the rear at A, travel behind A–B, emerge at B, travel front B–C, enter behind at C, travel rear C–D, emerge at D and finish right front. Four crossings return to the starting side. Audit the sequence before styles rather than making every span solid. Hole names are locations, not knots/cuts. Preserve ends and holes for left-to-right tracing. This invented route is no named standard stitch or universal material recommendation.

Keep front and rear segments continuously sourced

Start with one complete reference path, then create visible segments from the side list while retaining the hidden source. Use available dashes or manual fragments behind and solid spans in front, maintaining joins at holes rather than implying cuts through coincidental dash gaps. Keep weight consistent. Use explicit stacking for rim occlusion instead of arbitrary background patches. Name spans by hole pair/end so later edits find dependencies without random short-dash selection.

Update both adjoining spans when moving B

Move B slightly upward in a copy, holding strip/other holes fixed. Update rear A–B and front B–C to B’s centre, not only its pale marker. Side order remains unchanged: moving a hole adds no crossing and does not justify changing dashes to solid. A hole outside the strip violates the construction; record that instead of enlarging the strip to hide it. Compare equal-size versions and remove old-hole/span copies after restoration. Objects do not understand shared-hole dependencies.

Verify with monochrome and reverse tracing

Inspect one thread colour so styles/hole names, not red/blue alone, identify sides. Trace backward from right: D front-to-rear, C rear-to-front, B front-to-rear, A rear-to-front, returning left front consistently. Reverse tracing is a check, not an instruction to start right. A rear-view panel needs explicit flipped viewpoint/left-right mapping instead of a mirrored image with old labels. Defer needle/knots/tools until four crossings are clear.

Inspect hole rims and small dashes after export

Retain hole positions, full path and display-segment sources. Inspect four rims and three internal spans at actual size; dashes must not merge into an unreadable grey band. Test backgrounds and distinguish conceptual markers from transparency. Name four-hole front/rear schematic, dimensions and revision and exclude moved-B tests. Explain sources/independent spans for editable delivery. Adding holes requires a new side sequence, not one copied span. Physical production needs material/purpose checks; this verifies no tension, tools or safety procedure.

Check side ownership and rims when thread looks broken

For a missing A–B span, inspect intended rear dashes, deletion and contrast. Repair centre/source joins instead of enlarging holes to cover them. Ending behind after four holes suggests an extra/missing side change. For reversed left/right labels, check the viewing direction rather than merely changing the line style. Recheck hole count, forward list, reverse tracing and backgrounds so each span has a defined side/destination rather than scattered broken-looking marks.
