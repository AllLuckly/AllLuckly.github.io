In Mandarin pinyin, z and zh, and s and sh, are distinct initials. In Jianlai's Chinese input mode, enter two pairs of words and check the letters entered, candidates actually offered, and characters committed to the note separately. Candidate order can depend on version and usage history; this guide does not promise any word in first position or require changing default settings.

Prepare the practice environment

Create a blank note in an ordinary notes app, switch to Jianlai already enabled in system settings, and select the Chinese pinyin input mode actually visible. If Jianlai has not been added, follow the introductory guide first. Password fields and some hosts can use the system keyboard instead, making them unsuitable for this comparison. Record the installed version, host and current layout; follow the controls on your device if they differ. Avoid practising in real account fields, recipient fields or messages ready to send. In a nine-key layout, use the visible letter groups and inspect the target when candidates appear: a key containing a letter does not itself select the right character. On a 26-key layout, check the complete letters before selecting. The paths differ, so this record concerns the current layout and cannot establish the result on the other one.

Establish two pairs of targets

On paper or in a separate reference area, write “资格” and “之歌”, then “斯人” and “诗人”, and check each character. Their pinyin is zi ge, zhi ge, si ren and shi ren respectively. These common readings identify the targets; similarity of meaning is not the test of candidate accuracy. Ministry of Education spelling rules describe initials, finals and tones as syllable components. This exercise compares only initial letters; whether the keyboard accepts abbreviation or makes suggestions must be observed in the actual interface.

Enter the single-letter initials first

Enter zi ge in the note, then locate “资格” among the candidates or select its characters individually using controls that are present. Check the committed text. If the entire word does not appear, record that rather than changing the target to manufacture a success. On another line enter si ren and confirm “斯人”, checking both characters. Segmentation and candidates may differ. If a composition may still be uncommitted, inspect the boundary between the input area and note before continuing.

Enter the two-letter initials

On a new line enter zhi ge and select “之歌”; then enter shi ren and select “诗人”. Compare the letters actually entered for each initial syllable: the extra h belongs to the initial, not the beginning of the second character. If the whole target is absent, select the individual characters through the available interface and record that method. Do not infer that candidate positions are identical for everyone, or count an unconfirmed candidate as committed note text.

Check the four committed lines

Against the reference, the final lines should read “资格”, “之歌”, “斯人” and “诗人”. Check character count, first and last characters on each line, especially the visibly different “诗” and “斯”. Similar pronunciation alone does not establish correct text. In the first pair, the second characters differ; in the second pair they are the same while the first characters differ. Read once with the reference covered, then compare character by character: checking only line count or the second character can miss a wrong first character. This is a proofreading exercise, not proof of fixed candidate order. Distinguish an actual newline from automatic wrapping. Move the cursor away and inspect whether an uncommitted composition remains; confirm or cancel it before the next round so the rounds do not join.

Make one traceable correction

If the first character of a line is wrong, keep a practice record, select that character, enter the correct pinyin in place and confirm a candidate. Check that the first character changed, the second was not replaced, and the other three lines are unchanged. If selection or cursor location is unclear, cancel and reposition first. Do not assume that a host undo always removes exactly one character. The goal is a local correction, not clearing input history or resetting the app.

Record observations rather than guessed causes

For each line record the pinyin entered, whether a candidate appeared, whether you selected a word or individual characters, the final text, and whether a correction was needed. If the keyboard offers abbreviation or fuzzy-pinyin settings, record only a setting actually visible and enabled. Do not attribute a candidate difference to a feature that was not verified. A missing candidate can also depend on vocabulary, context or layout; one observation cannot identify its cause. For a comparison, keep host and layout fixed and change only one confirmed condition at a time. For example, complete and record all four lines in the original layout before repeating in another. Keep the two rounds separate and never fill the first record with later candidates. If the control is unavailable, stop that round and note why.

Troubleshoot and finish

If Jianlai is absent, return to an ordinary text field and check the system keyboard list and current selection. If letters rather than Chinese appear, inspect the actual input language instead of repeatedly testing a password field. If a target word is absent, select individual characters where available and note the limitation. If committed text differs from the candidate, reposition the cursor and check again. Save the local practice or delete your test note as you choose, and restore your previous keyboard selection. This guide uses public information and does not claim a step-by-step test on a particular device.
