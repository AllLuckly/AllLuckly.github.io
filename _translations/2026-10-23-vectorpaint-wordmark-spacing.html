When a short name becomes a wordmark, the space between each pair of characters becomes conspicuous. This VectorPaint exercise types the fictional name 山间小屋, or Mountain Cottage, and compares a short English word, moving from overall tracking to local optical spacing. The goal is smooth reading, not mathematically identical gaps.

Establish the wording and final use size first

Create a 1000×500 px canvas and enter the practice name using a font already on the device and permitted for the intended use. For a real brand, check name and font usage requirements first. This exercise studies typography only and does not establish trademark or brand clearance.

Before adjusting, view the wordmark at its actual use width, such as a webpage header or a small title beside an avatar. Elegant thin strokes at a large size may become hard to read. Choose a clear base typeface and moderate weight before spacing; this is easier to control than repeatedly adding thicker lines afterward.

Keep the default layout for comparison

After creating the text, confirm the content is applied and duplicate it above as a labeled default version. Use the lower copy for adjustments, keeping size, color, and wording identical. Change only spacing to isolate its actual effect.

Check for unintended spaces, especially in pasted text. Full-width spaces, ordinary spaces, and tracking are different. Clean the content before judging the font's default arrangement. Extra spaces used to imitate tracking make later font and wording changes harder to maintain.

Adjust overall letter spacing in small steps

Select the lower text and find letter spacing in its text properties. It adds or removes space relative to the font's original spacing, in pt. Begin near zero, change a little at a time, and inspect the whole line to see whether it feels looser or tighter.

Increasing tracking widens the whole line, so recheck space at both ends without immediately compressing glyphs to retain the old width. If characters separate into isolated graphics, spacing may be excessive. If strokes touch and the name becomes unclear, loosen it. Use how easily you can read the full name as another guide.

Separate local problems from overall problems

An unusually open pair may result from the glyphs' openings or stroke directions. A character with extra space on its right followed by one with an open left side can create a conspicuous gap. Tightening the entire line then crowds pairs that were already correct.

For local treatment, split the short name into individual text objects in a practice copy, retaining the same font and size, then position them separately. This enables manual pair spacing but fragments content editing too. Keep a complete text version so future renaming does not require finding and replacing every character.

Compare visual rhythm through empty areas

Observe the white regions between characters, not merely distances between bounding boxes. Two upright strokes can feel tight, while diagonals may leave larger triangular gaps. Local movement aims to harmonize the rhythm of empty space, not give every pair the same numerical value.

Keep the left end fixed while comparing the second, third, and fourth characters in turn. Zoom out after each pass so focusing on one pair does not undermine the whole. You can briefly view the wordmark upside down to focus on spaces between shapes, then restore normal orientation and check that the name remains clear.

Compare reversed-color and small-size results

Place a dark wordmark on a light background, then make a light-on-dark version with the same shapes and size. Observe fine strokes and internal spaces. Reversed text may feel heavier, so identical local spacing may not suit it. Compare small adjustments and record the chosen version.

Check again at a smaller display width for merged strokes. If a font is unclear when small, change its weight or choose clearer letterforms rather than endlessly increasing spacing. Spacing fixes relationships between neighboring characters, not a typeface unsuitable for the purpose.

Decide whether to retain text or make an outlined copy

Editable text makes wording changes easy. Outlined copies suit some delivery workflows that require fixed letterform appearance. Keep a complete editable-text original before deciding whether the receiving environment needs an outlined version. Once converted to paths, changing a name is no longer a matter of typing replacement text.

Export PNG as an appearance reference and SVG as needed, checking fonts or outlines in the receiving environment. Name files with the wording, palette, and version so default, adjusted, and reversed-color variants are not confused. Every final delivery file should come from the same approved layout stage.

Frequently asked questions

Why do two words look differently spaced at the same value? Typefaces differ in glyph width and built-in space, so identical additional spacing does not produce identical visual results. Keep font, size, and display dimensions fixed before gradually adjusting.

Is separating every character more professional? It only adds local control and also increases maintenance. If default layout with slight overall tracking already works, keep the text as one object. Add separate objects only for a specific local problem. Finally, read the name to ensure no character has become ambiguous or missing.

Record repeatable comparison conditions

Note the font, size, overall tracking, and preview width beside the original, then move those notes into a separate record afterward. If the font changes, reassess letter pairs; old tracking values are only a starting point. Save default and adjusted versions with the same canvas bounds so different preview crops do not create a false impression of improved spacing. Clear comparison conditions make later revisions more grounded.
