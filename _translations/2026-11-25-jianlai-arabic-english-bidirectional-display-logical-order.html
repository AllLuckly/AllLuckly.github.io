Arabic is displayed right to left, while English and numbers usually run left to right. On a mixed line, visible order can differ from the underlying logical character order. Enter English and numbers with Jianlai, then paste a trusted Arabic example to observe the host's display. Jianlai's public listing describes multilingual input, but this exercise does not assume it offers an Arabic keyboard or controls the host's bidirectional layout.

Create a safe practice copy

Create an empty document in an ordinary notes app. Confirm Jianlai is enabled in system settings and select an English input mode actually visible. Use only public example text and a fictional number, never a real name, address, account, filename or form that must be submitted. Record the device, system and host versions, and keyboard layout. Password fields, transaction interfaces and ready-to-send chat fields are unsuitable. If the current keyboard is uncertain, return to an ordinary text field. Type a test English word, confirm it entered this note, then delete that probe; keyboard appearance and actual input source are separate evidence. Save a blank copy or note the starting state so you can restart if insertion is uncertain.

Prepare trusted reference text

Using the concepts in Unicode's bidirectional algorithm, select a short trusted public Arabic example as right-to-left text. This guide uses “مرحبا” as a practice string, not for real communication. Save it in a separate reference area and make sure the intended text alone is copied, without surrounding lines, hidden direction controls or private content. If you cannot inspect it with a local tool, record it unverified rather than claiming the copied text contains no invisible characters.

Enter English and numbers first

Type “Sample 42” with Jianlai in the blank note and observe whether every letter, space and digit is committed. If a candidate or host autocorrection changes the text, correct it with the actual interface before continuing. Move the cursor to the end and type a space; record the visible position. A finger touch alone does not establish the insertion point, so use the host's cursor controls if necessary.

Paste right-to-left text

Copy only “مرحبا” from the trusted reference and paste at the confirmed insertion point. Observe and record the visible positions of the English, number and Arabic; do not demand that every app show the same arrangement. Pasting is a separate action and must not be described as Jianlai directly entering Arabic. If the host rejects the paste or displays it unexpectedly, stop and record the interface rather than substituting an unknown source or personal data.

Add an ending marker

On the same line, first confirm the current insertion point, then enter a space and “END” with Jianlai. Observe whether END appears where expected, but do not immediately move characters. Near a boundary between text directions, the cursor's visual position can make its actual insertion point hard to judge; hosts may provide different selection and cursor feedback. If uncertain, return to a saved earlier copy, retry and note why a step was incomplete.

Check visible and logical order separately

Unicode's bidirectional algorithm explains that characters are interpreted in logical order and positioned for display. Copy the practice line into a trusted local code-point inspector and check the expected English, digits, spaces, Arabic characters and ending marker individually. An entire line that the tool itself still displays bidirectionally is not a code-point-by-code-point result. If it shows only appearance, mark the order unverified. When code points are listed, record each rather than merely screenshotting the line; check spaces and their positions too. A character appearing at the far left or right does not by itself prove it is first or last in the underlying sequence. Do not normalize, reverse or automatically clean the copy during inspection; if processing is applied, label before and after separately.

Make a local edit

Select “42” in the English number and replace it with “43” using Jianlai without touching the right-to-left text. Afterwards, verify the number, English opening and ending marker, and check that Arabic text was neither lost nor accidentally added. If selection crosses the direction boundary, cancel and select again. Do not assume one undo necessarily restores exactly two digits. Save before and after separately so the edit's scope can be checked.

Investigate different displays

If two hosts render the line differently, first inspect whether their logical character sequences match, whether the pasted source was identical and whether paragraph direction or other host settings show an observable difference. Different screens alone do not establish that Jianlai changed characters. If unexpected directional controls appear in inspection, preserve the original and examine it with a trusted tool; establish their source before treating a copy, and do not blindly delete unknown characters from formal material. Record why any step could not be completed.

Record and finish

Keep four columns: method of entry, visual observation, verifiable logical sequence and unverified items. Specify which characters were typed with Jianlai and which were pasted; this separates host layout, source text and keyboard capabilities. Keep or delete the practice note as you choose and restore your previous keyboard selection. This guide uses public Unicode information and does not claim a step-by-step test on a particular device.
