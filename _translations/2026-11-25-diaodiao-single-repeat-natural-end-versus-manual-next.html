In repeat mode, a track ending naturally and a listener pressing Next are different events. 调调's public listing mentions queue and repeat playback, but does not promise a specific manual-skip rule for every mode. Use two short owned recordings to observe natural endings and manual skips separately; record the behaviour actually seen rather than prescribing it beforehand.

Prepare two distinguishable recordings

Use recordings A and B that you have permission to play and copy, ideally about twenty seconds each with recognizable beginnings; duration is only a practice suggestion. Keep the originals and listen to each beginning and end to confirm they are not renamed copies of the same sound. If playing aloud is unsuitable, use your own headphones at a comfortable volume. Do not use unknown or restricted audio, and do not include private recording contents in notes.

Establish a restorable queue baseline

Confirm that both recordings are imported and distinguishable in 调调. If names match, verify identity using title, duration or source; stop if uncertain. Record the current track, queue and playback mode so you can restore them afterwards. Use controls available in the current interface to arrange A before B and confirm their order. If the existing queue contains important entries, do not clear it without recording it. Disable other timers or shuffle settings that may interfere, using only visible states and without assuming every version uses identical controls.

Select and verify repeat state

Use the playback-mode control actually visible to select a state the interface identifies as single-track repeat. If an icon, label or other feedback cannot distinguish it, record unknown and stop that round. Record the state before and after selection so shuffle or list repeat is not mistaken for single repeat. If the interface shows only a repeat icon without an identifiable single-track marker, consult the app's available guidance; if still unclear, record unknown rather than clicking a fixed number of times and assuming success. Keep this state until the round ends. Start A and confirm that item identity, playback position and actual sound agree. Verify it is near the start and allow playback to continue without seeking.

Observe the natural ending

Let A play from beginning to end. Record whether the next observable state is A, B, stopped or something else; record the displayed current item and playback-position change if available. If A's opening is heard again, check displayed track and actual sound together rather than relying only on an icon. If a network issue or other interruption makes the outcome uncertain, mark the round inconclusive. Do not count an outcome following a manual button press as a natural ending.

Test manual Next separately

Return to the identified A and recheck queue and single-repeat state. Partway through A, press the actual visible Next control once and observe item identity, playback position and sound. Record the time and outcome of that one press; if no Next control is visible or available, mark not tested. Do not assume Next ignores, preserves or exits repeat, and do not apply the natural-ending result to a manual action.

Compare ordinary sequential playback

If ordinary sequential mode is clearly identifiable, select it, confirm A is before B, and record the changed mode. Separately observe A's natural ending using the same steps, then return to A and press Next once partway through. Keep files, queue, output and operator consistent, changing only the playback mode. If ordinary mode cannot be selected with confidence, skip that round rather than substituting results from another setting. Label each observation as natural ending or manual action; “Next works” alone is insufficient. A returning to A naturally and showing B after a manual skip is one possible record, not a result to fill in beforehand. If sound and display disagree, record them in separate columns rather than choosing the more expected result.

Account for interruptions and errors

Calls, notifications, Bluetooth switches or pauses may interrupt short samples. Record when an interruption occurred and the states before and after; a round that did not reach the end is not a natural ending. If you press twice by mistake, rerun that round and retain the invalid first record rather than guessing its category. If the recordings are too similar, return to the files to identify them and, if needed, prepare more distinct owned samples instead of guessing sound from a name.

Interpret without inferring implementation

Organize four outcomes: natural ending in repeat mode, manual Next in repeat mode, natural ending in ordinary mode, and manual Next in ordinary mode. Each may be A, B, stopped, other or unconfirmed; record device and app version. Equal outcomes do not prove equal internal implementation, and differences are not necessarily faults. This test cannot establish behaviour for other sources, servers, background states or versions. If the result does not meet your needs, first recheck mode and track identity, then adapt use to the interface actually present.

Restore the prior playback state

Afterwards restore the original queue and playback mode using the starting record. If unsure how, preserve the current record and avoid deleting unidentified items. Keep the original practice files; identify any test entry before cleaning it up. This guide uses public store information and does not claim step-by-step tests on a personal device or private server. Readers should rely on their own interface and observations.
