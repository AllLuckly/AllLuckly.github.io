Use three original sentences to check candidate selection and document text instead of assuming matching input letters establish the intended word.

1. Preserve three exact target sentences

Create an ordinary practice note preserving A 会议九点开始。, B 他会意地点头。 and C 会议结束后，他会意地点头。. A concerns a meeting, B understanding, and C uses both meanings. The target is the specified wording, not letting the keyboard decide the event. Use nonsensitive practice material without real notices or private chats. Keep the target separate from typed results; copying it into the result area is not evidence of Jianlai candidate selection. Retain the three identifiers.

2. Fix the input scheme without ranking dictionaries

Confirm Jianlai and a Chinese layout you already use, retaining theme, size and host. 会议 and 会意 commonly share huì yì; in untoned pinyin their letters can both be huiyi, so selection needs the target sentence. For another scheme, follow its actual rules rather than impose pinyin on every custom layout. No candidate position is guaranteed, and ranking does not establish semantic correctness. This task checks final text, not a dictionary score.

3. Check A’s candidate and insertion separately

Enter A and inspect the actual candidate near the target, choosing the meeting sense before completing the sentence. Candidate visibility and inserted document text are different evidence; inspect the committed result instead of only a candidate screenshot. If whole-sentence entry already produces the target, record that actual path without prescribing word-by-word confirmation. Mark a wrong 会意 in A rather than change the target or treat the words as interchangeable. Shared pronunciation does not erase meaning or spelling distinctions.

4. Change context for B while retaining the scheme

Save A and enter B independently under the same Chinese scheme and editor. The target 会意 means understanding; previously choosing 会议 does not justify accepting this round’s first item automatically. Inspect surrounding characters too, so one correct word does not hide another error. Record whole-sentence versus segmented selection without calling it automatic understanding of every context. Preserve target and result, and do not count uncommitted composition as saved document text.

5. Check both meanings inside C

After entering C, identify the opening 会议 and later 会意 and compare their order with the target. One search hit cannot pass a sentence containing two similar-looking but different positions. Record both targets and punctuation externally without assuming semantic highlighting or automatic error detection. Even a combined sentence candidate needs document inspection after commitment. A word absent from current candidates does not prove its dictionary entry is missing; the returned scope alone is insufficient.

6. Correct only an observed wrong occurrence

If a real wrong choice occurs, preserve it and note composition versus committed state before correcting that occurrence only. Use visible deletion/candidates before commitment and the host’s actual cursor tools afterward. Host selection menus are not Jianlai-only features. Recheck neighbours, punctuation and the other sentences instead of deleting everything for one word. If no error occurred, record that honestly. No private mis-send is needed, and one correction does not promise permanent learning or a personal dictionary.

7. Diagnose entry, selection and storage separately

For wrong input letters, inspect scheme/keys; for a correct candidate but wrong document, inspect selection/commitment; for missing text after leaving, inspect host storage/location. These are not all unknown vocabulary, and clearing history is unnecessary. Change one condition and retain target, result and version. Enlarge uncertain characters rather than guess shapes. Compare an ordinary note when a special field excludes third-party keyboards, without bypassing platform boundaries. Unreproduced causes remain unknown.

8. Reopen and deliver a position-by-position check

Save, leave and reopen all three sentences. Without old judgments, locate each 会议/会意 and compare with the target. Deliver scheme, actual selection path, positional results and any real correction instead of “homophones normal.” Separate meaning, candidate ranking, composition and host storage, leaving learning mechanisms unknown. Recheck new schemes/material rather than certify all Chinese vocabulary from three sentences. The deliverable is a verifiable small draft, not device dictionary accuracy or automatic semantic understanding.
