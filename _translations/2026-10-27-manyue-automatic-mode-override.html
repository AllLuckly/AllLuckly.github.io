Automatic layout can reduce initial setup, but one image’s proportions do not define an entire book. Compare automatic and explicit choices on mixed material and retain a rollback. Geometry-based decisions should not be confused with understanding panels or narrative intent.

Choose three layout references

Use readable page-based, vertical and mixed references where available, noting source, opening image and a middle scene. Include a meaningful unusual image in the mixed sample. Define expected direction and layout first so the evaluation does not simply adopt whatever automatic selection produces.

Read the automatic-choice conditions

Inspect the available automatic option and its description, recording its state and the current mode. Check explicit book preferences before inferring precedence. If absent, keep manual reading. Temporarily disable a recorded override when needed rather than deleting records or altering content to force automatic behaviour.

Observe each automatic result consistently

Open each sample through the same kind of entry point and record the chosen mode before changing it. Test movement and inspect both opening and middle content, particularly a wide cover before narrow pages. Record whether behaviour appears only at entry rather than assuming continuous per-image classification or a universal algorithm.

Evaluate suitability through reading

Check dialogue and spreads for page books, continuity for vertical comics, and transitions around unusual images for mixed material. Record concrete issues such as wrong narrative direction or unreadably small text. Separate mode, gesture mapping and source ordering before diagnosing file damage or repackaging originals.

Choose a deliberate manual baseline

Record the automatic result, then explicitly choose a suitable mode. Inspect whether doing so disables automatic selection. Keep margins and counts stable for the first comparison. Use supported book scope for exceptions rather than resizing source images to influence the automatic rule.

Verify chapters and reopening

Check another chapter and reopen the same entry. A mirror or another file identity may not share preferences. If behaviour reverts, record the chapter, scope and action and repeat consistently before clearing anything. A simple sample can test entry behaviour but does not validate an entire mixed-format series.

Keep a default with explained exceptions

Keep automatic defaults with a few explained overrides when useful, or use a stable manual default for a mostly mixed collection. One unsuitable book neither proves universal failure nor requires blaming the user. Record exception identities and reasons and revisit them when files change.

Acceptance and mistaken assumptions

Finish with understood automatic choices, explicit overrides and stable reopening. Image geometry is only a clue, and manual selection may affect the automatic switch. Inspect actual linkage and keep rollback values. Natural reading and recoverable position matter more than requiring automatic handling to decide every layout correctly.
