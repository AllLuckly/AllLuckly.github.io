Convert one authorized, unprotected MOBI to EPUB and separately verify the job, output and Book Isle import.

Choose one book you may convert

Prepare a self-created or explicitly authorized, unprotected MOBI novel, a computer running calibre and an iPhone or iPad with Book Isle. Keep the MOBI original in a separate folder and record title, edition, chapter name and opening and closing passages. The Book Isle listing says MOBI can be managed but recommends conversion for reading; EPUB is a supported reading format. Renaming an extension is not conversion. Purchase or reading permission does not automatically authorize removing protection; ask the publisher for a lawful accessible edition when a file is protected.

Check the source record in calibre

Open calibre, add the one working copy using the current Add books entry and wait for its record. Select the row and compare title, author and source; same-named translations are not automatically the same book. Inspect the formats actually listed and confirm MOBI input. If EPUB already exists, stop and save that EPUB separately before identifying its edition and source; do not rely on a replacement warning always appearing. Do not edit calibre’s managed folders directly or delete the original to handle a duplicate record. If the displayed author sort name or normalized title differs, compare it with the file source. A change to displayed metadata does not mean the original body text changed. When edition identity remains uncertain, compare chapter and passage evidence before choosing a similar title to convert.

Convert just the selected book

With the verified row selected, open Convert books, choose individual conversion, and check MOBI input and EPUB output in the conversion window. For a simple novel start with current default settings; retain the earlier notes and do not bulk-apply layout rules you do not understand. Start the job and wait for calibre to report completion. Labels and window positions depend on the installed version. If an existing EPUB would be replaced and a prompt appears, cancel and preserve it until you have decided which edition to create.

Separate job status from available formats

After the job, inspect the actual success or error and whether the book record lists EPUB. Queuing, a closed window or the original remaining in the list alone does not prove conversion succeeded. If calibre reports protection or cannot parse the file, retain the original and error and stop; do not bypass restrictions. For damage, check completeness with the lawful source. Record tool version and failure stage instead of blaming every error on Book Isle. A generated format still needs content checking; output size cannot substitute for reading.

Sample-check the output on the computer

Open the new EPUB in calibre and compare the table of contents, beginning, middle, end and one meaningful note or illustration against the original; do not invent a note if the sample has none. Observe paragraph boundaries, punctuation and chapter navigation. Layout changes differ from missing chapters, garbled text or wrong order; record them separately. If unacceptable, retain the MOBI and output for diagnosis and consider obtaining a better EPUB from a lawful source. An openable file is not proof of completeness.

Save the EPUB separately where you can find it

Select the record in calibre and use Save to disk, choosing the single-format option and EPUB, or an equivalent option actually visible in your version. Calibre may create author and title subfolders: record the generated path rather than directly moving files within its internal library. Confirm the saved file is EPUB, not the original MOBI or a metadata sidecar. Use an existing trusted transfer method to put the EPUB in a location accessible to Files on the mobile device; retain the computer original after transfer. An export template can produce a filename different from the source MOBI; match author, title and export directory instead of renaming it back unnecessarily. If a namesake already exists in the destination, choose an empty folder to avoid overwriting another edition.

Import into Book Isle and check the same content

Using Book Isle’s actually visible local import entry, find the saved EPUB in the file picker and verify filename and edition before import. Locate the result on the shelf and distinguish it from any same-named older book. Recheck the recorded chapter, same passage, illustration or note and ending. If the app reports a duplicate or another format exists, identify the actual record and readable edition instead of deleting the original to tidy counts. A sample is not exhaustive; record navigation or character differences and compare the computer output.

Retain originals, output and unresolved differences

Leave and reopen the EPUB from the shelf. Record source file, conversion-tool version, output path, checked passages and unresolved issues. If offline reading is needed and practical, temporarily disconnect for a sample check and restore the network. Retain both MOBI original and EPUB output; do not assume previous reading position or notes map automatically because paragraphs and chapter identifiers may change. Mark untested items accordingly. Opening this EPUB confirms only the checked content, not lossless conversion of every MOBI or a way around protection.
