A nonnegative square alone does not complete a minimum proof: the lower bound must be attained by an allowed input. Use an original card with three domains in Book Isle, retaining algebra, equality conditions and counterexamples. Recalculate externally; the reader is not an automatic optimizer.

Fix the function and three condition cards

Externally make Q1 with f(x)=x²−6x+11 over all real numbers. Q2 keeps the function but requires x≤0; Q3 uses x<0. Add markers, export a clear PDF/EPUB and retain editable sources. Import into Book Isle and check all inequality signs and constant eleven, rather than guess a faint equality bar. Record file and card identity so conditions do not silently carry over. For image formulas inspect characters instead of assuming searchable exponents or symbols.

Add and subtract nine, then expand back

Half of −6 is −3 and its square is 9. Add and subtract 9 to obtain (x−3)²+2, rather than insert 11 into the square. Expanding gives x²−6x+9+2, recovering the original coefficients. Mark added and removed terms together to show the function is unchanged. The erroneous (x−6)²+11 expands to x²−12x+47. Keep that faulty control for checking instead of deleting inconvenient terms until the answer looks right.

f(x)=x^2-6*x+11
=x^2-6*x+9-9+11
=(x-3)^2+2
all real x: f(x)>=2; equality iff x=3

Write the lower bound and equality case separately

A real square is nonnegative, so f≥2. Separately solve (x−3)²=0 to obtain x=3 and verify it belongs to Q1, establishing minimum 2. The first statement alone is only a bound. Highlight inequality and equality separately if the format supports it; otherwise record page locations and keep two-column notes externally. Minimum output 2 differs from attaining input 3. Label point(3, 2), input 3 and output 2 rather than use one unexplained answer number.

Use symmetric samples as checks rather than proof

For x=1, 2, 3, 4, 5, f=6, 3, 2, 3, 6. Equal distances from 3 give equal values, and f(0)=11 checks the constant. Samples do not exclude a smaller value at an unlisted real input; the square argument proves the whole domain. Any graph is an external aid with labelled axes, not exact values measured from pixels. Keep table and proof separate; the smallest sampled value does not make x=3 valid in every changed domain.

For Q2 remove the forbidden equality point first

On Q2, x≤0 excludes 3, so minimum 2 cannot be copied. Here x−3≤−3, hence its square is at least 9 and f≥11, attained at x=0. The function is unchanged; allowed inputs changed. f(−1)=18 checks one larger value without proving the entire range. Keep domain x≤0, bound 11 and equality input 0 together so an excerpt never loses its condition. A graph comparison must show only the permitted portion.

Independently use f(x)−f(0)=x(x−6). For x≤0 both factors are nonpositive, so the product is nonnegative and 0 attains that domain’s minimum. For x<0 it is positive, agreeing with unattained 11 on Q3. The product argument also needs its domain; it is not nonnegative for every real x.

If Q2 retains positive-input samples for comparison, mark them outside-domain references rather than allowed candidates. Evaluating the polynomial at 3 does not make 3 an allowed input on that card.

Retain a bound without a minimum on Q3

For x<0 the square exceeds 9 and f>11, while 0 is excluded. Inputs−0.1 and−0.01 give 11.61 and 11.0601. More generally x=−ε with ε>0 gives 11+6ε+ε², approaching 11 as ε→0. The infimum 11 is unattained, so Q3 has no minimum. There is no closest negative real number. Restricting to integers would be another domain and cannot be silently substituted to manufacture an answer.

A separate Q4 over negative integers has nearest-to-zero allowed input−1 and minimum 18; other negative integers lie farther from 3. This new number set does not repair Q3’s absence of a real-domain minimum. Label Q4 separately and retain changing the number set as an explicit condition.

Use a negative-square control to check extremum direction

For real-domain R, g(x)=−(x−3)²+2 has maximum 2, not minimum. The leading minus makes larger squares lower values; g is unbounded below. Similar appearance to Q1 cannot transfer its conclusion. Diagnose constants by expansion, domains by inequalities and attainment by the equality input. A few samples still do not prove a global extremum. Record a specific correction rather than treat finding an answer paragraph as completing the checks.
