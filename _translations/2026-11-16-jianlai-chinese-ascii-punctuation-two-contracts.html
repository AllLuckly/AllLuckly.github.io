Prepare two punctuation-specified versions of the same wording and inspect quotes, colon, comma, ending and version dot separately.

1. Preserve two distinct targets

Preserve A 记录：“review”，版本2.1。 and B 记录: "review", 版本2.1. as two original punctuation exercises with the same words. A uses Chinese display punctuation; B specifies ASCII punctuation and spaces. B still contains Chinese wording, so ASCII punctuation does not mean an entirely ASCII string. Keep identifiers separate. Both version numbers retain an ASCII dot; changing surrounding style does not justify changing that identifier.

2. Identify five punctuation locations

List colon, opening quote, closing quote, comma and ending, plus the version’s dot. Paired quotes need direction, not merely two similar curved shapes. Do not infer B’s straight quote characters from visual width alone. Preserve specified spaces rather than add them to A. This does not rank one style as universally correct. A different publishing standard needs a third explicit target instead of being retroactively applied to these two originals.

3. Enter A through actual available symbol pages

Confirm Jianlai and an ordinary editor, then use actual symbol pages for A and inspect committed text. No universal hold menu or one-tap full-width conversion is promised. An unavailable required character remains incomplete instead of being replaced and passed. Preserve Chinese, English and version wording rather than translate/rewrite while entering punctuation. Save A before B so the next language state does not obscure this round’s conditions.

4. Check B’s straight quotes and ordinary delimiters

Enter B separately and inspect colon, straight double quotes, comma, final ASCII period and specified spaces. If candidates or the host change quotes, record actual stored characters before using available correction methods; no identically named Jianlai substitution switch is assumed. An English-looking keyboard does not prove every symbol satisfies the contract. Read the document rather than accept a retained Chinese comma merely because B remains understandable.

5. Separate the version dot from the sentence ending

Both drafts contain the version dot; B also ends in an ASCII period. Their positions and roles differ. Do not replace every dot and damage the identifier, or include A’s final Chinese stop in the version. Read the surrounding words through the ending without assuming automatic grammatical/version recognition. The digits are a text identifier, not a calculation. Recover the whole sentence after wrapping instead of deleting punctuation solely because its display position moved.

6. Distinguish entry from storage substitutions

For an immediate mismatch, inspect input state/selected symbol. For a later change, inspect host storage/presentation/substitution. Different glyph appearance is not necessarily a different character, and a screenshot alone does not prove a code-point change. Keep uncertainty or use an existing separate plain-text check without attributing it to a Jianlai report. After one correction, inspect paired quotes and nearby spaces rather than delete all punctuation and claim a one-location edit.

7. Avoid turning punctuation differences into semantic failure

Different punctuation contracts do not establish understanding of publishing standards or equivalence with every translation. Check the specified characters and diagnose special-host restrictions separately rather than change all permissions. Vary one input, symbol or host condition while retaining before/after evidence. No bulk formatter, width scanner or punctuation corrector is invented. This task delivers manual comparison, not an automatic-feature claim.

8. Reopen and deliver two independent proofs

Save and reopen A/B independently, checking five punctuation locations, version dot and spaces against retained originals. State which contract each meets, remaining uncertainty and actual corrections rather than simply reporting Chinese/English input. New hosts or standards need new targets; old theme screenshots are not current document evidence. Deliver two character-checkable proofs, not a publishing engine, semantic correction or device-wide consistency claim.
