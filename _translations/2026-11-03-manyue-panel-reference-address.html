A reference to page five may identify a whole page when the evidence concerns one small panel. Build a human-readable address that lets you or a later reader find that panel. Use available page bookmarks as entry points and describe the position manually, without assuming automatic panel detection, coordinate annotations or screenshot recognition.

Choose a panel that needs precise reference

Choose evidence such as a first handover of a key or a changed background sign and state its purpose. Avoid cataloguing every panel without need. Establish work, language, edition, chapter and source identity, then inspect the complete page. Useful nearby objects or dialogue help distinguish a small blank-looking panel. The address supports personal notes and legitimate reference, without editing the comic or substituting extensive copied artwork for location details.

Combine page location with a content anchor

Pair the displayed page number with a distinctive scene or brief dialogue and, if useful, source image number. Label reader, printed and archive numbering separately. Image descriptions remain useful after cover or pairing changes. For server material record connection and item identity without credentials or temporary URLs. Resolve page identity before panel position so later layout changes do not silently invalidate the address.

Describe row and column in a regular grid

For a regular grid use a consistent description such as top-row centre or second-row right, supplemented by reading order. Left/right refer to the complete source page, not the tap direction. Describe a spanning panel as spanning rather than forcing it into one column. State your convention rather than presenting it as an industry standard, and retain a short content description to distinguish similar actions. The grid narrows the search; content and context still verify the evidence.

Use boundaries and landmarks for irregular panels

Diagonal, inset and borderless layouts need descriptions such as the narrow panel below the window figure or the lower-right inset in the large scene. Identify its source page and neighbouring boundaries first. Do not force decorative elements or speech balloons into panel identities; say “region” if uncertain. Two stable landmarks are more useful than display-dependent pixel coordinates. The goal is recognisability, not a tidy but inaccurate grid or an app-generated panel outline.

State the reference unit for spreads and tall images

In paired display identify the left or right source page before its internal location, not merely the screen corner. Distinguish a single wide image from paired portrait images. For tall pages use narrative landmarks, such as the second horizontal panel after the bridge, rather than screen-height segments. Percentages are secondary. Restore the full image before defining position so panning a zoomed detail does not confuse its relationship to the source.

Use bookmarks for the page-level return

Create a supported page bookmark and attach the full panel address in your notes, externally if remarks are unavailable. Leave the page before testing the return so immediate spatial memory does not conceal a poor description. Validate one address before adding more. Cropping and reimporting panels would create another file identity and weaken the source-context relationship; it is unnecessary here.

Read the adjacent panels when checking a reference

After locating the panel, inspect its neighbours for context: it may depict memory, imagination or reported action. Precise location does not guarantee correct interpretation. In a replacement edition, find the content anchor and inspect changed panel boundaries before dating a revised address. Separate visible facts from analysis and use only necessary quotation. The address answers where, not automatically what it means.

Acceptance and address failures

Finish when the record alone can recover the same page and panel later, with clear edition, units and context. Check identity, pairing units and tall-image landmarks before rewriting internal positions. Restore the whole view if the target seems absent. Location text and minimal authorised evidence can support discussion without sharing a book. Extend a convention proven on two samples rather than claiming an automatic panel-citation system.
