Understand Apple’s system boundary

Apple’s developer documentation says the default restricted custom-keyboard extension cannot access the network and has restricted writes to its containing app’s shared container. If an app declares open access and the user explicitly allows it, the system permits additional capabilities including network access and a shared container. This describes platform capabilities; it does not establish when or why a particular keyboard collects or sends data.

Distinguish other system permissions
