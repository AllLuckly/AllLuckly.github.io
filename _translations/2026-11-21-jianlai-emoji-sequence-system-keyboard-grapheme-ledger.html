Adding an emoji to ordinary text may involve switching between Jianlai and the system emoji keyboard. Emoji appearance, component code points and the text saved by the host have separate boundaries. Do not describe the system emoji picker as a feature Jianlai necessarily includes.

Prepare a nonprivate target and copy

Create a practice copy in an ordinary note you control. The target is 完成 👍🏽: two Han characters, one ASCII space and a medium-skin-tone thumbs-up. Preserve a separate reference card with U+1F44D for the base thumbs-up and U+1F3FD for the medium-skin-tone modifier. Their combined appearance as one emoji does not mean one Unicode code point. If the device offers no such tone, mark it pending; do not use private conversations or real work items as test material.

Record current keyboard and system conditions

Confirm Jianlai is added and actually selected in an ordinary field. Record device system, host, Jianlai version and previously enabled keyboards. Apple provides a system emoji keyboard, but available entry points depend on version, settings and host. If it is not enabled, add it according to Apple’s instructions only if you wish and know how to restore the setup. If restoration is uncertain, record the baseline and stop. Do not remove other keyboards, change permissions or use secure fields.

Enter the words first

Using Jianlai’s actually available Chinese scheme, enter “完成,” confirm candidates or direct submission as appropriate, and insert one ASCII space. Inspect document text and cursor; key labels or candidate previews do not establish committed content. If the space looks unusually wide, a local character inspector may check U+0020. Without a reliable tool, record appearance rather than guessing from font spacing. Preserve the first result and the reference.

Observe the actual emoji entry and tone choice

Switch to the emoji keyboard using the system’s visible method and confirm the keyboard actually changed. Do not assume Jianlai has an in-app emoji panel or a fixed long-press gesture. Find thumbs-up and any actual available skin-tone choices and select the target medium tone. If absent or indistinguishable, record the state and leave it pending; selecting the default tone does not complete the target. Record the action without sharing recent emoji or usage history.

Separate display from document text

After selection inspect whether the host shows 完成 👍🏽, including the text, one space and emoji location, then return to Jianlai using the available method. Record keyboard and cursor before and after. A displayed option is not necessarily inserted; Jianlai reappearing does not prove the host saved it. If the document shows a box, default tone or another form, preserve that observation and record device, font and host without immediately asserting the raw sequence was lost.

Inspect the raw sequence locally

If a local Unicode tool can preserve original text, inspect the practice sentence: 完 and 成 are U+5B8C and U+6210, the space U+0020, and thumbs-up plus tone U+1F44D U+1F3FD. Copying to a tool can also change text, so verify it with a known reference first. Without a reliable tool, record appearance observed and code points pending. Five code points do not necessarily mean five cursor moves or five user-perceived characters; movement and deletion require separate observations.

Observe deletion in an independent copy

For a visual control you may insert an unmodified thumbs-up in another practice line, then the selected tone if the system actually offers it. Record user choice, appearance and committed text separately. Neither default nor modified appearance is universally right or wrong; this exercise specifies one sequence. Glyph design differs by device, so color alone does not prove the sequence. Keep the host and recoverable copy constant and obtain consent before using another person’s device.

Preserve the verified original, copy it to a separate line, place the cursor after the emoji using the host’s available controls, and perform one deletion. Record the result. A host may delete the entire sequence at once or behave differently; do not assume a deletion unit or report several deletions as one. If extra text is deleted, record it and restore from backup. Stop if cursor position or deletion is unclear rather than repeatedly editing the original.

Troubleshoot and restore the usual keyboard

If the emoji entry is missing, check enabled system keyboards and actual switching. For a default tone, inspect the choice and host display; for unexpected deletion, separately record host behavior, cursor and sequence. Change one condition per trial. Do not automatically blame Jianlai for system emoji or host behavior. Restore the original keyboard list, usual keyboard and any changed volume or display settings. Retain the reference and nonprivate record. Apple’s emoji guidance and Unicode’s emoji mechanism inform the exercise; no physical input or emoji compatibility test is claimed.

Record the date and system version; observe again after an update instead of treating the old result as a current guarantee.
