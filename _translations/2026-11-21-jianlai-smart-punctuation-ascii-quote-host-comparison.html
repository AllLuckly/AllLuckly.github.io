Straight and curly quotation marks may look similar but are different characters. Use an unsent practice sentence to compare Jianlai input, system options and the host’s final text. Do not assume Smart Punctuation affects every third-party keyboard or editor.

Specify two targets

Prepare the literal text He said, "Go.": one ASCII space after the comma, capital G, period inside the quotation marks, and U+0022 straight double quotes on both sides. The display version is He said, “Go.”, using U+201C on the left and U+201D on the right, with all other characters unchanged. These are different punctuation contracts. Keep a reference card and practice on a separate copy; do not use real conversations.

Check the host and keyboard baseline

Choose an ordinary text editor you control that will not publish or send automatically. Confirm Jianlai is added and actually selected in the field; record device system, host, keyboard language and layout. Inspect the system keyboard settings for an actually visible Smart Punctuation option and record its original state. If absent, mark it unconfirmed. Do not assume this setting controls Jianlai or the host; observe each separately. No privacy permission or password field is needed.

Enter a first draft under the original setting

Use actual visible keys or candidates to enter the first sentence, recording how each quote was entered. Inspect case, comma, space, period and committed text. If candidates or the host alter quotation marks during entry, retain the first result and record when it changed. A key label showing a straight quote does not prove the document retained U+0022; an automatically curved result is not a user’s deliberate selection.

Inspect committed text before deciding character identity

Look at the shape and direction of both quotation marks, recognizing that some fonts make them hard to distinguish. Use the host’s available selection or copying or a local character inspector for the nonprivate practice text. If possible inspect the code point of both quotes. Without a tool that verifies original text, record visual observation and code points pending. Pasting or the tool can also transform text; first validate against the two saved known references. Do not upload private text to an external site.

Change one system condition

If Python 3 is available, this local program prints every character and code point from the nonprivate practice sentence. It uses no network and does not edit the original. Copying or terminal input may still transform text, so validate both reference cards first; similar appearance does not replace code-point inspection.

text = input("Practice sentence: ")
for position, ch in enumerate(text, 1):
    print(position, repr(ch), f"U+{ord(ch):04X}")

The literal version’s two quotes should be U+0022; the display version uses U+201C and U+201D. Positions depend on the actual text, so check each line rather than applying another sentence’s indexes. If references change before entering the tool, stop and mark the original characters pending.

If Smart Punctuation is shown, record its original setting and change only that option. On a new line repeat the same sentence, keeping host, keyboard, input language and manual actions fixed. Record the visible setting, actions and final document before and after. An unchanged Jianlai result is useful evidence, not proof of an ineffective setting or app defect. Skip and mark pending if unavailable or unsafe to change, then restore the original setting.

Optional system keyboard control

To explore scope, switch to an already enabled system keyboard in a new copy in the same host. Try the same target under the same system option and record the actually selected keyboard. Do not change host settings at the same time. Different outcomes establish only this observation, not behavior of every third-party keyboard or app. Do not remove or alter previously enabled keyboards for the exercise.

Troubleshoot and protect the original

If quotes change after entry, distinguish keyboard input, candidate confirmation, host autoformatting and pasted source. If they change only after reopening, examine saving and synchronization separately. Check the target field and similar punctuation, changing one condition per retry. Straight and curly marks are not universally correct or incorrect: the literal and display drafts have different contracts. Preserve the first result rather than overwriting it to hide differences.

Restore and deliver

Restore the original Smart Punctuation setting and usual keyboard; confirm existing drafts and other keyboards remain. Deliver references, before/after system setting, keyboard and host, actual input actions, character identities or pending status. If characters cannot be distinguished, report the observed scope only. Public multilingual information and Apple’s system settings inform this exercise; no physical auto-replacement or compatibility test is claimed.

Record the date and device system version. Observe again after a version or host changes instead of carrying the old result forward.
