A missing edge marker in a PDF need not mean that the image was permanently cut away: a page box may restrict the default visible region. Record two original samples in ManYue and interpret them using external page-box information. The reader need not edit PDF boxes, and a box record does not guarantee complete recoverable content outside it.

Choose two original samples with known boundaries

Create one simple page in an existing desktop PDF tool, with central artwork and different markers on its left and right. Use no restricted works or private data. Obtain both page-box records from the creator, or list them with an available read-only inspector. A and B have identical page content; only B’s visible box is narrower. Label the filenames A and B. Record tool, time, page position and output path, preserving the originals. Confirm that the tool changed boxes rather than rasterising or deleting artwork while presenting a single-variable control.

Read four coordinates as a rectangle

Here MediaBox is [0 0 600 800]; A has the same CropBox, while B uses [50 0 550 800]. Read the values as lower-left and upper-right coordinates. This example has no rotation or special UserUnit. B’s visible width is five hundred and height eight hundred, not a width of fifty or five hundred fifty. Subtract left from right and bottom from top, retaining the coordinate assumptions. These user-space numbers are not character measurements in centimetres or values inferred from the phone’s screen. Rotation or a nonzero origin requires its own record.

Separate media extent from display clipping

MediaBox describes the media extent; CropBox specifies the clipping region for display or printing. B is inset fifty on each side while its central artwork remains inside. A missing explicit CropBox may inherit through the page tree or default to MediaBox; absence from one dictionary does not mean no visible boundary. Use the creator’s effective box record instead of hand-editing objects. Different boxes neither double the page count nor create another cover: they are geometric properties of one page and must not be added as content pages.

Compare markers after import rather than fitted size

Import A and B separately, confirm identities and page position, then compare left marker, centre and right marker in the same orientation and single-page conditions. Record visible, partly visible or not visible, rather than only saying B enlarged. Fit-to-screen may fill the screen with a narrower region without changing artwork dimensions. Keep a full-page record or positional note before enlarging details. If actual clipping differs, record version and reading path honestly; a format concept is not proof that every PDF engine renders it identically.

Keep changing a box separate from deleting content

Save C externally by restoring only the visible box to A’s extent, then check whether both markers return. Their return supports that the content remained in that copy. Failure to return does not prove ManYue lost it: check deletion, an already cropped image or another clipping operation. C is a newly generated external file, not an in-reader one-click recovery. Shrinking CropBox is also not a privacy-removal method: it generally hides display rather than deleting content. This exercise uses only original non-sensitive material.

A page box cannot recreate missing image pixels

Create a separate control D in which the left marker was actually removed externally. Restoring a six-hundred-wide box cannot recreate that marker. Comparing B and D shows why identical absence may have different causes: content can lie outside a box or be absent altogether. A reading screenshot alone cannot distinguish them; combine originals, creation records and external inspection. Content-stream clipping can also matter. This lesson does not require dissecting every PDF object or infer whole-book completeness from one marker.

Check inheritance, rotation and copy mismatches

When results disagree, verify actual paths and page positions for A, B and C, then effective boxes, rotation and any export changes to content. Do not attach an old same-name file’s observation to a new copy or clear all app data to investigate one page box. If an inspector shows raw dictionaries without inheritance, request effective values from the creator instead of guessing. Separate reader version, marker observations and geometric evidence. Provide a minimal original sample and steps when seeking help, not a private library or an unsupported single-cause diagnosis.

Leave and return to document geometry and appearance

Leave the reader and return to A and B. Confirm the central artwork first, then recheck both markers. Inspect C and D separately instead of predicting results from names. Retain file identity, four effective box coordinates, page position, display conditions, three marker observations and any separate content modification. Success explains what geometry and actual appearance each establish, not guaranteed recovery of every cropped work. This adds PDF page geometry to ordinary edge checking without replacing source quality, rights or whole-book checks.
