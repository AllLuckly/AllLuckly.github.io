Book Isle 1.1.4 adds result counts and a clear-filters entry to the note centre, helping explain a narrowed list. Audit existing notes/highlights instead of treating no matches as deleted content. Search, type and colour jointly define scope; clearing them changes neither quoted text, annotations nor highlights.

Establish an all-record baseline on the Notes page

Open global Notes and record type, colour and search state. Clear existing filters to All types, all colours and empty search. Record total notes/highlights and two or three recognisable items with book title and short necessary text, not entire chapters. With no records, create a few personal annotations/highlights in permitted sample material, without deleting originals. Book section headers are not notes; count records rather than sections.

Distinguish annotated records from highlight-only records

Select With notes and confirm personal annotation text, then Highlight only for highlights without annotation. Adding annotation can remove an item from Highlight only; these categories distinguish annotation presence rather than requiring an item in both. All restores their combined scope. Record selected type/count at every step instead of the title alone. Observe existing samples without mass-erasing notes; use one recoverable self-written test if checking a transition and retain its original content.

Treat colour as highlight colour, not cover colour

Fix a type, open colour selection, compare all colours with a colour present in a sample and record matching results. This is highlight colour, not cover colour or a search for all similarly coloured book text. Zero matches need no library-wide recolouring. Type and colour operate together, so an annotated item with another colour is excluded. Change one condition and record result/total counts to understand the intersection before restoring all colours; an empty list is not automatically a loading failure.

Check search against five stored fields

Enter a known fragment under the current conditions and check five stored fields: selected text, annotation, book title, chapter and author. This is not full-book text search. A word in the book but absent from note records may not match here. Verify actual text/case/whitespace rather than cycling remembered approximations. Search combines with type/colour, so fewer matches can be expected. Identify matched records and fields; reduced count alone proves neither accurate search nor absence of the word in the source book.

Distinguish matched count from the overall count

With filters, the summary distinguishes displayed matches and overall records; without them it gives the total. Read the whole phrase rather than interpreting a slash as counts of two content types. An illustrative 2 of 6 means two shown, not four deleted; actual numbers come from the device. Current results include matching items across all book sections, not only the first. Batch mode adds a selected count, another scope. Exit selection before comparing ordinary filter summaries in this exercise.

Use Clear filters to investigate empty matches

Search an invented token known absent from sample records and inspect No results and Clear filters. Clear, then verify empty search, All type and all colours and compare returned baseline items. This clears more than a keyword and deletes no matching records. With no notes initially, clearing cannot create them; distinguish that from existing records with no match. Reopen one known item to verify quote/annotation identity rather than relying only on equal totals. Record/remove the test token so it cannot interfere later.

Keep scope records and restore everyday conditions

Keep type, colour, keyword, displayed/overall counts and a representative record per round, sanitising titles/notes before sharing. Restore prior search as needed rather than leaving All solely for the exercise. Do not delete notes, reimport books or clear databases to repair zero matches before checking conditions. Before exporting, distinguish current results from selected items through the export-scope workflow; one visible screen is not the export set. This checks the current note library, not unsynchronised remote/other-device data.

Inspect combined conditions and batch mode for count anomalies

For missing notes, inspect type/colour/search and whether the summary is showing selection. If clearing still differs, check book identity and recent edits/sync with times recorded. Do not delete content to force With notes and Highlight only into equal counts. For failed phrase search, establish whether it exists in stored excerpts rather than only the book. Preserve sources and minimal reproducible steps for persistent issues. Explain each count’s scope instead of treating Clear filters as universal recovery.
