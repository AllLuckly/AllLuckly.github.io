Side-by-side demonstrations can make changes look simultaneous. Read a single already-composed two-panel file in iCouldPlay: observe each panel separately, then return to the shared file timeline. This is neither simultaneous playback of two sources nor a new dual-window feature, and one screen does not establish common recording time.

Prepare distinguishable self-made material

Film two marked desktop areas, with a red card left and blue card right, moving, pausing and returning them in one shot. An authorised existing two-panel course also works without installing an editor. Record file, duration and panel labels, preserving the original. If separate recordings were composed later, label the result as a composite rather than proof of a shared recording event.

Fix panel labels and orientation

Use screen-left red area and screen-right blue area rather than “my left-hand side”. After rotation, verify that labels still match; a person’s own left differs from screen-left. Record the file location of any mirroring, panel swap or rearrangement, then continue with updated labels. The first pass establishes panel identity, not which action is faster.

Follow the complete left action first

Play from before the segment and follow only red. Note approximate file times for onset, key state, pause and return, using explicit descriptions such as red card fully outside its box. Do not fill gaps from the other panel’s state. Mark title-obscured actions unseen instead of reconstructing a hand path from the outcome. Preserve this left-panel pass, then prepare the blue-panel pass. Do not silently revise the saved left-panel account while watching the right.

Record the right process independently

Return to the same start and follow blue using the same state criteria, without forcing equal step counts. It may pause less or split a movement in two. Do not assign a caption about the left panel to the right; record narration references separately. Compare independent observations before accepting a course’s claim of synchronisation.

Align both records by file time

If red leaves its box near five seconds and blue near seven, record an approximate two-second difference with display precision. Equal vertical placement does not make that difference zero. With separately recorded panels, a two-second edited difference is not an experimental performance result. Compare the sequence presented in this file, not original recording times or scientific outcomes.

Track freezes and replays separately

If one panel stays unchanged while the other moves, it may be a real pause or an edited freeze; appearance alone may not decide. Record replay, comparison-pause or speed labels separately from observation. Overall playback speed cannot correct one panel independently because it affects viewing of both. Without originals, mark the cause unknown while preserving the visible edited sequence.

Revisit before each key state

Replay from before red leaves through after blue leaves, checking both logs. If seeking lands mid-action, start earlier rather than infer order from a still. Inspect whether onset was confused with fully leaving the box; correct the criterion while retaining the earlier note. Revisit enough to verify, without repeated dragging to fabricate frame precision from ordinary controls.

Handle obscured or undersized panels

Record when and where captions obscure hands or boundaries. Temporarily disable selectable captions for comparison, then restore them. If burned-in text cannot be disabled, record it as source-image occlusion; do not generalise a selectable-caption result to every text layer. Keep both panels visible when using available fit controls, since enlargement that removes one side changes the comparison. Leave unreadable states unassessed rather than guessing to fill the log.

Finish two logs with bounded conclusions

Keep file identity, panel labels, two action logs, common times and unseen intervals. State which edited event appeared first and which pauses remain unexplained, not that a method is always two seconds faster. Reopen the same file and restore viewing position. Hand off external notes with lawful references without claiming automated multitrack analysis, dual-stream sync or device performance testing.
