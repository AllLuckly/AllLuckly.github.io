Once single-file import works, folder import makes a batch easier to bring in. The goal is not to fill the library immediately, but to record counts, platforms, and same-name relationships so you know what copied and what needs separate handling. Practice with fewer than ten items before expanding.

Choose a directory with a clear scope

Create a dedicated import directory in the system Files app containing only ROMs you are entitled to use and necessary disc companions. Keep screenshots, download notes, old archives, and temporary files elsewhere to avoid irrelevant clutter. Subdirectories can organize consoles, but do not guarantee that the app will retain the same library hierarchy.

Prepare a short checklist of the expected game count. Games and files are different counts: one disc may have one CUE and several BINs while still representing one game. The file picker's item count is not necessarily the number of library entries that should be added.

Resolve duplicate names before import

Check for exactly identical filenames within a platform. For example, Practice Game.gba in two subfolders may map to the same destination filename after import. Different directories do not guarantee permanent distinction. Give source copies identifiable names, such as region or version markers, and retain a naming reference.

Rename disc files more carefully. A CUE may reference track names; renaming a BIN without updating those references breaks the relationship. Prefer retaining the entire original naming set, checking it separately, then adding it to the batch. On the first organization pass, importing fewer games is better than breaking a complete image for uniform names.

Open folder selection from the plus button

Tap the plus button in Yearn's library and choose folder import. The system folder picker differs slightly from single-file selection. Enter the target folder and use the system's Open or Select button to grant access. Download cloud files beforehand so network and file-reading problems do not arise midway through the operation.

The app scans recognizable files in the selected directory and its subdirectories. This is an import, not continuous monitoring. Later additions to the source folder should not be expected to appear automatically. For new content after an import, prepare an incremental directory and start another import.

Recheck by platform after completion

Stay in the app during import and observe the current file and progress. Back in the library, clear search and inspect platforms separately. Compare main-file names with your checklist first. PS1 companion files may not appear as separate games, which is not necessarily an omission.

Choose three representative samples: the first game, the last, and one with companion files. Check each information page's platform and size, then try reaching its title screen. A thumbnail in the library is not a runtime check. Batch copying completed and every game is compatible are different conclusions; record them separately.

Narrow the scope for missing items

If a whole batch creates no entries, confirm that the folder contains extracted ROMs and that source files are actually downloaded to the device. If only one game is missing, try importing it individually and observe unsupported-format or read errors. This separates directory permissions, file types, and individual-file faults.

If fewer entries appear than expected, check same-name destinations and disc companions before repeating the whole batch. Reimporting identical names may replace current copies and is especially unsuitable for games with important progress. List missing items and retry only those, retaining the unchanged source directory.

Manage source directories and app copies separately

Folder import copies supported content into app-managed storage; the source is not the only working location. During storage cleanup, distinguish originals in the import directory from copies in Yearn's library. Deleting a game inside the app may also affect associated saves. Existing source files do not mean all progress is safe.

After checking, store originals and the checklist in a clearly identified backup location. Do not immediately delete your only source or interpret iCloud save synchronization as a ROM backup. For a collection kept long term, record import date and platform categories so later additions can follow the checklist instead of requiring another full directory review.

Common questions and completion criteria

Will subdirectory names become game groups? Folder import finds and copies files. The library mainly organizes them by recognized platform. A source folder named Weekend Games does not automatically create a favorites group with that name. Use the library's own filters and favorites after import.

Why does one disc image set create only one entry? The app tries to avoid listing companion files beside a main file as duplicate games. Check whether the entry launches correctly rather than trying to give every extension its own library tile.

The batch is organized when every checklist item has a clear result and representative samples reach their title screens. Label unlaunched items Imported, Awaiting Check so an unverified batch is not later mistaken for a fully tested library.
