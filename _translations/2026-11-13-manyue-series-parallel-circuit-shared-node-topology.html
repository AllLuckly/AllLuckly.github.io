Two resistors drawn in separate rows are not automatically parallel, and a shared row does not establish series. Read original paper-only circuits in ManYue, naming nodes along wires before checking connections. This is mathematical diagram reading without power supplies, hardware changes or household safety judgments. The app is a reader, not a circuit simulator or measuring instrument.

State ideal-wire and junction conventions

Make original diagrams A and B without real outlets or repair photographs. Use ideal wires, components R1/R2 and external nodes A/B. Declare dots as junctions and bridge crossings as unconnected; follow another book’s convention when applicable. A node can extend along continuous ideal wire, not merely one printed dot. Bends alone do not create new nodes.

Trace both components on one path in the series sketch

In the series sketch, trace A through R1 to C and then R2 to B, with no other branch at C. Check for bypass wires. Redrawing the same endpoints vertically or in a bent route preserves connectivity; appearance alone does not erase series identity. A third branch at C requires reassessment rather than being ignored to keep the old classification.

Check both shared endpoints in the parallel sketch

In the parallel sketch both R1 and R2 connect between A and B. Check both endpoints: sharing only the left endpoint is insufficient when the right ends differ. Nearby lines are not necessarily connected. Trace all A-wire segments with one checking colour and then B, treating that as your annotation, not a new source component or automatic app wire recognition.

Redraw parallel R2 above-left of R1 while keeping its wires connected to A/B without new junctions. Trace endpoints again; the equivalent still uses the same parallel model. Long wires add no resistance only under this ideal premise. Real wiring can have additional impedance conditions, so the rearranged sketch is not a construction plan.

Use the legend to interpret crossings

A bridge-marked crossing in the control does not merge nodes; changing it to the stipulated junction dot changes topology. Neither every cross nor every dotless meeting can be interpreted without the source’s full symbol convention. For a blurred scan, preserve uncertainty and consult a clear source rather than add a dot that fits your expectation. Zoom can reveal existing detail, not create missing information.

Recalculate with two ideal six-ohm resistors

With both ideal resistors six ohms, series gives twelve ohms. Parallel gives one sixth plus one sixth in reciprocal form, hence three ohms. Identical component counts and values yield different equivalents because connections differ. This fixed-resistance model does not automatically describe lamps, complex electronics or temperature changes. Three below six is a check here, not proof that any real wiring is safe or usable.

Separate currents if an ideal voltage is supplied

For a separate paper calculation with twelve ideal volts across A/B, series current is one amp through both. Parallel total is four amps, with two amps in each branch summing to four. Label total and branch currents separately instead of putting four through each parallel resistor. These are mathematical premises, not instructions to build or touch circuitry. Without a supplied voltage, stop at equivalent resistance rather than invent a battery experiment.

Check broken-looking lines and node mistakes in ManYue

Read the legend and whole diagram in ManYue before zooming C and both shared endpoints. A cropped or obscured line is unresolved, not automatically an open circuit. Repeated A labels can identify one node if the author says so, not by arbitrary letter matching. Check units, connections and branches before altering values. An original paper diagram and arithmetic suffice for help; no live-hardware instructions or claimed simulation are involved.

Leave and return to reconstruct from endpoints

Leave and return with classification labels hidden. State each resistor’s endpoints before calculating twelve and three ohms, adding one- and four-amp totals only if twelve volts is supplied. Keep legend, nodes, paths, ideal parameters, working and unknowns. Explain the conditions for shared current versus shared terminal voltage, not a page-layout shortcut. New symbols or branches require retracing, with originals and readable copies retained.
