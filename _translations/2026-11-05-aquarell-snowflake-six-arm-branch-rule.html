As lines accumulate in snowflake decoration, its six main arms can become indistinguishable from smaller branches. Rather than reproducing a particular ice crystal, establish one clear six-direction design rule and hand-draw an invented snowflake. Specify the main-arm count, branch positions and line hierarchy. No automatic symmetry feature is required in Aquarell: counting, axes and negative-space comparisons keep six hand-drawn directions within one design despite small variations.

Separate the six-direction framework and background

Use an approximately 1600×1600 px square canvas with a mid-dark blue-grey background, initially drawing the flake in pale grey-blue rather than pure white. Mark a centre and draw three guide lines through it, creating six directions roughly 60 degrees apart. Check with a paper sketch or your own angle reference instead of assuming automatic division. Keep the six rays similar in length and leave surrounding space. Separate sketch, main arms, branches and light accents. Confirm a single shared origin. If the lines instead surround a small empty hexagon without reaching the centre, deliberately choose that centre motif or connect the framework before continuing.

Write one repeatable branching rule

Write the design rule outside the artwork: each arm has two left/right branch pairs, one near the inner third and another near the outer two-thirds, followed by one pointed tip. Angle small branches outward with clear separation from the main arm instead of making one crowded starburst. These positions are an invented design, not a claim about every real crystal. Finish only the upward arm first, checking the lengths, spacing and weights of its two pairs. If that sample is crowded, simplify it before carrying it to the other directions rather than repeating an unreadable complex unit six times.

Rotate local left and right with each arm

Arrange paired branches around each remaining arm’s own axis. Local left and right rotate with the arm’s outward direction rather than always running horizontally across the canvas. Draw the upper-right arm and its opposite lower-left partner, proceeding in pairs so one side does not gradually grow larger. Trace each completed arm from centre to tip and confirm the same two branch pairs. If one arm resembles an arrow while another resembles a tree, unify branch angles and spacing rather than filling visual differences with extra short lines. Small hand-drawn irregularities are acceptable, but the rule must not silently change from two pairs on one arm to three on another.

Use distinct weights for main arms and branches

Keep main arms a little heavier than branches. The centre may thicken slightly without becoming a large white ball. Check weights in one pale colour before adding glow. Keep six separate tips rather than adding an equally long second line beside each, which would make the main-arm count ambiguous. If branches dominate at reduced size, thin or shorten them first. Small weight variations preserve a hand-drawn character, but each main arm needs continuous support. Double outlines along every line would turn fine crystal-like strokes into hollow tubes and change this exercise’s visual rule.

Inspect negative spaces as well as tips

Compare the six wedge-shaped gaps between neighbouring main arms. Their negative spaces should broadly correspond, without small branches crossing into adjacent sectors and creating new apparent axes. Hide background decoration and compare gaps clockwise. If one gap is unusually narrow, distinguish an incorrect arm angle from an overlong branch and correct that cause instead of blindly scaling the whole flake. Count the six arms that originate directly at the centre before examining branches; counting only outer points would mistake branches for arms. Slight variation is allowed, but it should be explainable rather than abandoning structural checks because there are many lines.

Place decoration within a clear hierarchy

If adding small diamonds or crossbars, choose only one motif and repeat it at a consistent level, such as one small diamond toward the inside of each arm. Do not fill every gap impulsively or extend diamonds into new bridges joining neighbouring arms. Use lower-contrast blue-white so the main arms remain dominant. A few light accents may sit near the centre or selected turns; these are decoration, not simulated ice-crystal sparkle. The flake must remain complete with decoration hidden. If six directions disappear when that layer is off, repair the framework rather than adding a halo to conceal it.

Test the rule with a reduced-branch version

Save a copy and remove the same outer branch pair from every arm, keeping other weights, lengths and angles unchanged. Both versions should still have six countable main arms, differing only in complexity. Removing branches from just two arms would not be the same rule-based simplification. Reduce both versions to the same display size and compare their tightest gaps and centre contrast. If the simpler one reads better, it may become the finished version; detail alone does not justify retaining every branch. This exercise tests consistent repetition and omission, not a scientific record of a natural crystal, and complex terminology cannot replace visible structure.

Remove guides and recount before output

Save the native artwork, hide the guide axes and export a PNG. From the exported centre, count the main arms clockwise again and check for fine branches that disappeared or merged during reduction. If the centre becomes a glowing blob, reduce the brightest area so the six roots separate. If background dots compete, reduce their number rather than making the flake ever whiter. Keep the written rule and sample-arm sketch. A future version may use one large branch pair per arm, but update all six directions together. Record a definite fault, such as one missing branch in the lower-left outer pair, instead of randomly adding more lines.
