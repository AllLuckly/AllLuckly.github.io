Draw a directed graph with one negative edge, list S-to-T routes and independently verify distances with an edge-limited ledger. The initial acyclic graph already defeats a settled-vertex Dijkstra process applied indiscriminately to negative weights. Add one edge separately to show why a reachable negative cycle can eliminate a finite minimum.

Declare directed edges and abstract weights

Use vertices S,A,B,T and edges S→A:2,S→B:5,B→A:−4,A→T:2,B→T:10. Weights are additive abstract costs, not physical distances/times becoming negative. S,B,A,T is a topological order, so the initial graph is acyclic. Omitting directions changes the problem. Create vertex, arrow, weight, route-ledger and control layers; save native work. “Route” here permits repeated-vertex directed walks; initial acyclicity prevents repetition, while the later negative-cycle control uses it explicitly.

List the three complete routes and minimum three

The original graph has exactly three S-to-T routes: S→A→T costs 2+2=4, S→B→T costs 5+10=15, and S→B→A→T costs 5−4+2=3. The minimum is 3 through B then A; best S-to-A cost is 1 rather than direct 2. Compare complete routes rather than treating more edges as automatically longer. Highlight the optimum independently while retaining all edges, labelled “abstract cost 3,” without turning negative weights into a real travel recommendation.

Demonstrate the failed settled-vertex premise step by step

From S, tentative A=2,B=5 settle A first and produce T=4. Since 4<5, stopping when T is settled returns 4 before processing B’s−4 improvement. Continuing while refusing to update settled A also misses its correct 1. This demonstrates failure of the nonnegative-weight guarantee, not that every graph with a negative edge necessarily fails. Algorithms reopening vertices need their own definitions/proofs; renaming a process does not preserve Dijkstra’s guarantee.

Start an at-most-one-edge ledger

Define δ_k(v) as the minimum S-to-v cost using at most k edges. Set δ0(S)=0 and others∞ for no route, not a very large real number. Layer 1 gives A=2,B=5,T=∞. Each layer keeps a previous value or adds one incoming edge to a previous-layer value, then minimizes. Read only the previous layer; mixing newly updated entries does not represent one additional edge. Label columns S,A,B,T and “at most,” avoiding confusion with exactly-k-edge rules.

Compute two more layers and compare route enumeration

Layer 2 gives A=min(2,5−4)=1, B=5, T=min(2+2,5+10)=4. Layer 3 improves T from previous-layer A=1 to 3, retaining A=1, B=5. T entries across layers 0–3 are∞,∞,4,3, agreeing with enumeration. With four vertices and no cycle, every route has at most three edges, so three layers suffice here. This is not a blind three-step limit for arbitrary cyclic graphs. Retain minus signs and treat∞ plus a finite weight as unreachable, never zero. A topological pass S,B,A,T independently gives B=5, then A=1 through−4, then T=3. This order respects every edge, providing another valid acyclic-graph check without pretending all weights are nonnegative.

Separate a negative edge from an added negative cycle

Save a control adding only A→B with weight 1. Cycle A→B→A costs 1−4=−3, is reachable from S, and can still lead to T. Each repetition lowers cost by 3, so walks allowing repeated vertices have no finite minimum. Restricting to simple paths defines another finite-candidate problem and does not refute this control. The original negative-edge graph has no negative cycle and minimum 3; a negative sign alone does not eliminate an answer. Preserve both versions.
