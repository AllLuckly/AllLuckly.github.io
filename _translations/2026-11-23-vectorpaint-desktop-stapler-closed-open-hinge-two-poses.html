Draw upper and lower components, rear hinge and two poses of one desktop stapler from visible references.

Identify one product and reference

Swingline’s 747 desktop-stapler description says the model can open for tacking; opening methods and visible structures vary by model. Choose permitted closed and open side-view photos of the same manual desktop stapler and record the model. If the two references show different models, do not assume identical hinge, base or top. This exercise draws visible shapes and does not require disassembly or operation.

Plan two panels and working layers

Create an approximately 1800 by 1100 landscape canvas in the current VectorPaint interface and save an editable original; the dimensions are suggestions. Use equal-size left and right observation panels for closed and open poses, each with a horizontal ground guide. Separate sketch, base, upper part, details and labels using available layers and the labels actually displayed. Leave sufficient space for the raised upper part.

Build a common base silhouette

Use the side reference to draw a stable lower edge and front and rear contours, starting with few nodes to set length and height. The base is the same part in both poses, so retain size, orientation and ground position. If the photos use different angles, choose a consistent illustrative view instead of combining incompatible perspective outlines. Add rounded corners or non-slip pads only where visible.

Mark the rear connection

Mark the visible hinge or connection location at the back of the base and use it as the corresponding point in both panels. Some mechanisms are hidden by the case, so do not invent screws. The closed pose may need only a sketch-layer hinge marker; if a small circular connection is visible in the open reference, draw it according to the photo. Record its position relative to the bottom and rear so it remains consistent when the base is copied.

Draw the closed upper part

From the closed reference draw the top cover and visible magazine shape, comparing their lengths to the base before refining rounded corners and ends. There may be a narrow gap above the base; preserve visible space instead of merging both parts into one solid rectangle. Keep front ends aligned and the rear near the marked connection. At thumbnail size check that the upper part neither sinks into the table nor floats too far above the base.

Construct the open upper part

In the right panel copy a simplified upper outline of the same length and rotate it around the corresponding rear connection to the angle visible in the reference. Use a guide from hinge to front end to check that rotation has not changed the length. Use a recognizable rotation tool if the current interface provides one; otherwise redraw from the reference and compare sections. Do not assume all staplers open to a particular angle or treat the drawing as operating instructions.

Distinguish cover and magazine

On some models the cover and inner magazine separate, while other views show only a combined outline. Draw levels the reference actually reveals: if a slender inner rail is visible, suggest it with a lighter narrow shape; otherwise leave it unknown rather than adding a spring from another model. If both cover and magazine move near the rear, inspect their visible connections separately; they need not open at identical angles.

Arrange color and occlusion

Use a dark base, mid-gray cover and lighter interior as exercise colors to distinguish layers. In the open view, follow the reference for front-to-back order at intersections and stop hidden edges at occlusion rather than drawing internal lines through the case. Keep each part’s color consistent between poses. If gray parts merge with the background, adjust background value before thickening every outline.

Check hinge-to-front distance

Draw a temporary guide from hinge to upper front in each panel. If lengths differ substantially, check accidental scaling, a different chosen front point or projection differences in the photos. In an ideal side-view diagram, the distance on the same rigid part remains fixed during rotation about a fixed hinge; perspective photographs do not provide exact measurements by direct comparison. Hide the guides afterward and save a reviewable draft.

Check the paper opening and base plate

The front paper opening in the closed pose may be a narrow slot, represented by a short line or gap if the photo shows it. Follow the actual reference for any visible metal plate and inner layer in the open pose. Swingline describes an adjustable anvil on some models, but that is not a universal feature. This illustration need not show a staple penetrating paper; use the related cross-section lesson for that result. Do not mistake the table shadow for paper or a metal plate.

Save, export and inspect

Save the editable original, then use a share or export entry actually visible in the current version to save an image or SVG separately. Reopen and check both poses, hinge, upper length and corner crop, then return to inspect object layers. If a part is missing, check visibility and cropping first; a matching bitmap does not imply editable paths. Record source and pending device steps, without claiming that the stapler was operated or tested.
