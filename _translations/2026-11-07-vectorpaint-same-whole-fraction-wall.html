A fraction wall compares lengths meaningfully only when every row represents the same whole. Manually arrange whole, halves, thirds, quarters and sixths, checking complete rows and equivalent endpoints. This automatically simplifies no fractions or proofs and is no physical ruler; retain the shared-whole explanation.

Fix one total width for every row

Create a 1200 by 800 pixel canvas with each row x=200→920, total 720. Start with equal heights and separate gaps; height encodes no value. Rows represent one whole split into 1,2,3,4,6 cells, not increasing total quantities. Put labels outside widths. Inspect five identical frames before divisions rather than lengthening the sixths row for more cells. These are drawing proportions, not food portions or measured physical lengths.

Derive cell widths from denominators

Widths are 360 for halves, 240 thirds, 180 quarters and 120 sixths, with whole=720. Verify width×count=720 before boundaries. Larger denominators mean smaller cells, not wider cells because six is a larger number. Count shared boundaries once and inspect doubled strokes. Retain division lists and calculate each row rather than arbitrarily shrinking half-cells into six positions. Labels must match widths.

Separate cell labels from whole-row meaning

Use clear conventional labels—whole, one-half, one-third, one-quarter, one-sixth—repeated within the corresponding row, without reversing numerator and denominator order. Each cell has that fraction; the complete row still sums to one. If only the first cell is labelled for space, explain that it represents every equal cell, not a sole data cell. Colour may distinguish rows without implying a larger total through darkness. Inspect words/boundaries without colour first.

Check equivalent halves through a shared endpoint

From the shared left edge, 1/2, 2/4 and 3/6 all end at x=560. Verify endpoints before writing equivalence. Likewise 1/3 and 2/6 end at x=440. Optional light reference lines remain artwork whose final output needs checking. This compares lengths of one whole, not counts of cells. Halves of different wholes cannot inherit the comparison automatically.

Colour selections according to cell boundaries

Highlight one half-cell, two quarters and three sixths, all stopping at the common endpoint. First-cell highlighting everywhere does not represent a half. Define darker selection versus pale remainder without another unit meaning. Thirds cannot represent one-half through an integer count of cells; do not disguise one-and-a-half cells as an integer. Partial-cell versions need explanation. Start with whole-cell equivalences and retain complete rows; colouring does not delete the remainder.

Recalculate all rows after changing the whole width

Change total width to 600 in a copy: half 300, third 200, quarter 150, sixth 100. Keep left origin and move every right edge/equivalence endpoint consistently. Resizing one row alone creates false inequality. Relayout distorted text without moving boundaries for typography. This changes display scale while preserving fractions. Name versions and retain 720 separately; recalculate/check each width×count because the app does not do it automatically.

Keep the common-whole explanation in output

Retain frames, divisions and equivalence highlights. Inspect five shared origins/ends, counts and labels in export. Move long fraction labels outside when small rather than dropping the shared-whole explanation. Test backgrounds/remainders; white fills do not become transparent. Name same-whole fraction wall, total pixel width and revision and exclude mixed 600 tests. A cropped row still needs whole identity, not inferred absolute quantity. Keep calculations for editable extensions; new denominators need new widths, not arbitrary copies.

Check wholes and cell widths for unequal halves

For unequal 1/2 and 2/4, check common width/origin and whether quarter labels pushed 180-pixel cells wider. Correct cell counts still need width×denominator=whole, not revised labels. Repair overrun fills instead of thick reference covers. Preserve the limitation of representing halves through thirds rather than calling one third a half. Recheck whole width, equal divisions, equivalence endpoints and output so fractions have one common basis.
