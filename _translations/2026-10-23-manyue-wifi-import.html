When comic files are on a computer and you want them directly on an iPhone or iPad, use WiFi Import in ManYue. The phone temporarily provides a local upload page, and the computer browser selects files. This guide transfers one small CBZ, focusing on four stages: pairing, uploading, importing, and the destination bookshelf.

Prepare two devices on the same network

Connect the computer and the device running ManYue to the same mutually accessible local network. Both having internet access does not prove they can reach each other; guest networks or wireless isolation may block access. Start on a home network you manage, which is easier to check, rather than attempting a public-internet transfer.

Prepare a CBZ or PDF you are authorized to read whose page order you have verified on the computer, and keep the original. A sample of a dozen or so pages is easier to troubleshoot than a multi-GB collection. The computer browser needs no comic extension, but must open the exact address shown on the phone, including its port and pairing information.

Open WiFi Import and read the address

In ManYue's “Tools,” open “WiFi Import.” Check the service status, start the upload service through the current interface, and confirm it is running. The page provides an address and pairing code. Use values from this session rather than permanently reusing a bookmarked old address, because device network addresses and service details may change.

Enter the complete address into the computer browser's address bar, not its search box. If pairing is requested, enter the code currently shown on the phone. This address generally serves the current local network; devices outside it cannot access it directly. Keep ManYue in the foreground during upload and watch service status. After switching apps, return to the import page and confirm that the service is still running before sending the next batch.

Choose the destination bookshelf before selecting files

On the WiFi Import page, confirm the destination bookshelf or group, ideally named for this batch, such as “Weekend Samples.” Select the practice file on the computer page. If folder upload is offered, understand how its structure maps to books and chapters before using it. A single file is easier for a first check of filename, page count, and imported object.

If an import preview appears, check how many books and chapters it will create and where they will go. A folder containing both a cover image and several archives will not necessarily become the single book you intended. You can cancel and reorganize it first. A preview is valuable precisely because it reveals an unexpected hierarchy before writing anything.

Distinguish a finished upload from a successful import

When the browser upload progress reaches the end, the transfer stage has finished, but the app may still need to parse and import the file. Check the phone's import result or history to determine whether the item succeeded, failed, or is still processing. Do not stop the phone service immediately when the computer shows 100%, especially for files with many images or complex archive structures.

After a successful import, choose “View Bookshelf,” find the work, and open it. Check the first, middle, and last pages, comparing order, count, and content with the original file. A visible cover alone is insufficient: it may be generated early while later pages still have parsing or file-integrity problems.

Read once after stopping the service

Once local files are readable, return to WiFi Import and stop the service or leave the upload session through the current interface. Reopen the imported comic, then temporarily disconnect networking and check several pages. This confirms that you are reading the local import rather than content still dependent on the computer or temporary web page.

Keep the computer's original file in its existing collection directory, at least until the whole batch is verified. WiFi Import is only a transfer method, not an automatic two-way backup between computer and phone. Later changes to page order on the computer do not update the phone copy automatically; handle the new version separately.

Check an inaccessible page in order

First confirm that the phone shows the service as running, then compare the browser address with the correct protocol, IP, and port. Check whether the two devices share a mutually accessible network and whether the system permits ManYue to use the local network. If the phone reconnected to Wi-Fi, read the address again rather than refreshing an old link.

If the computer opens the page but uploading fails, initial connectivity is no longer the issue. Check file size, free device storage, browser messages, and the phone's import results. Retry one small file instead of repeatedly sending the same large archive. For a pairing-code mismatch, use the current displayed value rather than treating digits from an old session as a permanent password.

Frequently asked questions

Can I use a computer folder directly instead of a book file? The current page may offer folder selection, but how books and chapters are combined depends on the structure and preview. Test a folder with clear contents first; not every directory level should be treated as pages of the same comic.

Why does the browser report upload complete while the bookshelf is empty? Check whether the phone is still parsing, whether a preview needs confirmation, whether the destination group differs, and whether any failures appear in the results. Uploading, parsing, and adding to the library are separate stages. Do not check only the final number on the computer.

Does WiFi Import synchronize reading progress? This guide transfers comic files, not iCloud or WebDAV reading data. Transferring the same file to another device does not automatically carry favorites, history, or bookmarks. Use the corresponding data functions to migrate records.
