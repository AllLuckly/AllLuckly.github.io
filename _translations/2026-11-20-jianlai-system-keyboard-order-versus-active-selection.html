Record the complete system keyboard list, move only Jianlai, observe the active keyboard in an ordinary note and restore the original order.

Preserve the current keyboards and document

On your iPhone prepare an ordinary note and a non-private practice sentence “早安 ABC。”, retaining the original. Confirm Jianlai is installed and present in the system list alongside at least one system keyboard you normally use. Do not add or remove keyboards for this exercise. Record device, OS, identifiable app version and the keyboard actually shown in the field. The task compares system-list order with active selection; it does not promise every host automatically uses the first item.

Record the complete original order

Follow Apple’s guidance to open the system keyboard list and record every item in order, including your system keyboards, Jianlai and other existing entries. Keep a private recoverable note or non-sensitive screenshot; distinguish similarly named items. Do not press delete or change language preferences, full access or unrelated settings. If system management prevents editing, record that restriction and stop the reordering trial.

Observe the active keyboard in an ordinary field

Return to the same note and select the practice line. Record the keyboard actually displayed, its appearance and scheme. If a system switch control is available, inspect the menu and select Jianlai, then enter the entire same sentence “早安 ABC。”. Verify it reaches the document and retain the original line. Presence in the list does not establish that Jianlai is currently active. Hosts may retain previous choices, but this exercise does not assume a particular rule; secure fields are not the comparison target.

Move only Jianlai in the system list

Return to the system keyboard list, enter Edit using the actual interface, drag the reorder control beside Jianlai to an identifiable new position and finish editing. Change position only; do not delete items or alter their settings. Moving one item shifts those it passes, so compare the full list. If the item or reorder control is unclear, cancel and keep the initial state. Record the saved order instead of assuming a drag automatically persisted. For a paper example, moving Jianlai to the front of “system, Jianlai, emoji” yields “Jianlai, system, emoji”: the system item shifts without being deleted. This three-item illustration does not replace your real list; include every other keyboard when comparing and restoring your own order.

Observe the actual state in the same host

Reopen the original note and select a new practice line. First record which keyboard actually appears. Then choose Jianlai using a real available switch control and type the target. Inspect Chinese characters, Latin letters, spaces and punctuation, preserving the first result. Observe system list order, switch menu and active keyboard separately. The first list item is not automatically the default in every context, and moving an item does not establish that all hosts reset prior selections.

Compare list order and both input results

Compare the complete before and after lists, confirming no item disappeared and only the intended positional change occurred. Then compare the keyboard initially observed in each trial and the two committed lines. An unchanged initial selection with changed list order is a valid observation, not proof that reordering failed. If text differs, preserve both lines and inspect scheme, candidate confirmation and focus before attributing a cause. This does not measure switching speed or establish accuracy benefits.

Troubleshoot list, host and focus separately

If Jianlai is absent from the system list, inspect installation and addition. If present but absent from an ordinary host, inspect focus and the system switch menu. If only one app declines third-party keyboards, compare another ordinary field and distinguish host restrictions from list order. If the order did not persist, return to the list and check whether editing was completed; do not delete and re-add other keyboards as a first step. Mark unconfirmed selections pending instead of guessing from theme color.

Restore the original list and deliver the record

Using the initial complete record, restore each item to its original order with system reorder controls and verify none were removed. Return to the note, confirm Jianlai can be selected using actual controls and that both original lines and backup remain. Restoration concerns list order only; it does not require clearing a personal dictionary or changing other keyboards’ permissions. Keep before/after lists, the actual keyboard observed per trial, input results and pending work, omitting information you do not wish to share. Apple documents list reordering and switching; the listing describes Jianlai as a third-party keyboard. No physical device or host test is claimed.
