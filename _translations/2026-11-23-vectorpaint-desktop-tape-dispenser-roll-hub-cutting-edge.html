Draw the visible hub, tape roll, base and cutting end of a desktop dispenser.

Choose one specific reference

3M describes the Scotch C18 with a weighted base, replaceable hub and cutting blade; shapes differ between models. Choose a permitted side or slightly front-oblique photo of a similar structure and record model and viewpoint. Treat hidden internal attachments as unknown. This exercise depicts the exterior and visible tape, not disassembly or cutting instructions.

Set up an editable canvas

Create an approximately 1800 by 1200 landscape canvas in the current VectorPaint interface and save an editable original; these dimensions are a suggestion. Use available layers for sketch, base, hub, tape and background, noting that interface labels can vary. Place the dispenser centrally with the cutting end to the right and room above the object and for a ground shadow. Begin with light guides; do not start with the toothed edge.

Compare proportions with a bounding box

Draw a box around the dispenser and mark the roll top, base bottom, left end and cutting end. Estimate roll diameter relative to overall base length, then compare center-to-cutter distance. Do not treat this exercise’s proportions or perspective shortening as actual product dimensions. At thumbnail size ensure roll and front end have adequate space; revise the overall box before adjusting internal components if the silhouette is too long.

Build the base silhouette

Use available shape or path tools to build the side silhouette from the reference: draw a stable lower edge, then connect the roll support and upper edge near the cutter. The base may have rounded corners or sloped surfaces, but begin with few nodes rather than one at every small turn. Check that it rests on the table and does not inexplicably pass through the roll center. If it looks like a detached bar at thumbnail size, revise its relationship with the roll.

Place roll and hub

Draw the visible outer roll as a circle or ellipse, then establish the hub opening inside it according to the viewpoint. In a slightly oblique reference both may appear elliptical, with consistent orientation and centers. Tape roll and hub are distinct parts: use a lighter value or fine line to separate materials rather than making the opening a solid black dot. If they look off-center, first check reference occlusion or perspective before moving nodes; do not infer a mechanical fault.

Show base occluding the roll

Decide whether the near-side base wall hides the lower roll. Keep a complete roll in the sketch, then let the foreground base cover the obscured portion in the final drawing; do not carry the roll outline through a solid wall. Retain exposed hub portions actually visible in the photo without inventing hidden axle or latch details. Temporarily hide the base to inspect the roll, then restore it and confirm the stacking order.

Draw visible tape and cutting end

Observe the visible tape extending from the roll perimeter toward the cutting end in the photograph. Use two close lines or a narrow colored strip whose ends meet the corresponding parts. Suggest translucency with pale color and low contrast; any transparency control depends on the actual interface. Represent the cutter with simplified small teeth or short marks rather than measuring each one. If tape is not visible in the photo, do not invent an actual threading direction.

Use color and line weight to organize layers

Try a dark-gray base, light-gray hub and pale tape, with clear enough contours to distinguish roll from support. Small cutter teeth should remain recognizable at normal viewing size without becoming heavier than the roll. If transparent tape merges into a pale background, first adjust background or local edge value instead of covering the roll with an opaque black block. Colors are illustrative; actual model and materials follow the reference.

Check the visible tape path

Trace the drawn strip visually from the roll perimeter to the cutter, marking its start, route and end. If it breaks abruptly, first check whether the base genuinely occludes it; repair nodes or stacking for an unobscured break. Duplicate a thumbnail and intentionally connect the strip to the hub center, then compare it with the reference and consider why it no longer reads as emerging from the roll perimeter. This is a visual study, not a refill or disassembly procedure.

Review nodes and alignment before output

Zoom in on contacts between roll, hub, base wall and cutting end. If an unexpected white gap appears, decide whether it is visible background or disconnected paths; if a contour becomes sharp, inspect node directions and handles. Shrink to intended display size and ensure the hub opening and tape path remain legible, removing decoration meaningful only at extreme zoom. Check all four corners and ensure the cutter and roll top are not accidentally cropped.

Save and recheck

Save the editable original, then use a share or export entry actually shown in the current version to save an image or SVG separately without overwriting the only original. Reopen the output and check lines, color, cutter and roll; return to the original to inspect object layers. Matching bitmap appearance does not mean paths remain editable. If an element is missing, check visibility, crop and output format first. Record the source and one overlap to improve, marking unperformed device and export steps as pending.
