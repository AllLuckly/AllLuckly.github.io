Switching between Chinese and English involves publication markup, reader and system speech. Record each layer with one self-made sample.

Separate text language from voice

One EPUB passage can contain Chinese and English. W3C explains that programmatically identifying language changes can help assistive technology apply appropriate presentation and pronunciation rules; it does not guarantee every reader and voice switches automatically. Whether Book Isle exposes language information to device accessibility must be observed. A standard requirement is not proof of app support.

Prepare a self-made bilingual sample

Use an EPUB copy you created or are authorized to inspect, with a short Chinese passage and a separate English sentence, for example “这是测试。” and “Good morning.” If the sample has language tags, have the owner record them. Do not use private documents or lengthy copyrighted works. Preserve the original and existing Book Isle notes instead of overwriting a real book.

Establish the visual baseline

Open the sample in Book Isle, verify both strings are visible, and record chapter, sentence locations, app version and system version. Confirm actual text visually or with a reliable assistive method; do not mistake lettering in an image for selectable text. If the sample does not open or a sentence is illegible, record the file or page issue before attributing anything to voice settings.

Optionally inspect language tags

If the owner has rights and understands EPUB structure, inspect language markup read-only in an isolated copy, such as lang attributes on paragraphs or phrases. Check actual inheritance against the file and standard. Record confirmed language for each passage; do not turn “not inspected” into “untagged.” Do not inspect protected or unauthorized files internally.

Record initial system voice settings

Following current Apple device help, inspect the system accessibility speech settings for voice, default language, language detection and rate. Labels vary by OS release. Record original values and do not require disabling existing accessibility settings. Without available speech or familiarity, skip the test rather than reporting that speech was performed.

Speak the two sentences separately

If the current Book Isle interface permits text selection and system Speak Selection, select the Chinese sentence and record actual language and voice, then repeat for English. Record only what was heard; do not share audio or private content. If selection or speech entry is unavailable, mark it unavailable or not observed. Another supported system method may be used, but do not assume the app itself provides a speech button.

Compare automatic language detection

Only if the device offers language detection and the user wishes, record its original state, switch that one setting and repeat the same bilingual text. Keep device, voice and rate constant. Apple describes detection of multiple languages, while actual app output can depend on content structure and implementation. An unchanged result is valid; do not prefill a required voice switch or corrected pronunciation.

Check selection and voice

If English is still spoken with the Chinese voice, check that the entire English sentence was selected, language detection is enabled, the corresponding system voice is configured and the sample is text rather than an image. The app and device may use different reading paths. One pronunciation does not prove missing EPUB tags or a Book Isle defect. If useful, compare the same authorized copy in another reliable reader.

Separate file and output evidence

An English tag proves that the file provides language information; actual voice switching also depends on system, assistive technology and reader. Conversely correct English speech does not prove the EPUB tag was used, since another detection mechanism may apply. Record file inspection, system settings, selected range and actual sound separately without inferring implementation.

Use four cells to avoid mixing results

Give Chinese and English two rows each, before and after a language-detection change. Include selected range, system voice, actual speech, time and completion status. Fill an observation only after the whole intended sentence is selected and heard. If focus or sound is unavailable, mark unobservable rather than assigning a language. If the user wants only one setting tested, leave the other unperformed.

Names, borrowed words and short phrases can have context-dependent language treatment. This sample uses complete separate sentences so a proper name’s pronunciation is not mistaken for a language-detection result. The test concerns readability, not a judgment about accents or a person’s language ability; it does not prove every mixed-language passage behaves the same. Self-made text improves reproducibility without sharing a book.

A developer report can specify authorized EPUB source, OS and Book Isle versions, detection state, actual selection action and heard difference. Exclude passwords, private notes and complete copyrighted chapters. Mark unreproduced runs explicitly instead of filling expected speech as an observation.

Restore settings and hand off

Restore initial language detection, voice and rate and confirm the original book, bookmarks and notes are unchanged. Record sample edition, sentence markers, before/after settings, actual speech and unperformed steps; do not share private files or credentials. Based on public W3C and Apple guidance, this guide claims no Book Isle device or assistive-technology test.
