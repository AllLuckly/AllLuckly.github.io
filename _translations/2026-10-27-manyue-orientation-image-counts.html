Gallery image counts can support a multi-image overview in one orientation and close reading in another. This changes display rather than producing an exported contact sheet. Establish how many images appear after rotation and how to return to a selected page.

Choose a suitable small collection

Use a modest authorised collection with recognisable cover, portrait and landscape images. Verify source order in single-page mode and choose a middle anchor. Overview display suits composition comparison better than unread dense dialogue. The task concerns switching views, not changing the source page count or panel structure.

Find separate orientation controls

Use a supported multi-image gallery mode and inspect separate portrait/landscape controls. Continuous mode may follow different rules. Record both starting values and scope, then choose a modest available overview count while retaining close reading in the other orientation. Respect version limits and do not assume every screen suits the same count.

Establish the close-reading orientation

Set a readable count in portrait and inspect detail and edges at normal distance. Preserve aspect ratio and use zoom if needed. Verify forward/back direction. A change from two visible images to one changes presentation rather than proving missing imported pages. Stabilise this orientation before configuring the other.

Increase landscape count for an overview

Change only the landscape count and inspect order and edges. Compare composition and colour masses rather than demanding small-text readability at reduced size. Reduce the count if crowded and accept aspect-ratio whitespace. Use the overview to choose images for detail, without assuming automatic semantic grouping or evaluation.

Check cover and wide-image handling

Inspect the cover and landscape image for first-image and smart handling that may alter grouping. Do not derive source indices mechanically from screen count or delete covers for tidier arithmetic. Compare optional special handling one control at a time and verify every sample type remains accessible.

Use the anchor while rotating

Rotate from an overview containing the anchor to the close-reading orientation, locate the target and return. Group boundaries can change with image count, so judge continued access to the intended image rather than pixel-perfect alignment. Reopen once, and check system orientation lock before diagnosing an ineffective app setting.

Choose counts for the actual purpose

Use multi-image views for overview and readable views for dialogue. Keep only necessary differences, use supported book scope when specific to an art collection, and check another ordinary comic. Record the purpose of each orientation rather than treating old counts as permanent after a screen or distance change.

Acceptance and troubleshooting

Finish with intended counts, understood exceptions and a recoverable anchor. Separate orientation values explain why changing one may leave the other unchanged. Inspect cover and wide-image rules before suspecting missing content. Restore single-page display when overview is unsuitable; more simultaneous images are not inherently better.
