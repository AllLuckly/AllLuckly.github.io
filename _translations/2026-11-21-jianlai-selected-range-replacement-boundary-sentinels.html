When revising a sentence, correctly entering the replacement does not prove the selection was correct: adjacent punctuation may be replaced too, or new text may be inserted without replacing the old phrase. Compare host selection, Jianlai input and final document in a nonprivate copy.

Prepare original and target sentences

In an ordinary note create a practice copy with “地点：东门；时间：上午。” The target is “地点：西门；时间：上午。” Only the direction differs; preserve colons, semicolon, time and full stop. Keep a separate original reference. Record that both characters “东门” are to be selected and replaced. No real event or calendar item is created. If the host cannot show or reliably convey the selection, mark it pending and use another ordinary editor.

Confirm system keyboard and host roles

Confirm Jianlai was added and actually selected in this ordinary field. Record host, device system, Jianlai version and input scheme. An onscreen keyboard does not prove the document cursor is in the intended position. The system or host handles text selection and editing; Jianlai supplies available text input. Do not assume identical gestures or menus in every host, or use password fields and weaker security.

Identify both selection boundaries

In the practice copy locate “东门”: a colon precedes it and a semicolon follows. Use the host’s actual selection control to select both Han characters. Verify neither punctuation mark is included and “门” is not omitted. If only the cursor can be identified and selection extent is unclear, cancel and select again; do not assume both characters were selected. Familiar assistive technology may help, but its availability is not a universal keyboard-accessibility guarantee.

Enter the replacement and confirm candidates

After verifying the selection, enter “西门” using an available Chinese scheme. Confirm a candidate using the real interface or record direct commitment. Do not assume Space, Return or another key always confirms. Record the initial selection, user confirmation and document change separately; a candidate preview does not prove replacement. If focus or selection disappears before entry, stop and record it instead of pretending the original selection remained.

Check target and neighboring text separately

Check “西门” occurs once and “东门” no longer appears. Then inspect “地点：” on the left and “；时间：上午。” on the right, character by character. The complete target sentence, not merely the presence of “西门,” is the acceptance condition. Record extra space, missing semicolon, retained original or text inserted at the end as distinct results. Preserve the first result before correcting a different copy.

Compare insertion and replacement

In another independent copy, place the cursor before “东门” without selecting text and enter one recognizable practice symbol. Record that insertion leaves the old phrase. Restore with the host’s available undo or direct editing; do not assume one undo corresponds to one character. If neighboring content changes unexpectedly, stop and restore from the independent reference. This control distinguishes insertion from selection replacement without damaging the accepted result.

Handle invisible or changing selections

Create a three-row comparison card: the target “地点：西门；时间：上午。”, an insertion counterexample “地点：西门东门；时间：上午。”, and an overly broad selection counterexample “地点：西门时间：上午。”. These are hypothetical checks, not instructions to damage an existing document. Inspect the old phrase, replacement and semicolon separately to distinguish insertion, an overbroad boundary and the intended result; also verify the time. If the actual outcome differs from all examples, record it accurately.

Some hosts change selection when a keyboard appears, a candidate composes or focus moves. Record only what you observe; cancel and reselect if boundaries are no longer clear, finishing or cancelling unconfirmed input first when needed. Host auto-selection, keyboard candidates and deliberate user selection are distinct events. Font, magnification and speech can change selection presentation; use the host’s reliable feedback and mark boundaries pending when evidence is insufficient.

Compare selection across focus loss in a separate copy

Keep the first result and select the whole “东门” in a fresh practice copy, first checking the colon and semicolon on either side. Only if the host offers another identifiable ordinary field, shows focus reliably and allows a safe return, tap that other field once without entering or changing its text. Record whether the original selection was visible, feedback during the focus change, and the selection or cursor state after tapping the original field again. The selection may remain, become a cursor, become indeterminate or behave differently; these are possibilities to observe, not predicted outcomes. Moving focus is not the same as undo.

After returning, check whether both characters and their boundaries are actually still selected. Only if the desired range is clear should you enter “西门” in this new copy and compare the target sentence and adjacent punctuation. If the range has disappeared or is uncertain, stop and mark it pending rather than overwriting by guess. If you reselect before retrying, record that separate action; it is not evidence that the original selection survived. Keep the no-focus-change first trial and the actual second trial separate. Mark the second untested if no second field, reliable feedback or safe return is available; the first result remains valid.

Troubleshoot and preserve the original

If selection boundaries remain unclear, practice the host selection method on separate disposable text and confirm its visible or spoken feedback before returning to the saved copy. Do not probe by overwriting a real document; stop if no recoverable copy exists.

If the old phrase remains, first determine whether text was inserted rather than selected. If punctuation disappeared, inspect selection bounds. If the target differs, check input scheme and candidate confirmation. Change one condition per trial, recording baseline and actual result. Restore the usual keyboard and retain reference, first result and corrected copy without sending the exercise. Apple’s text-selection guidance and public Jianlai multilingual information inform this exercise; no physical selection, undo or compatibility test is claimed.
