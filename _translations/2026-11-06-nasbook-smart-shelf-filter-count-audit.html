Book Isle 1.1.4 improves smart-shelf filter state and group counts, which should be checked against a fixed scope. Use the existing library to compare group numbers, selected conditions and returned shelf results without altering progress or reading dates to manufacture counts. Groups derive from library records, not measured comprehension speed, and need not be mutually exclusive.

Record a shelf baseline without a keyword

On the shelf, record filter name, search text and count. Save any keyword, clear search and clear existing filter conditions to establish a current-library baseline. Clearing filters is not deleting books; do not alter files/tags for the exercise. Record time, app version, total and one or two recognisable titles, not counts from another device or remote folder. Shelf counts refer to current records, which may include separate same-name entries. Fix library/time before interpreting group counts.

Separate category browsing from applying a group

Open smart filters through the shelf’s current-filter entry. The category menu browses group types. Choose reading pace and inspect available Active reading, Slow start or Stalled groups and their parenthesised counts. A group can be absent when no records qualify. Browsing categories is not applying a specific group: select its chip before comparing returned results. If merely closing the sheet, inspect the shelf’s actual condition instead of assuming the browsed category took effect. Follow available names/categories in the installed version.

Inspect name, selected state and results together

Select one available group and record its name/count. Back on the shelf, inspect current filter name, result count and representative books; reopen filters to inspect that group’s selection state rather than colour alone. One category name does not establish the same subgroup. Check one group without rapid repeated selections. Section headings are not book entries and the first screen is not necessarily the whole group. Compare chip/result counts only after excluding search text and library changes.

Do not add pace-group counts into a library total

Check other populated pace groups independently rather than requiring their sum to equal all books. A book may qualify for multiple conditions or none; these are not an exhaustive partition. They reflect recorded progress/recent reading, not words per minute or ability ratings. Inspect actual records for surprising membership without falsifying dates, mass-completing or resetting progress. Keep evidence scope and check date because time-dependent conditions can later change counts.

Add one keyword to inspect the combined scope

Within a selected group, search a known title fragment and record whether results narrow. Chip counts can differ from keyword-filtered shelf counts because search adds a condition. Clearing the smart-shelf filter requires separately checking the shelf search text; do not equate it with the note centre’s all-filter clearing. Clear the keyword too before comparing full group counts again. For a missing result, inspect scope/text before deleting or reimporting books to change numbers.

Switch away and return to repeat one group check

Record group A, switch to another populated group, then return with library unchanged. Compare name, selection and representative books after updates settle, not a transient old list. Reading or importing during the test changes conditions and requires a new baseline. Hidden category preferences can alter available entries without losing books; inspect actual settings. A two-group round trip provides reproducible steps without hiding/reordering every category.

Save the record and restore the previous state

Keep baseline, group name/count, shelf results, keyword state and check time, sanitising private titles in screenshots. Restore prior search/filter and confirm daily-use books remain. Clearing filters restores scope without library-cache clearing or deleting files, and proves no remote-file synchronisation. For support, give version, selected group, search presence and precise mismatch without credentials. This covers one device’s current records, not every category/device because one count agreed.

Exclude search and record changes before count defects

For a mismatch, check residual search, group/category, time and unchanged library first. Reopen the current filter to inspect selection rather than random tapping until colour seems right. An absent group calls for qualifying-record/category-visibility checks, not a deletion claim. Record one changed book instead of editing the entire library. If the mismatch repeats without a keyword, retain minimal evidence. Scope-aware results are more reliable than one isolated parenthesised count.
