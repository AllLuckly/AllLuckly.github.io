When both pages display but a spread does not join, inspect pairing and reading direction before editing the file. Use one known spread as an anchor and work backwards to the cover and front matter. Preserve the original, including apparently blank pages, while testing the display configuration.

Find an unmistakable spread

Browse in single-page mode and identify two consecutive images that clearly form one scene. Use a building, figure or dialogue crossing the join to confirm the relationship, then note neighbouring pages. If the file already contains a single wide image, record that distinction: displaying that image intact is different from pairing two portrait pages.

Count the cover and front matter

Count the actual images before the story: covers, title pages, publication information, contents and blanks. Added front matter can shift the same story in another edition. A blank may be intentional for print pairing. Record visible content alongside reader positions because printed numbering and file order can differ. Establish the source structure before adjusting the display.

Fix direction and device orientation

Choose the book’s intended reading direction and keep the device in one orientation. Select two-page display for that orientation using the available reader controls. Portrait and landscape settings can differ. Check left-to-right placement at the anchor before testing the cover setting; a reversed direction can prevent a valid pair from joining.

Compare first-image treatment

If a first-image-alone option is visible for your two-page layout, record its initial state and compare both states at the same spread. Inspect the cover, the anchor and the next pair. If the control is absent, verify that the current layout supports multi-image gallery display. Record the available controls instead of assuming another platform’s interface applies.

Check images that already contain spreads

A landscape image inserted among portrait pages may already contain the complete spread. If your version provides smart two-page handling, inspect its description and test that image separately, then check adjacent portrait pairs. A wide scan with empty margins is not necessarily a spread. Change one control at a time and retain the starting values rather than cropping away content.

Separate constant and local mispairing

A constant one-image offset suggests the starting pair. A problem that begins halfway through suggests an inserted page, missing image or merged spread near that point. Inspect the boundary in single-page mode and compare the archive directory. Display settings cannot restore missing artwork, and deleting a good page merely to realign later pairs leaves the book incomplete.

Keep a suitable configuration for this book

After correcting the anchor, inspect ordinary dialogue, another spread and the ending. If book-specific preferences are available, read their scope before saving. Otherwise keep a short configuration note. Open another book with a different direction or cover structure to check whether global changes affected it. The right pairing depends on the individual file.

Questions and completion criteria

What if neither first-image setting works? Check direction, merged spreads and missing source pages. Should you insert blanks immediately? Editing the archive changes positions and should follow evidence, with the original preserved. Completion means a recognisable cover, a correctly joined known spread, sensible ordinary-page order and no new offset later in the book. Record the successful configuration.
