A seating plan should help someone locate a seat by its identifier. Practise four rows of six seats for a fictional screening with repeated shapes, row labels and an aisle. This illustration does not validate real evacuation, capacity or booking status.

Define seat scope and viewing direction

List rows A–D and seats 1–6, with the screen at the top. Record intentional gaps explicitly before drawing. Reserve screen, row-label and legend areas on a 1000 by 800 pixel canvas, using a central aisle for the exercise. Label it illustrative; real entrances, routes and capacities require independent confirmation.

Build one readable seat symbol

Construct a simple grouped seat and backrest with clear viewing direction. Duplicate six in one row and preserve an aisle between seats three and four. Distribute each side separately so the aisle is not erased. Test whether numbers fit on or below seats, then use one consistent rule throughout.

Verify one row before duplicating it

Check first-row size, spacing and aisle before duplicating three more rows. Group rows while retaining access to individual seats. Keep consistent columns and adequate row gaps. Hide labels to count actual seat symbols, then restore them and compare; the number of text labels does not prove the seat count.

Replace identifiers row by row

Put row and seat identifiers in fixed locations and explain their format. Update copied labels manually; do not assume auto-numbering. Keep direction consistent unless a verified rule differs. Read each row both ways to catch duplicates or omissions, and document any different numbering scheme across the aisle.

Make gaps and unavailable seats explicit

Distinguish a physically missing seat from an existing but unavailable one, using words or symbols as well as colour. A static colour is not connected to booking or check-in data. Assign update responsibility for real use and replace exercise identifiers with a verified venue list. Keep the legend with the plan.

Test orientation through a seat-finding task

Locate A1 and D6 from the entrance perspective and check that left/right is explicit. Show the screen and explain numbering direction only if it matches the real rule. Inspect normal phone viewing without rotating labels into awkward orientations for symmetry. This tests diagram logic, not actual venue guidance.

Count by rows and columns before output

Save and count by both rows and columns, noting intentional gaps, then audit every label. Check exported small text and margins at actual placement size. Name revisions clearly. Adding a row also changes labels, counts and possibly the legend. Reopen the delivery file to exclude diagnostic colours or unexplained gaps.

Diagnose mismatched seat labels

Inspect overlapping text when a seat shows two numbers. Restore common size before aligning a distorted row. Recreate left/right spacing if the aisle collapses. Resolve status changes against the update list rather than expecting automatic freshness. Repeat seat-finding and row/column counts, including neighbours of the corrected seat.
