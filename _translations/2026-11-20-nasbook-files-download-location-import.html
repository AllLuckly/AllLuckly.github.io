Trace an EPUB through browser downloads and Files, then check the picker, import and shelf separately.

Identify the book you are trying to find

Choose an EPUB you purchased or are authorized to download and note its filename, edition, source, and recognizable cover or text anchor. This exercise addresses a file downloaded earlier but not found while importing into Book Isle. Do not redownload an entire batch or change its extension. If the provider requires sign-in, use its normal entry and do not share account or order details. If you have not obtained the file, record the source and finish the authorized download first.

Start with Safari download history

If Safari just obtained the file, inspect its visible downloads list and status. Confirm that the target completed and note its displayed name; an ongoing or failed download is not a complete book. The destination can be changed in settings, so do not assume every download is in one folder. Locate the item from the record, then open Files. For email or another app, follow its actual save destination rather than assuming the Safari example applies.

Identify location and folder in Files

Open Files on the iPhone or iPad, tap Browse, and inspect the actual location: for example Downloads in iCloud Drive or a folder under On My iPhone/iPad. Apple’s example may show iCloud Drive Downloads, but the device’s configured destination controls the actual location. Third-party drives or external storage must appear among available locations. Record location, parent folder and filename; Recents alone does not identify the original path. If absent, check the search scope before downloading repeatedly. If same-named books exist in cloud and device locations, record each location and modification time, then compare size, edition and text; different times alone do not identify a complete original. Keep external storage connected until checking is complete: its folder disappearing after removal does not mean the file was deleted. If a location is unavailable, check the original download source before clearing any potentially useful copy.

Separate a visible entry from a complete copy

Check size, format, same-named editions and source. If a cloud item still needs downloading, stay online and wait using the controls actually offered by Files. Status markers vary by provider; if unsure, record unknown rather than assuming an icon means all bytes are present. Where system preview is available, check readability, but preview success does not guarantee Book Isle supports every part or its licensing. Do not delete the cloud original, sign out or clear caches to manufacture an offline result.

Select the actual file in Book Isle

Open the local import entry actually visible in Book Isle. In the system file picker browse to the recorded location and folder, then verify filename and edition. If only some locations appear, return to Browse and check whether the provider and permissions are available; do not assume every provider appears on every device. Select one sample, follow visible import prompts and record errors or waiting states. If the entry or item is unavailable, retain the observation without inventing a button or substituting a same-named book.

Verify edition and text on the shelf

Return to the shelf and identify the result by title, cover and the text anchor recorded earlier; read the opening and one later passage. A processing message, closing picker or visible cover alone does not prove the book is readable. With same-named books, distinguish editions and text rather than counting an old book as a new success. Leave the reader and locate the same item again. If only queued or failed, retain the time and actual message and consult the single-item retry guide.

Record source and import outcomes separately

Record browser download, Files location, cloud availability, Book Isle queue and reading as success, failure or untested separately. If Files sees the item but the picker does not, record both paths and entries and check provider availability. If selected but unreadable on the shelf, investigate format, completeness and license. Success in one layer does not prove the next, and repeated imports can create confusing copies. Follow current on-screen and provider rules for any permissions or entitlement prompts.

Retain the original and recheck within scope

Confirm the original download remains in place, leave Book Isle and reopen the verified book. If practical and other work is unaffected, after download and import temporarily disconnect to test one passage, then restore the network; otherwise mark untested. One offline success covers that observed passage, not permanent retention of the cloud source or copies of all books. Record the device and time so you can recheck after changing devices. If seeking help, share redacted device, version, source type and failure stage, not private books or account details.
