A larger poster wall is not always easier to browse. Choose source, category and card size in order. These change visible scope and arrangement, not filenames or storage locations.

Define today’s browsing scope first

For home NAS movies, select that source first; for server series, enter that server. Keeping source context clear reduces confusion among local copies, remote originals and duplicate posters.

Practise with a familiar small library, noting movie and series counts and recent items. This reveals what filters hide without needing to organise every library immediately.

Fix an unavailable source connection first. Category buttons change display scope, not an offline server’s availability. A retained card with failed playback calls for file-access checks, not category adjustments.

Compare All, Movies and Series

Inspect available categories. Start with All and note familiar items, then compare Movies and Series. A series card may represent many episodes, so card count is not file count.

If a series appears under Movies, check episode recognition and folders rather than switching categories repeatedly. Refer to Series-naming tutorial for S01E01 details, then inspect refreshed results.

Source-specific categories may differ from local libraries. Use current options without expecting identical category counts on all servers. Missing a category does not prove unplayable content.

Exclude filtering before concluding content is missing

For a missing video, restore All, clear search and verify source one step at a time, observing which restores it. Multiple filters jointly reduce results.

If still absent, search a short title keyword and inspect source. Another matching work needs edition and progress checks; identical posters do not prove the original entry. See Search and resume.

Filtering does not move disk files. If deletion or movement happened earlier, inspect the location. Separate temporarily hidden items from changed originals rather than reimporting duplicates for a filter problem.

Choose library columns for the screen

In appearance settings, find Library Columns and compare adjacent available choices. Device ranges may differ; matching another device’s number is unnecessary.

Fewer columns enlarge posters and titles for browsing; more show many familiar items quickly. Compare two settings on phone, then tablet, rather than judging numbers alone.

In the real library, test long titles, same-name films from different years and posterless entries. Names must remain distinguishable and tap areas usable. Fewer columns usually help more than ever-smaller type.

Recheck orientations and sources separately

Rotation changes available width. Check neat arrangement, truncated long titles and easy access. More cards do not mean more files; only the same collection’s layout changes.

Compare another source. Servers may provide posters while home videos have only names or thumbnails, so one density may not suit both. Optimise the usual task first, supplementing other cases through categories and search.

Check tablet window sizes too, not just one full-screen result. If settings seem ineffective, return to the library and confirm the visible list is controlled by that option.

Use recent records to plan viewing

Use the source’s Continue Watching or recent records for unfinished videos, returning to categories for something new. Separating resume from selection avoids repeatedly browsing the whole library from its first screen.

If favourites are available, add a few upcoming items and check their sources. Favourites aid retrieval, not downloading or independent backup. Verify required videos truly open offline before travel.

After finishing a work, inspect watched state and personal list needs before tidying. Do not delete originals for visual neatness: categories, column density and file cleanup serve separate purposes.

Final checks for your own library

Test three everyday tasks: find a known movie, open a specific season episode and resume yesterday’s video. All three succeeding proves the browsing arrangement useful, beyond prettier posters.
