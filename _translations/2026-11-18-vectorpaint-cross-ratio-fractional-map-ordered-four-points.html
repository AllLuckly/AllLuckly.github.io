Compare cross-ratios calculated from coordinates rather than screen-pixel ratios. Retain directed differences, point names and the forbidden input so the invariant has an auditable ledger.

Choose a cross-ratio convention and fix point order

Define CR(A,B;C,D)=[(c−a)(d−b)]/[(d−a)(c−b)], using directed coordinates on one number line. Set A=0,B=1,C=3,D=6: distinct points with nonzero denominator. References can permute points or adopt reciprocal conventions, so display the formula before comparison. Create source-axis, image-axis, ticks/points and ledger layers, then save native work. Identify order by names, not a temporary left-to-right visual arrangement, and retain each input/output pairing.

Calculate the original value and identify reciprocal-order risks

In the chosen order the numerator is(3−0)(6−1)=15 and denominator(6−0)(3−1)=12, giving 5/4=1.25. This is five quarters, not four fifths. Swapping A and B yields 4/5=0.8. Keep this order control with the original point labels so a reciprocal after permutation is not blamed on the map. Record 15/12 before reduction to distinguish wrong differences, inverted fractions and decimal transcription errors.

Evaluate the fractional map point by point

Use T(x)=x/(x+1), excluding x=−1. Its coefficient determinant is 1, not zero, so it is not a degenerate constant map. The images are 0,1/2,3/4,6/7. Evaluate each independently. Adjacent spacings change; a uniform horizontal scale of the source group does not implement this map. Keep a four-row input/output table in fractions. Decimals aid placement only: replacing 6/7 by0.86 is unsuitable for an exact identity check.

Recalculate the image cross-ratio with exact fractions

The image numerator is(3/4)(6/7−1/2)=15/56; the denominator is(6/7)(3/4−1/2)=3/14. Their quotient is5/4. Ordinary AC/BC changes from 3/2 to(3/4)/(1/4)=3, while AD/BD changes from 6/5 to(6/7)/(5/14)=12/5. Each ordinary ratio changes although their combination in the defined cross-ratio does not. Put these columns together without extending the invariant to all lengths, distance ratios or angles. Externally derive T(v)−T(u)=(v−u)/[(v+1)(u+1)]. In the four image differences, each input’s plus-one factor occurs once in numerator and denominator and cancels. This explains invariance beyond numerical coincidence. All inputs must avoid the pole and the cross-ratio denominator must be nonzero.

CR(a,b;c,d)=((c-a)*(d-b))/((d-a)*(c-b))
(a,b,c,d)=(0,1,3,6)
CR=15/12=5/4
T(x)=x/(x+1), x != -1
(T(a),T(b),T(c),T(d))=(0,1/2,3/4,6/7)
image numerator=15/56; image denominator=3/14

swap A and B: CR=4/5

Check the domain using a pole and repeated inputs

For input−1 the denominator vanishes, so no ordinary finite-axis coordinate exists in this lesson. A projective point at infinity requires an extended representation; the canvas edge is not a substitute. Setting C=B also gives a zero cross-ratio denominator and violates distinctness. Do not retain 5/4 in that case. Diagnose domain/order before denominators, reduction and panel scale. Preserve the control’s failed premise instead of deleting inconvenient labels to make the drawing look correct.

Separate ordering errors from approximation errors

Hide the answer and read the four directed differences in A,B,C,D order before restoring the displayed formula. A result 0.8 suggests swapped A/B or another convention. A near 1.25 discrepancy suggests premature decimal rounding; a large discrepancy may come from mixing panel pixel scales. Change one factor and preserve both versions. Correspondence leaders assist reading; they are not camera rays or physical lengths, and this one-dimensional illustration does not establish camera calibration. These inputs preserve left-to-right order, yet names still determine the formula. On other legal intervals, do not silently rename the leftmost point A to force an answer.
