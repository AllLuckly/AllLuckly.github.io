A converging lens does not always produce an inverted real image on the other side. An object inside the focal length requires backward ray extensions. Prepare three original ideal thin-lens diagrams, calculate image distance/height under one sign convention and review lines in ManYue. Calculations are an external paper model; PDF reading, zoom and returning are not measurements by a physical lens.

State the ideal thin-lens model and sign convention

Draw a horizontal axis and central converging thin lens, with light left-to-right and a real object on the left. Use positive f=10 cm, positive d_o for this object, positive d_i for a real outgoing-side image and negative d_i for an object-side virtual image. Fix object height h_o=4 cm and initially omit the image. State paraxial, thin-lens, ideal-in-air assumptions, neglecting aberration/thickness. Not every convex transparent object automatically fits. Mark center and both focal points; measure distances along the axis, not oblique rays.

For a thirty-centimeter object distance derive fifteen

For A set d_o=30 cm. From 1/f=1/d_o+1/d_i, obtain 1/d_i=1/10−1/30=1/15, hence d_i=+15 cm. Combine reciprocals, not 10−30 as a supposed−20 cm image distance. Magnification m=−d_i/d_o=−0.5 gives height−2 cm: negative means inverted, not negative material length. Place the image between 10 and 20 on the right, half the object height. An image drawn at 30 needs repositioning rather than deletion of the inconsistent calculation.

Cross-check with two paraxial rays

From the object tip draw an incident ray parallel to the axis, refracted through the right focus, and another through the ideal thin-lens center continuing straight. Their actual outgoing intersection is A’s image tip, below the axis consistently with−2 cm. Do not refract the parallel ray through the left focus or bend it before the lens. Label hand placement schematic if imprecise; numbers/construction govern it, not an assumed reader intersection solver. Distinguish real rays from later backward extensions by an explicit legend.

For A set lens center to zero and object tip to(-30,+4) in centimeters. The refracted parallel ray obeys y=4−0.4x and the center ray y=−(2/15)x. Their intersection is(15,−2). This cross-check uses declared ideal optical coordinates, not PDF curve-control coordinates or an assumed app equation parser.

Recalculate the fifteen-centimeter object and twofold image

For B change only object distance to 15 cm, retaining f=10 and height 4. Then 1/d_i=1/10−1/15=1/30, so d_i=+30, m=−2 and image height−8 cm. It is inverted/enlarged beyond twice the focal length. Swapping 30/15 relative to A does not permit arbitrary swapping of all lengths; focus and signs remain conditions. Save a separate marked page rather than overwriting A and claiming an old bookmark returns to the original. Check each ratio with its own labelled image height.

As another control use d_o=20 cm: d_i=+20, m=−1, height−4 cm, at twice the focal length. Equal-size inversion differs from A’s reduction and B’s enlargement; all outside-focus objects need not share a size. Keep this control separate while retaining f=10 and object height 4, without mixing its numbers into A/B labels.

For a five-centimeter object use backward extensions

For C use d_o=5 cm:1/d_i=1/10−1/5=−1/10, so d_i=−10, m=+2 and image height+8 cm. Outgoing rays diverge rightward; dashed backward extensions meet 10 cm to the left, forming an upright enlarged virtual image. Extensions are not backward-traveling light or a change to a diverging lens. An upward image arrow is not necessarily a real luminous object. Keep the negative sign instead of moving the image right for layout. Drawing a virtual location does not mean a paper screen there can receive it.

Do not invent a finite distance at the focal point

For the boundary d_o=10 cm, the equation gives 1/d_i=0. Ideal outgoing rays are parallel; there is no finite image distance to enter. Do not write d_i=0, which differs from its reciprocal tending to zero, or reuse A’s 15 cm. “At infinity” remains an ideal paraxial statement, not a measured infinite distance with a real lens. Keep inside, outside and exactly-at-focus cases distinct rather than assuming the word converging guarantees a real intersection at every object distance.

Check signs and line styles together while reading

Arrange A/B/C and the boundary in a readable PDF. In ManYue find the marker, then compare object distance, image distance, magnification and height. Enlarge intersections through visible controls; bookmarks identify report pages, not recognized equations or automatically corrected rays. Repair crowded labels externally instead of guessing a hidden minus. Model centimeters are coordinates. Pinch zoom changes display scale, not f=10 into another focal length, and screen rulers do not measure actual optical imaging.

Reopen and classify images by actual ray intersection

Reopen and recalculate 30→15, 15→30 and 5→−10 with heights−2,−8,+8, identifying which two use actual outgoing intersections. Acceptance includes the no-finite-distance boundary and C’s dashed extensions rather than memorized size categories. Redefine/recalculate changed focal length, medium, object position or sign convention. Preserve drawings/calculations and state that no physical-lens, camera or screen optics test occurred; diagram reading is not an added automatic ray tracer.
