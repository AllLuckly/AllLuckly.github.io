After entering a short passage with Jianlai, supported iPhone systems and hosts can speak a selected passage using Speak Selection. Jianlai enters the text; system accessibility supplies speech. Hearing speech does not establish that text is correct or make speech a Jianlai feature. Use fictional sentences to check committed text, selection and sound feedback separately.

Prepare safe practice text

Create a test page in an ordinary notes app. Confirm Jianlai is enabled in system keyboards and select an actually visible Chinese input mode. Prepare two fictional sentences on separate lines: “明天带雨伞” and “今天不带雨伞”. Do not enter real plans, names or other private details. Choose a place suitable for brief sound, set a comfortable volume and remain aware of your surroundings. If sound cannot be played, still check text and mark speech not tested. You do not need to record the system voice or send these sentences to anyone.

Record the original settings

Apple's accessibility instructions say enabling Speak Selection allows selected text to be spoken; names vary by system version and language. Record the current setting and sound output destination first. If you temporarily enable it, restore it from that record afterwards. Do not enable unrelated features or change account or security permissions. Apple's current guide places controls in the accessibility reading area of Settings; older versions can use different names. Follow the device and matching version's instructions, not a screenshot location alone. Recording the original state lets you restore it instead of treating a changed setting as permanent. Some hosts may not expose selectable text or a Speak menu; follow the actual interface.

Enter both sentences with Jianlai

Enter “明天带雨伞” and “今天不带雨伞” with an actual newline between them. Check “明天” versus “今天” and the second sentence's “不” character, then confirm both lines are committed to the note. An unconfirmed candidate is not body text. If you select a wrong character, locate and correct it locally first. These are comparison samples, not real plans.

Check the text baseline first

Before listening, compare both lines character by character with the reference. Record the first phrase, negative character and order. You may copy the non-sensitive text into a second test note as a baseline, confirming the copy is complete; copying is not device synchronization. Inspect the first sentence separately, then the second, especially whether the negation is present. Do not compare line length alone. If the copy differs, record the difference and establish a matching baseline rather than treating different text as one comparison. Mark uncertain characters and do not infer your original entry from a voice heard later. Voices, languages and punctuation may produce pronunciation different from personal expectations.

Enable and find the speech entry

Follow the current iPhone settings and Apple's guidance to find the accessibility reading controls. If the entry is unavailable or unsupported, mark incomplete instead of installing an unknown substitute. Confirm Speak Selection is enabled as shown, then return to the test note. Settings labels and layout can change, so use what appears on the device. If it was already on, no change is needed.

Select and speak only the first sentence

Select the first sentence in the note and inspect selection boundaries so the second is not included. Use the system's actual Speak action and record the selected text, whether sound was heard and approximately what was spoken. If the menu has no Speak action, first check selection and the system setting, then honestly record inability to complete. Do not confuse Jianlai key sounds with system speech. If hard to hear, first verify output destination and volume rather than changing several settings at once.

Select the second sentence separately

Select the second sentence and verify that “不” is within the selection, then use the visible speech action. Record whether the negative character was heard and the actual spoken range. If unclear, mark uncertain rather than filling in the expected result. Keep voice settings and host constant across rounds; do not attribute changes caused by a different device or language to the keyboard. Afterwards check that neither sentence was replaced.

Compare text and speech

Keep three columns: character-by-character body result, actual selection and sound feedback. Correct text with speech not tested is not a sound pass; speech that sounds plausible with extra or missing characters is not a text pass. Speech synthesis pauses, pronunciation and language detection can affect what you hear, so inspect committed text as the basis for character accuracy. Users must independently assess factual meaning rather than relying solely on machine speech.

Restore and finish

Record device and system versions, visible entry, both round results and reasons for unexecuted steps. If Speak Selection or sound output was changed, restore it from the starting record. Keep or delete the non-sensitive note as you prefer. Do not share recordings or screenshots containing private content. This guide uses Apple's public accessibility documentation and does not claim step-by-step testing on a personal device.
