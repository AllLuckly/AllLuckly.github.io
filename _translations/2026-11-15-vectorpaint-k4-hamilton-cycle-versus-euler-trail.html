Visiting four vertices once does not use all six edges. Draw undirected K4 in VectorPaint, mark a cycle through every vertex and back to the start, then separately test for an edge-once trail. A Hamilton cycle and no Euler trail can coexist. The drawing is manual explanation, not a route solver.

Declare four vertices and six undirected edges

On an approximately 1700×1500 canvas use A=(800,300),B=(300,1200),C=(1300,1200),D=(800,800). Join AB,AC,AD,BC,BD,CD once each. Edges are undirected, without one-way arrows. D is a declared node, not an accidental crossing; this plane layout avoids extra crossings. Coordinates are layout, not real roads, distances or travel speeds.

Write separate acceptance conditions

A Hamilton cycle visits each vertex once except the closing return; an Euler trail uses each edge once and may revisit vertices. An Euler circuit additionally closes. Keep separate task cards and label which condition a route tests. Four letters do not prove edge coverage, nor six edges prove unique vertices. Colours and order numbers track traversal, not directions, edge counts or weights.

Check A-B-C-D-A step by step

For A-B-C-D-A, traversed edges AB,BC,CD,DA all exist. Each vertex occurs once except the final closing A, so this is Hamiltonian. An intermediate return would differ. Highlight these four edges while retaining unselected AC and BD, not deleting them into a four-edge cycle graph. The selected route has four edges; K4 still has six. Label selected/unselected edges to expose incomplete edge coverage.

Verify degree three at all four vertices

Each vertex neighbours the other three, so all four degrees are 3, odd. Degree sum 12 divided by two gives six edges. Endpoint incidences are not separate edges, and highlighted edges contribute no doubled degree. Interior D still has three neighbours. List neighbour names before degrees rather than relying on visible strokes; adjust overlapping drawing while preserving the declared model.

Use odd degrees to exclude an edge-once trail

In a connected undirected Euler trail, internal visits pair entry/exit, allowing at most two odd-degree endpoints; an Euler circuit has all even degrees. K4 has four odd vertices, so neither exists. Confirm connectivity and use degrees, not crossings or one drawing failure. Its Hamilton cycle remains valid because the constraints concern different objects. Put nonexistence on the edge-once card, not the vertex-once card.

Use a failed attempt as evidence to inspect, not proof

Try A-B-C-D-A-C separately: five distinct edges AB,BC,CD,DA,AC. C has no unused incident edge while BD remains. This illustrates getting stuck, not universal failure; four odd degrees supplies the proof. Revisiting A is allowed for Euler, so that alone is not the fault. Retain unused BD instead of deleting it, and do not continue over an already used edge under the edge-once rule.

Troubleshoot missing edges and closing-vertex confusion

For a claimed Euler trail inspect omitted AC/BD, then list each consecutive pair and require all six once. Distinguish final closure from intermediate repeats when assessing Hamilton. A disconnected crossing-like D is not this K4; restore the model. Correct model or route separately, not definitions and graph together. Keep faint endpoints visible beneath highlights and move labels without connections. Styling does not automatically certify completeness or optimality.

Reopen and assess the two task cards separately

Save native work, export PNG and reopen. Check four vertices/six edges, then trace the Hamilton cycle and two unselected edges. Inspect four degree-threes and the Euler nonexistence argument, keeping the failed attempt separate. Reopen editable model/route/text. Success supplies a vertex cycle and excludes an edge trail, not a vague one-stroke claim or a rule for every four-vertex graph.
