Captions and text alternatives have different roles. Use a self-made sample to record visual information and actual device output separately.

Separate the image, caption and text alternative

An EPUB image can have the image itself, a visible caption and a text alternative for assistive technology. W3C recommends alternatives that convey essential information for informative images; purely decorative images can use an empty alternative. These need not be identical. Whether Book Isle and device assistive technology expose each item must be observed on the actual versions; silence does not prove an EPUB has no alternative.

Prepare self-made test content

Choose an EPUB copy you created or are authorized to inspect, containing a simple chart, visible caption and author-provided alternative, plus a decorative image for comparison. Without a sample, plan one on paper: a self-made bar chart with A = 2 and B = 5, captioned only “Figure 1,” with alternative text giving both values. Do not alter protected originals or distribute unauthorized images.

Record visible information

Open the sample visually and record chart title, both bar values, units and caption, noting which information comes from the graphic and which from the caption. Do not guess values solely from bar height. If the image is illegible, mark unknown. For the decorative image record its location; attractiveness alone does not establish that it contains data requiring narration.

Optionally inspect the source

If the file owner has rights and knows EPUB structure, inspect the image-containing XHTML read-only in an isolated copy. Check the img alt attribute, caption text and image resource location. Empty alt and missing alt are distinct; W3C recommends an empty alternative for purely decorative images. If inspection is unavailable or a chart has a longer description elsewhere, record known entry points and unknowns. Do not remove images or edit the original.

Establish the page in Book Isle

Open the same EPUB in Book Isle and find the image using the contents or search controls actually offered. Confirm book, chapter and caption. Record system version, app version and time. If the image is absent, first verify file integrity and copy identity. A visible caption does not prove an alternative exists, and text inside an image is not automatically selectable text.

Observe assistive output

If the device and personal workflow permit, use existing system assistive reading in the Book Isle page following current device help. Record original accessibility settings first. At the image or caption, write what is actually spoken and the focus location. Without audio, familiarity or exposed focus, mark unperformed or not observed; do not require someone to disable their usual accessibility settings.

Compare completeness of chart information

Keep visible chart, caption and actual speech in separate columns. For example, the graphic shows A = 2 and B = 5 while the caption is only a figure number. Record actual words if both values are conveyed. Hearing only the caption once does not establish that the source has no alt or that all chart information was obtained. A complex chart may need a longer description; a short title is not automatically its data equivalent.

Compare the decorative image

Under the same reading conditions observe the self-made decorative image. Silence may fit its decorative role, but check source and actual focus before concluding. If a name is spoken, record it without inferring author intent directly. Whether an image is decorative depends on its contextual purpose, not simply on the absence of numbers.

Investigate differences and retain evidence

If an image is visible but not spoken, first check whether focus reached it, that the EPUB edition matches and that system assistive reading works as expected. If useful, compare the same authorized copy in another reliable reader. Record device, versions, steps and actual output without disclosing a private document. Do not alter original structure or generalize one client’s behavior to every device.

Define a concrete observation table

Use five columns: object, visible content, confirmed source description, actual assistive output and open questions. For the self-made chart record A = 2 and B = 5, then check whether units and axis labels exist; do not invent missing units. A caption of “Figure 1” identifies a figure but does not independently convey both bar values. If a full table or long description is present, record its location and actually test whether it can be reached.

For the decorative image, record empty alt only if source inspection confirms it. If the file was not inspected, mark that unknown. Whether assistive technology skips the image is a separate observation because device settings, focus and reader implementation may affect output. Confirm the same file, chapter and image before comparing results.

A report to the publisher can include title, edition, chapter, figure number and sanitized steps without uploading private books, full pages or account information publicly. When nothing is spoken, report “not heard in this test” with device and software versions rather than declaring a feature unavailable everywhere.

Restore and hand off

Restore the recorded device settings and confirm the original EPUB, bookmarks and notes are unchanged. Separate visual graphic, caption, source inspection, assistive output and unperformed steps in the results table. Keep chart values distinct from personal inferences. Based on public W3C guidance, this guide claims no Book Isle device or assistive-technology test.
