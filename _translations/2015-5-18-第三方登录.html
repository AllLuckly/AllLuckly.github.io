Apple recently introduced a review rule against directing users to install third-party software, so third-party login should not prompt users that the app is missing. The best approach is to hide the option or disable it and gray it out. Put the following code in the login view controller's viewDidLoad method. The commented-out section hides the icons. These examples mainly cover QQ and WeChat.

// Check whether the app for third-party login is installed; if not, disable its icon and make it gray
