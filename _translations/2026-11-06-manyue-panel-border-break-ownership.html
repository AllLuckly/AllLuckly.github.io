A hand extending into a gutter or an object crossing two panels may seem to enter another scene. Choose a border-breaking composition in ManYue and manually check attachment, frame and neighbouring imagery. This concerns ownership within the original page, not a blanket diagnosis of clipping, and requires no automatic panel segmentation or rearrangement.

Establish the full page and visible gutters

Choose a completed authorised page and record edition, chapter, crossing object and the two neighbouring panel positions. Return to a view showing all four page edges to rule out zoom-hidden borders. Compare the identical source first if edges are missing, postponing interpretation. Start with one arm or prop rather than an explosive collage. Gutters separate panels but may contain intentional overhang; their usual blankness does not make every intrusion an application alignment error.

Trace attachment back to body or setting

Follow the overhang to wrist, sleeve, handle or contact and record where it connects to a figure or object. Similar colour is insufficient without contour, occlusion and orientation. In an invented case, an arm crossing the right panel’s left edge can belong to the right-hand figure if traced to that shoulder. Its palm lying above the left panel does not make it the left figure’s hand. Leave hidden middle sections uncertain; invented guide lines are not original evidence. Establish attachment before discussing sequence.

Check which border is interrupted

Check whether the border disappears behind the object, crosses in front or was never closed. Log each overlap instead of imposing one page-wide rule from a crossing. A hand hiding a frame establishes graphic layering, not necessarily a physical frame inside the story. Verify a broken line against the source to exclude low resolution. Return from zoom to the whole page to identify the line correctly. Record overhang, borderless composition and damaged border as different observations.

Check neighbouring scene identities separately

Describe people, place, time cues and action in each panel before deciding whether they share a scene. Overhang does not automatically merge spaces, particularly across times or close-ups. Retain explicit cross-panel interaction jokes where wording and action support them rather than ruling them out in advance. One connected object does not erase conflicting surroundings. Use same scene, different scene or unknown for story space, keeping that judgement separate from graphic front/back layering.

Test whether overhang changes a candidate reading order

Read once in the page’s usual direction, then inspect whether the object draws attention elsewhere and whether dialogue or action supports it. Visual attraction is not an explicit reading instruction; compare two candidate orders for pronoun or continuity problems. An invented finger pointing toward a lower panel still needs sentence links rather than being treated as a navigation arrow. Separate initial order from rechecked understanding. Changing tap-to-turn mapping does not repair ordering inside an original page; those are different operations.

Use a non-overhanging part of the page as a control

Compare a same-page panel with an intact border and no overhang. If every border is blurred, inspect display and source rather than calling one unclear region special composition. A uniquely interrupted target border is supporting evidence, not proof of a single authorial intention. Change only the observed region, not edition or crop at the same time. Label any self-made diagram approximate: it explains the judgement without adding connections to the original work.

Save the full page and junctions, then return

Save a supported page bookmark or external locator with crossing point, attachment and both panel positions. Leave the reader and return, checking full page before junctions to exclude another similar pose. Add chapter and complete-page identity to a palm-only favourite, which cannot establish which frame it crosses. Tall images need stable object locators beyond percentage. Recheck cropping and lines after source changes, without promising finger-level bookmark mapping or splitting the original page for convenience.

Finish ownership and error classification

Finish by identifying ownership, hidden border segments, scene relationship and unresolved attachment. Graphic layers differ from story space, and broken borders can reflect poor or missing source detail. Retain alternative ownership when uncertain rather than altering lines to create an answer. State observed relationships and limited order evidence separately from surprise or dynamism. Future discussion can then return to an actual junction instead of calling all overhang a layout error.
