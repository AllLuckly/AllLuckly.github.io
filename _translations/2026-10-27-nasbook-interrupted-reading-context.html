A saved position does not restore your memory of the preceding argument. Keep a small context record before pausing, then verify it against the text when returning. The workflow uses location and personal notes rather than a full-book summary or automatic reconstruction.

Record the unfinished question before pausing

Write one sentence about the current action or argument and the next reading task, keeping it distinct from quotation. Record date and edition. If no pause note exists, recover only what the text supports instead of inventing a remembered conclusion.

Save a verifiable return anchor

Test a bookmark or note return, then record chapter and a distinctive phrase for reflowable text, or both file and printed page numbers for PDF. For scans, use a page/image reference externally. Position and understanding are separate; a percentage alone does not identify the unfinished argument.

Confirm the same edition on returning

Check title, creator, translator and file source before trusting the resumed percentage. If the edition changed, locate the old phrase or chapter, inspect differences and create a new reference while preserving provenance. Do not skip content simply to match an earlier percentage.

Read back to a complete unit of meaning

Read back to a scene, subsection, definition or premise sufficient to explain the current passage. Choose the boundary by meaning rather than a fixed page count. Use contents and earlier notes when necessary. Recover enough context to continue instead of rereading the whole book for appearance or statistics.

Search a verified phrase when needed

Use a short recorded phrase in the actual text-search scope, checking readable extractable text first. Refine wording for edition changes without treating an empty query as missing notes. For scans use contents or page/image references. Open surrounding text after a match; the search snippet is only a locator.

Compare the pause note with present understanding

Compare the pause note with the recovered passage and add a dated correction instead of overwriting history. Distinguish changed interpretation from changed source text. Retain unresolved questions for subsequent reading. A few precise sentences are enough; a polished new summary is unnecessary.

Set the next stopping point deliberately

Continue to a natural boundary and update the pause note only with useful new context. Test the new anchor and retain old ones as needed. Across devices, follow existing sync and verify the same book file separately. Export important notes where available without treating a screenshot as complete recovery data.

Acceptance without an earlier note

Finish when the preceding context is explainable and reading continues from verified text. Without an old note, reread from a confirmed boundary and distinguish memory from checked facts. Resolve unavailable files separately. A short clear pause record is sustainable without accumulating unexplained highlights.
