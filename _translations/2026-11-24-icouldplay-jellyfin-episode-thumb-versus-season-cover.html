Use two self-made images in an isolated shows library to compare season cover and episode artwork scopes.

Understand two artwork scopes

Jellyfin distinguishes series, season and episode artwork: cover.jpg in a season folder can serve as its cover, while a -thumb.jpg image following an episode filename can serve as that episode’s primary image. These are server-side identities and do not guarantee that every iCouldPlay page displays the same type. An episode image is also not a chapter preview on the playback timeline. Check the server before recording client presentation.

Prepare isolated samples

Have an administrator prepare two self-made or authorized short videos and two self-made JPG images in an isolated shows library: one labeled “SEASON” and one “EPISODE 1,” with clearly different colors. Preserve original videos and images. Avoid family photos, someone else’s copyrighted posters and real account details; the labels identify the samples and need not contain an actual series title. Open both images in a viewer first to confirm their colors and text, and keep unrenamed sources so an image defect can be distinguished from server recognition.

Set up the series hierarchy

Create a folder for a fictional Practice Series (2030), with Season 01 inside it. Put two video copies there, for example Practice Series S01E01.mp4 and Practice Series S01E02.mp4. Extensions must match the actual video; renaming one does not convert a format. Record opening pictures and locations, check that nothing was overwritten, and have the administrator scan the library.

Place only the season cover first

Before the next scan, copy the self-made SEASON image into Season 01 as cover.jpg and do not add an episode image yet. Have the administrator scan normally and wait. In the Jellyfin web interface record the artwork shown for series, season and each episode separately; do not automatically attribute the season card image to every episode. If the custom cover is absent, check path, filename, read permission and scan status.

Add first-episode artwork

Copy the EPISODE 1 image into the same season folder as Practice Series S01E01-thumb.jpg, matching the first video’s base filename. Do not name it the season’s cover.jpg. Leave episode two without a dedicated sample as a control. Episode two may show an image generated by the server or supplied by a provider, so the control records actual source and position rather than requiring a blank image. Record spaces and case in filenames and ensure the image is actually JPG; renaming an extension does not convert an image.

Refresh and compare on the server

Have the administrator use a normal refresh or scan available in the installed version and wait for completion. Inspect the season and both episodes separately in the web interface. Record where SEASON and EPISODE 1 actually appear and whether episode two uses another picture. If the outcome differs from expectations, check the image prefix against the video base name, read permissions and existing server artwork sources before blaming a client.

Observe iCouldPlay presentation

Connect iCouldPlay to the same server under an account with test-library access. Find the season and both episode entries, recording the image or absence of an image at each location and whether the test lettering is visible. If the interface offers no place for a particular artwork type, write “not shown.” Confirm episode identity from the opening picture instead of assuming a thumbnail proves the correct short was opened.

Check cache and source

If the web interface shows the new image while iCouldPlay still shows an older one, record the screen first, then return, reopen or refresh using controls visible in the current interface. One old image does not prove a cache defect; first verify the same server, account, item and display location. Existing server artwork or other providers can also affect results. Ask an administrator to investigate rather than deleting real-library artwork or changing global settings.

Distinguish episode and chapter images

An episode image identifies the episode as a whole; chapter images relate to particular points within video and differ in generation, storage and use. This exercise does not require generating chapter images or assume iCouldPlay must show timeline previews. If static text appears during playback, identify whether it comes from the video itself, episode page or timeline control and record those observations separately. During playback also verify the current time and audio so playback failure is not conflated with static-artwork differences.

Handle cropping and readability

If SEASON and EPISODE 1 are unreadable on small cards, increase contrast and margins in the preserved source images, replace only test copies and record the before-and-after refresh. Do not overwrite real posters. Different pages can choose different dimensions and crops; visibility on the server does not guarantee identical cropping in iCouldPlay. Keep a screenshot or short note if uncertain, removing private addresses. Use the same account and item for before-and-after checks, avoiding an apparent difference caused by another same-named test entry.

Restore or clean up and hand over

Have the administrator retain or remove the two self-made images and video copies under the test-library agreement, confirming originals and real posters remain unchanged. Record season and episode filenames, relative paths, web locations, actual iCouldPlay presentation and unperformed steps. If permissions or display remain problematic, preserve observations rather than reporting fabricated success. This guide uses public sources and claims no private-server or device operation.
