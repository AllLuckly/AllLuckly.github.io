An original recording and short edit can share artwork while differing in duration and dialogue timing. iCouldPlay metadata helps locate a work without identifying every file edition. Use your own full and shortened demonstration to map scenes, progress and subtitles separately, avoiding unverified assumptions across copies.

Establish versions from the source files

Retain independent originals and edits, recording names, sizes, durations and production dates. Copy dates alone do not establish chronology. Open both and locate actual cuts rather than overwriting unique footage to manufacture a test.

Use understandable original and short-edit names with genuine extensions. Resolution, codec and length are separate dimensions; equal durations can still hide track or quality differences. Record known facts and leave uncertainties blank instead of trusting full-version or high-quality filename claims.

Choose three content anchors independent of time

Describe a distinct opening, middle and ending event, then find each timestamp in both versions. Times aid navigation and events establish content, which is more reliable than applying one progress percentage to another edition.

Mark absent scenes as missing rather than substituting neighbours. Insertions, introductions and alternate endings need not share one constant offset. Establish real differences before planning subtitles or transferred reading positions instead of assuming identical content.

Separate metadata from file identity after import

Import both copies, check sources and durations and inspect openings. Automatic matching may identify the same work without making files identical. Use your inventory to identify the chosen cut; shared artwork does not prove duplication and different display names do not prove different content.

For a missing second entry, check name handling before deleting anything. Give an external copy a clear name when independent retention is needed. Metadata editing cannot extend a short cut or guarantee a universal rematch control; use actual available operations.

Transfer scene references rather than progress numbers

Leave the original at a clear scene and record content and time. In the short version, find the same event through the map before continuing. Different paths and entries need actual progress checks; matching work metadata does not promise automatic merging.

Pay attention around cuts, where nearby times can represent different sections. Watch missing explanations in the original if necessary before entering shared content. Reopen the current version and confirm continuing selects the intended file rather than merely familiar artwork.

Keep subtitle counterparts explicit

Label each subtitle's video edition and inspect dialogue near beginning, middle and end. Original subtitles can become suddenly displaced after a short cut; one delay value may not repair it. Identify the relationship before choosing matching captions or creating an independently edited subtitle copy.

Audio commentaries and live sound may contain different words, so listen beyond track labels. Distinguish recorded text from external captions: disabling the latter does not remove the former. Preserve both original and revised captions instead of overwriting a working full-version timeline.

Decide what to retain long term

Full recordings suit archives and short edits repeated viewing; both can remain useful. Choose purpose before space cleanup. Before removing a test copy, verify independently retained originals and captions and read deletion scope rather than assuming card removal cannot affect files.

Apply the same checks to server versions and note any transformed playback copy. Mobile duration alone does not establish server-original identity; compare content and parameters at the source. Map work, file and playback path separately to explain cross-device differences.

Verify using the version map

Choose an entry and identify it using source, edition name and scenes, then locate shared content. If artwork guesses or memory remain necessary, improve the map. One row per edition with original location, duration, differences and subtitle name is sufficient if understandable later.

Completion means knowing each file's edition, intended use, continuation scene and caption counterpart. Append future revisions instead of erasing old relationships, repeating three-location checks. Metadata improves discovery; content verification establishes an accurate version choice.
