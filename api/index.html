PUBLIC DATA

公开数据接口

给站内搜索、阅读工具和 AI 阅读器用的几个数据入口。这里返回已经生成好的文件：取回索引，在本地筛选，再打开需要的文章。

Public, read-only static JSON resources. Download an index, filter it locally, then follow an article's url or markdown_url. No authentication, server-side search, query parameters or pagination.

文章索引

两个入口分别返回该语言的完整文章元数据数组，包含教程、作品和开发笔记。内容随网站发布更新；date 是文章原始发表时间，不能当作应用当前版本的证明。

地址返回内容
/search.json中文文章，lang 为 zh-CN
/en/search.json英文文章，lang 为 en

使用 GET 读取 JSON，使用 HEAD 查看响应头。没有关键词查询、分页或排序参数；添加 ?q=… 不会执行搜索。需要筛选时，在自己的程序里处理返回的数组。例如，读取英文索引后查找包含 “VectorPaint” 的文章：

const response = await fetch('https://allluckly.cn/en/search.json');
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const articles = await response.json();
const query = 'vectorpaint';
const matches = articles.filter(article =>
  [article.title, article.description, ...(article.keywords || [])]
    .join(' ').toLocaleLowerCase().includes(query)
);
console.log(matches.slice(0, 5));

字段怎么读

字段含义
title、description文章标题和纯文本摘要。
url、markdown_url文章网页和可直接读取的 Markdown 正文绝对地址。
date、shortdate带时区的发表时间和用于展示的英文日期字符串。比较时间请用 date。
lang、category内容语言和原文分类；部分历史文章的分类为 null。
author原作者姓名。缺少署名时为 null；引用时请以正文署名与来源说明为准。
app_name、keywords应用名和关键词数组，用来辅助筛选。是否适用于某个应用，应再核对正文；keywords 可以是空数组。
version_note历史技术文章的版本限制说明，没有说明时为空字符串。旧代码和旧 API 请先核对当前文档。

阅读技能目录

/.well-known/agent-skills/index.json 返回阅读技能的名称、说明、文件地址与 SHA-256 摘要。url 可能是站内相对路径，请以 https://allluckly.cn/ 为基址解析后读取，再用 digest 核对下载文件的完整字节。

目前的技能说明如何查找教程、视频和历史技术文章，以及如何保留作者、版本限制与引用链接。它是公开的操作说明文件，不会调用后台服务或代替用户操作。

访问与缓存

这些入口匿名可读，不需要账号、API Key、Cookie 或授权头。站点没有写入 API；应用中的个人书库、播放记录等内容也不在这些索引中。详细访问边界见 访问说明。

索引是完整快照，建议缓存并复用。可保存响应的 ETag，下次通过 If-None-Match 发起条件请求；未变化时会返回没有正文的 304，继续使用已缓存内容。缓存时长请以实际 Cache-Control 为准，不必反复下载同一文件。

请沿文章链接读取正文后再引用。历史转载保留原作者与来源；可公开访问不代表可以去掉署名、整站转载或用于训练，使用偏好见 robots.txt。
